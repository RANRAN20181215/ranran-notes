# 📝 冉冉错题本

> 把丢的分变成进步的台阶

---

## 使用指南

每次考试/练习后，把错题记下来，按 **错因** 分类。

### 错因标签

| 标签 | 含义 |
|:---:|:-----|
| 🗳️ **粗心** | 会做但写错、看错数、漏题 |
| 🤔 **概念不清** | 这个知识点没真正理解 |
| 📖 **读题** | 题目没看懂就下笔了 |
| 💪 **计算** | 进退位算错、口诀背错 |
| ⏰ **超时** | 会做但来不及写完 |

### 格式

```markdown
## 2026-05-25 | 数学 | 期中考试

### ❌ 题目
（原题描述）

### ✅ 正确答案
（正确答案）

### 💡 错因
标签：🤔 概念不清

### 📝 分析
（为什么会错、怎么避免）
```
