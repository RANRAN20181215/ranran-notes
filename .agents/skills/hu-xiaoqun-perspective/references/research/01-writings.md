## 一、人物背景

**胡小群**，原复旦大学附属中学（复旦附中）数学名师，数学科普作者。曾获教育总课题国家一等奖，出版多部数学培优教材及讲义。现为 B 站 UP 主（ID：**胡小群讲数学**），粉丝约 **5.6 万**。

---

## 二、B 站内容矩阵与核心观点

### 2.1 教育理念：源头活水，回归本质

胡小群的教育核心理念可概括为 **"源头活水"**——强调数学学习应当追根溯源，理解概念的来龙去脉，而非机械记忆套路。这一理念贯穿其所有内容。

#### 反对过早使用方程
- 在《列方程解应用题的好处是什么？为什么说太早学方程也不是好事？》中，他指出过早引入代数方法会阻碍孩子对算术思维和数量关系的深入理解，主张在小学阶段应该充分发展算术推理能力。

#### 反对"模型化"教学
- 他的视频"痛批'胡不归'模型"（虽然非本人视频，但出现在其推荐列表中）代表的立场是：反对将数学解题过度套路化、标签化，认为"模型"教学助长思维懒惰。

#### 基础概念的深度追问
- 《减法去括号为什么要变号？》—— 7.5 万播放
- 《为什么没有除法分配律？》—— 2.2 万播放
- 《为什么到了初高中，我们就不大看到除号了？》—— 1181 播放
- 这些视频体现他的核心方法：对每个看似"理所当然"的规则追问"为什么"，从数学本质出发解释运算规则。

### 2.2 学科本质：数学是思维的语言

#### 数学好 = 语文好？
- 《你以为的数学好，其实是语文好》—— **6.3 万播放**
- 核心论点：数学学习中的困难，根源往往是阅读理解和语言表达能力不足。数学问题本质上是"阅读理解问题"，需要从文字中提取数学结构。

#### 平面几何不可替代
- 《要把平面几何赶出教材？看看原复旦附中名师怎么说！》—— **2.6 万播放**
- 他捍卫平面几何在数学教育中的地位，认为平面几何训练的是逻辑推理和空间想象，是其他学科无法替代的思维训练工具。

### 2.3 计算学习：反对机械刷题

- 《计算不行，练就完了？小心踩中计算学习这三大误区！》
- 《一个视频给孩子彻底讲明白乘法分配律》—— **2.8 万播放**
- 《数学草稿应该怎么打？》
- 他认为计算能力不能靠刷题堆砌，而需要理解算理、规范打草稿习惯、培养数感。

### 2.4 社会评论：尖锐敢言

胡小群不回避教育热点，其评论风格犀利：

#### 深圳南山期末卷事件
- 《深圳南山期末卷不是改革方向，是彻头彻尾的命题事故》—— **14.9 万播放**（最高播放量）
- 严批南山试卷将阅读量堆砌当作"素养考查"，认为这是"以教育的名义给孩子做出了最坏的榜样"。

#### 指标到校政策
- 《"指标到校"可能是一个弊远大于利的招生政策》—— 1525 播放
- 对分配生政策可能带来的消极影响提出质疑。

#### 教育内卷
- 《为什么我的复旦同学都放弃鸡娃了？》—— **3.5 万播放**
- 以复旦同学的亲身经历为素材，反思"鸡娃"文化的性价比与副作用。

#### 教师专业素养
- 《有些数学老师，常常忘了自己是个职业选手》—— **3.2 万播放**
- 批评部分数学教师将教学套路化为己任，却丧失了作为数学专业工作者的本质追求。

### 2.5 学法指导

- 《什么是数学学习的融会贯通》—— 最新视频（2026-05-13）
- 《从高中回头看，初中数学的学习重点和常见的误区是什么？》
- 《2025高考数学透露什么信号？》—— **4.1 万播放**
- 《什么是数学天赋？怎么判断孩子的天赋？》
- 系统性地从小学到高中给出数学学习路径建议。

### 2.6 关于他的课

- 《胡老师的课，挑家长！》—— 1961 播放
- 这一标题本身就是鲜明立场：他的课程需要家长有相当的认知水平，否则难以理解和配合。暗示他的教育内容不是"速成提分"类，而是需要家庭共同参与深度理解。

## 三、风格特征总结

| 维度 | 描述 |
|------|------|
| **语言风格** | 理性严谨，偶带讽刺，以理服人而非情绪煽动 |
| **受众定位** | 有一定认知水平的家长、一线教师、对教育有思考的群体 |
| **内容深度** | 中等偏深，不回避数学本质，但不追求学术化表达 |
| **话题广度** | 从 K12 数学具体知识点，到教育政策评论，再到学习方法论 |
| **价值观** | 反对套路化、反对过早分化、推崇理解式学习、关注思维发展 |
| **与其他创作者对比** | 比一般"解题技巧"类 UP 主更关注教育理念；比纯科普类更贴近应试现实；比鸡汤类更硬核有料 |

## 六、初步印象与判断

胡小群是一位 **"学院派出走"** 的教育 KOL——有顶级中学的一线教学经验，有系统的教育研究背景，选择通过自媒体发声。他的内容兼具：

- **学院的功底**：对数学本质的理解扎实，不是"网红教培"出身
- **公共知识分子的锐度**：敢于批评政策、批评同行、批评家长
- **产品经理的定位意识**："挑家长"本身就是筛选用户的策略

他的最大差异化在于：**大多数教育 UP 主讲"怎么解题"，他讲"为什么要这么想"**。这种回归本质的定位，在当下焦虑的教育市场中具备长期价值和稀缺性。
