## 一、关键决策

### 1.1 离开复旦附中（约2023–2024）

**已知事实：**
- 2008年入职复旦附中，2023–2024年间离开（确切时间未公开）
- 公开语态从"现任复旦附中教师"切换为"原复旦附中数学名师"
- 转型为独立教育内容创作者，运营抖音/B站/小鹅通

**公开提及的原因：**
- 未在任何公开资料中正面、详细解释离开原因
- 小宇宙节目（G大成长论 EP.54, 2024-08-13）提到："选择自己创业后，他在直播间里把这些思考讲了出来"
- 新民晚报（2024-07-03）将其转型描述为"转战直播领域"

**推断的可能原因：**
| 因素 | 推断依据 |
|------|----------|
| **影响力天花板** | 一个班级数十人 vs 线上百万家长——教育理念传播的规模效应 |
| **商业动机** | 在线课程（小鹅通200讲）+ 出书（《巧算大学问》《小学数学·一步到位》）的商业收益远超教职 |
| **言论自由度** | 胡小群公开批评教育政策（指标到校、深圳南山卷）、批评同行、批评家长，体制内可能受限 |
| **时间节点** | 2023年正值后疫情时代在线教育热潮，窗口期明显 |
| **教育理念实践** | 其在复旦附中期间的"概念教学法"或许在体制内推行受限，独立后可以完全按自己理念打造课程体系 |

- **他说过的/别人说他的/推断的**：他说过的（只说"选择创业"），其余为推断

### 1.2 选择小初高一体化路线

**决策内容：** 不按学段割裂教学，而是打通K-12数学脉络

**影响：**
- 课程产品线覆盖学龄前到高中
- 内容制作成本极高（200讲×每讲50分钟 = 约10,000分钟视频）
- 用户购买决策门槛高（全套课程价格不低）

**战略意义：**
- 这是与其"源头活水"理念最一致的产品策略——只有理解整个K-12体系，才能在每个学段做对选择
- 商业上也是高客单价、高LTV（用户生命周期价值）策略
- **他说过的/别人说他的/推断的**：他说过的（多篇访谈中阐述小初高一体化），推断的（战略分析）

### 1.3 以抖音/B站为主阵地

**决策内容：** 选择直播科普+短视频作为主要获客渠道，而非传统教培地推/学校合作

**特点：**
- 抖音：面向家长群体直播科普（"百万家长直播科普"）
- B站：945个视频，以教育理念和学科本质内容为主
- 个人网站（hxqjsx.cn）：承接流量，展示完整课程体系

**效果评估：**
- B站粉丝~5.6万（截至2026-05），增长缓慢但稳定
- 抖音直播观看量可观，但具体数据未公开
- 个人网站自称"全网200万+"，但无法独立验证
- **他说过的/别人说他的/推断的**：推断的

### 1.4 出版《巧算大学问》与《小学数学·一步到位》

**决策内容：** 从纯线上内容扩展到图书出版

**意义：**
- 增加收入来源（版税）
- 提升权威性（"正式出版物"的信任背书）
- 线上导流至图书、图书导流回线上的闭环
- 与图灵出版社合作，获中科院院士推荐

**出版过程矛盾点：**
- 编辑戴老师访谈透露：胡小群收到初稿时"有些不满"——暗示其对成品质量有高标准，但也可能反映控制欲
- **他说过的/别人说他的/推断的**：别人说他的（编辑描述）

### 1.5 公司化运营

**决策内容：** 注册上海奇课科技有限公司

**意义：**
- 从个人IP转型为正规化商业运营
- 可能涉及团队组建（内容制作、运营、客服）
- 推测公司设立时间在2023年左右（与转型线上同步）
- **他说过的/别人说他的/推断的**：推断的（仅抖音显示公司主体）

## 二、教学思想演变

### 2.1 思想演变时间线

```
2008–2018（体制内积累期）
  ├─ 实验班教学实践
  ├─ 参与命题工作（小升初、中考）
  ├─ 形成"概念教学法"雏形
  └─ 获教育总课题国家一等奖（具体时间不详）

2018–2023（思想成熟期）
  ├─ 开始系统反思应试教育弊端
  ├─ 形成"小初高一体化"框架
  └─ 准备转型线上

2023–2024（理念输出期）
  ├─ 抖音直播开始面向家长科普
  ├─ 明确"反套路"立场
  ├─ 出版《小学数学·一步到位》
  └─ 网易/新民晚报专访——理念开始广为人知

2025–2026（体系完善期）
  ├─ 全套K-12课程上线
  ├─ 出版《巧算大学问》
  ├─ 与柳智宇深度对谈——理念向"教育+心理"维度拓展
  └─ 《长谈》全面总结六大理念板块
```

## 三、自我标榜与事实对照

### 3.1 "系出名门"——⭕ 基本属实
- 复旦大学数学系毕业 ✅
- 复旦附中任教16年 ✅（年限有歧义，但总体属实）

### 3.2 "大部分学生考取清北复交"——⚠️ 归因偏误
- 复旦附中学生本身即为择优录取，升学率高是学校 + 学生的综合结果
- 将其归因于个人教学成果，属于媒体和本人共同受益的模糊表述

### 3.3 "曾获教育总课题国家一等奖"——❓ 无法验证
- 唯一来源是其B站个人简介
- 未查到具体课题名称、颁奖机构、年份
- 不等于虚假，但缺乏第三方验证

### 3.4 "全网200万+"——❓ 存疑
- 来自个人网站自称
- B站仅5.6万粉丝
- 抖音粉丝数未公开
- 可能指累计直播/视频触达人次而非关注数——存在包装空间

### 3.5 "参与各地小初高阶段的数学命题"——⭕ 可信
- 在冷月清谈文章（2025-05-26）中详细叙述了参与某大型小升初考试命题的具体经历
- 细节具体、场景真实，可信度高

### 3.6 "我自己的孩子也要看"——⭕ 核心承诺
- 反复出现在B站、媒体报道中
- 既是营销话术，也体现其教育理念——自己的课要先过得了自己这关
- 无法验证他孩子是否真的在看，但作为一个表达承诺是自洽的

## 五、决策风格总结

胡小群的决策轨迹呈现以下特征：

1. **理念驱动而非机会驱动**：小初高一体化是其理念的自然延伸，而非市场热门方向
2. **长期主义**：低频率出书、高投入课程制作，不走"日更抖音"式快餐路线
3. **价值筛选**："挑家长"主动过滤非目标用户，宁愿小而精不愿大而泛
4. **独立性优先**：离开体制、独立创业、拒绝机构合作姿态，保持言论自由
5. **品牌＞短期收入**：公开批评同行（吴彦祖卖课）、批评政策（深圳南山卷），宁可得罪人不愿损害公信力

这与"割韭菜"的指控形成鲜明对比——如果目标是最大化短期收入，策略会完全不同。
