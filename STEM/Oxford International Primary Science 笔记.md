## 导论：How to be a Scientist

**核心流程**（科学探究循环）：
1. **提问** — 用 "which / what / do / does" 开头
2. **观察** — "I am looking for..."
3. **预测** — 猜想会发生什么
4. **计划** — 设计怎么做、保持什么不变、改变什么
5. **记录** — 用表格整理结果
6. **结论** — 看结果，判断预测是否正确

**示例实验**：哪种材料能最久保持棉花干燥？

### 词汇
- 科学探究 (scientific enquiry)
- 提问 (ask questions)
- 预测 (predict / prediction)
- 记录 (record)
- 结论 (conclusion)

## 单元 1：Ourselves（我们自己）

### 1.1 相同与不同

- 所有人都是人类 (human)，但每个人长得不一样
- 所有人都有脸、鼻子、两只眼睛、两只耳朵、一张嘴、头发，但每张脸都不同
- 随着长大，我们会变高，脸和身体会变化
- 人们的喜好也不同

### 1.2 身体部位

**主要身体部位词汇**：
- 头 (head)、肩膀 (shoulder)、手臂 (arm)、手肘 (elbow)
- 手 (hand)、手指 (fingers)、腿 (leg)、膝盖 (knee)
- 脚 (foot/feet)、脚趾 (toes)

**身体连接关系**：
- 手指 → 手 → 手臂 → 肩膀
- 脚趾 → 脚 → 腿
- 膝盖是腿弯曲的地方

### 1.3 五感 (The Five Senses)

| 感官 | 感觉 | 使用器官 | 作用 |
|------|------|---------|------|
| 视觉 (seeing) | 看 | 眼睛 | 分辨颜色、形状 |
| 听觉 (hearing) | 听 | 耳朵 | 感知声音 |
| 嗅觉 (smell) | 闻 | 鼻子 | 气味好坏 |
| 味觉 (taste) | 尝 | 舌头（味蕾） | 甜/咸 |
| 触觉 (touch) | 摸 | 皮肤 | 硬/软、安全/危险 |

**知识点**：
- 猫的嗅觉比人类强约 14 倍
- 猫在暗处比人类看得更清楚
- 食物闻起来好、尝起来好，我们才喜欢吃
- 有些东西摸起来安全，有些危险

### 单元复习题举例
- 找路去学校最常用的两种感官：视觉 + 听觉
- 判断食物坏了的三种感官：嗅觉、味觉、触觉

## 单元 2：What Is It Made Of?（它是什么做的）

### 2.1 不同材料

**核心概念**：物体由不同材料 (material) 制成。同一功能的物体可以用不同材料。

**常见材料**：
- 石头 (stone)、木头 (wood)、塑料 (plastic)
- 蜡 (candle wax)、羊毛 (wool)、布料 (fabric)
- 金属 (metal)：铁 (iron)、钢 (steel)、铜 (copper)、铝 (aluminium)、金 (gold)、银 (silver)

### 2.2 材料性质 (Properties)

**性质就是材料的样子、手感、或能做什么**：

| 性质 | 反义 |
|------|------|
| 硬 (hard) | 软 (soft) |
| 光滑 (smooth) | 粗糙 (rough) |
| 闪亮 (shiny) | 暗淡 (dull) |
| 防水 (waterproof) | 透水 |
| 可拉伸 (stretchy) | 不可拉伸 |

### 2.3 材料的功能

**防水实验**：
- 用纸、卡纸、塑料、布包裹棉球放入水中
- 结果：塑料袋最防水
- 关键：保持其他条件相同（公平实验 fair test）

**拉伸实验**：
- 哪些材料可以拉伸？
- 橡皮筋可以拉伸

**金属的特性**：
- 通常硬且闪亮
- 加热变软后可锤打成形或拉成丝
- 敲击时发出铃声般的响声
- 特例：水银 (mercury) 是液态金属

### 2.4 金属与非金属

**非金属**：塑料、木头、玻璃、黏土 (clay)、橡胶 (rubber)、石头、布料

**橡胶的特性**：
- 可拉伸、有弹性、防水
- 由树木制成
- 用途：橡胶靴、橡胶球、橡皮筋、橡胶手套

### 2.5 材料分类

**分类依据**：按材料性质分组，而非按颜色（颜色分类不是科学方法）

**常见问题**：
- 桥为什么不用意大利面做？因为它不够坚固
- 衣服为什么用布料不用木头？因为布料更柔软、可弯曲

## 单元 3：Living and Growing（活着与成长）

### 3.1 生物 vs 非生物

**生物 (living things) 的特征**：
- 能呼吸 (breathe)
- 能生长 (grow)
- 能移动 (move)
- 能吃 (eat)

**非生物 (non-living things)**：不能呼吸、生长、移动或吃
- 曾经活过的（如死掉的植物）不算"活着"
- 从未活过的（如石头、椅子、塑料、玻璃）

### 3.2 动植物栖息地

**动物和植物喜欢在适合它们的地方生活**：

| 栖息地 | 典型生物 |
|--------|---------|
| 沙漠 (desert) | 棕榈树、蚂蚁 |
| 草原 | 羚羊 |
| 海洋 (sea) | 海星 |
| 森林 (forest) | 黑猩猩 |
| 北极 (Arctic) | 北极熊、仙人掌 |

**动植物生存需要**：
- 动物：食物、水、住所
- 植物：水才能生长
- 有些动物和鸟需要筑巢 (make a place to sleep)

### 3.3 饮食与健康

**健康饮食 (healthy diet)** = 五大类食物：

1. 水果蔬菜 (fruit and vegetables) — 多吃
2. 面包和谷物 (bread and cereals) — 多吃
3. 肉和鱼 (meat and fish) — 适量
4. 奶制品 (milk and dairy) — 适量
5. 脂肪和糖 (fat and sugar) — 少量

知识点：
- 需要喝大量水保持健康
- 不能只吃一两类食物，会不健康

### 3.4 家庭与成长

- 人类从婴儿 (baby) → 儿童 (child) → 成年人 (adult)
- 人类的宝宝叫做 offspring
- 动物也有家庭

## 单元 4：Pushes and Pulls（推和拉）

### 4.1 什么是力 (Force)

**核心概念**：
- 推 (push) 和拉 (pull) 都是力 (force)
- 我们看不见力，但力让物体运动
- 力无处不在

**证据**：学校里的运动物体——球滚动、旗子飘动、人走路

### 4.2 身体运动

- 我们自己移动身体也用力
- 走路时摆动手臂
- 手臂摆得快，走得快；手臂摆得慢，走得慢
- 推力和拉力是我们做每件事的一部分

### 4.3 让物体更快、更慢

**用力大小与速度**：
- 更大的推力 → 物体移动更快
- 更小的推力 → 物体移动更慢
- 力也可以让物体停止

**实践实验**：
1. 玩具车：推/拉让它动、用更大的力让它更快、用手让它停
2. 气球车：气球放气产生推力让车前进
3. 弹簧玩具：拉伸弹簧然后松手

### 4.4 风和水让物体运动

**风 (wind)**：
- 吹动树叶、帆船、风车
- 吹得越用力，风车转得越快
- 吹得轻，风车转得慢

**水 (water)**：
- 水流推动水车 (waterwheel) 旋转
- 水越多，水车轮转得越快
- 水停，轮子停

**风向与速度变化**：
- 吹泡泡实验：风让泡泡改变速度和方向
- 风吹散沙子的方向即风的方向

### 词汇
- 推 (push)、拉 (pull)
- 力 (force)、运动 (movement)
- 快 (fast)、慢 (slow)
- 停止 (stop)、方向 (direction)
- 风 (wind)、水 (water)

## 单元 5：Making Sounds（制造声音）

### 5.1 声音的来源

**动物发出声音的原因**：
1. 警告危险 (warn of danger)
2. 吓唬其他动物 (frighten)
3. 传递信息 (pass on information)
4. 交流 (communicate/talk)

**例外**：海绵 (sea sponge) 不发出任何声音交流

### 5.2 说话和倾听

**人类用声音交流**：
- 说话分享想法
- 唱歌——人类和动物都会
- 口哨——用来吸引注意力或娱乐
- 拍手——用力拍声音大，轻轻拍声音小

**动物之间**：
- 鸟唱歌传递信息
- 一些动物用声音警告同伴危险

### 5.3 身体制造声音

**实验**：用身体制造各种声音
- 口哨：抿嘴轻轻吹气
- 拍手：用力/轻轻，制造不同声音
- 拍手节奏练习

### 5.4 声音的远近变化

**核心概念**：声音离我们越远，听起来越安静 (quieter)

**实验：听声辨位游戏**
- 一人闭眼站中心（听者）
- 其他人在外围悄悄靠近
- 听者听到声音就转身
- 测量听到声音时的距离

**动物也利用这个原理**：
- 食肉动物的脚有软垫 (soft pads)，可以无声靠近猎物
- 斑鬣狗 (hyena) 就是悄悄接近猎物的

### 5.5 响度比较

**分贝计 (sound-level meter)**：测量声音大小的仪器

**紧急车辆**：
- 警车、救护车、消防车都有警笛 (siren)
- 警笛作用：告诉人们有危险 / 告诉人们救援来了 / 让其他车辆让路

### 5.6 听觉

**耳朵如何工作**：
- 声音从发出地点传入耳朵
- 两只耳朵帮助我们听到来自四面八方的声音
- 眼睛和耳朵一起工作帮我们保持安全（如过马路）

**趣味知识**：
- 人类只能听到部分声音，飞蛾能听到比人类更多的声音
- 螳螂 (praying mantis) 只有一只耳朵

**过马路安全**：
- 使用眼睛（看）和耳朵（听）
- 两只耳朵比一只听得更好

## 单元 6：Growing Plants（植物成长）

### 6.1 植物的主要部分

**植物有四个主要部分**：

| 部分 | 功能 | 可食用示例 |
|------|------|-----------|
| 根 (roots) | 吸收水分和养分 | 胡萝卜 (carrot) |
| 茎 (stem) | 支撑植物，输送养分 | 芹菜 (celery) |
| 叶 (leaves) | 光合作用 | 生菜 (lettuce) |
| 花 (flower) | 繁殖 | 藏红花 (saffron) |

**注意**：有些植物可以吃，有些植物有毒不能吃

### 6.2 种子如何生长

**向日葵生长过程**：
- 种子 (seed) → 幼苗 (seedling) → 成熟植株
- 向日葵长得非常高
- 种子看起来像特定的形状

**种植实验步骤**：
1. 准备花盆，底部放鹅卵石
2. 填入堆肥 (compost)
3. 种入 2 粒向日葵种子，浇水
4. 每天检查，3-8 天后看到幼苗
5. 注意：种完种子要洗手

**测量植物**：
- 植物生长很慢，我们看不见
- 但可以测量高度来知道它长了多少
- 使用直尺测量，用条形图 (bar chart) 记录

### 6.3 为什么种植物

- 提供食物（水果、蔬菜）
- 看起来很漂亮，闻起来很香
- 人类和动物都吃植物提供的食物

### 6.4 植物需要什么

**光照实验**：
- 同样条件种水芹种子 (cress seeds)
- 一盆放在光亮处，一盆放在暗处
- 结果：光照下的长得更好

**水分实验**：
- 每天给一株植物浇水
- 观察变化
- 结果：没有水，叶子会变黄并枯萎 (wilt)

**核心知识点**：
- 植物需要光 (light) 和水 (water) 才能生长
- 没有光 → 叶子变黄 (yellow)
- 没有水 → 叶子枯萎 (wilt)
- 仙人掌 (cacti) 不需要很多水，但仍需一些
- 新鲜芹菜很脆，因为里面有很多水；不新鲜就蔫了
