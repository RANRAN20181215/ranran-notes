# 新加坡数学方法论

## 一、什么是新加坡数学

新加坡数学（Singapore Math）是以新加坡公立小学数学教材（Primary Mathematics / Math in Focus）为核心的教学体系，全球超过60个国家引入，**连续多年TIMSS排名前三**。核心并非"难"或"快"，而是**建立在理解之上的掌握**。

### 与国内数学的核心区别

| 维度 | 新加坡数学 | 国内数学（苏教版等） |
|:---|:---|:---|
| 认知路径 | CPA三阶 | 定义→公式→练习 |
| 问题解决 | Bar Model 图示化 | 直接列算式 |
| 学习节奏 | 掌握式（Mastery），不赶进度 | 按学期走，覆盖面广 |
| 计算基础 | Number Bonds + 位值理解 | 口诀背诵 + 竖式 |
| 应用题 | 建模→推理→求解 | 找关键词→套公式 |

> **给lulu的核心启发**：国内数学偏"算得快"，新加坡数学偏"想得通、讲得清"。冉冉做对的题未必是真理解——新加坡数学提供了检验"是否真理解"的方法论。

## 二、CPA 教学法

CPA = **C**oncrete（具象）→ **P**ictorial（形/半抽象）→ **A**bstract（抽象）

这是认知神经科学验证的学习路径——儿童大脑在12岁前抽象皮层尚未完全发育，绕过CPA直接上抽象=拔苗助长。

### C——具象阶段（用实物操作建立数量感）

| 概念 | 具象操作示例 |
|:---|:---|
| 加减法 | 积木块、计数棒、乐高拼插 |
| 位值 | 十位用一捆10根吸管，个位用散装 |
| 乘法 | 用蛋托摆 2×6 阵列 |
| 分数 | 用披萨纸盘切分 |
| 小数 | 用百分格纸（10×10网格） |

### P——形/半抽象阶段（用图形替代实物）

核心工具：
- **Ten Frame（十格框）**：5+3=8，在10格框里画圈
- **Number Bond（数字塔）**：10 = 6 + 4
- **Bar Model（条形图）**：长方形条块表示数量关系
- **Number Line（数轴）**：数轴上的跳跃

### A——抽象阶段（数字和符号）

前提是前两个阶段真正走通。

> **检测方法**：如果冉冉在A阶段卡住（如不理解竖式借位），退回P阶段画图；还卡则退回C阶段摆实物。**在哪退、何时进，才是CPA的精髓。**

## 三、Number Bonds（数字塔）

这是新加坡数学从K就开始的核心工具，也是国内数学**缺失但极重要的一环**。

### 什么是 Number Bond

```
    10
   /  \
  3    7
```

3和7"合起来"是10；10"拆开"可以是3和7。

### 一年级必须掌握的分解

- 5的分解：0+5, 1+4, 2+3...
- 10的分解（重中之重）：9+1, 8+2, 7+3, 6+4, 5+5
- 20以内所有数的分解

> **为什么对冉冉重要？** 苏教版凑十法口诀是记忆，Number Bond 让孩子**看见**为什么 9+4=13（9+1+3=10+3=13）。

### 在家练习

```
画：口算时在旁边画 bond
摆：用乐高搭 towers
说："7和几合起来是10？""3！"
找：看车牌号，5 3 2 → 5+3+2=10
```

## 四、Bar Model（条形图建模）— 新加坡数学的灵魂

### 四种基本模型

#### 1. Part-Whole Model（部分-整体）

适用于：求总数、求部分

```
[   整体   ]
[ 部分 ][ 部分 ]

例：冉冉有8本书，lulu有5本，两人共有几本？
[    ?本     ]
[ 8本 ][ 5本 ]
```

#### 2. Comparison Model（比较模型）

适用于：谁比谁多/少、差多少

```
冉冉：[————————] 8本
lulu： [————] 5本
        差3本
```

#### 3. Equal Parts / Fractions Model（等分/分数）

适用于：倍数、分数、比例

```
冉冉：[—][—][—]
lulu： [—][—]
冉冉有12本，lulu有几本？
每份=12÷3=4，lulu=4×2=8本
```

#### 4. Before-After Model（前后变化）

适用于：移多补少、变化题

```
之前：冉冉[————]10本  lulu[————]6本
之后：冉冉给lulu2本 → 两人各[————]8本
```

### 画 Bar Model 五步法

```
1. 读题 → 圈出"谁、什么数据"
2. 画条 → 先画整体，再画部分/比较
3. 标数 → 标已知和未知（?号）
4. 写式 → 根据图写出算式
5. 验算 → 答案带回图里检查
```

> Bar Model 最强的不是"解题"，而是让孩子**指着图讲出每一步的意思**——这是国内数学最缺的训练。

## 五、小学六年知识体系（新加坡 vs 苏教版对照）

### K-1（学前-一年级）

| 模块 | 新加坡 | 苏教版 |
|:---|:---|:---|
| 20以内加减 | Number Bonds + 十格框 | 凑十法/破十法 |
| 位值 | 实物→图→数位板 | 计数器+数位顺序表 |
| 长度/重量 | 非标准→标准单位 | cm/kg 直接学 |
| 时间 | 整点/半点 | 整时/半时 |
| 钱币 | 硬币+纸币找零 | 人民币换算 |

### 2-3 年级

| 模块 | 新加坡 | 苏教版 |
|:---|:---|:---|
| 乘法口诀 | Bar Model + 阵列→口诀 | 口诀背诵为主 |
| 除法/余数 | 等分/包含两种情境 | 竖式计算 |
| 分数概念 | 单位分数→等值分数 | 三年级上册初步 |
| 长度/面积 | 周长→面积递进 | 分单元教学 |
| 统计 | 条形图 | 统计初步 |

### 4-5 年级

| 模块 | 新加坡 | 苏教版 |
|:---|:---|:---|
| 小数 | 百分格+分数→小数 | 三年级下册开始 |
| 分数计算 | 等值→通分→运算 | 四五年级分步 |
| 比例 | Bar Model 解所有比例题 | 六年级上册 |
| 百分数 | 折扣、增长率 | 六年级上册 |
| 面积/体积 | 复合图形+Bar Model | 公式套用为主 |

### 6 年级

| 模块 | 新加坡 | 苏教版 |
|:---|:---|:---|
| 比与比例 | 多级 Bar Model | 六年级下册 |
| 百分数应用 | 利润、增长率、利息 | 综合应用 |
| 几何 | 圆、棱柱、复合图形 | 全册 |
| 代数入门 | 字母表示数/简单方程 | 简易方程 |
| 数据分析 | 饼图/折线图/平均数 | 统计与概率 |

## 六、在家实操建议

### 推荐资源

| 类型 | 推荐 |
|:---|:---|
| 教材 | Primary Mathematics (US Edition) / Math in Focus |
| 练习册 | Intensive Practice / Challenging Word Problems |
| 中文引进 | 中信出版社《新加坡数学》1-6年级 |
| 免费 | Khan Academy 新加坡数学专题 |
| APP | Moose Math / Todo Math（CPA风格） |

### 冉冉当前（一年级）优先级

1. **Number Bond 熟练（10/20以内）** — 每天3分钟口答
2. **Ten Frame 可视化** — 买/做十格框卡片
3. **Bar Model 起步** — 从 Part-Whole 开始画
4. **竖式的理解** — 用 Base-10 Blocks 解释"为什么要对齐"
5. **思维题** — 每周1-2道非计算类逻辑推理

### 每周15分钟流程

```
周一：1道拓展 Bar Model 题（画图+讲题）
周三：3道心算（限时，只冲速度）
周五：1道多步挑战题
周末：数学游戏（24点/数独/大富翁数学版）
```

> 不求多，求"能讲清"。一个题能画出 Bar Model + 说出来，胜过刷10道。

### 避坑指南

| 误区 | 纠正 |
|:---|:---|
| 以为CPA就是玩教具 | 教具是手段，关键是**出来后能画、能说、能写** |
| 跳过C直接上P | 一年级脑发育没到，跳过=空中楼阁 |
| 让冉冉自己画图 | 初期**lulu画给冉冉看**，示范思维过程 |
| 追求答案对就行 | 新加坡数学核心是"过程"/"推理"，答案对但过程错=没懂 |
| 和国内方法冲突 | 不冲突。**多一种工具=更多确信** |

## 七、总结

> **CPA 是路径，Number Bond 是基础，Bar Model 是武器，Mastery 是目标。**

不需要买全套新加坡教材。用新加坡数学的**方法论**分析苏教版的题——才是最高效的搭配。
