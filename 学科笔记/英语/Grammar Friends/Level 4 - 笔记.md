# Grammar Friends · Level 4

> 适合：四~五年级 · 搞定条件句和被动语态入门

## 单元速览

| 单元 | 语法点 | 例句 | ⚠️ 注意 |
|:----:|:------|:-----|:-------|
| 1 | 频率副词（复习+加深） | I always brush my teeth. | always/usually/sometimes/never 放动词前 |
| 2 | 现在进行时表将来 | I am meeting Tom tomorrow. | 安排好的计划用进行时 |
| 3 | 一般过去时（复习） | I played football. She went home. | 不规则动词查表 |
| 4 | 过去进行时 | I was watching TV at 8 pm. | was/were + doing |
| 5 | 现在完成时·规则 | I have finished my homework. | have/has + 过去分词 |
| 6 | 现在完成时·不规则 | I have seen that film. | 不规则过去分词要背 |
| 7 | 现在完成时·疑问和否定 | Have you been to Beijing? | been vs gone |
| 8 | will / won't（将来） | I will call you tomorrow. | will + 原形，不随主语变 |
| 9 | be going to（计划） | I am going to learn piano. | 已有计划的打算 |
| 10 | will vs be going to | I'll help you（临时决定）vs I'm going to be a doctor（计划） | 临时 vs 事先 |
| 11 | 比较级和最高级（复习） | bigger, the biggest, more beautiful | as...as 同级比较 |
| 12 | 第一条件句 | If it rains, I will stay home. | if + 现在时, will + 原形 |
| 13 | 反意疑问句 | You like cats, DON'T you? | 前肯后否，前否后肯 |
| 14 | 被动语态·一般现在时 | English is spoken in many countries. | be + 过去分词 |
| 15 | 反身代词 | myself, yourself, himself, herself | 主语和宾语是同一人时用 |
| 16 | 关系从句·who/which/that | The boy who is running is my friend. | 修饰人用 who；物用 which/that |

## ⚠️ 冉冉可能卡的地方

### 1. 现在完成时 vs 一般过去时（Unit 5-7）
```
✅ "I have eaten lunch."       ← 不说时间，强调"现在饱了"
✅ "I ate lunch at 12."        ← 有具体时间，纯描述过去
```

**方法：** 问"有没有说时间？说时间用过去时，没说时间用完成时"

### 2. been vs gone（Unit 7）
```
He has BEEN to Shanghai.  ← 去过回来了
He has GONE to Shanghai.  ← 去了还没回来
```

**方法：** been = been there and back，gone = gone away and not back yet

### 3. will vs be going to（Unit 10）
```
"Phone's ringing — I'll get it!"     ← 临时决定，用 will
"I'm going to travel next summer."  ← 早有计划，用 going to
```

**方法：** 问"是刚才想到的还是早就想好的"

### 4. 反意疑问句（Unit 13）
```
You like pizza, DON'T you?    （前肯后否）
You don't like pizza, DO you?（前否后肯）
She isn't here, IS she?
He can swim, CAN'T he?
```

**方法：** 前半句有否定词（not/never/no），后半句就用肯定

### 5. 被动语态（Unit 14）
```
主动：People speak English.
被动：English IS SPOKEN by people.
         be + 过去分词 + (by...)
```

**方法：** 告诉他"把动作的承受者移到前面当主语，动词变成 be + pp"

## 📝 小口诀

```
现在完成时
have/has + 过去分词
been 是去过，gone 是没回
for + 一段时间，since + 时间点
```

```
反义疑问句
前面肯定后面否
前面否定后面肯
回答用 Yes/No 看事实
"你吃饭了吗"用中文想
```

```
被动语态口诀
主语变宾语，
宾语变主语，
动词变 be 加 plus，
by 加上施动者。
```
