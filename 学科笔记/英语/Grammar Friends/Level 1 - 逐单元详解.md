# Grammar Friends Level 1 · 逐单元详解

> 家长辅导专用 · 每个语法点怎么教

---

## Unit 1：be 动词 (am/is/are)

### 要教什么
```
I am Tom.  (我是 Tom)
You are 6. (你 6 岁)
He is a boy. (他是男孩)
She is a girl. (她是女孩)
It is a cat. (它是一只猫)
We are friends. (我们是朋友)
They are students. (他们是学生)
```

### 给冉冉讲的方式
- am 只跟 I 配对（I'm）
- is 跟 he/she/it 配对（He's, She's, It's）
- are 跟 you/we/they 配对（You're, We're, They're）

### ✍️ 小练习
```
I ___ a student. (am/is/are)
She ___ my friend.
They ___ happy.
```

## Unit 2：a / an

### 规律
```
a + 辅音开头的词  → a dog, a book, a big apple
an + 元音开头的词 → an apple, an egg, an hour
```

### ⚠️ 注意
冉冉可能**只看字母不看发音**：
- an hour（h 不发音，所以用 an）← 这个先不管
- an umbrella（u 发元音 /ʌ/）← 重点记

**方法：** 先让孩子说这个词，听开头是什么音，再看用 a 还是 an。

## Unit 3：复数 -s / -es

### 规律

| 情况 | 加什么 | 例子 |
|:----|:------|:-----|
| 大多数单词 | +s | cat→cats, dog→dogs, book→books |
| 以 s/x/ch/sh/o 结尾 | +es | bus→buses, box→boxes, watch→watches |
| 辅音+y 结尾 | 去 y +ies | baby→babies, fly→flies |

---

## Unit 4：have got / has got

### 句式
```
肯定： I have got a pen.
       She HAS got a pen.   ← 最容易错

否定： I haven't got a pen.
       She hasn't got a pen.

疑问： Have you got a pen?  Yes, I have.
       Has she got a pen?   Yes, she has.
```

**方法：** he/she/it → has，其他 → have。就这么记。

## Unit 5：形容词

### 语序
```
形容词 + 名词

a BIG dog    ← 不是 a dog big
a RED car    ← 不是 a car red
```

### 多个形容词的顺序
不用教太多，冉冉这个阶段知道"形容词放名词前面"就够了。

## Unit 6：can / can't

### 句式
```
I can swim.          (我会游泳)
I can't fly.         (我不会飞)
Can you swim?        (你会游泳吗？)
Yes, I can. / No, I can't.
```

**can't 的发音：** /kɑːnt/ 不是 "看特"，冉冉听力好应该没问题。

## Unit 7：现在进行时

### 结构
```
be 动词 + 动词-ing

I am running.
She is sleeping.
They are playing.
```

### 拼写规则
```
一般直接 +ing：    play→playing, read→reading
不发音的 e 去掉：  make→making, write→writing
重读闭音节双写：   run→running, swim→swimming
```

---

## Unit 8：一般现在时

### 核心规律
```
I/You/We/They + 动词原形
He/She/It + 动词 + s/es

I play football.
She plays football.  ← 第三人称单数加 -s
```

### 第三人称单数 +s 规则
- 一般 +s：like→likes, get→gets
- s/x/ch/sh/o +es：do→does, go→goes, watch→watches
- 辅音+y 去 y +ies：fly→flies, study→studies

---

## Unit 9：there is / there are

### 规律
```
There is + 可数名词单数 / 不可数名词
There are + 可数名词复数

There is a book on the table.
There are two books on the table.
```

### 否定
```
There isn't a cat.
There aren't any cats.    ← some 变 any
```

## Unit 10：介词 in / on / under

### 图示
```
on 上面          under 下面          in 里面

  +---+         +---+               +---+
  |   |         |   |               | ● |
  +---+         +---+               +---+
  ↑ 在···上面    ↑ 在···下面          ↑ 在···里面
```

## Unit 11：祈使句

### 句式
```
动词原形开头（没有 to，没有 s）

Sit down.       ✓
Open the door.  ✓
To sit down.    ✗
Sits down.      ✗
```

---

## Unit 12：疑问词

### 基础疑问词
```
What —— 什么
What is this?  (这是什么？)

Where —— 哪里
Where is my bag?  (我的包在哪里？)

Who —— 谁
Who is she?  (她是谁？)

How —— 怎么样
How are you?  (你好吗？)
```

### 语序
```
疑问词 + be 动词 + 主语？

What   + is      + this?
Where  + is      + my book?
Who    + is      + she?
```
