## ⚠️ 冉冉可能卡的地方

### 1. 过去完成时（Unit 2）
```
✅ "When I arrived, she HAD ALREADY LEFT."
       我到的时候          她已经走了（走的动作在我到之前发生）
```

**方法：** 画时间线。过去完成时 = "过去的过去"。两个过去动作，先发生的用 had done

### 2. 条件句 0 型（Unit 5）
```
If you heat ice, it MELTS.   ← 科学事实
这里的 if = when/whenever，不是假设
```

**方法：** 0 型 = 客观规律，主将从现 ≠ 客观规律。区分方法：能不能用"每次"替换"如果"

### 3. 间接引语·疑问句转述（Unit 7）
```
直接： "Do you like pizza?" 
间接： He asked IF I liked pizza.

直接： "Where do you live?"
间接： He asked WHERE I lived.  ← 注意语序变陈述句
```

**方法：** 一般疑问句转述用 if/whether；特殊疑问句保留疑问词 + 陈述句语序

### 4. 非限制性定语从句（Unit 8）
```
限制性（不用逗号）：The boy WHO IS RUNNING is my friend.
   → 是一个在跑的那个男孩（不是别的男孩）

非限制性（用逗号）：My brother, WHO IS A DOCTOR, lives in Shanghai.
   → 我哥哥只有一个，"是医生"是额外信息
```

**方法：** 非限制性前面的逗号 = 括号，去掉逗号部分句子意思照样成立

### 5. 假位主语 It（Unit 9）
```
✅ "It is important TO STUDY English."
✅ "Studying English is important."  ← 等价
```

**方法：** It + be + 形容词 + to do 是最常见的句型，作文里非常实用

### 6. 形容词顺序（Unit 13）
```
✅ "a big old brown wooden table"
   大小→新旧→颜色→材质→名词
```

**方法：** 告诉冉冉"写作文时两个形容词就够了，不用硬记顺序——重要的是不要在一句话里堆太多形容词"

## 📝 小口诀

```
过去完成时
过去的过去，
had + 过去分词，
两个过去先后到，
先做的用 had done
```

```
间接引语疑问句
一般疑问用 if，
特殊疑问词不变，
语序变成陈述句，
时态往后要退一
```

```
被动语态全时态
is done（现在时）
was done（过去时）
has been done（完成时）
will be done（将来时）
情态 + be done（can be done）
```
