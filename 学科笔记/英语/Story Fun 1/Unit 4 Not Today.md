# 🍽️ Unit 4 Not Today!

> 今天不行哦！

---

## 📖 Story 读一读

今天大家去逛街买东西啦！🛒

有人喜欢这个，有人不喜欢那个——

Dan likes oranges but he **doesn't like** carrots.
Lucy likes chickens but she **doesn't like** mice.

"I like T-shirts and jeans!"  "But I **don't like** donkeys!"

"I like meatballs but I **don't like** apple pie."

每个人都有自己喜欢的和不喜欢的。你的喜好是什么呢？

## 💡 Key Sentences 重点句型

| 英文 | 中文 | 
|:----|:----|
| **I like...** | 我喜欢…… |
| **I don't like...** | 我不喜欢…… |
| **She likes...** | 她喜欢…… |
| **She doesn't like...** | 她不喜欢…… |
| **He likes...** | 他喜欢…… |
| **He doesn't like...** | 他不喜欢…… |
| **Do you like...?** | 你喜欢……吗？ |

**例子：**
- **I like** oranges. 我喜欢橙子。
- **I don't like** carrots. 我不喜欢胡萝卜。
- **She likes** T-shirts. 她喜欢 T 恤。
- **He doesn't like** donkeys. 他不喜欢驴。

---

## 📝 Grammar 语法小课堂

### like / don't like（喜欢/不喜欢）

| 人称 | 肯定 | 否定 |
|:----|:----|:----|
| **I** | I like | I **don't** like |
| **You** | You like | You **don't** like |
| **He / She / It** | He **likes** | He **doesn't** like |
| **We / They** | We like | We **don't** like |

> ⚠️ 第三人称单数 (he/she/it) 要加 **-s**：like → **likes**
> 否定用 **doesn't** + 动词原形

## 🎮 Fun Activities 趣味活动

1. **🍽️ 喜好大调查**：用 `Do you like...?` 问家人，用 `I like / I don't like` 回答
