# 🎮 Unit 6 I Want That Game!

> 我要那个游戏！

---

## 📖 Story 读一读

一个小朋友看到别人有一个超级好玩的游戏/玩具，特别想要！

故事中的人物和物品：
- 👨‍👩‍👧 家人：aunt, uncle, parents, grandma, grandpa
- 🚗 交通工具：bus, helicopter, lorry, motorbike
- 🧸 玩具和物品：board game, doll, robot, keyboard

小朋友看到别的小朋友有一个新游戏（board game），自己也想要。"I want that game!"

他哭了（crying），大人们安慰他："Don't worry!"（别担心！）

最后发生了什么？可能是家人帮他找到了解决办法，或者他学会了耐心等待。

## 💡 Key Sentences 重点句型

| 英文 | 中文 | 用法 |
|:----|:----|:----|
| **I want that game!** | 我要那个游戏！ | 表达愿望 |
| **I want a doll.** | 我想要一个娃娃。 | want + 名词 |
| **I want to play.** | 我想玩。 | want + to do |
| **Don't worry!** | 别担心！ | 安慰用语 |
| **What is it?** | 这是什么？ | 询问物品 |
| **This is my aunt/uncle.** | 这是我的阿姨/叔叔。 | 介绍家人 |
| **He/She is crying.** | 他/她在哭。 | 进行时描述 |
| **It is a board game.** | 这是一个棋盘游戏。 | 描述物品 |

## 🎮 Fun Activities 趣味活动

1. **🧸 玩具店游戏**：用玩具玩购物——"I want that robot!" "Here you are."
2. **👨‍👩‍👧 家人介绍**：拿出家人照片介绍——"This is my aunt."
3. **🚗 交通工具分类**：把交通工具图片按 land/air/water 分类
4. **😊 情绪卡片**：制作情绪卡片（happy/sad/crying/worried）做表情配对
