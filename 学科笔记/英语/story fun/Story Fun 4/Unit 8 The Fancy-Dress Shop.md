# 🎭 Unit 8 The Fancy-Dress Shop

> 化装舞会上的完美变身

---

## 📖 Story 读一读

Ben 和 Amy 要去参加化装舞会，他们来到了一家神奇的服装店。
- 店里挂满了各种各样的 costume —— 海盗、公主、超人、小丑、女巫、机器人……
- Amy 先试了公主裙，漂亮但太长了，走起路来不方便
- Ben 试了海盗帽和眼罩，看起来很酷，但朋友们说不够特别
- Amy 又试了超人披风，有点大，不太合身
- Ben 试了小丑的大鼻子和彩色假发，把大家都逗笑了
- Amy 试了机器人的银色衣服，太紧了，穿脱都很费劲
- 店主人（一只聪明的鹦鹉！）说："不如试试这套？"
- Amy 穿上了小猫 costume，Ben 穿上了小狗 costume —— 哇，太完美了！
- 两人开开心心地去了 party，还得了"最佳装扮奖"

## 💡 Key Sentences 重点句型

| 英文 | 中文 | 用法 |
|:----|:----|:----|
| What do you want to be? | 你想扮成什么？ | want to 表达愿望 |
| I'm going to be a pirate. | 我打算扮成海盗。 | going to 表达计划 |
| Try this on! | 试试这个！ | 祈使句鼓励尝试 |
| Which costume is better? | 哪套服装更好？ | 比较级问选择 |
| The perfect costume! | 完美的服装！ | 感叹句表达惊喜 |
| Let's go to the party! | 我们去派对吧！ | Let's 提议一起做 |
| This dress is too long. | 这条裙子太长了。 | too + 形容词表示"太……" |
| The robot costume is funnier. | 机器人服装更有趣。 | 比较级形容词对比 |

## 🎮 Fun Activities 趣味活动

1. **👗 Costume Design**：画一套自己最想穿的 costume，标出每个部分用英文怎么说
2. **🕵️ Guess Who I Am**：一个人用英文描述自己的 costume（I'm wearing a cape and a mask），其他人猜是什么角色
3. **⚖️ Which Is Better？**：两个同学各选一张服装卡片，全班用比较级投票——"The clown is funnier！"
4. **🎵 Fancy-Dress Fashion Show**：播放音乐走秀，每个人走到前排介绍——"I'm going to be a…！"
