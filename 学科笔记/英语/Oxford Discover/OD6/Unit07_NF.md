## Unit 7 (NF) — Summing Up Symmetry

### BQ4: Why do we like symmetry?

**Genre**: Informational Text (Nonfiction)
**Reading Strategy**: Compare and Contrast

### Vocabulary

| Word | POS | Definition |
|------|-----|------------|
| symmetrical | adj | the same on both sides |
| equilateral | adj | having all sides or faces equal |
| identical | adj | exactly the same |
| infinite | adj | endless; without limit |
| reproduce | v | to make a copy of |
| repetition | n | the action of repeating something |
| extend | v | to make something bigger or longer |
| interlocking | adj | joined together firmly |
| dimensions | n | measurements (length, width, height) |
| structure | n | something that is constructed |
| internal | adj | inside something |
| arrangement | n | how things are organized |
| aesthetic | adj | pleasing to the senses; artistic |

**Words in Context**: balance, pattern, proportion, order, harmony, mirror

### Word Study
Prefix **sym-** / **syn-** (together, same):
- *symmetry, sympathy, synonym, synchronize*

### Grammar: Conditionals (Type 0, 1, 2, 3)

| Type | Form | Use | Example |
|------|------|-----|---------|
| 0 | if + present, present | general truth | *If a shape is symmetrical, it has balance.* |
| 1 | if + present, will + base | real future | *If we measure carefully, we will get symmetry.* |
| 2 | if + past, would + base | unreal present | *If nature weren't symmetrical, nothing would seem balanced.* |
| 3 | if + past perfect, would have + pp | unreal past | *If they had used symmetry, the design would have looked better.* |
