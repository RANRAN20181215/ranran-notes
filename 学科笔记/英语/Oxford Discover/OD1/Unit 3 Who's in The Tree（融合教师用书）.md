# Unit 3 Who's in The Tree（融合教师用书版）

> Big Question 2: **Where can we see colors?**
> 阅读类型：韵律诗（虚构） | 阅读策略：Predicting from Titles
> 写作技巧：问号 Question marks
> 重点发音：/b/（bird, blue, butterfly）

## 家长备课（提前 10 分钟看）

### 本单元教学目标
- 能用 There is / There are 描述存在的人/物
- 能认读 8 个颜色词 + 6 个动物词
- 能用颜色 + There be 句型描述场景
- 知道 6 组反义词（big/small, long/short, hot/cold, fast/slow, old/new, happy/sad）

## 环节 ① Big Question 导入（15 分钟）

### Step 1：看视频（3 分钟）
- 播放 Big Question 2 视频
- 看完后问（中文）：「你看到了哪些颜色？颜色都在哪里？」

### Step 2：KWL 讨论（7 分钟）
拿一张纸画三列：

| K（我知道的） | W（我想知道的） | L（我学到的，最后填） |
|------------|--------------|-------------------|

家长引导问题（用中文问）：
- 「你知道哪些颜色的英文？红色？蓝色？」
- 「你最喜欢什么颜色？」
- 「你觉得颜色可以在哪里看到？」
- 「天空是什么颜色的？树是什么颜色的？」

### Step 3：引出 Big Question（5 分钟）
- 指学生书第 4-5 页的大图
- 问：「你看到什么颜色？」
- 大声读 Big Question：**Where can we see colors?**
- 让孩子跟读 2 遍
- 用中文解释：「这个单元我们要学颜色的英文，还有怎么描述颜色在哪里」

## 环节 ② 词汇 + 阅读（25 分钟）

### 词汇教学（12 分钟）

**颜色词汇（8 个）**：

| 英文 | 中文 | 发音提示 |
|------|------|---------|
| red | 红色 | /red/ — r 要卷舌 |
| yellow | 黄色 | /ˈjeləʊ/ — ll 发 /l/ |
| blue | 蓝色 | /bluː/ — bl 连读，长音 u |
| green | 绿色 | /ɡriːn/ — gr 连读，长音 ee |
| purple | 紫色 | /ˈpɜːpl/ — pur-ple，两音节 |
| black | 黑色 | /blæk/ — bl 连读，短 a |
| brown | 棕色 | /braʊn/ — br 连读，ow 发 /aʊ/ |
| white | 白色 | /waɪt/ — wh 发 /w/，不送气 |

**动物词汇（6 个）**：

| 英文 | 中文 | 发音提示 |
|------|------|---------|
| bird | 鸟 | /bɜːd/ — ir 卷舌 |
| fish | 鱼 | /fɪʃ/ — sh 发 /ʃ/ |
| frog | 青蛙 | /frɒɡ/ — fr 连读 |
| chameleon | 变色龙 | /kəˈmiːliən/ — 四音节，重音在 mee |
| butterfly | 蝴蝶 | /ˈbʌtəflaɪ/ — butter + fly |
| bee | 蜜蜂 | /biː/ — 长音 ee |

#### 第一步：听音指图（3 分钟）
放音频，让孩子在学生书上指出对应的单词和图。

#### 第二步：跟读 + 拼读（4 分钟）
每个词放音频 → 孩子跟读 → 家长纠正发音

特别注意：
- **purple** /ˈpɜːpl/ — 末尾 /pl/ 不要读成"普"
- **chameleon** /kəˈmiːliən/ — 不是"查美利昂"
- **butterfly** /ˈbʌtəflaɪ/ — 重音在 butter 上
- **brown** /braʊn/ — /r/ 要卷舌

#### 第三步：词汇游戏（5 分钟）
**颜色寻宝**：你说「Find something red!」孩子在家里找一个红色的东西。
**闪卡抢答**：展示颜色卡片，孩子快速说英文。

### 阅读教学（13 分钟）

**诗歌内容概要**：
一首关于大自然颜色的韵律诗。黄色的鸟在树上，红色的鱼在水里，蓝色的青蛙，绿色的变色龙……颜色无处不在！诗歌有节奏和韵律，读起来朗朗上口。

#### 第一步：预测（2 分钟）
看标题和诗歌的插图，问：
- 「这首诗会讲什么？」
- 「Who's in the tree? 树上有什么？」
- 「你看到了哪些颜色？」

**预测策略**：从标题「Who's in The Tree」推测内容

#### 第二步：第一次听音频（3 分钟）
放课文音频，孩子边听边指着字。注意感受诗歌的节奏和韵律。

#### 第三步：跟读（4 分钟）
一句一句暂停，孩子跟读。

**诗歌重点句子**：
- Who's in the tree? A yellow bird!
- Who's in the water? A red fish!
- A blue frog. A green chameleon.
- Purple flowers. Brown bees.
- Colors are everywhere!

**韵律提示**：告诉孩子这首诗像儿歌一样有节奏，读的时候可以拍手打拍子。

#### 第四步：理解检测（4 分钟）

| 问题类型 | 问题 | 中文引导 |
|---------|------|---------|
| 主旨 | What is the poem about? | 这首诗在讲什么？ |
| 细节 | What color is the bird? | 鸟是什么颜色的？ |
| 细节 | Where is the red fish? | 红色的鱼在哪里？ |
| 推理 | What animals can you see? | 你看到了哪些动物？ |
| 个人关联 | What colors can you see outside? | 你在外面能看到什么颜色？ |

**第五步（可选）**：让孩子自己读一遍，可以拍手打节奏。

## 环节 ③ 语法发现 — There is / There are（15 分钟）

### Step 1：看例子（3 分钟）
看学生书的语法框，读例句：

| 英文 | 中文 | 用法 |
|------|------|------|
| There is a yellow bird. | 有一只黄色的鸟。 | 单数名词前用 is |
| There is a green frog. | 有一只绿色的青蛙。 | 单数 |
| There are five red fish. | 有五条红色的鱼。 | 复数名词前用 are |
| There are purple flowers. | 有紫色的花。 | 复数 |

### Step 2：发现规律（5 分钟）

**教师用书发现式引导（全中文）**：

```
看这两组句子：

There is 后面跟一个东西（单数）
There are 后面跟多个东西（复数）

There is a bird.     — 一只鸟 → is
There are two birds. — 两只鸟 → are

"Is" 是 "一个"，"are" 是 "多个"。

记住：
There is + a/an + 单数名词
There are + 数字/没有数字 + 复数名词
```

让孩子自己总结规律，家长补充。

### Step 3：练习（5 分钟）

**看图说话**：指着一幅画，让孩子用 There is / There are 描述

**口头填空**：
```
There ___ a cat. → is
There ___ three dogs. → are
There ___ a red flower. → is
There ___ blue birds. → are
```

**冉冉自己造句**：
```
There is a yellow bird in the tree.
There are five red fish.
There is a blue frog.
```

### Step 4：写下来（2 分钟）
在练习本上抄写 3 个句子：

```
There is a yellow bird in the tree.
There are five red fish.
There is a green frog.
```

## 环节 ④ 听说练习（10 分钟）

### 听力（4 分钟）
放听力音频，做学生书上的听力题。

听力内容类型：
- 听描述颜色的对话
- 听描述烟花（fireworks）颜色的场景

### 发音重点（3 分钟）
本单元的发音重点是 **/b/**（双唇紧闭，突然放开）

**/b/** 练习词：
- **b**ird /bɜːd/
- **b**lue /bluː/
- **b**utterfly /ˈbʌtəflaɪ/
- **b**ee /biː/
- **b**ig /bɪɡ/
- **b**rown /braʊn/

**对比练习**（送气 vs 不送气）：
/b/ 是不送气的浊音，/p/ 是送气的清音
big / pig、bee / pea

让孩子把手放在嘴前感受 /p/ 送气、/b/ 不送气。

### 口语活动（3 分钟）
**Color Hunt 颜色寻宝对话**：

```
家长：I see something blue. What is blue?
冉冉：The sky is blue!
家长：Good! Now you say: There is blue in the sky.
冉冉：There is blue in the sky.
```

**冉冉出题，家长猜**：
```
冉冉：I see something red. What is red?
家长：There is a red flower.
冉冉：Yes!
```

## 环节 ⑤ 写作（10 分钟）

### 写作技巧：问号 Question marks

**教师用书处理方式**：

看范文中的问号和句号，让孩子找出区别：
- 问问题用问号 `?`
- 陈述用句号 `.`
- 问号的句子读起来声调会上扬

**对比练习**：
```
This is a bird.     （陈述，句号，声调下降）
What is this?        （问题，问号，声调上升）
How many birds?      （问题，问号）
There are three.     （回答，句号）
```

### 写作任务

写 3 个句子描述你看到的颜色（1 个问句 + 2 个答句）：

1. ___________________________
2. ___________________________
3. ___________________________

**写前口头练习**：
```
家长：Ask me a question about colors.
冉冉：What color is the bird?
家长：It is yellow. Say: There is a yellow bird.
冉冉：There is a yellow bird.
```

**差异化建议**：
- **冉冉写不出**：先口头说问句，再写
- **问号和句号搞混**：写完让她自己读一遍，感受声调
- **字母写错**：重点纠 1 个问题，不要全改

### 检查清单
- [ ] 问句结尾用 `?`
- [ ] 陈述句结尾用 `.`
- [ ] 句子开头大写
- [ ] There is / There are 用对了

## 环节 ⑥ Wrap Up 收尾（15 分钟）

### 复习游戏（5 分钟）
**颜色宾果**：画 3×3 格子，填 6-9 个颜色词，你说中文她圈英文。

**There is / There are 快速抢答**：
```
___ a yellow bird. → There is
___ five red fish. → There are
___ a blue frog. → There is
___ purple flowers. → There are
```

### Word Study：反义词 Opposites（5 分钟）

本单元的 Word Study 重点是反义词：

| 英文 | 反义词 | 中文 |
|------|--------|------|
| big | small | 大 ↔ 小 |
| long | short | 长 ↔ 短 |
| hot | cold | 热 ↔ 冷 |
| fast | slow | 快 ↔ 慢 |
| old | new | 旧 ↔ 新 |
| happy | sad | 开心 ↔ 伤心 |

**活动：反义词配对**
- 你说一个词，冉冉说反义词
- 可以加上动作（big 张开手臂，small 手指捏在一起）

### Project：Color Poem 颜色诗（3 分钟）

**教师用书 Project 步骤**：

1. **Plan**：选 3-4 种颜色
2. **Do**：写 4 行小诗
3. **Share**：读给家长听

冉冉可以做：
```
Red is a flower.
Blue is the sky.
Yellow is the sun.
Green is a tree.
```

### 回到 Big Question（2 分钟）
- 再读一遍 Big Question：**Where can we see colors?**
- 冉冉试着回答：「Colors are everywhere! In the sky, in the water, in the tree!」
- 填 KWL 表的 L 列：「这个单元你学到了什么颜色的新词？」

## 教师用书额外活动推荐

### 活动 1：Color Hunt 颜色寻宝
- 在家/小区里找不同颜色
- 每找到一种颜色就说：「There is red. / There is blue.」
- 数一数能找到多少种颜色

### 活动 2：Rainbow Drawing 画彩虹
- 画一道彩虹，写出 7 种颜色的英文
- 在每种颜色下面写一句话：
  ```
  Red is a rose.
  Yellow is the sun.
  Blue is the sky.
  ```

### 活动 3：Opposite Game 反义词游戏
- 你说一个词，冉冉做动作表示反义词
- big → 张开手臂 / small → 手指捏着
- hot → 扇风 / cold → 发抖

### 活动 4：Color Poem 颜色诗
- 选一种颜色，写出关于这种颜色的 3 句话
- 例：
  ```
  Blue is the sky.
  Blue is the ocean.
  Blue is a bluebird.
  ```
