## 🎯 学习目标

- 掌握 **400+** 核心词汇（家庭、颜色、动物、季节、数字、需求、居住地、音乐、生物）
- 熟练运用 **Verb Be**、**There is/are**、**Have**、**Simple Present**、**Present Continuous**
- 学会 **Wh- 疑问句**、**Can/Should 情态动词**、**物主代词/所有格**
- 掌握 **介词**（in/on/under/next to）
- 培养 **阅读策略**：预测、推理、主旨细节、顺序、对比
- 学会写 **完整句子**、正确使用 **标点符号**（句号/问号/感叹号）
