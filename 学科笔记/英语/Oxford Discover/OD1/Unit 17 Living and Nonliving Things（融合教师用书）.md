# Unit 17 Living and Nonliving Things（融合教师用书版）

> Big Question 9: **What are living things?**
> 阅读类型：信息文（非虚构） | 阅读策略：Contrasting（对比）
> 写作技巧：Can/Can't 写句子
> 重点发音：/l/（living, long, lovely）

---

## 家长备课（提前 10 分钟看）

### 本单元教学目标
- 能用 Can/Can't 区分 living 和 nonliving things
- 能认读 14 个核心词汇（living, nonliving, breathe, move, change 等）
- 能用 Can...? 提问并回答
- 能用 2-3 个带 can/can't 的句子描述事物特征

## 环节 ① Big Question 导入（15 分钟）

### Step 1：看视频（3 分钟）
- 播放 Big Question 视频
- 看完后问（中文）：「你看到了哪些有生命的东西？哪些没有生命？」

### Step 2：KWL 讨论（7 分钟）
拿一张纸画三列：

| K（我知道的） | W（我想知道的） | L（我学到的，最后填） |
|------------|--------------|-------------------|

家长引导问题（用中文问）：
- 「你觉得什么东西是活的（living）？什么东西不是活的（nonliving）？」
- 「人算不算 living thing？树呢？石头呢？」
- 「活的東西有什么特别的本领？」
- 「你想知道关于生命的什么？」

### Step 3：引出 Big Question（5 分钟）
- 指学生书上的大图
- 大声读 Big Question：**What are living things?**
- 让孩子跟读 2 遍
- 用中文解释：「这个单元我们要学会区分有生命和没有生命的东西」

## 环节 ② 词汇 + 阅读（25 分钟）

### 词汇教学（12 分钟）

**教师用书词汇教学步骤**：

#### 第一步：听音指图（3 分钟）
放音频，让孩子在学生书上指出对应的单词和图。

核心词汇：
- living, nonliving, breathe, move, change, air, grow, need
- 例子：people, dog, tree, flower, bird（living）
- 例子：rock, desk, chair, water, book（nonliving）

#### 第二步：跟读 + 拼读（4 分钟）
每个词放音频 → 孩子跟读 → 家长纠正发音

特别注意以下词的发音：
- **living** /ˈlɪvɪŋ/ — /l/ 舌尖顶住上齿龈
- **nonliving** /ˌnɒnˈlɪvɪŋ/ — 重音在 living 上
- **breathe** /briːð/ — th 要咬舌，/ð/ 是浊音
- **move** /muːv/ — /v/ 上牙咬下唇
- **change** /tʃeɪndʒ/ — /tʃ/ 像「吃」但更短
- **people** /ˈpiːpəl/ — 不是「皮剖」，是长音 /iː/
- **flower** /ˈflaʊə/ — 不是「福老二」，/fl/ + /aʊ/

#### 第三步：词汇游戏（5 分钟）
**Living or Nonliving 分类**：拿出物品卡片，让孩子放到 living 或 nonliving 两堆里。
**你说我猜**：你描述特征，她说出是 living 还是 nonliving。
- 「This thing breathes. It needs air. Is it living or nonliving?」

### 阅读教学（13 分钟）

**课文内容概要**（教师用书版）：
这篇信息文介绍 living 和 nonliving 的区别：
- Everything is either living or nonliving
- Living things breathe, move, change, need air/water/food, grow
- Nonliving things don't breathe, don't move on their own
- People, animals, plants are living
- Rocks, chairs, water are nonliving

#### 第一步：Contrasting 策略（2 分钟）
看课文标题和图片，解释本单元的阅读策略是对比：
- 「今天我们要用对比（contrast）来看 living 和 nonliving 有什么不同」
- 「对比就是看两样东西哪里不一样」
- 引导观察：「living things 有的，nonliving things 有没有？」

#### 第二步：第一次听音频（3 分钟）
放课文音频，孩子边听边指着字。

#### 第三步：跟读（4 分钟）
一句一句暂停，孩子跟读。
遇到不懂的词，用中文解释。

#### 第四步：理解检测（4 分钟）

| 问题类型 | 问题 | 中文引导 |
|---------|------|---------|
| 主旨 | What is this text about? | 这篇文章在讲什么？ |
| 对比 | What can living things do? | 有生命的东西能做什么？ |
| 对比 | Can nonliving things move? | 没生命的东西能自己动吗？ |
| 细节 | What do living things need? | 有生命的东西需要什么？ |
| 分类 | Is a tree living or nonliving? | 树是有生命还是没生命？ |
| 推理 | Why is a rock nonliving? | 为什么石头是没有生命的？ |

**第五步（可选）**：让孩子自己读一遍出声。

## 环节 ③ 语法发现 — Can and Can't（15 分钟）

### Step 1：看例子（3 分钟）
看学生书第 4 页的语法框，读例句：

| 英文 | 中文 |
|------|------|
| Living things can move. | 有生命的东西会动。 |
| A bird can fly. | 鸟会飞。 |
| A rock can't move. | 石头不会动。 |
| Can a fish swim? | 鱼会游泳吗？ |
| Yes, it can. | 是的，它会。 |
| No, it can't. | 不，它不会。 |

### Step 2：发现规律（5 分钟）

**教师用书发现式引导（全中文）**：

```
看这些句子，can 和 can't 放在哪里？

Living things **can** move.
A bird **can** fly.
A rock **can't** move.
**Can** a fish swim?

发现了没？
- can 放在动词前面
- can't = cannot，表示不会/不能
- 问句把 can 提到句子开头
- 问句和肯定句里的 can 不变，不管是 he/she/it 都一样
- 回答用 Yes, it can / No, it can't
```

**对比表**：

| 句型 | 结构 | 例句 |
|------|------|------|
| 肯定句 | 主语 + can + 动词 | A dog can run. |
| 否定句 | 主语 + can't + 动词 | A fish can't walk. |
| 疑问句 | Can + 主语 + 动词? | Can a bird swim? |
| 肯定回答 | Yes, 主语 + can. | Yes, it can. |
| 否定回答 | No, 主语 + can't. | No, it can't. |

### Step 3：练习（5 分钟）

**口头填空**：
```
A bird ___ fly. → can
A rock ___ move. → can't
___ a fish swim? → Can
Yes, it ___. → can
No, it ___. → can't
```

**Living or Nonliving 判断**：
```
家长：Can a dog run?
冉冉：Yes, it can. It's living.

家长：Can a chair move?
冉冉：No, it can't. It's nonliving.
```

**自己造句**：用 can 和 can't 每个造一个句子
```
A flower can grow.
A rock can't breathe.
Can a cat climb? Yes, it can.
```

### Step 4：写下来（2 分钟）
在练习本上抄写 3 个句子。
**差异化提示**：如果冉冉写不出来，先口头说，家长写下来，她抄一遍。

## 环节 ④ 听说练习（10 分钟）

### 听力（4 分钟）
放听力音频，做学生书上的听力题。
- 听关于公园场景的观察对话
- 区分听到的是 living 还是 nonliving

**听力词汇**：bench（长椅）, bush（灌木）, statue（雕像）, grass（草）, rose（玫瑰）, fountain（喷泉）

### 发音重点（3 分钟）
本单元的发音重点是 **/l/**

练习词：
- **l**iving
- **l**ong
- **l**ovely
- **l**ight
- f**l**ower

发音要领：
- /l/ 有两种：清晰 L（在元音前）和模糊 L（在元音后）
- living 里的 /l/ 是清晰 L — 舌尖顶住上齿龈，气流从舌头两侧出来
- 对比练习：living / nonliving — 感受 /l/ 的发音位置

**发音游戏**：你说一个词，如果词里有 /l/ 孩子举手。slow, flower, cat, dog, lovely, tree — 孩子要举对。

### 口语活动（3 分钟）
**Apologizing（道歉）**

角色扮演场景：
```
场景 1：不小心碰到对方
A: Oops! I'm sorry.
B: That's OK.

场景 2：不小心把水撒了
A: I'm so sorry!
B: It's all right.
```

家长引导：
- 先用中文说明：「今天学怎么道歉和回应道歉」
- 演一遍，再换角色演

## 环节 ⑤ 写作（10 分钟）

### 写作技巧：Can/Can't 写句子

**教师用书处理方式**：

看范文，让孩子发现 Can/Can't 在写作中的用法：
- A bird can fly. → 用 can + 动词表示能力
- A rock can't move. → 用 can't + 动词表示不能
- 句子开头大写，结尾句号

### Word Study：形容词（Adjectives）

本单元扩展的形容词对：

| 形容词 | 中文 | 形容词 | 中文 |
|--------|------|--------|------|
| big | 大的 | small | 小的 |
| tall | 高的 | short | 矮的/短的 |
| fast | 快的 | slow | 慢的 |
| old | 老的/旧的 | new | 新的 |
| long | 长的 | short | 短的 |

融合进写作的示范：
```
A big dog can run fast.
A small bird can fly.
A tall tree can grow.
```

### 写作任务

写 2-3 个句子，用 can/can't 描述 living 和 nonliving：

1. A ___ can ___. ___________________________
2. A ___ can't ___. ___________________________
3. ___ can ___? ___________________________

**教师用书差异化建议**：
- **冉冉写不出**：先口头说，家长写下来，她抄一遍
- **冉冉写得简单**：鼓励加形容词（a tall tree / a long river）
- **冉冉写错**：重点纠 1 个问题，不要全改

**写前口头练习**：
```
家长：Tell me about a dog. What can it do?
冉冉：A dog can run.
家长：Good! Make it longer — A big dog can run fast.
冉冉：A big dog can run fast.
```

### 检查清单
- [ ] 每个句子开头大写
- [ ] 结尾有句号
- [ ] can/can't 后面跟动词原形

## 环节 ⑥ Wrap Up 收尾（15 分钟）

### 复习游戏（5 分钟）
**Living/Nonliving 抢答**：你说一个词，孩子说 living 或 nonliving，并造一个 can/can't 句子。
```
家长：Dog!
冉冉：Living! A dog can run.
家长：Rock!
冉冉：Nonliving! A rock can't move.
```

**语法快速抢答**：
```
A bird ___ fly. → can
A desk ___ move. → can't
___ a fish swim? → Can
A flower ___ grow. → can
```

### Project：Living/Nonliving 海报（8 分钟）

**教师用书 Project 步骤**：

1. **Plan**：决定画什么场景（公园、教室、家里）
2. **Do**：画 3 个 living 和 3 个 nonliving，写标签
3. **Share**：用英文介绍

冉冉可以做：
- 画一个公园场景
- 标注 living（tree, bird, grass）和 nonliving（bench, statue, fountain）
- 在下面写句子：A tree can grow. / A bench can't move.
- 用英文介绍：「This is a park. A tree is living. A bench is nonliving.」

### 回到 Big Question（2 分钟）
- 再读一遍 Big Question：**What are living things?**
- 冉冉试着回答：「Living things can breathe, move, grow...」
- 填 KWL 表的 L 列：「这个单元你学到了什么？」
