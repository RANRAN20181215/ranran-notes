# 📘 Unit 3 Who's in The Tree?

> Big Question 2: **Where can we see colors?**
> 阅读类型: 韵律诗（虚构） | 阅读策略: Predicting from Titles

---

## 📖 Reading 读一读

- 一首关于动物和颜色的韵律诗
- 不同颜色的动物出现在树上和树下
- 黄色的鸟在树上，红色的鱼在水里
- 蓝色的青蛙、绿色的变色龙、紫色的花……
- 诗歌有节奏和韵律，读起来朗朗上口
- 大自然到处都是颜色！

## 📝 Grammar 语法: There is / There are

| 结构 | 用法 | 例句 |
|:----|:----|:----|
| There is + 单数名词 | 有一个…… | There is a red bird in the tree. |
| There are + 复数名词 | 有多个…… | There are three yellow fish. |
| There is + 不可数名词 | 有…… (不可数) | There is blue water. |

### 否定句

| 英文 | 中文 |
|:----|:----|
| There isn't a purple bird. | 没有紫色的鸟。 |
| There aren't any black flowers. | 没有黑色的花。 |

## 🎮 Fun Activities 趣味活动

1. **🎨 Color Hunt**：在教室里找颜色，用 "There is a red book / There are blue pencils"
2. **📝 Color Poem**：写一首关于颜色的诗，用 "Red is a rose / Blue is the sky"
3. **🎆 Fireworks Game**：用颜色烟花图片练习 "I see red / There is yellow"
