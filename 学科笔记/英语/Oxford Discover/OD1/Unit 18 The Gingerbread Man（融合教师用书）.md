> 阅读类型：童话（虚构） | 阅读策略：Sequence（顺序）

## 环节 ① Big Question 导入（15 分钟）

### Step 1：回顾 Big Question（3 分钟）
- 回顾上学期学过的 Big Question 9：**What are living things?**
- 快速复习：「living things 有什么特点？——会呼吸、会动、会变化、需要空气和水」
- 引入故事：「今天的故事里有一个特殊的 living thing——一个姜饼人！他活了！」

### Step 2：KWL 讨论（7 分钟）
拿一张纸画三列：

| K（我知道的） | W（我想知道的） | L（我学到的，最后填） |
|------------|--------------|-------------------|

家长引导问题（用中文问）：
- 「你吃过姜饼人吗？姜饼人是什么？」
- 「你觉得姜饼人要是活了会发生什么？」
- 「如果有个东西追你，你会怎么说？」
- 「你想知道姜饼人最后怎么样了？」

### Step 3：引出故事（5 分钟）
- 指学生书上的故事图片
- 大声读故事标题：**The Gingerbread Man**
- 让孩子跟读 2 遍
- 用中文简单介绍：「这是一个经典童话——老奶奶烤的姜饼人活了，跑掉了，一路上遇到很多人和动物」

## 环节 ② 词汇 + 阅读（25 分钟）

### 词汇教学（12 分钟）

**教师用书词汇教学步骤**：

#### 第一步：听音指图（3 分钟）
放音频，让孩子在学生书上指出对应的单词和图。

角色词汇：
- gingerbread man, old woman, old man, cow, horse, pig, fox

动作词汇：
- bake, run away, chase, catch/caught, stop, cross, smell, open, eat/ate

#### 第二步：跟读 + 拼读（4 分钟）
每个词放音频 → 孩子跟读 → 家长纠正发音

特别注意以下词的发音：
- **gingerbread** /ˈdʒɪndʒəbred/ — /dʒ/ 像「知」但不卷舌，/g/ 在 bread 里
- **gingerbread** — 注意拼写：gin-ger-bread，三个部分
- **chase** /tʃeɪs/ — /tʃ/ 像「吃」，/s/ 轻轻送气
- **catch** /kætʃ/ — /æ/ 嘴巴张大口型扁
- **caught** /kɔːt/ — /ɔː/ 长音，和 catch 元音不同
- **ate** /eɪt/ — 长元音 /eɪ/，和数字 eight 同音
- **cross** /krɒs/ — /kr/ 连读，舌头卷起快速松开
- **fox** /fɒks/ — /f/ 上牙咬下唇，/ks/ 快速连读

#### 第三步：词汇游戏（5 分钟）
**动作模仿**：你说动作词，孩子表演。「bake!」「run away!」「chase!」「catch!」
**角色抢答**：你说特征，她说角色。「This animal says moo. → Cow!」「This animal has a long nose. → Fox!」

### 阅读教学（13 分钟）

**故事概要**（教师用书版）：
老奶奶烤了一个姜饼人。他跳起来跑掉了！老奶奶和老爷爷追他，一路上遇到牛、马、猪都在追他。每次姜饼人都喊：「Run, run, as fast as you can! You can't catch me, I'm the gingerbread man!」最后狐狸说要帮他过河——然后一口把他吃掉了。

#### 第一步：Sequence 策略（2 分钟）
解释本单元的阅读策略是顺序：
- 「今天我们要用 sequence（顺序）来理解故事——先发生了什么，然后发生了什么，最后发生了什么」
- 「讲故事的时候，顺序很重要」
- 写 4 个关键词：First → Then → Next → Finally

#### 第二步：第一次听音频（3 分钟）
放故事音频，孩子边听边指着字。

#### 第三步：跟读（4 分钟）
一句一句暂停，孩子跟读。
特别注意姜饼人的经典台词要读得有节奏感和语气：
**「Run, run, as fast as you can! You can't catch me, I'm the gingerbread man!」**
——鼓励孩子用得意的语气读，可以站起来边跑边读。

#### 第四步：理解检测（4 分钟）

| 问题类型 | 问题 | 中文引导 |
|---------|------|---------|
| 顺序 | What happens first? | 最先发生什么？ |
| 顺序 | Who does he meet first? | 他先遇到谁？ |
| 细节 | What does the gingerbread man say? | 姜饼人说了什么？ |
| 推理 | Why does the fox help him? | 狐狸为什么要帮他？ |
| 推理 | Is the fox a friend? | 狐狸是朋友吗？ |
| 个人关联 | What would you do? | 如果你是姜饼人你会怎么办？ |

**第五步（可选）**：让孩子自己读一遍出声，重点读姜饼人的台词。

## 环节 ③ 语法发现 — Should and Shouldn't（15 分钟）

### Step 1：看例子（3 分钟）
看学生书上的语法框，读例句：

| 英文 | 中文 |
|------|------|
| You should stop. | 你应该停下来。 |
| You shouldn't run away. | 你不应该跑掉。 |
| Should I cross the river? | 我应该过河吗？ |
| Yes, you should. | 是的，你应该。 |
| No, you shouldn't. | 不，你不应该。 |

### Step 2：发现规律（5 分钟）

**教师用书发现式引导（全中文）**：

```
看这些句子，should 和 shouldn't 放在哪里？

You **should** stop.
You **shouldn't** run away.
**Should** I cross the river?

发现了没？
- should 放在动词前面
- shouldn't = should not，表示不应该
- 问句把 should 提到句子开头
- should 和 shouldn't 后面跟动词原形
- 不管主语是谁，should 都不变！
```

**对比表**：

| 句型 | 结构 | 例句 |
|------|------|------|
| 肯定建议 | 主语 + should + 动词 | You should stop. |
| 否定建议 | 主语 + shouldn't + 动词 | He shouldn't run away. |
| 征求意见 | Should + 主语 + 动词? | Should I cross? |
| 肯定回答 | Yes, 主语 + should. | Yes, you should. |
| 否定回答 | No, 主语 + shouldn't. | No, you shouldn't. |

**和 Can 的对比**（和 Unit 17 关联）：
```
Can — 能力（会不会）
Should — 建议（应不应该）

A bird can fly. 鸟会飞。（能力）
You should eat. 你应该吃东西。（建议）
```

### Step 3：练习（5 分钟）

**故事角色建议**：
```
家长：The gingerbread man runs away. What should he do?
冉冉：He should stop.

家长：The fox wants to eat him. Should he trust the fox?
冉冉：No, he shouldn't.
```

**给冉冉的建议**：
```
家长：It's late. What should you do?
冉冉：I should go to bed.

家长：You have homework. What should you do?
冉冉：I should do my homework.
```

**自己造句**：
```
You should eat healthy food.
You shouldn't play outside late.
Should I help my friend? Yes, you should.
```

### Step 4：写下来（2 分钟）
在练习本上抄写 3 个句子，注意 should/shouldn't 后面跟动词原形。

- 听关于给孩子建议的对话
- 听到 should 还是 shouldn't？

**听力词汇**：
| 英文 | 中文 |
|------|------|

| play outside | 在外面玩 |
| early | 早 |
| late | 晚 |
| healthy food | 健康食品 |
| junk food | 垃圾食品 |

### 发音重点（3 分钟）
本单元的发音重点是 **/g/**

练习词：
- **g**ingerbread
- **g**ood
- **g**o
- **g**et
- **g**irl
- **g**arden

发音要领：
- /g/ 是浊辅音，声带振动
- 舌根抬起顶住软腭，然后突然放开
- 对比：/g/ vs /k/（good vs cook）— /g/ 声带振动，/k/ 不振动

**对比练习**：
```
good / cook
go / coat
girl / cake
```

### 口语活动（3 分钟）
**Giving Advice（提建议）**

场景对话：
```
场景 1：朋友要熬夜
A: I want to play games all night.
B: You shouldn't play games late. You should go to bed.

场景 2：朋友不吃蔬菜
A: I don't like vegetables.
B: You should eat vegetables. They are healthy.
```

家长引导：
- 先用中文说明：「今天学怎么给别人提建议」
- 演一遍，再换角色演
- 鼓励孩子用 You should... / You shouldn't...

## 环节 ⑤ 写作（10 分钟）

### 写作技巧：标点复习

**教师用书处理方式**：

复习三种标点的用法：

| 标点 | 名称 | 什么时候用 | 例句 |
|------|------|-----------|------|
| . | 句号（period） | 陈述句/命令句末尾 | I am a boy. / Stop. |
| ? | 问号（question mark） | 问句末尾 | Can you run? |
| ! | 感叹号（exclamation mark） | 强烈感情/命令 | Run! / Help! |

**发现式引导**：
```
看这三个句子，标点有什么不同？

The gingerbread man runs away.
Can a dog swim?
Run, run, as fast as you can!

第一个是告诉事情 → 句号
第二个是问问题 → 问号
第三个是喊叫/命令 → 感叹号
```

**故事中的感叹号**：
姜饼人的台词全部用感叹号，因为他在大喊！让孩子找出故事里的感叹号：
「Run, run, as fast as you can!」
「Stop! Come back!」

### 写作任务

写 3-4 个句子复述故事，用 First / Then / Next / Finally，注意用对标点：

1. First, ___. ___________________________
2. Then, ___. ___________________________
3. Finally, ___. ___________________________

**范文**：
```
First, the old woman bakes a gingerbread man.
Then, he runs away.
Next, he meets a cow, a horse, and a pig.
Finally, the fox eats him.
```

**教师用书差异化建议**：
- **冉冉写不出**：先让她口头复述故事，家长写下来，她抄一遍
- **冉冉写得简单**：鼓励加细节（a sly fox / a kind old woman）
- **冉冉标点错**：专门练最后一个句子的标点，读出来判断语气

**写前口头练习**：
```
家长：What happens first?
冉冉：The old woman bakes the gingerbread man.
家长：Good! Now, what happens then?
冉冉：He runs away.
家长：Can you put them together with First and Then?
冉冉：First, the old woman bakes the gingerbread man. Then, he runs away.
```

### 检查清单
- [ ] 句子的标点正确（句号 / 问号 / 感叹号）
- [ ] First / Then / Next / Finally 后面有逗号
- [ ] 句子开头大写

## 环节 ⑥ Wrap Up 收尾（15 分钟）

### 复习游戏（5 分钟）
**故事顺序卡片**：拿出 6 张顺序卡片，打乱，让孩子按故事发生顺序排序。
```
1. Old woman bakes the gingerbread man.
2. He runs away.
3. He meets a cow.
4. He meets a horse and a pig.
5. He meets a fox.
6. The fox eats him.
```

**Should/Shouldn't 快速抢答**：
```
You ___ eat healthy food. → should
You ___ run away from home. → shouldn't
___ I help my friend? → Should
He ___ stop. → should
She ___ tell lies. → shouldn't
```

### Project：故事翻翻书（8 分钟）

**教师用书 Project 步骤**：

1. **Plan**：决定故事分成几个部分
2. **Do**：每页画一个场景，写一句话
3. **Share**：用英文讲给家长听

冉冉可以做：
- 折一张纸成 4 格
- 每格画一个故事场景：
  - Page 1：烤箱里的姜饼人
  - Page 2：姜饼人跑掉了
  - Page 3：动物追他
  - Page 4：狐狸吃掉他
- 每格下面写一句话，注意标点
- 用英文讲：「First, the woman bakes him. Then, he runs away...」

### 回到 Big Question（2 分钟）
- 再读一遍 Big Question：**What are living things?**
- 联系故事：「The gingerbread man is living — he moves and runs. But cookies don't really live. This is just a story!」
- 填 KWL 表的 L 列：「这个单元你学到了什么？」

## 教师用书额外活动推荐

### 活动 1：姜饼人角色扮演
- 你演老奶奶/动物，孩子演姜饼人
- 孩子边跑边喊：「Run, run, as fast as you can! You can't catch me, I'm the gingerbread man!」
- 换角色再演一遍

### 活动 2：故事改编
- 问孩子：「如果你是姜饼人，你会怎么做？你会相信狐狸吗？」
- 改编结局：「如果你是姜饼人，你会怎么过河？」
- 写一个新结局

### 活动 3：标点找茬
- 家长写 3 个句子，标点故意用错
- 让孩子找出错误并改正
```
The gingerbread man runs away? （应该用句号）
Stop （应该用感叹号！）
Can you catch me （应该用问号？）
```

### 活动 4：Should Game
- 说出一个情景，孩子用 You should... 或 You shouldn't... 提建议
```
家长：I feel tired.
冉冉：You should go to bed.

家长：I'm hungry.
冉冉：You should eat.
```
