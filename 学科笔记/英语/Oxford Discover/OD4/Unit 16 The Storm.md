# 📘 Unit 16 The Storm

> Big Question 8: **What can we learn from nature's power?**
> 主题领域: Geography / Science（地理/自然力量）| 阅读策略: Sequence（顺序）
> 文体: **Fiction（故事）**

---

## 📖 Reading 读一读

- 故事讲一家人经历一场大风暴
- 一开始天空变暗，风越来越大
- 他们做好了准备：存食物、关窗户、充好手电筒
- 风暴来了——风咆哮、雨倾盆、树倒了
- 他们躲在安全的地方，互相鼓励
- 风暴过后，他们出来看 damage
- 邻居互相帮助清理
- 他们学到了：尊重自然、团结互助

## 📝 Grammar 语法: Second Conditional

### 什么是 Second Conditional？

- 虚拟条件句：假设**不太可能**或**完全不可能**的情况

### 结构 Formula

| If 从句 (if clause) | 主句 (main clause) |
|:-------------------|:------------------|
| **If** + 一般过去时 | **would** + 动词原形 |
| If I **were** you, | I **would stay** home. |

### 用法 Usage

| 情境 | 例句 |
|:----|:-----|
| 不可能的情况 | If I **were** a superhero, I **would stop** the storm. |
| 不太可能的情况 | If we **had** a warning, we **would prepare** better. |
| 建议 | If I **were** you, I **would stay** inside. |

### 例句 Examples

| 英文 | 中文 |
|:----|:-----|
| If I **were** a firefighter, I **would help** people. | 如果我是消防员，我会帮助人们。 |
| If the storm **came**, we **would go** to the basement. | 如果暴风雨来了，我们会去地下室。 |
| What **would** you **do** if a tornado **hit** your town? | 如果龙卷风袭击你的城镇你会怎么办？ |
| If people **prepared** more, there **would be** less damage. | 如果人们准备更多，伤害就会更少。 |

### ⚠️ 注意

- **Be** 动词在 if 从句里用 **were**（不是 was）
  - ✅ If I **were** you… / If he **were** here…
  - ❌ If I was you…
- 主句用 **would + 动词原形**（不是 will）

## 💡 Key Sentences 重点句型

## 🎧 Listening & Speaking 听说练习

- 听关于风暴安全的对话
- 口语练习：Hypothetical situations（假设情况）
  - "What would you do if a hurricane came?"
  - "If I were you, I would…"
  - "If we had a warning, we would…"
- 用 Second Conditional 聊假设

---

## ✍️ Writing 写作

- **Hypothetical Paragraph**：写一个"如果……"的假设段落
  - 开头：If I were a weather scientist, I would study tornadoes.
  - 中间：I would watch the sky. I would warn people. I would help keep everyone safe.
  - 结尾：If I could predict storms, many lives would be saved.
- 用 4+ Second Conditional 句子

## 🎮 Fun Activities 趣味活动

2. **🎲 If I Were… Chain Game**：If I were a superhero, I would stop the storm → If I stopped the storm…
3. **🪁 Storm Safety Poster**：画安全海报用 Second Conditional 写注意事项
4. **📊 Would You Rather?**：用 Would you rather + if 条件句选择
