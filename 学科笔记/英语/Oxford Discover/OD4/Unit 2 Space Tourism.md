# 📘 Unit 2 Space Tourism

> Big Question 1: **Where are we in the universe?**
> 主题领域: Science（科学/天文）| 阅读策略: Sequence（顺序）
> 文体: **Fiction（故事）**

---

## 📖 Reading 读一读

- **Harry** 是一个去太空旅行的孩子
- 故事讲他在 **space hotel**（太空酒店）的经历
- 在太空里，things **float**（漂浮）because there's no gravity
- 食物会飘走，睡觉要固定在墙上
- 穿 **spacesuit**（宇航服）才能出舱
- **Space tourists**（太空游客）需要先训练
- 读故事时注意 Sequence：事情发生的先后顺序
  - First → Next → Then → Finally

## 📝 Grammar 语法: Future Real Conditional

### 结构 Formula

| 从句 (if clause) | 主句 (main clause) |
|:---------------|:------------------|
| **If** + 一般现在时 | **will** + 动词原形 |
| If he **goes** to space, | he **will see** Earth. |

### 词序 Word Order

| 顺序 | 例句 |
|:----|:----|
| **If 在前** | **If** the sky is clear, we **will see** the stars. |
| **If 在后** (不加逗号) | We **will see** the stars **if** the sky is clear. |

### 问句 Questions

| 类型 | 例句 |
|:----|:----|
| 一般疑问句 | **Will** we go back to Earth if there's a storm? |
| 肯定回答 | Yes, we **will**. |
| 否定回答 | No, we **won't**. |
| 特殊疑问句 | What **will** happen if we slow down? |

### 例句 Examples

| If 从句 | 主句 |
|:--------|:-----|
| If you go to space, | you **will float**! |
| If you don't exercise, | you **won't stay** healthy. |
| If you feel sick, | doctors **will give** you advice. |
| If I see Mars, | I **will take** a photo! |
| If we create fast spacecraft, | people **will travel** through the solar system. |

### ⚠️ 注意

- **if 从句用一般现在时**（不是 will）
- ✅ If you **go** to space, you will float.
- ❌ If you **will go** to space, you will float.
- **if 在前**时加逗号，**if 在后**不加逗号

## 💡 Key Sentences 重点句型

| 英文 | 中文 |
|:----|:----|
| If you go to space, you will float. | 如果你去太空，你会漂浮。 |
| Will we go back to Earth if there's a storm? | 如果有风暴我们会回地球吗？ |
| What will you do if you see an asteroid? | 如果你看见小行星你会怎么做？ |
| Space tourists need to train before they go. | 太空游客出发前需要训练。 |
| First, they learn about the spacecraft. | 首先，他们了解航天器。 |
| Next, they practice in a spacesuit. | 接着，他们练习穿宇航服。 |

## ✍️ Writing 写作

- **Choice Questions** 选择题问句（用 or）
  - Should astronauts explore, **or** should space probes?
  - Is Saturn an inner planet **or** an outer planet?
- 写一段话：If I go to space, I will…

## 🎮 Fun Activities 趣味活动

1. **🚀 If… Then… Chain Game**：接龙造句（If I go to space → I will float → If I float → I will bump into things…）

3. **🎭 Space Interview**：一个演 Harry（太空游客），一个演记者提问
4. **📊 Choice Question Quiz**：用 or 做选择题小测验
