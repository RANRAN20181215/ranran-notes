## 🎯 学习目标

- 掌握 **~900** 核心词汇（太空、历史、食物、艺术、城市、人体、传媒、自然力量、生态）
- 熟练运用 **Future Real Conditional** (If...will)
- 掌握 **Present Perfect** 的基本用法 + **for / since**
- 学会 **Quantifiers**（many/much/a few/a little/some/any）
- 学会 **Extreme Adjectives**（boiling / freezing / exhausted / starving）
- 学会 **Passive Voice**（一般现在时被动语态）
- 掌握 **Reported Speech**（间接引语 + 转述问句/命令）
- 熟练运用 **Comparatives & Superlatives** + **As + Adj + As**
- 掌握 **Modals**（Have to / Must / Should）
- 学会 **Second Conditional** 和 **Past Perfect**
- 培养 **阅读策略**：Identify Main Idea, Sequence, Cause & Effect, Compare & Contrast, Categorize, Fact vs Opinion
- 学会写 **Choice Questions**、**Compare & Contrast Paragraph**、**Opinion Paragraph**、**Health Advice**、**News Report**
