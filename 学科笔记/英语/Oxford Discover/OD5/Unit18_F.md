# BQ9: Why do we make buildings? — Unit 18 F

## Big Question
Why do we make buildings?

## Reading Genre
Fiction — a story about building something meaningful (a house, a community center, a bridge)

## Vocabulary Review
Apply Unit 17 vocab in narrative: architecture, structure, foundation, design, construct, shelter, material, engineer

## Grammar in Context: Purpose Clauses + Tense Review

| Purpose | Example |
|---|---|
| to | *They saved money **to** build a community center.* |
| in order to | *She studied engineering **in order to** design safe buildings.* |
| so that | *He added extra beams **so that** the bridge would not collapse.* |

### Tense Review — all grammar from OD5
| Grammar | Example |
|---|---|
| Pres Perf vs PPC | *They have designed many buildings. They have been building for years.* |
| Modals of Ability | *She was able to complete the project on time.* |
| Past Perfect | *By 1900, engineers had already used steel frames.* |
| Passive | *The building was constructed in 1889.* |
| Relative Clauses | *The architect who designed it was famous.* |
| Conditionals | *If they had used better materials, the building would have lasted longer.* |
| Reported Speech | *The engineer said that the structure was safe.* |
| Question Tags | *It's a beautiful design, isn't it?* |

## Word Study: Prefix over-
- **over** + load → overload
- **over** + crowd → overcrowd
- **over** + come → overcome
- **over** + look → overlook
- **over** + build → overbuild

## Writing: A Future Building Design
Describe a building you would design

### Structure
1. What kind of building (school, museum, home)?
2. What materials would you use?
3. What special features would it have?
4. What is it for? (purpose clauses)

### Example
*I would design a school made entirely of recycled materials. We would use solar panels so that the building could generate its own energy. The classrooms would have glass walls to let in natural light.*

## Example Sentences
> They constructed the library so that everyone could access books.
> The architect used local materials to preserve the traditional style.
> If the foundation had been stronger, the building would not have collapsed.
