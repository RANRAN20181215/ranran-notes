# 考试策略与检查方法

> 从平时作业到期末大考，怎么考得好
> 适用：想在现有水平上多拿分的学生

---

## 一、考试心态第一

胡小群关于考试的第一句话：

> **考试不是"展示你会什么"，是"把你会的都写对"。**

```
很多孩子的问题：
  平时作业都会，一考试就错。
  不是没学会——是考试的状态不一样了。

平时：没压力、慢慢想、做对了
考试：紧张、做快点、做错了
```

### 考试焦虑的真相

焦虑不是"心理问题"，是"准备不足"的信号。

```
充分准备 → 自信 → 不焦虑
没有准备 → 不自信 → 焦虑 → 更做不出来（恶性循环）

解决方案：把"焦虑"当成"还需要准备"的信号
```

## 二、各年级考试重点

### 小学：习惯 > 聪明

| 年级 | 考试重点 | 核心要求 |
|:----|:--------|:--------|
| 1-2 年级 | 听题能力、书写规范 | 字写清楚、数位对齐 |
| 3-4 年级 | 读题审题、检查习惯 | 圈关键词、做完检查 |
| 5-6 年级 | 时间分配、步骤完整 | 不在难题上死磕 |

### 初中：方法 > 题海

| 年级 | 考试重点 | 核心要求 |
|:----|:--------|:--------|
| 初一 | 计算准确率 | 看得分率，不看速度 |
| 初二 | 几何证明规范 | 步骤完整，不跳步 |
| 初三 | 综合题策略 | 先易后难，保障基础分 |

### 高中：策略 > 蛮干

| 年级 | 考试重点 | 核心要求 |
|:----|:--------|:--------|
| 高一 | 概念题拿分 | 选择题填空不丢分 |
| 高二 | 计算题规范分 | 过程分 > 结果分 |
| 高三 | 时间管理 | 压轴题策略性放弃 |

## 三、审题训练——拿分的第一步

### 审题三步法

```
第一步：通读一遍
  不要看一句做一句——看完整题再动笔
  理解"题目在说什么事"

第二步：圈关键词
  数字 → 圈出来
  关系词 → 画线（比……多/少、是……的几分之几）
  问题 → 指着读一遍

第三步：复述确认
  用自己的话把题目说一遍
  说清楚了再动笔
```

**训练方法：** 每周 3-5 道题，只做"审题训练"——不计算，只读题、翻译、列式。

### 常见审题错误

| 错误 | 原因 | 对策 |
|:----|:----|:----|
| 题目没看完就做 | 急 | 强制自己读两遍再动笔 |
| 看到数字就列式 | 思维惯性 | 问自己"这个数字代表什么" |
| 漏看单位 | 粗心 | 圈出所有单位，答案带单位 |
| 忽略隐藏条件 | 读题不仔细 | "在实数范围内"、"k≠0"都是条件 |

## 四、时间分配策略

### 通用原则

| 原则 | 说明 |
|:----|:----|
| 先易后难 | 先做会的题，不会的跳过去 |
| 不在一道题上死磕 | 超过 5 分钟没思路 → 先跳过 |
| 保障"会做的全对" | 80% 的分来自基础题 |
| 留出检查时间 | 提前 5-10 分钟做完 |

### 各学段时间分配模版

**小学（考试 60 分钟）：**
```
前 30 分钟：做完所有题
中间 10 分钟：检查计算题（重算一遍）
后 10 分钟：检查应用题（答案是否合理）
最后 10 分钟：检查填空题（有没有漏写单位）
```

**初中（考试 120 分钟）：**
```
前 40 分钟：选择题+填空题（不超过 30 分钟）
中间 40 分钟：解答题基础题（做完 80% 的题）
后 30 分钟：压轴题 + 综合题
最后 10 分钟：检查选择题有没有涂卡
```

**高中（考试 150 分钟）：**
```
前 30 分钟：选择题（每题不超过 3 分钟）
中间 40 分钟：填空题+解答题基础题
后 50 分钟：解答题综合题+压轴题
最后 30 分钟：检查+压轴题策略性抢分
```

### 难题处理策略

```
遇到不会的题：
  1. 判断：真的不会，还是一时没想到？
  2. 真的不会 → 写基本步骤（公式、方程）→ 拿步骤分
  3. 一时没想到 → 标个记号，先做后面的
  4. 做完所有题后回头再做这个记号题
```

## 五、检查方法——多拿 10 分的秘诀

### 不同题型的检查方法

| 题型 | 检查方法 |
|:----|:--------|
| 计算题 | **重算法**：不看原计算过程，重新算一遍——对比两次结果 |
| 方程/应用题 | **代入法**：把答案代回题目，看是否符合所有条件 |
| 选择题 | **排除法**：把四个选项代回去验证 |
| 几何证明 | **读一遍证明过程**——看看每一步的理由是否成立 |
| 函数图像题 | **特值法**：取一个特殊值，看是否符合图像 |

### 检查的顺序

```
① 先检查计算题（最容易拿回分）
② 再检查选择题涂卡（涂错就全没了）
③ 再检查填空答案格式（单位、化简、近似符号）
④ 最后检查难题（看有没有漏掉的条件）
```

### 检查时最容易犯的错

```
❌ 检查时"再看一遍"——你只会看到你想看到的东西

✅ 正确的检查：
  计算题 → 重新算，不看第一次的草稿
  证明题 → 遮住证明过程，自己重新证一遍
  应用题 → 把答案代回原题检验
```

### "草稿纸管理"——检查的基础

**会考试的人，草稿纸都是整整齐齐的。**

```
好的草稿习惯：
  ① 按题号写草稿——每道题的草稿标上题号
  ② 不跳步——每一步都写清楚
  ③ 不用橡皮擦——划掉重写，保留思路痕迹

好处：
  检查的时候能找到"这题当时怎么算的"
  发现错误时知道"错在哪一步"
```

## 六、胡小群的考试哲学

### "先好再快"在考试中

> 平时追求"好"（做得对），考试自然就"快"（做得完）。
> 平时只追求"快"，考试一定"差"（做不对）。

### 考试是"减法"不是"加法"

> 考试不是"尽量多拿分"——是"尽量少丢分"。
>
> 会做的题做对，比做出一道难题更重要。
> 一道 12 分的简单题做错，等于做对了一道 12 分的难题。

### 考后比考前更重要

```
考后做三件事：
  ① 分析错因——不是"粗心"，是哪个环节出了问题
  ② 分类统计——计算错了几道？概念错了几道？
  ③ 制定对策——针对薄弱环节做专项训练
```

---

## 七、给家长的一句话

> **把"考了多少分"改成"哪些题做对了，哪些题有进步"。**
>
> 分数只是一个数字，反映的不是"孩子好不好"，而是"这段时间哪里学得好、哪里需要补"。
