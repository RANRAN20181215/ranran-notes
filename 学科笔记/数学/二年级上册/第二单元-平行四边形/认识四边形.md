## 💡 讲一讲

### 图形是按什么命名的？

**按边的数量！**

| 图形 | 有几条边 | 叫什么 |
|:---:|:---:|:---:|
| △ | **3** 条边 | 三角形 |
| □ | **4** 条边 | **四边形** |
| ⬠ | **5** 条边 | **五边形** |
| ⬡ | **6** 条边 | **六边形** |

> **有几条边，就叫几边形！** 超级好记！🎯

### 生活中的图形

**找找看，你身边有没有这些图形？**

| 图形 | 在哪里 |
|:---|:---|
| 📄 **四边形** | 课本封面、手机屏幕、窗户 |
| 🏠 **五边形** | 足球上的花纹、五角星的轮廓 |
| 🐝 **六边形** | 蜂巢、雪花、龟壳花纹 |

## 📝 记一记

> **⭐ 重点：** 数边的时候，别忘了数 **最后一条边**！从一条边开始，沿着图形走一圈，回到起点才算数完。

```
三角形 = 3条边
四边形 = 4条边
五边形 = 5条边
六边形 = 6条边
```
