# 👀 观察物体

> 第七单元：观察物体

---

## 🎯 学什么

- ✅ 从 **不同角度** 观察物体
- ✅ 知道 **不同角度看到的形状不同**
- ✅ 能根据图形判断观察者的位置

---

## 💡 讲一讲

### 从不同方向观察

**同一个物体，从不同方向看，形状可能不一样！**

**例：一辆小汽车**

| 位置 | 看到的样子 |
|:---|:---|
| 🚗 **前面** | 看到车灯、车牌 |
| 🚗 **后面** | 看到后备箱 |
| 🚗 **侧面** | 看到车身、车轮 |
| 🚗 **上面** | 看到车顶 |

### 经典例子：茶壶

```
前面看 → 看到壶嘴和壶把
后面看 → 只能看到壶把
左面看 → 壶嘴在右，壶把在左
右面看 → 壶嘴在左，壶把在右
上面看 → 看到圆圆的口和盖子
```

---

## 📝 记一记

### 判断观察位置的技巧

> **❶ 先找特征：** 物体的每个面有什么特点？
> **❷ 注意方向：** 左右、前后、上下的区分
> **❸ 联想自己：** 站在那个位置，你会看到什么？

### 容易混淆的情况

| 观察角度 | 看到的特点 |
|:---|:---|
| 🅰️ **正面** | 正对着你的那一面 |
| 🅱️ **侧面** | 左边或右边看到的 |
| 🅲 **后面** | 背面的样子 |
| 🅳 **上面** | 从上往下俯看 |

- 从左边和右边看同一个杯子，看到的是一样的。（ ）

## 🎮 小游戏

### 🧱 积木观察

用积木搭一个造型，分别从：

1. **前面** 看
2. **后面** 看
3. **左边** 看
4. **右边** 看
5. **上面** 看

画出你看到的形状，和同桌比比有什么不同！

## 🧩 想一想

**🤔 为什么我们看一个正方体，怎么看都是一个正方形的形状？**

> **提示：** 因为正方体 **六个面都是相同的正方形**。但如果是长方体，从不同方向看就不同了。
> 
> **并不是所有物体从不同方向看都不同！** 像球、正方体这种 **对称** 的物体，从各个方向看可能都一样。
