# 假期学习方案模板

> 寒暑假数学计划怎么定——放而不废，学而不累
> 适用：1-12 年级通用，按需调整

---

## 一、假期学习的底层逻辑

胡小群的观点：

> **假期是用来"补漏洞"和"做铺垫"的，不是用来"抢跑"的。**

```
假期的正确打开方式：
  上学期遗漏的概念 → 假期补上（补漏）
  下学期要用的工具 → 假期铺垫（铺垫）
  平时没时间做的拓展 → 假期做（拓展）

假期的错误打开方式：
  把下学期课本提前学一遍 → 抢跑（开学不好好听）
  刷大量的题 → 疲劳（假期比上学还累）
  彻底放空 → 开学需要 2-3 周找回状态
```

### 假期学习的三个原则

| 原则 | 说明 |
|:----|:----|
| 保持节奏 | 每天固定学习时间，不突击不中断 |
| 以旧带新 | 先复习上学期的薄弱点，再预习下学期的开头 |
| 留有空白 | 假期是假期，要有足够的自由时间 |

## 二、假期学习计划模板

### 时间分配（通用版）

```
┌──────────────────────────────────────────┐
│  假期时间分配方案                          │
│                                          │
│  总假期 = 6 周（寒）/ 8 周（暑）          │
│                                          │
│  第 1 周：彻底休息（旅游、放松、阅读）     │
│  第 2-4 周：学习期（每天 1-2 小时数学）    │
│  第 5 周：拓展期（数学游戏/阅读/项目）     │
│  第 6-8 周：收心期（调整作息、预习开学）   │
└──────────────────────────────────────────┘
```

### 每日时间安排（学习期）

| 年级 | 每天数学时间 | 安排 |
|:----|:-----------|:-----|
| 1-2 年级 | 20-30 分钟 | 口算 + 数学游戏 |
| 3-4 年级 | 30-45 分钟 | 计算 + 应用题 |
| 5-6 年级 | 45-60 分钟 | 计算 + 专题 + 预习 |
| 初中 | 60-90 分钟 | 薄弱章节 + 预习 |
| 高中 | 90-120 分钟 | 复习整理 + 预习 |

## 三、各年级假期建议

### 小学低段（1-2 年级）

**复习重点：**
- 口算速度（20 以内加减脱口而出）
- 乘法口诀（二年级暑假前必须背熟）

**预习重点：**
- 没有预习压力——回顾上学期的内容即可

**推荐活动：**
```
✅ 数独（4×4 入门版）
✅ 七巧板（图形感知）
✅ 购物游戏（算钱、找零）
✅ 数学绘本阅读
❌ 不要刷题
❌ 不要提前学课本
```

### 小学中段（3-4 年级）

**复习重点：**
- 计算正确率（竖式规范）
- 应用题读题习惯

**预习重点：**
- 翻看新学期前两章的目录和例题
- 只看到"大概学什么"就够了

**推荐活动：**
```
✅ 24 点游戏（四则运算）
✅ 数独（6×6）
✅ 折纸/剪纸（几何直观）
✅ 生活中的测量（长度、面积）
```

### 小学高段（5-6 年级）

**复习重点：**
- 分数小数的四则运算
- 分数应用题

**预习重点：**
- 六年级/初一的目录浏览
- 接触"字母表示数"的概念

**推荐活动：**
```
✅ 数独（9×9）
✅ 魔方（空间想象）
✅ 简单编程（逻辑思维）
✅ 生活中的分数（食谱、折扣）
```

### 初中（7-9 年级）

**复习重点：**
- 上学期的错题本（重做错题）
- 因式分解/方程/函数等核心模块

**预习重点：**
- 下学期第一、第二章
- 只读概念和例题，不做大量练习

**特别注意：**
```
初二的暑假 → 要补初一因式分解（否则初二一元二次方程跟不上）
初三的暑假 → 初高衔接（函数概念、抽象思维准备）
```

### 高中（10-12 年级）

**复习重点：**
- 函数概念的深化理解
- 薄弱章节的专项突破

**预习重点：**
- 翻看下学期课本的"概念"部分
- 标记看不懂的地方——开学带着问题听课

**特别注意：**
```
高一暑假 → 重点复习函数概念（高一的函数学好了，高二不慌）
高二暑假 → 重点突破薄弱模块（高三没时间了）
高三寒假 → 真题训练 + 查漏补缺
```

## 四、专题训练：寒暑假可以做的专项

### 计算专项

| 年级阶段 | 内容 | 频率 |
|:--------|:----|:----|
| 1-2 年级 | 口算（20/100 以内） | 每天 5 分钟 |
| 3-4 年级 | 多位数乘除、简便运算 | 每天 10 分钟 |
| 5-6 年级 | 分数小数混合运算 | 每天 10 分钟 |
| 初中 | 因式分解、分式化简 | 每天 5 分钟 |
| 高中 | 导数/指对运算 | 每天 5 分钟 |

### 错题回顾

**假期是清理错题本的最佳时间——平时没空看，假期有空了。**

```
错题回顾计划：
  第 1 次（假期第 2 周）：重做上学期所有错题
  第 2 次（假期第 4 周）：再做一次
  第 3 次（开学前）：最后过一遍

如果连续 3 次都做对了 → 错题本"毕业"
如果还错 → 说明概念没搞懂 → 停下来搞懂
```

### 数学阅读

| 年级 | 推荐类型 | 示例 |
|:----|:--------|:----|
| 1-2 年级 | 数学绘本 | 《数学帮帮忙》《走进奇妙的数学世界》 |
| 3-4 年级 | 数学故事 | 《数学西游记》《数学家的故事》 |
| 5-6 年级 | 数学科普 | 《可怕的科学·数学系列》 |
| 初中 | 数学史/思维 | 《古今数学思想》《什么是数学》 |
| 高中 | 拓展阅读 | 相应专题的课外书籍 |

## 五、假期计划表示例

### 五年级暑假

```
一、目标
  1. 分数四则运算正确率从 80% 提升到 95%
  2. 错题本全部清理
  3. 预习六上第一章（分数乘法）

二、时间安排
  每天上午 9:00-9:45（45 分钟）
    前 10 分钟：口算/计算
    中间 20 分钟：专题复习或预习
    最后 15 分钟：错题回顾

三、每周安排
  周一、三、五：复习（分数运算、方程）
  周二、四：预习（翻六上课本）
  周六：数学游戏/阅读
  周日：休息

四、评估方式
  每周做一次小测（10 道题）
  正确率 ≥ 90% 下周继续
  正确率 < 90% 重复本周内容
```

### 初一暑假

```
一、目标
  1. 因式分解熟练运用四种方法
  2. 一元一次方程应用题过关
  3. 预习八上第一章（全等三角形）

二、时间安排
  每天上午 9:00-10:00（60 分钟）
    前 15 分钟：计算训练（因式分解 2 道）
    中间 30 分钟：专题
    最后 15 分钟：错题整理

三、专题安排
  第 2 周：七下薄弱点复习（方程、不等式）
  第 3 周：因式分解专项（提公因式→公式→十字→分组）
  第 4 周：八上预习（全等三角形概念）
  第 5 周：数学阅读 + 拓展
```

## 六、给家长的提醒

### 假期的红线

```
❌ 不要安排过满——假期每天 1-2 小时数学足够了
❌ 不要用"别人家的孩子"比较——每个孩子的节奏不同
❌ 不要把假期变成"第二学期"——孩子需要休息

✅ 要做什么——
    保持节奏（每天固定时间）
    保持轻松（不是考试，不紧张）
    保持兴趣（不让孩子讨厌数学）
```

### 如果孩子抵触

```
孩子不想在假期学数学 →
  1. 先问"为什么"——是太累了、太难了、还是太无聊了
  2. 减量——从 1 小时减到 30 分钟
  3. 换形式——换成游戏、读故事书
  4. 最坏情况——彻底休息一周

假期数学的目的不是"超越别人"，是"下学期不被动"。
```

### 一句话总结

> **假期是用来"休整"的，不是用来"冲刺"的。**
>
> 保持手的温度（每天碰一下数学），不要让大脑生锈，但也不用磨出火花。
