## 💡 讲一讲

### 分数的意义

**把单位"1"平均分成若干份，表示这样一份或几份的数叫分数。**

```
把 1 个蛋糕平均分成 5 份：
🍰🍰🍰🍰🍰
取 2 份 → 2/5
```

**分数单位：**
2/5 的分数单位是 1/5，有 2 个这样的分数单位。

---

### 真分数和假分数

**真分数：** 分子 < 分母（小于 1）
```
1/2、2/3、3/4、5/8
```

**假分数：** 分子 ≥ 分母（大于或等于 1）
```
5/3、7/4、8/8（=1）
```

**带分数：** 整数 + 真分数
```
1 1/2（读作"一又二分之一"）
```

**互化：**
假分数 7/3 → 7 ÷ 3 = 2……1 → **2 1/3**
带分数 2 1/3 → (2×3+1)/3 = **7/3**

---

### 分数的基本性质

> 分数的分子和分母同时乘或除以一个相同的数（0 除外），分数的大小不变。

```
1/2 = 2/4 = 3/6 = 4/8 = 5/10

1/2  分子分母同 ×2 → 2/4
4/8  分子分母同 ÷4 → 1/2
```

---

### 约分

把一个分数化成最简分数。

**例：** 把 12/18 约分

```
12/18 = 12÷6 / 18÷6 = 2/3
```

**最简分数：** 分子分母互质（最大公因数为 1）

---

### 通分

把异分母分数化成同分母分数。

**例：** 比较 2/3 和 3/4 的大小

```
找公分母：3 和 4 的最小公倍数是 12

2/3 = 8/12
3/4 = 9/12

8/12 < 9/12 → 2/3 < 3/4 ✅
```

---

## 📝 记一记

| 概念 | 说明 |
|:---|:---|
| 🎯 **真分数** | 分子 < 分母，小于 1 |
| 🎯 **假分数** | 分子 ≥ 分母，≥ 1 |
| 🔄 **基本性质** | 分子分母同乘除，分数大小不变 |
| ✂️ **约分** | 分子分母同除最大公因数 |
| 🔗 **通分** | 异分母变同分母（最小公倍数） |

## 🧩 想一想

**🤔 分子和分母同时加上同一个数，分数的大小变不变？**

> **会变！**
> 1/2 = 0.5，(1+1)/(2+1) = 2/3 ≈ 0.67
> 分数基本性质说的是 **同时乘或除**，不是加或减。
> **只有同乘同除才能保持大小不变。**

## 📖 小口诀

> **真分小于 1，假分大于等于 1。**
> **分数性质要记牢，同乘同除值不变。**
> **约分要找最大公因，通分用最小公倍。**
