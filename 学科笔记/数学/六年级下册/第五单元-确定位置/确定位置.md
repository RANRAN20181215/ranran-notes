# 🎯 确定位置（二）

> 第五单元：确定位置

---

## 🎯 学什么

- ✅ 用 **方向** 和 **距离** 描述位置
- ✅ 会在平面图上确定物体的位置
- ✅ 会描述简单的 **路线图**

---

## 💡 讲一讲

### 方向和距离

**例：** 学校在超市的什么位置？

```
              北
               ↑
               │
         超市  │  学校
          ●   │   ●
               │
               │
               └──────────→ 东
```

学校在超市的 **东偏北 30° 方向 500 米处**。

**描述格式：** 方向 + 角度 + 距离

---

### 八个基本方向

```
       北
       |
  西北  |  东北
  -----+-----> 东
  西南  |  东南
       |
       南
```

---

### 在平面图上确定位置

**步骤：**
1. 确定 **观测点**
2. 确定 **方向**（用量角器量角度）
3. 根据 **比例尺** 算出图上距离
4. 标出位置

**例：**
> 以学校为观测点，图书馆在学校南偏西 40° 方向 600 米处。比例尺 1 : 20000。

```
图上距离 = 60000 cm ÷ 20000 = 3 cm
在学校南偏西 40° 方向画 3 cm 的线段。
```

---

### 描述路线图

**例：** 描述从家到学校的路线

```
家 → 向东走 200 米到超市 → 
超市 → 向东偏北 30° 走 300 米到书店 →
书店 → 向北走 150 米到学校
```

**描述格式：** 从（起点）→ 向（方向）走（距离）到（地点）

---

## 📝 记一记

| 要素 | 说明 |
|:---|:---|
| 🧭 **观测点** | 以谁为参照 |
| 📐 **方向** | 东偏北、北偏西等 |
| 📏 **距离** | 实际距离 |
| 🗺️ **比例尺** | 图上距离与实际距离的比 |

## 🧩 想一想

**🤔 用"东偏北 30°"和"北偏东 60°"描述的是同一个方向吗？**

> 是的！东偏北 30° = 北偏东 60°。
> 这是同一个方向的不同说法。
> 习惯上以 **东、西** 为基准时，说"东偏北"；以 **北、南** 为基准时，说"北偏东"。
