## 💡 讲一讲

### 什么是扇形统计图

扇形统计图用 **圆** 表示整体，用 **扇形** 表示各部分占整体的百分比。

**例：** 小明一天的时间安排

扇形统计图用圆表示整体（100%），用扇形表示各部分占整体的百分比。

| 活动 | 百分比 |
|:---:|:---:|
| 睡眠 | 40% |
| 学习 | 25% |
| 运动 | 15% |
| 娱乐 | 10% |
| 其他 | 10% |

> **整个圆 = 100%（全部）**
> **每个扇形 = 一部分占总体的百分比**

---

### 扇形统计图的特点

| 特点 | 说明 |
|:---|:---|
| 🎯 **直观** | 一眼看出谁多谁少 |
| 💯 **百分比** | 清楚地显示各部分占比 |
| 📊 **整体与部分** | 看出部分和整体的关系 |

---

### 如何计算

**例：** 全班 50 人，喜欢篮球 20 人
篮球扇形的百分比 = 20 ÷ 50 × 100% = **40%**

**扇形圆心角：** 360° × 百分比
篮球圆心角 = 360° × 40% = **144°**

---

### 读图分析

**例：** 下图是某班最喜欢的运动统计图

```
   一天时间安排
+------------------+
|  ####  睡眠 40%  |
|  #  #            |
|  #  +------+     |
|  #  |学习  |     |
|  #  | 25%  |     |
|  #  +------+     |
|  ##  运动 15%    |
+------------------+
```

**问题：**
① 喜欢什么运动的人最多？→ **足球**
② 喜欢篮球的有 10 人，全班多少人？→ 10 ÷ 25% = **40 人**
③ 喜欢足球的比喜欢跑步的多百分之几？→ 30% - 15% = **15%**

## 📝 记一记

| 要点 | 说明 |
|:---|:---|
| ⭕ **整个圆 = 100%** | 表示总体 |
| 🥧 **扇形** | 表示各部分 |
| 🎨 **扇形大小** | 取决于百分比大小 |
| 🔢 **计算** | 百分比 = 部分 ÷ 整体 × 100% |

## 🧩 想一想

**🤔 扇形统计图、条形统计图、折线统计图各有什么特点？**

> - **条形图：** 看出数量的 **多少**
> - **折线图：** 看出数据的 **变化趋势**
> - **扇形图：** 看出各部分占整体的 **百分比**
> **根据不同的需要，选择合适的统计图。**
