## 💡 讲一讲

### 比例的意义

表示两个比相等的式子叫 **比例**。

```
3 : 6 = 4 : 8
两个比值都是 0.5
```

**比例的形式：** a : b = c : d 或 a/b = c/d

**各部分的名称：**
```
3 : 6 = 4 : 8
↑       ↑
外项    外项
    ↑   ↑
   内项 内项
```

---

### 比例的基本性质

> **两外项之积 = 两内项之积。**

a : b = c : d → a × d = b × c

**验证：** 3 : 6 = 4 : 8
外项积：3 × 8 = 24
内项积：6 × 4 = 24
24 = 24 ✅

---

### 解比例

**例：** 3 : 5 = x : 15

```
3 × 15 = 5 × x
45 = 5x
x = 9 ✅
```

---

### 比例尺

**比例尺 = 图上距离 : 实际距离**

```
比例尺 1 : 1000
表示图上 1 cm 代表实际 1000 cm = 10 m
```

**例：** 地图比例尺 1 : 500000，两地图上距离 8 cm，实际距离是多少？

```
8 : x = 1 : 500000
x = 8 × 500000
x = 4000000（cm）= 40（km）✅
```

---

### 按比例分配

**例：**
> 把 60 按 2 : 3 分给甲乙两人。

```
总份数：2 + 3 = 5
甲：60 × 2/5 = 24
乙：60 × 3/5 = 36 ✅
```

## 🧩 想一想

**🤔 比例和比有什么区别？**

> - **比**：两个数相除（如 3 : 5）
> - **比例**：两个比相等（如 3 : 5 = 6 : 10）
> - **比是比例的一部分**，比例是两个相等的比。

> **比例尺是距离比，图上实际要统一。**
> **按比例分配用分数，总数乘以占比就得到。**
