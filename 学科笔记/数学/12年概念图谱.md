# 12 年数学概念图谱

> 按概念脉络跨年段梳理，不看年级看关联
> 适用对象：想真正理解数学"从哪来到哪去"的家长和孩子

---

## 一、图谱总览

12 年数学沿着 **5 条主线** 展开：

```
① 数：自然数 → 分数 → 有理数 → 实数 → 复数
② 方程与不等式：等式 → 方程 → 不等式 → 函数方程
③ 函数：比例 → 一次/反比例/二次 → 抽象函数 → 三角函数 → 导数
④ 几何：图形认识 → 平面几何 → 解析几何 → 立体几何
⑤ 统计概率：数据描述 → 概率计算 → 分布与推断

┌─────────────────────────────────────────────────────┐
│ 每条线 = 一个概念的"生长过程"                        │
│ 不看"几年级学什么"，看"这个概念在小初高分别长什么样"  │
└─────────────────────────────────────────────────────┘
```

---

## 二、主线 ①：数

### 概念生长

```
                    ┌── 有理数（七上）
                    │   ├── 自然数（小学低段）
                    │   ├── 0（小学低段）
    实数（八上）─────┤   ├── 正负数（七上）
                    │   └── 分数与小数（小学中高段）
                    │
                    └── 无理数（八上）
                         ├── √2
                         └── π
                            │
        复数（高一下）──────┘
              └── a + bi（i² = -1）
```

### 每个阶段的"为什么"

| 阶段 | 遇到什么问题 | 怎么解决的 | 新数 |
|:----|:------------|:-----------|:----|
| 小学低段 | 数不够数了 | 发明更大的自然数 | 100, 1000... |
| 小学中段 | 分东西分不均 | 发明分数 | $\frac{1}{2}$ |
| 小学中段 | 钱找不开 | 发明小数 | 0.5 |
| 七上 | 减法不够减（3-5） | 发明负数 | -2 |
| 八上 | 没有平方等于 2 的有理数 | 发明无理数 | $\sqrt{2}$ |
| 高一下 | 没有平方等于 -1 的实数 | 发明复数 | $i$ |

### 核心概念一览

| 概念 | 首次出现 | 说明 |
|:----|:--------|:----|
| 自然数 | 一上 | 1, 2, 3... 用于计数 |
| 0 | 一下 | 表示"没有"——但也是数 |
| 分数 | 三上 | $\frac{a}{b}$，b 等分中的 a 份 |
| 小数 | 三下 | 十进制分数 |
| 负数 | 七上 | 相反意义的量 |
| 数轴 | 七上 | 数的"地图"——每个数都有位置 |
| 绝对值 | 七上 | 数到原点的距离 |
| 有理数 | 七上 | 能写成分数的数 |
| 无理数 | 八上 | 不能写成分数的数 |
| 实数 | 八上 | 有理数+无理数 |
| 复数 | 高一下 | $a+bi$（$i^2=-1$） |

## 三、主线 ②：方程与不等式

### 概念生长

```
等式（小学低段）    不等式（七下）
    │                   │
    ├── 方程概念         ├── 一元一次不等式（七下）
    │   ├── 一元一次（七上） └── 一元二次不等式（高一上）
    │   ├── 二元一次（七下）
    │   ├── 一元二次（八下）
    │   └── 分式方程（...）
    │
    └── 等号的意义
        ├── 小学：算式的"结果"
        └── 七上：两边平衡的关系
```

### 跨年段对照

| 方程类型 | 年级 | 核心思想 |
|:--------|:----|:---------|
| $x+3=7$ | 二三年级 | 用加减法"猜"出 x |
| $2x+1=9$ | 四年级 | 逆运算：x=(9-1)/2 |
| $3x+5=14$ | 七上 | 正式学"两边同时" |
| $\begin{cases} x+y=5 \\ x-y=1 \end{cases}$ | 七下 | 消元——两个变一个 |
| $x^2-3x+2=0$ | 八下 | 三种解法、判别式 |
| $ax^2+bx+c>0$ | 高一上 | 函数图像法 |

### 胡小群视角

> **等号的理解，决定了方程能不能学好。**
>
> 小学理解：等号是"算出来了"（3+2 → 5）
> 初中理解：等号是"两边一样重"（3+2 = 5 = 4+1）

## 四、主线 ③：函数

### 概念生长

```
                                    抽象函数 f(x)
"变量关系"的萌芽 ──┬── 正/反比例（六下）─────────────────┤
  （小学）          │                                     │
                    ├── 一次函数（八上）      ┌── 指数/对数（高一上）
                    ├── 反比例函数（八下）───┤
                    ├── 二次函数（九下）      └── 三角函数（高一上）
                    │                              │
                    └── 函数的本质                    └── 导数（高二下）
                        └── 定义域/值域/单调性/奇偶性（高一上）
```

### 每个阶段的"函数"

| 阶段 | 学什么 | 怎么理解 |
|:----|:------|:--------|
| 小学 | 正比例、反比例 | "一个变了另一个也跟着变" |
| 八上 | 一次函数 $y=kx+b$ | 最简单的线性关系 |
| 八下 | 反比例函数 $y=k/x$ | 你增我减的关系 |
| 九下 | 二次函数 $y=ax^2+bx+c$ | 抛物线——最大/最小值问题 |
| 高一上 | 函数概念 $f(x)$ | 对应关系——不再需要具体公式 |
| 高一上 | 指数/对数函数 | 爆炸式增长vs爬坡式增长 |
| 高一上 | 三角函数 | 周期性的第一次出现 |
| 高二下 | 导数 $f'(x)$ | 函数的变化率——函数分析的终极工具 |

### 胡小群视角

> **函数是整个中学数学的核心。**
>
> - 方程是"函数值等于 0"的特殊情况
> - 不等式是"函数值在某个区间"的问题
> - 几何图形用函数表达就变成了解析几何
>
> 函数概念每升级一次，数学能力就上一个台阶。

## 五、主线 ④：几何

### 概念生长

```
立体图形（小学）
   │
   ├── 三视图（九下）┐
   │                 ├── 立体几何（高一、高二）
   │                 │    ├── 平行与垂直
   平面图形（小学）    │    ├── 表面积体积
   │                  │    └── 空间向量法
   ├── 线与角（七上）  │
   ├── 平行线（七下） ─┘
   ├── 全等三角形（八上）
   ├── 轴对称（八上）
   ├── 勾股定理（八上） ──┐
   ├── 四边形（八下）      │
   ├── 相似三角形（九上）──┤── 解析几何（高二上）
   ├── 圆（九上）─────────┘    ├── 直线与圆
   └── 三角函数（九上）         ├── 椭圆/双曲线/抛物线
                                 └── 坐标方法
```

### 跨年段对照

| 几何思想 | 小学 | 初中 | 高中 |
|:--------|:----|:----|:----|
| 认识图形 | 长方形、正方形 | 三角形、四边形、圆 | 空间几何体 |
| 测量 | 周长、面积 | 勾股定理 | 体积、表面积 |
| 推理 | 无 | 全等、相似、证明 | 立几证明、向量法 |
| 位置 | 上/下/左/右 | 坐标系 | 解析几何 |
| 变化 | 平移、旋转 | 轴对称、位似 | 仿射变换 |

### 胡小群视角

> 几何的发展脉络很清楚：
> 1. **小学：认识它**——这是什么形状，叫什么名字
> 2. **初中：研究它**——有什么性质，怎么证明
> 3. **高中：计算它**——放在坐标系里，用代数方法算

## 六、主线 ⑤：统计与概率

### 概念生长

```
统计 ──┬── 数据收集（小学）
        ├── 统计图表（小学）
        ├── 平均数/中位数/众数（小学、八上）
        ├── 方差（八下）
        ├── 抽样方法（高一下）
        └── 回归分析（高三）

概率 ──┬── 可能性大小（小学）
        ├── 简单概率（八下）
        ├── 古典概型（高一下）
        ├── 条件概率（高三）
        └── 分布列（高三）
```

### 跨年段对照

| 概念 | 小学 | 初中 | 高中 |
|:----|:----|:----|:----|
| 可能性 | 哪个更可能 | 简单概率值 | 分布列、期望 |
| 平均值 | 算术平均 | 加权平均 | 数学期望 |
| 数据展示 | 条形/折线/扇形 | 频数分布 | 频率分布直方图 |
| 相关性 | — | 正相关/负相关 | 线性回归 |

## 七、跨主线联系

### 数→方程→函数：一条线

```
数（具体值）
  ↓  用字母替代
代数式（符号表达式）
  ↓  建立相等关系
方程（解是具体的数）
  ↓  把等号变成对应关系
函数（输入→输出、定义域→值域）
  ↓  研究变化率
导数（每一点的瞬时速度）
```

### 几何→函数：数形结合

```
坐标系（连接处）
  ├── 代数←几何 → 解析几何
  │   几何图形 → 坐标方程
  │   几何条件 → 代数运算
  │
  └── 函数←图像 → 函数图像
      函数关系 → 曲线形状
      单调性 → 上升/下降
      零点 → 与 x 轴交点
```

### 概率→统计：不确定性分析

```
统计 → 用样本估计总体（描述已发生的事）
概率 → 预测未发生的事的可能性
        │
统计+概率 → 科学决策的基础（在不确定中做判断）
```

## 八、第 0 条主线：单位——贯穿 12 年的隐藏线索

> 以上 5 条主线各走各的，但有一条线索**横跨所有主线**——**单位**。
>
> 胡小群反复强调：数学的本质是"用单位数数"。

### 单位主线的三件核心事

```
① 认识不同的单位
② 用单位"数数"（量一量有几个）
③ 统一单位才能运算
```

### 单位 × 5 条主线

#### ① 数 ←→ 计数单位

| 年级 | 新认识的"计数单位" | 本质 |
|:----|:-----------------|:-----|
| 一上 | 1~10（单位是"一"） | 1个1个数 |
| 一下 | 十（10个一是1个十） | 进位 = 满十换大单位 |
| 二下 | 千、万 | 大单位继续升级 |
| 三上 | 分数单位 $\frac{1}{n}$ | 不是"分东西"，是"新的计数单位" |
| 三下 | 小数单位 0.1, 0.01... | 十进制往小走 |
| 五下 | 分数单位再深化 | 约分=换小单位，通分=统一单位 |
| 七上 | 负数单位（-1） | 计数单位扩展到反方向 |
| 八上 | 无理数的单位 | √2 不能写成整数比例 |
| 高一下 | 复数单位 $i$ | 虚数单位——全新的计数单位 |

> 一句话：**整个"数"的发展史，就是发现新计数单位的历史。**

#### ② 方程 ←→ 等号的单位意义

| 阶段 | 单位视角 |
|:----|:---------|
| 小学：$x+3=7$ | 未知数和已知数用的是同一个单位 |
| 七上：等号性质 | 等号两边是"同一个量的不同表示" |
| 七下：消元 | 消元的本质——去掉不同的单位，留一个共同的 |
| 高一：不等式 | 比较大小就是"同一个单位下谁的个数多" |

#### ③ 函数 ←→ 单位的对应关系

```
y = 2x     ← 每 1 个单位的 x 对应 2 个单位的 y
y = kx + b ← 斜率 k = y 对 x 的单位变化率
```

> 函数就是"两个不同单位之间的对应规则"。

#### ④ 几何 ←→ 测量单位

| 年级 | 新单位 | 为什么用这个单位 |
|:----|:------|:----------------|
| 二上 | 厘米、米 | 用统一的标准代替"拃" |
| 三上 | 毫米、千米 | 小到不够、大到不够→换单位 |
| 三下 | 平方厘米、平方米 | 面积单位 = 边长 1cm 的正方形 |
| 五上 | 公顷、平方千米 | 更大的面积需要更大的单位 |
| 六下 | 立方厘米、立方米 | 从面到体，从二维到三维 |
| 八上 | 角度单位（度、弧度） | 用圆来测量角大小 |

#### ⑤ 统计 ←→ 统计单位

```
平均数  ← 把总量按"份"重新分配
概率   ← 用"可能性"做单位衡量不确定性
```

### 单位主线的四大规律

```
第 1 条：认识新单位 → 用这个单位数数 → 多个单位之间换算
    例：认识厘米 → 量长度 → 厘米和米的换算

第 2 条：单位分得越细，结果越精确
    例：米 → 分米 → 厘米 → 毫米（分得越细量得越准）

第 3 条：运算必须同单位，不同就要换算
    例：3m + 5cm = 300cm + 5cm = 305cm（减法和除法同理）
    更深：分数加减要通分 = 统一单位；小数加减要对齐小数点 = 对齐单位

第 4 条：每一次"数系扩张"都在发明新单位
    自然数 → 分数 → 小数 → 负数 → 无理数 → 复数
    每一步都是"原来不够用了，发明一个新的计数单位"
```

### 给家长的辅导提示

> 教任何数学概念时，先问自己三个问题：
> 1. 这个知识点涉及什么**单位**？
> 2. 孩子能不能**用这个单位数一数**？
> 3. 有没有**不同单位需要换算**？
>
> 如果三个问题都能答上来，说明你抓住了这个知识的本质。

## 九、使用指南

### 这张图怎么用

| 使用场景 | 怎么用 |
|:--------|:-------|
| 孩子学某个概念卡住了 | 往前看——这个概念的"前身"是什么？从更基础的开始补 |
| 孩子问"学这个有什么用" | 往后看——这个概念发展到哪里去了？ |
| 总复习阶段 | 按主线而不是按年级复习——建立"知识网络" |
| 预习新内容 | 先找到新知识在主线的哪个位置——前面是什么、后面连什么 |

### 胡小群的"图谱式学习"建议

> 不要学"一个知识点"——要学"这个知识点在整条线上​​的位置"。
>
> 比如学一元二次方程时：
> - 它前面连着"一元一次方程"和"因式分解"
> - 它后面连着"二次函数"和"判别式"
> - 它和"不等式"是邻居
>
> 知道位置，就知道了"为什么要学"和"学了有什么用"。
