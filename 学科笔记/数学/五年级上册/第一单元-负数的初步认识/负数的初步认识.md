# ➖ 负数的初步认识

> 第一单元：负数的初步认识

---

## 🎯 学什么

- ✅ 认识 **负数**，理解正数和负数的含义
- ✅ 正确读写正负数
- ✅ 认识 **0 既不是正数也不是负数**
- ✅ 在数轴上表示正负数

---

## 💡 讲一讲

### 什么是负数

生活中有些数量是 **相反意义** 的：

```
温度：零上 3°C 和 零下 3°C
钱：收入 100 元 和 支出 100 元
海拔：海平面以上 100 米 和 海平面以下 100 米
```

**零上 3°C → +3°C 或 3°C（正数）**
**零下 3°C → -3°C（负数，读作"负三"）**

> **负数：** 比 0 小的数，前面加"−"号。

---

### 正数和负数

```
正数：+3、5、+100（可以省略"+"号）
负数：−3、−5、−100（"−"号不能省略）

0 既不是正数也不是负数，是正负数的分界点。
```

| 例子 | 正数还是负数 |
|:---|:---:|
| 零下 10°C | 负数（−10°C） |
| 海拔 500 米 | 正数（+500 m） |
| 亏损 200 元 | 负数（−200 元） |
| 盈利 300 元 | 正数（+300 元） |

---

### 在数轴上表示

```
  -3   -2   -1    0    1    2    3
--+----+----+----+----+----+----+--
  负数          0          正数
```

**规律：** 0 的左边是负数，0 的右边是正数。

---

### 比较大小

**负数 < 0 < 正数**

```
例子：
-5 < -2（离 0 越远越小的负数）
-2 < 0
0 < 3
-3 < 1

温度：−5°C 比 −2°C 更冷
```

> **数字越大，温度越高：** 5°C > 1°C > −1°C > −5°C

---

## 📝 记一记

| 概念 | 说明 |
|:---|:---|
| ➕ **正数** | 大于 0，可以省略"+"号 |
| ➖ **负数** | 小于 0，"−"号不能省 |
| 0️⃣ **0** | 既不是正数也不是负数 |
| 📏 **数轴** | 0 左边是负数，右边是正数 |

## 🧩 想一想

**🤔 为什么 0 既不是正数也不是负数？**

> 0 是正数和负数的 **分界点**。
> 正数是比 0 大的数，负数是比 0 小的数。
> 0 本身就是一个特殊的分界线，既不比 0 大，也不比 0 小。

---

## 📖 小口诀

> **正数负数分两边，0 在中间是分界。**
> **正号可以省略写，负号千万不能缺。**
> **负数都小于 0，正数全都大于 0。**
