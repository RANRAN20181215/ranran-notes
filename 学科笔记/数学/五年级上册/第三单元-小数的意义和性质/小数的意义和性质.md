# 🔢 小数的意义和性质

> 第三单元：小数的意义和性质

---

## 🎯 学什么

- ✅ 理解 **小数的意义**（十分位、百分位、千分位）
- ✅ 掌握小数的 **数位顺序表**
- ✅ 掌握小数的 **性质**（末尾添 0 去 0 大小不变）
- ✅ 会比较小数的大小
- ✅ 会把大数改写成用"万"或"亿"作单位的小数

---

## 💡 讲一讲

### 小数的数位顺序

| 整数部分 | 小数点 | 小数部分 |
|:---:|:---:|:---:|
| 个位 | . | 十分位 百分位 千分位 |
| 1 | . | 2 3 4 |

**1.234 读作：** 一点二三四

**各数位含义：**
- 十分位：1/10，0.1
- 百分位：1/100，0.01
- 千分位：1/1000，0.001

---

### 小数的性质

> 小数的 **末尾** 添上"0"或去掉"0"，小数的大小 **不变**。

```
0.5 = 0.50 = 0.500
3 = 3.0 = 3.00
```

**注意：** 是末尾的 0，不是中间的 0！

```
0.05 ≠ 0.5 ❌（中间 0 不能去）
0.05 = 0.050 ✅（末尾加 0 可以）
```

---

### 比较小数大小

**规则：**
1. 先比较整数部分
2. 整数部分相同，比较十分位
3. 十分位相同，比较百分位
4. 依此类推

**例：** 0.35 ○ 0.4

```
0.35：整数 0，十分位 3
0.4： 整数 0，十分位 4
3 < 4 → 0.35 < 0.4 ✅
```

---

### 改写

**改写为"万"作单位：** 小数点向左移 4 位

```
384000 = 38.4 万
234500 = 23.45 万
```

**改写为"亿"作单位：** 小数点向左移 8 位

```
384000000 = 3.84 亿
123456789 = 1.23456789 亿
```

---

### 求近似数

**四舍五入保留小数位数：**

38456 改写成"万"作单位（保留一位小数）

38456 = 3.8456 万 ≈ **3.8 万**（看百分位 4 < 5，舍去）

## 🧩 想一想

**🤔 为什么 0.5 和 0.50 一样大，但 0.5 和 0.05 不一样？**

> 0.5 是 5/10（5 个 0.1）
> 0.50 是 50/100（50 个 0.01）
> 5 个 0.1 = 50 个 0.01，所以一样大。
> 0.05 是 5/100（5 个 0.01）= 5 个 0.01 ≠ 50 个 0.01
