# 🔢 整数四则混合运算

> 第七单元：整数四则混合运算

---

## 🎯 学什么

- ✅ 掌握 **不含括号** 的混合运算顺序
- ✅ 掌握 **含括号** 的混合运算顺序
- ✅ 会用递等式计算
- ✅ 解决相关的实际问题

---

## 💡 讲一讲

### 运算级别

| 级别 | 运算 | 优先级 |
|:---:|:---|:---:|
| 一级 | ＋ 加法、－ 减法 | **最低** |
| 二级 | ✖️ 乘法、➗ 除法 | **中间** |
| — | ( ) 括号 | **最高** |

**规则：** 先算括号 → 再算乘除 → 最后算加减

---

### 不含括号（两级运算）

**例①：** 120 + 45 × 3

```
120 + 45 × 3
= 120 + 135    ← 先算乘法
= 255 ✅
```

**例②：** 240 - 60 ÷ 5

```
240 - 60 ÷ 5
= 240 - 12     ← 先算除法
= 228 ✅
```

---

### 含括号

**例①：** (120 + 45) × 3

```
(120 + 45) × 3
= 165 × 3      ← 先算括号
= 495 ✅
```

**例②：** 240 ÷ (8 - 3) × 2

```
240 ÷ (8 - 3) × 2
= 240 ÷ 5 × 2  ← 先算括号
= 48 × 2       ← 同级运算从左到右
= 96 ✅
```

---

### 括号的嵌套

**例：** 150 ÷ [5 × (4 + 6)]

```
150 ÷ [5 × (4 + 6)]
= 150 ÷ [5 × 10]   ← 先算小括号
= 150 ÷ 50         ← 再算中括号
= 3 ✅
```

> 小括号 ( ) 里面算完 → 再算中括号 [ ]。

---

### 递等式的写法

```
正确的递等式：
  240 - 60 ÷ 5 × 3
= 240 - 12 × 3
= 240 - 36
= 204

错误的写法（跳步容易出错）：
  240 - 60 ÷ 5 × 3
= 240 - 12 × 3
= 228 ❌（12×3 算成了 12）
```

---

## 📝 记一记

| 顺序 | 规则 |
|:---|:---|
| ➊ | 先算括号里面的 |
| ➋ | 再算乘除法 |
| ➌ | 最后算加减法 |
| ➡️ | 同级运算从左到右 |

## 🧩 想一想

**🤔 为什么要有运算顺序的规定？**

> 如果没有统一的规定，同一个算式会算出不同结果。
> 比如 4 + 5 × 2：
> - 如果先加后乘：(4+5)×2 = 18
> - 如果先乘后加：4+5×2 = 14
> **统一规定让全世界的人算出的结果都一样！**

> **乘除加减排好队，不行乱来搞错对。**
> **同级运算左到右，一步一步慢慢来。**
