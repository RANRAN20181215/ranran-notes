# 👀 观察物体

> 第三单元：观察物体

---

## 🎯 学什么

- ✅ 从 **前面、右面、上面** 观察物体
- ✅ 能辨认从不同方向看到的形状
- ✅ 会根据视图拼摆物体
- ✅ 发展空间想象力

---

## 💡 讲一讲

### 从不同方向观察

**例：** 观察一个长方体盒子

从前面看、从上面看、从右面看，三个方向看到的形状可能不一样。

```
从前面看：    从上面看：    从右面看：
+------+      +------+      +----+
|      |      |      |      |    |
+------+      +------+      +----+
```

---

### 摆放小正方体

**例：** 用 4 个正方体摆成一个物体

```
 摆放方式：
 +---+
 |   |
 +---+
 前面看是正方形
```

---

### 根据视图拼摆

**例：** 从前面看是 2 个正方形并排，从上面看也是 2 个正方形并排，最少需要几个正方体？

从前面看至少有 2 列，从上面看至少有 2 行，所以最少需要 2 个正方体。

---

## 📝 记一记

| 方向 | 看到什么 |
|:---|:---|
| 👀 **前面** | 物体的正面 |
| 👀 **上面** | 物体的顶部（俯视图） |
| 👀 **右面** | 物体的右侧 |
| 🔍 **关键** | 不同方向看到的形状可能不同 |

---

## 🧩 想一想

**🤔 从不同方向观察同一个物体，看到的形状一定不同吗？**

> 不一定！比如观察一个 **球**，从哪个方向看都是圆形。
> 观察一个 **正方体**，从前面、上面、右面看都是正方形。
> 所以有些物体从不同方向看形状是一样的。

---
