## 💡 讲一讲

### 线段、射线、直线

| 名称 | 图示 | 端点 | 长度 |
|:---|:---:|:---:|:---:|
| **线段** | ●───● | 2 个 | 有限长 |
| **射线** | ●───→ | 1 个 | 无限长 |
| **直线** | ←───→ | 0 个 | 无限长 |

```
线段：o-----o   有 2 个端点，有限长
射线：o-------->  有 1 个端点，无限长
直线：<-------->  没有端点，无限长
```

---

### 认识角

**角** 是从一点引出两条射线组成的图形。

```
    A
   /
  /     边
 /
O-------> C
顶点
```

**角的命名：** ∠AOB 或 ∠O

**角的大小和什么有关？**
- 和 **两边张开的程度** 有关
- 和 **边的长短无关** ❗

---

### 角的分类和量角

| 角类型 | 度数 | 样子 |
|:---:|:---:|:---|
| 锐角 | < 90° | 尖尖的 |
| 直角 | = 90° | L 形 |
| 钝角 | > 90° 且 < 180° | 宽宽的 |
| 平角 | = 180° | 一条直线 |
| 周角 | = 360° | 一圈 |

**量角器使用：**
1. 中心点对齐角的顶点
2. 0 刻度线对齐角的一条边
3. 看另一条边对准的刻度

---

### 垂线

**垂直：** 两条直线相交成直角。

```
  |
  +-----   两条直线相交成直角
```

**画垂线：**
1. 用三角尺的一条直角边贴住已知直线
2. 沿另一条直角边画线

**点到直线的距离：** 从直线外一点到这条直线所画的 **垂直线段最短**。

---

### 平行线

**平行：** 同一平面内不相交的两条直线。

```
+-----------------+
+-----------------+   两条直线不相交，距离处处相等
```

**画平行线：**
1. 用三角尺贴住已知直线
2. 用直尺靠住三角尺的另一边
3. 平移三角尺画线

---

## 📝 记一记

| 概念 | 关键点 |
|:---|:---|
| 📏 **垂线** | 相交成直角 |
| 📏 **平行线** | 不相交，距离处处相等 |
| 📐 **角的大小** | 看两边张开程度，不看边的长短 |
| 🔢 **量角** | 中心对顶点，0 线对一边 |

## 🧩 想一想

**🤔 过一点能画几条直线？过两点能画几条？**

> 过一点可以画 **无数条** 直线。
> 过两点只能画 **一条** 直线。
> "两点确定一条直线"——生活中钉木条时，两个钉子就能固定位置。
