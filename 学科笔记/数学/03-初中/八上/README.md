## 三、各章底层逻辑

### 第13章 全等三角形——几何推理的核心

**核心：两个三角形完全一样，怎么判断？**

全等判定是初中几何的基石。
- SSS：三边对应相等
- SAS：两边及其夹角对应相等
- ASA：两角及其夹边对应相等
- AAS：两角及一角的对边对应相等
- HL：直角三角形的一条斜边和一条直角边对应相等

**胡小群追问：**
> 为什么 SSA（两边及其中一边的对角）不能判定全等？——画个图就明白了：给定两条边和一个对角，可以画出两个不同的三角形

**全等的价值**不仅是判定两个三角形一样，更是**证明线段相等、角相等的核心工具。**

### 第14章 轴对称图形——对称性思维

**核心：对称就是"翻折后重合"**

等腰三角形的性质（两底角相等、三线合一）都来自轴对称。

这章培养的是"对称性思维"——在几何中，看到等腰三角形就想到对称，看到对称就想到线段相等。

### 第15章 实数——"数"的第二次扩张

**核心：不是所有数都能写成分数**

$$
\sqrt{2} = 1.41421356...
$$

$\sqrt{2}$ 不能写成分数形式——这叫"无理数"。

有理数 + 无理数 = 实数。

这是孩子第二次遇到"数不够用了"——第一次是分数（整数不够用），第二次是实数（有理数不够用）。

### 第17章 勾股定理——数形结合的开始

**核心：直角三角形中，$a^2 + b^2 = c^2$**

勾股定理的美妙之处在于**连接了代数和几何**——两条直角边的平方和 = 斜边的平方，这个关系是"数与形"的第一次相遇。

**勾股定理的证明**（赵爽弦图、毕达哥拉斯证法等）是初中数学最好的逻辑训练之一。

### 第18章 一次函数——变量关系入门

**核心：y = kx + b——描述一条直线**

一次函数是"函数"概念的第一次正式引入。

**胡小群视角：**
> $$
> y = 2x + 1
> $$
>
> 这不是公式，这是在说：**y 随着 x 的变化，以 2 倍的速度增长，且起始值是 1。**

**k 的意义**（斜率）：变化率——x 每增加 1，y 增加 k
**b 的意义**（截距）：x = 0 时的 y 值

一次函数的图像是一条直线——这是"代数关系可视化"的起点。

## 五、常见错误

| 错误 | 原因 |
|:----|:----|
| 全等判定混用（SSA 当成 SAS） | 每个判定对应的"边角位置"没理解 |
| 等腰三角形"三线合一"用错 | 没有理解它是"同一个条件推出的三个结论" |
| 勾股定理只记 $a^2+b^2=c^2$，不会判断哪条是斜边 | 没有培养"最长边是斜边"的习惯 |
| 一次函数中 $k$ 和 $b$ 的意义分不清 | 没有把"代数"和"几何"对应起来 |
