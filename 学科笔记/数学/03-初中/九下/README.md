## 三、各章底层逻辑

### 第31章 二次函数——初中函数的顶峰

**核心：$y = ax^2 + bx + c$——一条抛物线**

二次函数为什么重要？
1. 它是小学到初中所有代数知识的综合运用
2. 它是高中"函数"模块的第一个深入学习对象
3. 它把方程、函数、不等式、图像融合在一起

**三种表达形式：**
1. **一般式**：$y = ax^2 + bx + c$（最常用）
2. **顶点式**：$y = a(x-h)^2 + k$（$(h,k)$ 是顶点）
3. **交点式**：$y = a(x-x_1)(x-x_2)$（$x_1, x_2$ 是根）

**胡小群追问：**
> 为什么 $a$ 的符号决定开口方向？
> - $a > 0$：开口向上（有最小值）
> - $a < 0$：开口向下（有最大值）
>
> 从顶点式 $y = a(x-h)^2 + k$ 来看：$(x-h)^2$ 永远 ≥ 0，所以 $a$ 的符号决定了 $(x-h)^2$"乘完后"的方向——正朝上、负朝下。

**二次函数与一元二次方程的关系（核心中的核心）：**

> 求二次函数 $y = ax^2 + bx + c$ 的零点 → 解方程 $ax^2 + bx + c = 0$

这个关系在高中会扩展到"函数与方程"的一般化理解。

**应用：** 抛体运动（物理）、最优化（利润问题）、桥梁设计（拱形）

### 第32章 投影与视图——空间想象力

**核心：把一个三维物体用二维的"正视图/侧视图/俯视图"表示**

这不是很难的章节，但考查的是空间想象力——很多孩子在高中学立体几何时卡住，问题就出在这里。

**给家长的建议：** 如果孩子空间想象力弱，可以搭乐高、看工程图纸、玩三维模型——这些都能培养"从二维看三维"的能力。

### 总复习——三年的知识串成网

**胡小群的总复习策略：**

> **不要按"知识点"复习，按"关系"复习。**

```
错误方式：
  第一章 → 第二章 → 第三章 → ……（线性推进）

正确方式：
  数的扩张：自然数→有理数→实数
  运算的体系：加减→乘除→乘方→开方
  几何的体系：点→线→角→三角形→四边形→圆→相似
  函数的体系：一次→反比例→二次
```

### 胡小群的"三不原则"

1. **不迷信押题卷**——回归课本和基础概念
2. **不盲目刷题**——做一道题，搞懂一类题
3. **不放过错题**——错题的本质是某个概念没到位，不是"粗心"

### 什么是最有效的复习

**检验标准：** 能不能用自己的话讲清楚一个知识板块的逻辑。

> 让孩子讲"函数是什么"：
> - 初中就讲了三种函数：一次函数、反比例函数、二次函数
> - 共同点都是"x 确定 → y 确定"
> - 区别是"x 的变化引起 y 的变化方式不同"

如果能这样讲，说明知识已经成网了，考试不会差。
