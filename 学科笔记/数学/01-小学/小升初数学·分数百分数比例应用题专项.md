# 小升初数学 · 分数百分数比例应用题专项

> 小升初应用题大题中最核心的板块
> 五、六年级复习用，一个专题一类题型

---

## 一、分数应用题

### 核心概念：单位"1"

```
已知单位"1" → 用乘法：单位"1" × 对应分率 = 对应量
未知单位"1" → 用除法：对应量 ÷ 对应分率 = 单位"1"
```

### 三种基本题型

**题型一：求一个数的几分之几**
```
一本书共120页，小明看了3/5，看了多少页？
→ 120 × 3/5 = 72 页
```

**题型二：已知一个数的几分之几是多少，求这个数**
```
小明看了72页，正好是全书的3/5，全书多少页？
→ 72 ÷ 3/5 = 72 × 5/3 = 120 页
```

**题型三：求一个数是另一个数的几分之几**
```
小明看了72页，全书120页，看了全书的几分之几？
→ 72 ÷ 120 = 3/5
```

### 较复杂的分数应用题

**例：提高/降低几分之几**
```
一件衣服原价200元，先涨价1/5，再降价1/5，现价多少？
第一次涨价后：200 × (1 + 1/5) = 240 元
第二次降价后：240 × (1 - 1/5) = 192 元
→ 注意：两次的"1/5"对应的单位"1"不同！
```

**例：剩余问题**
```
一桶油，第一次用去1/4，第二次用去剩下的1/3，还剩多少？
→ 设原来为单位"1"
→ 第一次后剩：1 - 1/4 = 3/4
→ 第二次用去：3/4 × 1/3 = 1/4
→ 还剩：3/4 - 1/4 = 1/2
```

### 分率与具体量的区分

```
易错：
"吃了1/4" vs "吃了1/4千克"
  - 1/4（分率）→ 没有单位，表示比例
  - 1/4千克（具体量）→ 有单位，表示具体数量
```

## 二、百分数应用题

### 核心公式

```
百分率 = (部分 ÷ 整体) × 100%
部分 = 整体 × 百分率
整体 = 部分 ÷ 百分率

涨跌问题：
  涨价后的价格 = 原价 × (1 + 涨价的百分率)
  降价后的价格 = 原价 × (1 - 降价的百分率)
```

### 常见题型

**题型一：折扣（打几折 = 原价 × 十分之几）**
```
一件衣服原价300元，打八折出售，现价多少？
→ 300 × 80% = 240 元
注意：打八折 = 乘 0.8，不是减 0.8
```

**题型二：税率**
```
李叔叔月收入8000元，超过5000元的部分要缴纳3%的个人所得税。
他每月应缴税多少元？
→ (8000 - 5000) × 3% = 3000 × 0.03 = 90 元
```

**题型三：利率**
```
妈妈在银行存了10000元，年利率2.5%，存两年，到期利息多少？
→ 10000 × 2.5% × 2 = 500 元
注意：利息 = 本金 × 年利率 × 年数（不计复利的小学范围）
```

**题型四：涨跌问题**
```
一种商品先涨价10%，再降价10%，现价是原价的百分之几？
→ 设原价为1
→ 涨价后：1 × (1 + 10%) = 1.1
→ 降价后：1.1 × (1 - 10%) = 1.1 × 0.9 = 0.99 = 99%
→ 比原价低了1%
```

## 三、比例应用题

### 题型一：按比例分配

**核心：** 先求总份数，再求每份的量

```
一个三角形的三个内角度数比是 2:3:4，三个角各是多少度？
总份数：2 + 3 + 4 = 9 份
每份：180° ÷ 9 = 20°
三个角：20°×2=40°，20°×3=60°，20°×4=80°
```

### 题型二：比例尺

```
核心公式：图上距离 : 实际距离 = 比例尺

在比例尺 1:5000000 的地图上，甲乙两地相距 6cm，实际距离是多少？
→ 6 ÷ 1/5000000 = 6 × 5000000 = 30000000 cm = 300 km
```

### 题型三：正反比例

```
正比例：x/y = 定值（一个量扩大，另一个也扩大）
反比例：x × y = 定值（一个量扩大，另一个缩小）

例：一辆车行驶速度一定，路程与时间成（正）比例
例：总路程一定，速度与时间成（反）比例
```

## 四、浓度问题

### 核心公式

```
浓度 = 溶质 ÷ 溶液 × 100%
溶质 = 溶液 × 浓度
溶液 = 溶质 ÷ 浓度
```

### 例题

**例1：** 将100克盐放入400克水中，盐水的浓度是多少？
```
溶液 = 100 + 400 = 500 克
浓度 = 100 ÷ 500 × 100% = 20%
```

**例2：** 有200克浓度为15%的盐水，蒸发掉多少克水后浓度变成20%？
```
原来含盐：200 × 15% = 30 克
盐不变，浓度变成20% → 新溶液 = 30 ÷ 20% = 150 克
蒸发水：200 - 150 = 50 克
```

## 五、经济问题

### 核心概念

```
成本价 = 进价（老板进货花的钱）
售价 = 卖出去的价格
利润 = 售价 - 成本
利润率 = 利润 ÷ 成本 × 100%
```

### 例题

**例：** 一件商品成本80元，售价120元，利润率是多少？
```
利润 = 120 - 80 = 40 元
利润率 = 40 ÷ 80 × 100% = 50%
```

## 六、工程问题中的分数应用

### 核心公式

```
工作效率 × 工作时间 = 工作总量
通常把工作总量看作单位"1"
工作效率 = 1 ÷ 完成时间
```

### 例题

**例：** 一项工程，甲单独做10天完成，乙单独做15天完成，甲乙合作几天完成？
```
甲每天做：1/10
乙每天做：1/15
合作每天做：1/10 + 1/15 = 3/30 + 2/30 = 5/30 = 1/6
合作时间：1 ÷ 1/6 = 6 天
```

## 七、分数百分数比例综合应用题

### 综合例1
```
某校男生比女生多1/5，女生比男生少60人，全校共多少人？

方法一：设女生为单位"1"
男生 = 1 + 1/5 = 6/5
男生比女生多：6/5 - 1 = 1/5
1/5对应60人 → 女生 = 60 ÷ 1/5 = 300 人
男生 = 300 × 6/5 = 360 人
全校 = 300 + 360 = 660 人
```

### 综合例2
```
一种商品按定价打八折出售，仍能获得20%的利润。
已知成本100元，定价是多少元？

设定价为x元
八折售价 = 0.8x
利润 = 0.8x - 100
利润率 = (0.8x - 100) ÷ 100 = 20% = 0.2
0.8x - 100 = 20
0.8x = 120
x = 150 元
→ 定价150元
```

## 八、解题步骤总结

```
分数/百分数/比例应用题，通用的四步法：

第一步：找单位"1"
  "的"前面，"比"后面，通常是单位"1"
  "的"字前面的量 → 单位"1"
  "比"字后面的量 → 单位"1"

第二步：画线段图
  把抽象的关系变成看得见的条块

第三步：列数量关系式
  标准量（单位"1"）× 对应分率 = 比较量

第四步：判断用乘还是用除
  已知单位"1" → 乘法
  未知单位"1" → 除法（或方程）
```
