## 💡 讲一讲

### 什么是平移？

**平移**：物体沿直线方向移动，形状大小不变。

**生活中的平移：**
- 🚪 推拉窗户
- 🛗 电梯上下
- 🎢 抽屉拉进拉出
- 🏗️ 传送带上的物品

```
平移 →→→→→→→→
┌──┐          ┌──┐
│  │          │  │
└──┘          └──┘
```

> 平移的特点：**方向不变**，**位置改变**。

---

### 什么是旋转？

**旋转**：物体围绕一个点或轴转动。

**生活中的旋转：**
- 🎡 摩天轮
- 🕐 钟表的指针
- 🌀 电风扇叶片
- 🚗 方向盘

```
  ┌──┐
  │  │   ↻ 旋转
  └──┘
```

> 旋转的特点：**围绕中心**，**方向改变**。

### 认识轴对称图形

**轴对称图形**：对折后两边完全重合的图形。

**折痕所在的直线叫对称轴。**

```
对折前：     对折后：
  ┌─┐        ┌─┐
  │ │        │ │    ← 两边完全重合
  └─┘        └─┘
```

**生活中的轴对称：**
- 🦋 蝴蝶
- 🏠 房子正面
- ❤️ 心形
- 🍁 某些树叶

---

### 常见图形的对称轴

| 图形 | 对称轴数量 | 图示 |
|:---:|:---:|:---|
| 正方形 | **4 条** | ─ │ ╱ ╲ |
| 长方形 | **2 条** | ─ │ |
| 圆 | **无数条** | |
| 等边三角形 | **3 条** | |
| 等腰三角形 | **1 条** | |

---

### 判断轴对称图形的方法

**三步法：**
1. 找一条可能的对称轴
2. 想象对折
3. 看两边是否完全重合

> 完全重合就是轴对称，不完全重合就不是。

### 胡小群追问

> **平移、旋转、轴对称这三种运动的共同点是什么？**

> 它们都**不改变图形的形状和大小**——只是改变了位置或方向。数学里这叫"刚体变换"或者"全等变换"。

## 🧩 想一想

**🤔 平行四边形是轴对称图形吗？为什么？**

> 普通的平行四边形不是轴对称图形——对折后两边不能完全重合。
> 但 **菱形**（特殊的平行四边形）是轴对称图形，它有 2 条对称轴。
> 所以不能一概而论，要具体看图形的形状！

**📌 从高中回头看：** 高中函数图像的"平移变换"——y=f(x)+3是把图像向上平移3个单位，和你把图形往上推是一样的操作。
