# 🔢 0~5 的认识和加减法

> 第一单元：小学数学的真正起点

---

## 🎯 学什么

- ✅ 认识 **0~5** 各数——会读会写会数
- ✅ 理解 **几和第几**——序数和基数的区别
- ✅ 认识 **0**——"没有"也是一个数
- ✅ 会用 **=、>、<** 比较大小
- ✅ 理解 **加法和减法** 的意义

---

## 💡 讲一讲

### 数不只是"数"

数字有三个意思，这是孩子最容易混淆的地方：

| 意思 | 例子 | 说明 |
|:----|:-----|:-----|
| 数量（基数） | 3个苹果 | 一共有几个 |
| 顺序（序数） | 第3个 | 排在第几 |
| 代号 | 3路公交车 | 名字而已 |

### 0 不是"什么都没有"

这是孩子第一次遇到"空"的概念。

> 盘子里有 3 个苹果，吃掉了 3 个，还剩 0 个。
> 0 就是"一个都没有"。
>
> **0 是一个真实的数，不是"不存在"。**

### 加法和减法——动作

很多孩子卡在"符号"上。其实加法和减法就是两个动作：

```
加法 → 合在一起 → 越来越多
减法 → 拿走一部分 → 越来越少
```

**例子：**
```
树上有 3 只鸟，又飞来了 2 只 → 3 + 2 = 5（合在一起）
树上有 5 只鸟，飞走了 2 只 → 5 - 2 = 3（拿走一部分）
```

### 胡小群追问

> **为什么 3 + 2 一定等于 5？能不能等于别的？**

> 这个问题听起来傻，但它是"数学确定性"的种子。3 + 2 = 5 不是老师规定的——你把 3 个和 2 个合在一起数，永远都是 5 个。数学的"对"不是老师说了算，是**事实说了算**。这个信念越早建立，后面学方程、学证明就越顺。

## 📝 记一记

| 概念 | 一句话 |
|:----|:-------|
| 基数 | "3个苹果"——表示数量 |
| 序数 | "第3个"——表示位置 |
| 0 | 一个都没有 |
| = | 两边一样多 |
| > | 左边比右边大 |
| < | 左边比右边小 |
| 加法 | 合在一起，越来越多 |
| 减法 | 拿走一部分，越来越少 |

## 🧩 想一想

**🤔 家里有 4 个人，吃饭要摆几双筷子？用加法怎么表示？**

> 4 个人，每人 1 双筷子 → 1 + 1 + 1 + 1 = 4
> 以后你会学到：这也可以写成 4 × 1 = 4（乘法就是相同加数的加法）
