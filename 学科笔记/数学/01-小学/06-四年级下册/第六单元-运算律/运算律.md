# 🔗 运算律

> 第六单元：运算律

---

## 🎯 学什么

- ✅ 理解 **加法交换律** 和 **加法结合律**
- ✅ 理解 **乘法交换律**、**乘法结合律** 和 **乘法分配律**
- ✅ 会用运算律进行 **简便计算**
- ✅ 能用字母表示运算律

---

## 💡 讲一讲

### 加法交换律

> 两个数相加，交换加数的位置，**和不变**。

```
a + b = b + a

例：26 + 38 = 38 + 26
    64 = 64 ✅
```

---

### 加法结合律

> 三个数相加，先算前两个或先算后两个，**和不变**。

```
(a + b) + c = a + (b + c)

例：(15 + 28) + 12 = 15 + (28 + 12)
    43 + 12 = 15 + 40
    55 = 55 ✅
```

**简便计算：**
28 + 36 + 64 = 28 + (36 + 64) = 28 + 100 = **128** ✅

---

### 乘法交换律

> 两个数相乘，交换乘数的位置，**积不变**。

```
a × b = b × a

例：25 × 4 = 4 × 25
   100 = 100 ✅
```

---

### 乘法结合律

> 三个数相乘，先算前两个或先算后两个，**积不变**。

```
(a × b) × c = a × (b × c)

例：25 × 17 × 4 = 25 × 4 × 17（先交换）
   = 100 × 17
   = 1700 ✅
```

---

### 乘法分配律

> 两个数的和乘一个数，等于每个数分别乘这个数再相加。

```
(a + b) × c = a × c + b × c

例：(40 + 4) × 25
= 40 × 25 + 4 × 25
= 1000 + 100
= 1100 ✅
```

**反过来用（提取公因数）：**
```
36 × 12 + 64 × 12
= (36 + 64) × 12
= 100 × 12
= 1200 ✅
```

---

### 运算律总结

| 名称 | 字母公式 | 例子 |
|:---|:---:|:---|
| 加法交换律 | a + b = b + a | 26 + 38 = 38 + 26 |
| 加法结合律 | (a + b) + c = a + (b + c) | (15+28)+12 = 15+(28+12) |
| 乘法交换律 | a × b = b × a | 25 × 4 = 4 × 25 |
| 乘法结合律 | (a × b) × c = a × (b × c) | 25×17×4 = (25×4)×17 |
| 乘法分配律 | (a + b) × c = a×c + b×c | (40+4)×25 = 40×25+4×25 |

---

### 胡小群追问

> **为什么加法交换律（a+b=b+a）和乘法交换律（a×b=b×a）都成立，但减法和除法没有交换律？**

> 因为减法和除法的结果会变——5-3≠3-5，6÷3≠3÷6。交换律是"顺序不影响结果"——只有加法和乘法有这个性质。

## 🧩 想一想

**🤔 为什么乘法分配律是"分配"？**

> 因为把 c 分给了 a 和 b，每人一份：
> (a + b) × c = a × c + b × c
> 就像把糖果分给两个人——先加起来再分，和先分再加起来，总数一样多！

**📌 从高中回头看：** 高中的"矩阵乘法"不满足交换律（A×B≠B×A），"向量的叉乘"也不满足——当你学到这里时会发现，交换律原来不是理所当然的。小学的运算律是代数结构的基石。
