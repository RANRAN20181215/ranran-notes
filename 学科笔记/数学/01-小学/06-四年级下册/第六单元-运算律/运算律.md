# 🔗 运算律

> 第六单元：运算律

---

## 🎯 学什么

- ✅ 理解 **加法交换律** 和 **加法结合律**
- ✅ 理解 **乘法交换律**、**乘法结合律** 和 **乘法分配律**
- ✅ 会用运算律进行 **简便计算**
- ✅ 能用字母表示运算律

---

## 💡 讲一讲

### 加法交换律

> 两个数相加，交换加数的位置，**和不变**。

```
a + b = b + a

例：26 + 38 = 38 + 26
    64 = 64 ✅
```

---

### 加法结合律

> 三个数相加，先算前两个或先算后两个，**和不变**。

```
(a + b) + c = a + (b + c)

例：(15 + 28) + 12 = 15 + (28 + 12)
    43 + 12 = 15 + 40
    55 = 55 ✅
```

**简便计算：**
28 + 36 + 64 = 28 + (36 + 64) = 28 + 100 = **128** ✅

---

### 乘法交换律

> 两个数相乘，交换乘数的位置，**积不变**。

```
a × b = b × a

例：25 × 4 = 4 × 25
   100 = 100 ✅
```

---

### 乘法结合律

> 三个数相乘，先算前两个或先算后两个，**积不变**。

```
(a × b) × c = a × (b × c)

例：25 × 17 × 4 = 25 × 4 × 17（先交换）
   = 100 × 17
   = 1700 ✅
```

---

### 乘法分配律

> 两个数的和乘一个数，等于每个数分别乘这个数再相加。

```
(a + b) × c = a × c + b × c

例：(40 + 4) × 25
= 40 × 25 + 4 × 25
= 1000 + 100
= 1100 ✅
```

**反过来用（提取公因数）：**
```
36 × 12 + 64 × 12
= (36 + 64) × 12
= 100 × 12
= 1200 ✅
```

---

### 运算律总结

| 名称 | 字母公式 | 例子 |
|:---|:---:|:---|
| 加法交换律 | a + b = b + a | 26 + 38 = 38 + 26 |
| 加法结合律 | (a + b) + c = a + (b + c) | (15+28)+12 = 15+(28+12) |
| 乘法交换律 | a × b = b × a | 25 × 4 = 4 × 25 |
| 乘法结合律 | (a × b) × c = a × (b × c) | 25×17×4 = (25×4)×17 |
| 乘法分配律 | (a + b) × c = a×c + b×c | (40+4)×25 = 40×25+4×25 |

### 胡小群追问

> **为什么加法交换律（a+b=b+a）和乘法交换律都成立，但减法和除法没有？**
>
> 因为减法和除法的结果会变——5-3≠3-5，6÷3≠3÷6。交换律是"顺序不影响结果"——只有加法和乘法有这个性质。

---

### 📏 单位视角看运算律

#### 加法交换律 + 加法结合律 → 同单位才能合并

三上已经学过**单位**的概念——计数单位、长度单位、面积单位。运算律的秘密藏在这里：

```
加法能交换能结合，前提是：所有加数都是"同一个单位"。

3个一 + 5个一 = 8个一    ✅ 同单位，直接合并
3个十 + 5个十 = 8个十    ✅ 同单位，直接合并
3个十 + 5个一 = ？       ❌ 单位不同，不能直接加

换句话说：加法就是"用同一个单位数数"。
```

> **追问：** 那 3 个十 + 5 个一到底等于多少？
>
> 答：3个十 = 30个一，所以 30个一 + 5个一 = 35个一 = 35。
> 这就是"进位"的本质——**换一个更小的单位，让单位统一**。

---

#### 乘法交换律 + 乘法结合律 → 单位的角度

乘法一样依赖"同单位"：

```
3×5 的意思是"3个5"，单位是"5"
5×3 的意思是"5个3"，单位是"3"

3×5 ≠ 5×3 从字面看不一样：
  3个5：5 + 5 + 5 = 15  （单位是5）
  5个3：3 + 3 + 3 + 3 + 3 = 15  （单位是3）

虽然单位不同，但总数一样——这就是"交换律"的几何意义：
把 3 行 5 列转置成 5 行 3 列，总数不变。
```

> **追问：** 那为什么 25×17×4 可以先算 25×4？
>
> 答：因为你可以换个顺序看——25个17×4 相当于 4个25×17。
> 本质上是用"交换律"重新分组，让计算变得更顺手。
> **更深一层：** 乘法分配律的提取公因数也是在提取"公共单位"。

---

#### 乘法分配律 → 分配的是"单位"

```
(40 + 4) × 25
= 40 × 25 + 4 × 25
= 1000 + 100
= 1100
```

**用单位的话说：**
- 40个25 + 4个25 = 44个25
- 25 就是"单位"，40和4是"有几个"
- 分配律就是把同一个单位分配给两个部分，再合起来

**反过来（提取公因数）：**
```
36 × 12 + 64 × 12
= (36 + 64) × 12
= 100 × 12
= 1200
```

**用单位的话说：**
- 36个12 + 64个12 = 100个12
- 12 就是"公共单位"，合并"有几个"就行了
- 这和一年级学的"3个一加5个一 = 8个一"是**同一个道理**！

> **追问：** 提取公因数和初中的"合并同类项"是什么关系？
>
> 答：**一模一样的关系。**
> 合并同类项：2x + 3x = (2+3)x = 5x —— x 就是"单位"
> 提取公因数：36×12 + 64×12 = (36+64)×12 —— 12 就是"单位"
> 因式分解：ax + bx = x(a+b) —— x 就是"公共单位"
>
> **运算律 = 单位的合并规则。** 小学就在学，到高中还在用。

---

### 🧩 等号三条性质 × 运算律

运算律的本质就是**等号三条性质**在计算中的具体表现：

| 等号性质 | 运算律体现 |
|:---------|:----------|
| **自反性**（A=A） | 同单位的量才能用等号连接 |
| **对称性**（A=B→B=A） | 交换律：a+b = b+a |
| **传递性**（A=B, B=C→A=C） | 结合律：(a+b)+c = a+(b+c) |

> 等号的传递性告诉你：换一种运算顺序，结果不变。
> 运算律不是"巧算技巧"，是**"顺序不影响结果"的数学证明**。

## 🧩 想一想

**🤔 为什么乘法分配律是"分配"？**

> 因为把 c 分给了 a 和 b，每人一份：
> (a + b) × c = a × c + b × c
> 就像把糖果分给两个人——先加起来再分，和先分再加起来，总数一样多！

**📌 从高中回头看：** 高中的"矩阵乘法"不满足交换律（A×B≠B×A），"向量的叉乘"也不满足——当你学到这里时会发现，交换律原来不是理所当然的。小学的运算律是代数结构的基石。
