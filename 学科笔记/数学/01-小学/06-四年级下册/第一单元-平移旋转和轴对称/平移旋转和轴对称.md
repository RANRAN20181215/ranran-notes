# 🔄 平移、旋转和轴对称（二）

> 第一单元：平移、旋转和轴对称

---

## 🎯 学什么

- ✅ 在方格纸上 **平移** 图形
- ✅ 在方格纸上 **旋转** 图形（90°）
- ✅ 认识 **轴对称图形** 的对称轴
- ✅ 在方格纸上画轴对称图形的另一半

---

## 💡 讲一讲

### 在方格纸上平移

**例：** 把三角形向右平移 5 格

```
 平移前             平移后
+---+---+---+    +---+---+---+
|   |   |   |    |   |   |   |
|   | o |   |    |   |   | o |
|   | o |   |    |   |   | o |
+---+---+---+    +---+---+---+
     ----> 向右 5 格
```

**规则：** 图形平移后，形状、大小、方向不变，位置改变。

---

### 在方格纸上旋转

**例：** 把线段绕 O 点顺时针旋转 90°

```
 原图           旋转 90°
 o----           o
                 |
                 |
```

**画旋转图形的方法：**
1. 确定旋转中心 O
2. 确定旋转方向（顺时针或逆时针）
3. 依次画出旋转后的每条边

---

### 画轴对称图形

**例：** 画出下面图形的另一半

```
     对称轴
       |
       |       已有一半
    +--+--+
    |  |  |
    +--+--+
```

**方法：** 找到关键点，量出到对称轴的距离，在另一边画出对称点，再连线。

---

### 胡小群追问

> **平移和旋转的区别是什么？**

> 平移是沿直线移动——每个点移动的方向和距离都一样。旋转是绕一个点转圈——每个点转的角度一样，但移动的距离不一样（离中心越远移得越多）。

---

## 📝 记一记

| 图形变换 | 特点 |
|:---|:---|
| ↔️ **平移** | 沿直线移动，形状大小方向不变 |
| ↻ **旋转** | 绕中心转动，形状大小不变，方向变 |
| 🪞 **轴对称** | 对折后两边完全重合 |

## 🧩 想一想

**🤔 平移和旋转有什么相同点和不同点？**

> **相同点：** 都不改变图形的形状和大小
> **不同点：**
> - 平移是 **沿直线移动**，方向不变
> - 旋转是 **绕中心转动**，方向改变

**📌 从高中回头看：** 高中"三角函数"就是在描述旋转——sin和cos告诉你旋转后的点在什么位置。再往后到大学，"矩阵"可以一次完成平移+旋转。你现在在方格纸上画的每一个变换，都是未来"线性代数"的直观基础。
