# ➕ 分数加法和减法

> 第五单元：分数加法和减法

---

## 💡 讲一讲

### 同分母分数加减法

**规则：分母不变，分子相加减。**

**加法：** 2/7 + 3/7 = (2+3)/7 = **5/7**
**减法：** 5/9 - 2/9 = (5-2)/9 = **3/9 = 1/3**

**例：**
> 小明吃了 1/4 个蛋糕，小红吃了 2/4 个，一共吃了多少？

1/4 + 2/4 = 3/4 ✅

---

### 异分母分数加减法

**规则：先通分，再按同分母分数加减法计算。**

**例①：** 1/2 + 1/3 = ?

```
1/2 = 3/6
1/3 = 2/6
1/2 + 1/3 = 3/6 + 2/6 = 5/6 ✅
```

**例②：** 5/6 - 1/3 = ?

```
5/6 = 5/6
1/3 = 2/6
5/6 - 1/3 = 5/6 - 2/6 = 3/6 = 1/2 ✅
```

---

### 分数加减混合运算

**例：** 1/2 + 1/4 - 1/8

```
= 4/8 + 2/8 - 1/8
= (4 + 2 - 1)/8
= 5/8 ✅
```

> 和整数混合运算一样：有括号先算括号，没括号从左到右。

---

### 分数加减法简便计算

**交换律：** a + b = b + a
**结合律：** (a + b) + c = a + (b + c)

**例：** 2/7 + 3/8 + 5/7

```
= 2/7 + 5/7 + 3/8
= 7/7 + 3/8
= 1 + 3/8
= 1 3/8 ✅
```

---

### 计算结果化简

> 计算结果能约分的要 **约成最简分数**，是假分数的要 **化成带分数或整数**。

**例：** 3/8 + 5/8 = 8/8 = **1**
**例：** 5/6 + 5/6 = 10/6 = 5/3 = **1 2/3**

---

### 胡小群追问

> **为什么1/2+1/3不能直接2+3、1+1？**

> 因为"单位"不同——1/2是把1分成2份取1份，1/3是把1分成3份取1份。通分就是让它们变成"相同大小的一份"——1/2=3/6, 1/3=2/6, 3/6+2/6=5/6。

## 🧩 想一想

**🤔 为什么异分母分数不能直接相加减？**

> 因为 **分数单位不同**！
> 1/2 的分数单位是 1/2，1/3 的分数单位是 1/3。
> 就像 1 米 + 1 分米不能直接加一样，要先化成相同单位。
> **通分就是把分数单位变成相同的过程。**

**📌 从高中回头看：** 高中"分式加减"原理完全一样——$\frac{1}{x} + \frac{1}{x+1} = \frac{x+1}{x(x+1)} + \frac{x}{x(x+1)}$，还是通分、分母不变分子加减。区别只是分母从数字变成了代数式。你现在练的"异分母通分"，就是未来"分式运算"的根基。
