## 💡 讲一讲

### 小数加法

**规则：小数点对齐，按整数加法算。**

**例①：** 0.6 + 0.3 = ?

```
  0.6
+ 0.3

  0.9
```

**例②（进位）：** 5.7 + 3.8 = ?

```
  5.7
+ 3.8

  9.5    ← 7+8=15，写 5 进 1
```

---

### 小数减法

**规则：小数点对齐，按整数减法算。**

**例①：** 0.9 - 0.4 = ?

```
  0.9
- 0.4

  0.5
```

**例②（退位）：** 6.2 - 4.7 = ?

```
  5 12
  6.2        ← 2 不够减 7，从个位借 1
- 4.7

  1.5
```

---

### 位数不同怎么办

**补 0 再算：**

**例：** 3.5 + 2.16 = ?

```
  3.50    ← 补一个 0
+ 2.16

  5.66
```

> 利用小数的性质：末尾补 0 大小不变。

---

### 生活中的小数加减

**例：**
> 小明买了一支笔 2.5 元，一块橡皮 1.8 元。一共花了多少钱？

```
  2.5
+ 1.8

  4.3（元）✅
```

**例：**
> 小红有 10 元，买了一个 6.8 元的文具盒，还剩多少钱？

```
  10.0    ← 补一个 0
-  6.8

   3.2（元）✅
```

---

### 胡小群追问

> **小数加减法为什么必须小数点对齐？**

> 因为小数点对齐就是"相同数位对齐"——和整数加减一个道理。5.3+2.47，5.3的3在十分位，2.47的4也在十分位，两个十分位才能相加。

## 🧩 想一想

**🤔 为什么小数加减法要把小数点对齐，而不是末尾对齐？**

> 整数加减法把末尾对齐，是因为个位在最右边。
> 小数的小数点位置就是 **个位和十分位的分界点**。
> 小数点对齐 = 个位对齐 = 相同数位对齐。
> 这样才能保证 **十分位对十分位、百分位对百分位**。

**📌 从高中回头看：** 高中代数式中"合并同类项"的原理和小数点对齐完全一样——只有相同数位（同类项）才能直接加减。比如 $3x^2 + 2x^2 = 5x^2$，也是"相同单位的才能合并"。你现在学的小数点对齐，就是未来代数变形的基础。
