## 🧭 家长使用建议

- **冉冉现在一年级** → 优先看 `00-一年级上册` 和 `00-一年级下册`
- 每个笔记格式：学什么 → 讲一讲 → 记一记 → 练一练 → 小游戏 → 想一想
- **胡小群追问** 部分标注了每个单元的关键概念深挖点
- **从高中回头看** 标注了当前知识在未来的延伸方向
