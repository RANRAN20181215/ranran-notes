> 第三单元：认识方向

## 💡 讲一讲

### 生活中的方向

**太阳是从东边升起的！**

面对太阳升起的方向（东）：
- 背后是 **西**
- 左手指向 **北**
- 右手指向 **南**

> **面东背西，左北右南**

### 方向口诀

```
        北
         ↑
   西北  │  东北
         │
西 ──────┼──────→ 东
         │
   西南  │  东南
         ↓
        南
```

### 八个方向

| 方向 | 在哪儿？ |
|:---|:---|
| 🧭 **东** | 太阳升起的地方 |
| 🌅 **西** | 太阳落下的地方 |
| 🥶 **北** | 北极星的方向 |
| ☀️ **南** | 太阳在正南方（中午） |
| 🟠 **东北** | 东和北之间 |
| 🟡 **东南** | 东和南之间 |
| 🟢 **西北** | 西和北之间 |
| 🔵 **西南** | 西和南之间 |

### 怎样看平面图？

平面图通常 **上北、下南、左西、右东**。

```
          ↑ 北
        ╔══════╗
   西 ← ║ 操场 ║ → 东
        ╚══════╝
          ↓ 南
```

**教学楼在操场的北面。**
**大门在操场的南面。**

### 描述位置

> 图书馆在学校的 **东面**。
> 食堂在图书馆的 **北面**。

关键是找到 **参照物**——"在谁的哪一面"，谁就是参照物。



### 胡小群追问

> **为什么方向只有"东南西北"四个？**

> 这是一个"参照系"——先确定一个方向（北），剩下三个就都定了。以后学坐标（平面直角坐标系）也是类似的思路：先确定原点和方向，然后每个点都有了一个"地址"。

## ✍️ 练一练

**① 填空：**
- 太阳从（ ）方升起，从（ ）方落下。
- 面向北站着，背面是（ ），左面是（ ），右面是（ ）。
- 地图上通常的方向是：上（ ）、下（ ）、左（ ）、右（ ）。

**② 看图回答问题：**

```
          ↑ 北
    ┌────┐    ┌────┐
    │书店│    │医院│
    └────┘    └────┘
  ┌────┐ ┌────┐ ┌────┐
  │学校│ │广场│ │邮局│
  └────┘ └────┘ └────┘
    ┌────┐    ┌────┐
    │超市│    │公园│
    └────┘    └────┘
```

- 书店在学校的（ ）面。
- 邮局在广场的（ ）面。
- 医院在学校的（ ）面。
- 超市在学校的（ ）面。

*参考答案：① 东，西；南，西，东；北，南，西，东　② 北，东，东北，南*

## 🧩 想一想

**🤔 如果你面向北，向左转 90° 后面向什么方向？再向左转 90° 呢？**

> 面向北 → 向左转 → 面向 **西**
> 再向左转 → 面向 **南**
>
> 每向左转一次，方向逆时针变化：
> **北 → 西 → 南 → 东 → 北**
