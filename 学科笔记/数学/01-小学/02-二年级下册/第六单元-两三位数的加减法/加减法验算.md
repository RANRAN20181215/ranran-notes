## 💡 讲一讲

### 为什么需要验算？

做计算题的时候，谁都有可能犯错。**验算就是再算一遍，用不同的方法检查答案对不对。**

### 加法的验算

**加法算式：** 加数 + 加数 = 和

**验算方法一：交换加数位置再算一遍**

> 236 + 157 = 393
>
> 验算：157 + 236 = 393 ✅

因为加法交换律，交换两个加数的位置，和不变。

**验算方法二：用减法验算**

> 和 - 加数 = 另一个加数
>
> 393 - 236 = 157 ✅
> 393 - 157 = 236 ✅

### 减法的验算

**减法算式：** 被减数 - 减数 = 差

**验算方法一：用加法验算**

> 差 + 减数 = 被减数
>
> 415 - 238 = 177
>
> 验算：177 + 238 = 415 ✅

**验算方法二：用减法验算**

> 被减数 - 差 = 减数
>
> 415 - 177 = 238 ✅

### 验算三步法

```
① 写答案
② 用另一种方法再算一遍
③ 两次结果一样 → 答案正确
   两次结果不一样 → 检查哪里算错了
```

### 估算也帮忙

**估一估，看看答案是否合理：**

> 256 + 378 = 634
> 估算：250 + 380 = 630，接近 634 ✅

> 800 - 324 = 476
> 估算：800 - 300 = 500，接近 476 ✅

如果估算和答案差很远，一定算错了！



### 胡小群追问

> **为什么加法可以用减法验算？**

> 因为加法和减法互为逆运算——a+b=c，那么c-b=a，c-a=b。反过来，减法也可以用加法验算。

## 📝 记一记

| 运算 | 验算方法 |
|:---|:---|
| ➕ **加法验算** | ① 交换加数再算 ② 和 - 加数 = 另一个加数 |
| ➖ **减法验算** | ① 差 + 减数 = 被减数 ② 被减数 - 差 = 减数 |
| 🔍 **估算检查** | 把数看成整百、整十进行估算，看答案是否合理 |
| ✏️ **避免粗心** | 数位对齐、进位退位标记清楚后再验算 |

## 🎮 小游戏

### 🔄 验算小侦探

一人写一道计算题（故意可能算错），另一人扮演小侦探，用验算找出错误！

**例：** A 写"500 - 236 = 274"，B 验算：274 + 236 = 510 ≠ 500 → 发现错了！正确答案是 264。

## 🧩 想一想

**🤔 做减法验算时，为什么用"差 + 减数"来验算？这和加法有什么关系？**

> 因为减法是加法的 **逆运算**。
>
> 被减数 - 减数 = 差，那反过来：差 + 减数 = 被减数。
>
> 就像上楼梯和下楼梯，一个向上一个向下，但走的是同一段路！
