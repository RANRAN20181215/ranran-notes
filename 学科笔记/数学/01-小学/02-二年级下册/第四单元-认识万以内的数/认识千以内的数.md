# 🔢 认识千以内的数

> 第四单元：认识万以内的数

---

## 🎯 学什么

- ✅ 认识计数单位 **"千"**
- ✅ 知道 **10 个一百是一千**
- ✅ 会读、写千以内的数
- ✅ 理解 **数位顺序**：个位、十位、百位、千位

---

## 💡 讲一讲

### 从一百到一千

我们已经认识了 **百**，10 个十是一百。

那 **一千** 有多大？

> **10 个一百是一千！**

```
100, 200, 300, 400, 500, 600, 700, 800, 900, 1000
↑                                  ↑          ↑
一百                             九百        一千
```

### 数位顺序表

| 千位 | 百位 | 十位 | 个位 |
|:---:|:---:|:---:|:---:|
| | | | |

**从右边起：**
- 第一位是 **个位**
- 第二位是 **十位**
- 第三位是 **百位**
- 第四位是 **千位**

### 读写方法

**写数：** 从高位写起，哪一位上有几个单位就在那一位写几。

**例：** 三百五十七

| 千位 | 百位 | 十位 | 个位 |
|:---:|:---:|:---:|:---:|
| | 3 | 5 | 7 |

写作：**357**

**读数：** 从高位读起，百位是几读几百，十位是几读几十……

**例：** 406

> 百位是 4 → 四百
> 十位是 0 → 不读（中间有 0 要读"零"）
> 个位是 6 → 六
> 读作：**四百零六**

**例：** 730

> 百位是 7 → 七百
> 十位是 3 → 三十
> 个位是 0 → 不读（末尾的 0 不读）
> 读作：**七百三十**

### 数的组成

**582 = 500 + 80 + 2**
> 5 个百、8 个十、2 个一

**举个例子：** 有 3 个百、4 个十、8 个一组成的数是 **348**。



### 胡小群追问

> **1000为什么是"一千"而不是"十百"？**

> 因为每满10就进一个新的计数单位：个→十→百→千→万。这是十进制位值制的精髓。
