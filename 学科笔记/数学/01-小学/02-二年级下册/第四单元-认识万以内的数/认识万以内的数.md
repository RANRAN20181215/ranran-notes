## 💡 讲一讲

### 从一千到一万

10 个一百是一千，那 **一万** 有多大？

> **10 个一千是一万！**

```
1000, 2000, 3000, 4000, 5000, 6000, 7000, 8000, 9000, 10000
```

### 数位顺序表（四位一级）

| 万位 | 千位 | 百位 | 十位 | 个位 |
|:---:|:---:|:---:|:---:|:---:|
| 第 5 位 | 第 4 位 | 第 3 位 | 第 2 位 | 第 1 位 |

### 数的组成

**3256 = 3000 + 200 + 50 + 6**

| 万位 | 千位 | 百位 | 十位 | 个位 |
|:---:|:---:|:---:|:---:|:---:|
| | 3 | 2 | 5 | 6 |

> 3 个千、2 个百、5 个十、6 个一

### 读写法规则

**写数** 从高位写起：

> 三千二百零五 → 3205
> 五千零六十 → 5060
> 一万 → 10000

**读数** 从高位读起：

| 数字 | 读法 | 注意 |
|:---:|:---|:---|
| 4305 | 四千三百零五 | 中间有 0 要读"零" |
| 5008 | 五千零八 | 中间连续两个 0，只读一个"零" |
| 3800 | 三千八百 | 末尾的 0 不读 |
| 10000 | 一万 | |

### 算盘上的数

**认识算盘：**

- 一颗 **上珠** 表示 **5**
- 一颗 **下珠** 表示 **1**
- 记数前先 **清盘**（上珠拨上，下珠拨下）

**例：** 在算盘上拨出 352

```
   ┌──┬──┬──┬──┬──┐
   │  │  │  │  │  │
   ├──┼──┼──┼──┼──┤
   │  │  │● │  │  │  ← 上珠（一个=5）
   ├──┼──┼──┼──┼──┤
   │  │●●│  │●●│  │  ← 下珠（一个=1）
   └──┴──┴──┴──┴──┘
     万  千  百  十  个
```

> 百位：上珠 1 个（5）+ 下珠 3 个（3）= 3？不对，应该是百位上一颗上珠（5）不够，需要：百位上珠 0 + 下珠 3 = 3

其实正确的拨法：百位 3 用 3 颗下珠，十位 5 用 1 颗上珠，个位 2 用 2 颗下珠。



### 胡小群追问

> **9999再添1是10000——为什么读作"一万"而不是"十千"？**

> 因为每4位是一级（个级、万级、亿级），满一万就升到万级。这是"四位一级"的中文数字读法。

## 📝 记一记

| 规则 | 说明 |
|:---|:---|
| 🔢 **10 个一千是一万** | 千和万之间的进率是 10 |
| 📋 **数位顺序** | 个、十、百、千、万（从右往左） |
| 📖 **读数规则** | 中间有 0 读"零"，不管几个 0 只读一个；末尾 0 都不读 |
| ✍️ **写数规则** | 从高位写起，哪一位上没有就写 0 |
| 🧮 **算盘** | 上珠一个=5，下珠一个=1 |

## 🧩 想一想

**🤔 用 2、0、0、8 四张数字卡片能摆出哪些四位数？从小到大排一排。**

> 注意：千位不能是 0。
> 2008、2080、2800、8002、8020、8200
>
> 从小到大：2008 < 2080 < 2800 < 8002 < 8020 < 8200
>
> **📌 从高中回头看：** 高中"科学记数法"（3×10⁵）和"对数"(log)，都源于同一种需要——用简洁的方式表示很大的数。你现在学的万、亿、兆，就是中文版的"科学记数法"。

---

📏 **单位主线连接：** 从一上到二下，计数单位从"一"扩展到"万"——个、十、百、千、万，每级×10。数位顺序表本质上就是**计数单位的层级表**。万以内数的读写规则（中间0读一个、末尾0不读）都是在处理"哪些位上有单位、哪些位上没有"。
