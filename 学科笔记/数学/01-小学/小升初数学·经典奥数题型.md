# 小升初数学 · 经典奥数题型

> 选拔性考试必考题型
> 五、六年级复习用

## 一、植树问题

### 核心公式

```
① 两端都种：棵数 = 段数 + 1 = 总长 ÷ 间距 + 1
② 一端种一端不种：棵数 = 段数 = 总长 ÷ 间距
③ 两端都不种：棵数 = 段数 - 1 = 总长 ÷ 间距 - 1
④ 环形种树：棵数 = 段数 = 总长 ÷ 间距
```

### 例题

**例1：** 一条路长100米，每隔5米种一棵树（两端都种），需要多少棵树？
```
100 ÷ 5 + 1 = 21 棵
```

**例2：** 一个圆形花坛周长60米，每隔3米种一棵花，共种多少棵？
```
60 ÷ 3 = 20 棵（环形=段数）
```

**例3：** 一座桥长120米，在桥的两边从头到尾每隔6米装一盏灯，共需多少盏？
```
一边：120 ÷ 6 + 1 = 21 盏
两边：21 × 2 = 42 盏
```

### 变式
```
敲钟问题：敲6下用10秒，每下之间间隔相同，敲12下用几秒？
→ 6下有5个间隔，每个间隔 10÷5=2秒
→ 12下有11个间隔，需 11×2=22秒

锯木头：锯成5段需要锯几次？→ 5-1=4次
爬楼梯：从1楼到4楼爬了几层？→ 4-1=3层
```

## 二、鸡兔同笼

### 核心方法：假设法

```
假设全是鸡（或全是兔）→ 算出差值 → 调整
```

### 例题

**例1：** 笼子里有鸡和兔共35个头，94只脚。鸡兔各几只？
```
假设全是鸡：35 × 2 = 70 只脚
比实际少：94 - 70 = 24 只脚
一只鸡换一只兔多2只脚：24 ÷ 2 = 12 只（兔）
鸡：35 - 12 = 23 只
→ 答：鸡23只，兔12只
```

**例2：** 停车场有自行车和三轮车共20辆，轮子共48个。自行车、三轮车各几辆？
```
假设全是自行车：20 × 2 = 40 个轮
比实际少：48 - 40 = 8 个
一辆自行车换三轮车多1个轮：8 ÷ 1 = 8 辆（三轮车）
自行车：20 - 8 = 12 辆
→ 答：自行车12辆，三轮车8辆
```

### 口诀
```
鸡兔同笼不用慌，假设法是王中王
先全假设成一种，差值除以单只差
```

## 三、盈亏问题

### 核心公式

```
（盈 + 亏）÷ 两次分配差 = 人数
（盈 - 盈）÷ 两次分配差 = 人数
（亏 - 亏）÷ 两次分配差 = 人数
```

### 例题

**例1：** 分苹果，每人分3个多5个，每人分4个少3个。有多少人？多少个苹果？
```
人数：(5 + 3) ÷ (4 - 3) = 8 ÷ 1 = 8 人
苹果：8 × 3 + 5 = 29 个（或 8 × 4 - 3 = 29 个）
```

**例2：** 分书，每人分5本多10本，每人分6本多2本。有多少人？
```
两次都多（盈 - 盈）：(10 - 2) ÷ (6 - 5) = 8 ÷ 1 = 8 人
```

**例3：** 分练习本，每人分8本少6本，每人分7本少2本。有多少人？
```
两次都少（亏 - 亏）：(6 - 2) ÷ (8 - 7) = 4 ÷ 1 = 4 人
```

## 四、周期问题

### 核心方法

```
周期数（一个完整的循环）→ 总数量 ÷ 周期长度
余数 → 找到余数对应的位置
```

### 例题

**例1：** 按"红黄蓝绿"的顺序重复排列彩灯，第38盏灯是什么颜色？
```
周期长度：4（红黄蓝绿）
38 ÷ 4 = 9……2
余数2 → 第2个是黄色
→ 答：第38盏是黄色
```

**例2：** 今天是星期一，第100天是星期几？
```
周期长度：7（周一到周日）
(100 - 1) ÷ 7 = 14……1（今天算第0天或第1天）
→ 先减第1天：100-1=99，99÷7=14…1，余1是星期一
→ 第100天是星期二
```

### 易错点
```
「第几个」和「第几天后」不一样：
- 第20个 → 直接看 20 ÷ 周期
- 20天后 → 今天是第0天，过1天是第1天
```

## 五、年龄问题

### 核心规律

```
① 年龄差永远不变
② 每人每年长1岁
③ 画线段图最直观
```

### 例题

**例1：** 爸爸今年36岁，儿子今年8岁。几年后爸爸的年龄是儿子的2倍？
```
年龄差：36 - 8 = 28 岁（永远不变）
爸爸是儿子2倍时，儿子年龄 = 年龄差 ÷ (倍数-1)
儿子 = 28 ÷ (2-1) = 28 岁
28 - 8 = 20 年后
→ 答：20年后
```

**例2：** 妈妈今年30岁，女儿今年6岁。几年前妈妈的年龄是女儿的5倍？
```
年龄差：30 - 6 = 24 岁
妈妈是女儿5倍时，女儿 = 24 ÷ (5-1) = 6 岁
现在女儿就是6岁，所以是0年前→不对，重新想：
实际上现在就是5倍？30÷6=5，对，现在就是5倍，0年前。
换个题：妈妈32岁，女儿8岁，几年前妈妈是女儿的5倍？
年龄差：24岁
当时女儿 = 24 ÷ (5-1) = 6 岁
8 - 6 = 2年前
```

## 六、和倍与差倍问题

### 核心公式

```
和倍问题：
  小数 = 和 ÷ (倍数 + 1)
  大数 = 小数 × 倍数

差倍问题：
  小数 = 差 ÷ (倍数 - 1)
  大数 = 小数 × 倍数
```

### 例题

**例1（和倍）：** 甲、乙两数的和是60，甲是乙的3倍。甲、乙各是多少？
```
乙（小数）= 60 ÷ (3 + 1) = 15
甲（大数）= 15 × 3 = 45
```

**例2（差倍）：** 甲比乙多24，甲是乙的4倍。甲、乙各是多少？
```
乙 = 24 ÷ (4 - 1) = 8
甲 = 8 × 4 = 32
```

## 七、牛吃草问题（牛顿问题）

### 核心思路

```
① 先求每天新长出的草（单位时间增量）
② 再求原来有多少草
③ 最后求"几头牛吃几天"
```

### 例题

**例：** 一片草地，10头牛吃20天，15头牛吃10天。多少头牛吃5天？
```
设每头牛每天吃1份草
10头牛20天：10 × 20 = 200 份（草总量）
15头牛10天：15 × 10 = 150 份（草总量）

每天新长草：(200 - 150) ÷ (20 - 10) = 50 ÷ 10 = 5 份/天

原来有草：200 - 20 × 5 = 100 份

5天新长草：5 × 5 = 25 份
总共草：100 + 25 = 125 份
牛数：125 ÷ 5 = 25 头
→ 答：25头牛吃5天
```

## 八、抽屉原理

### 核心原理

```
把 n+1 个物体放进 n 个抽屉，至少有一个抽屉里有 2 个以上物体。
把 mn+1 个物体放进 n 个抽屉，至少有一个抽屉里有 m+1 个以上物体。
```

### 例题

**例1：** 有5个苹果放到4个抽屉里，不管怎么放，总有一个抽屉至少有几个苹果？
```
5 ÷ 4 = 1…1 → 1 + 1 = 2
至少有2个苹果放在同一个抽屉里
```

**例2：** 一副扑克牌（不含大小王）52张，至少抽多少张才能保证有3张同花色？
```
最坏情况：每种花色各抽2张，共2×4=8张
再抽第9张，无论什么花色都会凑成3张同花色
→ 至少抽9张
```

## 九、逻辑推理

### 常用方法

```
① 列表法（画表格，打✓打✗）
② 假设法（先假设一个条件成立，推出矛盾则假设不成立）
③ 排除法（不是A不是B→只能是C）
```

### 例题

**例：** 甲、乙、丙三人中，一人是语文老师，一人是数学老师，一人是英语老师。已知：
```
① 甲比数学老师年龄大
② 乙和英语老师是朋友
③ 丙比英语老师年龄小
问：三人各教什么？

推理：
从②可知：乙不是英语老师
从①可知：甲不是数学老师
从③可知：丙不是英语老师

→ 英语老师只能是甲
→ 甲不是数学老师，甲是英语老师，所以乙或丙是数学老师
从①可知：甲比数学老师大→数学老师是乙或丙
从③可知：丙比甲（英语老师）小
→ 甲是英语老师、乙是数学老师、丙是语文老师
→ 答：甲英语、乙数学、丙语文
```

## 十、综合刷题策略

```
小升初奥数题不要追求"全部会做"：

① 基础题（80%）：植树、鸡兔同笼、和倍差倍、年龄、周期
   → 必须熟练掌握，考试中不能失分

② 进阶题（15%）：盈亏、逻辑推理、牛吃草
   → 能做就做，不会就写步骤分

③ 难题（5%）：复杂的牛吃草、多重周期
   → 可以战略性放弃，把时间留给前面的题

复习建议：
  - 每类先做 3 道例题（看懂）
  - 再做 3 道练习题（独立完成）
  - 错题标记，一周后重做
```
