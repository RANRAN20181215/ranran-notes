# 应用题大全

> 从 1 年级到高三，应用题只有 4 种结构
> 适用：想突破应用题关的所有孩子

---

## 一、应用题的底层逻辑

胡小群说得最直接的一句话：

> **数学好其实是语文好。**

应用题考的不是数学计算，是**把"中文描述"翻译成"数学表达式"的能力。**

```
题目（中文） → 理解（脑子） → 翻译（数学式子） → 计算（数学） → 答案
                │
         80% 的孩子卡在这里
         不是不会算，是没读懂题目在说什么
```

### 所有应用题的 4 种核心结构

不管小学还是高中，应用题翻来覆去就这四种结构：

| 结构 | 一句话描述 | 例子 |
|:----|:----------|:----|
| **加法结构** | 两个部分合起来 | 小明有 3 个苹果，小红有 5 个，一共有几个？ |
| **比较结构** | 两个量比大小 | 小明比小红多几个？ |
| **乘法结构** | 一份×份数=总数 | 每盘 3 个苹果，5 盘有几个？ |
| **比例结构** | 两个量的关系固定 | 3 个苹果 6 元，5 个苹果多少钱？ |

每个阶段的差异只是——**数据越来越复杂、关系越来越隐蔽**，但底层的逻辑没有变。

## 二、各年级应用题的演进

### 小学低段（1-2 年级）：图中找数

```
特征：有图有文字，一步计算，数字小
核心：看懂图的意思 → 找到"谁和谁" → 用加还是减

典型题：
  ┌─────────────────────┐
  │  🍎🍎🍎              │
  │  🍎🍎🍎🍎           │
  │  ─────              │
  │  左边有 3 个苹果     │
  │  右边有 4 个苹果     │
  │  一共有几个？        │
  └─────────────────────┘

解法：3 + 4 = 7
```

**常见问题：** 孩子不看图就列式，或者看漏了图里的信息。

**训练方法：** 做题前先问三个问题：
> 1. 题目里都说了什么？（复述）
> 2. 要我们求什么？（指着问题读一遍）
> 3. 用什么方法？（加还是减，为什么）

---

### 小学中段（3-4 年级）：两步应用题

```
特征：没有图了，纯文字，需要两步计算
核心：先求什么→再求什么

典型题：
  商店有 5 盒铅笔，每盒 6 支。卖了 8 支，还剩几支？

第一步：一共有几支？5 × 6 = 30（支）
第二步：还剩几支？30 - 8 = 22（支）
```

**分水岭：** 三年级开始，应用题从"一步"变成"两步"。很多孩子卡在"不知道先算什么"。

**胡小群建议：**
> 两步应用题的训练方法是"倒着想"：
> - 要求"还剩几支" → 需要知道"原来有几支"和"卖了几支"
> - "原来有几支"不知道 → 需要"每盒几支"×"几盒"
> - 两个条件都够了 → 列式

### 小学高段（5-6 年级）：分数应用题

```
特征：出现分数、百分数、比例
核心：找准"单位 1"

典型题：
  一袋大米吃了 3/5，还剩 12 千克，这袋大米原来有多少千克？

关键是：剩下的 12 千克对应总数的几分之几？
  吃了 3/5 → 剩下 2/5
  2/5 对应 12 千克 → 总重 = 12 ÷ 2/5 = 30 千克
```

**最大的坑：** 分不清"谁的几分之几"。

```
❌ 错误：一袋大米吃了 3/5，又吃了剩下的 1/3，共吃了多少？
   以为：3/5 + 1/3 = 14/15
   ✅ 正确：第一次吃 3/5，剩下 2/5；第二次吃 2/5 的 1/3 = 2/15
            共吃：3/5 + 2/15 = 11/15

   关键：第二个 1/3 的"单位 1"是"剩下的"，不是"总数"
```

---

### 初中七年级：方程应用题

```
特征：从"算术法"到"方程法"——设未知数
核心：找到等量关系

典型题：
  小明和小红共有 50 本书，小明比小红多 10 本，两人各有多少本？

算术法：小红 = (50 - 10) ÷ 2 = 20 本
        小明 = 20 + 10 = 30 本
  （直觉但不好推广）

方程法：设小红有 x 本，小明有 x+10 本
        x + (x+10) = 50
        2x + 10 = 50
        x = 20
       小红 20 本，小明 30 本
  （直接翻译题目）
```

**方程法的本质：** 把"中文"直接翻译成"数学"，不需要绕弯子。

**胡小群观点：**
> 方程不教"设→列→解"三步法——教"怎么把题目变成数学句子"。
>
> "小明比小红多 10 本" → 数学句子：小明 = 小红 + 10
> "共有 50 本" → 数学句子：小明 + 小红 = 50
>
> 把这两句话放在一起，方程就出来了。

#### 初中方程应用题 6 种常见模型

| 模型 | 核心关系 | 典型题 |
|:----|:--------|:------|
| 和差倍分 | $A+B = 总数$，$A = kB \pm m$ | 两人共多少，甲是乙的几倍多几 |
| 行程问题 | $路程 = 速度 \times 时间$ | 相遇、追及、顺逆水 |
| 工程问题 | $工作效率 \times 时间 = 工作量$ | 两人合作、先做后做 |
| 利润问题 | $售价 - 进价 = 利润$ | 打折、利润率 |
| 调配问题 | 调配后两边相等 | 甲给乙多少后两边一样 |
| 数字问题 | $十位\times10+个位 = 两位数$ | 数字的排列组合 |

### 初中八~九年级：函数应用题

```
特征：变量之间的关系，求最值
核心：建立函数关系式，确定定义域

典型题（二次函数最值）：
  某商品进价 40 元，售价 60 元时可卖 300 件。
  每涨价 1 元，少卖 10 件。定价多少时利润最大？

  设涨价 x 元：
    售价 = 60 + x
    销量 = 300 - 10x
    利润 = (售价-进价) × 销量 = (20+x)(300-10x)
         = -10x² + 100x + 6000
  当 x = 5 时利润最大（顶点），即售价 65 元
```

**难点：** 孩子需要找到"变量"，建立"关系式"——这不是计算问题，是建模问题。

---

### 高中：综合应用题

```
特征：知识融合——函数、数列、概率、几何结合
核心：读题→翻译→建模→求解→检验

典型题（数列应用题）：
  某公司 2024 年利润 1000 万，每年增长 10%。
  问：第几年利润首次超过 2000 万？

  解：a₁ = 1000，增长率 10% → 等比数列
      aₙ = 1000 × (1.1)^{n-1} > 2000
      (1.1)^{n-1} > 2
      (n-1)lg1.1 > lg2 → n-1 > 7.27
      n ≥ 9
      第 9 年（2032 年）利润首次超过 2000 万
```

**高中应用题和初中的区别：**
- 初中：一个知识点对应一个应用模型
- 高中：可能需要函数+数列+不等式的组合

## 三、读题四步法（适合所有年级）

胡小群的"读题方法论"：

```
第一步：读一遍（获取大意）
  → 这题在说什么事？（买苹果、修路、存钱、利润）

第二步：圈关键词
  → 数字、单位、关系词（比……多、是……的几分之几）
  → 注意：关键词信息要圈出来，画在题干上

第三步：翻译成数学语言
  → "小明有 x 本书" 写成 x
  → "比小红多 10 本" 写成 = 小红 + 10
  → 把中文句子变成数学表达式

第四步：检查条件是否用全
  → 题目给了几个条件？用上了几个？有没有多余的？
  → 答案符合实际情况吗？（比如人数不能是负数）
```

## 四、常见错误诊断

| 错误表现 | 真正原因 | 解决方案 |
|:--------|:--------|:--------|
| 该加的时候减了 | 题目没读懂——"多/少/一共"的关系判断错 | 用实物演示，建立"多=加"的直觉 |
| 分数应用题找错单位 1 | "的"前面的量没找准 | 训练："A 的几分之几"——单位 1 是 A |
| 方程设对了但等号列错 | 等量关系没找准——题目中的"="没发现 | 找"是/比/相当于/等于"这些词 |
| 行程问题不会做 | 三种情况的区分不熟练 | 背熟：#路程=速度×时间#，画图！ |
| 二次函数最值题不会建模型 | 找不到"利润=售价-进价"的关系 | 从简单的一步一步来，不跳步 |
| 高中应用题不知道怎么下手 | 信息量太大、不会选工具 | 用"这个题和哪个知识点有关"来引导 |

## 五、给家长的具体训练方法

### 1. 复述法（1-3 年级）

```
孩子读完题 → 不要让他马上做 → 问：
"这个题目说的是什么事？"
"要我们算什么？"
"你准备用什么方法？"
```

**目的：** 确保孩子读懂了再做，而不是蒙着做。

### 2. 画图法（3-6 年级）

```
任何应用题都画图：
  行程问题 → 线段图（甲从 A 出发、乙从 B 出发）
  分数问题 → 长方形分块（单位 1 切成几份）
  比较问题 → 条形对比（谁长谁短）
```

很多孩子到了初中还不会画图——这是小学就该培养的习惯。

### 3. 翻译法（5-9 年级）

```
把题目写成"数学句子"：

题目：小明买了 3 支笔，每支 2 元，给了 10 元，找回多少？
翻译：
  总价 = 3 × 2
  找回 = 10 - 总价
  找回 = 10 - 3 × 2
```

### 4. 检验法（所有年级）

```
问孩子：你这个答案合理吗？
  – 算出来人数是 2.5 个 → 肯定错了
  – 算出来速度是 1000 km/h → 那是飞机
  – 算出来利润是负数 → 是不是问题问错了？
```

## 六、应用题的核心能力清单

| 能力 | 什么时候练 | 怎么练 |
|:----|:----------|:------|
| 读题提取信息 | 1 年级起 | 读一遍→复述一遍 |
| 画图辅助理解 | 2 年级起 | 线段图、示意图、表格 |
| 找单位 1 | 5 年级起（分数） | "的"字前面的量 |
| 找等量关系 | 7 年级起（方程） | 找"是/等于/比…多/一共" |
| 建立函数模型 | 8 年级起（一次函数） | 确定变量→写关系式 |
| 综合建模 | 高中 | 多工具组合使用 |

## 七、一句话总结

> **应用题不是"数学题"，是"翻译题"。**
>
> 中文→数学式子 的翻译能力强，应用题自然就会做。
> 翻译能力怎么练？——多读题、多复述、多画图、多检验。
