## 💡 讲一讲

### 什么是小数

像 0.5、1.3、3.14 这样的数叫 **小数**。

```
 0 . 5
 ↑   ↑
整数部分  小数部分
    ↑
 小数点
```

**读法：** 0.5 读作"零点五"
**写法：** 一点三 → 1.3

---

### 小数和分数的关系

**十分之几就是零点几。**

```
1/10 = 0.1（十分之一 = 零点一）
3/10 = 0.3（十分之三 = 零点三）
7/10 = 0.7（十分之七 = 零点七）
```

**例：** 1 元 = 10 角
```
1 角 = 1/10 元 = 0.1 元
5 角 = 5/10 元 = 0.5 元
1 元 3 角 = 1.3 元
```

**例：** 1 米 = 10 分米
```
1 分米 = 1/10 米 = 0.1 米
3 分米 = 3/10 米 = 0.3 米
```

---

### 比较小数的大小

**先比较整数部分，整数部分大的就大；整数部分相同再比小数部分。**

**例：**
```
0.6 ○ 0.4
整数部分都是 0
看小数部分：6 > 4
所以 0.6 > 0.4 ✅
```

```
1.2 ○ 0.9
整数部分：1 > 0
所以 1.2 > 0.9 ✅
```

---

### 小数加减法

**规则：小数点对齐，按整数加减法计算。**

**例①：** 0.5 + 0.3 = ?

```
  0.5
+ 0.3
─────
  0.8
```

**例②：** 1.6 - 0.4 = ?

```
  1.6
- 0.4
─────
  1.2
```

**例③（生活中的小数）：**
> 一支铅笔 1.5 元，一块橡皮 0.8 元，一共多少钱？

```
  1.5
+ 0.8
─────
  2.3
```

一共 **2.3 元** ✅

| 规则 | 说明 |
|:---|:---|
| 🔢 **读写** | 整数部分按整数读，小数点读"点"，小数部分依次读数字 |

| 🔍 **比较** | 先比整数部分，再比小数部分 |

## 🧩 想一想

**🤔 0.5 和 0.50 一样大吗？**

> 一样大！0.5 是 5/10，0.50 是 50/100，大小相等。
> 小数末尾添上 0 或去掉 0，小数的大小不变。
> 但 0.5 和 0.05 就不同了：0.5 = 5/10，0.05 = 5/100。
