# ➕ 两、三位数的加法

> 第六单元：两、三位数的加法和减法

---

## 🎯 学什么

- ✅ 会用竖式计算 **两位数加两位数**（进位）
- ✅ 会用竖式计算 **三位数加三位数**（进位）
- ✅ 理解 **哪一位满十就向前一位进 1**
- ✅ 养成 **数位对齐** 的好习惯

---

## 💡 讲一讲

### 两位数加两位数（进位）

**例：** 46 + 37 = ?

**竖式：**
```
   4 6
+  3 7
──────
   8 3
```

**计算过程：**
1. 个位：6 + 7 = **13**，写 3 进 1
2. 十位：4 + 3 + 1（进位）= **8**
3. 结果是 **83**

> **个位满十，向十位进 1！**

### 三位数加三位数（一次进位）

**例：** 256 + 138 = ?

```
   2 5 6
+  1 3 8
────────
   3 9 4
```

1. 个位：6 + 8 = **14**，写 4 进 1
2. 十位：5 + 3 + 1 = **9**，写 9
3. 百位：2 + 1 = **3**，写 3
4. 结果是 **394**

### 三位数加三位数（两次进位）

**例：** 365 + 187 = ?

```
   3 6 5
+  1 8 7
────────
   5 5 2
```

1. 个位：5 + 7 = **12**，写 2 进 1
2. 十位：6 + 8 + 1 = **15**，写 5 进 1
3. 百位：3 + 1 + 1 = **5**，写 5
4. 结果是 **552**

### 连续进位

**例：** 473 + 529 = ?

```
   4 7 3
+  5 2 9
────────
  1 0 0 2
```

1. 个位：3 + 9 = **12**，写 2 进 1
2. 十位：7 + 2 + 1 = **10**，写 0 进 1
3. 百位：4 + 5 + 1 = **10**，写 0 进 1
4. 千位：进上来的是 **1**，写 1
5. 结果是 **1002**

### 竖式注意事项

```
   3 4 8         ✅ 数位对齐
+   2 6          ❌ 没有对齐！
```
> **相同数位要对齐！个位对个位，十位对十位，百位对百位。**

---

## 📝 记一记

| 规则 | 说明 |
|:---|:---|
| 📐 **数位对齐** | 个位对个位，十位对十位，百位对百位 |
| ➡️ **从个位算起** | 从个位开始，依次往高位计算 |
| 🔁 **满十进一** | 哪一位相加满十，就向前一位进 1 |
| ✏️ **标上进位** | 在小进位"1"记在横线上方，避免忘记 |
| ✅ **检查** | 估算或用减法验算 |

## 🎮 小游戏

### 🎯 进位大挑战

两人各掷两次骰子（或抽两张数字卡片），组成两位数，加在一起。谁的结果更大谁赢！

**例：** 抽到 4 和 7 → 47；抽到 5 和 3 → 53；47 + 53 = 100

比比看谁的加法又快又准！

## 🧩 想一想

**🤔 小马虎在计算 256 + 187 时，把 256 看成了 265，结果比正确结果多了几？**

> 265 - 256 = 9，多算了 9，所以结果也比正确结果多了 9。
>
> 正确结果：256 + 187 = **443**
> 错误结果：265 + 187 = **452**
> 452 - 443 = **9** ✅
