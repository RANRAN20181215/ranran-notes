# 数学公式速查手册

> 小初高核心公式一张表速查
> 适用：日常查阅、复习回顾

## 一、小学（1-6 年级）

### 四则运算

| 名称 | 公式 |
|:----|:----|
| 加法交换律 | $a + b = b + a$ |
| 加法结合律 | $(a + b) + c = a + (b + c)$ |
| 乘法交换律 | $a \times b = b \times a$ |
| 乘法结合律 | $(a \times b) \times c = a \times (b \times c)$ |
| 乘法分配律 | $a \times (b + c) = a \times b + a \times c$ |
| 减法的性质 | $a - b - c = a - (b + c)$ |
| 除法的性质 | $a \div b \div c = a \div (b \times c)$ |

### 几何

| 名称 | 公式 |
|:----|:----|
| 长方形周长 | $C = 2(a + b)$ |
| 正方形周长 | $C = 4a$ |
| 长方形面积 | $S = a \times b$ |
| 正方形面积 | $S = a^2$ |
| 三角形面积 | $S = \frac{1}{2}ah$ |
| 平行四边形面积 | $S = ah$ |
| 梯形面积 | $S = \frac{1}{2}(a+b)h$ |
| 圆周长 | $C = \pi d = 2\pi r$ |
| 圆面积 | $S = \pi r^2$ |
| 长方体体积 | $V = a \times b \times h$ |
| 正方体体积 | $V = a^3$ |
| 圆柱体积 | $V = \pi r^2 h$ |

## 二、初中（7-9 年级）

### 有理数

| 名称 | 公式 |
|:----|:----|
| 绝对值 | $\|a\| = \begin{cases} a, & a \geq 0 \\ -a, & a < 0 \end{cases}$ |
| 相反数 | $a$ 的相反数是 $-a$ |

### 幂的运算

| 名称 | 公式 |
|:----|:----|
| 同底数幂相乘 | $a^m \cdot a^n = a^{m+n}$ |
| 同底数幂相除 | $a^m \div a^n = a^{m-n}$ |
| 幂的乘方 | $(a^m)^n = a^{mn}$ |
| 积的乘方 | $(ab)^n = a^n b^n$ |
| 零次幂 | $a^0 = 1\ (a \neq 0)$ |

### 因式分解

| 公式 |
|:----|
| $a^2 - b^2 = (a+b)(a-b)$ |
| $a^2 \pm 2ab + b^2 = (a \pm b)^2$ |
| $x^2 + (a+b)x + ab = (x+a)(x+b)$ |

### 方程与不等式

| 名称 | 公式 |
|:----|:----|
| 一元二次方程 | $ax^2 + bx + c = 0$ |
| 求根公式 | $x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$ |
| 判别式 | $\Delta = b^2 - 4ac$ |
| 韦达定理 | $x_1 + x_2 = -\frac{b}{a}$，$x_1 x_2 = \frac{c}{a}$ |
| 不等号方向 | 两边乘除负数时方向反转 |

### 几何

| 名称 | 公式/定理 |
|:----|:---------|
| 勾股定理 | $a^2 + b^2 = c^2$（$c$ 为斜边） |
| 三角形内角和 | $A + B + C = 180°$ |
| 多边形内角和 | $(n-2) \times 180°$ |
| 相似比 | $\frac{h_1}{h_2} = \frac{l_1}{l_2} = k$ |
| 面积比 | $\frac{S_1}{S_2} = k^2$ |
| 圆周角定理 | 同弧所对圆周角 $=$ 圆心角的一半 |
| 垂径定理 | 过圆心垂直弦 $\Rightarrow$ 平分弦 |
| 切线判定 | 过半径外端且垂直半径 $\Rightarrow$ 切线 |
| 弧长 | $l = \frac{n\pi r}{180}$ |
| 扇形面积 | $S = \frac{n\pi r^2}{360} = \frac{1}{2}lr$ |

### 函数

| 名称 | 公式 |
|:----|:----|
| 一次函数 | $y = kx + b$ |
| 反比例函数 | $y = \frac{k}{x}$ |
| 二次函数一般式 | $y = ax^2 + bx + c$ |
| 二次函数顶点式 | $y = a(x-h)^2 + k$，顶点 $(h,k)$ |
| 二次函数交点式 | $y = a(x-x_1)(x-x_2)$ |
| 顶点坐标 | $h = -\frac{b}{2a}$，$k = \frac{4ac - b^2}{4a}$ |

### 三角函数（锐角）

| 名称 | 公式 |
|:----|:----|
| $\sin A$ | $\frac{\text{对边}}{\text{斜边}}$ |
| $\cos A$ | $\frac{\text{邻边}}{\text{斜边}}$ |
| $\tan A$ | $\frac{\text{对边}}{\text{邻边}}$ |
| 30° | $\sin=\frac{1}{2}$，$\cos=\frac{\sqrt{3}}{2}$，$\tan=\frac{\sqrt{3}}{3}$ |
| 45° | $\sin=\frac{\sqrt{2}}{2}$，$\cos=\frac{\sqrt{2}}{2}$，$\tan=1$ |
| 60° | $\sin=\frac{\sqrt{3}}{2}$，$\cos=\frac{1}{2}$，$\tan=\sqrt{3}$ |

## 三、高中（10-12 年级）

### 集合与逻辑

| 名称 | 公式 |
|:----|:----|
| 交集 | $A \cap B = \{x \mid x \in A \text{ 且 } x \in B\}$ |
| 并集 | $A \cup B = \{x \mid x \in A \text{ 或 } x \in B\}$ |
| 补集 | $\complement_U A = \{x \mid x \in U \text{ 且 } x \notin A\}$ |
| 德摩根律 | $\complement (A \cup B) = \complement A \cap \complement B$ |

### 不等式

| 名称 | 公式 |
|:----|:----|
| 基本不等式 | $a + b \geq 2\sqrt{ab}\ (a,b \geq 0)$ |
| 取等条件 | $a = b$ 时取等号 |

### 指数与对数

| 名称 | 公式 |
|:----|:----|
| 指数定义 | $a^n = a \times a \times ... \times a$（$n$ 个） |
| 分数指数 | $a^{\frac{m}{n}} = \sqrt[n]{a^m}$ |
| 负指数 | $a^{-n} = \frac{1}{a^n}$ |
| 对数定义 | $\log_a b = c \iff a^c = b$ |
| 积的对数 | $\log_a (MN) = \log_a M + \log_a N$ |
| 商的对数 | $\log_a \frac{M}{N} = \log_a M - \log_a N$ |
| 幂的对数 | $\log_a M^n = n\log_a M$ |
| 换底公式 | $\log_a b = \frac{\log_c b}{\log_c a}$ |

### 三角函数

| 名称 | 公式 |
|:----|:----|
| 基本关系 | $\sin^2 \theta + \cos^2 \theta = 1$ |
| 基本关系 | $\tan \theta = \frac{\sin \theta}{\cos \theta}$ |
| 诱导公式 | $\sin(-\theta) = -\sin\theta$，$\cos(-\theta) = \cos\theta$ |
| 诱导公式 | $\sin(\pi - \theta) = \sin\theta$，$\cos(\pi - \theta) = -\cos\theta$ |
| 和角公式 | $\sin(A+B) = \sin A\cos B + \cos A\sin B$ |
| 和角公式 | $\cos(A+B) = \cos A\cos B - \sin A\sin B$ |
| 周期 | $\sin x$ 和 $\cos x$ 周期 $2\pi$，$\tan x$ 周期 $\pi$ |

### 平面向量

| 名称 | 公式 |
|:----|:----|
| 坐标表示 | $a = (x, y)$ |
| 模长 | $\|a\| = \sqrt{x^2 + y^2}$ |
| 数量积 | $a \cdot b = |a||b|\cos\theta = x_1x_2 + y_1y_2$ |
| 平行 | $a \parallel b \iff x_1y_2 = x_2y_1$ |
| 垂直 | $a \perp b \iff a \cdot b = 0$ |

### 数列

| 名称 | 公式 |
|:----|:----|
| 等差数列通项 | $a_n = a_1 + (n-1)d$ |
| 等差数列求和 | $S_n = \frac{n(a_1 + a_n)}{2} = na_1 + \frac{n(n-1)}{2}d$ |
| 等比数列通项 | $a_n = a_1 q^{n-1}$ |
| 等比数列求和 | $S_n = \begin{cases} na_1, & q=1 \\ \frac{a_1(1-q^n)}{1-q}, & q \neq 1 \end{cases}$ |

### 导数

| 名称 | 公式 |
|:----|:----|
| 导数定义 | $f'(x) = \lim_{\Delta x \to 0} \frac{f(x+\Delta x) - f(x)}{\Delta x}$ |
| 幂函数 | $(x^n)' = nx^{n-1}$ |
| 正弦 | $(\sin x)' = \cos x$ |
| 余弦 | $(\cos x)' = -\sin x$ |
| 指数 | $(e^x)' = e^x$，$(a^x)' = a^x \ln a$ |
| 对数 | $(\ln x)' = \frac{1}{x}$，$(\log_a x)' = \frac{1}{x\ln a}$ |
| 和差法则 | $(u \pm v)' = u' \pm v'$ |
| 乘积法则 | $(uv)' = u'v + uv'$ |
| 链式法则 | $[f(g(x))]' = f'(g(x)) \cdot g'(x)$ |

### 解析几何

| 名称 | 公式 |
|:----|:----|
| 两点距离 | $d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$ |
| 椭圆标准 | $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$（$a > b > 0$） |
| 双曲线标准 | $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ |
| 抛物线标准 | $y^2 = 2px$ |
| 弦长公式 | $\|AB\| = \sqrt{1+k^2} \cdot \|x_1 - x_2\|$ |

### 立体几何

| 名称 | 公式 |
|:----|:----|
| 长方体体对角线 | $l = \sqrt{a^2 + b^2 + c^2}$ |
| 圆柱体积 | $V = \pi r^2 h$ |
| 圆锥体积 | $V = \frac{1}{3}\pi r^2 h$ |
| 球体积 | $V = \frac{4}{3}\pi r^3$ |
| 球表面积 | $S = 4\pi r^2$ |

### 概率统计

| 名称 | 公式 |
|:----|:----|
| 排列数 | $P(n,k) = \frac{n!}{(n-k)!}$ |
| 组合数 | $C(n,k) = \frac{n!}{k!(n-k)!}$ |
| 条件概率 | $P(A\|B) = \frac{P(A \cap B)}{P(B)}$ |
| 全概率公式 | $P(A) = \sum P(A\|B_i)P(B_i)$ |
| 二项分布 | $P(X=k) = C(n,k)p^k(1-p)^{n-k}$ |
