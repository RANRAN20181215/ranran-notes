# 📐 三角形、平行四边形和梯形

> 第七单元：三角形、平行四边形和梯形

---

## 🎯 学什么

- ✅ 认识三角形，掌握三角形的特征
- ✅ 按角分类：锐角三角形、直角三角形、钝角三角形
- ✅ 按边分类：等腰三角形、等边三角形
- ✅ 认识平行四边形和梯形

---

## 💡 讲一讲

### 三角形

**特征：3 条边、3 个角、3 个顶点**

```
     /\
    /  \
   /    \
  /______\
```

**三角形的高：** 从顶点到对边的垂直线段。

**底和高是一一对应的**，一个三角形有 3 条高。

---

### 三角形的分类（按角）

- 锐角三角形：3 个角都小于 90°
- 直角三角形：1 个角等于 90°
- 钝角三角形：1 个角大于 90°

```
锐角三角形    直角三角形    钝角三角形
   /\             |             /\
  /  \            |            /  \
 /____\           +____       /____\__
```

---

### 三角形的分类（按边）

- 等腰三角形：两条边相等
- 等边三角形：三条边都相等（也叫正三角形，每个角都是 60°）
- 不等边三角形：三条边都不相等

```
等腰三角形    等边三角形
   /\            /\
  /  \          /__\
 /____\
```

---

### 三角形的内角和

> **任意三角形的内角和都是 180°！**

**验证方法：**
把三个角撕下来拼在一起：
```
   ∠1
∠3   ∠2

拼成一个平角 = 180° ✅
```

**已知两个角求第三个：**
∠1 = 50°，∠2 = 60°，∠3 = ?
∠3 = 180° - 50° - 60° = **70°** ✅

---

### 三角形三边关系

> **三角形任意两边之和大于第三边。**

**判断：** 3cm、4cm、5cm 能围成三角形吗？
3 + 4 > 5 ✅　3 + 5 > 4 ✅　4 + 5 > 3 ✅
→ **能** ✅

**判断：** 2cm、3cm、5cm 能围成吗？
2 + 3 = 5 ❌（等于都不行）→ **不能** ❌

---

### 平行四边形

平行四边形：两组对边分别平行且相等

```
  +--------+
 /        /
+--------+
```

**特征：**
- 两组对边分别 **平行且相等**
- 两组对角分别相等
- 容易变形（不稳定性）

---

### 梯形

梯形：只有一组对边平行

```
  +------+
 /        \
+----------+
```

**特征：** 只有 **一组** 对边互相平行。

**各部分名称：**
- 上底：较短的平行边
- 下底：较长的平行边
- 腰：不平行的那两条边

**等腰梯形：** 两腰相等的梯形。

## 🧩 想一想

**🤔 为什么三角形具有稳定性，平行四边形容易变形？**

> 三角形三条边长度固定后，形状就被唯一确定了（三边定形）。
> 平行四边形的四条边长度固定后，形状还能变化——因为角度可以改变。
> 所以：**三角形稳定**（用于桥梁、房顶），**平行四边形易变形**（用于伸缩门）。
