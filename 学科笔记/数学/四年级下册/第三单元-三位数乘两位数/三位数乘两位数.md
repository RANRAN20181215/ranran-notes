## 💡 讲一讲

### 三位数乘两位数（一般情况）

**例：** 145 × 12 = ?

```
     1 4 5
×      1 2
──────────
     2 9 0    ← 145 × 2 = 290
   1 4 5 0    ← 145 × 10 = 1450
──────────
   1 7 4 0    ← 290 + 1450 = 1740
```

**答案：** 145 × 12 = **1740** ✅

---

### 乘数末尾有 0

**例：** 340 × 20 = ?

**简便算法：**
先算 34 × 2 = 68
再在末尾添两个 0 → **6800**

**竖式：**
```
     3 4 0
×       2 0
──────────
     6 8 0 0
```

> 把 0 前面的数相乘，再在后面加上所有 0 的个数。

---

### 乘数中间有 0

**例：** 206 × 34 = ?

```
     2 0 6
×       3 4
──────────
     8 2 4    ← 206 × 4 = 824
   6 1 8 0    ← 206 × 30 = 6180
──────────
   7 0 0 4    ← 824 + 6180 = 7004
```

> **注意：** 206 中间的 0 也要参与运算！

---

### 速度、时间、路程

**公式：**
```
速度 × 时间 = 路程
路程 ÷ 时间 = 速度
路程 ÷ 速度 = 时间
```

**例：** 一辆汽车每小时行 85 千米，12 小时行多少千米？

85 × 12 = **1020（千米）** ✅

---

### 常见的数量关系

**单价 × 数量 = 总价**

**例：** 每台电脑 3800 元，买 15 台需要多少钱？

3800 × 15 = **57000（元）** ✅

## 📝 记一记

| 规则 | 说明 |
|:---|:---|
| ➊ **从个位乘起** | 用第二个乘数的个位、十位依次乘 |
| ➋ **两次积相加** | 不要忘记加 |
| ➌ **末尾有 0** | 先乘 0 前面的数，再加 0 |
| ➍ **速度公式** | 速度 × 时间 = 路程 |
| ➎ **总价公式** | 单价 × 数量 = 总价 |

## 🧩 想一想

**🤔 怎样判断三位数乘两位数的积是几位数？**

> 用最小和最大情况判断：
> - 100 × 10 = 1000（四位数）
> - 999 × 99 ≈ 1000 × 100 = 100000（五位数）
> 所以三位数乘两位数的积可能是 **四位数或五位数**。
> 具体判断：看 百位 × 十位 是否进位。
