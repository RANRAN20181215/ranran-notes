# 🔢 认识多位数

> 第二单元：认识多位数

---

## 🎯 学什么

- ✅ 认识 **万级** 和 **亿级** 的计数单位
- ✅ 会读写多位数
- ✅ 掌握多位数的大小比较
- ✅ 会把多位数改写成 **万** 或 **亿** 作单位
- ✅ 会求 **近似数**

---

## 💡 讲一讲

### 数位顺序表

| 亿级 | 万级 | 个级 |
|:---:|:---:|:---:|
| 千亿 百亿 十亿 亿 | 千万 百万 十万 万 | 千 百 十 个 |

**每相邻两个计数单位之间的进率是 10。**

---

### 读多位数

**例：** 读 3842005

**方法：** 先分级，从高位读起

```
384│2005
万级  个级

读作：三百八十四万二千零五
```

**读写规则：**
1. 从高位读起
2. 亿级和万级按个级读法读，再加"亿"或"万"
3. 每级中间有 0 读一个"零"
4. 每级末尾的 0 不读

---

### 写多位数

**例：** 五千万零三百

```
五千万 → 5000 万位
零 → 0
三百 → 300

写作：5000 0300
```

---

### 大小比较

**规则：**
1. 位数不同 → 位数多的数大
2. 位数相同 → 从高位比起

**例：**
- 9999 ○ 10000（9999 < 10000，位数少）
- 38420 ○ 38510（从高位比，百位 4 < 5，38420 < 38510）

---

### 改写

**改写成"万"作单位：**
3842000 = **384 万**（去掉末尾 4 个 0 加"万"字）

**改写成"亿"作单位：**
3840000000 = **38 亿**（去掉末尾 8 个 0 加"亿"字）

---

### 近似数

**四舍五入法：**
- 看要保留的位数后面一位
- ≥ 5 就进一，< 5 就舍去

**例：** 38456 ≈ 万（保留到万位）

看千位：8 ≥ 5 → 进一
38456 ≈ **4 万**

## 🧩 想一想

**🤔 为什么每级末尾的 0 不读？**

> 比如 3800 读作"三千八百"，不读"三千八百零零"。
> 末尾的 0 不影响这个数的大小，所以不读。
> 但中间的 0 要读，比如 3008 读作"三千零八"——不读"三千八"就错了！
