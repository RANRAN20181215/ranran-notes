## 💡 讲一讲

### 什么是数对

**数对**是用两个数来确定位置的表示方法。

```
(列, 行)

例：(3, 2) → 第 3 列第 2 行
```

**规则：** 先写 **列**（竖着的），再写 **行**（横着的），中间用逗号隔开，两边加括号。

---

### 用数对标位置

```
行
5 +  |  |  |  |  |  |
4 +  |  |  |  |  |  |
3 +  |  |  |* |  |  |    * = (3,3)
2 +  |  |  |  |  |  |
1 +  |  |  |  |  |  |
   +--+--+--+--+--+--
     1  2  3  4  5  列
```

用方格图表示位置：第 1 列第 1 行用 (1,1) 表示。★ 在第 3 列第 3 行，用 (3,3) 表示。

★ 的位置是 **(3, 3)** ✅

> **注意：** (3, 3) 表示第 3 列第 3 行。
> 先数竖着的列，再数横着的行。

---

### 数对的变换

**向右平移：** 列数增加，行数不变
```
(2, 3) → 右移 2 格 → (4, 3)
```

**向左平移：** 列数减少，行数不变
```
(2, 3) → 左移 1 格 → (1, 3)
```

**向上平移：** 行数增加，列数不变
```
(2, 3) → 上移 2 格 → (2, 5)
```

**向下平移：** 行数减少，列数不变
```
(2, 3) → 下移 1 格 → (2, 2)
```

| 📌 **数对** | (列，行) |
| 🔢 **列** | 竖着的，从左往右数 |

## 🧩 想一想

**🤔 数对 (a, b) 和 (b, a) 表示的是同一个位置吗？**

> **不一定！**
> (3, 5) 是第 3 列第 5 行
> (5, 3) 是第 5 列第 3 行
> 这是两个不同的位置！
> **数对中两个数的顺序很重要！**
