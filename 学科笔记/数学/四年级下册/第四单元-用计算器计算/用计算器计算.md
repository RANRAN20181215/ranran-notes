## 💡 讲一讲

### 认识计算器

```
┌─────────────┐
│  计算器      │
│ ┌─────────┐ │
│ │   0.    │ │ ← 显示屏
│ └─────────┘ │
│             │
│  ON/AC  CE  │
│  ÷  ×  -  + │
│  7  8  9    │
│  4  5  6    │
│  1  2  3    │
│  0    .  =  │
└─────────────┘
```

**常用按键：**
- **ON/AC**：开机/全部清除
- **CE**：清除当前输入
- **+、-、×、÷**：运算键
- **=**：得到结果
- **.**：小数点

---

### 用计算器计算

**例：** 计算 456 + 789 = ?

```
按 456 → 按 + → 按 789 → 按 =
→ 显示：1245 ✅
```

**例：** 计算 320 × 15 = ?

```
按 320 → 按 × → 按 15 → 按 =
→ 显示：4800 ✅
```

---

### 用计算器探索规律

**例：** 用计算器算一算

```
1 × 1 = 1
11 × 11 = 121
111 × 111 = 12321
1111 × 1111 = 1234321
11111 × 11111 = 123454321
```

**规律：** 两个由 1 组成的数相乘，积是回文数（正着读反着读一样），中间数字就是位数。

---

### 什么时候用计算器

**适合用计算器：**
- 大数计算（如 12345 × 67890）
- 探索数学规律
- 验证计算结果

**不适合用计算器：**
- 简单的口算（如 25 × 4）
- 考试的时候（除非允许）
- 需要展示计算过程的题目

## 🧩 想一想

**🤔 有了计算器，是不是就不用学计算了？**

> 不是！计算器只是工具。
> - 计算器不会帮你 **理解算理**（为什么这样算）
> - 小数目口算比计算器更快
> - 考试时不能全靠计算器
> - **会算理 + 用工具 = 计算高手**
