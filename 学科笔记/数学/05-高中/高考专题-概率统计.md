# 高考专题：概率统计

> 高考分值约 18-22 分，**全卷阅读量最大的模块**。贴近实际应用，难度中等，但"读懂题"往往是最大的门槛。

## 一、高考考纲定位

| 维度 | 内容 |
|:-----|:------|
| 分值占比 | 约 12-15%（约 18-22 分） |
| 常见题型 | 选择 1 道 + 填空 1 道 + 解答 1 道 |
| 解答题位置 | 常在第 19/20 题（中档位置） |

## 二、知识体系

```
统计 ──┬── 数据获取 ──┬── 简单随机抽样
        │              ├── 分层抽样
        │              └── 系统抽样
        ├── 数据描述 ──┬── 频率分布直方图（频率 = 面积 / 组距）
        │              ├── 茎叶图
        │              └── 数字特征 ──┬── 集中趋势：平均数、中位数、众数
        │                             └── 离散程度：极差、方差、标准差
        └── 数据推断 ──┬── 回归分析 ──┬── 线性回归（最小二乘法）
                       │              └── 相关系数 r
                       └── 独立性检验（列联表 + χ² 统计量）

概率 ──┬── 计数原理 ──┬── 分类加法计数（"或"的关系：做一件事有不同类方法）
        │              ├── 分步乘法计数（"且"的关系：做一件事分几步）
        │              ├── 排列 P(n,m) = n!/(n-m)!（顺序重要）
        │              └── 组合 C(n,m) = n!/(m!(n-m)!)（顺序不重要）
        ├── 随机事件 ──┬── 古典概型 P(A) = |A|/|Ω|
        │              ├── 几何概型（长度/面积/体积比）
        │              ├── 互斥事件 P(A∪B) = P(A) + P(B)
        │              └── 独立事件 P(AB) = P(A)P(B)
        ├── 随机变量 ──┬── 分布列（列表格：取值 → 概率）
        │              ├── 期望 E(X) = Σxi·pi（加权平均）
        │              ├── 方差 D(X) = E(X²) - [E(X)]²（波动大小）
        │              ├── 二项分布 X ~ B(n,p)
        │              ├── 超几何分布 X ~ H(N,M,n)
        │              └── 正态分布 N(μ, σ²)
        └── 条件概率 ──┬── P(B|A) = P(AB)/P(A)
                       └── 全概率公式 P(B) = ΣP(Ai)P(B|Ai)
```

## 三、核心概念深度拆解

### 3.1 排列组合——计数原理的灵魂

> 排列组合不是独立的考点，而是**概率计算的底层工具**。几乎所有古典概型题都在测试"数得清数"的能力。

**两个基本原理：**

| 原理 | 口诀 | 判断标准 |
|:-----|:-----|:---------|
| 分类加法 | "要么...要么..." | 完成一件事有**不同类**的方法，每类各自独立 |
| 分步乘法 | "先...再...然后..." | 完成一件事需要**分步骤**，缺一不可 |

**排列 vs 组合：**

- **排列**（Permutation）：顺序重要。选出来之后还要排顺序。
  - P(n,m) = n!/(n-m)!，相当于"从 n 个里选 m 个，再把这 m 个排好"
  - 实例：从 5 人中选 3 人分别担任班长、学委、体委——顺序重要

- **组合**（Combination）：顺序不重要。选出来就行了。
  - C(n,m) = n!/(m!(n-m)!)，相当于"从 n 个里选 m 个"
  - 实例：从 5 人中选 3 人参加比赛——顺序不重要

**六种常用技巧：**

| 方法 | 适用场景 | 操作 |
|:-----|:---------|:-----|
| 捆绑法 | 某些元素必须相邻 | 把相邻元素绑成一个整体参与排列 |
| 插空法 | 某些元素不能相邻 | 先排其他元素，再把不相邻元素插入空隙 |
| 除序法 | 有相同元素 | 总数除以相同元素的全排列数 |
| 间接法 | 正面讨论太复杂 | 总数 - 反面情况数 |
| 先选后排 | 先分组再分配 | 先 C 后 P，注意重复分组要除序 |
| 定位优先 | 某个元素有特殊位置 | 先安排特殊元素/位置 |

> 孩子最常犯的错：**分不清"类"和"步"**。要么多算了（重复计数），要么少算了（遗漏情况）。建议多练"把题目翻译成分步流程"。

### 3.2 补充：二项式定理——排列组合的经典应用

**二项式定理公式：**
(a+b)^n = C(n,0)a^n + C(n,1)a^(n-1)b + C(n,2)a^(n-2)b² + ... + C(n,n)b^n = ΣC(n,k)a^(n-k)b^k

**核心概念：**
1. **通项公式**：T(k+1) = C(n,k)a^(n-k)b^k（第 k+1 项）
2. **二项式系数**：C(n,0), C(n,1), ..., C(n,n)
3. **系数和**：二项式系数之和 = 2^n（令 a=b=1）
4. **奇数项系数和 = 偶数项系数和** = 2^(n-1)

**高考常考题型：**

| 题型 | 解法 | 难度 |
|:----|:-----|:----:|
| 求特定项系数 | 用通项公式，令 x 的指数为特定值 | ★★ |
| 求有理项 | 通项中 x 的指数为整数 | ★★★ |
| 求常数项 | 通项中 x 的指数为 0 | ★★ |
| 赋值法求系数和 | 令 x = 1 / x = -1 | ★★ |
| 最大系数/最大项 | 比较相邻项系数大小 | ★★★ |

**易错点：**
- 通项中 C(n,k) 对应的是第 k+1 项，不是第 k 项
- 二项式系数 vs 项的系数：二项式系数就是 C(n,k)，项的系数还要考虑系数部分
- 赋值法：不要只记住令 x=1，要理解"赋值的目的是消去变量"

### 3.3 古典概型——最基本的概率模型

> P(A) = 事件 A 包含的基本事件数 / 总基本事件数

**核心要求：不重不漏地数清楚基本事件。**

解题三步走：
1. 明确总基本事件数 —— 用排列组合或列举法
2. 明确所求事件包含的基本事件数
3. 两者相比即得概率

**两种计数方式：**
- **列举法**：适用于基本事件数很少（不超过 20 个），直接列表或用树形图
- **公式法**：基本事件数多时，用排列组合计数

> 新高考趋势：古典概型正在和实际情境深度绑定（如核酸检测混检方案、疫苗有效率评估），不再只是"摸球""掷骰子"。

### 3.4 条件概率与全概率公式

> **条件概率的本质：在已知部分信息的条件下，重新计算概率。** 相当于"缩小了样本空间"。

**条件概率公式：** P(B|A) = P(AB) / P(A)

通俗理解：已知 A 发生了，那么 B 发生的概率就是"A 和 B 同时发生的概率"除以"A 发生的概率"。

**全概率公式：**
P(B) = P(A₁)P(B|A₁) + P(A₂)P(B|A₂) + ... + P(Aₙ)P(B|Aₙ)

通俗理解：B 的发生有多个"可能原因"A₁, A₂, ..., Aₙ，把每个原因下 B 发生的概率加起来。

**使用场景：**
- 条件概率：已知结果推条件，或已知一部分信息
- 全概率：需要"分情况讨论"的概率问题
- 贝叶斯公式（了解即可）：已知结果反推原因的概率

> 注意全概率公式要求{Ai}是**完备事件组**——它们互斥且覆盖所有可能性。常见错误：事件组有遗漏。

### 3.5 随机变量的数字特征

| 概念 | 公式 | 意义 |
|:-----|:-----|:-----|
| 期望 E(X) | Σxi·pi | 加权平均，反映"平均水平" |
| 方差 D(X) | Σ(xi - E(X))²·pi = E(X²) - [E(X)]² | 反映"波动大小"，方差越大越分散 |
| 标准差 σ(X) | √D(X) | 方差开方，单位与 X 相同 |

**期望和方差的性质（极其重要）：**

| 性质 | 期望 | 方差 |
|:----|:-----|:-----|
| 线性变换 | E(aX + b) = aE(X) + b | D(aX + b) = a²D(X) |
| 加法（不要求独立） | E(X + Y) = E(X) + E(Y) | — |
| 加法（要求独立） | E(X + Y) = E(X) + E(Y) | D(X + Y) = D(X) + D(Y) |

> 期望的可加性**不要求独立**，这是很多难题的突破口。方差的可加性要求独立。

**核心计算技巧：**

方差计算优先用 D(X) = E(X²) - [E(X)]²，而非定义式。先算 E(X²)（把 x² 作为新变量求期望），再减掉 E(X) 的平方。

### 3.6 三大分布

#### 二项分布 X ~ B(n, p)

> n 次独立重复试验，每次成功概率为 p，求成功 k 次的概率。

公式：P(X = k) = C(n, k) · p^k · (1-p)^(n-k)

数字特征：E(X) = np, D(X) = np(1-p)

**判断标准：**
- ✅ 每次试验独立
- ✅ 每次成功概率相同
- ✅ n 次试验次数固定

**常见场景：** 射击命中、产品合格率、种子发芽、独立重复抽样

#### 超几何分布 X ~ H(N, M, n)

> 一批产品共 N 个，其中 M 个次品。不放回抽取 n 个，求抽到 k 个次品的概率。

公式：P(X = k) = C(M, k) · C(N-M, n-k) / C(N, n)

数字特征：E(X) = n · M/N

**判断标准：**
- ✅ 不放回抽样
- ✅ 总体有限，已知"次品"总数

> 当 N 很大时（n/N ≤ 0.1），超几何分布 ≈ 二项分布（不放回近似为有放回）。

#### 正态分布 N(μ, σ²)

> 钟形曲线，关于 x = μ 对称，σ 决定"胖瘦"。

**3σ 原则（必背）：**

| 区间 | 概率 | 意义 |
|:----|:-----|:-----|
| (μ - σ, μ + σ) | 68.3% | 约 2/3 的数据在这个范围内 |
| (μ - 2σ, μ + 2σ) | 95.4% | 约 95% 的数据 |
| (μ - 3σ, μ + 3σ) | 99.7% | 几乎所有数据 |

**解题关键：**
- 对称性：P(X ≤ μ - a) = P(X ≥ μ + a)
- 转化：任何正态分布可标准化为 Z = (X - μ)/σ ~ N(0, 1)
- 概率计算：利用 3σ 原则和对称性进行加减

### 3.7 回归分析与独立性检验

#### 线性回归

> 核心思想：找到一条直线 ŷ = bx + a，使得所有点到直线的垂直距离的平方和最小。

回归系数公式：
- b = [Σ(xi - x̄)(yi - ȳ)] / [Σ(xi - x̄)²] = [Σxiyi - n·x̄·ȳ] / [Σxi² - n·x̄²]
- a = ȳ - b·x̄

> 回归直线**必过均值点** (x̄, ȳ)。这条性质经常被用来列方程求参数。

**相关系数 r：**

r = [Σ(xi - x̄)(yi - ȳ)] / √[Σ(xi - x̄)² · Σ(yi - ȳ)²]

- |r| ≤ 1
- |r| 越接近 1，线性相关越强
- r > 0 正相关，r < 0 负相关
- |r| > 0.75 强相关，|r| < 0.25 弱相关

#### 独立性检验

> 判断两个分类变量是否有关。

步骤：
1. 列出 2×2 列联表
2. 计算 χ² 统计量：χ² = n(ad - bc)² / [(a+b)(c+d)(a+c)(b+d)]
3. 查临界值表判定

> χ² 越大，越有把握说"两个变量有关"。临界值：3.841（95% 把握）、6.635（99% 把握）。

**常见陷阱：** 独立性检验只能说"有多大的把握认为有关"，不一定是因果关系。

### 题型 1：排列组合计数

**解题步骤：**
1. 判断是"分类"还是"分步"——"或"用加法，"且"用乘法
2. 判断是"排列"还是"组合"——顺序重要用排列，不重要用组合
3. 特殊元素优先处理
4. 相邻用捆绑，不相邻用插空

**示例：** 3 男 2 女排成一排，要求女生不相邻，有多少种排法？
- 先排 3 个男生：P(3,3) = 6
- 3 个男生产生 4 个空位（含两端），选 2 个放女生：P(4,2) = 12
- 总数：6 × 12 = 72

**坑：** 插空时容易忘记两端也可以放。建议画图确认空位数量。

---

### 题型 2：古典概型

**解题步骤：**
1. 确定总的基本事件数（列表或公式）
2. 确定所求事件包含的基本事件数
3. P = 所求 / 总

**示例：** 从 1, 2, 3, 4, 5 中任取 3 个不同的数，求取出的 3 个数中最大数为 4 的概率。
- 总事件：C(5,3) = 10
- 所求事件：最大数是 4，则从 1, 2, 3 中选 2 个 → C(3,2) = 3
- P = 3/10

**坑：** 注意"任取"是"一次取多个"还是"逐个取不放回"。前者用组合，后者分情况。

---

### 题型 3：条件概率

**解题步骤：**
1. 确定已知条件 A
2. 缩小样本空间到 A 包含的基本事件
3. 在缩小的空间里计算 P(B|A) = n(AB) / n(A)

**示例：** 某工厂产品合格率为 0.9，合格品中一等品率为 0.8。求任取一件产品是一等品的概率。
- P(合格) = 0.9，P(一等|合格) = 0.8
- P(一等) = P(一等且合格) = P(合格) × P(一等|合格) = 0.9 × 0.8 = 0.72

**坑：** 条件概率中 P(AB) 算错。先确认 A 和 B 的交集究竟是什么。

---

### 题型 4：分布列 + 期望

**解题步骤：**
1. 确定随机变量 X 的所有可能取值
2. 逐个计算每个取值的概率（利用排列组合或已知分布）
3. 列出分布列表格
4. 套公式 E(X) = Σxi·pi
5. 方差可求可不求（看题目要求）

**示例：** 一个箱子有 2 个红球 3 个白球，不放回取 2 次，X 为红球个数，求分布列和期望。
- X = 0：全白，P = C(3,2)/C(5,2) = 3/10
- X = 1：一红一白，P = C(2,1)C(3,1)/C(5,2) = 6/10
- X = 2：全红，P = C(2,2)/C(5,2) = 1/10
- E(X) = 0×0.3 + 1×0.6 + 2×0.1 = 0.8

**坑：** 概率之和必须为 1。如果算出来不是 1，一定有遗漏或重复。

---

### 题型 5：二项分布

**解题步骤：**
1. 确认是独立重复试验
2. 确定 n 和 p
3. P(X = k) = C(n,k)·p^k·(1-p)^(n-k)
4. 期望方差直接用公式

**示例：** 射击命中率为 0.6，独立射击 4 次，求恰好命中 2 次的概率。
- n = 4, p = 0.6, k = 2
- P = C(4,2) × 0.6² × 0.4² = 6 × 0.36 × 0.16 = 0.3456

**坑：** 注意"恰好 k 次"和"至少 k 次"的区别。至少 k 次要累加求和。

---

### 题型 6：超几何分布

**解题步骤：**
1. 确认是不放回抽样
2. 确定 N（总数）、M（目标数）、n（抽取数）
3. P(X = k) = C(M,k)·C(N-M,n-k)/C(N,n)

**示例：** 20 件产品中 5 件次品，不放回取 6 件，求恰有 1 件次品的概率。
- N = 20, M = 5, n = 6, k = 1
- P = C(5,1)·C(15,5)/C(20,6)

**坑：** 区分二项分布和超几何分布：有放回/独立 → 二项；不放回 → 超几何。如果只说"抽取"没提放回不放回，默认不放回（超几何）。

---

### 题型 7：正态分布

**解题步骤：**
1. 确定 μ 和 σ
2. 利用 3σ 原则和对称性
3. 所求概率转化为标准区间

**示例：** X ~ N(2, 9)，求 P(2 < X < 5)。
- μ = 2, σ = 3
- 2 到 5 是 μ 到 μ + σ
- P(μ < X < μ + σ) = P(μ - σ < X < μ + σ)/2 = 0.683/2 = 0.3415

**坑：** 对称性容易用错——关于 μ 对称，不是关于 0。同时注意 N(μ, σ²) 中第二个参数是**方差**（σ²），不是标准差。

---

### 题型 8：频率分布直方图

**解题步骤：**
1. 确认纵轴是"频率/组距"
2. 每组频率 = 纵轴高度 × 组距
3. 各组频率之和 = 1
4. 平均数估计：每组取中点 × 该组频率，再求和

**坑：** 很多孩子把纵轴直接当频率读。注意纵轴是"频率/组距"不是"频率"。

---

### 题型 9：线性回归

**解题步骤：**
1. 计算 x̄, ȳ
2. 套公式求 b
3. 代入均值点求 a
4. 写出回归方程 ŷ = bx + a
5. 代入 x 预测 y

**坑：** 回归直线必须过 (x̄, ȳ)，但**不一定过原点**。另外注意预测值 ŷ 不是实际值，是估计值。

---

### 题型 10：独立性检验

**解题步骤：**
1. 整理 2×2 列联表
2. 计算 χ² = n(ad - bc)² / [(a+b)(c+d)(a+c)(b+d)]
3. 与临界值比较
4. 下结论：是否"有把握认为有关"

**坑：** χ² 公式中分母的四个因式不要漏。孩子经常只算了部分分母。

---

### 题型 11：概率 + 实际情境

**解题步骤：**
1. 通读题目，画出关键数据
2. 确定概率模型（二项/超几何/条件概率？）
3. 建立随机变量
4. 按模型计算

**示例（新高考典型）：** 某市进行核酸检测，采用 10 人混检。假设感染率为 0.001。
求一个混检管中至少 1 例阳性的概率。
- 每管 10 人，每人独立
- P(至少 1 阳性) = 1 - P(都阴性) = 1 - (1 - 0.001)^10 = 1 - 0.999^10 ≈ 0.00996

**坑：** 实际情境题最大的障碍是"读不懂"——孩子需要练习把"一大段文字"翻译成"数学表达式"。

## 五、必背公式速查

### 计数原理

| 公式 | 表达式 |
|:-----|:-------|
| 排列数 | P(n,m) = n!/(n-m)! |
| 组合数 | C(n,m) = n!/(m!(n-m)!) |
| 组合性质 1 | C(n,m) = C(n,n-m) |
| 组合性质 2 | C(n,m) + C(n,m-1) = C(n+1,m) |
| 二项式定理 | (a+b)^n = Σ_{k=0}^{n} C(n,k) a^(n-k) b^k |

### 概率分布

| 分布 | 公式 | 期望 | 方差 |
|:-----|:-----|:-----|:-----|
| 二项分布 B(n,p) | P=C(n,k)p^k(1-p)^(n-k) | np | np(1-p) |
| 超几何分布 H(N,M,n) | P=C(M,k)C(N-M,n-k)/C(N,n) | n·M/N | — |
| 0-1 分布 | P(X=1)=p, P(X=0)=1-p | p | p(1-p) |

### 统计公式

| 内容 | 公式 |
|:-----|:-----|
| 样本平均数 | x̄ = (1/n)Σxi |
| 样本方差 | s² = (1/(n-1))Σ(xi - x̄)² |
| 回归系数 b | b = [Σ(xi-x̄)(yi-ȳ)] / [Σ(xi-x̄)²] |
| 回归系数 a | a = ȳ - b·x̄ |
| 相关系数 r | r = [Σ(xi-x̄)(yi-ȳ)] / √[Σ(xi-x̄)²·Σ(yi-ȳ)²] |
| χ² 统计量 | χ² = n(ad-bc)²/[(a+b)(c+d)(a+c)(b+d)] |

## 六、易错点速查

| 易错点 | 正解 | 常见错误 |
|:-------|:-----|:---------|
| 排列 vs 组合 | 顺序重要用排列，不重要用组合 | 分不清，该用 P 的时候用 C，反之亦然 |
| 二项 vs 超几何 | 有放回/独立→二项；不放回→超几何 | 混淆两个分布，用错公式 |
| 条件概率的 P(B\|A) | 分子是 P(AB)，分母是 P(A) | 分子直接用了 P(B) |
| 方差公式的选择 | D(X) = E(X²) - [E(X)]² 更方便 | 只用定义式 Σ(xi-μ)²pi，计算量大 |
| 互斥 vs 独立 | 互斥：不能同时发生；独立：互不影响 | 混为一谈，互斥事件在独立事件中出错 |
| 回归方程过 (x̄, ȳ) | 必过均值点 | 直接用原始数据，不过均值点 |
| 全概率的完备事件组 | 事件组必须覆盖所有可能且互斥 | 事件组有遗漏，导致概率和不为 1 |
| 正态分布对称轴 | 关于 x = μ 对称 | 默认关于 0 对称，忽略 μ 的值 |
| 频率直方图纵轴 | 纵轴是"频率/组距"，不是频率 | 直接把纵轴值当频率用 |
| 独立性检验结论 | "有 95% 的把握认为有关" | 说成"有 95% 的概率相关" |
| 不放回抽样 | 用超几何分布或用排列数 | 用了二项分布（那是放回） |

## 七、跨专题关联

**概率 + 计数原理（排列组合）：**
计数是概率计算的底层工具。几乎所有古典概型题都需要用排列组合数清楚"基本事件的数量"和"所求事件的数量"。

**统计 + 函数：**
回归分析本质上是在"寻找最佳拟合函数"。线性回归是拟合直线，也可以推广到非线性回归（如指数型、对数型）。

**概率 + 数列：**
n 次独立重复试验中的递推关系——类似"传球问题""爬楼梯问题"，背后是一阶线性递推数列。

**概率 + 算法思想：**
- 全概率公式 = 分情况讨论（分类讨论）
- 条件概率 = 缩小问题范围（"已有信息"的处理）
- 期望 = 加权平均（决策优化的核心概念）
- χ² 检验 = 假设检验的雏形（"先假设无关，看矛盾有多大"）

## 八、给家长的提醒

> **概率统计是高考中"最不像数学"的数学题**——阅读量大、情境新、套路少。

**几条实用建议：**

- **排列组合的关键不是背公式，是练分类讨论。** 建议每天练 1-2 道排列组合小题，重点练"分得清类和步"，而不是追求难题。

- **新高考趋势：概率统计题越来越实际。** 新冠检测方案、工厂质检方案、产品抽检、保险理赔、游戏规则——建议让孩子多接触这些真实场景的题目。

- **统计推断比概率计算更重要。** 旧高考偏重"算概率"，新高考偏重"分析数据、下结论"。独立性检验的结论表述、回归分析的意义解释，都是得分点也是失分点。

- **最实用的练习：** 让孩子多做"给出一段实际情境，自己列出所有可能情况并建模"的练习。概率统计的难点从来不是公式，而是"题目到底在说什么"。

- **警惕"粗心"的假象。** 概率统计做错，很多家长归结为"粗心没看清题"。其实往往是"分类讨论的能力不足"——建议让孩子把"分类过程"完整写出来，不要跳步。

- **公式记忆：** 建议把本节"必背公式速查"打印出来贴在书桌前。二项分布和超几何分布的期望公式经常在选填中直接使用，能节省大量时间。
