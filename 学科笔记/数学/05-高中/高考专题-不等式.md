# 高考专题分析：不等式

---

## 一、高考考纲定位

> 不等式本身是"小题"——单独命题约 5-8 分（约占 5%），但它是**贯穿整个高中数学的"工具模块"**，几乎所有大题都离不开它。

| 维度 | 说明 |
|:----|:-----|
| 单独命题 | 通常 1 道选择/填空：线性规划或基本不等式（5 分） |
| 作为工具 | **函数**定义域/值域、**导数**单调性讨论、**数列**放缩求和、**解析几何**最值范围 |
| 难度跨度 | ★★（基本不等式）→ ★★★★★（放缩法证明，压轴题最后一问） |
| 命题趋势 | 新高考弱化单独考不等式，强化在导数、数列中的工具性应用 |

> 一句话：不等式不值得大块时间单独刷题，但**每个模块都要带着练**。

## 二、知识体系

```
不等式
├── 性质（传递性 / 可加性 / 可乘性 / 倒数 / 乘方）

├── 解法
│   ├── 一元一次不等式
│   ├── 一元二次不等式（三位一体：函数↔方程↔不等式）
│   ├── 分式不等式（移项通分→化乘积）
│   ├── 绝对值不等式（零点分段法）
│   └── 高次不等式（穿根法：奇穿偶不穿）

├── 基本不等式
│   ├── 二元均值不等式：√(ab) ≤ (a+b)/2
│   ├── 三元均值不等式：³√(abc) ≤ (a+b+c)/3
│   └── 柯西不等式（拓展）

├── 线性规划
│   ├── 二元一次不等式组 → 可行域
│   └── 目标函数最值（截距型 / 斜率型 / 距离型）

└── 综合应用
    ├── 恒成立问题（分离参数法 / 函数最值法）
    ├── 能成立问题（存在性）
    └── 不等式证明（比较法 / 综合法 / 放缩法 / 构造函数法）
```

## 三、核心概念深度拆解

### 3.1 不等式性质——不要想当然

> 性质使用中最常见的错误：**两边乘以一个不知道正负的数**

| 性质 | 公式 | 注意 |
|:----|:----|:-----|
| 传递性 | a > b, b > c ⇒ a > c | 链式传递 |
| 可加性 | a > b ⇒ a + c > b + c | 任何 c 都成立 |
| 可乘性 | a > b, c > 0 ⇒ ac > bc；c < 0 ⇒ ac < bc | **c 的符号决定方向** |
| 倒数性质 | a > b > 0 ⇒ 1/a < 1/b | 必须同号才成立 |
| 乘方性质 | a > b > 0 ⇒ aⁿ > bⁿ | n 为正整数 |
| 开方性质 | a > b > 0 ⇒ ⁿ√a > ⁿ√b | 与乘方互逆 |

**经典陷阱题：**
```
已知 a > b，下列哪个一定成立？
A. a² > b²      B. 1/a < 1/b      C. ac > bc      D. a + c > b + c
```
正确答案：D。A 需要 a,b > 0；B 需要同号；C 需要知道 c 的符号；只有 D 永远成立。

### 3.2 一元二次不等式——"三位一体"

> 二次函数图像、二次方程的根、不等式的解集——**三者是一一对应的关系**，这是高中数学最重要的数形结合之一。

**解题流程：**
```
化标准形（ax² + bx + c > 0）
    → 求对应方程的根（Δ 决定根的个数）
    → 画二次函数草图（开口方向 + 根的位置）
    → 从图像读出解集
```

| Δ | 根的个数 | 解集（a > 0） |
|:-:|:--------:|:-------------|
| Δ > 0 | 两不等实根 x₁, x₂ | x < x₁ 或 x > x₂（大于取两边） |
| Δ = 0 | 两相等实根 x₀ | x ≠ x₀ |
| Δ < 0 | 无实根 | R（恒成立） |

**含参讨论三步法：**
1. 二次项系数是否为 0（退化一次不等式）
2. Δ 的正负（根的个数）
3. 两根大小比较（需要分类讨论时）

### 3.3 基本不等式——最值问题的万能钥匙

> 最核心的一句话：**"一正二定三相等"**

**二元均值不等式：**
```
a + b ≥ 2√(ab)  当且仅当 a = b 时取等
(a + b)/2 ≥ √(ab)  算术平均 ≥ 几何平均
```

**三元均值不等式：**
```
a + b + c ≥ 3·³√(abc)  当且仅当 a = b = c 时取等
```

**使用条件详解：**
- **一正**：a, b > 0。如果 a, b 可能是负数，先取绝对值或换元
- **二定**：和定 → 积最大；积定 → 和最小
- **三相等**：检查 a = b 是否在定义域内——能取到才成立

**常用变形：**
| 原始形式 | 变形 | 用途 |
|:---------|:-----|:-----|
| a + b ≥ 2√(ab) | √(ab) ≤ (a+b)/2 | 积有上限 |
| a² + b² ≥ 2ab | a² + b² ≥ 2ab | 平方和与乘积 |
| (a+b)² ≥ 4ab | ab ≤ (a+b)²/4 | 和定积最大 |
| a + 1/a ≥ 2（a > 0）| 对勾函数 | 倒数型最值 |

### 3.4 线性规划

> 线性规划本质是**几何法解最值**——把代数问题变成在平面上画图。

**解题流程：**
```
画可行域（不等式组 → 半平面交集）
    → 找顶点（边界线的交点）
    → 目标函数平移（或直接代入顶点验证）
```

**三种目标函数：**
| 类型 | 形式 | 几何意义 | 解法 |
|:----|:-----|:---------|:-----|
| 截距型 | z = ax + by | 直线纵截距 | 平移直线 |
| 斜率型 | z = (y-b)/(x-a) | 两点连线斜率 | 观察边界 |
| 距离型 | z = (x-a)²+(y-b)² | 点到点距离的平方 | 几何法 |

**易错：** 边界虚实线——不等式含等号画实线，不含等号画虚线。取点时注意是否在边界上。

### 3.5 恒成立问题——高考最热门的考点之一

> 恒成立是把不等式问题转化为函数最值问题的桥梁，是导数大题的核心技能。

| 问题类型 | 转化方式 |
|:---------|:---------|
| ∀x, f(x) ≥ a 恒成立 | ⇔ f(x)min ≥ a |
| ∀x, f(x) ≤ a 恒成立 | ⇔ f(x)max ≤ a |
| ∃x, f(x) ≥ a 成立（能成立） | ⇔ f(x)max ≥ a |
| ∃x, f(x) ≤ a 成立 | ⇔ f(x)min ≤ a |

**两种主流解法：**

**方法一：分离参数法**
```
把参数 a 单独放在一边，另一边是不含参数的函数
例：x² + ax + 1 > 0 在 x ∈ [1, +∞) 恒成立
   → a > -(x + 1/x)
   → 求 g(x) = -(x + 1/x) 的最大值
   → a > g(x)max
```
> 分离参数时注意：如果除以一个含参的式子，要讨论符号。

**方法二：函数最值法**
```
构造新函数 F(x) = f(x) - a（或 f(x) - g(x)）
求 F(x) 在给定区间上的最值
转化为 F(x)min ≥ 0
```

**恒成立与能成立的对比：**
> "恒成立"是"所有同学都要及格"——看最差的那个；"能成立"是"至少有一个同学及格"——看最好的那个。

## 四、高考核心题型

### 题型 1：不等式性质判断

**解法核心：** 逐项验证，注意举反例（特值法是最快的）

**解题步骤：**
1. 看条件中是否有正负限制
2. 对每个选项尝试取特值验证
3. 注意可乘性需要判断乘数符号

**示例：**
```
若 a < b < 0，则下列不等式成立的是？
A. 1/a < 1/b    B. a² < b²    C. a³ < b³    D. a² < ab
```
解：a < b < 0 ⇒ -a > -b > 0 ⇒ (-a)³ > (-b)³ ⇒ -a³ > -b³ ⇒ a³ < b³，选 C

**常见陷阱：** 倒数性质需要同号，平方性质需要非负

---

### 题型 2：一元二次不等式

**解法核心：** 三位一体——求根画图写解集

**解题步骤：**
1. 化标准形（二次项系数化为正）
2. 求判别式 Δ，判断根的个数
3. 求根（因式分解或求根公式）
4. 画二次函数图像，读出解集

**示例：**
```
解不等式 -x² + 3x - 2 > 0
→ x² - 3x + 2 < 0（两边乘 -1，变号）
→ (x - 1)(x - 2) < 0
→ 1 < x < 2
```

**常见陷阱：** 二次项系数为负时忘记变号；Δ < 0 时误认为无解（a > 0, Δ < 0 时解集是 R）

---

### 题型 3：分式不等式

**解法核心：** 移项通分 → 化乘积 → 穿根

**解题步骤：**
1. 把所有项移到一边，通分
2. 分子分母化乘积形式
3. 等价转化为整式不等式（注意分母不为 0）
4. 穿根法求答案

**示例：**
```
解 (x - 1)/(x + 2) ≥ 0
→ 等价于 (x - 1)(x + 2) ≥ 0 且 x ≠ -2
→ x ≤ -2 或 x ≥ 1，但 x ≠ -2
→ x < -2 或 x ≥ 1
```

**常见陷阱：** 直接两边乘以分母（分母可能是负的）；忘记分母不为 0

---

### 题型 4：基本不等式求最值

**解法核心：** 配凑 → 一正二定三相等

**解题步骤：**
1. 检查是否为正数（不正则取反或换元）
2. 配凑成和定或积定的形式
3. 套公式求最值
4. 验证取等条件

**示例 1——直接型：**
```
x + 1/x ≥ 2（x > 0），当 x = 1 时取等
```

**示例 2——配凑型：**
```
已知 x > 0，求 x + 4/x 的最小值
→ 直接套公式：x + 4/x ≥ 2√(x·4/x) = 4
→ 当 x = 4/x 即 x = 2 时取等
```

**示例 3——"1"的代换：**
```
已知 x > 0, y > 0, 2x + y = 1，求 1/x + 1/y 的最小值
→ 1/x + 1/y = (2x + y)(1/x + 1/y)
            = 2 + 2x/y + y/x + 1
            = 3 + (2x/y + y/x)
            ≥ 3 + 2√(2x/y · y/x)
            = 3 + 2√2
→ 当 2x/y = y/x 即 y = √2·x 时取等
```

**常见陷阱：** 忘记检查取等条件；正负数没判断就套公式

---

### 题型 5：含参不等式讨论

**解法核心：** 分类讨论——系数、Δ、根的大小

**解题步骤：**
1. 讨论二次项系数是否为 0
2. 若为二次，讨论 Δ 的符号
3. 若 Δ > 0，讨论两根的大小关系
4. 每种情况写出对应的解集

**常见陷阱：** 漏掉二次项系数为 0 的情况；分类讨论不完整

---

### 题型 6：线性规划

**解法核心：** 画可行域 → 代入顶点验证

**解题步骤：**
1. 在坐标系中画出每个不等式对应的半平面
2. 标出可行域（所有半平面的交集）
3. 找出所有顶点坐标
4. 把顶点代入目标函数，比较大小

**常见陷阱：** 虚实线混淆；可行域画反

---

### 题型 7：恒成立求参数范围

**解法核心：** 分离参数或构造函数

**解题步骤：**
1. 判断用分离参数还是函数最值法
2. 如果参数容易分离 → 分离参数，求另一侧的最值
3. 如果不好分离 → 构造函数，求导找最值
4. 转化为最值与参数的不等式

**示例：**
```
若 x² - ax + 1 ≥ 0 在 x ∈ R 上恒成立
→ Δ = a² - 4 ≤ 0
→ -2 ≤ a ≤ 2
```

**常见陷阱：** 分离参数时符号搞反；端点是否可取没确认

---

### 题型 8：不等式证明

**解法核心：** 比较法 / 综合法 / 分析法 / 放缩法

| 方法 | 思路 | 适用场景 |
|:----|:-----|:---------|
| 比较法 | 作差（或作商）→ 判断正负 | 多项式不等式 |
| 综合法 | 从已知性质出发推导 | 简单不等式 |
| 分析法 | 从结论逆推，找充分条件 | 复杂不等式 |
| 放缩法 | 放大或缩小一边 → 中间桥梁 | 数列求和、积分估计 |
| 构造函数法 | 构造函数 → 求导 → 证明单调 | 导数压轴题 |

**常见陷阱：** 放缩方向搞反；放缩幅度太大（失效）

---

### 题型 9：绝对值不等式

**解法核心：** 零点分段法

**解题步骤：**
1. 找出所有零点（使绝对值内为 0 的 x 值）
2. 按零点分段讨论
3. 每段去掉绝对值符号求解
4. 取各段解集的并集

**常见陷阱：** 分段时漏掉等号归入哪一段

---

### 题型 10：高次不等式（穿根法）

**解法核心：** 数轴标根 → 从右上方画 → 奇穿偶不穿

**解题步骤：**
1. 把不等式化为 (x - x₁)(x - x₂)... > 0 的形式
2. 在数轴上标出所有根（实心或空心取决于等号）
3. 从右上方开始画线
4. 奇次根穿过数轴，偶次根不穿
5. 上方为正，下方为负

**常见陷阱：** 方向搞反（必须从右上方开始）；偶次根忘记不穿

## 五、基本不等式的高级应用

### 5.1 配凑法

> 配凑的核心：**把给定的表达式变形成"和定"或"积定"的形式**

| 原始形式 | 配凑方式 | 结果 |
|:---------|:---------|:-----|
| x(1 - x)，x ∈ (0,1) | 和为 1，直接套 | ≤ 1/4 |
| x + 1/x，x > 0 | 积为 1，直接套 | ≥ 2 |
| (x² + 2)/x，x > 0 | 拆写成 x + 2/x | ≥ 2√2 |
| (x² + 1)/(x - 1)，x > 1 | 令 t = x - 1，换元 | 换元后套用 |

**配凑技巧：**
- **加一项减一项**：比如 x + 1/(x-1) → (x-1) + 1/(x-1) + 1
- **乘一项除一项**：构造"和定"或"积定"
- **拆项**：把分子拆成若干部分

### 5.2 "1"的代换

> 已知 ax + by = 1（或类似条件），求分式型最值——这是基本不等式最重要的技巧之一。

**标准套路：**
```
要求 1/x + 1/y 的最小值，已知 2x + y = 1
→ 目标 = (2x + y)(1/x + 1/y)
       = 3 + 2x/y + y/x
       ≥ 3 + 2√2
```
> 核心思路：把"1"用条件表达式替换，展开后用基本不等式。

### 5.3 换元法

当表达式形式复杂时，通过换元转化为基本不等式的标准形式。

```
例：求 (x² + 1)² / x² 的最小值（x > 0）
令 t = x² > 0，则原式 = (t + 1)² / t = t + 2 + 1/t
t + 1/t ≥ 2，所以原式 ≥ 4
当 t = 1 即 x = ±1 时取等
```

## 六、易错点速查

| 易错点 | 正解 | 常见错误 |
|:-------|:-----|:---------|
| 基本不等式条件 | a, b > 0 才能直接套 | 没检查正负直接套公式 |
| 取等条件 | 验证 a = b 是否在定义域内 | 算出最值但不验证取等 |
| 不等式乘负数 | 不等号方向要变 | 忘记变号 |
| 分式不等式 | 移项通分 → 乘积形式 | 两边直接乘分母（可能为负） |
| 线性规划边界 | 看不等式是否含等号确定虚实 | 画反边界或虚实搞错 |
| 恒成立分离参数 | 分离时注意参数系数的正负 | 分离后不等号方向搞反 |
| 穿根法 | 从右上方开始，奇穿偶不穿 | 方向搞反或忘记偶次不穿 |
| 绝对值不等式 | 零点分段，取并集 | 分段讨论时漏了某段 |
| 可乘性 | c 的符号决定方向 | 见到 a > b 直接两边乘 c |
| 倒数性质 | 需要同号 | 负数直接取倒数 |

## 七、不等式在函数与导数中的应用

> 这是不等式在高考中最重要的角色——**导数大题的本质就是用不等式解决问题**。

### 7.1 利用导数证明不等式

**标准套路三步走：**
```
① 构造函数：把所有项移到一边，令 F(x) = f(x) - g(x)
② 求导研究单调性：F'(x) → 判断正负 → 确定 F(x) 的走势
③ 求最值比较：F(x)min ≥ 0 或 F(x)max ≤ 0
```

**示例：**
```
证明：当 x > 0 时，x > sin x
→ 令 F(x) = x - sin x
→ F'(x) = 1 - cos x ≥ 0（仅 x = 2kπ 时取等）
→ F(x) 在 [0, +∞) 单调递增
→ F(x) > F(0) = 0
→ 即 x > sin x，得证
```

### 7.2 利用导数研究恒成立问题

```
例：当 x > 0 时，x² + ax + ln x ≥ 0 恒成立，求 a 的范围
→ 分离参数：a ≥ -(x² + ln x)/x = -(x + ln x/x)
→ 令 g(x) = -(x + ln x/x)，求 g(x)max
→ 导数求最值 → 得到 a 的范围
```

### 7.3 常见放缩不等式（导数大题常用）

> 这些放缩关系要熟练掌握，导数压轴题经常需要用到。

| 不等式 | 适用范围 |
|:-------|:---------|
| eˣ ≥ x + 1 | x ∈ R（当 x = 0 取等） |
| ln x ≤ x - 1 | x > 0（当 x = 1 取等） |
| sin x ≤ x ≤ tan x | x ∈ [0, π/2) |
| x/(x+1) ≤ ln(1+x) ≤ x | x > -1 |
| eˣ ≥ ex | x ∈ R |

**记忆口诀：** eˣ 站在切线 x+1 上面，lnx 趴在切线 x-1 下面。

## 八、给家长的提醒

> 不等式不是一个独立模块——它是"打杂"的，到处都要用。

1. **基本不等式的"配凑"能力，本质上是代数变形能力。** 因式分解学得好的人配凑也好，反过来如果配凑总是不会，说明初中代数功底可能还有漏洞。

2. **孩子最容易犯的错误不是"不会做"，而是"忘记检查取等条件"。** 基本不等式的题型套路有限，多数孩子都能学会套公式，但在大题中经常因为不验证取等条件而丢分。

3. **建议学习策略：**
   - 单独的不等式专题，花 3-4 节课把基本框架过一遍即可
   - 线性规划做 10 道典型题掌握画图方法
   - 基本不等式多练配凑和"1"的代换
   - 恒成立问题在导数专题中重点攻克
   - **每遇到一次不等式，就复习一遍"一正二定三相等"**

4. **不等式在不同分数段的学习重点：**
   | 分数段 | 重点 |
   |:------|:-----|
   | 90 以下 | 不等式性质、一元二次不等式解法、基本不等式套公式 |
   | 90-120 | 基本不等式配凑、线性规划、恒成立分离参数 |
   | 120-135 | 含参讨论、不等式证明、放缩法 |
   | 135+ | 导数中的不等式证明、数列放缩、高难度放缩构造 |

5. **长期来看**：不等式的核心价值在于培养"放缩直觉"和"最值思维"。这两样东西，到了大学高等数学（极限、级数、积分估计）会继续用到。

---

> **最后一句：不等式解题，方向比精度重要。先判断放还是缩、是求最大还是最小，再动手算。**
