# 高考专题·平面向量

> 平面向量是高考数学的"万能工具包"——它一头连着代数运算，一头勾着几何直观。文章虽短，用处极广。
> 对冉冉来说：向量不是孤立章节，而是贯穿解几和立几的底层语言。

---

## 一、考纲定位

| 项目 | 内容 |
|:----|:-----|
| 分值占比 | 约 5%（5-8 分） |
| 常考题型 | 选择 1 道，选填偶尔再考一道；解几/立几大题中作为工具间接使用 |
| 难度系数 | ★☆（基础送分题为主，偶有 ★★★ 最值问题） |
| 核心要求 | 掌握向量的几何意义与代数运算，会灵活切换两种视角 |
| 新高考趋势 | 单独命题减少，更多融入解析几何和立体几何作为向量法工具 |

> 平面向量在高考中极少单独出难题，但它是立体几何向量法的根基——向量法学不好，建系也白搭。

## 二、知识体系

```
平面向量
 ├── 概念
 │    ├── 有向线段 —— 向量的几何表示
 │    ├── 模（长度）—— |a| 或 |AB|，表示大小
 │    ├── 零向量 —— 模为 0，方向任意（特殊！）
 │    ├── 单位向量 —— 模为 1，方向与 a 相同记作 a/|a|
 │    ├── 平行向量 —— 方向相同或相反（含零向量）
 │    └── 共线向量 —— 平行向量移动到同一直线上
 │
 ├── 运算
 │    ├── 加法（三角形法则 / 平行四边形法则）
 │    ├── 减法 —— a - b = a + (-b)
 │    ├── 数乘 —— λa，方向：λ>0同向，λ<0反向
 │    └── 数量积（点乘）—— a·b = |a||b|cosθ
 │
 ├── 坐标表示
 │    ├── 坐标运算 —— 加减数乘点乘全部对应坐标运算
 │    ├── 平行判定 —— x₁y₂ = x₂y₁
 │    └── 垂直判定 —— x₁x₂ + y₁y₂ = 0
 │
 ├── 定理
 │    ├── 共线定理 —— a∥b ⇔ 存在唯一λ使 a=λb
 │    └── 平面向量基本定理 —— 任意向量可由两个不共线基底唯一表示
 │
 └── 应用
      ├── 模长计算 —— |a| = √(x²+y²)
      ├── 夹角计算 —— cosθ = (a·b)/(|a||b|)
      ├── 投影与投影向量
      ├── 三角形/四边形中的向量表示
      └── 物理中的合成与分解
```

> 整个知识体系就一根主线：**形→数→用**。先画图理解，再坐标计算，最后应用到图形和物理中。

## 三、核心概念深度拆解

### 3.1 向量 vs 数量——方向是灵魂

| | 向量 | 数量（标量） |
|:--|:-----|:------------|
| 定义 | 既有大小又有方向的量 | 只有大小没有方向的量 |
| 举例 | 力、速度、位移 | 温度、质量、时间 |
| 表示 | a 或 AB（带箭头） | a 或 5 |
| 运算规则 | 遵循平行四边形法则 | 普通加减乘除 |

> 向量的三要素：大小、方向、起点。但作为自由向量，**起点不重要**——平移不改变向量本身。冉冉如果一开始被"AB箭头放哪"搞晕，就强调这一点。

### 3.2 向量加法的几何意义——画图是关键

**三角形法则（首尾相连）：**
- AB + BC = AC
- 把向量首尾相接，从第一个起点指向最后一个终点
- 适用于多个向量连续相加

**平行四边形法则（共起点作对角线）：**
- 两个向量从同一点出发，作平行四边形，对角线即为和向量
- 适合两个向量相加，直观展示合成效果

> 加法是两个法则，减法则只记一个：**a - b = a + (-b)**。把减法转化为加法，再用三角形法则最快。

### 3.3 数量积（点乘）的灵魂地位

> 数量积是平面向量最重要的运算，没有之一。高考中超过 60% 的向量题最后都落到数量积上。

**公式与含义：**
```
a·b = |a||b|cosθ
```
- 几何含义：**"a 在 b 上的投影长度 × b 的长度"**
- 结果是一个数（数量），不是向量
- 坐标形式：a·b = x₁x₂ + y₁y₂

**数量积的三大判断功能：**

| 条件 | 结论 | 说明 |
|:----|:-----|:-----|
| a·b = 0 | a ⊥ b | 垂直（最常用，非零向量前提） |
| a·b > 0 | θ 为锐角 | 夹角小于 90° |
| a·b < 0 | θ 为钝角 | 夹角大于 90° |

> 注意陷阱：a·b > 0 只说明夹角小于 90°，但可能等于 0°（同向），所以不能直接说"锐角"。高考填空中这里是易错点。

### 3.4 平面向量基本定理——坐标的理论基础

> 定理本身不直接考，但它是"坐标表示"和"基底法"的根基。

```
如果 e₁、e₂ 是同一平面内两个不共线向量，
那么对平面内任意向量 a，存在唯一实数对 (λ, μ)，使得：
    a = λe₁ + μe₂
```

**选择基底的技巧：**
- 优先选已知夹角和大小的向量（夹角余弦值已知或易求）
- 优先选长度已知的向量
- 在三角形中，常选两边所在向量为基底

> 对冉冉来说：基底法其实就是"用已知量表示未知量"的向量版本，和方程思想是一回事。

### 3.5 投影与投影向量

> 这是近几年高考的热点新概念，很多孩子搞不清"投影"和"投影向量"的区别。

| 概念 | 公式 | 说明 |
|:----|:-----|:-----|
| a 在 b 方向上的**投影**（数量） | \|a\|cosθ = (a·b)/\|b\| | 有正负！锐角为正，钝角为负 |
| a 在 b 方向上的**投影向量** | (a·b/|b|²)·b | 投影方向沿着 b，长度为\|投影\| |

> 区分口诀：**投影是个数，投影向量是向量**。考试问"投影向量"就带方向，问"投影"就给一个数（可正可负）。

### 3.6 向量的模——平方是万能钥匙

```
|a|² = a·a = x² + y²
```

> 处理带模的题目（求范围、最值），几乎唯一的突破口就是平方。

| a + b |² = |a|² + |b|² + 2a·b
| a - b |² = |a|² + |b|² - 2a·b

## 四、高考核心题型

### 4.1 向量加减法与几何表示 ★

> 纯送分题，画图即可。

**解题步骤：**
1. 看清向量方向
2. 三角形法则首尾相连，或平行四边形法则作对角线
3. 注意减法方向：a - b 指向被减数 a 的终点

### 4.2 坐标运算 ★

> 单纯套公式，不能失分。

```
a ± b = (x₁ ± x₂, y₁ ± y₂)
λa = (λx, λy)
a·b = x₁x₂ + y₁y₂
```

### 4.3 平行/垂直判定 ★★

| 判定 | 坐标形式 | 易错点 |
|:-----|:---------|:-------|
| a∥b | x₁y₂ = x₂y₁ | 不要错写成 x₁y₁ = x₂y₂ |
| a⊥b | x₁x₂ + y₁y₂ = 0 | 记得验证向量非零 |

> 冉冉最容易犯的错：把平行的坐标条件记成比值相等 x₁/x₂ = y₁/y₂。这在分式中分母可能为 0，用乘积形式 x₁y₂ = x₂y₁ 才安全。

### 4.4 模长与距离计算 ★

```
|a| = √(x² + y²)
|AB| = √((x₂-x₁)² + (y₂-y₁)²)
```

### 4.5 夹角计算 ★★

```
cosθ = (a·b) / (|a||b|)
```

> 注意：夹角 θ ∈ [0, π]，余弦值在 [0, π] 上是减函数。cosθ 越大，角越小。

### 4.6 投影与投影向量 ★★★

**典型问法：**
1. 求 a 在 b 方向上的投影 → 直接算 |a|cosθ 或 (a·b)/|b|
2. 求 a 在 b 方向上的投影向量 → 算完投影再乘以 b 的单位向量

### 4.7 平面向量基本定理应用 ★★★

> 选好基底，剩下的就是解方程。

**解题流程：**
1. 观察图形，选择两个已知夹角/长度的不共线向量作为基底
2. 把目标向量用基底表示
3. 利用已知条件（平行、垂直、长度相等）列方程
4. 解出参数

### 4.8 最值问题 ★★★

> 平面向量中最值问题的三把刀：

| 方法 | 适用场景 | 操作要点 |
|:----|:---------|:---------|
| **坐标法** | 有垂直关系的图形（矩形、直角三角形） | 建系→设点坐标→用参数表示目标→求最值 |
| **数量积** | 涉及两向量模长或垂直 | 将目标平方→转化为数量积→利用范围公式 |
| **几何意义** | 动点轨迹可见（圆、直线） | 观察几何意义：模长=距离/点乘=投影 |

> 最值问题是平面向量中唯一能拉开差距的题型，也是冉冉需要重点练的。十道向量最值题做下来，方法就定型了。

### 4.9 图形中的向量表示 ★★★

**三角形中的常用结论：**
- AB + BC + CA = 0
- 向量中点公式：M 为 BC 中点 → AM = (AB + AC)/2
- 向量重心公式：G 为重心 → GA + GB + GC = 0
- 向量共线：若 A、B、C 共线，则 AB = λAC 或 OC = αOA + βOB 且 α+β=1

**平行四边形：**
- 对角线互相平分 → 对角线中点的向量坐标相等
- 对角线向量：d₁ = a + b, d₂ = a - b

> 这些结论不需要死背，做题时画图推导最快。背结论反而容易记混。

## 五、易错点速查

> 以下每个易错点，冉冉都在某次测验中踩过一次。考前看一遍，至少多拿 5 分。

| # | 易错点 | 正解 | 常见错误 |
|:-:|:-------|:-----|:---------|
| 1 | 零向量方向 | 零向量方向任意（不能说"没有方向"） | 认为零向量没有方向 |
| 2 | 平行向量定义 | 方向相同或相反（包含零向量） | 认为平行 = 同向 |
| 3 | 共线向量 | 平行向量就是共线向量 | 认为共线必须在同一条线上 |
| 4 | 数量积 = 0 | 非零向量时 ⇔ 垂直 | 忘记零向量的特殊情况 |
| 5 | a·b = 0 推出 | a⊥b 或 a=0 或 b=0 | 类比实数认为a=0或b=0 |
| 6 | 投影正负 | 有正有负，由夹角决定 | 认为投影总是正值 |
| 7 | 投影 vs 投影向量 | 投影是数量，投影向量是向量 | 两者混用 |
| 8 | 平行坐标条件 | x₁y₂ = x₂y₁ | 错写成 x₁y₁ = x₂y₂ |
| 9 | 垂直坐标条件 | x₁x₂ + y₁y₂ = 0 | 混淆为平行条件 |
| 10 | 向量夹角的范围 | θ ∈ [0, π] | 忘记包含 0 和 π |
| 11 | a∥b 时 λ 存在性 | λ 唯一且存在（b≠0） | b=0 时特殊讨论 |
| 12 | 单位向量的标准化 | a/|a| 仅当 a≠0 时成立 | a=0 时忘了讨论 |
| 13 | 三角形法则方向 | 和向量从首指向尾 | 方向搞反 |
| 14 | 减法的方向 | a - b 指向 a 的终点 | 误以为指向 b 的终点 |
| 15 | 基底的选择条件 | 两个向量不共线 | 选了一对平行向量当基底 |

> 建议：让冉冉把这些易错点抄在一张小卡片上，每次考前看两分钟。易错点 4、5、9 是最高频踩坑区。

## 六、解题心法

### 6.1 三大解题视角

| 视角 | 什么时候用 | 操作 |
|:----|:-----------|:-----|
| **几何视角** | 有图形、有中点/重心/三等分点 | 画图→基底法→几何意义 |
| **坐标视角** | 有垂直关系/圆/矩形 | 建系→坐标运算→代数求解 |
| **数量积视角** | 涉及垂直、模长、夹角、投影 | 点乘→转化为方程→解参数 |

### 6.2 向量翻译表（代数⇔几何）

| 代数条件 | 几何含义 |
|:---------|:---------|
| a·b = 0 | a ⊥ b |
| a = λb | a∥b（λ>0 同向，λ<0 反向） |
| \|a\| = \|b\| | a 和 b 长度相等 |
| (a+b)·(a-b) = 0 | 平行四边形对角线垂直→菱形 |
| \|a+b\| = \|a-b\| | 平行四边形对角线相等→矩形 |
| a·b = \|a\|\|b\| | a 与 b 同向且共线 |
| a·b = -\|a\|\|b\| | a 与 b 反向且共线 |
| AB = λAC | A、B、C 三点共线 |
| OP = αOA + βOB，α+β=1 | P 在直线 AB 上 |

### 6.3 遇到难题时的降维法

1. **能画图先画图**——向量是几何工具，图画出来一半式子就自然写出来了
2. **无坐标不欢**——有垂直关系立刻建坐标系
3. **平方来救场**——模长最值、范围问题，99% 用平方转数量积
4. **基底法找关系**——不会做就选基底，把目标向量一步步表示出来
5. **特殊位置猜答案**——选择题动点最值，先试两个极端位置看趋势

## 七、跨专题关联

| 关联专题 | 向量角色 | 具体应用 |
|:---------|:---------|:---------|
| **解析几何** | 方向向量/法向量 | 直线方向向量 d，法向量 n；点到直线距离公式推导；直线的参数方程 |
| **立体几何** | 空间向量法 | 建立空间直角坐标系后，用向量法求线面角、二面角、点到平面的距离 |
| **三角函数** | 数量积中的 cosθ | 向量夹角与三角恒等变换交汇；与正余弦定理结合解三角形 |
| **平面几何** | 向量表示几何关系 | 用向量证明平行、垂直、三点共线、四心问题 |
| **物理** | 矢量运算 | 力的合成与分解、速度与位移的分解、做功 W = F·s |

> 平面向量最妙的地方就在这里——它像一根万能插头，插进哪个专题都能用。冉冉学到解几和立几时会反复见到它。

## 八、给家长的提醒

> 以下针对冉冉的实际情况，lulu 参考。

**1. 向量是"代数与几何的桥梁"**
- 有的孩子几何好代数差，向量可以帮助用图形理解
- 有的孩子代数好几何差，向量可以用坐标精确计算
- 对冉冉来说，关键是**两种视角都要会切换**

**2. 平面向量的核心就三件事**
- **画图**（几何意义不能丢）
- **坐标**（建系能解决大部分问题）
- **点乘**（数量积是出题人最爱）

**3. 向量在考试中的真实占比**
- 单独出题：选填 1 道（约 5 分），难度低
- 作为工具：解几大题、立几大题中默认会使用向量法
- 所以向量表面只占 5%，实际是 20%+ 大题的"前置技能"

**4. 冉冉的学习建议**
- 基础阶段：把坐标运算练熟，平行垂直判定条件滚瓜烂熟
- 提高阶段：基底法解图形中的向量表示（三角形重心、四边形中点等）
- 冲刺阶段：最值与范围问题的三种解题视角（坐标/数量积/几何意义）
- 易错点：每周看一遍上面的 15 个易错点，直到零失误

**5. 推荐练习方向**
- 近 3 年高考真题中所有的向量小题（先做）
- 近 3 年模考中的向量最值题（再做）
- 立几大题中建系法的向量运算（日常练）

> 一句话总结：**向量就算不单独出难题，也值得花精力学透——它是解几和立几这两大板块的入场券。**

## 九、公式速查卡

> 以下所有公式，考前默写一遍，确保手不生。

```
1. 向量坐标表示
   AB = (x₂-x₁, y₂-y₁)

2. 模
   |a| = √(x² + y²)
   |AB| = √((x₂-x₁)² + (y₂-y₁)²)

3. 数量积
   a·b = |a||b|cosθ = x₁x₂ + y₁y₂

4. 平行
   a∥b ⇔ x₁y₂ = x₂y₁ ⇔ a = λb (b≠0)

5. 垂直
   a⊥b ⇔ x₁x₂ + y₁y₂ = 0 ⇔ a·b = 0（非零向量）

6. 夹角
   cosθ = (a·b) / (|a||b|) = (x₁x₂+y₁y₂) / (√(x₁²+y₁²)·√(x₂²+y₂²))

7. 投影
   a 在 b 方向上的投影 = |a|cosθ = (a·b) / |b|

8. 投影向量
   a 在 b 方向上的投影向量 = (a·b / |b|²) · b

9. 中点公式
   若 M 为 AB 中点，则 OM = (OA + OB)/2

10. 重心公式
    若 G 为 △ABC 重心，则 OG = (OA + OB + OC)/3

11. 三点共线
    A、B、C 共线 ⇔ AB = λAC ⇔ 存在 t 使 OC = (1-t)OA + tOB

12. 单位向量
    e_a = a/|a| (a≠0)
```

> 打印出来，贴在冉冉书桌上。每次做题之前瞄一眼，一个月后自然在心里了。
