## 三、各章底层逻辑

### 第6章 平面向量——有方向也有大小的量

**核心：向量是一个"既有大小又有方向"的量**

向量是个非常强大的工具——它同时具有代数的计算能力和几何的直观性。

**核心运算：**
1. 加法（平行四边形法则、三角形法则）
2. 数乘（改变长度和方向）
3. 数量积（点乘）$a \cdot b = |a||b|\cos\theta$

**胡小群视角：**
> 向量的本质是什么？——两个字："位移"。
> 你从 A 走到 B，这个"移动"就是一个向量——它有距离（大小）和方向。
> 理解了这个，向量加减法的平行四边形法则就合理了：两个位移合在一起，相当于先走一步再走一步。

**向量的价值：** 它是把几何问题转化成代数计算的工具。在物理中尤其重要——力、速度、加速度都是向量。

### 第7章 复数——数的第三次扩张

**核心：$i^2 = -1$——给平方等于负数的数一个名字**

这是数的第三次扩张（自然数→实数→复数）。

$$
a + bi \quad (a, b \text{是实数})
$$

**复数的加减乘除**就是普通的代数运算，只要记住 $i^2 = -1$ 就可以了。

**胡小群追问：**
> $i$ 是什么？——$i$ 不是"虚数"（这个中文翻译容易引起误解），它是一个"平方等于 -1 的数"。就像 $\sqrt{2}$ 是一个"平方等于 2 的数"。

### 第8章 立体几何初步——三维空间推理

**核心：从平面的"两条线的关系"到空间的"线和面的关系"**

这是很多高一学生的"第二座大山"（第一座是函数）。

**核心内容：**
1. 空间点、线、面的位置关系
2. 平行与垂直的判定和性质
3. 表面积和体积的计算

**胡小群的立场：**
> 平面几何证明学得好的人，立几不会太差。立几其实就是"平几的推理能力 + 空间想象能力"。
>
> 反过来，如果孩子立几学不好，往往不是空间想象的问题，而是**推理逻辑本身就没建立起来**——初中平面几何遗留的问题。

### 第9~10章 统计与概率——从"确定性"到"不确定性"

**核心：数据会说话，但也会有"偏差"**

统计和概率是高中第一次系统学习"不确定性"。

- 统计：怎么获取数据、怎么描述数据
- 概率：怎么描述"可能性的大小"

## 五、常见错误

| 错误 | 原因 |
|:----|:----|
| 向量数量积符号搞反 | $a \cdot b = |a||b|\cos\theta$，不是 sin |
| 复数除法不会算 | 忘记"乘共轭"的方法 |
| 线面垂直条件记不全 | 判定定理和性质定理混用 |
| 古典概型数错样本点 | 枚举不完整或重复计数 |
