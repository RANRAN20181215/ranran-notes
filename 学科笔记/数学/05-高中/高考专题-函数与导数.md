## 三、核心概念深度拆解

### 3.1 函数概念的三要素

| 要素 | 定义 | 高考常见陷阱 |
|:----|:----|:------------|
| 定义域 | x 的取值范围 | 自然定义域易漏：分母≠0、偶次根号≥0、对数真数>0、tan x 定义域 |
| 值域 | y 的取值范围 | 有界性（三角函数/二次函数）、单调性决定取值范围 |
| 对应关系 | f 如何把 x 变成 f(x) | 抽象函数中 f 的"角色"容易混淆 |

> **胡小群：做任何函数题，先问"定义域是什么"。**
> 上来就化简、求导、代入——这是高一学生最常见的死法。

**抽象函数定义域陷阱：**

```
f(2x+1) 的定义域是 [0,1]，求 f(x) 的定义域

  f(2x+1)：x ∈ [0,1] → 2x+1 ∈ [1,3]
  f(x)：    x ∈ [1,3]

关键：定义域永远是对"x"说的，不是对"括号里的东西"说的。
```

---

### 3.2 单调性的两种证明方法

| 方法 | 适用场景 | 操作 | 优点 |
|:----|:--------|:----|:----|
| 定义法 | 抽象函数、不便求导 | 设 x₁<x₂，作差 f(x₁)-f(x₂) 判号 | 不受可导条件限制 |
| 导数法 | 具体函数求导可行 | f'(x) > 0 则增，f'(x) < 0 则减 | 快速、机械、不易出错 |

> **导数法不是万能的——抽象函数没有解析式，只能用定义法。**

**复合函数单调性：** 同增异减

```
f(g(x)) 的单调性 = f 的单调性 × g 的单调性
  f 增、g 增 → 整体增
  f 减、g 减 → 整体增
  f 增、g 减 → 整体减
  f 减、g 增 → 整体减
```

> **易错：先求定义域！复合函数定义域经常把增减区间切碎。**

---

### 3.3 奇偶性的判断与运用

**检查流程：**

```
① 定义域是否关于原点对称？ 不对称 → 非奇非偶（直接排除）
② f(-x) = f(x)   → 偶函数（关于 y 轴对称）
   f(-x) = -f(x)  → 奇函数（关于原点对称）
```

**三大性质：**

| 性质 | 内容 | 高考应用 |
|:----|:----|:--------|
| 奇函数 f(0)=0 | 若奇函数在 x=0 有定义，则 f(0)=0 | 求参数、验证 |
| 对称区间单调性一致 | 奇函数在对称区间单调性相同 | 解不等式 |
| 对称区间单调性相反 | 偶函数在对称区间单调性相反 | 解不等式 |

---

### 补充：函数图像变换

高考考查频率高，常在选择题中出现。

**1. 平移变换（左加右减，上加下减）**
- y = f(x+a)：向左平移 a 个单位（注意：是"加左减右"！最容易搞混）
- y = f(x) + a：向上平移 a 个单位

**2. 伸缩变换**
- y = f(kx)：横坐标变为原来的 1/k 倍
- y = kf(x)：纵坐标变为原来的 k 倍

**3. 对称变换**
- y = -f(x)：关于 x 轴对称
- y = f(-x)：关于 y 轴对称
- y = -f(-x)：关于原点对称
- y = |f(x)|：保留 x 轴上方，下方翻到上方
- y = f(|x|)：保留 y 轴右侧，左侧与右侧关于 y 轴对称

**常见错误：** y = f(x+2) 是向左移 2 还是向右移 2？——"左加右减"指 x 本身加常数，是向左移。

### 3.4 指对运算与函数

**互化关系：**

```
a^b = N  ⇔  log_a N = b
```

**两种增长模型对比：**

| 模型 | 函数 | 增长速度 | 高考场景 |
|:----|:----|:--------|:--------|
| 指数增长 | y = a^x (a>1) | 越增越快（爆炸式） | 人口增长、复利、细菌繁殖 |
| 对数增长 | y = log_a x (a>1) | 越增越慢（趋缓） | 学习曲线、pH 值、地震震级 |

> **胡小群追问：指数和对数为什么是"反函数"？**
> 因为把 x 和 y 的角色互换——一个"谁变到谁"反过来。

**换底公式：**

```
log_a b = log_c b / log_c a
```

**高考经典题型——比大小：**

```
比较 2^0.3, 0.3^2, log_2 0.3

① 2^0.3 > 1
② 0 < 0.3^2 < 1
③ log_2 0.3 < 0
→ 2^0.3 > 0.3^2 > log_2 0.3

核心：找中间量（0 和 1）分三段
```

---

### 补充：幂函数——"变化速度"的对比

**定义：** y = x^α（α 为常数）

**5种常见幂函数的图像特征（α 不同，形状不同）：**
- α > 1：增长越来越快（如 y = x²）
- α = 1：直线 y = x
- 0 < α < 1：增长越来越慢（如 y = √x）
- α = 0：常函数 y = 1（x ≠ 0）
- α < 0：递减趋向于 0（如 y = 1/x）

**高考考查方式：** 通常不单独考幂函数，而是在比大小题中出现——比较指数函数、对数函数、幂函数的大小关系。

### 3.5 导数概念

**定义式：**

```
f'(x₀) = lim_{Δx→0} [f(x₀+Δx) - f(x₀)] / Δx
```

**两种意义：**

| 意义 | 理解 | 对应高考题 |
|:----|:----|:----------|
| 物理意义 | 瞬时变化率（速度 = 位移的导数） | 物理应用、实际变化率问题 |
| 几何意义 | 切线斜率 | 切线方程、公切线问题 |

**可导与连续的关系：**

> 可导 ⇒ 连续（可导一定连续）
> 连续 ⇏ 可导（连续不一定可导，如 y=|x| 在 x=0 处连续但不可导）

---

### 3.6 导数研究函数单调性

**核心定理：**

```
在区间 I 上：
  f'(x) > 0  ⇒  f(x) 单调递增
  f'(x) < 0  ⇒  f(x) 单调递减
```

> **注意：f'(x) ≥ 0 且不恒为 0 ⇔ 单调递增（不严谨的说法是"f'(x) ≥ 0 且等号只在孤立点成立"）**
> 常见反例：f(x)=x³，f'(0)=0，但函数整体递增。

**分类讨论的三种触发条件：**

| 触发条件 | 典型场景 | 讨论方向 |
|:--------|:--------|:--------|
| 参数在导数中导致判别式不确定 | f'(x)=ax²+bx+c 中 a 是否为零 | a=0 vs a≠0；Δ>0 vs Δ≤0 |
| 参数导致分母正负变化 | f'(x)=(x-a)/(x²+1) | x 与 a 的大小比较 |
| 定义域受参数影响 | 对数真数含参：ln(x-a) | x 与 a 的关系 |

---

### 3.7 极值与最值

**极值的必要条件（费马定理）：**

> 若 x₀ 是 f(x) 的极值点且 f 在 x₀ 可导，则 f'(x₀) = 0

**注意：逆命题不成立。** f'(x₀)=0 只是"嫌疑犯"，是不是真凶还要验证。

**极值的充分条件：**

| 方法 | 判断标准 | 什么时候用 |
|:----|:--------|:----------|
| 一阶导数变号法 | f'(x) 在 x₀ 左右由正变负 → 极大值；由负变正 → 极小值 | 通用（最常用） |
| 二阶导数符号法 | f''(x₀) > 0 → 极小值；f''(x₀) < 0 → 极大值 | 二阶导容易求时 |

**最值的求解流程：**

```
Step 1: 求 f'(x) = 0 的解（驻点）
Step 2: 判断极值（一阶变号或二阶）
Step 3: 比较极值 + 端点值
Step 4: 最大（小）的那个就是最值
```

---

### 3.8 导数综合——构造函数

**常见构造模式：**

| 条件形式 | 构造的函数 | 原理 |
|:--------|:----------|:----|
| f'(x) > g'(x) | h(x) = f(x) - g(x) | 导数差为 0 判断单调性 |
| xf'(x) + f(x) | h(x) = xf(x) | (xf)' = f + xf' |
| xf'(x) - f(x) | h(x) = f(x)/x | (f/x)' = (xf' - f)/x² |
| f'(x) + f(x) | h(x) = e^x f(x) | (e^x f)' = e^x (f + f') |
| f'(x) - f(x) | h(x) = f(x)/e^x | (f/e^x)' = (f' - f)/e^x |

> **构造函数的核心不是"背形式"，是看出左右两边的"亲戚关系"。**
> 看到 xf' + f 就想 xf，看到 f' + f 就想 e^x f——这是条件反射。

## 四、高考核心题型与方法

### 题型 1：定义域 / 值域问题

**是什么：** 求函数的定义域或值域，常作为解答题的第一步。

**标准解法：**

```
定义域：
  ① 分母 ≠ 0
  ② 偶次根号内 ≥ 0
  ③ 对数真数 > 0
  ④ tan x: x ≠ π/2 + kπ
  ⑤ 复合函数：内函数的值域要满足外函数的定义域

值域：
  ① 二次函数配方法
  ② 分离常数法（分式函数）
  ③ 单调性法（已知单调区间直接求）
  ④ 换元法（指数/对数/三角）
```

**例题：** 求 f(x) = √(1 - x²) + 1/ln(x+1) 的定义域

```
1 - x² ≥ 0         ⇒  -1 ≤ x ≤ 1
x + 1 > 0          ⇒  x > -1
ln(x+1) ≠ 0        ⇒  x+1 ≠ 1 ⇒ x ≠ 0
→ 定义域：(-1,0) ∪ (0,1]
```

**常见陷阱：** 对数真数大于 0 和分母不为 0 记漏一个。**建议：每次先列"限制清单"再取交集。**

---

### 题型 2：单调性判断

**是什么：** 判断函数在给定区间上的单调性。

**标准解法：**

```
导数法（90% 的题用这个）：
  Step 1: 求定义域
  Step 2: 求 f'(x)
  Step 3: 令 f'(x) > 0 解出增区间，f'(x) < 0 解出减区间
```

**例题：** 判断 f(x) = x³ - 3x 的单调区间

```
f'(x) = 3x² - 3 = 3(x² - 1)
f'(x) > 0 ⇒ x < -1 或 x > 1
f'(x) < 0 ⇒ -1 < x < 1
增区间：(-∞,-1) 和 (1,+∞)
减区间：(-1,1)
```

**常见陷阱：** 增区间写成 (-∞,-1) ∪ (1,+∞)——这是错的，两个增区间不能并，要用"和"连接。

---

### 题型 3：奇偶性应用

**是什么：** 利用奇偶性化简计算、求参数、解不等式。

**标准解法：**

```
① 检查定义域对称性
② 利用 f(-x) = ±f(x)
③ 在对称区间上，奇函数积分=0，偶函数翻倍
```

**例题：** 已知 f(x) 是奇函数，当 x>0 时 f(x) = x² - 2x，求 x<0 时的解析式。

```
x < 0 时，-x > 0
f(x) = -f(-x) = -(x² + 2x) = -x² - 2x
```

**常见陷阱：** 奇函数 f(0)=0 只在"0 在定义域内"时才成立。若定义域不含 0 则不能用。

---

### 题型 4：指数 / 对数比大小

**是什么：** 比较两个或多个指数/对数式的大小。

**标准解法：**

```
① 找中间量：0、1、-1 分界线
② 构造函数利用单调性
③ 取中间量"搭桥"
④ 特值法（取特殊数验证）
```

**例题：** 比较 a = log₂3, b = log₃4, c = log₄5 的大小

```
a = log₂3 > log₂2 = 1
b = log₃4 > log₃3 = 1
c = log₄5 > log₄4 = 1

用换底公式转化为比较 ln3/ln2, ln4/ln3, ln5/ln4
构造函数 f(x) = ln(x+1)/lnx，研究其单调性...
```

**常见陷阱：** 直接比较底数和真数，忘用中间量分割。

---

### 题型 5：切线问题

**是什么：** 求曲线在某点的切线或过某点的切线。

**标准解法：**

```
在点 (x₀, f(x₀)) 处的切线：
  Step 1: 求斜率 k = f'(x₀)
  Step 2: 点斜式 y - f(x₀) = k(x - x₀)

过点 (a,b) 的切线（切点未知）：
  Step 1: 设切点 (t, f(t))
  Step 2: 斜率 f'(t)
  Step 3: 切线方程 y - f(t) = f'(t)(x - t)
  Step 4: 代入 (a,b) 得关于 t 的方程，解 t
```

**例题：** 求曲线 y = x² 过点 (0,-1) 的切线

```
设切点 (t, t²)，f'(x) = 2x，斜率 k = 2t
切线：y - t² = 2t(x - t)
代入 (0,-1)：-1 - t² = -2t²
t² = 1  ⇒  t = ±1
切线：y = 2x - 1 或 y = -2x - 1
```

**常见陷阱：** "在点 (x₀,y₀) 处"和"过点 (x₀,y₀)"的区别——前者切点已知，后者切点未知。

---

### 题型 6：含参单调性讨论

> **这个题型是分类讨论能力的"照妖镜"。**

**是什么：** 函数中含有参数，讨论参数取不同值时函数的单调性。

**标准解法：**

```
Step 1: 求定义域
Step 2: 求 f'(x)，整理成最简形式
Step 3: 找出 f'(x) 中"不确定正负的部分"
Step 4: 按"谁导致不确定"进行分类讨论

讨论的逻辑树：
  f'(x) = 0 是否有解？
    ├── 无解 → 直接判断 f'(x) 正负
    └── 有解 → 解在定义域内吗？
                ├── 不在 → 直接判断
                └── 在 → 比较解与定义域、比较多个解
```

**例题：** 讨论 f(x) = (1/3)x³ - ax² + (a² - 1)x 的单调性

```
f'(x) = x² - 2ax + a² - 1 = (x - a)² - 1 = (x - a - 1)(x - a + 1)

f'(x) = 0 的解：x = a+1 或 x = a-1

分类讨论 a：
  两个解的大小：a-1 < a+1 恒成立

  a-1 和 a+1 都在实数轴上，不在定义域上受限

  所以：
    x < a-1 或 x > a+1 时 f'(x) > 0 → 增
    a-1 < x < a+1 时 f'(x) < 0 → 减
```

**常见陷阱：** 漏讨论二次项系数为 0 的情况、漏讨论判别式 Δ > 0 / = 0 / < 0。

---

### 题型 7：极值最值问题

**是什么：** 求函数的极值或给定区间上的最值。

**标准解法：**

```
Step 1: f'(x) = 0 求驻点
Step 2: 列表（x 区间 + f'(x) 符号 + f(x) 增减）
Step 3: 确定极值类型
Step 4: 若含参 → 讨论参数对驻点位置和类型的影响
```

**例题：** 求 f(x) = x³ - 3x² + 1 在 [-1,2] 上的最值

```
f'(x) = 3x² - 6x = 3x(x - 2)
驻点：x = 0 和 x = 2

x    | -1  | (-1,0) | 0  | (0,2) | 2
f'   |     |   +    | 0  |   -   | 0
f    | -3  |   J    | 1  |   K   | -3

最大值：f(0) = 1
最小值：f(-1) = f(2) = -3
```

**常见陷阱：** 端点值也要参与比较，不能只看极值点。

### 补充：零点存在性定理与二分法

**零点存在性定理：**
如果 f(x) 在 [a,b] 上连续，且 f(a)·f(b) < 0，则存在 c ∈ (a,b) 使得 f(c) = 0。

注意：这只是存在性，不是唯一性。如果再加上单调性，就是唯一零点。

**零点个数问题（高考常考）：**
- 直接法：解方程 f(x) = 0
- 图像法：f(x) = g(x) 的零点 → y = f(x) 与 y = g(x) 的交点
- 结合单调性：单调函数最多一个零点

**二分法求近似解（了解即可）：**
- 每次取中点，判断符号，缩小区间
- 算误差 |b-a| < ε 时停止

### 题型 8：零点个数问题

**是什么：** 判断函数 f(x) 在某个区间内有多少个零点（根）。

**标准解法：**

```
法一（直接讨论）：
  Step 1: 画 f(x) 的图像草图（单调性 + 极值）
  Step 2: 找每个单调区间上 f(x) 的端点值
  Step 3: 零点定理 + 单调性确定零点个数

法二（分离参数）：
  Step 1: 把方程变形为 f(x) = k 的形式
  Step 2: 研究 g(x) = f(x) 的图像
  Step 3: y = g(x) 与 y = k 的交点个数
```

> **判断标准：何时用分离参数？**
> 参数容易被分离出来 → 用分离参数法（更直观）
> 分离后函数很复杂 → 用直接讨论法

**例题：** 判断 f(x) = lnx - ax 的零点个数

```
定义域 x > 0
f'(x) = 1/x - a

a ≤ 0 时：f'(x) > 0，f(x) 单调增
  lim(x→0⁺) f(x) = -∞, lim(x→+∞) f(x) = +∞
  → 1 个零点

a > 0 时：
  f'(x) = 0 ⇒ x = 1/a 为极大值点
  f(1/a) = -ln a - 1

  -ln a - 1 > 0 ⇒ a < 1/e → 0 个零点
  -ln a - 1 = 0 ⇒ a = 1/e → 1 个零点
  -ln a - 1 < 0 ⇒ a > 1/e → 2 个零点
```

**常见陷阱：** 只讨论了极值符号，忘了看区间端点的极限。

### 题型 9：不等式恒成立

**是什么：** 对于所有 x ∈ D，都有 f(x) ≥ 0（或 ≤ 0）成立，求参数范围。

**标准解法：**

```
法一（最值转化法）：
  f(x) ≥ 0 恒成立 ⇔ f(x)_min ≥ 0
  f(x) ≤ 0 恒成立 ⇔ f(x)_max ≤ 0

法二（分离参数法）：
  分离出参数 a ≥ g(x) 恒成立 ⇔ a ≥ g(x)_max
  a ≤ g(x) 恒成立 ⇔ a ≤ g(x)_min

法三（端点效应）：
  若 f(a) = 0，且 f(x) ≥ 0 恒成立 ...
用二阶导数或洛必达判断端点处的趋势
```

**例题：** 若 x > 0，ax - lnx ≥ 0 恒成立，求 a 的取值范围

```
分离参数：a ≥ lnx/x
设 g(x) = lnx/x
g'(x) = (1 - lnx)/x²
g'(x) = 0 ⇒ x = e

x < e 时 g'(x) > 0，x > e 时 g'(x) < 0
g(x)_max = g(e) = 1/e

a ≥ 1/e
```

**常见陷阱：** 恒成立 ⇔ 存在性混淆。

```
∀x ∈ D, f(x) ≥ a  ⇔ f(x)_min ≥ a（恒成立）
∃x ∈ D, f(x) ≥ a  ⇔ f(x)_max ≥ a（存在性）
```

### 题型 10：双变量问题

> **高考压轴题最高频类型。**

**是什么：** 题干中出现两个变量 x₁、x₂（通常满足某种约束），求范围、证明不等式等。

**标准解法：**

```
① 消元法：利用约束条件把双变量化单变量
② 主元法：固定一个变量，看成关于另一个的函数
③ 对称构造函数：利用 x₁ 和 x₂ 的对称性
④ 比值换元：令 t = x₁/x₂ 或 t = x₁ - x₂
```

**例题：** 已知 f(x) = lnx - x，若 0 < x₁ < x₂ 且 f(x₁) = f(x₂)，证明 x₁ + x₂ > 2

```
思路：设 x₂ = tx₁ (t > 1)，代入 f(x₁) = f(x₂)
lnx₁ - x₁ = lnt + lnx₁ - tx₁
⇒ x₁(t-1) = lnt
⇒ x₁ = lnt/(t-1), x₂ = tlnt/(t-1)

只需证 x₁ + x₂ = (t+1)lnt/(t-1) > 2
⇔ (t+1)lnt > 2(t-1)

构造函数 g(t) = (t+1)lnt - 2(t-1), t > 1
g'(t) = lnt + (t+1)/t - 2 = lnt + 1/t - 1
g''(t) = 1/t - 1/t² = (t-1)/t² > 0
g'(t) > g'(1) = 0, g(t) > g(1) = 0
得证。
```

**常见陷阱：** 消元后忘记新元的取值范围。

### 题型 11：数列型导数不等式

**是什么：** 用导数研究函数，再代入特殊点得到数列不等式。

**标准解法：**

```
Step 1: 利用导数证明一个函数不等式（如 ln(1+x) ≤ x）
Step 2: 把 x 换成特定的数列值（如 x = 1/n）
Step 3: 累加/累乘得最终不等式
```

**例题：** 证明 1 + 1/2 + 1/3 + ... + 1/n > ln(n+1)

```
先证：x > 0 时 ln(1+x) < x

令 x = 1/k：
ln(1 + 1/k) < 1/k
ln((k+1)/k) < 1/k

累加 k=1 到 n：
ln(2/1) + ln(3/2) + ... + ln((n+1)/n) < 1 + 1/2 + ... + 1/n
ln(n+1) < 1 + 1/2 + ... + 1/n
```

**常见陷阱：** 不等式放缩的方向搞反。

## 五、高考压轴题套路拆解

### 套路 1：含参分类讨论——讨论什么、怎么不漏

**讨论的本质：导数符号不确定的时候，凭什么确定？**

**三类必讨论场景：**

```
① 导数是二次式
   讨论顺序：二次项系数 → 判别式 → 根的大小

② 导数的零点含参
   讨论顺序：零点和定义域的关系 → 多个零点互比

③ 定义域本身含参
   讨论顺序：参数对定义域边界的影响
```

> **不漏讨论的方法：画"决定函数符号的因素"的树状图。**
> 每一层分叉都是"一个条件判断"，画完整棵树就不会漏。

**万能流程：**

```
f'(x) 整理 → 找"符号使能器"（含参数的因式）
                 ↓
          分类讨论树
  ੤
  参数=0   参数正    参数负
  的情况   的情况    的情况
           ↓
  在每个分支中继续分析 f'(x) 的符号
```

---

### 套路 2：构造函数证明不等式——怎么想到构造什么

**这不是灵机一动，是有章可循的：**

| 要证的式子 | 构造方向 | 原因 |
|:----------|:--------|:----|
| f(x) > g(x) | h(x) = f(x) - g(x) | 证 h(x)_min > 0 |
| f(x) ≥ 0 恒成立 | 研究 f(x) 最值 | 最值 ≥ 0 |
| x₁ + x₂ > 2a | 比值换元 t = x₁/x₂ | 双变量化单变量 |
| e^x > x + 1 | 设 h(x) = e^x - x - 1 | 经典切线放缩 |
| lnx ≤ x - 1 | 设 h(x) = lnx - x + 1 | 经典对数放缩 |

> **胡小群：看到不等式，不要想"怎么证"，想"什么时候取等"。**
> 取等条件就是构造函数时想让你发现的东西。

**两个最重要的切线放缩：**

```
e^x ≥ x + 1（x = 0 取等）
lnx ≤ x - 1（x = 1 取等）
```

这两个放缩是高考导数压轴题的"基础砖块"。很多难题第一步就是这两个放缩的变形。

---

### 套路 3：零点问题——分离参数 vs 直接讨论

**选择矩阵：**

| 条件 | 推荐方法 | 原因 |
|:----|:--------|:----|
| 参数可分离、分离后函数简单 | 分离参数法 | 转化为水平线与函数交点，直观 |
| 分离后函数复杂 | 直接讨论法 | 避免讨论新函数的性质 |
| 参数在指数/对数位置 | 直接讨论法 | 分离后可能更难处理 |
| 要确定零点精确个数 | 直接讨论法 | 分离后丢失零点位置的精确信息 |

**直接讨论法的核心步骤：**

```
① 单调性分析，把定义域拆成单调区间
② 在每个单调区间上用零点定理判断
③ 零点的个数 = 满足 f(左)×f(右) < 0 的区间个数
④ 注意：端点恰好为零的情况要单独说
```

**分离参数法的本质：**

```
f(x, a) = 0 ⇒ a = g(x)
f(x, a) = 0 的根的个数 = y = a 与 y = g(x) 图像的交点个数
```

## 六、易错点速查表

| 易错点 | 正解 | 常见错误 |
|:-------|:-----|:---------|
| 定义域忽略 | 先求定义域再解题 | 上来就化简/求导 |
| f'(x₀)=0 不是极值的充要条件 | 还需要验证变号 | f'(x₀)=0 ⇒ 极值点 |
| 复合函数求导 | 外层导 × 内层导 | 忘记乘内层导 |
| 参数讨论漏情况 | 系数为 0 的情况单独讨论 | 默认系数 ≠ 0 |
| 恒成立与存在性混淆 | ∀x 存在 x | 把存在性当恒成立做 |
| 单调区间用∪连接 | 用"和"、"或"连接 | (-∞,1) ∪ (2,+∞) |
| 切线"在"vs"过"混淆 | 切点已知 vs 切点未知 | 过点切线直接代点 |
| 对数真数 > 0 漏写 | ln(-x) 中 -x > 0 | 以为 ln 里的负号是整体的 |
| 奇函数 f(0) 滥用 | 只在 0 在定义域内成立 | 不管定义域直接写 f(0)=0 |
| 分离参数后忘范围 | 参数分离后新函数的定义域限制 | 约分后丢定义域 |

## 七、跨专题关联

**函数与不等式：**

```
恒成立问题 ← 最值转化（函数工具）
比较大小   ← 构造函数利用单调性
线性规划   ← 一次函数的区域划分
```

**函数与数列：**

```
递推函数        ← 数列的"函数视角"：a_n = f(a_{n-1})
数列型不等式    ← 导数放缩后代入特殊点
裂项相消        ← 和函数的构造思想
```

**函数与解析几何：**

```
切线问题        ← 导数的几何意义
最值问题        ← 几何最值的函数建模
曲线的切线与法线 ← 解析几何中的导数应用
```

**导数与概率统计：**

```
正态分布密度函数  ← f(x) = (1/σ√2π)·e^{-(x-μ)²/2σ²}
似然函数         ← lnL(θ) 求导找最大值
```

> **函数不是数学的一个分支——它是数学的"元语言"。**
> 所有数学问题最终都可以归结为寻找一个"对应关系"。

## 八、给家长的提醒

> **函数不是高中三年的"一个单元"——它是整个高中三年的"主线"。**

```
高一上：函数概念 + 基本函数   ← 打地基（决定天花板）
高一下：三角函数             ← 拓展视野
高二上：数列（函数的离散版）  ← 换个角度看函数
高二下：导数                 ← 升级武器
高三：综合                 ← 终极考验
```

**如何判断孩子函数学得怎么样：**

```
"学渣"：看到 f(x) 就头疼，不知道 x 和 f(x) 什么关系
"普通"：会做具体的函数题（如求二次函数最值）
"良好"：能处理含参讨论（分类讨论思路清晰）
"优秀"：能构造函数证明不等式（知道"要证什么就构造什么"）
"顶级"：能在压轴题中灵活选择分离参数 / 直接讨论
```

**高一上学期第一次月考的核心内容就是函数——**

> 如果这次月考函数概念没搞懂（如定义域/值域/单调性判断），后面会越来越吃力。
> 高一函数不过关，高三导数压轴题基本没戏。

**判断孩子是否真懂了的标准：**

> 能不能用自己的话解释"f(x) 到底是什么"。
> 如果只能说"f(x) 就是 y"，说明还没真懂。
> 如果能说"f(x) 是在 x 上的对应规则"，才算入门。

**导数不是高三才学的：**

> 选必二（高二下学期）就学导数了。
> 但在高考中，导数直接考到压轴难度——不会因为是"新学的"就手下留情。
> 所以高二下学导数的时候，必须一步到位压轴难度。
> 否则高三根本没时间重学，只能刷题修补。

**家长注意的四个关键时间点：**

| 时间 | 事件 | 家长做什么 |
|:----|:----|:----------|
| 高一上第 2 个月 | 函数第一次月考 | 关注定义域/值域是否过关 |
| 高一上期末 | 指对函数 + 函数综合 | 关注图像变换是否熟练 |
| 高二下开学 | 导数入门 | 关注极值/最值基本题型能否独立完成 |
| 高三一轮 | 函数与导数综合 | 关注含参讨论 + 构造函数是否形成套路 |

> **函数这条路，走慢了无所谓，走偏了才是灾难。**
> 宁可三角/几何暂时弱一点，函数必须扎实——因为其他内容拿不到的分，大不了不要；
> 函数没搞懂，高三复读一年都不一定能翻身。
