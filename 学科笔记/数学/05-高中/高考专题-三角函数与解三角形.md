## 三、核心概念深度拆解

### 3.1 弧度制——为什么 180° = π？

弧度 = 弧长 / 半径。当弧长等于半径时，角度为 1 rad。

半圆周长 = πr，对应弧长 = πr，所以半圆 = πr / r = π rad，即 180°。

> **弧度制的本质是"用弧长来度量角"**——这让三角函数不再是"角度"的函数，而是"实数"的函数，为微积分打下基础。

常见弧度换算：

| 角度 | 0° | 30° | 45° | 60° | 90° | 120° | 135° | 150° | 180° | 270° | 360° |
|:---:|:--:|:---:|:---:|:---:|:---:|:----:|:----:|:----:|:----:|:----:|:----:|
| 弧度 | 0 | π/6 | π/4 | π/3 | π/2 | 2π/3 | 3π/4 | 5π/6 | π | 3π/2 | 2π |

**口诀**：30 度六分之 π，45 度四分之 π，60 度三分之 π。

### 3.2 单位圆——三角函数的几何本质

在单位圆（r=1）上取点 P(cosθ, sinθ)：

- **sinθ = 纵坐标**——从 x 轴到 P 的垂直距离
- **cosθ = 横坐标**——从原点到 P 的水平距离
- **tanθ = 纵/横 = sinθ/cosθ**——过点(1,0)切线的纵坐标

**象限符号**（ASTC 口诀）：

| 象限 | sin | cos | tan | 口诀 |
|:----:|:---:|:---:|:---:|:----|
| 一 (0~90°) | + | + | + | **A**ll（全正） |
| 二 (90~180°) | + | - | - | **S**in（正弦正） |
| 三 (180~270°) | - | - | + | **T**an（正切正） |
| 四 (270~360°) | - | + | - | **C**os（余弦正） |

> 从单位圆能直观理解为什么三角函数是周期函数——转一圈就回来。这也是理解诱导公式的根本。

### 3.3 诱导公式——"奇变偶不变，符号看象限"

**不要背 6 组公式！理解这一句话就够了。**

#### 怎么理解"奇变偶不变"？

- 把原角度写成 `k·90° ± α`（或 `k·π/2 ± α`）的形式
- **奇**：k 为奇数（1,3,5,...）→ 函数名改变（sin ↔ cos，tan ↔ cot）
- **偶**：k 为偶数（0,2,4,...）→ 函数名不变

#### 怎么理解"符号看象限"？

- **把 α 看作锐角**（不管实际多大）
- 看 `k·90° ± α` 落在哪个象限
- 根据原函数在该象限的符号，决定最终正负

#### 完整推导示例：sin(π+α)

1. π = 2·90°，k=2 为偶数 → 函数名不变，仍为 sin
2. π+α 在第三象限，sin 在第三象限为 **负**
3. 结果：sin(π+α) = -sinα

> 验证：如果 α=30°，sin(210°) = -1/2，sin30° = 1/2，成立。

#### 速查表（不需要背，要能自己推）

| 公式 | 推导 |
|:----|:-----|
| sin(π/2 - α) = cosα | k=1(奇)变名，一象限 sin 正 |
| sin(π/2 + α) = cosα | k=1(奇)变名，二象限 sin 正 |
| sin(π - α) = sinα | k=2(偶)不变名，二象限 sin 正 |
| sin(π + α) = -sinα | k=2(偶)不变名，三象限 sin 负 |
| sin(3π/2 - α) = -cosα | k=3(奇)变名，三象限 sin 负 |
| sin(3π/2 + α) = -cosα | k=3(奇)变名，四象限 sin 负 |
| sin(2π - α) = -sinα | k=4(偶)不变名，四象限 sin 负 |

### 3.4 y = Asin(ωx + φ) 的图像变换

**这是高一最容易搞混的内容，没有之一。**

#### 从 y = sinx 到 y = Asin(ωx+φ) + b

| 参数 | 作用 | 说明 |
|:----|:----|:-----|
| A | 振幅 | 纵向伸缩，|A|>1 拉高，|A|<1 压扁 |
| ω | 角频率 | 横向伸缩，周期 T = 2π/|ω| |
| φ | 初相 | 左右平移 |
| b | 纵向偏移 | 上下平移 |

#### 先平移后伸缩 vs 先伸缩后平移

**例：y = sinx → y = sin(2x + π/3)**

**路径一：先平移后伸缩**
1. y = sinx → 左移 π/3 → y = sin(x + π/3)
2. 横坐标变为 1/2 → y = sin(2x + π/3)

**路径二：先伸缩后平移**
1. y = sinx → 横坐标变为 1/2 → y = sin2x
2. 左移 π/6（注意！不是 π/3）→ y = sin[2(x + π/6)] = sin(2x + π/3)

> 为什么第二步移的是 π/6 而不是 π/3？**因为平移是相对于 x 的，先伸缩后，φ 也要被 ω 除。**

**一句话：先伸缩后平移时，平移量要除以 ω。**

#### 五点法作图

取 ωx+φ = 0, π/2, π, 3π/2, 2π，解出五个 x 值：

| ωx+φ | x | y |
|:----:|:--:|:--:|
| 0 | -φ/ω | 0 |
| π/2 | (π/2-φ)/ω | A |
| π | (π-φ)/ω | 0 |
| 3π/2 | (3π/2-φ)/ω | -A |
| 2π | (2π-φ)/ω | 0 |

> 检查孩子：画五点图不是在原点上随便取，而是让括号里的整体取五个关键值。

### 3.5 辅助角公式

**公式**：a sinx + b cosx = √(a²+b²) · sin(x+φ)，其中 tanφ = b/a

**φ 的象限判断**（这是易错点）：

| a,b 符号 | φ 所在象限 | 例子 |
|:---------|:-----------|:-----|
| a>0, b>0 | 一象限（0~90°） | sinx+cosx → φ=45° |
| a<0, b>0 | 二象限 | -sinx+cosx |
| a<0, b<0 | 三象限 | -sinx-cosx |
| a>0, b<0 | 四象限 | sinx-cosx → φ=-45° |

> 常见错误：直接用 arctan(b/a) 算 φ——arctan 只会返回 -90°~90° 的值，必须结合 a,b 的符号判断象限。

**应用场景**：
- 求最值：-√(a²+b²) ≤ f(x) ≤ √(a²+b²)
- 求周期：T = 2π/ω
- 求单调区间：代入 sin 的单调区间解不等式
- 求对称轴：令 ωx+φ = π/2 + kπ

### 3.6 正弦定理 vs 余弦定理的选择

| 已知条件 | 用哪个 | 备注 |
|:---------|:------|:-----|
| 两角一边 | **正弦** | 先求第三角，直接代 |
| 两边夹角 | **余弦** | 直接代公式求第三边 |
| 三边 | **余弦** | 选最大边对角求 cosine |
| 两边及对角 | **正弦** | ⚠️ **注意两解！** |

> **两解问题的本质**：已知两边及其中一边的对角时，正弦值是确定的，但 0~180° 中有两个角的正弦值相同（互补角）。判断是否两解，用"大边对大角"。

#### 两解判断流程

已知 a, b, A（a 对 A，b 对 B）：

1. 用正弦定理求 sinB = b·sinA / a
2. 若 sinB > 1 → 无解
3. 若 sinB = 1 → B=90°，一解
4. 若 sinB < 1 → 初步得 B₁ = arcsin(sinB)，B₂ = 180° - B₁
5. 检查 B₂ + A < 180°？是则两解，否则一解

**记忆**：所谓"两解"就是角 B 可以是锐角也可以是钝角，只要加起来不超过 180°。

## 四、高考核心题型

### 题型 1：三角函数求值

**解法核心**：公式化简 → 角的配凑 → 代入求值

**例**：已知 sinα = 3/5，α∈(π/2, π)，求 cos(α + π/6)

**步骤**：
1. 由 α 在第二象限，cosα = -4/5
2. cos(α+π/6) = cosα·cosπ/6 - sinα·sinπ/6
3. = (-4/5)(√3/2) - (3/5)(1/2) = -(4√3+3)/10

**陷阱**：α 范围给出的象限信息不能漏——不然 cosα 符号就错了。

**角的配凑技巧**：
- 已知 α 求 α±β → 展开
- 已知 sin(α+β) → 求 cos 时注意 β 的范围
- 齐次式 → 分子分母同除 cosⁿx

### 题型 2：图像变换

**解法核心**：找到变换路径，注意平移量与 ω 的关系

**例**：如何由 y = sin2x 得到 y = sin(2x+1)？

**错误回答**：左移 1。这错了。

**正确回答**：
- y = sin2x → 向左平移 1/2 → y = sin[2(x + 1/2)] = sin(2x+1)

> 平移是针对 x 本身的。sin2x 到 sin(2x+1)，括号里加了 1，但 x 前有个 2，所以 x 实际只加了 1/2。

**常见变换路径**：

| 目标 | 操作 |
|:----|:-----|
| sinx → sin(x+φ) | 左移 φ（φ>0） |
| sinx → sinωx | 横缩为 1/ω |
| sinx → Asinx | 纵伸为 A 倍 |
| sinx → sinx + b | 上移 b（b>0） |

### 题型 3：求单调区间 / 周期 / 最值

**解法核心**：先化为 y = Asin(ωx+φ) + b 的标准形式

**例**：求 f(x) = sin2x + √3cos2x 在 [0, π] 上的单调递增区间

**步骤**：
1. 辅助角：f(x) = 2sin(2x + π/3)
2. sin 的增区间：-π/2 + 2kπ ≤ 2x+π/3 ≤ π/2 + 2kπ
3. 解不等式：-5π/12 + kπ ≤ x ≤ π/12 + kπ
4. 取 k=0：[-5π/12, π/12]，与 [0,π] 交集为 [0, π/12]
5. 取 k=1：[7π/12, 13π/12]，与 [0,π] 交集为 [7π/12, π]
6. 答案：[0, π/12] ∪ [7π/12, π]

**陷阱**：解不等式后**一定要**结合定义域取交集，这是扣分最多的点。

**周期性**：ω 决定周期 T = 2π/|ω|。如果题目中同时有 sin 和 cos，先把其中一个化掉。

**最值**：Asin(ωx+φ) + b 的范围是 [b-|A|, b+|A|]。

### 题型 4：解三角形求边 / 角

**解法核心**：选对定理 → 代入 → 解方程

**例**：△ABC 中，a=√3, b=1, C=60°，求 c

**解**：用余弦定理
c² = a² + b² - 2ab·cosC = 3 + 1 - 2√3·1·1/2 = 4 - √3
c = √(4 - √3)

**例**：△ABC 中，A=30°, B=45°, a=2，求 b

**解**：用正弦定理
a/sinA = b/sinB
b = a·sinB/sinA = 2·(√2/2)/(1/2) = 2√2

### 题型 5：解三角形的两解问题

**解法核心**：算出 sinB → 判断 B 两个可能值 → 验证范围

**例**：△ABC 中，a=10, b=8, A=30°，求 B

**步骤**：
1. 正弦定理：sinB = b·sinA/a = 8·0.5/10 = 0.4
2. B₁ = arcsin(0.4) ≈ 23.6°
3. B₂ = 180° - 23.6° = 156.4°
4. 检查：B₂ + A = 156.4° + 30° = 186.4° > 180°，舍去
5. 答案：B ≈ 23.6°（一解）

> 如果把题目改成 a=8, b=10, A=30°，那么 B₁≈38.7°, B₂≈141.3°。B₂+A=171.3°<180°，**两解**！
这里的判断关键就是"大边对大角"——当 b>a 时，B 可能大于 90°。

**两解情形速判**：

| 条件 | 解数 |
|:----|:----:|
| A 为钝角，a ≤ b | 无解 |
| A 为钝角，a > b | 一解 |
| A 为锐角，a < b·sinA | 无解 |
| A 为锐角，a = b·sinA | 一解（直角） |
| A 为锐角，b·sinA < a < b | 两解 |
| A 为锐角，a ≥ b | 一解 |

### 题型 6：三角与向量综合

**解法核心**：向量运算 → 三角函数表达式 → 最值 / 周期

**常见套路**：
- 数量积：a·b = |a||b|cosθ → 转化为 cos 函数
- 坐标运算：a·b = x₁x₂ + y₁y₂ → 得到一个含三角的式子
- 然后就是用辅助角公式化简，求周期/最值/单调区间

**例**：a=(sinx, 1), b=(cosx, -1)，求 f(x)=a·b 的最大值

1. f(x) = sinx·cosx + 1·(-1) = ½sin2x - 1
2. 最大值：½ - 1 = -½

### 题型 7：实际应用（测量）

**解法核心**：画示意图 → 找到三角形 → 选定理

**三种基本模型**：

| 模型 | 图示 | 方法 |
|:----|:-----|:-----|
| 测河宽 | 河两岸 A-B，在岸边测角度 | 直角三角形，正切 |
| 测山高 | 山底测顶角，已知距离 | 仰角 → 解三角形 |
| 航海方位 | 船的方向与速度合成 | 向量分解或正余弦定理 |

**关键**：一定要画图！实际应用题 90% 的失误是因为图画错了或没画。

## 五、易错点速查

| 易错点 | 正解 | 常见错误 |
|:-------|:-----|:---------|
| 诱导公式符号 | 看象限确定符号，sin(π+α) 第三象限为负 | 死记硬背，sin(π+α)=sinα |
| 平移方向 | y=sin2x→sin(2x+1)，左移 1/2 | 左移 1（没除 ω） |
| 平移与伸缩顺序 | 先伸缩后平移要除以 ω | 两种路径混用导致数错 |
| 三角形两解 | sinB=0.4, B=23.6° 或 156.4°, 验证和是否<180° | 只取锐角一个 |
| 辅助角 φ 的象限 | 由 a,b 符号共同决定 | 直接用 arctan(b/a) |
| 角度制与弧度制混用 | 全程统一用一种 | sin30°和 π/6 混在同一个式子 |
| 求单调区间 | 先化成标准形，再解不等式，最后与定义域取交集 | 解完就写不检查范围 |
| cosA=0 的情况 | A=90°，单独讨论 | 忽略余弦定理分母为 0 |
| 面积公式 | S=½bc·sinA，角的两边是夹角 | 用非夹角的两边 |
| sin²x+cos²x=1 | 恒等变换的基础，随时可用 | 忘记这个"万能替代" |

> 这些易错点统计来自近五年高考真题的失分分析。**平移和两解是出现频率最高的扣分点。**

## 六、跨专题关联

| 关联专题 | 结合方式 | 典型考法 |
|:---------|:---------|:---------|
| **平面向量** | 数量积 a·b=|a||b|cosθ | 给向量坐标 → 求夹角或模长 |
| **复数** | 复数三角形式 z=r(cosθ+isinθ) | 复数乘除法的几何意义 |
| **导数** | (sinx)'=cosx, (cosx)'=-sinx | 三角函数的极值、切线问题 |
| **实际应用** | 测量距离/高度/方位 | 解三角形在测量和航海中的应用 |
| **数列** | 周期数列 | 三角函数周期性与数列递推结合 |
| **不等式** | 三角函数有界性 | 利用 -1≤sinx≤1 求最值或证明 |

> **边角互化思想**：解三角形中，"边化角"（用正弦定理把边转为 sin 值）往往能简化计算；"角化边"则适合处理角的关系。这是三角与解三角形之间最本质的桥梁。

## 七、给家长的提醒

> **三角函数和解三角形是高考性价比最高的模块——没有之一。** 公式固定，题型固定，套路固定。掌握了就是 15-20 分到手。

**检查孩子是否真掌握的几个问题**：

1. **诱导公式背了 6 组？** → 如果是，说明还在死记。正确的状态是："奇变偶不变，符号看象限"一句话能推导所有情况。

2. **y=sin2x 到 y=sin(2x+1) 怎么移？** → 如果回答"左移 1"，说明对"平移是对 x 本身操作"的理解不到位。正确答案是"左移 1/2"。

3. **已知两边及对角求另一边，用正弦还是余弦？** → 用正弦（先求角）。如果回答余弦，说明对定理适用条件不清晰。

4. **解三角形时画图吗？** → 如果从来不画图，实际应用题一定会出错。好习惯是：拿到题目先画草图，标出已知量。

**刷题建议**：
- 近五年真题的三角部分全部刷两遍——第一遍练准确率，第二遍练速度
- 限时训练：一道三角解答题控制在 10 分钟内完成
- 每天 2 道恒等变换 + 1 道解三角形，维持手感，直到高考

> **高考三角函数送分，但不代表白送。公式要真理解、计算要零失误、套路要烂熟于心——这三条缺一不可。**

## 附录：核心公式速查

### 同角三角函数关系
- sin²α + cos²α = 1
- tanα = sinα/cosα

### 诱导公式口诀
"奇变偶不变，符号看象限"

### 两角和与差
- sin(α±β) = sinαcosβ ± cosαsinβ
- cos(α±β) = cosαcosβ ∓ sinαsinβ
- tan(α±β) = (tanα ± tanβ)/(1 ∓ tanαtanβ)

### 倍角公式
- sin2α = 2sinαcosα
- cos2α = cos²α - sin²α = 2cos²α - 1 = 1 - 2sin²α
- tan2α = 2tanα/(1 - tan²α)

### 半角公式
- sin²(α/2) = (1 - cosα)/2
- cos²(α/2) = (1 + cosα)/2

### 辅助角公式
- a sinx + b cosx = √(a²+b²) sin(x+φ)，tanφ = b/a（注意象限）

### 正弦定理
- a/sinA = b/sinB = c/sinC = 2R（R 为外接圆半径）

### 余弦定理
- a² = b² + c² - 2bc·cosA
- b² = a² + c² - 2ac·cosB
- c² = a² + b² - 2ab·cosC

### 三角形面积
- S = ½bc·sinA = ½ac·sinB = ½ab·sinC
- S = abc/4R（R 外接圆半径）
- S = ½(a+b+c)r（r 内切圆半径）
- S = √[p(p-a)(p-b)(p-c)]，海伦公式，p = (a+b+c)/2
