# 高考专题：数列

> 数列是高中数学中"最像编程"的模块——递推就是循环，求和就是累加。约 10-15 分，中等难度，核心考查"递推"思维。

---

## 一、高考考纲定位

| 项目 | 内容 |
|:----|:-----|
| 分值占比 | 约 8%-10%（约 12-15 分） |
| 常见题型 | 选择 1 道 + 填空 1 道 + 解答 1 道 |
| 解答题位置 | 第 17/18 题位置（偶尔与不等式/导数综合成压轴） |
| 难度 | 中等，区分度适中 |
| 核心思维 | **递推** 和 **求和** 两种 |

> 数列大题通常位于解答题前两题，是必须拿满分的板块。如果出现在压轴位置，往往是与不等式放缩的综合。

## 三、核心概念深度拆解

### 1. 递推思维——数列的本质

> 数列不是"一堆数"，而是"一个规则"——给定前一项或几项，如何得到下一项。这是高中数学第一次正式研究"递推"思维。

- **递推关系**：给出 aₙ 与 aₙ₊₁（或前几项）之间的关系式
- **通项公式**：用含 n 的式子直接表示第 n 项
- **递推与通项的关系**：递推是过程（怎么做），通项是结果（是什么）

例：`a₁ = 1, aₙ₊₁ = aₙ + 2`（递推）→ `aₙ = 2n - 1`（通项）

> 理解递推是理解数列的起点。如果一个孩子能说清楚"给我前一项，我能算出下一项"，就说明他真正理解了。

### 2. 等差数列 vs 等比数列——两种最基础的变化模式

#### 对比表

| 对比项 | 等差数列 | 等比数列 |
|:------|:--------|:--------|
| 定义 | aₙ₊₁ - aₙ = d（常数） | aₙ₊₁ / aₙ = q（常数，q ≠ 0） |
| 变化方式 | 加同一个数（线性增长） | 乘同一个数（指数增长） |
| 通项公式 | aₙ = a₁ + (n-1)d | aₙ = a₁ · qⁿ⁻¹ |
| 前 n 项和 | Sₙ = n(a₁ + aₙ)/2 = na₁ + n(n-1)d/2 | Sₙ = a₁(1-qⁿ)/(1-q)（q≠1）；Sₙ = na₁（q=1） |
| 中项 | 2A = a + b（等差中项） | G² = a·b（等比中项） |
| 下标和性质 | m+n = p+q → aₘ + aₙ = aₚ + a_q | m+n = p+q → aₘ · aₙ = aₚ · a_q |
| 函数视角 | aₙ 是关于 n 的一次函数 | aₙ 是关于 n 的指数型函数 |

#### 等差数列的常用性质

- 若 {aₙ} 是等差，则 {kaₙ + b} 也是等差
- 若 {aₙ} 是等差，则 Sₙ, S₂ₙ - Sₙ, S₃ₙ - S₂ₙ 成等差（公差 n²d）
- aₙ = kn + b（k 为公差 d，b = a₁ - d）

#### 等比数列的注意点

> 等比数列的核心陷阱只有一个：**q=1 的情况必须单独讨论**。考试中凡是没有说明 q≠1 的，都要分类讨论。

- 等比数列中，所有项同号（q>0时）或正负交替（q<0时）
- 若 {aₙ} 是等比且各项为正，则 {log aₙ} 是等差
- Sₙ, S₂ₙ - Sₙ, S₃ₙ - S₂ₙ 成等比（公比 qⁿ）

### 3. 等差 / 等比数列的判定

四种判定方法（由易到难）：

**等差判定：**
- **定义法**（最根本）：aₙ₊₁ - aₙ = d（常数）→ 等差
- **中项法**：2aₙ = aₙ₋₁ + aₙ₊₁（n≥2）→ 等差
- **通项法**：aₙ = kn + b → 等差（k 为公差）
- **求和法**：Sₙ = An² + Bn → 等差（公差 2A）

**等比判定：**
- **定义法**（最根本）：aₙ₊₁ / aₙ = q（常数，q≠0）→ 等比
- **中项法**：aₙ² = aₙ₋₁ · aₙ₊₁（n≥2）→ 等比
- **通项法**：aₙ = k · qⁿ（k ≠ 0）→ 等比
- **求和法**：Sₙ = A(qⁿ - 1)（q≠1）→ 等比

> 定义法是万能解法，其他方法都是定义法的推论。用定义法证明最稳妥，阅卷最认可。

### 4. 数列求和——四种核心方法

> 高考数列大题几乎必考求和。四种方法中，裂项相消和错位相减是高频考点。

#### 裂项相消

把一项拆成两项的差，使中间项正负抵消。

**基本形式：**
- `1/(n(n+1)) = 1/n - 1/(n+1)`
- `1/(n(n+k)) = 1/k  (1/n - 1/(n+k))`
- `1/((2n-1)(2n+1)) = 1/2  (1/(2n-1) - 1/(2n+1))`

**根式裂项：**
- `1/(√n + √(n+1)) = √(n+1) - √n`

> 裂项的关键是"系数"——拆出来的两项与原来的分子要对齐。最常见的错误就是漏掉前面的系数 1/k。

#### 错位相减

处理"等差 × 等比"型的数列求和。设 {aₙ} 为等差，{bₙ} 为等比，求 `cₙ = aₙ · bₙ` 的前 n 项和。

**标准步骤：**
1. Sₙ = a₁b₁ + a₂b₂ + ... + aₙbₙ
2. q  Sₙ = a₁b₂ + a₂b₃ + ... + aₙbₙ₊₁
3. (1 - q)Sₙ = a₁b₁ + (a₂ - a₁)b₂ + ... + (aₙ - aₙ₋₁)bₙ - aₙbₙ₊₁
4. 化简得 Sₙ

> 错位相减是高考数列大题的标准考法。练到闭着眼睛都能做——第一步写 Sₙ，第二步乘公比右移一位，第三步相减，第四步整理。

**常见陷阱：**
- 相减后中间的公差 d 要提出来写成等比数列求和
- 最后一项是 -aₙbₙ₊₁，符号别弄反
- 数清楚等比求和的项数

#### 分组求和

当通项可以拆成两个或多个数列的和时，分别求和再合并。

例：aₙ = 2ⁿ + n → 一个等比 + 一个等差

#### 并项求和 / 奇偶分析

当通项有正负交替规律时，两两合并。

例：aₙ = (-1)ⁿ · n → 相邻两项和为 1 或 -1

### 5. 递推数列的构造法

> 构造法（aₙ₊₁ = paₙ + q 型）是数列中最优雅的方法——一个简单的"换元"就能把陌生问题变成熟悉问题。

#### 类型一：aₙ₊₁ = paₙ + q（p ≠ 1, q ≠ 0）

设 aₙ₊₁ + λ = p(aₙ + λ)，解出 λ = q/(p-1)

则 {aₙ + λ} 是等比数列，公比 p。

**例：** a₁ = 1, aₙ₊₁ = 2aₙ + 3
设 aₙ₊₁ + λ = 2(aₙ + λ) → λ = 3
则 {aₙ + 3} 是等比，aₙ + 3 = 4 · 2ⁿ⁻¹ → aₙ = 2ⁿ⁺¹ - 3

#### 类型二：aₙ₊₁ = paₙ + f(n)

- 若 f(n) 是多项式：用待定系数法构造
- 若 f(n) 是指数形式：两边同除 pⁿ⁺¹ 或同除 f(n+1)

#### 类型三：aₙ₊₁ = (p · aₙ) / (q · aₙ + r)

**取倒数**：1/aₙ₊₁ = (q·aₙ + r) / (p·aₙ) = q/p + r/p · 1/aₙ

化为 1/aₙ 的递推，回到类型一。

#### 类型四：aₙ₊₁ = aₙ^p

**取对数**：lg(aₙ₊₁) = p · lg(aₙ)

化为 lg(aₙ) 的等比数列。

### 6. 数列与不等式的综合

这是数列的难点，通常出现在压轴位置。

**常见放缩技巧：**
- **裂项放缩**：把通项放大或缩小成可裂项的形式
- **等比放缩**：把通项放大成等比数列，用等比求和放缩
- **利用函数单调性**：构造函数证明数列单调有界

**例：** 证明 1/1² + 1/2² + ... + 1/n² < 2
放缩：1/k² < 1/(k(k-1)) = 1/(k-1) - 1/k（k≥2）

## 四、高考核心题型

### 题型 1：等差 / 等比基本量计算

**核心思路：** 已知几个条件，列方程组解 a₁, d（或 q）

**步骤：**
1. 设出首项 a₁ 和公差 d（或公比 q）
2. 根据已知条件列出关于 a₁, d（或 q）的方程
3. 解方程组

**示例：** 等差数列 {aₙ} 中，a₂ + a₅ = 16，a₃ · a₄ = 28，求 aₙ

**陷阱：** 注意等比数列 q 可能有多个解，需要验证是否满足所有条件

### 题型 2：等差 / 等比判定证明

**核心思路：** 用定义法证明 aₙ₊₁ - aₙ 为常数（或 aₙ₊₁/aₙ 为常数）

**步骤：**
1. 写出 aₙ₊₁ 的表达式
2. 计算 aₙ₊₁ - aₙ（或 aₙ₊₁/aₙ）
3. 化简后说明其为常数

**示例：** 已知 a₁ = 2, aₙ₊₁ = 2aₙ + 1，证明 {aₙ + 1} 是等比数列

**陷阱：** 证明等比时，要说明 aₙ ≠ 0 且比值是常数（不能含有 n）

### 题型 3：已知 Sₙ 求 aₙ

> 这是最基本、最常考的题型，必须刻进 DNA。

**公式：** aₙ = Sₙ - Sₙ₋₁（n ≥ 2），a₁ = S₁

**步骤：**
1. n = 1 时，a₁ = S₁
2. n ≥ 2 时，aₙ = Sₙ - Sₙ₋₁
3. 验证 a₁ 是否满足 n ≥ 2 的通项
4. 若不满足，写成分段形式

**示例：** Sₙ = n² + n，求 aₙ
a₁ = 2，n ≥ 2 时 aₙ = (n² + n) - [(n-1)² + (n-1)] = 2n
a₁ 满足，故 aₙ = 2n

**陷阱：** 忘记 n ≥ 2 的条件，或忘记验证 n = 1

### 题型 4：裂项相消求和

**适用对象：** 通项是分式，分母是两项乘积

**步骤：**
1. 将通项拆成两项的差
2. 逐项写出前几项，观察抵消规律
3. 写出最终结果

**常见裂项公式：**
- 1/(n(n+1)) = 1/n - 1/(n+1)
- 1/(n(n+2)) = 1/2(1/n - 1/(n+2))
- 1/((2n-1)(2n+1)) = 1/2(1/(2n-1) - 1/(2n+1))
- 1/√n + 1/√(n+1) = √(n+1) - √n

> **陷阱：系数！系数！系数！** 分母相差 k 就要乘以 1/k。

### 题型 5：错位相减求和

**适用对象：** 等差 × 等比（如 aₙ = (2n-1) · 2ⁿ）

**步骤：**
1. 写出 Sₙ = ...
2. 两边同乘公比 q，右移一位对齐
3. 两式相减
4. 右边的等比部分求和
5. 化简整理

**示例：** aₙ = (2n-1) · 2ⁿ，求 Sₙ
Sₙ = 12¹ + 32² + 52³ + ... + (2n-1)2ⁿ
2Sₙ = 12² + 32³ + ... + (2n-3)2ⁿ + (2n-1)2ⁿ⁺¹
相减得 -Sₙ = 2 + 2(2² + 2³ + ... + 2ⁿ) - (2n-1)·2ⁿ⁺¹
整理得 Sₙ = (2n-3)·2ⁿ⁺¹ + 6

**陷阱：** 相减后中间也是等比数列求和，项数是 n-1 项而不是 n 项

### 题型 6：递推求通项（构造法）

**适用对象：** aₙ₊₁ = paₙ + q 型

**步骤：**
1. 设 aₙ₊₁ + λ = p(aₙ + λ)
2. 展开得 aₙ₊₁ = paₙ + (p-1)λ
3. 比较得 (p-1)λ = q → λ = q/(p-1)
4. {aₙ + λ} 是等比数列
5. 求出 aₙ + λ，再移项得 aₙ

**示例：** a₁ = 1, aₙ₊₁ = 3aₙ - 2
λ = (-2)/(3-1) = -1
aₙ₊₁ - 1 = 3(aₙ - 1)
{aₙ - 1} 是等比数列，aₙ - 1 = 0·3ⁿ⁻¹ = 0
aₙ = 1（常数列，验证正确）

**陷阱：** λ 的符号容易设错，展开后对照原递推验证

### 题型 7：数列最值

**适用对象：** 求 Sₙ 的最大值或最小值

**方法一（二次函数法）：** Sₙ = dn²/2 + (a₁ - d/2)n，是 n 的二次函数
**方法二（正负分界法）：** 找出数列项的正负分界点

**示例：** 等差 aₙ = 27 - 3n，求 Sₙ 的最大值
aₙ ≥ 0 → n ≤ 9，所以前 9 项都是正的
S₉ 最大，S₉ = (27 + 0) × 9/2 = 121.5

**陷阱：** 二次函数法要注意 n 是正整数，对称轴不一定刚好是整数

### 题型 8：数列与不等式

**适用对象：** 证明数列前 n 项和 ≤ 某值

**核心方法：**
- **放缩法**：把通项放大/缩小成可求和的形式
- **数学归纳法**：当放缩失效时使用

**示例：** 证明 1/1² + 1/2² + ... + 1/n² < 2

### 题型 9：周期数列

**适用对象：** 递推中有常数项导致循环

**步骤：**
1. 多算几项，观察是否重复
2. 找出周期 T
3. 利用周期性求第 n 项

**示例：** a₁ = 1, aₙ₊₁ = 1 - 1/aₙ
算得 a₁=1, a₂=0（无定义）→ 此递推要小心定义域

### 题型 10：奇偶项数列

**适用对象：** 递推公式分奇偶

**步骤：**
1. 分别写出 n 为奇数和偶数时的表达式
2. 分别处理奇数项和偶数项
3. 有时需要分别求奇偶各自的通项

**示例：** a₁ = 1, aₙ₊₁ = aₙ + 2n（n 为奇）、aₙ₊₁ = aₙ + 2n - 1（n 为偶）

## 五、易错点速查

| 易错点 | 正解 | 常见错误 |
|:-------|:-----|:---------|
| aₙ = Sₙ - Sₙ₋₁ 的 n 范围 | n ≥ 2，单独验证 n=1 | 直接当通项不验证首项 |
| 等比数列 q=1 | q=1 时是常数列，求和为 na₁ | 直接套 a₁(1-qⁿ)/(1-q)，分母为 0 |
| 裂项系数 | 1/(n(n+2)) = 1/2(1/n - 1/(n+2)) | 漏了系数 1/2 |
| 错位相减的项数 | 中间等比求和共 n-1 项 | 数错项数 |
| 构造法 λ 的符号 | aₙ₊₁ + λ = p(aₙ + λ) 展开后与原式对照 | 设错 λ 的符号 |
| 等差数列前 n 项和最值 | d<0 时前几项和最大，看正负分界点 | 用导数思维求极值 |
| 等比中项的符号 | G² = a·b，G 与 a,b 同号 | G = ±√(ab) 不检验符号 |
| 使用 -1 的 n 次方 | (-1)ⁿ 的规律是 n 为奇→-1，n 为偶→1 | 搞反奇偶 |
| 递推中 n 的范围 | 注意递推式的定义域，避免分母为 0 | 不去验证就继续算 |

## 六、跨专题关联

| 关联专题 | 关联方式 | 典型题 |
|:---------|:---------|:-------|
| **函数** | 数列是定义在正整数集上的函数 | aₙ = f(n) 的单调性、最值 |
| **不等式** | 放缩法证明、求和后比较大小 | 证明 Sₙ < 某值 |
| **导数** | 数列型不等式、导数证明单调性 | 用导数证明 aₙ₊₁ > aₙ |
| **解析几何** | 点列在曲线上，坐标满足数列关系 | 点 Pₙ(aₙ, bₙ) 在抛物线上 |
| **三角函数** | 周期数列与三角函数的周期性 | aₙ = sin²(nθ) 的求和 |
| **概率统计** | 概率递推模型 | 马尔可夫链型概率问题 |
| **向量** | 向量运算中构造数列 | 向量线性递推求通项 |

> 数列的跨专题结合能力很强，尤其是"数列 + 不等式"和"数列 + 概率递推"是近年高考的热门方向。

## 七、给家长的提醒

> 数列是高中数学中"最像编程"的模块——递推就是循环，求和就是累加。如果孩子数列学得好，往往说明他具备"按规则执行多步操作"的思维习惯。

1. **递推思维是关卡**
   - 数列的核心不是背公式，而是理解"已知前面，推出后面"
   - 可以类比生活中的"排队"——知道第一个人和前后关系，就能算出所有人的位置

2. **错位相减必须练到肌肉记忆**
   - 高考数列大题的标准考法，概率极高
   - 步骤固定、套路清晰，是"只要练就能拿满分"的题型
   - 建议连续练 10 道同类型题，直到不出任何错误

3. **构造法是最优雅的换元**
   - aₙ₊₁ = paₙ + q 型构造是数列中最大的思维亮点
   - 核心思想："把陌生的递推变成熟悉的等比"
   - 如果孩子能独立想通这一步，说明他已经具备了"转化化归"的数学思维

4. **不要忽略等比数列 q=1 的讨论**
   - 这是数列中最经典的扣分点
   - 考试中凡是等比数列，都要问自己一句：q 可能等于 1 吗？

5. **数列是区分"刷题有效"和"刷题无效"的标尺**
   - 数列的题型高度套路化：裂项、错位、构造都有固定步骤
   - 只要方法对路，提分效果立竿见影
   - 反之，不理解原理只背公式，稍微变形就做不出来

6. **建议的学习路径**
   - 第一步：熟练掌握等差/等比的基础计算和性质
   - 第二步：死磕四种求和方法，尤其是错位相减和裂项相消
   - 第三步：掌握构造法三种基本类型
   - 第四步：数列与不等式的放缩训练（这是冲高分的门槛）

---

> **一句话总结：数列 = 递推找规律 + 求和方法论。套路固定、提分容易，是高考数学性价比最高的板块之一。**
