## 一、整册定位

选择性必修第二册的核心只有一个——**导数**。

导数是高中最重要的数学工具，也是高考压轴题的核心。

**核心任务：理解"变化率"——函数在每一个点的"瞬时变化速度"**

```
初中：一条直线的斜率 = 这个函数变化的速度
高中：导数 = 曲线在每个点的"瞬时斜率"
```

**一句话：导数是"变化"的数学描述。**

## 三、各章底层逻辑

### 第5章 导数——"变化"的数学语言

**核心：导数 = 函数在某一点的"变化率"**

$$
f'(x) = \lim_{\Delta x \to 0} \frac{f(x+\Delta x) - f(x)}{\Delta x}
$$

**物理意义：** 位移 $s(t)$ 对时间 $t$ 的导数 = 速度 $v(t)$

**几何意义：** $f'(x_0)$ = 曲线在 $(x_0, f(x_0))$ 处的切线斜率

**三个核心应用：**

1. **判断单调性**
   - $f'(x) > 0$ ⇒ 函数递增
   - $f'(x) < 0$ ⇒ 函数递减

2. **求极值**
   - $f'(x_0) = 0$ ⇒ $x_0$ 可能是极值点
   - 极值点两侧导数符号相反

3. **求切线**
   - 过曲线上一点 $(x_0, y_0)$ 的切线方程：
   - $y - y_0 = f'(x_0)(x - x_0)$

**胡小群追问：**
> 为什么 $f'(x) > 0$ 意味着递增？——斜率 > 0，表示曲线在这一点是"向上走"的。这是直观的。
>
> 但更重要的问题是：为什么有时候 $f'(x_0) = 0$ 了，$x_0$ 却不是极值点？
> 比如 $f(x) = x^3$，在 $x=0$ 处导数为 0，但这是"拐点"不是极值——因为导数在 0 左右两边没有变号。
>
> 这个细节就是高考压轴题常见的出题点。

**常见函数的求导公式（必须背熟）：**
$$
(x^n)' = nx^{n-1}, \quad (\sin x)' = \cos x, \quad (\cos x)' = -\sin x
$$
$$
(e^x)' = e^x, \quad (\ln x)' = \frac{1}{x}
$$

### 推理与证明——数学归纳法

**核心：先证明 n=1 成立，再假设 n=k 成立推 n=k+1 成立**

数学归纳法是高中最精妙的证明方法之一——像"多米诺骨牌"一样，推倒第一张牌，后面全部倒下。

## 五、常见错误

| 错误 | 原因 |
|:----|:----|
| 求导公式记混 | 公式不够熟练——每天默写一遍 |
| 极值点判断失误（把拐点当极值） | 没有检验极值点左右导数的符号 |
| 复合函数求导忘记链式法则 | 求导过程中跳步 |

## 六、给家长的提醒

**导数综合题（高考压轴题）是孩子可能遇到的第一个"做不出来就是做不出来"的题型。**

```
前面的题——没思路，看看答案就会了
导数压轴——看了答案，也不一定理解为什么要这么想
```

这不是孩子的错。导数压轴题本身要求的就是"数学思维的高度"。能做出来的学生，不是"多刷了题"，是**函数概念理解得足够深**。

**所以高一学函数时如果"混过去了"，到了导数压轴题阶段就现原形了。**
