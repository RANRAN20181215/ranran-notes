# 高考专题：立体几何

> 高考分值约 18-22 分，中等难度。拿满的关键不是空间想象——是建构清晰的推理体系和掌握向量法这个"通法"。

---

| 项目 | 内容 |
|:----|:-----|
| 分值占比 | 约 12-15%，约 18-22 分 |

## 三、核心概念深度拆解

### 3.1 平行关系的判定与性质

**平行链（变换路径）：**

```
线线平行 ──(判定)──→ 线面平行 ──(判定)──→ 面面平行
     ↑                                    │
     └──────────(性质)─────────────────────┘
     
 面面平行 ──(性质)──→ 线面平行 ──(性质)──→ 线线平行
```

| 类型 | 判定（条件→结论） | 性质（条件→结论） |
|:----|:-----------------|:-----------------|
| 线面平行 | 平面外一直线平行于平面内一直线 → 该直线平行于此平面 | 一直线平行于一平面，过该直线的平面与已知平面相交 → 该直线平行于交线 |
| 面面平行 | 一平面内两条**相交**直线都平行于另一平面 → 两平面平行 | 两平面平行，第三个平面与它们相交 → 两条交线平行 |

> **关键：** 证线面平行，就是"在平面内找一条线跟已知直线平行"。辅助线的常见做法是中位线或平行四边形。

**例：** 已知正方体 ABCD-A₁B₁C₁D₁，E、F 分别为 BB₁、B₁C₁ 中点。
求证：EF ∥ 平面 ACD₁。

**步骤：**
1. 连接 BC₁（辅助线）
2. 在 △BB₁C₁ 中，E、F 为中点 → EF ∥ BC₁（中位线）
3. 又 AD₁ ∥ BC₁（正方体对面平行）→ EF ∥ AD₁
4. AD₁ ⊂ 平面 ACD₁，EF ⊄ 平面 ACD₁
5. ∴ EF ∥ 平面 ACD₁

> **注意：** 步骤 3 完成"线线平行"后，一定要说明"一条在平面内，一条在平面外"，这是最容易丢分的地方。

### 3.2 垂直关系的判定与性质

**垂直链（变换路径）：**

```
线线垂直 ──(判定：两条相交)──→ 线面垂直 ──(判定)──→ 面面垂直
     ↑                                          │
     └──────────────(性质)───────────────────────┘

 面面垂直 ──(性质：交线垂线)──→ 线面垂直 ──(性质)──→ 线线垂直
```

| 类型 | 判定（条件→结论） | 性质（条件→结论） |
|:----|:-----------------|:-----------------|
| 线面垂直 | 一条直线垂直于平面内两条**相交**直线 → 该直线垂直于该平面 | 一条直线垂直于一个平面 → 该直线垂直于平面内任意直线 |
| 面面垂直 | 一个平面过另一个平面的垂线 → 两平面垂直 | 两平面垂直，一个平面内垂直于交线的直线 → 垂直于另一个平面 |

> **核心：** 线面垂直是垂直体系的核心——它是证面面垂直的"原料"，又是面面垂直的"产物"。

**三垂线定理及其逆定理：**

- **三垂线定理：** 平面内的一条直线，如果和这个平面的一条斜线的射影垂直，那么它也和这条斜线垂直。
- **逆定理：** 平面内的一条直线，如果和这个平面的一条斜线垂直，那么它也和这条斜线的射影垂直。

> 三垂线定理是处理二面角的利器，但在新高考中不再要求记忆定理名称，重在理解其本质——**垂影→垂斜** 的关系。

**例：** 四棱锥 P-ABCD 中，底面为矩形，PA ⊥ 底面 ABCD。
求证：平面 PAD ⊥ 平面 PCD。

**步骤：**
1. ∵ PA ⊥ 底面 ABCD，CD ⊂ 底面 ABCD
2. ∴ PA ⊥ CD（线面垂直性质：垂线垂直于平面内任意直线）
3. 又矩形中 AD ⊥ CD，PA ∩ AD = A
4. ∴ CD ⊥ 平面 PAD（线面垂直判定：垂直两条相交直线）
5. CD ⊂ 平面 PCD
6. ∴ 平面 PAD ⊥ 平面 PCD（面面垂直判定：过垂线）

### 3.3 空间向量法——解决一切立体几何问题的"通法"

> 向量法是立几大题的保底方法。空间想象再差，只要算得对，一样满分。

**建立坐标系的原则：找"三垂直"**

找一个点作为原点，三条两两垂直的线作为坐标轴。常见模型：
- 长方体/正方体：天然三垂直，直接用顶点建系
- 直棱柱：用底面的两条垂直边 + 侧棱
- 三棱锥：找底面的高 + 底面两条垂线

**核心公式表：**

| 求什么 | 公式 | 说明 |
|:------|:----|:-----|
| 方向向量 | 两点的坐标差 | AB = OB - OA |
| 法向量 | 方程组解（叉积法更快） | n = v₁ × v₂ |
| 线线角 | cosθ = \|v₁·v₂\| / (\|v₁\|\|v₂\|) | 取绝对值，θ ∈ [0, π/2] |
| 线面角 | sinθ = \|v·n\| / (\|v\|\|n\|) | **这里是 sin，不是 cos！** |
| 面面角 | cosθ = \|n₁·n₂\| / (\|n₁\|\|n₂\|) | 锐二面角取绝对值 |
| 点到面距离 | d = \|AP·n\| / \|n\| | P 为面上一点，A 为目标点 |

> **线面角的记忆口诀：** "线面角，法向量，sin 值，别忘掉"——很多孩子用 cos 然后改半天改不出来。

**法向量的快速计算（叉积法）：**

已知平面内两个不共线向量 a = (x₁, y₁, z₁)，b = (x₂, y₂, z₂)：

       n = a × b = (y₁z₂ - z₁y₂,  z₁x₂ - x₁z₂,  x₁y₂ - y₁x₂)

> 这个公式比解方程组快得多，选择题中直接套。

---

### 3.4 几何法 vs 向量法的选择

| 对比维度 | 几何法 | 向量法 |
|:--------|:------|:-------|
| 是否需要空间想象 | 需要 | 基本不需要 |
| 计算量 | 小 | 大 |
| 卡住概率 | 较高（辅助线找不到就完） | 低（建立坐标系就能做） |
| 书写量 | 少 | 多 |
| 适用范围 | 小题、部分证明 | 大题、角度距离计算 |

> **高考策略：**
> - **选择题/填空题** → 优先几何法（快且准），算不出的用向量法备选
> - **解答题** → 优先向量法（稳定拿分），建系→求向量→套公式，三步走
> - 几何证明题中，如果有中点，优先考虑中位线法

### 3.5 体积与表面积

| 几何体 | 表面积（侧 + 底） | 体积 |
|:------|:-----------------|:-----|
| 柱体（棱柱/圆柱） | S侧 = Ch（C 为底面周长） | V = Sh |
| 锥体（棱锥/圆锥） | S侧 = (1/2)Cl（l 为斜高） | V = Sh/3 |
| 台体（棱台/圆台） | S侧 = (1/2)(C + C')l | V = (S' + S + √(S'S))h/3 |
| 球 | S = 4πR² | V = 4πR³/3 |

**等体积法（换底法）：**

求点到平面的距离时，把锥体的顶点换成不同的点，利用同一个锥体体积不变列方程：

V = Sh/3 → h = 3V/S（S 是底面面积，h 是顶点到底面的距离）

> **举例：** 求三棱锥 A-BCD 中，A 到平面 BCD 的距离。
> 1. 算出三棱锥 A-BCD 的体积 V（换一个更容易算的底面和高）
> 2. 算出 △BCD 的面积 S
> 3. d = 3V/S

> 等体积法是求点到面距离最快的方法，比向量法更快，建议小题中使用。

### 3.6 球的"切"与"接"——高考几何小题最难题

"切"和"接"是立体几何中两个容易混淆的概念：
- **外接球**：球在几何体外面，几何体的所有顶点都在球面上（球包住几何体）
- **内切球**：球在几何体里面，球与几何体的所有面相切（球在几何体里面）

**1. 长方体的外接球（最重要）**
长方体的体对角线 = 外接球的直径
公式：2R = √(a²+b²+c²)，其中 a,b,c 为长方体的三边长
特殊情况：正方体 2R = a√3

**2. 直棱柱的外接球**
转化为找"底面外接圆圆心 + 高的一半"
方法：底面的外接圆半径为 r，棱柱高为 h，则 R² = r² + (h/2)²

**3. 正四面体的外接球与内切球**
正四面体棱长为 a：
- 外接球半径 R = a√6/4
- 内切球半径 r = a√6/12
- R:r = 3:1（正四面体的重要性质）

**4. 圆锥的外接球**
过顶点和底面圆心的截面是等腰三角形
转化为求三角形外接圆半径

**5. 补形法——最常用的技巧**
把不规则的几何体"补"成长方体或正方体
典型例子：三棱锥的四个面都是直角三角形→补成长方体

**高考考法：**
- 通常在选择题中出现，属于中档偏难题
- 核心思路：找球心位置→建立勾股关系→求半径
- 球心位置判断口诀："外接球心在体心，内切球心在重心"

### 3.7 截面问题

**截面作图的三条公理：**
1. 两个平面相交，交线是一条直线
2. 如果一条直线上的两个点在一个平面内，则整条直线都在这个平面内
3. 不共线的三点确定一个平面

**作图步骤：**
1. 找截面与几何体表面的交点
2. 连接同一面内的两个交点（得交线）
3. 利用平行关系延长交线（截面与平行面的交线平行）
4. 重复直到截面闭合

> 截面题的突破口通常是两个面交线的延**长相遇**。

**截面面积计算：**
- 确定截面形状（三角形、四边形、五边形……）
- 计算各边长（利用勾股定理或相似三角形）
- 用海伦公式或分割法求面积

## 四、高考核心题型

### 题型 1：三视图还原

**方法：** "长对正、高平齐、宽相等"

**步骤：**
1. 三视图对齐：正视图与侧视图同高，正视图与俯视图同长，俯视图与侧视图同宽
2. 俯视图定底面形状和位置
3. 正视图定高度和前后遮挡关系
4. 侧视图辅助确认左右层次

**例：** 某几何体三视图为正三角形（正视图）、等腰三角形（侧视图）、圆加圆心（俯视图），问是什么几何体？

解：俯视图为圆 → 底面为圆形；正视图为正三角形 → 高与底面直径的关系。
综合判断：圆锥。

> **易错：** 三视图中的虚线表示被遮挡的轮廓线。还原时一定要**把虚线对应的结构画出来**，否则会漏。

---

### 题型 2：表面积与体积计算

**方法：** 直接套公式，关键在于正确识别几何体的类型

**步骤：**
1. 读题提取几何体类型及其尺寸参数
2. 确认是否要减去/加上某个部分（组合体问题）
3. 代入公式计算

**例：** 圆台上下底面半径分别为 2 和 4，母线长为 5，求体积。

解：h = √(5² - (4-2)²) = √21
V = (1/3)π·√21·(4 + 16 + 8) = 28√21π/3

> **易错：** 圆台的母线不是高，需要先用勾股定理求高。

---

### 题型 3：平行垂直证明（几何法）

**方法：** 判定定理 + 辅助线

**关键思路：**
- 证平行 → 在目标平面内找一条平行线（中位线、平行四边形对边）
- 证线面垂直 → 在平面内找两条**相交**直线与已知直线垂直
- 证面面垂直 → 找一个平面的一条垂线在另一个平面内

> **易错：** 很多孩子证线面垂直时，只找了平面内的一条直线，忘了要"两条相交直线"。

---

### 题型 4：异面直线所成角

**几何法（平移法）：**
1. 将其中一条直线平移，使两直线相交
2. 构造三角形
3. 用余弦定理求角

**向量法：**
1. 取两直线的方向向量 v₁, v₂
2. cosθ = |v₁·v₂| / (|v₁||v₂|)
3. θ = arccos(cosθ)

> **注意：** 异面直线夹角范围是 (0°, 90°]，是锐角或直角。如果向量点积算出来是负数，取绝对值就是了。

---

### 题型 5：线面角

**几何法（垂线法）：**
1. 过线上一点作平面的垂线
2. 连接垂足和斜足（得射影）
3. 斜线和射影的夹角即为线面角
4. 在直角三角形中求角

**向量法：**
1. 求直线的方向向量 v
2. 求平面的法向量 n
3. sinθ = |v·n| / (|v||n|)
4. θ = arcsin(结果)

> **易错：** 线面角用 sinθ = |cos⟨v,n⟩|，不是 cosθ！很多孩子错在这里。

---

### 题型 6：二面角

**几何法：**
- **定义法：** 在棱上取一点，分别在两个面内作棱的垂线
- **三垂线法：** 过一个面内一点作另一个面的垂线，再利用三垂线定理

**向量法：**
1. 求两个平面的法向量 n₁, n₂
2. cosθ = |n₁·n₂| / (|n₁||n₂|)（锐二面角）
3. 如果要判断二面角是锐角还是钝角，看两个法向量的"朝向"

> **二面角的正负判断：** 观察法向量 n₁ 和 n₂ 的方向，如果都指向二面角内部或都指向外部，则 θ = π - arccos(cosθ)；如果一个指向内部一个指向外部，则 θ = arccos(cosθ)。实际做题中，大部分题目要的是锐角。

---

### 题型 7：点到面距离

**等体积法（小题）：**
1. 以目标点为顶点，目标平面为底面构造锥体
2. 换底算出体积
3. d = 3V/S

**向量法（大题）：**
1. 求平面的法向量 n
2. 在平面上任取一点 P，计算向量 AP（A 为目标点）
3. d = |AP·n| / |n|

> 大题两种写法都行，但向量法的书写更规范、更容易拿步骤分。

---

### 题型 8：截面问题

**方法：** 公理法 + 平行线性质

**步骤：**
1. 确定截面上的已知点
2. 如果两点在同一面上，连接得交线
3. 利用"截面与平行面的交线平行"这一性质
4. 延长交线到几何体边缘，直到截面闭合

**例：** 正方体 ABCD-A₁B₁C₁D₁ 中，过 A、C₁、B₁ 三点的截面是什么形状？

解：
1. 连接 AC₁——不在同一条棱上，放一放
2. 观察发现这三个点分别是三个不同面的顶点
3. 连接 B₁C₁ 和 A₁B₁ 的辅助点
4. 截面是经过这三点的平行四边形

> **易错：** 连接不在同一面上的两个点时，要先判断它们的连线是否在几何体的某一个面上。

---

### 题型 9：最短路径（展开图）

**方法：** 侧面展开为平面图形 → 两点之间线段最短

**步骤：**
1. 确定要展开的侧面
2. 沿某条棱剪开铺平
3. 将起点和终点在展开图上标出
4. 连接两点，用勾股定理求长度

**例：** 圆柱高 4，底面半径 1，从底面边缘 A 点到侧面以上边缘 B 点（正上方）的最短路径。

解：侧面展开为矩形（长 2π，高 4），A 和 B 在矩形上的对应点连接，用勾股定理求斜边。

> 展开问题关键是：**沿着哪条棱剪**。选对了就是一道勾股定理题，选错了会非常复杂。

---

### 题型 10：外接球与内切球

| 题型 | 方法 | 难度 |
|:----|:----|:----:|
| 外接球/内切球半径 | 补形法/截面法/公式法 | ★★★★ |

**方法：** 找球心→建立勾股关系→求半径

**核心公式速查：**
- 长方体/正方体外接球：2R = √(a²+b²+c²)
- 直棱柱外接球：R² = r² + (h/2)²
- 正四面体外接球：R = a√6/4
- 正四面体内切球：r = a√6/12

**关键技巧：**
- 补形法把不规则几何体补成长方体/正方体
- 截面法通过截面把空间问题转化为平面三角形问题
- 球心位置口诀："外接球心在体心，内切球心在重心"

> **注意：** 外接球问题是高考小题中的"压轴题"，补形法是破解这类问题最有效的武器。

## 五、易错点速查

| 易错点 | 正解 | 常见错误 |
|:-------|:-----|:---------|
| 线面角公式选错 | sinθ = \|cos⟨v,n⟩\| | 用 cosθ = \|cos⟨v,n⟩\| |
| 二面角正负号 | 看法向量"朝向"；大部分题目求锐角 | 直接取绝对值，不论实际大小 |
| 三视图还原 | 俯视图定底面、正视图定高；虚线表示被遮挡轮廓 | 漏掉虚线对应的结构 |
| 锥体体积 | V = Sh/3 | 忘了除以 3 |
| 台体体积 | V = (S'+S+√(S'S))h/3 | 只用(S'+S)h/2 近似 |
| 异面直线夹角范围 | (0°, 90°] | 当成相交角 > 90° |
| 证线面垂直 | 需平面内**两条相交**直线 | 只找了一条直线 |
| 证面面平行 | 需一个面内两条**相交**直线平行于另一个面 | 只找了一条或两条平行线 |
| 球的截面 | 截面圆半径 r = √(R² - d²) | 直接用 R 当截面圆半径 |
| 法向量 Z=0 | 检查是否计算错误 | 盲目把 Z=0 代进去算 |
| 向量点积 | 对应坐标相乘再相加 | 漏项或错位相乘 |
| 中点坐标 | ((x₁+x₂)/2, (y₁+y₂)/2, (z₁+z₂)/2) | 忘记了除以 2 |

## 六、跨专题关联

| 关联专题 | 具体结合点 |
|:---------|:-----------|
| **平面向量** | 空间向量是平面向量的推广，向量公式基本一致 |
| **解三角形** | 余弦定理在异面直线夹角、截面三角形中大量使用 |
| **解析几何** | 空间中的线面关系在坐标系中的表示，本质是"升维"的解几 |
| **函数与导数** | 最值问题：体积最大、表面积最小、距离最短（导数为工具） |
| **不等式** | 基本不等式与几何体最值（如给定表面积求最大体积） |
| **复数** | 复数的三角形式可以辅助理解空间旋转（拓展视野，非考点） |

**常见跨题型：**

1. **立体几何 + 函数最值：** 一个圆锥内接一个圆柱，当圆柱的高为多少时体积最大？
   - 设变量 → 建立函数关系 → 导数或基本不等式求最值

2. **立体几何 + 解三角形：** 三棱锥中已知几个面的边长和角度，求某个面面积
   - 先用空间关系确定要求的量 → 再用正余弦定理解平面三角形

## 七、给家长的提醒

> **立体几何不是"天才学科"，是"训练学科"。**

1. **初中平面几何没学好，高中立几一定吃力**
   - 这不是空间想象的问题，是推理能力的问题。
   - 平面几何中的全等、相似、中位线、平行四边形判定等，在立几辅助线中大量使用。
   - 如果孩子初中几何底子薄，先补平面几何再攻立几。

2. **"空间想象能力差"通常只是借口**
   - 向量法是绕过空间想象的"最优解"——只要会算坐标，不用想象也能做出来。
   - 大部分孩子不是想象不出来，而是**懒得画图**。不画图直接想，神仙也做不到。
   - 告诉孩子：画图是立体几何的第一生产力。每次做题，先画图（不要求美观，关键是自己能看懂）。

3. **立几证明写不清楚？让他理清"三段论"**
   - 每步推理都要明确：条件是什么 + 用了什么定理 + 结论是什么。
   - 举例："∵ PA ⊥ 底面 ABCD，CD ⊂ 底面 ABCD，由线面垂直性质，得 PA ⊥ CD"——这就是完整的三段论。
   - 让孩子把所用的定理名称写在旁边，练几道题就熟了。

4. **高考立几大题（第 18/19 题）是"保分题"**
   - 分值约 12 分，是整个试卷中最有把握的题目之一。
   - 目标是：**拿满分，不丢分**。
   - 如果孩子在这道题上失分，通常不是不会做，而是：
     - 建系不规范（原点没标、轴方向没写）
     - 坐标算错了（符号出错）
     - 公式记混了（线面角用 cos）
   - 这些都是可训练、可纠正的。

5. **学习顺序建议**
   - 第 1 步：熟记所有公式（表面积、体积、向量公式），每天默写一遍
   - 第 2 步：练三视图还原（10 道题打基础）
   - 第 3 步：练向量法建系计算（10 道大题，每道都完整写下来）
   - 第 4 步：练几何法证明（找平行、找垂直——10 道经典题）
   - 第 5 步：刷综合卷（高考真题，限时完成）

6. **常见心理建设**
   - "我空间想象差" → 没关系，向量法不需要想象
   - "辅助线太难找" → 常用辅助线就那么几种：中位线、底面垂线、连接对角线
   - "计算太容易错" → 向量法的计算要像解方程一样一步一步写，不要跳步
   - "证明写不全" → 三步走：条件 → 定理 → 结论，每步都写全

> **一句话总结：** 立体几何不是拼天赋，是拼规范。
> 建系正确 + 坐标准确 + 公式对号 = 满分。
> 几何法锦上添花，向量法保底上岸。
