# 高考专题——复数

> 复数在高考中约 5 分，必考 1 道选择题，是所有模块里最简单的，属于"白送分"。只要不粗心，这 5 分必须拿满。

---

| 项目 | 内容 |
|:----|:-----|
| 分值占比 | 约 3-5%（约 5 分） |

## 三、核心概念

### 1. 虚数单位 i

i² = -1 是复数的基石，**这是高考中唯一必须刻在脑子里的公式**。

> 每年都有学生把 i² 写成 1，这 5 分丢得太冤枉了。

| 幂次 | 结果 | 规律 |
|:----|:----|:-----|
| i¹ | i | i |
| i² | -1 | -1 |
| i³ | -i | -i |
| i⁴ | 1 | 1 |
| i⁵ | i | 循环周期为 4 |

**记忆口诀**：i 的幂次循环 4 — i, -1, -i, 1 重复。

### 2. 复数的表示

复数的标准形式：**z = a + bi**（a, b ∈ R）

- a 称为**实部**（记作 Re(z)）
- b 称为**虚部**（记作 Im(z)）
- 注意：虚部是 b，不是 bi

**纯虚数**：a = 0, b ≠ 0，即 z = bi

**两个复数相等当且仅当实部和虚部分别相等**。复数是不能比较大小的（模可以比）。

> 跟孩子说清楚：一个复数就像一对有序实数 (a,b)，两个数对相等就是各自相等。

### 3. 四则运算

**加法**：z₁ + z₂ = (a₁ + a₂) + (b₁ + b₂)i

**减法**：z₁ − z₂ = (a₁ − a₂) + (b₁ − b₂)i

> 加减法一句话：实部算实部，虚部算虚部，各算各的。

**乘法**：像多项式乘法展开，然后用 i² = -1 化简

```
(a + bi)(c + di) = ac + adi + bci + bdi²
                 = (ac − bd) + (ad + bc)i
```

**除法**：分母有理化——分子分母同时乘分母的共轭

```
(a + bi) ÷ (c + di) = (a + bi)(c − di) / (c² + d²)
```

> 除法是高考最常考的运算，考试时让孩子注意：乘完共轭后分母一定是实数，别化简到一半发现分母还有 i。

### 4. 共轭复数

若 z = a + bi，则 z̄（z 的共轭）= a − bi

| 性质 | 公式 |
|:----|:-----|
| 实部相同 | Re(z̄) = Re(z) = a |
| 虚部相反 | Im(z̄) = −Im(z) = −b |
| 自身共轭 | z = z̄ ⟺ b = 0（z 是实数） |
| 乘积 | **z · z̄ = a² + b² = \|z\|²** |
| 加和 | z + z̄ = 2a（实数） |

> z·z̄ = |z|² 是复数最常用的恒等式，贯穿所有复数运算。建议让孩子默写 5 遍再动手做题。

### 5. 复数的模

|z| = √(a² + b²)

几何意义：复平面上点 (a, b) 到原点 (0, 0) 的距离。

**模的性质**：

| 性质 | 公式 |
|:----|:-----|
| 非负性 | \|z\| ≥ 0，\|z\| = 0 ⟺ z = 0 |
| 乘积的模 | \|z₁·z₂\| = \|z₁\|·\|z₂\| |
| 商的模 | \|z₁/z₂\| = \|z₁\|/\|z₂\|（z₂ ≠ 0） |
| 共轭的模 | \|z̄\| = \|z\| |

### 6. 复数的几何意义

每个复数 z = a + bi 对应复平面上唯一的点 (a, b)：

- **实轴**（横轴）：表示实数
- **虚轴**（纵轴）：表示纯虚数
- 复数 z 也可以看作从原点指向点 (a, b) 的向量

| 几何量 | 公式 | 含义 |
|:-------|:-----|:-----|
| 模 \|z\| | √(a²+b²) | 向量的长度 |
| 辐角 θ | arctan(b/a) | 向量与实轴正方向的夹角 |

**高考常见题型**：给复数运算结果，问对应点在第几象限。

### 7. 实系数一元二次方程在复数范围内的解

对于 ax² + bx + c = 0（a ≠ 0, a,b,c ∈ R）：

- Δ > 0 → 两个不相等实根
- Δ = 0 → 两个相等实根
- **Δ < 0 → 一对共轭虚根**

虚根公式：

```
x = [−b ± √(|Δ|)·i] / (2a)
      = −b/(2a) ± [√(4ac−b²)/(2a)]·i
```

> 记住一个重要结论：实系数方程的虚根一定成对出现，且互为共轭。这是高考的常考知识点。

## 四、高考核心题型

### 题型 1：复数运算（直接计算）

**例题**：复数 z 满足 z(1 + i) = 2i，求 z。

**解法**：
```
z = 2i / (1 + i)
  = 2i(1 − i) / [(1 + i)(1 − i)]
  = 2i(1 − i) / 2
  = i(1 − i)
  = i − i²
  = i + 1
  = 1 + i
```

| 步骤 | 要点 |
|:----|:-----|
| ① 移项 | 把含有 z 的项单独放一边 |
| ② 乘共轭 | 分母 a+bi 就乘 a−bi |
| ③ 用 i²=−1 | 化简分子中的 i² |
| ④ 约分 | 分母变成实数，直接约掉 |

### 题型 2：复数相等

**考法**：已知 (a + bi)(c + di) = x + yi，求实数 a, b 等参数。

**核心**：左边展开后，实部 = 实部，虚部 = 虚部，解二元一次方程组。

**例题**：若 (1 + i)(a + bi) = 3 + i，其中 a, b ∈ R，求 a + b。

```
左边 = a + bi + ai + bi²
    = a + bi + ai − b
    = (a − b) + (a + b)i

∴ (a − b) + (a + b)i = 3 + i

实部相等：a − b = 3
虚部相等：a + b = 1

解得：a = 2, b = −1
∴ a + b = 1
```

### 题型 3：共轭复数

**考法**：已知 z 或 z̄，求相关表达式。

> 最常见的考法：给 z·z̄ 与 z + z̄ 的值，反求实部和虚部。核心就是联立 z·z̄ = |z|² 和 z + z̄ = 2a。

**例题**：设复数 z 满足 z·z̄ = 25 且 z + z̄ = 6，求 z。

```
设 z = a + bi，则：
z·z̄ = a² + b² = 25
z + z̄ = 2a = 6 → a = 3
∴ 9 + b² = 25 → b² = 16 → b = ±4

所以 z = 3 + 4i 或 z = 3 − 4i
```

### 题型 4：模的计算

**考法**：求 |z₁·z₂|、|z₁/z₂|、|z − 1| 等。

**思路**：用公式 |z| = √(a²+b²) 直接算，或用模的性质简化。

**例题**：|z − 1 + i| 的最小值，其中 z 在复平面单位圆上 |z| = 1。

> 这种题用几何法——模就是距离，|z − (1 − i)| 是单位圆上的点到点 (1,−1) 的最短距离。

|z| = 1 的圆，圆心 O(0,0)，半径 r = 1，到点 P(1,−1) 的距离 OP = √2
最短距离 = OP − r = √2 − 1

### 题型 5：复数几何意义

**考法**：给出复数运算，判断对应点在第几象限。

**核心方法**：化简出 z = a + bi，然后看 a, b 的符号。

| a 符号 | b 符号 | 象限 |
|:------|:------|:-----|
| a > 0 | b > 0 | 第一象限 |
| a < 0 | b > 0 | 第二象限 |
| a < 0 | b < 0 | 第三象限 |
| a > 0 | b < 0 | 第四象限 |

**例题**：复数 z = i(2 − i) 在复平面内对应的点在第几象限？

```
z = i(2 − i) = 2i − i² = 2i + 1 = 1 + 2i
a = 1 > 0, b = 2 > 0 → 第一象限
```

### 题型 6：复数范围内解方程

**考法**：Δ < 0 的情况，求方程的解。

**公式速记**：

```
x² + 1 = 0 → x = ±i
x² + x + 1 = 0 → x = (−1 ± √3·i)/2
```

**例题**：求方程 x² − 4x + 13 = 0 在复数范围内的解。

```
Δ = (−4)² − 4·1·13 = 16 − 52 = −36
√|Δ| = √36 = 6

x = [4 ± 6·i] / 2 = 2 ± 3i

方程的解为 x = 2 + 3i 和 x = 2 − 3i（一对共轭虚根）
```

## 五、解题卡壳自查清单

> 孩子做题卡住了，按这个顺序查：

| 步骤 | 检查 | 常见错误 |
|:----|:-----|:---------|
| ① | i² 有没有写成 1？ | 这是最最最常见的错误 |
| ② | 除法分母乘共轭了吗？ | 只乘了分子，分母没乘 |
| ③ | 纯虚数条件写全了吗？ | 只注意 b≠0，忘了 a=0 |
| ④ | 复数相等列方程了吗？ | 直接目测，漏了条件 |
| ⑤ | 共轭的虚部符号写对了吗？ | z̄ = a − bi，不是 a + bi |
| ⑥ | 模的平方算对了吗？ | \|z\|² = a² + b²，不是 a² + (bi)² |

## 六、易错点汇总

| 易错点 | 错误写法 | 正解 |
|:-------|:---------|:-----|
| i² 符号 | i² = 1 | **i² = −1** |
| 除法忘乘共轭 | 分母的 i 没消掉 | 分母 a+bi 就乘 a−bi |
| 纯虚数条件 | 只看 b≠0 | **a=0 且 b≠0**，缺一不可 |
| 模的平方 | a² + (bi)² | **a² + b²**（虚部 b 不带 i） |
| 共轭符号 | 把实部也变了 | 实部不变，只变虚部符号 |
| 方程虚根 | 忘了 ± | 虚根成对出现，答案必须写两个 |
| i 的幂次 | 硬算浪费时间 | 用周期 4，i^n → n mod 4 |
| 复数比较 | 写 3+2i > 1+i | **复数不能比大小** |

## 七、给家长的提醒

1. **复数是高考数学的送分题**，出现在试卷前几道，难度最低。大部分孩子出错不是因为不会，而是因为**不重视、粗心**。

2. **20 道题训练量就够了**。找近 5 年高考真题中所有复数题，让孩子集中刷一遍，正确率提到 100% 再停。

3. **最容易翻车的点**：
   - i² = −1 写成 1（每年都有人犯）
   - 除法分母忘记乘共轭
   - 纯虚数忘写实部 a = 0 这个条件

4. **五年级以下的娃不要碰复数**。虚数的概念需要有实数运算基础和代数思维，最早六年级暑假或初一可以接触。三年级到五年级的阶段，把实数四则运算练扎实更重要。

5. **每天练 1 道就够了**，不用安排大段时间。复数题做得快、准确率高就行，不值得花超过 3 天时间专门复习。

6. **目标**：看到复数题，5 秒判断题型，30 秒内出答案，不错。

```
i² = −1
z = a + bi
z̄ = a − bi
|z| = √(a² + b²)
z·z̄ = |z|² = a² + b²
|z₁·z₂| = |z₁|·|z₂|
|z₁/z₂| = |z₁|/|z₂|
x = [−b ± √(4ac−b²)·i] / (2a)   (Δ < 0)
```
