# 错题系统方法论

> 数学错题本怎么做才有效——不是抄题，是诊断概念漏洞
> 适用：3 年级及以上的学生

---

## 一、为什么大多数错题本没用

胡小群一针见血：

> **90% 的错题本最终变成了"抄题本"，然后被扔在角落里吃灰。**

```
典型的错题本：
  ❌ 题目抄一遍（浪费时间）
  ❌ 答案抄一遍（没有思考）
  ❌ 标注"粗心"（掩盖真实问题）
  ❌ 从来不再看（做了等于没做）
```

**错题本的真正目的不是"记录错误"，而是"诊断漏洞"——每道错题背后都有一个没搞懂的概念。**

---

## 二、错误的 5 种类型

不是所有错误都需要进错题本。先判断错了什么：

| 类型 | 标签 | 表现 | 怎么办 |
|:----|:----|:----|:------|
| 概念不清 | 🔴 概念 | 完全不知道怎么下手 | **需要进错题本**——重学概念 |
| 方法不对 | 🟡 方法 | 有思路但选错了方向 | **需要进错题本**——记录正确方法 |
| 计算失误 | 🔵 计算 | 思路对、算错了 | 每天 10 分钟计算专项，不进错题本 |
| 审题失误 | 🟢 审题 | 看错条件、漏看信息 | 圈关键词 + 复述题目，不进错题本 |
| 书写失误 | ⚪ 书写 | 字太乱自己看错了 | 练书写规范，不进错题本 |

**只有概念不清和方法不对才需要进错题本。计算、审题、书写问题——用专项训练解决。**

## 三、错题本的正确打开方式

### 第一步：判断是否值得记

```
做错的题 ↓
  是概念不清或方法问题？→ 进错题本
  是计算/审题/书写问题？→ 专项训练解决，不进
```

### 第二步：记什么（不是抄题）

**错误的三段式记录法：**

```
┌────────────────────────────────────────┐
│ 第 X 题                                  │
│                                          │
│ ① 题目（剪下来贴上，不要抄）              │
│                                          │
│ ② 我是怎么错的（写当时的真实想法）        │
│    当时觉得……所以用了……方法              │
│    但忽略了……条件                        │
│                                          │
│ ③ 正确思路（写"为什么"而不是"是什么"）    │
│    这道题的关键是……因此应该……            │
│    它和之前学过的 XX 概念有关              │
│    下次遇到类似题应该想……                │
└────────────────────────────────────────┘
```

**关键：② 和 ③ 是对比着写的——"我原来怎么想的"vs"应该怎么想"。**

### 第三步：复习（最重要的步骤）

```
错误的复习方式：
  平时不翻 → 考试前翻一遍 → 考试时不会的还是不会

正确的复习方式：
  当天：记完错题，重做一遍（遮住答案）
  3 天后：重新做一遍
  周末：这一个星期的错题过一遍
  月末：这一个月的错题再过一遍
```

### 第四步：判断"真的会了"

> 一道错题，什么时候可以从错题本里"毕业"？
>
> 标准：**连续 3 次重新做都做对了，而且能讲清楚每一步为什么。**

讲清楚"为什么"比做对更重要。

## 四、不同学科的错题差异

### 数学错题的特殊性

数学错题和其他学科不同——**数学错题往往是"连锁反应"：**

```
一道二次函数综合题错了 →
  根本原因可能是：
    配方法不熟（八年级问题）
    因式分解不过关（七年级问题）
    甚至是一元一次方程移项符号问题（七年级问题）

所以数学错题不要只在"表面"记——要往"底层"挖
```

### 挖到底的方法

问孩子三个"为什么"：

```
为什么这道题错了？
  → 我配方配错了
为什么配方会配错？
  → 我忘了怎么配
为什么忘了怎么配？
  → 我完全平方公式没记住 → 真正的根源在这里！
```

## 五、错题本的高阶用法

### 建立"错误模式"档案

当错题积累到一定程度，回头看看——是不是有固定的"错误模式"？

```
常见错误模式：
  ① 看到"比……多"就做加法（不一定——要看主语）
  ② 看到"平方"就开方（不一定——要看是否涉及负数）
  ③ 看到"方程"就用公式法（不一定——因式分解更快）

发现自己的"错误模式"后，写上大字警示贴在书桌前。
```

### 错题的"概念归因"

把每道错题关联到一个具体的概念：

```
错题：解方程 x² = 9，写了 x = 3
概念归因：平方根的概念不清——漏了负根
关联概念段：八上实数——平方根与算术平方根
```

这样可以发现：**自己哪一章的概念最薄弱**——然后针对性复习。

## 六、给家长的操作指南

### 各年级怎么做

| 年级 | 角色 | 怎么做 |
|:----|:----|:------|
| 1-2 年级 | 家长主导 | 家长帮孩子发现"总是错的一类题"——不记错题本 |
| 3-4 年级 | 家长引导 | 教孩子三段式记录法，家长帮剪题目 |
| 5-6 年级 | 共同管理 | 孩子自己记，家长检查"②和③"写没写 |
| 初中 | 孩子自主 | 家长只提醒——"这周错题复习了吗" |
| 高中 | 完全自主 | 孩子自己管理 |

### 低年级可以不记错题本

> **1-2 年级不需要错题本。**
>
> 这个阶段的问题基本是"熟练度不够"——多练几次就好。
> 需要家长在脑子里记住"孩子哪种题容易错"，而不是让孩子自己记。

### 家长最该问的一句话

> **不要问"这道题订正了吗"——要问"这道题错在哪，你想明白了没"。**

订正是动作，想明白才是结果。

## 七、错题本模板（可直接用）

```
┌─────────────────────────────────────────────────────┐
│ 日期：____年__月__日   来源：□作业  □考试  □练习   │
│                                                      │
│ ① 原题（贴/简写）：                                  │
│                                                      │
│                                                      │
│ ② 我的错误思路（当时怎么想的）：                     │
│                                                      │
│                                                      │
│ ③ 正确思路：                                        │
│                                                      │
│                                                      │
│ ④ 概念归因（和哪个知识点有关）：                    │
│                                                      │
│ ⑤ 复习记录： □第1次 ✓  □第2次 ✓  □第3次 ✓ 毕业    │
└─────────────────────────────────────────────────────┘
```

**说明：**
- ⑤ 的"毕业" = 连续 3 次做对 + 能讲清为什么
- 一张纸记一道错题（方便分类和复习）
- 用不同颜色荧光笔标出错误类型
