# 第三单元 · 小说的多样化

> 外国小说四篇——四种叙事传统
> 4 课：大卫·科波菲尔 / 复活 / 老人与海 / 百年孤独

---

## 单元定位

**核心任务：接触四种不同传统的外国小说——现实主义到魔幻现实主义。**

```
必修下册学了中国小说（祝福/林教头/促织）
选择性必修上册学外国小说
  → 从 19 世纪到 20 世纪
  → 从写实到魔幻
  → 不同的叙事传统
```

---

## 11 大卫·科波菲尔（节选）— 狄更斯

### 文体
- 自传体小说（第一人称叙事）
- 19 世纪英国批判现实主义

### 背景

```
狄更斯的半自传体小说
  → 狄更斯童年曾因父亲欠债入狱 → 去工厂做童工
  → 这本书写的就是"一个孩子如何成长"

选段：大卫被送到工厂做童工
  → 小小年纪失去母亲 → 被继父虐待 → 被迫工作
```

### 考试要点

- **第一人称叙事的效果**——"我"的视角让读者感同身受
- **细节描写**——工厂的肮脏、工作的辛苦
- **狄更斯的风格**——幽默中带着悲悯

## 12 复活（节选）— 托尔斯泰

### 文体
- 长篇小说，俄国批判现实主义巅峰
- 托尔斯泰晚年代表作

### 背景

```
贵族聂赫留朵夫年轻时引诱了侍女玛丝洛娃
玛丝洛娃被赶出家门 → 沦落风尘 → 被冤枉入狱
聂赫留朵夫良心发现 → 去监狱看她 → 请求宽恕

选段：监狱相见
  → 聂赫留朵夫第一次见到被流放的玛丝洛娃
  → 玛丝洛娃已经不再是当年的少女
```

### "复活"的双重含义

```
聂赫留朵夫的"复活"：从道德堕落中觉醒
玛丝洛娃的"复活"：从绝望中找回尊严
→ 两个人在彼此救赎
```

### 考试要点

- **心理描写**——托尔斯泰最擅长的"心灵辩证法"
- **人物关系**——加害者和受害者的角色反转
- **托尔斯泰思想**——自我救赎、道德觉醒

## 13 老人与海（节选）— 海明威

### 文体
- 中篇小说，海明威代表作
- "冰山原则"的巅峰体现

### 背景

```
老渔夫圣地亚哥在海上 84 天没捕到鱼
第 85 天钓到一条大马林鱼 → 在海上搏斗三天
→ 终于杀死鱼 → 但鲨鱼来了 → 吃掉了鱼
→ 回到港口时只剩下一副骨架
```

### "冰山原则"

```
海明威的写作原则：
  "冰山在海面移动，看起来只有八分之一在水面上"

→ 文本只说了一小部分
→ 大部分含义藏在文字的"水下"
→ 读者需要自己去体会

比如：老人说"我不服输"
  表面上：一条鱼的故事
  水面下：人的尊严、坚持的意义
```

### 经典段落

```
"一个人可以被毁灭，但不能被打败。"
  → 这句话不是老人说出来的
  → 是整个故事呈现出的人生态度
```

### 考试要点

- **"冰山原则"的理解**——含蓄的写法
- **象征意义**——大海=世界，鲨鱼=命运，老人=不屈的人
- **独白**——老人自言自语 = 内心世界的展现
- **与大卫·科波菲尔对比**——英国现实主义的温暖 vs 美国"迷惘一代"的硬汉

---

## 14 百年孤独（节选）— 马尔克斯

### 文体
- 魔幻现实主义小说
- 加西亚·马尔克斯代表作，1967 年出版

### 魔幻现实主义

```
魔幻现实主义 = 在现实中有魔幻 + 在魔幻中有现实

比如选段中的"失眠症"：
  马孔多（虚构小镇）全城失眠 + 失忆
  → 魔幻（现实中有这种病吗？没有）
  → 但隐喻现实：一个民族如果失去了记忆，就会灭亡
```

### 考试要点

- **魔幻与现实的关系**——魔幻是手法，现实是内核
- **重复的名字**——全书七个"奥雷里亚诺"——宿命感
- **叙事的"循环感"**——马孔多的兴衰像循环
- **与老人与海的对比**——海明威是现代主义的一种，马尔克斯是后现代/魔幻

| 篇目 | 国别 | 流派 | 核心手法 |
|:----|:----|:----|:--------|
| 大卫·科波菲尔 | 英国 | 批判现实主义 | 第一人称+细节 |

| 老人与海 | 美国 | 象征主义 | 冰山原则 |
| 百年孤独 | 哥伦比亚 | 魔幻现实主义 | 魔幻+现实 |

```
四篇的共同线索：
  人面对困境时的选择
  → 大卫（坚持生活）
  → 聂赫留朵夫（自我救赎）
  → 老人（不被打败）
  → 马孔多人（抵抗遗忘）
```
