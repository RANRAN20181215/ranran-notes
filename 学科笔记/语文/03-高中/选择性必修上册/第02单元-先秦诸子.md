## 5 论语十二章

### 核心思想速览

```
"君子"与"仁"是贯穿《论语》的核心概念。

精选十二章覆盖：
  ① 君子与小人的对比
    "君子坦荡荡，小人长戚戚"
    "君子喻于义，小人喻于利"
  
  ② 仁的内涵
    "克己复礼为仁"
    "己所不欲，勿施于人"
  
  ③ 学习方法
    "学而不思则罔，思而不学则殆"
    "温故而知新"
  
  ④ 为人处世
    "不患人之不己知，患不知人也"
```

### 考试要点

- **固定句式**："不亦……乎"、"何……之有"
- **通假字**："女"通"汝"；"知"通"智"
- **对比阅读**：同一概念在不同章节的不同表达

## 6 大学之道

### 核心

```
"大学之道，在明明德，在亲民，在止于至善。"

三纲领 → 八条目：
  "格物→致知→诚意→正心→修身→齐家→治国→平天下"

最重要的是"修身"：
  "自天子以至于庶人，壹是皆以修身为本"
  → 修己是起点，治国平天下是终点
```

## 7 人皆有不忍人之心 — 孟子

### 核心

```
"人皆有不忍人之心"= 每个人都有一颗不忍心看别人受苦的心

四心→四端：
  恻隐之心 → 仁之端
  羞恶之心 → 义之端
  辞让之心 → 礼之端
  是非之心 → 智之端

→ 性善论的核心论证
→ 人不是被教育才变好的，人性本来就向善
```

### 考试要点

- **比喻论证**："孺子将入于井"——看见小孩要掉井里，人人都会去救
- **四端→四德**的推导过程

## 8 老子四章

### 核心

```
老子思想的核心：道法自然、无为而治

四章对应：
  第 11 章：有与无的辩证
    "三十辐共一毂，当其无，有车之用"
    → 实体有用，虚空也有用
  
  第 24 章：不争
    "企者不立，跨者不行"
    → 急于求成的反而做不成
  
  第 33 章：知足
    "知足者富"
    → 真正的富有是知道满足
  
  第 64 章：慎终如始
    "民之从事，常于几成而败之。慎终如始，则无败事"
```

### 考点

- **辩证思维**——有无相依、福祸相依
- **与儒家的对比**——儒家"入世有为"vs 道家"无为而治"

## 9 五石之瓠 — 庄子

### 核心

```
故事：
  惠子说：有一棵大葫芦，因为太大，做不了水瓢 → 废物
  庄子说：为什么不把它做成船？大葫芦=大船

→ "无用之用"的哲学
  你认为是废物 → 只是你没找到用途
  所谓"有用" = 在某个特定框架里"有用"
  跳出框架 → "无用"也可能"大用"
```

### 考点

- **寓言说理**——把抽象哲理用故事讲出来
- **对比**：惠子的实用主义 vs 庄子的超脱

---

## 10 兼爱 — 墨子

### 核心

```
"兼相爱，交相利"——没有差别的爱

墨子和儒家的区别：
  儒家：爱有差等（先爱家人，再爱别人）
  墨子：爱无差等（对所有人都一样爱）

→ 墨子的核心思想
→ 批评的是当时的社会问题（国与国相攻、家与家相乱）
```

## 单元总结

```
三家对比：
  儒家：仁爱 → 礼 → 修身齐家治国平天下（有为）
  道家：自然 → 无为 → 顺应道（无为）
  墨家：兼爱 → 非攻 → 交相利（实用）
```
