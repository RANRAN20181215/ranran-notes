# 选择性必修上册（统编版）

> 高二了——思辨能力决定一切
> 年级：高二上学期

---

## 一、整册定位

**核心任务：从"理解"到"辨析"**

```
高一：老师讲什么 → 我学什么
高二上：老师给材料 → 我自己分析
高二下：我自己找材料 → 我自己判断
高三：一切都是为了 150 分钟内的准确输出
```

选择性必修只有 4 个单元，比必修少了一半。
**不是因为内容变少了，而是因为每个单元的深度翻倍了。**

```
必修上册：8 个单元    → 每个单元 2-3 周
选择性必修上册：4 个单元 → 每个单元 3-4 周
```

### 第一单元：革命文化——从了解到了解为什么

**核心：不是"革命故事"，是"革命为什么能成功"**

这个单元和初中的革命题材不一样：

```
初中：李大钊很伟大 → 我感动了 → 懂了
高中：为什么在中国革命中，这些人愿意牺牲？
  → 革命文化的核心不是"苦难"，是"信仰"
  → 信仰的背后是：对国家出路的不同探索
```

**四篇文章的组织逻辑：**

| 篇目 | 时间节点 | 视角 | 文体 |
|:----|:--------|:----|:----|
| 中国人民站起来了 | 1949 开国大典 | 国家领袖 | 开幕词 |
| 长征胜利万岁 | 1936 长征结束 | 亲历者回忆 | 回忆录 |
| 大战中的插曲 | 1940 百团大战 | 战地故事 | 叙事散文 |
| 别了不列颠尼亚 | 1997 香港回归 | 记者现场 | 新闻特写 |

**从 1949 到 1936 到 1940 到 1997——时间线并不连续。**
这个单元的编排不是按顺序讲故事，而是**选取四个最能代表"革命精神"的瞬间**。

### 第二单元：先秦诸子——高二最难单元 🔴🔴

**核心：不是"读懂诸子"，而是"诸子之间的对话"**

这是整个高中语文最有深度、也最难的一个单元。

**结构：**

```
儒家：
  论语十二章 → 孔子：日常生活中的道
  大学之道 → 修身齐家治国平天下（政治哲学）
  人皆有不忍人之心 → 孟子：性善四端

道家：
  老子四章 → 老子：无为、不争、柔弱胜刚强
  五石之瓠 → 庄子：有用 vs 无用

墨家：
  兼爱 → 墨子：兼爱 vs 儒家"差等之爱"
```

**⚠️ 最大难点：诸子对同一个问题的回答不同。**

```
问：人与人应该怎么相处？

孔子：仁者爱人（推己及人，由近及远）
孟子：扩充四端（人人都有善的种子，浇水就好）
老子：小国寡民（最好不相往来）
庄子：相忘于江湖（各自逍遥）
墨子：兼相爱（不分远近，一视同仁）

→ 不是谁对谁错
→ 是"对同一个问题，不同流派给出了不同答案"
→ 高考考的是：你能不能说清楚"不同在哪里，为什么不同"
```

**学习方法：做辨析表**

| 问题 | 孔子 | 孟子 | 老子 | 庄子 | 墨子 |
|:----|:----|:----|:----|:----|:----|
| 人性 | 相近 | 本善 | 自然 | 自然 | 无善恶 |
| 治理 | 礼乐 | 仁政 | 无为 | 无为 | 尚贤 |
| 核心价值 | 仁 | 义 | 道 | 逍遥 | 兼爱 |

### 第三单元：外国小说——另一种叙事传统

**核心：外国小说和中国小说的叙事方式有什么不同？**

| 篇目 | 作家 | 国家 | 叙事特点 | 主题 |
|:----|:----|:----|:--------|:----|
| 大卫科波菲尔（节选） | 狄更斯 | 英国 | 第一人称成长叙事 | 社会批判 |
| 复活（节选） | 托尔斯泰 | 俄国 | 心理描写极其细腻 | 道德救赎 |
| 老人与海（节选） | 海明威 | 美国 | 冰山原则（简洁对话） | 人的尊严 |
| 百年孤独（节选） | 马尔克斯 | 哥伦比亚 | 魔幻现实主义 | 民族命运 |

**阅读建议：**

```
中国小说 → 关注"故事讲了什么"
外国小说 → 关注"故事是怎么讲的"

老人与海：
  中国小说会写：老人想什么（内心独白）、海什么样（环境描写）
  海明威只写：老人说什么、做什么
  剩下的让读者自己脑补——这就是"冰山理论"
```

### 第四单元：逻辑的力量——工具性单元

**核心：理性表达的基础**

```
本单元内容：
  - 概念的内涵和外延
  - 判断和推理
  - 演绎推理 vs 归纳推理
  - 常见的逻辑谬误
  
应用场景：
  作文中的逻辑严密性
  阅读中的逻辑分析
  日常思辨能力
```

**这个单元在高考中不单独考，但渗透在所有板块中——**
论述类文本阅读的本质就是逻辑分析，作文的逻辑链条直接影响分数档位。

## 四、本册最大挑战

| 难点 | 原因 | 应对 |
|:----|:-----|:-----|
| 🔴🔴 先秦诸子辨析 | 概念抽象 + 各家的回答不同 | 做辨析表，对比记忆 |
| ⚠️ 外国小说的叙事差异 | 文体陌生 + 翻译腔 | 先了解作家背景，再读正文 |

## 五、给家长的提醒

1. **高二的"诸子"是冉冉现在就可以埋下伏笔的**
   - 小学多读成语故事（画蛇添足、守株待兔→出自诸子）
   - 初中可以开始读《论语别裁》等轻松的解读
   - 到了高二就不会觉得诸子"晦涩"

2. **高二上的语文成绩可能仍然不高**
   - 选择性必修的评分标准比必修更严
   - 作文开始要求"思辨性"，不是"文采好"就行
   - 让孩子坚持每周一篇随笔，保持手感

3. **逻辑能力不是一天练成的**
   - 日常生活中的"杠精"反而是好事
   - 喜欢问"为什么"的孩子，逻辑不会差
