# 第一单元 · 复兴之路

> 从革命到建设——百年党史中的伟大转折
> 4 课：中国人民站起来了 / 长征胜利万岁 / 别了，"不列颠尼亚" / 县委书记的榜样

---

## 单元定位

**核心任务：了解中国革命和建设的伟大历程，体会不同文体的表达效果。**

```
本单元的几篇文章文体各不相同：
  开幕词 / 回忆录 / 新闻特写 / 通讯报道
  → 同一主题（中国革命与建设）
  → 同一精神（奋斗与奉献）
  → 不同文体（各有哪些特点？）
```

## 1 中国人民站起来了 — 毛泽东

### 文体
- 开幕词（1949 年 9 月 21 日，中国人民政治协商会议第一届全体会议）

### 核心分析

```
结构：
  第一段：会议的意义
    "占人类总数四分之一的中国人从此站立起来了"
  
  第二段：回顾历史
    一百多年来的斗争 → 终于胜利

  第三段：展望未来
    建设新中国 → 经济/文化/国防

语言特色：
  排比句：
    "我们的民族将……"
    "我们将……"
    "我们的朋友将……"
  
  气势磅礴的口语化书面语
```

## 2 长征胜利万岁 — 杨成武

### 文体
- 回忆录（杨成武将军回忆长征胜利）

### 核心分析

```
结构：
  以"到达陕北"为主线
  长征结束 → 与陕北红军会师 → 庆祝大会

重点段落：
  毛主席在大会上的讲话
    "长征是宣言书，长征是宣传队，长征是播种机"
  
  长征精神的总结：
    不怕牺牲、排除万难
```

## 3 别了，"不列颠尼亚" — 周婷、杨兴

### 文体
- 新闻特写（1997 年 7 月 1 日香港回归）

### 核心分析

```
标题的双关含义：
  "不列颠尼亚" = 英国皇家游轮的名字
  "别了" = 告别英国殖民统治

叙事特色：
  以时间线推进：
    下午 4:30 → 下午 6:15 → 下午 7:45 → 午夜 → 7 月 1 日零时

  全文没有一句抒情，但处处有情感
    用细节表达情感，不用议论
```

## 4 县委书记的榜样——焦裕禄 — 穆青等

### 文体
- 人物通讯（1966 年发表，影响了一代人）

### 核心分析

```
焦裕禄精神的核心：
  "心中装着全体人民，唯独没有他自己"

结构：
  治理"三害"——内涝/风沙/盐碱
  忍着病痛工作 → 最后牺牲

细节的力量：
  肝癌晚期还在工作
  藤椅被顶出了一个窟窿
  → 用细节震撼人心
```
