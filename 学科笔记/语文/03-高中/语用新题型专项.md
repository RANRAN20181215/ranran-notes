# 语用新题型专项

> 新高考"语言文字运用"20分的全部新考法
> 标点·近义词·语段综合·修辞进阶·句式变换·压缩语段

---

## 一、考纲定位

### 新高考三大变化

```
旧高考：单题独立——成语一题、病句一题、衔接一题，各自独立
新高考：语段综合——所有题目放在一个语段中，情境化考查
```

**核心变化：**
1. 从"单题独立"到"语段综合"——所有题共用一段材料
2. 新增标点符号作用题——冒号/破折号/引号/省略号等成为独立考点
3. 近义词辨析——"依次填入文中横线的词语"替代单纯的成语选择
4. 修辞效果分析——不只判断修辞类型，要分析"为什么用""好在哪里"
5. 句式变换/压缩语段——回归传统但放在语段情境中

### 分值 & 题型特点

| 项目 | 说明 |
|:----|:----|
| 总分 | 约 20 分（新课标全国卷） |
| 题量 | 5 道小题左右 |
| 材料 | 1 个语段（约 300-500 字） |
| 组合方式 | 每年微调，但语段综合不变 |
| 趋势 | 越来越强调"在语境中运用" |

> 语用题是整张卷子中性价比最高的板块——不需要大量知识储备，靠方法和训练就能拿满分。

## 二、标点符号作用专项

### 冒号 "："

| 作用 | 说明 | 示例 |
|:----|:----|:----|
| 引出下文 | 提示后面有解释/列举/引用 | 他有三句话要说：第一…… |
| 解释说明 | 前文较抽象，后面具体展开 | 他只有一个愿望：考上大学 |
| 总结上文 | 冒号前是列举，后是总结 | 语文、数学、英语：这三科他最拿手 |

> 高考常考"总结上文"，容易被忽略。

**真题示例：**
```
文中"我有三件事要提醒你：第一……"中冒号的作用是？
答：引出下文，表示后面是列举内容。
```

### 破折号 "——"

| 作用 | 说明 | 示例 |
|:----|:----|:----|
| 解释说明 | 对前文进行具体解释（最常考） | 他最喜欢一种运动——足球 |
| 话题转换 | 突然转到另一件事 | 今天天气真好啊——你吃饭了吗 |
| 声音延长 | 模拟拖长音 | "我们——回家——" |
| 列举分承 | 总说后的分项列举 | 三种方法——①……②……③…… |
| 语意递进 | 意思更进一步 | 他是——不，他是天才 |

> 破折号和冒号都可以表示"解释说明"，区别在于：冒号后的内容是对前面的补充展开，破折号后的内容是对前面的具体解释。高考选择题里这个区分是高频考点。

**真题示例：**
```
（2022年全国甲卷）"他又感觉那手——那只温暖的手——在她心上停留了很久"中破折号的作用是？
答：表示解释说明，具体说明是哪只手。
```

### 引号 " "（最常考）

| 作用 | 说明 | 示例 |
|:----|:----|:----|
| 直接引用 | 引用原话或原文 | 他说："我来了。" |
| 特殊含义 | 字面之外有特定意思 | 这种"文明"不过是野蛮的伪装 |
| 强调 | 突出重要内容 | 这就是所谓的"核心竞争力" |
| 反语讽刺 | 说反话，表否定 | 你可真是个大"好人"啊 |
| 特定称谓 | 专有名称/术语 | "嫦娥五号"成功发射 |

**高考考法有两种：**
1. 判断文中引号的作用
2. 选出"下列各句中的引号与文中引号作用相同的一项"

> 这是标点题中的最高频考点。关键是区分"特殊含义"和"反语讽刺"——反语带有明显贬义和否定态度，特殊含义是中性的。

**真题示例：**
```
（20xx年全国卷）文中的"聪明人"的引号作用是？
答：表示反语讽刺，指那些自以为聪明的人。
```

### 省略号 "……"

| 作用 | 说明 |
|:----|:----|
| 列举省略 | 列举未完，用法……、苹果……等 |
| 说话断断续续 | 犹豫/恐惧/虚弱时说话不连贯 |
| 语意未尽 | 话没说完，留给读者想象 |
| 沉默不语 | 表示无话可说 |

### 括号 "（）"

| 作用 | 说明 |
|:----|:----|
| 注释说明 | 对前文进行注释，不如破折号强烈 |
| 补充内容 | 补充时间/地点/出处等附加信息 |

> 括号内的内容是可以跳过去不读的（不是主干），而破折号后的内容常常是重点。

### 书名号 "《》"

| 作用 | 说明 |
|:----|:----|
| 作品名 | 书籍/文章/影视/歌曲等名称 |
| 文件名 | 法规文件/报告等 |
| 栏目名 | 报纸/电视/网站的栏目名称 |

> 书名号不能用于活动名称、奖项名称、课程名称等非作品类内容。

### 标点作用速查表

| 标点 | 最常考作用 | 一句话判断法 |
|:----|:----------|:-----------|
| 冒号 | 解释说明 / 总结上文 | 前总后分还是前分后总 |
| 破折号 | 解释说明 / 话题转换 | 删掉后意思变了没有 |
| 引号 | 特殊含义 / 反语讽刺 | 看是中性还是贬义 |
| 省略号 | 列举省略 / 语意未尽 | 看后面还有没有列举 |
| 括号 | 注释补充 | 去掉后句子通不通 |

## 三、近义词辨析

> 新高考用"依次填入文中横线的词语"替代了旧高考单独考成语选择题。选的是近义实词/虚词，不只成语。

### 辨析五维度（"五看法"）

**一看语义轻重：**
```
损坏 → 毁坏（程度加重）
请求 → 恳求（程度加重）
批评 → 批判（程度加重）
努力 → 竭力（程度加重）
```

**二看范围大小：**
```
事情（范围大） → 事件（范围小）
时代（范围大） → 时期（范围小）
局面（宏观） → 场面（微观）
边疆（大区域） → 边境（边界线附近）
```

**三看感情色彩：**
```
褒义：成果 / 果断 / 顽强 / 鼓舞
中性：结果 / 决断 / 坚强 / 鼓动
贬义：后果 / 武断 / 顽固 / 煽动
```

> 感情色彩要结合语境判断，有时候一个词在特定语境下会发生色彩变化。

**四看搭配对象：**
```
改善 + 生活 / 关系 / 环境
改进 + 方法 / 技术 / 工作
增加 + 数量 / 种类
增强 + 意识 / 能力 / 体质
履行 + 诺言 / 合同 / 义务
执行 + 任务 / 命令 / 计划
```

**五看语法功能：**
```
突然（形容词/副词）：突然事件 / 突然走了
猛然（副词）：猛然醒悟（不能修饰名词）
曾经（副词）：曾经去过
已经（副词）：已经完成
充分（形容词/副词）：充分的准备 / 充分发挥
充足（形容词）：阳光充足（不能修饰动词）
```

## 四、语段综合题专项

### 常见组合方式

**组合一：成语填空 + 病句修改 + 修辞分析**
```
第一步：先扫读语段，了解大意
第二步：成语填空——重点看上下文语境和搭配
第三步：病句修改——找主干，查搭配/语序/成分残缺
第四步：修辞分析——先判断修辞类型，再分析效果
```

**组合二：近义词选择 + 补写句子 + 句式变换**
```
第一步：近义词——从语义轻重/搭配/色彩三个维度排除
第二步：补写句子——看横线前后的逻辑关系（因果/转折/递进）
第三步：句式变换——注意不改变原意
```

**组合三：标点作用 + 语言表达 + 衔接排序**
```
第一步：标点题——回归原文，看标点前后句子是什么关系
第二步：语言表达——简明/连贯/得体，重点看前后照应
第三步：衔接排序——先找首句/尾句，再用代词/关联词逻辑定位
```

### 解题总策略

```
① 先通读语段，把握整体意思（30秒）
② 再逐题做，每道题回到原文定位
③ 不要跳着做，按顺序最有把握
④ 注意题目之间的关联——前面填的词后面可能用到
⑤ 做完后回看一遍，确认整体通顺
```

> 语段综合题的最大陷阱：各小题看似独立，实际上共用同一语境。前面选错了词可能导致后面理解出现偏差。

## 五、修辞效果进阶

> 新高考不满足于"判断修辞手法"，而是要求分析"为什么用这个修辞""有什么表达效果"。

### 答题公式

**比喻：** 把……比作……，生动形象地写出/表现/突出了……的……特点

**拟人：** 赋予……人的情感/动作/神态，使……更亲切/生动/鲜活

**排比：** 增强语势，层层递进，强调了……，使表达更有节奏感

**对偶：** 句式整齐，节奏感强，内容凝练，对比/呼应鲜明

**夸张：** 突出/强调……的特征，引发读者的联想，增强感染力

**反问：** 加强语气，发人深省，表达强烈的情感

**设问：** 引出下文，引起读者的思考，使文章有波澜

**借代：** 以……代指……，突出特征，语言更简洁生动

**通感：** 打通/打破……和……的感官界限，使描写更形象可感

**反复：** 强调/突出……，增强语气，强化情感

**对比：** 把……和……对比，突出……的……特点

**互文：** 前后文互相呼应补充，使表达更凝练

> 答题时三步走：判断修辞 → 结合原文分析 → 说明效果。不要只写"生动形象"，一定要写"生动形象地写出了什么"。

### 高频易混修辞辨析

```
比喻 vs 比拟（拟人）：
  - 比喻：本体+喻体（有"像""仿佛""好比"等比喻词，或暗喻直接用"是"）
  - 拟人：直接把物当人写（赋予人的动作/情感，不说"像人"）
  - 区分技巧：看到"像""仿佛"→比喻；看到"笑""说话""思考"→拟人

借喻 vs 借代：
  - 借喻：本体和喻体之间有相似性（可补为明喻）
  - 借代：借事物的特征代事物本身（不可补为明喻）
  - 区分技巧：能加"像"的是借喻，不能加"像"的是借代

排比 vs 对偶：
  - 排比：三个及以上结构相同/相似的句子
  - 对偶：两个结构严格对应的句子（字数相等、结构一致）
```

## 六、句式变换

### 长句变短句

```
步骤：
① 提取主干（主语+谓语+宾语）
② 拆分修饰语（定语/状语/补语各自成句）
③ 合理排序（按逻辑顺序或时间顺序）

口诀：先主干，再枝叶，拆开来，排好序
```

**示例：**
```
原文：他是一个在贫困山区工作了三十年的老教师。
① 主干：他是一个老教师。
② 拆分：他在贫困山区工作了三十年。
③ 排序：他是一位老教师，在贫困山区工作了三十年。
```

### 短句变长句

```
步骤：
① 确定主干句（常是最后一句或最重要的一句）
② 把其他短句变为修饰语（状语/定语）
③ 合理排序，注意语法通顺

口诀：定主干，变修饰，合一起
```

### 主动句变被动句/把字句

```
主动句：我把作业写完了。→ 把字句
作业被我写完了。→ 被动句

方法：调换主语和宾语的位置，加"把"或"被"
注意：不是所有主动句都能变为被动句，不及物动词不行
```

### 整句 vs 散句互变

```
散句变整句：
① 找一组并列的内容
② 统一结构（都用动宾/都用主谓/都用偏正）
③ 保持字数大致相当

整句变散句：
① 选一句做主干
② 其他的改为修饰语或补语
③ 不要硬凑对仗
```

> 整句变散句/散句变整句在新高考中偶尔出现，主要考语感。

### 陈述句变反问句

```
陈述句：这件事很重要。
反问句：难道这件事不重要吗？

加否定词法：
① 肯定句加"难道……不"+"吗/呢"
② 否定句加"难道"去掉"不"
注意：反问句比陈述句语气更强
```

### 句式变换总原则

> 变换句式不能改变原句意思。做完后一定要回读一遍，确认语义不偏差。

## 七、压缩语段 / 提取关键词

### 题型一：下定义

```
公式：被定义概念 = 种差 + 属概念

模板：……是……的……

示例：
将"人是能制造和使用工具的动物"写成下定义：
人（被定义概念）是能制造和使用工具（种差）的动物（属概念）

注意：
① 种差要写本质特征（不是所有特征）
② 不能用否定表述
③ 不能是比喻
```

### 题型二：新闻压缩

```
公式：时间 + 地点 + 人物 + 事件 + 结果

示例：
"2023年5月30日，神舟十六号载人飞船在酒泉卫星发射中心成功发射"
时间→2023年5月30日
地点→酒泉卫星发射中心
人物→神舟十六号/航天员
事件→发射
结果→成功

压缩为：2023年5月30日，神舟十六号在酒泉成功发射。
```

### 题型三：概括要点

```
步骤：
① 逐段提取中心句
② 合并同类信息
③ 删除具体事例/数据/修饰语
④ 控制字数

技巧：
· 关注首尾句（多数段落中心句在首句或尾句）
· 关注关联词（"因此""总之"后面常是结论）
· 删除"比如""例如"后的内容
· 保留"是""即""指"后面的核心定义
```

> 压缩的本质是"删"——先写全，再删到规定字数以内。宁多勿少，删的时候优先删除例证、修饰语、重复信息。

## 八、典型真题演示

### 真题一：语段综合（成语 + 病句 + 修辞）

```
语段：
    在互联网时代，"流量思维"成为一种普遍逻辑。很多人为了博取______（瞩目/关注），
不惜制造各种奇异言论。这种行为的背后，反映出的是人们对"被看见"的焦虑。然而，
真正的价值永远不依赖于短暂的流量。那些靠流量堆砌起来的内容，往往______（转瞬即逝/昙花一现），
而真正有深度、有温度的文字，才能经得起时间的______（考验/检验）。

题目：
1. 依次填入文中横线上的词语，最恰当的一组是（  ）
   A. 关注  转瞬即逝  考验
   B. 瞩目  昙花一现  检验
   C. 关注  昙花一现  考验
   D. 瞩目  转瞬即逝  检验

2. 文中画横线的句子"真正的价值永远不依赖于短暂的流量"运用了什么修辞手法？
   请简要分析其表达效果。

3. 文中画波浪线的句子有语病，请指出并修改。

参考答案：
1. C
   "关注"比"瞩目"更适合与前文"博取"搭配（博取关注）；
   "昙花一现"强调短暂出现就消失，比"转瞬即逝"更有文学色彩，与语境匹配；
   "考验"与"经得起"搭配，强调时间长度的检验。

2. 运用了对比的手法。
   将"真正的价值"与"短暂的流量"进行对比，鲜明地突出了真正价值的持久性
   和流量的短暂性，表达了作者对追逐流量现象的否定态度。

3. "很多人为了博取关注，不惜制造各种奇异言论"中，"制造"与"言论"搭配不当。
   修改为："捏造各种奇异言论"或"散布各种奇异言论"。
```

### 真题二：标点 + 近义词组合

```
语段：
    科学家们发现，有一种特殊的"鱼类"能够在极寒的南极海域生存。
这种鱼体内有一种天然的"防冻剂"——一种特殊的糖蛋白。正是这种物质，
让它们能够在零下的温度中______（自由/自如）活动。研究团队指出：
"如果能够人工合成这种物质，将会在食品保鲜领域产生深远影响。"

题目：
1. 第一段中"鱼类"的引号作用是什么？
   下列各项中，引号作用与此相同的是（  ）
   A. 他是一位真正的"天才"
   B. 这就是所谓的"文明"
   C. 他的"成功"不过是运气
   D. 这真是一个"了不起"的发现

2. 文中横线处应填入"自由"还是"自如"？请说明理由。

3. 文中破折号的作用是（  ）
   A. 解释说明
   B. 话题转换
   C. 声音延长
   D. 语意递进

参考答案：
1. 表示特殊含义，指不是真正意义上的鱼类（是特定种类的鱼）。
   与A项相同（A项的"天才"也是特殊含义，中性）。
   B为反语讽刺，C为反语讽刺，D为反语讽刺。

2. 应填"自由"。
   "自由"强调不受限制、随意，适合描述生物的活动状态；
   "自如"强调熟练自然、不费力（多用于人的技能动作）。

3. A。破折号后的"一种特殊的糖蛋白"是对"防冻剂"的解释说明。
```

### 真题三：句式变换 + 补写组合

```
语段：
    人工智能正在改变传统教育方式。过去，学生只能通过教师讲解和书本获取知识。
现在，AI可以个性化地分析每个学生的学习情况，_____________。
但专家指出，AI永远无法替代教师的情感陪伴和价值引导。

题目：
1. 将画线句子"过去，学生只能通过教师讲解和书本获取知识"改写为被动句。

2. 在文中横线处补写恰当的语句，使整段语意完整连贯，不超过15个字。

3. 文中最后一句"AI永远无法替代教师的情感陪伴和价值引导"如果改为反问句，
   应该怎样改写？改写后的语气有什么不同？

参考答案：
1. 在过去，知识只能通过教师讲解和书本被学生获取。

2. 答案示例：提供针对性（定制化）的学习方案
   （注意：要和前面的"分析"构成因果关系，语意连贯）

3. 改为反问句：AI难道能够替代教师的情感陪伴和价值引导吗？
   改写后语气更强，表达了不容置疑的态度，增强了说服力。
   陈述句语气平和客观，反问句语气强烈、带有反问意味。
```

## 九、易错点速查

| 易错点 | 正解 |
|:------|:-----|
| 标点作用和修辞判断混淆 | 先判断"是什么"，再分析"作用是什么" |
| 近义词只看语义不看搭配 | 要从语义/色彩/搭配三个维度综合判断 |
| 补写句子只写一句话不看前后 | 补写后通读一遍，检查逻辑是否通顺 |
| 句式变换改变了原意 | 变换句式不能改变原句意思（最重要原则） |
| 压缩语段删了关键信息 | 先写全，再删到规定字数；优先删除例证和修饰 |
| 修辞分析只写"生动形象" | 要写"生动形象地写出了……的……" |
| 病句找不到主干 | 先去掉状语/定语/补语，剩主谓宾再查 |
| 标点题不看上下文 | 标点作用完全取决于前后句的关系 |
| 通篇填成语靠语感 | 成语要拆开来理解每个字的含义 |
| 所有题一次性做完不复查 | 至少留2分钟回查语用题 |
