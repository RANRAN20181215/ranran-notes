# 信息类文本阅读简答专项

> 新高考"选择+简答"模式，简答占 6-12 分
> 原论述类+实用类合并为"信息类文本"，简答是最大变数

---

## 一、考纲定位

### 分值分布

| 题型 | 2021 新高考 I | 2022 新高考 I | 2023 新高考 I | 2024 新高考 I |
|:----|:-----------|:-----------|:-----------|:-----------|
| 选择题（3 道） | 9 分 | 9 分 | 9 分 | 9 分 |
| 简答题（2 道） | 6 分 | 6 分 | 6 分 | 6 分 |
| 总分 | 15 分 | 15 分 | 15 分 | 15 分 |

> 注意：2024 年起部分地区简答提至 8-12 分（如新课标卷 4+4，全国甲卷 6+6），趋势是简答比重持续上升。

### 三种考法及频率

| 考法 | 题型描述 | 出现频率 |
|:----|:--------|:--------|
| 论证分析 | 论证方法/论证思路/论证特点 | ★★★★★ 必考 |
| 内容理解 | 概括观点/分析原因/推断结论 | ★★★★☆ 高频 |
| 比较阅读 | 双文本角度/方法/观点比较 | ★★★☆☆ 趋势 |

### 和旧高考的区别

```
旧高考：论述类 3 道选择 + 实用类 3 道选择 → 纯选择题
新高考：信息类 3 道选择 + 2 道简答     → 选择+简答

核心变化：
  不再只是"判断对错"，而是"你要能说清楚为什么"
  "读出"→"读出+写出"的质变
```

## 二、论证方法系统梳理

> 这是简答的"原子能力"——所有简答题都建立在对论证方法的准确识别上

### 速查总表

| 序号 | 论证方法 | 判断标志 | 作用话术 |
|:---:|:--------|:--------|:--------|
| 1 | 举例论证 | 例如、比如、如、举……为例、诸如此类 | 通过列举……的具体事例，具体有力地论证了……观点，使论证更有说服力 |
| 2 | 引用论证 | 某某说、据……记载、……有云、研究表明、正如……所言 | 引用……的名言/数据/文献，权威有力地论证了……观点，增强说服力和可信度 |
| 3 | 对比论证 | 而、但、然而、与之相反、与此相对、反之 | 将……与……进行对比，突出强调了……观点，使论证更加鲜明深刻 |
| 4 | 比喻论证 | 如同、像、仿佛……一样（用于说理） | 将……比作……，生动形象地论证了……观点，使深奥的道理通俗易懂 |
| 5 | 因果论证 | 因为……所以、之所以……是因为、……导致……、其根源在于 | 从因果关系角度分析……，论证了……，使论证逻辑严密、环环相扣 |
| 6 | 类比论证 | 同样、类似、犹如、……也是如此、与之同理 | 将……与……进行类比，推论出……道理，使论证具有启发性和说服力 |
| 7 | 假设论证 | 如果……那么、假如……就、倘若……便会 | 从反面假设……（如果不这样），推论出……结果，有力论证了……的必要性/重要性 |
| 8 | 归谬法 | 如果……那么……就更荒谬了、难道……吗（驳论专用） | 先假设对方观点成立，然后推导出荒谬结论，从而驳倒对方观点，论证有力 |
| 9 | 演绎论证 | 引用权威理论/公理→分析具体情况→得出结论 | 从一般性原理出发，推导出具体结论，论证具有严密逻辑性和科学依据 |

### 各方法详解

#### 1. 举例论证

- **定义**：列举典型事例来证明论点
- **判断标志**："例如""比如""如""以……为例""诸如此类""试看"
- **答题话术**：通过列举……的具体事例，具体有力地论证了……的观点，使论证更具说服力
- **陷阱**：如果例子只是"提到"而没有"论证"某个观点，那它可能只是事实陈述，不是举例论证
- **示例**："以《红楼梦》为例，作者通过贾府的兴衰……"

#### 2. 引用论证

- **定义**：引用经典名言、权威数据、文献资料来证明论点
- **判断标志**："某某说""据……记载""有研究表明""正如……所指出的"
- **答题话术**：引用……的言论/数据，权威有力地论证了……的观点，增强论证的说服力和可信度
- **细分**：
  - 引用名言——增强权威性
  - 引用数据——增强科学性、精确性
  - 引用文献——增强可信度、有据可查

#### 3. 对比论证

- **定义**：将正反两方面或不同事物加以比较，突出观点
- **判断标志**："而""但""然而""与之相反""与此相对""反之""恰恰相反"
- **答题话术**：将……与……进行对比，突出强调了……，使论证更加鲜明深刻
- **易混淆**：对比论证 VS 类比论证
  - 对比：强调"不同"（A 与 B 相反/不同）
  - 类比：强调"相似"（A 与 B 同理/类似）

#### 4. 比喻论证

- **定义**：用比喻来说理，把抽象道理具体化
- **判断标志**："如同""像""仿佛""好比""正如……一样"（用于说理，不只是描写）
- **答题话术**：将……比作……，生动形象地论证了……，使深奥的道理通俗易懂
- **易混淆**：比喻论证 VS 比喻修辞
  - 比喻论证：服务于说理，目的是"论证观点"
  - 比喻修辞：服务于描写，目的是"让描写更生动"
  - **判断标准**：看这个比喻是不是在"讲道理"

#### 5. 因果论证

- **定义**：通过分析因果关系来论证观点
- **判断标志**："因为……所以""之所以……是因为""……导致……""其根源在于""……因此……"
- **答题话术**：从因果关系的角度分析了……，论证了……，使论证逻辑严密、环环相扣
- **注意**：因果论证可以是"由因推果"，也可以是"由果溯因"

#### 6. 类比论证

- **定义**：将性质相似的两种事物进行比较，由此及彼地推出道理
- **判断标志**："同样""类似""犹如""……也是如此""与之同理""就像……一样"
- **答题话术**：将……与……进行类比，推论出……道理，使论证具有启发性和说服力
- **易混淆**：类比论证 VS 比喻论证

| 维度 | 类比论证 | 比喻论证 |
|:----|:--------|:--------|
| 本质 | 同类事物间的比较推理 | 不同类事物间的形象化表达 |
| 目的 | 逻辑推理（由此及彼） | 形象化（变抽象为具体） |
| 例子 | "人类和灵长类动物一样，也有社会分工" | "文化犹如一座桥梁，连接着不同民族" |

#### 7. 假设论证

- **定义**：从反面进行假设，推出后果来证明论点
- **判断标志**："如果……那么""假如……就""倘若……便会""要是……的话"
- **答题话术**：从反面假设……，推导出……后果，从而论证了……的必要性/重要性
- **注意**：假设论证通常用于证明"如果不这样做，就会……"，从而反证"应该这样做"

#### 8. 归谬法

- **定义**：先假设对方观点正确，推出荒谬结论，从而驳倒对方（专用于驳论文）
- **判断标志**："如果……那么……岂不是/岂不/那就更荒谬了""难道……吗"
- **答题话术**：先假设对方观点成立，然后推导出……的荒谬结论，从而有力驳斥了……观点
- **典型结构**：假设→推导→荒谬→否定原假设

#### 9. 演绎论证

- **定义**：从一般性原理（公理、定理、普遍真理）出发，推导出具体结论
- **判断标志**：先引用权威理论/普遍原理，再分析具体对象
- **答题话术**：从……这一普遍原理出发，推导出……的具体结论，论证具有严密逻辑性
- **注意**：演绎论证的典型结构是"三段论"——大前提（一般原理）+ 小前提（具体对象）→ 结论

## 三、论证思路/行文脉络题

> 这是新高考简答最高频题型，几乎每年必考。

### 答题框架

```
首先，……（提出论点/引出话题/提出问题）
接着，……（展开论述/分析问题/论证观点）
然后，……（进一步论述/反面论证/补充说明）
最后，……（总结观点/得出结论/提出建议）
```

### 标志词法

| 逻辑关系 | 标志词 | 答题中的作用 |
|:--------|:------|:-----------|
| 开头 | 首先、第一、从……说起、近年来 | 引出话题/提出论点 |
| 递进 | 不仅如此、更重要的是、甚至、进而 | 论述深入一层 |
| 转折 | 但是、然而、不过、事实上、其实 | 转向反面论证/补充 |
| 并列 | 与此同时、另一方面、此外 | 从另一角度论述 |
| 因果 | 因此、所以、正因为此 | 得出结论/分析原因 |
| 总结 | 总之、由此可见、综上所述、一言以蔽之 | 总结观点/重申论点 |

### 答题模板

```
本文论证思路清晰：
首先，提出……（中心论点/核心问题）；
接着，从……角度展开论述，指出……；
然后，进一步论证……（或：从反面论证了……）；
最后，总结全文，得出……结论/提出……建议。
```

### 典型题目示例

**题目**：请简要分析文章的论证思路。（4 分）

**答题示范**：
```
首先，从"数字鸿沟"这一现象入手，提出数字素养的重要性；
接着，分别从教育、就业、社交三个层面，论述数字素养不足带来的影响；
然后，通过对比发达国家与发展中国家的差距，进一步论证数字素养建设的紧迫性；
最后，总结全文，提出政府、学校、个人三方协同提升数字素养的建议。
```

### 常见错误

```
✗ 错误示范：第一段写了……，第二段写了……，第三段写了……
  （只是概括段意，没有写出段与段之间的逻辑关系）

✓ 正确示范：首先提出……，接着从……方面论证……，然后进一步指出……
  （不仅概括内容，还点明逻辑关系）
```

## 四、论证特点分析题

> 比思路题更难，需要从三个维度综合分析

### 答题框架

```
① 从论证方法看，本文主要运用了……和……等论证方法。如……（举一例），……地论证了……观点。
② 从论证结构看，本文采用总分/递进/并列/对照式结构。先……，再……，最后……。
③ 从论证语言看，本文语言……（严谨准确/生动形象/通俗易懂/学术性强），具体表现在……
```

### 三个维度详解

#### 维度一：论证方法

| 情况 | 答题要点 |
|:----|:--------|
| 一种方法突出 | 重点分析这一种，举 1-2 例 |
| 多种方法综合 | 选出 2-3 种主要方法，说明"多种论证方法综合运用" |
| 论证方法有新意 | 如"比喻论证使抽象概念具象化" |

#### 维度二：论证结构

| 结构类型 | 特点 | 判断标志 |
|:--------|:----|:--------|
| 总分式 | 先总说，后分说；或先分后总 | "总的来说""具体而言" |
| 递进式 | 层层深入，由表及里 | "不仅如此""更进一步说" |
| 并列式 | 多个并列维度 | "第一……第二……第三""一方面……另一方面" |
| 对照式 | 正反对比 | "与之相反""与此相对" |

#### 维度三：论证语言

| 语言风格 | 特征 | 常用词汇 |
|:--------|:----|:--------|
| 严谨准确 | 多用限定词、科学术语 | "在某种意义上""一般来说""据统计" |
| 生动形象 | 多用比喻、拟人、形象化表达 | "犹如""仿佛""就像" |
| 通俗易懂 | 口语化、生活化 | "也就是说""说白了" |
| 学术性强 | 术语密集、句式复杂 | "文化自觉""范式转换" |

### 完整答案示例

**题目**：本文在论证上有哪些特点？请简要分析。（6 分）

**答案**：
```
① 论证方法上，主要运用了举例论证和对比论证。以不同国家的数字化实践为例论证观点，又通过发展中国家与发达国家的对比突出差距，增强说服力。
② 论证结构上，采用递进式结构。从现象到本质，从原因到对策，层层深入，逻辑严密。
③ 论证语言上，严谨准确，大量使用"一般来说""在某种程度上"等限定词，体现了学术论文的客观性。
```

## 五、论述类 vs 实用类——不同的答题策略

> 虽然合并为"信息类文本"，但两类文本的答题思路完全不同

| 维度 | 论述类文本 | 实用类文本 |
|:----|:----------|:----------|
| 典型文体 | 政论文、学术论文、时评、杂文、随笔 | 新闻、科普说明文、人物传记、调查报告、访谈 |
| 写作目的 | 论证观点，说服读者 | 传递信息，说明事实 |
| 核心能力 | 逻辑分析 | 信息提取+整合 |
| 简答常考 | 论证方法、论证思路、论证特点 | 内容概括、数据分析、图表解读、原因分析 |
| 答题侧重 | 分析"怎么论证""为什么这么论证" | 回答"材料说了什么""数据说明了什么" |
| 典型题干 | "本文是如何论证……的？" | "请概括……的主要原因" |

### 实用类文本的特殊题型

#### 图表解读题

```
三步法：
① 读图：标题、横纵轴、数据趋势、极值点
② 概括：数据说明/反映/揭示了……
③ 联系文本：图表信息与文本观点的关联
```

#### 内容概括题

```
答题模板：
① 从……角度看，……（信息一）
② 从……角度看，……（信息二）
③ 从……角度看，……（信息三）

注意：分点作答，每个点独立一条信息，不交叉
```

#### 非连续性文本

> 多则材料 + 图表 + 文字——信息交叉比对

```
常见问法：
  材料一和材料二在……方面的信息有何异同？
  综合几则材料，概括……。
```

## 六、双文本比较阅读

> 新高考趋势：给两个材料，比较它们的论证角度/方法/观点。

### 常见题型

| 题型 | 问法 | 分值 |
|:----|:----|:---:|
| 角度比较 | 两则材料在论证角度上有何不同？ | 4 分 |
| 方法比较 | 两则材料在论证方法上有何异同？ | 4-6 分 |
| 观点比较 | 两则材料的观点是否矛盾？请结合材料分析 | 4 分 |
| 综合比较 | 两则材料各有什么侧重？为什么？ | 6 分 |

### 比较维度

```
① 论证角度的不同
   - 材料一从……角度（如历史/现实/理论/实践）
   - 材料二从……角度

② 论证方法的异同
   - 相同点：都用了……方法（如举例论证）
   - 不同点：材料一侧重……，材料二侧重……

③ 观点结论的异同
   - 相同点：都认为……
   - 不同点：材料一认为……，材料二认为……

④ 材料侧重点的不同
   - 材料一重点讨论……，材料二重点讨论……
```

### 答题模板

```
两则材料既有一致性，又有差异：
相同之处在于，二者都关注/讨论/认同……；
不同之处在于，
  材料一侧重于……（角度/方法/观点），
  材料二侧重于……（角度/方法/观点）。
这种差异源于……（写作目的/读者对象/材料来源的不同）。
```

### 双文本比较典型答案

**题目**：材料一和材料二都是关于"人工智能伦理"的论述，请比较二者在论证角度和论证方法上的不同。（4 分）

**答案**：
```
论证角度上，材料一从技术发展的内在逻辑出发，讨论 AI 伦理问题的必然性；材料二则从社会应用的外部影响入手，关注 AI 带来的现实伦理挑战。

论证方法上，材料一主要运用因果论证，层层推理 AI 伦理问题为何不可避免；材料二则侧重举例论证，通过真实案例展示 AI 伦理困境的具体表现。
```

## 七、观点态度题

### 常见问法

```
① 作者对……持什么态度？请结合材料分析。
② 请概括作者在文中的主要观点。
③ 作者为什么认为……？
④ 对于……问题，作者提出了哪些见解？
```

### 答题模板

```
作者对……持肯定/否定/辩证/批判/中立的态度。
文章认为……（直接引用原文关键句或概括），
具体表现在：第一，……；第二，……；第三，……。
```

### 态度词库

| 态度类型 | 标志词 | 常见场景 |
|:--------|:------|:--------|
| 肯定/赞同 | 值得肯定、具有重要意义、值得推广 | 正面评价 |
| 否定/批判 | 这显然是错误的、值得我们反思、质疑 | 批评不良现象 |
| 辩证看待 | 既要看到……也要看到……、不可一概而论 | 全面分析 |
| 中立/客观 | 客观地说、就事论事 | 学术性论述 |
| 担忧/忧虑 | 令人担忧的是、不容忽视的是 | 讨论负面趋势 |
| 乐观/期待 | 令人欣慰的是、前景可期 | 展望未来 |

### 注意事项

```
1. 态度题≠内容概括题
   - 内容概括：材料说了什么
   - 态度题：作者怎么看（要有情感倾向判断）

2. 找态度标志词
   - 直接："我们认为""笔者以为"后一般跟观点
   - 间接：带有情感色彩的形容词（"可悲的""可贵的"）

3. 辩证态度不要漏
   - 很多社科论文的态度是"有所肯定但更强调不足"
   - 需要完整呈现，不能只答一半
```

## 八、典型例题演示

### 例题一：论证思路题

**题目**（2023 新高考 I 卷·信息类文本）：
请简要分析材料一的论证思路。（4 分）

**答案**：
```
首先，从"数字鸿沟"这一社会现象入手，引出数字素养的重要性；
接着，分别从教育、就业和社交三个维度，论述数字素养不足带来的负面影响；
然后，通过分析数字素养与国际竞争力的关系，进一步论证提升数字素养的紧迫性；
最后，总结全文，提出政府、学校、个人三方协同推进数字素养教育的建议。
```

**解析**：
```
得分点：
 ① 答出"首先引出话题/提出论点"——1 分
 ② 答出"接着从……方面论述"——1 分
 ③ 答出"然后进一步/深化论证"——1 分
 ④ 答出"最后总结/得出结论"——1 分

注意：
  必须写出"逻辑词"（首先/接着/然后/最后或同义词）
  必须写出"每段在论证中起到什么作用"
  只概括段意不给分
```

### 例题二：论证方法/特点题

**题目**（2022 新高考 I 卷·信息类文本）：
材料一在论证上有哪些特点？请简要分析。（4 分）

**答案**：
```
① 论证方法上，主要运用了举例论证和对比论证。
   如列举中外数字经济发展的实例，具体论证数字经济的积极作用；
   又将传统经济与数字经济对比，突出数字经济的独特优势。

② 论证语言上，严谨准确，大量使用"从某种意义上说""一般而言"等限定词，
   体现了学术论文的客观性和科学态度。
```

**解析**：
```
评分标准：
 ① 方法+例子+分析（2 分）——方法判断正确 1 分，结合文本分析 1 分
 ② 语言+特征+分析（2 分）——风格判断正确 1 分，结合文本说明 1 分

满分关键：
  始终"从文本中来，到文本中去"
  不要空谈理论，每个判断都要有文本依据
```

### 例题三：双文本比较题

**题目**（2024 新课标 I 卷·信息类文本）：
材料一和材料二都讨论了"算法推荐"的问题，但侧重点不同。请简要分析。（4 分）

**答案**：
```
材料一侧重于算法推荐对信息传播效率的积极意义，
强调算法能够精准匹配用户需求，提高信息获取效率；

材料二则侧重于算法推荐带来的伦理风险，
如"信息茧房"效应和用户隐私问题。

两则材料角度互补，分别讨论了同一事物的两面性。
```

**解析**：
```
失分重灾区：
  ✗ 只答不同，不答相同
    很多同学只写"材料一讲好处，材料二讲坏处"
    但题目要求"不同"，这意味着要两者都要写清楚各是什么

  ✗ 没有归纳性结论
    最后一句"两则材料角度互补"看似简单，但占了 1 分
```

## 九、易错点速查

| 易错点 | 正解 | 常见错误 |
|:-------|:----|:--------|
| 论证方法判断错误 | 看"论证了什么"——这个方法在论证什么观点 | 把举例当对比，看到"而"字就写对比论证 |
| 思路题漏步骤 | 注意段落间的逻辑关系词，不能只看段意 | 只是概括每段内容，没写出逻辑推进关系 |
| 特点题只答一个维度 | 方法+结构+语言至少选两个维度 | 只写了"用了举例论证"，没答结构和语言 |
| 实用类当论述类做 | 实用类重在信息提取和整合，不是逻辑分析 | 在科普文章里硬套"对比论证""比喻论证" |
| 双文本比较只答异不答同 | 同和异都要涉及 | 只写不同点，丢了"共同关注/一致观点" |
| 观点态度用自己话编 | 必须以原文为依据，不能主观发挥 | 自己推测"作者一定是反对的"而原文没明确说 |
| 简答不分点 | 分点作答（①/②/③ 或 首先/接着/然后） | 写一大段，阅卷老师找不到得分点 |
| 答题啰嗦重复 | 每个得分点独立不交叉 | 三个点说的是同一件事，被扣分 |
| 不看分答题 | 4 分通常 2 个点，6 分通常 3 个点 | 6 分只写了 1 个点，拿不全 |
| 不熟悉论证方法名称 | 准确说出"假设论证""归谬法""演绎论证" | 只会说"举个例子""引用一下" |

## 十、考场实战清单

> 考前 10 分钟，只看这一张清单

### 拿到信息类文本后

```
Step 1：判断类型（10 秒）
  - 论述类 → 准备分析逻辑
  - 实用类 → 准备提取信息

Step 2：标段落（20 秒）
  - 每段前写序号

Step 3：圈关键（1 分钟）
  - 论点句（首尾段 + 每段首尾句）
  - 转折词（但、然而、不过）
  - 论证方法标志词（例如、如果、因为）

Step 4：做选择（8 分钟）
  - 八大陷阱逐个排查

Step 5：做简答（5-8 分钟）
  - 看分值定要点数量
  - 看题型定答题模板
  - 分点作答，每题至少 2 个得分点
```

### 各类题型一句话急救

```
论证思路题：    首先___，接着___，然后___，最后___
论证方法题：    运用了___论证（判断）+ 论证了___（观点）+ 效果是___（作用）
论证特点题：    方法（哪些）+ 结构（哪种）+ 语言（什么风格）
双文本比较：    同（共同观点）+ 异（角度/方法/侧重点不同）
观点态度题：    找原文观点句 + 提炼情感倾向词 + 分条概括
实用类概括：    找出每则材料核心信息 + 整合归纳 + 分点写出
```
