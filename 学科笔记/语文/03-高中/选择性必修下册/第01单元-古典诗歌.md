# 第一单元 · 古典诗歌

> 诗歌巅峰一次收齐——从《诗经》到宋词
> 7 课：氓 / 离骚 / 孔雀东南飞 / 蜀道难 / 蜀相 / 望海潮 / 扬州慢

---

## 单元定位

**核心任务：打通中国古典诗歌的源流——从"风骚"到宋词。**

```
必修上册第三单元是"散点式"的诗歌学习（每类一首）
选择性必修下册是"系统式"的诗歌学习

本单元覆盖：
  诗经（氓）→ 楚辞（离骚）→ 汉乐府（孔雀东南飞）
  → 唐诗（蜀道难/蜀相）→ 宋词（望海潮/扬州慢）
  
  → 每个时期的代表性作品
```

## 1 氓 — 《诗经·卫风》

### 文体
- 四言诗，叙事诗，"弃妇诗"的代表

### 核心分析

```
一个女人的自述：从恋爱到结婚到被抛弃

六个阶段：
  ① "氓之蚩蚩"——男子前来求婚（看似憨厚）
  ② "乘彼垝垣"——女人天天盼他来
  ③ "以尔车来"——结婚
  ④ "三岁食贫"——婚后贫穷劳累
  ⑤ "女也不爽"——女人没有错，男人变心了
  ⑥ "反是不思"——被抛弃后的决绝

经典名句：
  "士之耽兮，犹可说也。女之耽兮，不可说也。"
  → 男人陷入感情，还能抽身
  → 女人陷入感情，就出不来了

  "信誓旦旦，不思其反"
  → 当初的誓言还在耳边
  → 但人心已经变了
```

### 考试要点

- **比兴手法**："桑之未落，其叶沃若"（用桑叶比喻青春）
- **叙述方式**：第一人称的女性叙事
- **"氓"字**：氓=民（不是氓流的氓）
- **诗经的"六义"**：风雅颂+赋比兴

## 2 离骚（节选）— 屈原

### 文体
- 楚辞体，中国最早的浪漫主义长诗
- 全诗 373 句，选段为开头部分

### 核心分析

```
第一段：自述身世
  "帝高阳之苗裔兮，朕皇考曰伯庸"
  → 我是高阳帝（颛顼）的后代
  → 出身高贵

第二段：追求理想
  "路曼曼其修远兮，吾将上下而求索"
  → 人生路很长，我会不懈追求

第三段：遭遇不公
  "众女嫉余之蛾眉兮，谣诼谓余以善淫"
  → 小人嫉妒我的才华 → 造谣中伤

第四段：不改初心
  "亦余心之所善兮，虽九死其犹未悔"
  → 只要是我心中的追求 → 死一万次也不后悔
```

### 核心考点

- **香草美人**的象征系统
  - "香草"= 品德高尚（江离/辟芷/秋兰）
  - "美人"= 君主/理想
- **"兮"字的用法**——楚辞体的标志
- **浪漫主义手法**——想象奇特、语言华丽
- **与诗经的对比**：
  - 诗经：现实、朴实、集体创作
  - 离骚：浪漫、华丽、个人创作

## 3 孔雀东南飞

### 文体
- 汉乐府叙事诗
- 中国文学史上第一首长篇叙事诗（356 句）

### 故事梗概

```
焦仲卿 + 刘兰芝 = 恩爱夫妻
  焦母不喜欢兰芝 → 逼儿子休妻
  刘兄逼兰芝改嫁 → 兰芝被迫答应
  结婚那天 → 兰芝投水自杀
  焦仲卿听到 → 上吊自尽
  两家把两人合葬 → 墓上长出连理枝
```

### 核心考点

- **封建礼教的批判**——焦母+刘兄=封建家长的代表
- **浪漫结尾**——"枝枝相覆盖，叶叶相交通"→化作鸳鸯
- **与氓的对比**：氓（被动被弃）vs 兰芝（主动反抗）
- **乐府诗的特点**——叙事性强、口语化

## 4 蜀道难 — 李白

### 核心

```
"噫吁嚱，危乎高哉！蜀道之难，难于上青天！"

→ 李白笔下的蜀道：比登天还难

第一层：蜀道的来历
  蚕丛及鱼凫 → 开国何茫然
  
第二层：蜀道的险
  "上有六龙回日之高标，下有冲波逆折之回川"
  "黄鹤之飞尚不得过，猿猱欲度愁攀援"
  "连峰去天不盈尺，枯松倒挂倚绝壁"
  
第三层：劝人别去
  "锦城虽云乐，不如早还家"
  "侧身西望长咨嗟"
  
浪漫主义：
  不是写实（蜀道没这么难）
  是夸张 + 想象 + 神秘感
```

### 考点

- **浪漫主义手法**——夸张、想象、神话
- **"难于上青天"的三次出现**——复沓手法
- **与离骚对比**——都浪漫，但李白的乐观 vs 屈原的悲壮

## 5 蜀相 — 杜甫

### 核心

```
"丞相祠堂何处寻，锦官城外柏森森"

上联写景：
  "映阶碧草自春色，隔叶黄鹂空好音"
  → "自"和"空"——景很美，但没人欣赏
  → 因为诸葛亮已经不在了

下联怀古：
  "三顾频频天下计，两朝开济老臣心"
  → 概括诸葛亮的一生——三顾茅庐→开创蜀汉→辅佐后主

  "出师未捷身先死，长使英雄泪满襟"
  → 北伐未成，诸葛亮去世
  → 不仅写诸葛亮，也写杜甫自己
```

## 6 望海潮 — 柳永

### 核心

```
写杭州的繁华——北宋最著名的城市赞歌

"东南形胜，三吴都会，钱塘自古繁华"
  "烟柳画桥，风帘翠幕，参差十万人家"
  "市列珠玑，户盈罗绮，竞豪奢"

"重湖叠巘清嘉，有三秋桂子，十里荷花"
  → 秋天桂花香 + 夏天荷花美
  
最后：
  "异日图将好景，归去凤池夸"
  → 把杭州美景画下来，回去给别人看
```

## 7 扬州慢 — 姜夔

### 核心

```
和望海潮形成对比的写法：
  柳永写杭州（盛世繁华）
  姜夔写扬州（战后的荒凉）

"淮左名都，竹西佳处，解鞍少驻初程"
  "过春风十里，尽荠麦青青"
  → 过去的繁华（春风十里）→ 现在的荒凉（荠麦）

"自胡马窥江去后，废池乔木，犹厌言兵"
  → 金兵南侵后，扬州被破坏
  → 连池塘和树都不想再提起那次战争

"二十四桥仍在，波心荡，冷月无声"
  → 桥还在，但热闹不在了
  → 只有冷冷的月亮
```

### 考点

- **与望海潮的对比阅读**——繁华 vs 荒凉
- **化用唐诗**——"春风十里"化用杜牧
- **虚实结合**——过去的繁华（虚）vs 现在的荒凉（实）

## 单元总复习

```
诗歌发展的脉络：
  诗经（现实）→ 楚辞（浪漫）
  → 汉乐府（叙事）→ 唐诗（巅峰）
  → 宋词（新形式）
  
  每一代都有自己独特的创造
  又互相影响、继承
```
