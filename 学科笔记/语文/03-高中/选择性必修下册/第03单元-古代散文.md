# 第三单元 · 古代散文

> 古代散文的巅峰——从魏晋到明清
> 5 课：陈情表 / 项脊轩志 / 兰亭集序 / 归去来兮辞 / 种树郭橐驼传

---

## 单元定位

**核心任务：经典散文中的"至情至性"——每一篇都是情感到极致的作品。**

```
什么是"至情至性"？
  陈情表：孝——"臣无祖母，无以至今日"
  项脊轩志：念旧——"庭有枇杷树，吾妻死之年所手植也"
  兰亭集序：感慨——"死生亦大矣"
  归去来兮辞：归隐——"归去来兮，田园将芜胡不归"
  种树郭橐驼传：论政——以种树喻治国
```

## 12 陈情表 — 李密

### 文体
- "表"=臣子写给皇帝的信
- 背景：晋武帝叫李密去做官 → 李密不想去 → 写了这封信

### 论证

```
李密怎么说服晋武帝让他留在家里照顾祖母？

第一步：自述悲惨身世
  "臣以险衅，夙遭闵凶"
  → 父亲早死、母亲改嫁、自己多病
  
  "外无期功强近之亲，内无应门五尺之僮"
  → 孤苦伶仃

第二步：祖母的养育之恩
  "臣无祖母，无以至今日"
  → 没有祖母就没有我

第三步：现在的困境
  "祖母刘愍臣孤弱，躬亲抚养"
  "今臣亡国贱俘，至微至陋"
  → 祖母已经 96 岁了
  → "日薄西山，气息奄奄，人命危浅，朝不虑夕"

第四步：请求
  "臣密今年四十有四，祖母刘今年九十有六"
  → 我四十四岁，以后有的是时间为国效力
  → 祖母九十六岁，等不了那么久了
  
  "是臣尽节于陛下之日长，报养刘之日短也"
  → 我报效您的时间还长
  → 我报答祖母的时间不长了
```

### 核心考点

- **"以"字的用法**——全文出现几十个"以"
- **"区区不能废远"**——个人情感的表达
- **"圣朝以孝治天下"**——李密抓住了晋武帝的政治口号
- **成语**：茕茕孑立、形影相吊、日薄西山、气息奄奄、朝不虑夕

## 13 项脊轩志 — 归有光

### 文体
- 明代散文（归有光是"唐宋派"的代表）

### 核心

```
项脊轩 = 归有光家里的一间小书房
"志"= 记

全文以项脊轩为线索，回忆家人：
  祖母：希望他光宗耀祖
  母亲：关心孩子的细节
  妻子：在轩中一起读书

最动人的结尾：
  "庭有枇杷树，吾妻死之年所手植也，今已亭亭如盖矣。"
  → 妻子死的那年种的树 → 现在已长大了
  → 树的成长 = 时间的流逝 = 对妻子的思念
```

### 考试要点

- **"以轩写人"**——通过写书房来写人
- **细节的力量**——"娘以指叩门扉曰：'儿寒乎？欲食乎？'"
- **结尾的抒情**——不直接说"我想你"，说"树已经这么大了"

## 14 兰亭集序 — 王羲之

### 文体
- "序"=诗集序言
- 书法和文章都是巅峰

### 核心

```
第一部分：兰亭雅集
  "永和九年，岁在癸丑"→ 353 年
  "群贤毕至，少长咸集"
  "此地有崇山峻岭，茂林修竹"
  "引以为流觞曲水"

第二部分：人生感慨（核心）
  "向之所欣，俯仰之间，已为陈迹"
  → 刚才还很高兴的事，转眼就成了过去
  
  "况修短随化，终期于尽"
  → 寿命长短都是命运，最后都一样要死
  
  "固知一死生为虚诞，齐彭殇为妄作"
  → 说"生和死一样"是假的
  → 说"长寿和短命一样"也是假的

第三部分：作序的目的
  "后之览者，亦将有感于斯文"
  → 希望后来的人看到我的文章，也会有同样的感慨
```

## 15 归去来兮辞 — 陶渊明

### 核心

```
"归去来兮，田园将芜胡不归？"
  → 田园快荒芜了，为什么不回去？

正文：
  回家的路上：
    "舟遥遥以轻飏，风飘飘而吹衣"
    → 轻松愉快——终于离开了官场
    
  到家：
    "僮仆欢迎，稚子候门"
    → 温馨的家庭场景
    
  田园生活：
    "悦亲戚之情话，乐琴书以消忧"
    → 和亲戚聊天、弹琴读书
    
    "农人告余以春及，将有事于西畴"
    → 春天来了，要到田里干活了

结尾：
  "乐夫天命复奚疑"
  → 安于命运的安排，还有什么可犹豫的？

与归园田居的联系：
  归园田居（诗）: 写"我回来了"的快乐
  归去来兮辞（赋）: 写"我为什么回来"的思考
```

## 16 种树郭橐驼传 — 柳宗元

### 文体
- 寓言式传记（借种树讲治国）

### 核心

```
郭橐驼 = 一个驼背的种树能手

他种树的秘诀：
  "其本欲舒，其培欲平，其土欲故，其筑欲密"
  → 根要舒展，土要平整，要用旧土，要压实

核心观点：
  "勿动勿虑，去不复顾。其莳也若子，其置也若弃"
  → 种下去之后就不要频繁去动它
  → 让它自然生长

类比：
  种树 = 治民
  频繁地"关心"（折腾）→ 反而长不好
  官员不要频繁地"扰民"→ 安静就是最好的治理
```

## 单元总结

```
五篇散文的共同核心：人应该怎样活着？

陈情表：为亲人而活
项脊轩志：在回忆中活着
兰亭集序：在感慨中活着
归去来兮辞：顺应天性活着
种树郭橐驼传：遵循规律活着
```
