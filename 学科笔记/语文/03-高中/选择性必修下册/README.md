## 一、整册定位

**核心任务：古代文学鉴赏的集大成**

```
必修上册：古诗词入门（8 首）
必修下册：古代散文+史传
选必上册：先秦诸子（思想深度）
选必中册：史传+史论（历史思维）
选必下册：古代散文+诗歌史（文学鉴赏的终极形态）
```

选择性必修下册是高中语文的**收山之作**，也是**最难的一册**。

前四册的核心是"分析"——分析手法、分析结构、分析论证。
这一册的核心是"鉴赏"——鉴赏语言、鉴赏意境、鉴赏情感。

**分析可以靠套路，鉴赏只能靠积累。**

### 第一单元：诗歌史——三千年的回响

**核心：这部诗集回答了一个问题——中国诗歌是怎么演变的？**

| 时代 | 篇目 | 诗歌形式 | 关键特征 |
|:----|:----|:--------|:--------|
| 先秦·诗经 | 氓 | 四言诗 | 赋比兴手法 |
| 战国·楚辞 | 离骚（节选） | 骚体 | 香草美人、浪漫主义 |
| 汉·乐府 | 孔雀东南飞 | 五言叙事诗 | 长篇叙事、悲剧主题 |
| 唐·古体诗 | 蜀道难 | 七言歌行 | 想象奇绝、语言夸张 |
| 唐·律诗 | 蜀相 | 七言律诗 | 情景交融、工整对仗 |
| 宋·慢词 | 望海潮 | 长调 | 铺叙手法、城市风光 |
| 宋·慢词 | 扬州慢 | 长调 | 今昔对比、黍离之悲 |

**这个单元不是 7 首诗，是中国诗歌的 7 个标本。**

**离骚为什么被称为"全高中最难"？**

```
第一重难：生字
  很多字一辈子就见这一次——比如"畦""芰""颉颃"
  但高考不会考这些生字

第二重难：句式
  "长太息以掩涕兮，哀民生之多艰"
  主语在哪里？状语的顺序为什么不对？
  → 骚体句法本身就很特殊

第三重难：意象
  香草 = 美德（江离、辟芷、秋兰）
  美人 = 国君（"众女嫉余之蛾眉兮"）
  如果不理解这个象征系统，就等于没读懂

第四重难：精神内核
  "虽九死其犹未悔"
  不是悲观，是中国文人最好的"明知不可为而为之"
```

**学习建议：**
```
7 首不能平均用力。

重点背诵：氓、蜀道难、蜀相、扬州慢
重点理解：离骚（象征系统）、孔雀东南飞（叙事艺术）
了解即可：望海潮（感受柳永的铺叙）
```

### 第二单元：现当代文学——从经典中看时代

**核心：中国现代文学如何回应"人的觉醒"**

| 篇目 | 作家 | 文体 | 核心主题 |
|:----|:----|:----|:--------|
| 阿Q正传 | 鲁迅 | 中篇小说 | 国民性批判——精神胜利法 |
| 边城 | 沈从文 | 中篇小说 | 乡土中国的牧歌 vs 现实的悲剧 |
| 大堰河——我的保姆 | 艾青 | 现代诗歌 | 土地与人民 |
| 再别康桥 | 徐志摩 | 现代诗歌 | 离别之美——新月派"三美"（音乐美/绘画美/建筑美） |
| 一个消逝了的山村 | 冯至 | 散文 | 自然与生命的哲思 |

**⚠️ 阿Q正传为什么重要？**
```
不是因为它故事情节精彩
而是因为"精神胜利法"是一个"文化概念"

阿Q被打 → "儿子打老子" → 我赢了
阿Q被看不起 → "不配" → 我反而清高了
阿Q要死了 → "二十年后又是一条好汉" → 我还是一条好汉

鲁迅不是在写一个人，是在写一种"国民性"
"阿Q"成为了一个文化符号——你是阿Q吗？他是阿Q吗？
```

### 第三单元：古代散文——巅峰对决 🔴🔴

**核心：6 篇古代散文，各自代表了不同的审美高度**

| 篇目 | 作者 | 朝代 | 文体 | 一句话概括 |
|:----|:----|:----|:----|:----------|
| 陈情表 | 李密 | 西晋 | 表 | 以孝感人——"读陈情表不哭者不孝" |
| 项脊轩志 | 归有光 | 明 | 记事散文 | 以小见大——一间书房里的百年兴衰 |
| 兰亭集序 | 王羲之 | 东晋 | 序 | 生死之思——"后之视今，亦犹今之视昔" |
| 归去来兮辞 | 陶渊明 | 东晋 | 辞 | 回归田园——"归去来兮！田园将芜胡不归" |
| 种树郭橐驼传 | 柳宗元 | 唐 | 传记+寓言 | 顺其自然——以种树喻治国 |
| 石钟山记 | 苏轼 | 宋 | 游记+考辨 | 事不目见耳闻不可臆断 |

#### 深度分析：陈情表

**堪称"中国最会说话的文章"。**

```
第一段：自述身世——我不是不孝，是真的命苦
  "臣以险衅，夙遭闵凶"——开头奠定悲情基调
  
第二段：忠孝两难——我不是想违抗命令
  "臣欲奉诏奔驰，则刘病日笃"
  "臣欲苟顺私情，则告诉不许"
  两个"则"字写出进退两难的困境

第三段：我不是不想当官——"圣朝以孝治天下"
  用朝廷自己的价值观来为自己辩护
  最高明的说理——不是"我凭什么"，是"你本来就这么说"

第四段：乌鸟私情，愿乞终养
  情感推到最高处
  "臣生当陨首，死当结草"——此生必报
```

**考试套路：**
```
为什么说陈情表的"说理"是最高明的？
  → 不是因为讲道理讲得清楚
  → 而是找到了"朝廷也在讲孝"这个共同前提
  → 用对方的逻辑说服对方
```

#### 深度分析：归去来兮辞

```
一个"归"字，贯穿全文：

归去来兮（决定回去）→ 回家的路上 → 到家了
  → 在家里做什么 → 在田园里做什么
  → 最后问：为什么还不回去？

全文结构 = 一个"归"的动作的逐步展开
陶渊明的语言：骈散相间，节奏极美
  "舟遥遥以轻飏，风飘飘而吹衣"
  → 两个叠词"遥遥""飘飘"写出归途的轻快
```

## 五、给家长的提醒

1. **这对冉冉意味着什么？——从小学开始埋线**

```
小学多背古诗：
  → 高一第三单元 8 首古诗词不陌生
  → 高二下诗歌史单元知道"诗经→楚辞→唐诗→宋词"的演变

初中精读《史记》选篇：
  → 高中读史传不吃力
  → 屈原列传、鸿门宴这些本来就读过

小学到初中坚持课外阅读：
  → 阿Q正传、边城这些到高中才读，但因为阅读习惯好，不会抵触
```

2. **陈情表、归去来兮辞、兰亭集序——这三篇值得提前接触**
   - 不需要小学就读原文
   - 但可以读白话版的故事或赏析
   - 有了"印象"，高中再精读时就不觉得陌生

3. **选择性必修下册学完，新课标内容全部结束**
   - 接下来就是高三的全面复习
   - 如果前面的文言文欠债了，这是"最后的补债机会"
   - 高三没有时间再一篇文章一篇文章地磨了
