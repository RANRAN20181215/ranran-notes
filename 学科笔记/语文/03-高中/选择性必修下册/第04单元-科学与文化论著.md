## 17 天文学上的旷世之争 — 关增建

### 核心

```
中国天文学史上的一场大争论：
  盖天说（天如盖，地如棋盘）
  vs 浑天说（天如蛋壳，地如蛋黄）

争论持续了一千多年
  → 最后浑天说胜出

文章核心：
  不是讲"哪个对"，是讲"科学争论怎么推动进步"
  → 有争论 → 有证据 → 有进步
```

## 18 宇宙的未来 — 霍金

### 核心

```
霍金关于宇宙命运的预测：
  宇宙会继续膨胀 → 还是会收缩？

霍金的态度：
  不确定——但可以计算概率

文章特色：
  用通俗的语言讲深奥的宇宙学
  幽默感："我不会赌宇宙的未来，因为我没有那么多钱"
```
