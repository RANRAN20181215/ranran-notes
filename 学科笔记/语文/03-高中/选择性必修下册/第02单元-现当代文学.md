## 单元定位

**核心任务：读鲁迅的杂文 + 现当代散文——从"事件"到"思想"。**

```
鲁迅的两篇：追悼牺牲的年轻人
  → 不只是悼念，更是愤怒

散文两篇：
  《风景谈》：延安的风景
  《秦腔》：陕西的乡土文化
```

## 8 记念刘和珍君 — 鲁迅

### 背景

```
1926 年 3 月 18 日：北京学生请愿 → 段祺瑞政府开枪
  → 刘和珍等 47 人死亡 → "三一八惨案"

鲁迅写下本文：
  不是普通的悼念文章
  是"对政府的控诉"
```

### 核心

```
"真的猛士，敢于直面惨淡的人生，敢于正视淋漓的鲜血"
  → 什么是"真的猛士"？= 刘和珍这样的人

"我向来是不惮以最坏的恶意来推测中国人的"
  → 但这次还是出乎我的意料
  → 政府对学生的屠杀

"沉默呵，沉默呵！不在沉默中爆发，就在沉默中灭亡"
  → 鲁迅在呼唤反抗
```

## 9 为了忘却的记念 — 鲁迅

### 背景

```
1931 年 2 月 7 日：左联五烈士被国民党杀害
  包括柔石等五位青年作家

"为了忘却的记念"的标题含义：
  不想沉浸在悲痛中 → 把悲痛转化为继续战斗的力量
```

---

## 10 风景谈 — 茅盾

### 核心

```
1940 年茅盾从延安回来 → 写延安的"风景"

表面：写风景
  沙漠、高原、延河边的青年
  
实际：写人
  不是风景美，是"风景里的人"美
  → 延安的新生活
  → 革命者的精神面貌
```

---

## 11 秦腔 — 贾平凹

### 核心

```
秦腔 = 陕西的地方戏曲
  贾平凹不是写秦腔的艺术特点
  而是写：秦腔在陕西人生活中的意义

"秦腔是他们表达喜怒哀乐的唯一方式"
  → 高兴了唱秦腔
  → 难过了唱秦腔
  → 秦腔=陕西人的灵魂
```
