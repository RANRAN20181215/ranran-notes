## 一、考纲定位

**分值：** 9 分（选择题 3 分 + 简答 6 分）
**建议用时：** 10-12 分钟

**近年趋势：**
- 选择题从"找错误"变成"选正确"，难度微降但更考细致
- 简答题越来越开放，不再问"表达了什么情感"，而问"你如何理解"
- 诗论题出现频率大增（2023/2024 全国卷、新高考 I 卷均有涉及）
- 比较阅读从偶尔考查变成多套卷常规题型

基础模板在大本营《高考阅读答题模板》古诗词鉴赏章节

## 二、常见意象词典

> 意象 = 客观物象 + 主观情意
> 同一个意象在不同诗中可能完全不同——永远结合语境，不死记硬背

### 自然类

| 意象 | 象征意义 | 举例 | 常见情感 |
|:----|:---------|:-----|:---------|
| 月亮 | 思乡怀人、永恒与变迁、孤独清冷 | "但愿人长久，千里共婵娟"——苏轼 | 思乡/怀人/孤寂/哲思 |
| 流水 | 时间流逝、愁绪绵长、世事无常 | "问君能有几多愁，恰似一江春水向东流"——李煜 | 愁苦/感慨/惜时 |
| 夕阳/落日 | 迟暮衰老、衰败没落、惜时 | "夕阳无限好，只是近黄昏"——李商隐 | 迟暮之叹/家国之悲 |
| 烟/暮霭 | 朦胧迷惘、愁绪笼罩 | "烟笼寒水月笼沙"——杜牧 | 忧愁/迷茫 |
| 春风/东风 | 生机希望、温暖喜悦（也可表思念） | "春风又绿江南岸"——王安石 | 喜悦/思乡 |
| 西风/秋风 | 萧瑟凄凉、离别愁苦 | "帘卷西风，人比黄花瘦"——李清照 | 悲秋/思人/漂泊 |
| 云 | 漂泊不定、高洁脱俗 | "浮云游子意"——李白 | 漂泊/隐逸 |

> 注意风的方向：东风=春风（温暖），西风=秋风（萧瑟），南风=夏风（和煦），北风=冬风（凛冽）

### 植物类

| 意象 | 象征意义 | 举例 | 常见情感 |
|:----|:---------|:-----|:---------|
| 柳 | 送别挽留、惜别怀人 | "渭城朝雨浥轻尘，客舍青青柳色新"——王维 | 送别/留恋 |
| 菊 | 隐逸脱俗、高洁坚贞 | "采菊东篱下，悠然见南山"——陶渊明 | 隐逸/高洁 |
| 梅 | 傲骨凌寒、高洁不屈 | "墙角数枝梅，凌寒独自开"——王安石 | 坚贞/孤傲 |
| 莲/芙蓉 | 高洁君子、爱情纯洁 | "出淤泥而不染"——周敦颐 | 高洁/爱慕 |
| 松/柏 | 坚贞不屈、长寿永恒 | "大雪压青松，青松挺且直"——陈毅 | 坚贞/节操 |
| 梧桐 | 凄凉孤独、离愁别绪 | "梧桐更兼细雨，到黄昏点点滴滴"——李清照 | 孤寂/愁苦 |
| 落花/残红 | 春逝、美好易逝、人生无常 | "无可奈何花落去"——晏殊 | 惜春/伤逝/感伤 |
| 红豆 | 相思 | "红豆生南国，春来发几枝"——王维 | 爱情/相思 |

> 柳与"留"谐音，古人折柳送别取"挽留"之意——《三辅黄图》记载，灞桥折柳送别已是汉朝习俗
> 梧桐是凄凉意象之王，几乎不在喜乐诗中出现

### 动物类

| 意象 | 象征意义 | 举例 | 常见情感 |
|:----|:---------|:-----|:---------|
| 雁 | 思乡怀人、书信传情、迁徙漂泊 | "乡书何处达，归雁洛阳边"——王湾 | 思乡/漂泊 |
| 杜鹃/子规 | 哀愁凄切、思归、亡国之痛 | "其间旦暮闻何物，杜鹃啼血猿哀鸣"——白居易 | 悲苦/思归 |
| 鹧鸪 | 离愁别绪、南方风物 | "江晚正愁余，山深闻鹧鸪"——辛弃疾 | 行路难/愁苦 |
| 蝉 | 高洁清高、悲凉凄切 | "居高声自远，非是藉秋风"——虞世南 | 高洁/悲秋 |
| 猿 | 哀愁悲凉、漂泊之苦 | "巴东三峡巫峡长，猿鸣三声泪沾裳"——郦道元 | 悲苦/孤寂 |
| 马 | 征战豪情、漂泊羁旅、壮志 | "老骥伏枥，志在千里"——曹操 | 壮志/漂泊 |
| 莺/燕 | 春光美好、生机 | "几处早莺争暖树，谁家新燕啄春泥"——白居易 | 喜悦/生机 |
| 乌鸦 | 荒凉破败、衰亡 | "枯藤老树昏鸦"——马致远 | 萧瑟/凄苦 |

> 杜鹃的哀愁源自"望帝春心托杜鹃"典故——望帝化为杜鹃啼血，所以杜鹃一出现就带着悲
> 雁分两种：北雁南飞=秋景/思乡，归雁=春天/希望，用法不同

| 意象 | 象征意义 | 举例 | 常见情感 |
|:----|:---------|:-----|:---------|
| 舟/孤帆 | 漂泊不定、自由归隐 | "孤帆远影碧空尽"——李白 | 送别/漂泊 |
| 笛/羌笛 | 思乡悲凉、边塞苍凉 | "羌笛何须怨杨柳，春风不度玉门关"——王之涣 | 思乡/悲凉 |
| 长亭/南浦 | 送别之地 | "长亭外，古道边，芳草碧连天"——李叔同 | 离别/伤感 |
| 关山/玉门关 | 征战边塞、遥远阻隔 | "秦时明月汉时关"——王昌龄 | 边塞/征战 |
| 捣衣/砧声 | 思妇思念、秋思 | "长安一片月，万户捣衣声"——李白 | 思妇/秋思 |
| 楼/危楼 | 登高怀远、孤独惆怅 | "昨夜西风凋碧树，独上高楼，望尽天涯路"——晏殊 | 怀远/孤独 |
| 灯/孤灯 | 孤独寂寞、守候 | "孤灯挑尽未成眠"——白居易 | 孤寂/愁苦 |

## 三、炼字/炼句专项

> "吟安一个字，捻断数茎须"——古人写诗最重炼字，高考也最爱考"某字妙在何处"

### 炼字答题模板（四步法）

```
标准格式：

① 释义：XX 字在诗中是……的意思（解释语境义，不照搬字典）
② 手法：运用了……手法（修辞/表现手法）
③ 效果：生动形象地写出了……（画面/意境/景物特征）
④ 情感：表达了诗人……的情感

送分技巧：把"生动形象"换成更具体的词
  "生动"→ 化静为动/化无形为有形/使画面具有动态感
  "形象"→ 使景物特征更鲜明/使情感更加具体可感
```

### 炼句答题模板（三步法）

```
标准格式：

① 内容：这句诗写了……（翻译 + 描绘画面）
② 手法：运用了……手法（修辞/描写角度/抒情方式）
③ 作用：对表达情感/深化主旨/营造意境的作用是……

注意：不是所有句子都有修辞——没有手法就跳过第二步，直接说内容+作用
```

### 高频炼字类型

**1. 动词——最核心的炼字类型**

动词能让静态画面"活"起来，是高考炼字题里出现频率最高的。

| 经典案例 | 字 | 妙处分析 |
|:---------|:---|:---------|
| "春风又绿江南岸" | 绿（形容词作动词） | 化静为动，写出春风吹过、江南变绿的动态过程 |
| "僧敲月下门" | 敲（vs"推"） | 以动衬静，敲门声更显月色下的幽静 |
| "红杏枝头春意闹" | 闹 | 化无声为有声，赋予春意以人的动作，生动写出春意盎然 |
| "星垂平野阔" | 垂 | 写出星空低垂的视觉效果，平野的辽阔因"垂"而更显 |

> 动词类炼字的核心逻辑：动静关系（化静为动 / 以动衬静）或 感官融通（通感）

**2. 形容词——营造氛围的关键**

| 经典案例 | 字 | 妙处分析 |
|:---------|:---|:---------|
| "大漠孤烟直" | 直 | 写出烽烟的挺拔、无风，凸显大漠的苍茫荒凉 |
| "长河落日圆" | 圆 | 写落日贴近地平线的视觉效果，壮美辽阔 |
| "昨夜西风凋碧树" | 碧 | 碧色越鲜明，越反衬秋风的萧瑟无情 |

**3. 副词——情感的刻度**

| 经典案例 | 字 | 妙处分析 |
|:---------|:---|:---------|
| "每逢佳节倍思亲" | 倍 | 一个"倍"字写出平日已思、佳节更甚的强烈情感 |
| "欲穷千里目，更上一层楼" | 更 | 递进关系，写出不断追求、永不止步的精神 |
| "只在此山中，云深不知处" | 只、不 | 肯定与否定对照，神秘幽深之感 |

**4. 叠词——韵律+渲染**

| 经典案例 | 字 | 妙处分析 |
|:---------|:---|:---------|
| "寻寻觅觅，冷冷清清" | 寻寻/冷冷 | 音韵凄切，渲染孤独凄凉的氛围 |
| "无边落木萧萧下" | 萧萧 | 模拟落叶声，画面感极强 |
| "晴川历历汉阳树" | 历历 | 分明的样子，写出清晰可见的视觉效果 |

**5. 数词——夸张与对比**

| 经典案例 | 字 | 妙处分析 |
|:---------|:---|:---------|
| "飞流直下三千尺" | 三千 | 夸张，写出瀑布的磅礴气势 |
| "一片两片三四片" | 数词递进 | 由少到多，视觉渐变 |
| "一曲新词酒一杯" | 一 | 一与一的反复，写出年复一年的单调感 |

### 炼字/炼句的判断信号

```
看到这些词，就要往炼字/炼句方向想：
"妙在何处""赏析""简析""哪个字用得好""
某字能否换成某字""某字历来为人称道"
"请赏析颔联""请赏析画线句"
```

## 四、诗歌语言风格系统

> 语言风格 = 用词习惯 + 句式特点 + 意象选择 + 情感基调
> 选择题和简答都可能考，也是比较阅读的高频维度

### 八大核心风格一览

| 风格 | 特征 | 代表诗人 | 标志词/意象 |
|:----|:-----|:---------|:------------|
| 豪放雄奇 | 气势磅礴、意象宏大、想象瑰丽 | 李白、苏轼、辛弃疾 | 大江/长空/万里/千骑/天外/九霄 |
| 婉约细腻 | 情感缠绵、语言柔美、意象纤巧 | 李清照、柳永、温庭筠 | 残月/落花/细雨/孤灯/珠帘/画楼 |
| 沉郁顿挫 | 深沉悲慨、语言凝练、含蓄蕴藉 | 杜甫 | 国破/艰难/老病/涕泪/风急/天高 |
| 含蓄蕴藉 | 言在此意在彼、多用象征/用典 | 李商隐 | 意象朦胧/典故密集/可多解 |
| 平淡自然 | 朴素真率、不事雕琢、口语化 | 陶渊明、王维（山水） | 日常景物/田间/简单动词 |
| 清新明丽 | 语言清秀、色彩鲜明、意境优美 | 王维、孟浩然、杨万里 | 绿/红/青/白/雨后/春山/清泉 |
| 雄奇瑰丽 | 想象奇特、色彩斑驳、神话入诗 | 李白、李贺 | 神仙/鬼魅/日月/奇幻色彩 |
| 悲壮慷慨 | 悲凉中见豪气、苍凉中见壮烈 | 高适、岑参、辛弃疾（部分） | 边塞/战场/白发/功名/铁衣 |
| 空灵淡远 | 意境空阔、语言洗练、禅意悠远 | 王维（山水禅诗）、孟浩然 | 空山/深林/明月/清泉/禅 |

> 豪放 vs 悲壮的区别：豪放是"I can"，悲壮是"I should but I can't"——前者自信，后者不甘
> 婉约 vs 含蓄的区别：婉约是纤巧柔美，含蓄是有话不直说——两回事

### 快速识别法

```
三秒锁定诗歌风格：

① 扫意象 → 大江/长空/千骑 → 豪放
             残月/落花/孤灯 → 婉约
             边塞/铁衣/战场 → 悲壮/边塞

② 看诗人 → 杜甫 → 沉郁（大概率，但不是所有诗都是）
             李白 → 豪放/雄奇
             王维 → 清新/空灵

③ 读首句 → "君不见黄河之水天上来" → 豪放
             "风急天高猿啸哀" → 沉郁
             "空山新雨后" → 清新

④ 查用典 → 典故密集 → 含蓄/沉郁
             极少用典 → 平淡/清新
```

### 风格的"灰色地带"

```
同一诗人可以有多元风格，这才是高考常设的陷阱：

李白：主要=豪放，也有《静夜思》式的平淡
苏轼：主要=豪放，也有《江城子》式的婉约
辛弃疾：主要=豪放/悲壮，也有"明月别枝惊鹊"式的清新
李清照：主要=婉约，也有"生当作人杰"式的豪放（南渡后）

答题原则：问的是"这首诗的风格"，不是"这位诗人的风格"
```

## 五、诗论题专项

> 新高考最大变量——2021 年新高考 I 卷首次出现，此后全国卷陆续跟上
> 本质是：用古人的话，说你的分析

### 什么是诗论题

题干引用古代诗论家的话，要求用这个观点去评析/印证/解读一首诗。

```
典型题干示例：

"王国维《人间词话》说：'能写真景物、真感情者，谓之有境界。'
请结合全诗，谈谈此诗是否达到了这一标准。"

"司空图《二十四诗品》云：'不著一字，尽得风流。'
请分析此诗是如何体现含蓄之美的。"

"严羽《沧浪诗话》以'羚羊挂角，无迹可求'形容妙悟。
本诗是否体现了这一特点？请结合诗句分析。"
```

### 答题模板（三阶法）

```
第一阶：理解诗论（1-2 句）
  用自己的话解释诗论观点的核心意思
  → "王国维认为，能写出真实的景物和真实的情感才算有境界"

第二阶：对应诗句（2-3 句）
  从诗中找出能印证这一观点的内容
  → "本诗前两联写……（具体意象），是'真景物'"
  → "后两联……（直接抒情/细节），是'真感情'"

第三阶：分析结论（1-2 句）
  总结诗论与诗歌的契合程度
  → "因此，此诗既有真景物又有真感情，符合王国维的'境界说'"
```

| 刘勰《文心雕龙》 | "登山则情满于山，观海则意溢于海" | 情感投射于景物 | 一切写景类 |
| 钟嵘《诗品》 | "气之动物，物之感人" | 外物触动人情感 | 触景生情类 |
| 曹丕《典论·论文》 | "文以气为主" | 作品风格源于作者气质 | 风格分析类 |

### 诗论题示例

**题目：** 王国维《人间词话》云："一切景语皆情语。"请结合杜甫《登高》赏析这一观点。

```
【答案参考】

① "一切景语皆情语"意为诗歌中所有景物的描写，归根结底都是为抒发情感服务的。

② 《登高》前两联写"风急天高猿啸哀，渚清沙白鸟飞回。无边落木萧萧下，
不尽长江滚滚来"，表面上句句写景，实则处处含情：
"风急""天高"写出环境的苍凉，也暗示诗人内心的动荡；
"猿啸哀"是景更是悲的投射；
"落木萧萧"象征生命凋零，"长江滚滚"暗示时光流逝不可挽回。

③ 这些景物裹挟着杜甫晚年漂泊、老病孤愁的复杂情感，真正做到"一切景语皆情语"。
```

## 六、比较阅读专项

> 基础模板在《高考阅读答题模板》已列出基本框架
> 这里补充深层维度和操作技巧

### 四大比较维度详解

**维度一：意象/意境比较**

```
问法：两首诗选取的意象有何异同？
分析路径：
① 列举各自的主要意象
② 比较意象的类别（自然 vs 人文 / 开阔 vs 狭小）
③ 分析不同意象如何造成不同意境

示例：
A 诗写"大漠""长河"——意境开阔苍茫
B 诗写"残月""孤灯"——意境冷寂凄清
→ 差异源于诗人处境不同：边塞诗人 vs 闺中思妇
```

**维度二：情感/主旨比较**

```
问法：两首诗表达的情感有何异同？
分析路径：
① 表层情感（都写了什么——如"都写思乡"）
② 深层差异（A 是羁旅漂泊之悲，B 是边塞征战之苦）
③ 造成差异的原因（身份/时代/个人遭遇）

关键：不说"都写了思乡"就完事——要挖到情感层次的差异
```

**维度三：手法比较**

```
问法：两首诗在表现手法上有何异同？
分析路径：
① 各自使用了什么核心手法
② 相同手法但用法不同（如都用比喻，A 是明喻 B 是暗喻）
③ 手法差异如何服务于不同的表达需求

最常见考点：借景抒情 vs 直抒胸臆、比喻 vs 比拟、正面 vs 侧面
```

**维度四：语言风格比较**

```
问法：从语言风格角度比较两首诗。
分析路径：
① 用风格词汇概括（豪放/婉约/沉郁/清新……）
② 从用词/句式/意象三个层面说明
③ 风格差异与诗人气质/时代背景的关系

参考本节"八大核心风格一览"来匹配
```

### 比较阅读答题模板

```
① 总起：这两首诗在……方面（相同/不同）

② 分点（每点都包含 A+B 对比）：

  同（或异一）：……
    A 诗：……（结合诗句）
    B 诗：……（结合诗句）

  异（或异二）：……
    A 诗：……（结合诗句）
    B 诗：……（结合诗句）

③ 原因分析（可选，分值够时加分）：
    造成这种（相同/差异）的原因是……
```

### 比较阅读的常见陷阱

```
陷阱一：只比较不结合诗句
  → 每一条对比都要有"诗句引号"支撑

陷阱二：说同不说异（或说异不说同）
  → 审题看清问的是"异同"还是"不同"

陷阱三：只停留在表面比较
  → 都写月亮 → 区别是 A 写圆月寄托团圆，B 写残月寄托凄凉
     (差异在情感内涵，不在意象本身)

陷阱四：忽略诗人背景
  → 同一个杜甫，前期《望岳》和后期《登高》风格截然不同
  → 诗人风格不是一成不变的
```

## 七、典型真题演示

### 真题一：意象+情感类

**（2023 全国甲卷）阅读下面这首宋诗，完成问题：**

```
和子由渑池怀旧
苏轼

人生到处知何似，应似飞鸿踏雪泥。
泥上偶然留指爪，鸿飞那复计东西。
老僧已死成新塔，坏壁无由见旧题。
往日崎岖还记否，路长人困蹇驴嘶。
```

**问题：** 请赏析"飞鸿踏雪泥"这一意象的妙处。（6 分）

```
【答案】

① "飞鸿踏雪泥"比喻人生经历——鸿雁在雪地上留下爪印后飞走，雪花一化痕迹全消。
② 这一意象化抽象为具体，把"人生无常"这一抽象哲理转化为生动的画面：
"飞鸿"象征漂泊不定的人生，"雪泥"象征短暂易逝的时空。
③ 意象中包含着深刻的哲理：人生处处留痕，但一切终将消逝。
④ 表达了苏轼面对人生无常时的豁达态度——既然留不住，不如坦然面对。
```

### 真题二：炼字+手法类

**（2022 新高考 I 卷）阅读下面这首宋词，完成问题：**

```
念奴娇·过洞庭（节选）
张孝祥

洞庭青草，近中秋、更无一点风色。
玉鉴琼田三万顷，着我扁舟一叶。
素月分辉，明河共影，表里俱澄澈。
悠然心会，妙处难与君说。
```

**问题：** "表里俱澄澈"一句中的"俱"字有何妙处？请简要分析。（6 分）

```
【答案】

① "俱"是"都、全部"的意思，指湖水的表面和内部都清澈透亮。
② 这个副词看似平常，实则一语双关：
   表层：洞庭湖月夜水面与深处皆晶莹澄澈；
   深层：暗喻诗人内心光明磊落、表里如一的品格。
③ "俱"字将写景与抒情完美统一——写的是湖之澄澈，抒的是心之澄澈。
④ 同时"俱"字还强化了"澄澈"的程度，营造出一种空明纯净的意境。
```

### 真题三：诗论题

**（2023 新高考 II 卷）阅读下面这首宋诗，完成问题：**

```
湖上晚归
林逋

卧枕船舷归思清，望中浑恐是蓬瀛。
桥横水木已秋色，寺倚云峰正晚晴。
翠羽湿飞如见避，红蕖香袅似相迎。
依稀渐近诛茅地，鸡犬林萝隐隐声。
```

**问题：** 王国维《人间词话》云："能写真景物、真感情者，谓之有境界。"请结合本诗分析其"境界"。（6 分）

```
【答案】

① 王国维认为，诗歌的"境界"来源于对真实景物和真实情感的呈现。
只有二者兼备，才算有境界。

② 本诗做到了"真景物"：
   "桥横水木已秋色""寺倚云峰正晚晴"——秋色、云峰、晚晴，写景如在眼前；
   "翠羽湿飞""红蕖香袅"——颜色（翠/红）与感官（视觉/嗅觉）交织，
   每一个意象都具体可感。

③ 本诗做到了"真感情"：
   "卧枕船舷归思清"——一个"清"字写出归思的纯净；
   "望中浑恐是蓬瀛"——"浑恐"二字写出沉醉美景时的似真似幻之感；
   尾联"鸡犬林萝隐隐声"——从视觉到听觉，写出归家的亲切感。

④ 此诗景物真实可感、情感自然流露，景物与情感浑然一体，
完全符合王国维"能写真景物、真感情者，谓之有境界"的标准。
```

## 八、易错点速查

> 考场上最容易丢分的不是"不会"，而是"会了但做错了"
> 这些坑，每一个都是历年考生的血泪教训

| 易错点 | 错误示范 | 正解 |
|:-------|:---------|:-----|
| 意象分析死板套用 | "月=思乡，所以这首诗表达了思乡之情" | 月可以表思乡、永恒、孤独、清冷——先看语境再判断 |
| 同一意象前后矛盾 | 前句说"梧桐表高洁"，后句说"梧桐表凄凉" | 梧桐几乎固定=凄凉/孤独，不要硬套"高洁" |
| 手法判断混淆 | 把"比喻"说成"比拟"，把"借景抒情"说成"托物言志" | 比喻=像，比拟=当作（拟人/拟物）；借景=情景分离，托物=物我合一 |
| 手法判断生搬硬套 | 每句都要说"用了XX手法" | 没有手法就不要写——硬写比不写更扣分 |
| 炼字分析空洞 | "生动形象地写出了……" | 要说清楚"哪里生动"——化静为动/化无形为有形/通感…… |
| 炼句忽略手法 | 只翻译句子不分析技巧 | 三步法：内容+手法+作用 |
| 诗论题只抄不分析 | 把诗论原文抄一遍，然后说"这首诗符合" | 要展开：诗论观点解释+对应诗句+契合分析 |
| 诗论曲解原意 | 把"不著一字"理解成"不写字" | "不著一字"=不直说，非不说，是含蓄之美 |
| 比较阅读只比较不结合 | "A诗是豪放风格，B诗是婉约风格" | 每一点都要跟具体诗句挂钩 |
| 风格判断以人废诗 | "杜甫写的所以肯定是沉郁" | 杜甫也有清丽的作品——从文本出发，不从作者出发 |
| 情感概括过于笼统 | "表达了诗人的悲伤" | 悲伤什么？羁旅漂泊/壮志难酬/思乡怀人/惜春伤时——要具体到类型 |
| 选择题用语模糊 | 看到"表达了对人生的感慨"就直接选 | "感慨"太宽泛，要对到具体的情感词才选——模糊选项通常是错的 |

### 考场应急 checklist

```
□ 审题：问"赏析"还是"分析"？"异同"还是"不同"？
□ 读了诗论题第一反应是"它到底在说什么"——不是马上答
□ 涉及手法时先确认"到底有没有这个手法"
□ 结合了诗句（引号不能少）
□ 情感词够具体（不是"悲伤"是"羁旅漂泊之悲"）
□ 比较阅读两边都写了（别偏废）
□ 答题完成了题目要求的所有要点
□ 检查了有没有错别字（"寄"和"寄"、"羁"和"稽"常写错）
```
