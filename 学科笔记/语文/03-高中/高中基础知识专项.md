## 一、成语（3-6 分）

### 新高考趋势

```
旧高考：四个选项选一个成语（选择题）
新高考：自己填成语（不给选项）

→ 从"认得"到"会写"
→ 从"选得出"到"填得对"
```

### 高频易错成语 60 例

#### 易望文生义

| 成语 | 正解 | 误解 |
|:----|:----|:----|
| 侧目而视 | 不敢正视，敬畏 | 斜眼看，轻视 |
| 不刊之论 | 不可修改的言论（刊=修改） | 不能刊登 |
| 差强人意 | 大体上还能让人满意 | 让人不满意 |
| 万人空巷 | 人非常多，都出来了 | 巷子里没人 |
| 文不加点 | 文章一气呵成（点=涂改） | 没有标点 |
| 首当其冲 | 最先受到冲击 | 冲在最前面 |
| 炙手可热 | 权势大，气焰盛（贬义） | 很受欢迎 |
| 明日黄花 | 过时的事物 | 未来很美好 |
| 久假不归 | 长期借用不归还（假=借） | 长期请假 |
| 身无长物 | 非常贫穷，没有多余的东西 | 没有特长 |

#### 易用错对象

| 成语 | 适用对象 |
|:----|:--------|
| 举案齐眉 | 夫妻之间 |
| 相敬如宾 | 夫妻之间 |
| 破镜重圆 | 夫妻失散后重逢 |
| 汗牛充栋 | 书多（不是人多） |
| 美轮美奂 | 建筑/房屋（不是风景） |
| 巧夺天工 | 人工技艺（不是自然） |
| 鬼斧神工 | 自然/人工皆可 |
| 天伦之乐 | 家庭团聚（不是朋友） |
| 不情之请 | 谦辞，自己提请求时用 |
| 鼎力相助 | 感谢别人帮助自己 |
| 洗耳恭听 | 自己听别人讲话 |
| 忝列门墙 | 谦辞，说自己不够格 |

#### 易混淆成语

| ① | ② | 区别 |
|:--|:--|:----|
| 不以为然（不认同） | 不以为意（不在乎） | ①是态度反对，②是态度忽视 |
| 目不暇接（看不过来） | 应接不暇（忙不过来） | ①眼睛，②手脚 |
| 不负众望（没让大家失望） | 不孚众望（不能服众） | ①负=辜负，②孚=信服 |
| 无可厚非（可以批评但不过分） | 无可非议（没有批评的理由） | ①程度轻，②程度重 |
| 鱼目混珠（假充真） | 鱼龙混杂（好坏混在一起） | ①物，②人 |
| 息息相关（密切相关） | 休戚相关（利害相关） | ②只能用于人 |
| 行而不远（不能流传久远） | 行之有效（有效果） | ①是反面，②是正面 |

### 成语做题法

```
三步判断：
① 看语境：感情色彩（褒/贬/中性）
② 看对象：适用对象对不对
③ 看词义：字面义 vs 实际义
```

## 二、病句（3 分）

### 六大类型

#### 1. 语序不当

```
常见错误：
① 多层定语顺序：表领属→时间→地点→数量→动词→形容词→名词
② 多层状语顺序：时间→地点→范围→程度→情态→对象
③ 关联词位置：前后主语一致时，关联词在主语后
                前后主语不一致时，关联词在主语前

例题：
"许多附近的妇女、老人和孩子都跑来看他们。"
→ "附近许多的妇女"（数量词在形容词前）
```

#### 2. 搭配不当

```
常见错误：
① 主谓搭配："他的写作水平有了很大增加"（水平+提高）
② 动宾搭配："他履行了职责"√"他履行了批评"×
③ 修饰语和中心语："激烈的月光"×
④ 一面对两面："能否成功取决于努力"×（两面对一面）

快速判断：
"的"前 → "地"后 → "得"后 → 检查搭配
```

#### 3. 成分残缺或赘余

```
残缺：
① 缺主语——"通过这次学习，使我进步了"（去掉"通过"或"使"）
② 缺宾语——"他提出了"（缺"的论点"）
③ 缺谓语——"他正在图书馆"（缺"看书"）

赘余：
① 语义重复——"大约……左右""非常……很"
② 重复用词——"凯旋归来""悬殊很大""涉及到"
```

#### 4. 结构混乱（句式杂糅）

```
常见杂糅结构：
"由于……的原因" → 由于…… / ……的原因
"是为了……为目的" → 是为了…… / 以……为目的
"本着……的原则" → 以……为原则 / 本着……的精神
"根据……显示" → 根据…… / ……显示
```

#### 5. 表意不明

```
① 指代不明："小明和小刚在路上走，他摔了一跤"（谁摔了？）
② 歧义："四个学校的老师"（四所学校/四个老师）
③ 停顿歧义："他没有做不出来的题"（两种理解）
```

#### 6. 不合逻辑

```
① 自相矛盾："他是全校成绩最好的学生之一"（最好只有一个）
② 否定不当："谁也不会否认他不是英雄"（三从否定=否定）
③ 范围失当："包括……等"多余
```

## 三、修辞手法（3-6 分）

### 九大常考修辞速查

| 修辞 | 定义 | 例句 | 作用模板 |
|:----|:----|:----|:--------|
| 比喻 | 打比方（明/暗/借） | 大弦嘈嘈如急雨 | 把 A 比作 B，生动形象地…… |
| 拟人 | 物当人写 | 废池乔木，犹厌言兵 | 赋予……人的特征，使……有生命力 |
| 排比 | 三个以上相同结构 | 顾吾念之，强秦之所以…… | 增强语势，层层递进 |
| 对偶 | 两两相对 | 落霞与孤鹜齐飞 | 句式整齐，节奏感强 |
| 夸张 | 言过其实 | 白发三千丈 | 突出特征，增强感染力 |
| 反问 | 用问句表肯定 | 安能摧眉折腰事权贵？ | 加强语气，引人思考 |
| 设问 | 自问自答 | 问君能有几多愁？恰似一江春水向东流 | 引出下文，加深印象 |
| 反复 | 重复同一词句 | 蜀道之难，难于上青天！ | 强调情感，加深印象 |
| 通感 | 感官互通 | 声音甜美/冷暖色调 | 丰富表达，新颖独特 |

### 新高考趋势：修辞分析题

```
示例题型：
"文中画线句用了什么修辞手法？请分析其表达效果。"

答题公式：
用了……修辞手法。
（分析）把……比作……/赋予了……人的特征……
（效果）生动形象地写出了……，表达了……情感。
```

## 四、补写句子（6 分）

### 题型本质

```
给一段话了中间挖 3 个空，让你填句子。
不是主观发挥，是"从上下文推断出应该写什么"。
```

### 做题法则

```
四步法：

① 读全文 → 理解这段话在说什么
② 看空的位置 → 
    段首：总起/观点
    段中：递进/转折/并列/因果
    段尾：总结/结论
③ 找关键词 → 空前后的"于是""因此""然而""比如"
④ 看句式 → 前后对称（……是……，……是……）
            前后呼应（不但……，而且……）
```

### 常见逻辑关系

| 位置 | 常见逻辑 | 模板 |
|:----|:--------|:----|
| 开头 | 总起 | ……是指…… / ……有以下几个特点 |
| 句中 | 因果 | 这是因为…… / 因此…… |
| 句中 | 转折 | 但是…… / 然而…… |
| 句中 | 递进 | 不仅……，而且…… |
| 句中 | 举例 | 例如…… / 比如…… |
| 句尾 | 总结 | 总之…… / 由此可见…… |

## 五、其他语用题型

### 表达得体

**常考场景：**

| 场景 | 正确表达 | 错误表达 |
|:----|:--------|:--------|
| 写信问候 | 见字如面/展信舒颜 | 您好（太现代） |
| 请人修改 | 斧正/雅正 | 指正（用于批评） |
| 请人保存 | 惠存 | 保存（太直白） |
| 请人原谅 | 海涵/包涵 | 原谅 |
| 询问年龄 | 贵庚（问成人）/芳龄（问女性）/高寿（问老人） | 你几岁 |
| 初次见面 | 久仰 | 你好 |
| 好久不见 | 久违 | 好久不见 |

### 句式变换

```
长句变短句：
① 提取主干（主谓宾）
② 把修饰语拆成独立短句
③ 按逻辑顺序排列

短句变长句：
① 确定主干（主谓宾）
② 把其他短句变成修饰语
③ 按"定语→状语→中心语"排列
```

### 衔接排序

```
排除法：
① 看首句（哪个句子适合开头）
② 看关联词（找成对的关联词）
③ 看代词（"这样""这种""它"前必有指代）
④ 看时间/空间顺序
```

### 压缩语段

```
① 新闻类：人物 + 时间 + 事件 + 结果
② 说明类：对象 + 特征 + 功能
③ 议论类：论点 + 论据
```
