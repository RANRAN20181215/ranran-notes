# 第五单元 · 使命与抱负

> 奏疏+书信——实用文体中的家国情怀
> 3 课：谏太宗十思疏 / 答司马谏议书 / 与妻书

---

## 单元定位

**核心任务：掌握"实用类文言文"的文体特征——不只是修辞，更是功能性写作。**

```
什么是"实用类文言文"？
  不是写景记叙（散文）
  不是虚构故事（小说）
  是"有明确的写作目的"的文本

本单元三篇：
  《谏太宗十思疏》——臣子对皇帝的建议书
  《答司马谏议书》——朋友之间的政论书信
  《与妻书》——丈夫给妻子的诀别信
  → 三篇都是书信类，但语境完全不同
```

## 10 谏太宗十思疏 — 魏徵

### 文体
- "疏"= 臣子写给皇帝的建议书
- 魏徵以直言敢谏著称，唐太宗李世民在位

### 全文论证

```
开头：居安思危
  "臣闻求木之长者，必固其根本"
  → 类比：想砍到好果子→先固根
  → 想国家长久→先积德义

  三个类比：
    "求木之长 → 固根本"
    "欲流之远 → 浚泉源"
    "思国之安 → 积德义"

中间：对比论证
  善始者实繁（开始做得好的人很多）
  克终者盖寡（能坚持到底的很少）
  → 为什么？因为"得志"之后容易放纵

正文：十思（十条建议）
  ① 见可欲 → 思知足（不贪）
  ② 将有作 → 思知止（不折腾）
  ③ 念高危 → 思谦冲（谦虚）
  ④ 惧满溢 → 思江海（包容）
  ⑤ 乐盘游 → 思三驱（适度）
  ⑥ 忧懈怠 → 思慎始（坚持）
  ⑦ 虑壅蔽 → 思虚心（听取意见）
  ⑧ 想谗邪 → 思正身（端正）
  ⑨ 恩所加 → 思无因喜以谬赏（不滥赏）
  ⑩ 罚所及 → 思无因怒而滥刑（不滥罚）

结尾：总结
  "文武并用，垂拱而治"
  → 做到这十条，不用做什么天下就治理好了
```

### 考试要点

- **"十思"的排比结构**——十句"见……则思……"
- **类比论证**——求木之长者固根本（三个类比连用）
- **"载舟覆舟"**——出自《荀子》"水则载舟，水则覆舟"
- **对比论证**——善始者实繁 vs 克终者盖寡

## 11 答司马谏议书 — 王安石

### 文体
- 书信体驳论
- 王安石变法 → 司马光反对 → 写了三千字的信批评王安石
- 王安石回信=本文

### 论证逻辑

```
司马光指责：王安石变法 → "侵官、生事、征利、拒谏、致怨"

王安石一条条驳（五条反驳）：

① 侵官（越权）？
  "受命于人主"（皇帝让我干的）
  "议法度而修之于朝廷"（经过朝廷讨论）
  "以授之于有司"（交给有关部门执行）
  → 程序合法

② 生事（折腾）？
  "举先王之政，以兴利除弊"
  → 我是继承先王的政策

③ 征利（敛财）？
  "为天下理财"
  → 不是为国库捞钱，是为天下理财

④ 拒谏（不听意见）？
  "辟邪说，难壬人"
  → 我拒绝的是错误的说法

⑤ 致怨（得罪人）？
  "士大夫多以不恤国事、同俗自媚于众为善"
  → 得罪的是那些只顾自己不顾国家的人

最后的名句：
  "度义而后动，是而不见可悔故也"
  → 我认为对的就去做，没什么可后悔的
```

### 核心考点

- **驳论的结构**——逐条反驳，不讲大道理，只讲事实
- **语言风格**——冷静克制（"不见可悔"=我不后悔）
- **名句**：
  - "不为侵官，不为生事，不为征利，不为拒谏"
  - "度义而后动，是而不见可悔故也"
  - "如曰今日当一切不事事，守前所为而已，则非某之所敢知"

## 12 与妻书 — 林觉民

### 文体
- 诀别信——辛亥革命烈士林觉民就义前写给妻子的信
- 背景：1911 年广州起义前三天

### 全文脉络

```
开头：悲痛的独白
  "意映，吾死后，吾家无人为家长"
  → 第一句就让人心碎

第一层：为什么"舍汝而死"
  "吾充吾爱汝之心，助天下人爱其所爱"
  → 不是不爱你，正是因为爱你
  → 才想把这份爱扩大到天下人

第二层：回忆恩爱
  "吾与汝并肩携手，低低切切"
  → 回忆婚后的恩爱
  → 越恩爱，越不舍

第三层：嘱咐后事
  "依新已五岁，转眼成人，汝其善抚之"
  → 嘱托抚养孩子
  → "教其以父志为志"

结尾：绝笔
  "吾今死无余憾，国事成不成自有同志者在。"
  "饮泣而已。"
  → 已无话可说，只剩眼泪
```

### 核心考点

- **书信的文体特征**——有称呼、有问候、有内容、有落款
- **抒情方式**——把"大爱"（爱国）和"小爱"（爱妻）统一起来
- **对比**——"吾至爱汝，即此爱汝一念，使吾勇于就死也"
  - 爱 → 所以更愿意为你去死
  - 不是不爱，是爱得太深所以做出牺牲
- **历史意义**——辛亥革命烈士的精神写照

## 单元总结

| 篇目 | 写信人→收信人 | 目的 | 情感基调 |
|:----|:-------------|:----|:--------|
| 谏太宗十思疏 | 魏徵→唐太宗 | 劝谏皇帝 | 严肃恳切 |
| 答司马谏议书 | 王安石→司马光 | 反驳批评 | 冷静坚定 |
| 与妻书 | 林觉民→妻子 | 诀别 | 深情悲壮 |

三篇共同的"使命与抱负"：
  魏徵：臣子的使命——劝导皇帝
  王安石：改革家的使命——坚持变法
  林觉民：革命者的使命——为天下人而死
