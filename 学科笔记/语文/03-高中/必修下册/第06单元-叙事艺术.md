# 第六单元 · 叙事艺术

> 小说单元——叙事手法的全面训练
> 5 课：祝福 / 林教头风雪山神庙 / 装在套子里的人 / 促织 / 变形记

---

## 单元定位

**核心任务：从"读故事"到"读叙事"——学会分析小说的叙事手法。**

```
初中问：这个人物有什么特点？
        这个故事告诉我们什么道理？

高中问：作者怎么讲述这个故事的（叙事视角）？
        为什么这样安排情节（叙事结构）？
        时间是怎么处理的（叙事节奏）？
```

## 6 祝福 — 鲁迅

### 文体
- 短篇小说，鲁迅写于 1924 年
- 收录于《彷徨》

### 叙事结构

```
顺叙：祥林嫂的一生
  第一次来鲁镇 → 被卖到山里 → 丈夫死 → 儿子被狼吃
  → 第二次来鲁镇 → 被歧视 → 捐门槛 → 仍然被歧视 → 死去

倒叙：故事的讲述方式
  开头："我"回到鲁镇 → 遇见祥林嫂 → 祥林嫂问灵魂问题
  → 第二天听说祥林嫂死了 → 开始回忆

↓
为什么用倒叙？
  → 开头制造悬念：这个半死的女人是谁？
  → 同时建立"我"的视角
  → 让读者带着"她最后死了"的已知结局去读
  → 更觉得悲剧
```

### 核心分析

**祥林嫂的悲剧——不止是个人命运，更是社会制度的必然**

```
祥林嫂的三个"不配"：
  ① 第一个丈夫死后 → 婆婆卖她 → 她不是人，是财产
  ② 第二个丈夫死后 → 被认为"克夫" → 不吉利
  ③ 儿子被狼吃 → 被认为"不详" → 连祭祀都不让碰
  
  最后：捐门槛（赎罪）→ 仍然不被接受
  → 她用尽了一切办法自救 → 但社会不给她出路
```

**"祝福"的双关含义：**

```
表面的祝福：鲁镇年终的祭祀活动（"祝福"）
深层的讽刺：祥林嫂在"祝福"声中死去
  → 大家忙着祝福，没人在乎一个老人的死亡
  → 吃人的封建礼教 vs 表面的祥和
```

### 考试要点

- **倒叙的作用**——为什么不是从祥林嫂小时候写起？
- **"我"的视角**——为什么需要一个"旁观者"来讲述？
- **环境描写的作用**——"祝福"的氛围反衬祥林嫂的死亡
- **标题的含义**——"祝福"的反讽

## 7 林教头风雪山神庙 — 施耐庵

### 文体
- 章回小说，出自《水浒传》第十回

### 林冲的人物弧光

```
从"忍"到"反"的转变——

忍的阶段：
  高衙内调戏林冲妻子 → 林冲"忍了"
  高俅设计陷害 → 林冲被刺配沧州
  路上差点被杀死 → 林冲还"忍了"
  被派去看守草料场 → 林冲还想"熬到刑满"

反的转折：
  陆谦+富安+差拨要烧死林冲
  林冲在庙里听到 → 忍无可忍
  "杀人须见血，救人须救彻"

  杀人的顺序：差拨（最先）→ 富安 → 陆谦（最后）
  对陆谦最恨——因为是最信任的朋友背叛
```

### 环境描写的作用

```
"正是严冬天气，彤云密布，朔风渐起，却早纷纷扬扬卷下一天大雪来。"

雪的三重作用：
  ① 推动情节——大雪压塌草厅 → 林冲去山神庙过夜
    → 不在草料场 → 没被烧死
    → 在山神庙听到阴谋

  ② 渲染气氛——寒冷 = 社会环境的冷酷

  ③ 比喻意义——冤屈像大雪一样铺天盖地
```

### 考试要点

- **林冲性格的变化**——从委曲求全到奋起反抗
- **"雪"的作用**——推动情节+渲染气氛+象征意义
- **"那雪正下得紧"**——"紧"字的妙用
- **"豹子头"的绰号**——林冲是八十万禁军教头

## 8 装在套子里的人 — 契诃夫

### 文体
- 短篇小说，俄国契诃夫代表作

### 别里科夫的"套子"

```
别里科夫的特点——什么都要"装进套子里"

物理的套子：
  晴天穿雨鞋、带雨伞
  耳朵塞棉花
  脸藏在衣领里

精神的套子：
  "千万别出什么乱子"
  所有事情都要循规蹈矩
  不允许任何"越轨"的行为
```

### 深层解读

```
别里科夫=沙皇专制制度的产物
  他不是一个"怪人"，是制度的"产品"

专制制度 → 害怕一切变化
  → 别里科夫 → 对一切"越轨"极度恐惧

他的死 = 旧制度的必然末路
  柯瓦连科推了他一把 → 他滚下楼 → 死了
  "套子"被打破了
  → 但是新生活来了吗？
  → 没有——"一个别里科夫死了，还有千万个别里科夫"
```

### 考试要点

- **"套子"的象征意义**——保守/僵化/害怕变化
- **夸张的手法**——晴穿雨鞋等（契诃夫式的讽刺）
- **结尾的意味深长**——"虽然埋葬了别里科夫，但这种装在套子里的人，还有许多"
- **讽刺的手法**——契诃夫不是大声骂，是用夸张的细节让你笑，笑完之后想哭

## 9 促织 — 蒲松龄

### 文体
- 文言短篇小说，出自《聊斋志异》

### 故事梗概

```
成名 → 被迫交纳蟋蟀（促织） → 抓不到 → 被逼到绝境
  → 妻子去问巫婆 → 得到一张画
  → 按照画找到了蟋蟀 → 儿子不小心弄死了蟋蟀
  → 儿子害怕 → 跳井自杀
  → 儿子的魂魄变成蟋蟀 → 被献上去 → 成名一家得救
```

### 核心分析

```
一只蟋蟀 = 一条人命

荒诞在哪里？
  → 皇宫中的人喜欢斗蟋蟀
  → 地方官为了讨好皇帝 → 逼百姓交蟋蟀
  → 成名交不出 → 妻子自杀未遂 → 儿子跳井
  → 儿子死了变成蟋蟀 → 才完成了任务

结局的反讽：
  "抚军不忘所自，无何，宰以卓异闻"
  → 因为蟋蟀交得好，官员升官了
  → 一个孩子的命换来了官员的政绩
```

### 考试要点

- **荒诞与现实的交织**——人变蟋蟀是荒诞的，但背后的社会现实是真实的
- **"以小见大"**——一只蟋蟀折射出整个社会的黑暗
- **文言词法**：
  - "岁征民间"（征=征收）
  - "里正"（地方小吏）
  - "宰"（县官）
  - "抚军"（巡抚）

## 10 变形记（节选）— 卡夫卡

### 文体
- 现代主义小说，卡夫卡写于 1912 年

### 开头（文学史上最有名的开头之一）

```
"一天早晨，格里高尔·萨姆沙从不安的睡梦中醒来，
发现自己躺在床上变成了一只巨大的甲虫。"
```

为什么开头就要写变形？
  → 现代主义手法："让不可能的事直接发生"
  → 不解释、不铺垫

### 核心解读

```
表面故事：一个人变成了甲虫
深层含义：
  ① 异化——人在现代社会变成了"非人"
    → 格里高尔被工作异化（旅行推销员）
    → 被家庭异化（全家靠他养活）
    → 变成甲虫 = 从"人"变成了"工具"

  ② 家人的态度变化：
    第1阶段：关心（妈妈不让他开门）
    第2阶段：接受（妹妹给他送吃的）
    第3阶段：厌烦（把房间里的东西搬走）
    第4阶段：抛弃（"它必须走"）

  ③ "虫"的象征：
    不是变异，是"真实自我的外化"
    → 原来做人的时候，他才是"虫"
    → 变成虫之后，反而比做人时更真实
```

### 考试要点

- **现代主义的特征**——荒诞、象征、内心独白
- **"变形"的寓意**——人异化为非人
- **与促织的对比**：
  - 促织：变形为救家人
  - 变形记：变形后被家人抛弃

## 单元总复习

### 叙事手法对比

| 篇目 | 叙事视角 | 叙事顺序 | 核心手法 |
|:----|:--------|:--------|:--------|
| 祝福 | 第一人称"我"（旁观者） | 倒叙 | 环境反衬 |
| 林教头 | 第三人称全知 | 顺叙 | 环境推动 |
| 套中人 | 故事中套故事 | 顺叙 | 夸张+讽刺 |
| 促织 | 第三人称全知 | 顺叙 | 荒诞+现实 |
| 变形记 | 第三人称限知（格里高尔视角） | 顺叙 | 荒诞象征 |
