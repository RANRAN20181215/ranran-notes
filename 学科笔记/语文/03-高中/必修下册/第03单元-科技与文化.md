# 第三单元 · 科技与文化

## 单元定位

**核心任务：读懂自然科学类文本——高考实用类文本阅读的直接对应。**

```
前两个单元：文学文本（散文/戏剧/小说）
这个单元：自然科学类文本
  → 逻辑严密，语言精确
  → 有学术术语，但也可以有文采
  → 同样可以赏析"语言表达"
```

## 7 自然选择的证明（节选）— 达尔文

### 文体
- 学术著作节选，出自《物种起源》
- 核心主题：自然选择学说

### 论证逻辑

```
达尔文怎么证明"自然选择"？

第一步：观察到的事实
  生物个体之间有差异
  有些差异可以遗传
  资源是有限的

第二步：推理论证
  个体差异 → 有的更能适应环境 → 生存下来
  → 形成"自然选择"
  
第三步：用例子支撑
  家养动物的人工选择 → 类比自然选择
  海岛上的物种 → 说明地理隔离的作用
```

### 考试要点

- **论证语言**：大量"因为……所以……""如果……那么……"——逻辑连接词密集
- **科学思维**：
  - 不是"一个实验证明一切"
  - 是"大量观察+严密推理"
- **与文学文本的区别**：
  - 不追求语言的优美
  - 追求"准确"和"严谨"

## 8 宇宙的边疆 — 卡尔·萨根

### 文体
- 科普散文——既是科普，也是散文
- 卡尔·萨根 = 美国天文学家 + 科普大师

### 逐段分析

```
第一段：宇宙的尺度
  "宇宙是浩瀚的，但它的法则却是简单的。"
  → 科学家的信念：宇宙是可以用规律理解的

第二段：地球的位置
  "我们在这个宇宙中只是沧海一粟。"
  → 但从宇宙的尺度看地球：它是唯一的家园

第三段：人类的意义
  "我们是宇宙认识自己的方式。"
  → 人类=宇宙的一部分
  → 人类的大脑=宇宙进化出来的"自我意识"

第四段：探索
  "我们为什么要探索宇宙？"
  → 因为我们好奇
  → 因为探索=人类的本质
```

### 核心考点

- **科普散文的"文采"**——不是枯燥的科普，有哲思有诗意
- **"我们是宇宙认识自己的方式"**——人不是宇宙的过客，是宇宙的一部分
- **情感线索**：从敬畏宇宙 → 到珍视地球 → 到肯定人类的价值

## 9 一名物理学家的教育历程 — 加来道雄

### 文体
- 自传性科普文章
- 加来道雄 = 日裔美国物理学家，理论物理学家

### 两条线索

```
第一条线：童年的"鲤鱼"故事
  儿时观察池中的鲤鱼
  想象：如果鲤鱼中有科学家，它们会怎么"解释"它们的世界？
  → 引出"视角"的问题
  → 我们看鲤鱼就像更高维度的生物看我们
  → 为"超弦理论"埋下伏笔

第二条线：青年时期建造"原子对撞机"
  课后自己动手：用废品做了一个小型对撞机
  → 不是"天才的灵光一闪"，是持续的兴趣和行动
  → "教育历程"=热爱+行动
```

### 考试要点

- **叙事方式**——不是平铺直叙，用"鲤鱼"这个比喻贯穿
- **"科学家是怎样炼成的"**——好奇心+动手能力+坚持
- **科普文章的特征**：用生活化的语言解释高深的概念

## 单元总结

```
本单元的三篇文章代表了三种科普类型：
  《自然选择的证明》——学术论著（从哪里来）
  《宇宙的边疆》——科普散文（我在哪里）
  《一名物理学家的教育历程》——科学家自述（我怎么成为的）
  
共同回答了"科学是什么"：
  达尔文：科学是观察和推理
  萨根：科学是仰望星空也脚踏实地
  加来道雄：科学是童年种下的一颗种子
```
