# 必修下册（统编版）

> 高一最难的一册——红楼梦来了
> 年级：高一下学期

---

## 一、整册定位

**核心任务：阅读能力的全面升级——从"读懂一篇"到"读通一类"**

必修下册和上册的明显区别：

```
必修上册：                          必修下册：
  单篇精读       ←→    比较阅读
  一种文体      ←→    多种文体并存
  老师带着读    ←→    自主研读
  短篇为主      ←→   长篇+整本书
```

上册在"适应"，下册开始"上强度"。

### 第一单元：诸子百家——文言文的第一次升级

**核心：从"读懂故事"到"读懂思想"**

这个单元的五篇文章分成两组：

**第一组：诸子思想（前三篇）**

| 篇目 | 出处 | 核心思想 | 文言难点 |
|:----|:----|:---------|:--------|
| 子路曾皙冉有公西华侍坐 | 论语 | 各言其志（不同弟子的不同志向） | 人物语言的理解 |
| 齐桓晋文之事 | 孟子 | 保民而王（仁政思想的集中阐述） | 长篇对话的逻辑推进 |
| 庖丁解牛 | 庄子 | 顺应自然之道 | 比喻说理 + 成语（游刃有余、踌躇满志） |

**第二组：历史叙事（后两篇）**

| 篇目 | 出处 | 核心分析方向 |
|:----|:----|:------------|
| 烛之武退秦师 | 左传 | 外交辞令的说理艺术——短短一段话如何说服秦伯 |
| 鸿门宴 | 史记 | 座次描写中的政治暗示 + 人物对比（项羽 vs 刘邦） |

**本单元最大难点：文言文不再"翻译完就完事"**

```
初中：烛之武退秦师 → 翻译成现代文 → 懂了
高中：烛之武退秦师 →
  第一步：逐字翻译（实词/虚词/句式）
  第二步：分析说理逻辑（每一句在做什么？）
  第三步：评价语言艺术（为什么这么说效果好？）
```

**学习建议：**
每篇文章准备两个版本的阅读：
1. **文言文原版**——读三遍，直到不翻译也能顺下来
2. **论证分析版**——画出每段的论证结构

### 第二单元：戏剧——全新的文体

**核心：戏剧不是"看"的，是"听"和"演"的**

这是高中语文唯一的戏剧单元，包含：

| 篇目 | 类型 | 核心分析 |
|:----|:----|:--------|
| 窦娥冤 | 元杂剧（中国） | 窦娥的三桩誓愿 + 悲剧的社会根源 |
| 雷雨 | 现代话剧（中国） | 戏剧冲突（周朴园 vs 鲁侍萍）+ 潜台词 |
| 哈姆莱特 | 莎士比亚（外国） | "生存还是毁灭"独白 + 人性复杂 |

**戏剧和小说最大的区别：**
```
小说有"叙述者"告诉你发生了什么
戏剧只有"对话"——你得从对话中推断发生了什么

读戏剧 = 当侦探
  谁是好人？——不一定
  谁在说谎？——一定有人
  真相是什么？——自己拼图
```

### 第四单元：信息时代——跨媒介阅读

**核心：在信息时代，你能分清真伪吗？**

```
"某某明星被曝出轨" —— 你信吗？
"转发这条能救命" —— 你转吗？
"专家说吃这个致癌" —— 你怕吗？
```

这个单元教的是**媒介素养**：
- 信息的来源可靠吗？
- 有没有其他证据？
- 传播者的目的是什么？

**考试不直接考，但作文素材常常用到。**

### 第五单元：革命经典——小说鉴赏 ⚠️

**核心：五篇小说，五种"异化"**

这个单元的五篇作品看似不相关，实则有一条隐藏主线：

| 篇目 | 主人公 | 异化的原因 | 结果 |
|:----|:-------|:----------|:----|
| 祝福 | 祥林嫂 | 封建礼教 | 死亡 |
| 装在套子里的人 | 别里科夫 | 恐惧变革 | 死亡 |
| 林教头风雪山神庙 | 林冲 | 官逼民反 | 反抗 |
| 促织 | 成名之子 | 赋税压迫 | 变形 |
| 变形记 | 格里高尔 | 资本压榨 | 变形 |

**所谓的"革命经典"，不只是红色文学，更是"社会批判"——批判旧制度、旧思想、旧压迫。**

#### 重点篇目深度分析：祝福

**叙事视角——"我"是谁？**
```
不是作者鲁迅
不是故事的主角
是一个"旁观者"
但"我"也有情感和判断

为什么要用一个旁观者来叙事？
→ 让读者成为"另一个旁观者"
→ 在"我"的无能为力中，感受那个社会的冷漠
```

**祥林嫂到底是被谁杀死的？**
```
鲁四老爷 → 不让碰祭品（封建礼教的代表）
柳妈 → 恐吓她捐门槛（迷信的推手）
街坊邻居 → 听她的悲惨故事取乐（冷漠的看客）
她自己 → 被"再嫁不洁"的道德枷锁压垮

没有凶手，但每个人都是凶手
```

**考试高频题：**
- 环境描写的作用（开头祝福氛围 vs 祥林嫂的死）
- 眼睛描写的变化（从"有神"到"呆滞"到"死去的"）
- 为什么叫"祝福"？（反讽——最热闹的时候，最悲惨的死亡）

#### 重点篇目：林教头风雪山神庙

**环境描写推动情节——这是全篇最精妙的设计**

```
雪越来越大：
  第一段：朔风渐起 → 纷纷扬扬卷下一天大雪
  第二段：雪地里踏着碎琼乱玉 → 那两间草厅已被雪压了
  第三段：看那雪，到晚越下得紧了

→ 情节越来越紧张：
  雪大 → 草厅倒 → 去山神庙 → 听到密谋 → 杀人报仇
  每个情节转折都是"雪"推着走的
```

### 第六单元：思辨性阅读——三篇议论文比较 ⚠️

**核心：同样的"劝谏"，不同的写法**

| 篇目 | 作者 | 劝谁 | 怎么劝 | 特点 |
|:----|:----|:----|:------|:----|
| 谏太宗十思疏 | 魏征 | 唐太宗 | 正面说理 | 排比铺陈，气势磅礴 |
| 答司马谏议书 | 王安石 | 司马光 | 驳论 | 逐条反驳，逻辑严密 |
| 六国论 | 苏洵 | 宋仁宗（借古讽今） | 借古论今 | 历史分析，引以为戒 |

**三篇对比的高考题：**

```
1. 三篇文章的论证方式各有什么不同？
2. 哪一篇的说服力最强？为什么？
3. 魏征的"十思"如果放在今天，有什么现实意义？
```

**学习建议：**
做一张"三篇对比表"——论题、论点、论证方式、语言风格、各自优势。

### 第七单元：红楼梦——高一最大工程 🔴🔴

**核心：第一部长篇小说的整本书阅读**

**为什么《红楼梦》这么难？**
```
人物多：有名有姓的 400+
情节杂：贵族日常 + 爱情主线 + 家族兴衰 + 诗词曲赋
主题深：不止是爱情小说，更是社会小说、人生小说
```

**读什么？**

```
前五回是全书总纲（必须精读）：
  第一回：神话缘起——女娲补天、木石前盟
  第二回：冷子兴演说荣国府——人物关系总图
  第三回：林黛玉进贾府——主要人物出场
  第四回：葫芦僧乱判葫芦案——社会背景
  第五回：贾宝玉神游太虚境——命运总预言
```

**怎么读？（给现在高一的学生）**

```
策略一：先看电视剧/精简版
  → 把"这谁啊"的问题先解决
  → 87版电视剧是很好的入门

策略二：拿"人物关系图"对着读
  → 看到不认识的名字先查图
  → 重点记住：贾宝玉、林黛玉、薛宝钗、王熙凤、贾母

策略三：前五回反复读三遍
  → 第一遍：知道谁是谁
  → 第二遍：理解主要冲突
  → 第三遍：看懂伏笔和暗示
```

**考试考什么？**
```
不是考"袭人是谁的丫鬟"
而是考：
  - 林黛玉的"葬花"体现了什么性格？
  - 贾府的衰败有哪些征兆？
  - 红楼梦中"梦"的意象有什么含义？
```

## 五、学期学习路线

```
第1-3周  ─ 第一单元（诸子百家·攻坚战）
第4-5周  ─ 第二单元（戏剧·新文体适应）
第6-7周  ─ 第三单元 + 第四单元（科技+信息·轻松）
第8-12周 ─ 第五单元（小说·中外比较）
第13-14周 ─ 第六单元（思辨阅读·三篇比较）
第15-18周 ─ 第七单元（红楼梦·持久战）← 实际上应该贯穿全学期
第19周   ─ 第八单元 + 期末复习
```

**⚠️ 红楼梦实际建议安排：**
- 第 1-5 周：每天读 2-3 回，做简单的人物卡片
- 第 6 周：读完前 40 回 → 写一段贾府印象
- 第 10 周：读到 80 回前后
- 第 15 周：读完 → 写整体感悟

## 六、给家长的提醒

1. **《红楼梦》一定一定一定要提前看**
   - 如果等老师布置了再读，绝对来不及
   - 暑假就让孩子看 87 版电视剧，先把人物认全

2. **高一下是语文成绩的"真低谷"**
   - 上册还在适应，下册直接上《红楼梦》
   - 很多孩子高一下语文不及格，正常
   - 别焦虑——高二会回升

3. **文言文能力在这里定调**
   - 第一单元的文言文是这个学期最难的
   - 熬过去了，高二的文言文就不怕了
   - 熬不过去，后面所有文言文都欠债

4. **作文开始出现分水岭**
   - 高一下的作文要求比上册高了一个档次
   - 不再是"写清楚"就行，要"有深度"
   - 多关注社会新闻，积累素材
