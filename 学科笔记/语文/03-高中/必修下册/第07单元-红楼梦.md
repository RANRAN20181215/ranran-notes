## 单元定位

**核心任务：读懂《红楼梦》——不只是"讲了什么故事"，更是"怎么讲的故事"。**

```
小学：四大名著之一（当故事看）
初中：记得主要人物和情节
高中：第一次要求"整本书阅读"
  → 不是只看精彩片段
  → 要读全书（至少读完前 80 回）
  → 要有自己的分析
```

## 全书结构速览

### 四大家族关系

```
贾家（宁国府+荣国府）——核心
  祖宗：贾演（宁国）+ 贾源（荣国）
  宁国府：贾敬→贾珍→贾蓉
  荣国府：贾母→贾赦/贾政→贾琏/贾宝玉

史家：
  史太君（贾母）= 贾家的老太君
  史湘云 = 贾母的侄孙女

王家：
  王夫人（贾政的妻子）
  王熙凤（王夫人的侄女）
  薛姨妈（王夫人的妹妹）

薛家：
  薛宝钗、薛蟠
```

### 前 80 回回目结构

```
1-5 回：总纲
  → 第一回：女娲补天+木石前盟（神话背景）
  → 第五回：贾宝玉梦游太虚幻境 → 金陵十二钗判词（人物命运预告）

6-18 回：贾府的全盛时期
  → 刘姥姥一进荣国府
  → 元春省亲（贾家最风光的时候）
  → 大观园建立

19-40 回：大观园里的青春
  → 宝黛的日常（共读西厢/葬花）
  → 众人写诗（海棠诗社）
  → 日常生活

41-60 回：矛盾开始显现
  → 凤姐生病 → 家务交给探春
  → 各种纷争

61-80 回：衰败的前奏
  → 抄检大观园（内斗）
  → 晴雯被赶出（悲剧信号）
  → 迎春出嫁（误嫁）
  → 薛潘娶妻（夏金桂）
```

### 后 40 回（高鹗续）

```
81-98 回：黛玉之死
  → 黛死钗嫁（同一天）
  → 宝玉被骗结婚

99-106 回：贾府被抄
  → 贾府衰败

107-120 回：败落后
```

## 核心人物分析

### 贾宝玉

```
"今古未有之一人"——不爱功名爱女孩

核心特征：
  ① 厌恶仕途经济
     "女儿是水做的骨肉，男子是泥做的骨肉"
     → 不是色狼，是真心尊重女性
   
  ② 痴情
     对黛玉的痴情 → 最后出家
     对晴雯/袭人的感情 → 不是王公子弟的玩弄

  ③ 反抗者
     拒绝"正途"（读书做官）
     不愿被家族安排
```

### 林黛玉

```
"满纸自怜题素怨，片言谁解诉秋心？"

核心特征：
  ① 才华——大观园第一诗人
  ② 敏感——"多心"的根源是自卑
     寄人篱下 → 每一件事都能联想到自己的处境
  ③ 真性情——不会表面一套背后一套
     和宝钗形成鲜明对比
  ④ 悲剧——"还泪"之说
     黛玉的前世=绛珠仙草
     来人间 = 用眼泪偿还神瑛侍者（宝玉）的灌溉之恩
```

### 薛宝钗

```
"好风凭借力，送我上青云。"

核心特征：
  ① 成熟——在所有事情上都很"得体"
  ② 务实——会做人、会办事
  ③ 有城府——不直接表达真实想法
  ④ "完美"的悲剧
     得到了宝玉的人 → 没得到宝玉的心
     同样是被家族安排的牺牲品
```

### 王熙凤

```
"机关算尽太聪明，反算了卿卿性命。"

核心特征：
  ① 精明能干——贾府的实际管理者
  ② 心狠手辣——弄权铁槛寺、逼死尤二姐
  ③ 失败——再精明也算不过"命运"
     最后："一从二令三人木，哭向金陵事更哀"
```

## 重要名场面

### 黛玉葬花（第二十七回）

```
"花谢花飞花满天，红消香断有谁怜。"

黛玉葬花 = 葬自己
  花落 = 春天结束 = 青春凋零 = 自己的命运

葬花词的核心：
  "质本洁来还洁去"——宁死也不妥协
  
  "一朝春尽红颜老，花落人亡两不知"
  → 写的是花，也是林黛玉自己
  → 最后的结局
```

### 共读西厢（第二十三回）

```
宝黛共同的青春期仪式
  宝玉用《西厢记》里的句子试探黛玉：
  "我就是个'多愁多病的身'，你就是那'倾国倾城的貌'"
  
  黛玉的反应：先是生气 → 后来也引用西厢记开玩笑
  → 这是宝黛爱情从"青梅竹马"到"爱情"的转折点
```

### 抄检大观园（第七十四回）

```
贾府的"内斗"爆发
  起因：一个绣春囊被找出来
  王夫人命令抄检大观园

抄检的过程：
  宝玉那边 → 没查出什么
  黛玉那边 → 没查出什么
  探春那边 → 探春反抗（"百足之虫死而不僵"）
  惜春那边 → 查出入画哥哥的东西
  迎春那边 → 查出司棋（最严重）

结果：
  晴雯被赶出（不久病死）
  司棋被赶出
  入画被赶出
  → 对大观园青春世界的毁灭性打击
```

## 考试必考概念

### 金陵十二钗判词

```
正册十二位女性：
  林黛玉/薛宝钗（同一首判词）
  贾元春、贾探春、史湘云、妙玉
  贾迎春、贾惜春、王熙凤、巧姐
  李纨、秦可卿

每一首判词 = 一个人的命运密码
  如：王熙凤
  "凡鸟偏从末世来，都知爱慕此生才。
  一从二令三人木，哭向金陵事更哀。"
  → 凡鸟=凤（繁体"鳳"）
  → 一从二令三人木 = 从/令/休（贾琏对她的态度变化）
  → 哭向金陵 = 最终被休掉回到娘家
```

### 《红楼梦》的艺术特色

```
1. 草蛇灰线，伏脉千里
  → 前文埋下的伏笔，后文一定有照应
  → 判词/曲子/谜语都是伏笔

2. 人物形象的立体性
  → 没有"好人""坏人"之分
  → 每个人都有自己的立场和苦衷

3. 语言的艺术
  → 每一句话说的人都符合其身份
  → 不同的人说不同的话（林黛玉的话vs薛宝钗的话）

4. 悲剧的层次
  爱情悲剧（宝黛）
  家族悲剧（贾府）
  时代悲剧（封建社会必然灭亡）
```
