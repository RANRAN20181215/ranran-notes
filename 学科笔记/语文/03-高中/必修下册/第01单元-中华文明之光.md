# 第一单元 · 中华文明之光

> 诸子散文 + 史传文学——文言文全面升级
> 4 课：齐桓晋文之事 / 庖丁解牛 / 烛之武退秦师 / 鸿门宴

---

## 单元定位

**核心任务：高中文言文的真正起点。**

```
必修上册第六单元是"议论性文言文"
  篇目短小，结构简单
  
必修下册第一单元是"诸子散文+史传文学"
  字词量翻倍 + 句式更复杂 + 思想深度更大
  是高考文言文阅读的直接对应
```

## 1 齐桓晋文之事 — 孟子

### 文体
- 对话体议论文，出自《孟子·梁惠王上》
- 孟子与齐宣王的对话

### 论证结构（重点）

**孟子怎么说服齐宣王推行仁政？**

```
第一步：巧设陷阱
  齐宣王问：齐桓公晋文公称霸的事（霸道）
  孟子答：我不知道，我来讲"王道"

第二步：破题——以羊易牛
  齐宣王见牛被宰而不忍 → 孟子说这就是"仁"
  → 你不是不能行仁政，是不愿意
  
第三步：类比穷追
  "力足以举百钧，而不足以举一羽"
  "明足以察秋毫之末，而不见舆薪"
  → 讽刺齐宣王：你能做到，只是不做

第四步：提出方案
  "老吾老以及人之老，幼吾幼以及人之幼"
  "保民而王，莫之能御也"
  → 核心观点：只要推行仁政，天下没人能阻挡
```

### 必背句子

```
"保民而王，莫之能御也。"
"老吾老以及人之老，幼吾幼以及人之幼。"
"权，然后知轻重；度，然后知长短。"
"是故明君制民之产，必使仰足以事父母，俯足以畜妻子。"
"谨庠序之教，申之以孝悌之义。"
"老者衣帛食肉，黎民不饥不寒，然而不王者，未之有也。"
```

### 考试要点

- **论证方法**：类比论证（以羊易牛 / 举百钧举一羽）+ 对比论证（霸道 vs 王道）
- **孟子的论辩技巧**：不是直接说"你错了"，是引导你自己发现
- **"推恩"的概念**：把对自己家人的爱推广到天下人
- **古今异义**：
  - "妻子"= 妻 + 子（不是配偶）
  - "中国"= 中原地区（不是全国）

## 2 庖丁解牛 — 庄子

### 文体
- 寓言故事，出自《庄子·养生主》
- 庖丁=厨师，解牛=分解牛

### 逐段分析

```
第一段：庖丁解牛的场面
  "手之所触，肩之所倚，足之所履，膝之所踦"
  "砉然向然，奏刀騞然，莫不中音"
  → 解牛 = 像是在跳舞/奏乐
  → 已经把工作变成了艺术

第二段：文惠君问 → 庖丁答（全文核心）
  
  庖丁的三重境界：
    ① "始臣之解牛之时，所见无非牛者"
       一开始：看到的是一整头牛 → 无从下手
    
    ② "三年之后，未尝见全牛也"
       三年后：看到的是牛的骨骼结构 → 知道从哪下刀
    
    ③ "方今之时，以神遇而不以目视"
       现在：不用眼睛看，用精神去感知 → 游刃有余

  三个对比：
    良庖岁更刀（好厨师一年换一把刀）
    族庖月更刀（普通厨师一个月换一把刀）
    庖丁十九年刀如新（十九年刀像新的一样）
    → 因为庖丁"依乎天理"——按照自然的纹理

第三段：文惠君的感悟
  "吾闻庖丁之言，得养生焉。"
  → 从解牛的道理，悟出了养生的道理
  → 养生=顺其自然，不硬碰硬
```

### 核心考点

- **"游刃有余"的含义**：刀在骨缝里游走——做事的最高境界
- **三重境界**：见牛是牛→见牛不是牛→见牛还是牛（哲学三境界）
- **寓言的特点**：借故事说道理
- **成语出处**：游刃有余 / 目无全牛 / 踌躇满志

## 3 烛之武退秦师 — 《左传》

### 文体
- 史传文学，出自《左传》
- 故事背景：公元前 630 年，秦晋联合围攻郑国

### 逐段分析

```
背景：晋文公联合秦穆公打郑国
  → 郑国危在旦夕

第一部分：郑伯请烛之武
  烛之武推辞："臣之壮也，犹不如人"
  → 年轻时没被重用，现在老了让我去？
  郑伯道歉："吾不能早用子"
  → 承认错误

第二部分：烛之武见秦伯（全篇核心）
  烛之武的"三段式"说服：
  
  第一段：先认怂
    "秦晋围郑，郑既知亡矣"
    承认郑国要完——先降低对方的防备心
  
  第二段：说"灭郑对秦不利"
    "越国以鄙远，君知其难也"
    秦国在晋国的西边，郑国在晋国的东边
    灭了郑国=给晋国扩大地盘
    → 对秦国没好处
  
  第三段：说"留着郑国对秦有好处"
    "若舍郑以为东道主"
    留下郑国 = 秦国在东边多一个朋友
    → 往来接待、物资供应
  
  第四段：挑拨秦晋关系
    "且君尝为晋君赐矣"
    你曾经帮过晋国（护送重耳回国）
    晋国现在强大起来了 → 早晚会反过来打你
    → 晋国不可信

  结果：秦伯很高兴 → 撤军
```

### 烛之武的说服逻辑

```
不是"求对方放过"，是"站在秦国的立场分析利弊"
  → 这就是"纵横家"的说话之道
  → 核心：永远用对方的利益来说服对方

四个步骤：
① 示弱（降低防备）
② 灭郑 = 损害秦国
③ 存郑 = 帮助秦国
④ 晋国不可信（离间）
```

### 考试要点

- **烛之武的说话艺术**——用对方利益说服对方
- **省略句**："晋军（于）函陵，秦军（于）氾南"
- **词类活用**：
  - "夜缒而出"（夜=名词作状语，在夜里）
  - "朝济而夕设版焉"（朝/夕=名词作状语）
  - "既东封郑"（东=向东，封=使成为疆界）
- **与《孟子》对比**：孟子是直接说理，烛之武是婉转说服

## 4 鸿门宴 — 司马迁

### 文体
- 史传文学，出自《史记·项羽本纪》
- 中国最著名的饭局

### 全文结构

```
序幕：曹无伤告密 → 项羽大怒 → 范增劝杀刘邦
  → 矛盾建立

第一部分：刘邦的应对
  项伯夜访张良 → 张良告诉刘邦
  刘邦求见项伯 → 结为亲家
  
第二部分：鸿门宴（全文核心）
  项羽留刘邦吃饭
  范增举玦三次 → 项羽默然不应
  项庄舞剑 → 意在沛公
  项伯拔剑对舞 → 保护刘邦
  樊哙闯帐 → 项羽欣赏樊哙的勇猛

第三部分：刘邦逃走
  借口上厕所
  从骊山小道逃回
  留张良善后

尾声：亚父叹
  "夺项王天下者，必沛公也"
  范增预言：项羽必败
```

### 人物分析

```
项羽：这场宴会上暴露了所有弱点
  - 刚愎自用（不信范增）
  - 优柔寡断（举玦不应）
  - 爱面子（不杀来客）
  → 司马迁的结论：项羽有"妇人之仁"

刘邦：这场宴会上展现了所有优点
  - 能屈能伸（屈尊道歉）
  - 善于用人（张良/樊哙）
  - 果断决绝（不打招呼就逃）
  → 这才是能得天下的人

范增：明白人，但老板不听
  "唉！竖子不足与谋"
  → 不是骂项庄，是骂项羽

樊哙：粗中有细
  闯帐 → 说理 → 保护刘邦
  勇 + 智
```

### 四字考点的"固定搭配"

```
项庄舞剑，意在沛公
人为刀俎，我为鱼肉
秋毫不敢有所近
竖子不足与谋
大行不顾细谨，大礼不辞小让
```

### 考试要点

- **人物对比**：项羽 vs 刘邦的决定性差异
- **座次的文化**："项王、项伯东向坐"——东向=最尊贵
- **关键词法**：一个"为"字贯穿全文（为之奈何/为击破沛公军/为天下者）
- **紧张感的营造**：一环扣一环——告密→项伯→鸿门宴→舞剑→闯帐→逃走

## 单元总复习

### 四篇的共同点

```
都在说"一个关键选择"：
  齐宣王：选霸道还是王道？
  庖丁   ：硬碰硬还是顺其自然？
  郑伯   ：放弃抵抗还是派烛之武？
  刘邦   ：硬扛还是示弱？
  
  答案都指向一个方向：
  → 用智慧而不是蛮力
```

### 文言文阅读建议

```
1. 本单元四篇都是高考文言文阅读的原型
   《烛之武退秦师》= 叙事类文言
   《齐桓晋文之事》= 议论类文言
   《庖丁解牛》= 寓言类文言
   《鸿门宴》= 史传类文言

2. 每篇至少逐字翻译三遍
   第一遍：自己尝试翻译
   第二遍：对照注释
   第三遍：不看注释独立翻译
```

### 必背篇目

- 齐桓晋文之事（部分段落）
- 庖丁解牛（全篇）
- 烛之武退秦师（全篇）
- 鸿门宴（第三段"沛公旦日从百余骑来见项王"起）
