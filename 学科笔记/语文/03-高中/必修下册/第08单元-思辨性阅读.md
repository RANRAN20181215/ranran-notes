# 第八单元 · 思辨性阅读

> 三篇经典——从"谏逐客"到"阿房宫赋"到"六国论"
> 3 课：谏逐客书 / 阿房宫赋 / 六国论

---

## 单元定位

**核心任务：思辨性阅读——学会分析论证的漏洞。**

```
前两个单元：欣赏文学作品（诗歌/小说/戏剧/散文）
这个单元：质疑和思辨
  → 作者说得对吗？
  → 这个论证成立吗？
  → 有没有反例？有没有漏洞？
```

## 11 谏逐客书 — 李斯

### 文体
- 奏疏（和《谏太宗十思疏》同类）
- 背景：秦国的宗室建议把外国来的客卿都赶走
- 李斯本人就是"客卿"（楚国人）→ 也在被驱逐之列

### 论证结构（一级棒的说理）

```
第一部分：用历史反驳
  秦穆公 → 用了百里奚（楚国人）+ 蹇叔 → 称霸
  秦孝公 → 用了商鞅（卫国人）→ 强秦
  秦惠文 → 用了张仪（魏国人）→ 扩张
  秦昭襄 → 用了范雎（魏国人）→ 成帝业
  
  结论："此四君者，皆以客之功"
  → 秦国历代君主靠"客卿"才强大
  → 现在要赶走客卿 = 自断臂膀

第二部分：用现在的事实反驳
  你秦王现在用的：
    "随和之宝" → 来自别国
    "明月之珠" → 来自别国
    "太阿之剑" → 来自别国
    "纤离之马" → 来自别国
    "郑卫之女" → 来自别国
  
  结论：你享受别国的东西，却要赶走别国的人
  → 双重标准

第三部分：说理+升华
  "是以泰山不让土壤，故能成其大"
  "河海不择细流，故能就其深"
  "王者不却众庶，故能明其德"

→ 结尾：赶走客卿 → 削弱自己 → 便宜了敌人
```

### 核心考点

- **论证方法**：历史论证（往昔）+ 事实论证（现在）+ 比喻论证（泰山河海）
- **排比句**——骈散结合（对仗工整但自然流畅）
- **对比论证**：用客卿的强大 vs 逐客卿的愚蠢
- **开头结尾**：开头不客气（"臣闻吏议逐客"→ 直接说正题），结尾有力（"不可得也"）

## 12 阿房宫赋 — 杜牧

### 文体
- "赋"——铺陈排比的文体，兼具散文和诗的特点
- 杜牧写在唐朝晚期，借秦朝的教训警示当朝

### 全文结构

```
第一部分：阿房宫的壮丽（铺陈）
  "六王毕，四海一，蜀山兀，阿房出"
  → 四个短句 = 秦国统一的过程
  → 蜀山的树木被砍光了 = 阿房宫盖起来了

  "覆压三百余里，隔离天日"
  "骊山北构而西折，直走咸阳"
  → 极写阿房宫的宏大

  明星荧荧 = 镜子发光
  绿云扰扰 = 女人的头发
  渭流涨腻 = 洗胭脂水把渭河都染腻了
  → 极写秦朝统治者的奢华

第二部分：转折——秦的灭亡
  "嗟乎！一人之心，千万人之心也。"
  → 秦朝统治者只顾自己享受

  "戍卒叫，函谷举"
  → 陈胜吴广起义 → 刘邦攻入关中

  "楚人一炬，可怜焦土"
  → 项羽一把火烧了阿房宫
  → 整个铺陈到这里全部崩塌

第三部分：教训（点明主旨）
  "灭六国者六国也，非秦也"
  → 六国是自己灭的，不是秦灭的

  "族秦者秦也，非天下也"
  → 秦是自己灭的，不是天下人灭的

  最后名句：
  "秦人不暇自哀，而后人哀之"
  "后人哀之而不鉴之，亦使后人而复哀后人也"
  → 如果后人只替秦朝悲哀不吸取教训
  → 那么后来的后人也会替我们悲哀
```

### 核心考点

- **"赋"的文体特征**——铺陈（写阿房宫的极度奢华）→ 转折（一把火烧光）→ 教训
- **对比手法**：开头多奢华 vs 结尾多惨烈
- **"后人哀之而不鉴之"**——杜牧真正想说的：唐朝也会走秦朝的路
- **语言特色**：骈散结合，四字句为主（"六王毕，四海一"）

## 13 六国论 — 苏洵

### 文体
- 论说文（史论）
- 苏洵（苏轼的父亲），写于北宋，借六国灭亡讽谏北宋

### 核心论点

```
"六国破灭，非兵不利，战不善，弊在赂秦。"

一句话概括：六国灭亡不是因为打不过，
               而是因为向秦国割地求和（赂秦）
```

### 论证结构

```
第一段：提出论点
  "六国破灭……弊在赂秦"

第二段：韩魏楚（赂秦三国的下场）
  "今日割五城，明日割十城"
  → 割一点 → 秦国又来要
  → 割到最后 → 被灭
  
  "抱薪救火，薪不尽，火不灭"
  → 比喻：越割地，秦国胃口越大

  核心推理：
    不赂 → 秦国打过来 → 可能打不过
    赂 → 秦国不会停止 → 早晚被灭
  
  ？那为什么不选择打？至少还有一线生机

第三段：齐赵燕（不赂/失策三国的下场）
  齐国：和秦国"连横" → 其他五国灭了 → 齐也灭了
  赵国：五战三胜 → 但中了反间计 → 赵括纸上谈兵 → 长平之战大败
  燕国：坚持最久 → 但最后也被灭了

第四段：总结
  "苟以天下之大，下而从六国破亡之故事"
  → 北宋面对契丹（辽国）也在"纳贡"
  → 这和六国的"赂秦"有什么不同？
  → 苏洵的真正用意：警告北宋朝廷
```

### 考试要点

- **中心论点**——"弊在赂秦"
- **论证方法**：举例论证（六国各自的结局）+ 比喻论证（抱薪救火）
- **借古讽今**——表面上写六国，实际上在批评北宋的"岁币"政策
- **与阿房宫赋对比**：
  - 阿房宫赋：秦的教训
  - 六国论：六国的教训
  - 共同指向：唐朝/北宋的政治现实

## 单元总复习

### 议论文的三要素

```
三篇议论文的"论点-论据-论证"：

谏逐客书：论点（逐客不对）→ 论据（历史证明客卿有用）→ 论证（类比）
阿房宫赋：论点（秦灭于奢）→ 论据（阿房宫的奢华→灭亡）→ 论证（铺陈对比）
六国论：论点（弊在赂秦）→ 论据（六国失败的各自原因）→ 论证（举例+比喻）

三篇都在"借古讽今"：
  李斯：拿历代君主的大度 vs 秦始皇的小气
  杜牧：拿秦的教训 vs 唐朝的奢侈
  苏洵：拿六国的教训 vs 北宋的纳贡
```

- 谏逐客书（全篇）
- 阿房宫赋（全篇）
