# 第二单元 · 戏剧

> 从"读故事"到"读剧本"——冲突是戏剧的灵魂
> 3 课：窦娥冤 / 雷雨 / 哈姆雷特

---

## 单元定位

**核心任务：第一次系统接触戏剧——认识"冲突"的力量。**

```
小说是"叙述"出来的
戏剧是"对话"呈现出来的
  → 没有"他心想""她哭了"这样的叙述
  → 一切信息都要从对白中读出来
  → 还要想象在舞台上的效果
```

## 4 窦娥冤 — 关汉卿

### 文体
- 元杂剧（古典戏剧）
- 关汉卿——元曲四大家之首

### 四折一楔子

```
楔子：窦娥被卖作童养媳
  窦娥三岁丧母，七岁被父亲卖给蔡婆婆
  → 悲剧的开始

第一折：张驴儿父子逼婚
  蔡婆婆被张驴儿父亲救 → 被迫答应婚事
  张驴儿看上窦娥 → 窦娥不从

第二折：诬告+毒杀
  张驴儿想毒死蔡婆婆 → 却毒死了自己的父亲
  张驴儿反过来诬告窦娥
  窦娥不肯认罪 → 被刑讯逼供 → 最终屈招

第三折：窦娥的控诉 ★★（全剧最高潮）
  赴刑场路上的三桩誓愿：
    血溅白练 → 证明冤情
    六月飞雪 → 天降异象
    大旱三年 → 惩罚楚州
  每一桩誓愿都是"不可能的事"
  三桩全部实现 → 冤情连老天都看不下去了

第四折：鬼魂告状 + 平反
  窦娥鬼魂向做官的父亲托梦
  最终冤案昭雪
```

### 核心考点

- **三桩誓愿的意义**——不只是在申诉冤情，更是对黑暗社会的控诉
- **"天地也！只合把清浊分辨"**——天地本该分辨善恶
- **浪漫主义手法**——三桩誓愿全部实现（现实中不可能）
- **窦娥形象**——善良（不愿牵连婆婆）→ 坚强（不肯认罪）→ 反抗（三桩誓愿）

### 重点句子

```
"地也，你不分好歹何为地！天也，你错勘贤愚枉做天！"
"这都是官吏每无心正法，使百姓有口难言。"
```

## 5 雷雨 — 曹禺

### 文体
- 现代话剧（中国 20 世纪最伟大的戏剧作品之一）
- 曹禺 1933 年创作（23 岁写出来的）

### 人物关系图（线索）

```
                  周朴园 ──── 侍萍
                    │            │
         繁漪 ───── 周萍    鲁大海  四凤
                    │            │
                   周冲 ──── 四凤（已死）
```

### 核心冲突

```
第一层：阶级冲突
  周朴园（资本家）vs 鲁大海（罢工工人）
  → 儿子（大海）要革老子（朴园）的命

第二层：伦理冲突
  周萍和继母繁漪有私情
  周萍和侍女四凤有私情 → 四凤是同父异母的妹妹

第三层：命运冲突
  侍萍 30 年前被抛弃 → 30 年后女儿四凤又进了周家
  → 同样的悲剧重复发生

高潮：所有秘密在雷雨之夜爆发
  四凤知道自己和周萍是兄妹 → 触电自杀
  周冲为救四凤也触电 → 死
  周萍开枪自杀
  大海出走
  侍萍疯了
  繁漪疯了
```

### 考试要点

- **"雷雨"的象征意义**——压抑到极点的社会/家庭矛盾 → 爆发
- **戏剧冲突的层次**——社会冲突（阶级）→伦理冲突（乱伦）→命运冲突（重复）
- **用台词表现性格**：
  - 周朴园的语言：居高临下、冷漠（"你是谁？你要多少钱？"）
  - 繁漪的语言：压抑中带着疯狂
  - 鲁大海的语言：直接、激烈
- **"序幕+尾声"的叙事结构**——不是单线叙事

## 6 哈姆雷特（节选）— 莎士比亚

### 文体
- 西方戏剧，莎士比亚最著名的悲剧
- 选段：第三幕第一场（"生存还是毁灭"）

### 背景速览

```
丹麦王子哈姆雷特：
  父亲（老国王）突然去世
  叔叔克劳狄斯娶了母亲 → 成为新国王
  父亲鬼魂告诉哈姆雷特：是叔叔杀了我
  
  哈姆雷特的任务：复仇
  哈姆雷特的问题：该不该信鬼魂？
                  信了之后怎么办？
```

### "生存还是毁灭"段分析

```
"To be, or not to be——that is the question"

生存还是毁灭 = 忍受还是反抗？

第一段：哪个更高贵？
  忍受命运的暴虐 → 默默承受
  奋起反抗 → 结束苦难

第二段：为什么人们选择"默默地忍受"？
  "死的睡眠" → 死后可能做噩梦
  对死后的恐惧 → 让人不敢行动

第三段：犹豫使人失去一切
  "顾虑使我们都成了懦夫"
  "果断炽热的光彩被审慎蒙上一层灰色"

→ 哈姆雷特在犹豫什么？
  不是杀不杀叔叔的问题
  是"要不要做这件事"的哲学思考
```

### 哈姆雷特的特点

```
"延宕的王子"——想得多，做得少

为什么延宕？
  ① 道德困境：杀人（复仇）本身对不对？
  ② 认知困境：鬼魂说的是真的吗？
  ③ 存在困境：人生的意义是什么？

→ 哈姆雷特不是不敢杀人
→ 而是停下来思考"杀人的意义"
→ 这就把他和"普通复仇者"拉开了距离
```

### 考试要点

- **"生存还是毁灭"的多重含义**——个人选择、哲学思考、存在困境
- **独白的作用**——西方戏剧中揭示人物内心的核心手段
- **哈姆雷特 vs 窦娥**——东方悲剧（社会压迫）vs 西方悲剧（人性困境）
- **经典台词**：
  - "即使把我关在一个果壳里，我也会把自己当作一个拥有着无限空间的君王"
  - "脆弱啊，你的名字就是女人"

## 单元总复习

### 三个剧本的对比

| | 窦娥冤 | 雷雨 | 哈姆雷特 |
|:--|:------|:----|:--------|
| 时代 | 元代中国 | 1930s 中国 | 中世纪丹麦 |
| 冲突 | 个人 vs 冤案 | 家庭 vs 社会 | 个人 vs 命运 |
| 核心 | 冤情如何昭雪 | 秘密如何摧毁一切 | 生与死的选择 |
| 结局 | 冤案昭雪 | 全员毁灭 | 同归于尽 |

### 戏剧鉴赏的核心

```
1. 找到"冲突"——戏剧的灵魂
   人与人之间的冲突
   人内心的冲突
   
2. 分析"对白"——不靠叙述
   人物在说什么？为什么这么说？
   人物没说什么？为什么要隐瞒？
   
3. 想象"舞台效果"
   这段对话在舞台上是什么效果？
   灯光/布景/动作有什么暗示？
```
