## 14 玩偶之家（节选）— 易卜生

### 文体
- 社会问题剧（挪威剧作家易卜生，1879 年）

### 故事

```
娜拉 = 家庭主妇，被丈夫称为"我的小云雀""我的小松鼠"
  → 她只是丈夫的一件玩具（"玩偶"）

真相：娜拉曾经伪造签名借钱救丈夫的命
  → 丈夫知道后 → 勃然大怒
  → 危机解除后 → 丈夫立刻原谅

娜拉的决定：
  她突然明白：自己在这个家里只是一个"玩偶"
  → 最后摔门而出

名句：
  "首先我是一个人，跟你一样的人——至少我要学做一个人。"
```

### 核心

```
"玩偶之家" = 娜拉=玩偶、家=笼子

主题：
  → 女性的觉醒
  → 婚姻中的不平等
  → 社会对女性的束缚

"娜拉走后怎样？"（鲁迅的问题）
  → 离开家庭 = 第一步
  → 但社会给女性出路吗？
```

## 15 迷娘（之一）— 歌德

### 核心

```
"你知道那地方？"
  → 迷娘在问：你知不知道我思念的故乡在哪？

重复的"你知道吗？" → 对故乡的渴望
柠檬花开的地方 → 意大利（歌德向往的南方）

情感：对故乡的思念 + 对自由的渴望
```

---

## 16 致大海 — 普希金

### 核心

```
普希金对着大海告别
  → 大海 = 自由的象征
  
提到拿破仑和拜伦：
  → 两个"自由"的代表人物
  
全诗主旨：再见，自由的大海
```

## 17 自己之歌（节选）— 惠特曼

### 核心

```
惠特曼的诗的特点：
  → 自由体诗（不押韵、不讲究格律）
  → 歌颂自我
  → 歌颂平凡

"我赞美我自己，歌唱我自己"
  → 不是自恋，是自信
  → 每个人都是值得被赞美的
```

---

## 18 树和天空 — 特朗斯特罗默

### 核心

```
瑞典诗人，诺贝尔文学奖得主

这首诗很短：
  树在雨中 → 在天空和大地之间
  树=连接天地的存在

意象：
  树 = 扎根大地，又伸向天空
  = 人在现实和理想之间
```
