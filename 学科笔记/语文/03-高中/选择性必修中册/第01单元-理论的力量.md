# 第一单元 · 理论的力量

> 学术理论文章——逻辑严密，论证有力
> 6 课：社会历史的决定性基础 / 改造我们的学习 / 实践是检验真理的唯一标准 / 修辞立其诚 / 怜悯是人的天性 / 人应当坚持正义

---

## 单元定位

**核心任务：读懂理论性文章——理解"论证"的力量。**

```
以前学的：叙述为主（故事/小说）或抒情为主（诗歌/散文）
这个单元：以"论证"为主——纯粹的理论文章

理论文章的特点：
  - 作者有一个观点
  - 用逻辑+证据来证明这个观点
  - 没有故事，没有抒情
```

---

## 1 社会历史的决定性基础 — 恩格斯

### 文体
- 书信体理论文章（恩格斯 1894 年写给瓦尔特·博尔吉乌斯）

### 核心

```
恩格斯的"历史唯物主义"核心命题：
  "经济关系是社会历史的决定性基础"

不是唯一因素？→ "上层建筑的各种因素也起作用"
  → 但归根到底，经济是"最终的决定因素"

难度：这是高中语文最"哲学"的文章
  理解的关键：知道"经济基础决定上层建筑"这个命题就够了
```

## 2 改造我们的学习 — 毛泽东

### 文体
- 政论文（1941 年延安整风运动中的报告）

### 核心

```
批判："主观主义"的学习态度
提倡："实事求是"的学习态度

论证：三种态度的对比
  主观主义的态度：教条主义/经验主义
  马克思列宁主义的态度：实事求是

名句：
  "实事" = 客观存在的事物
  "求是" = 探求其内部规律
```

## 3 实践是检验真理的唯一标准

### 文体
- 理论文章（1978 年发表，引发真理标准大讨论）

### 核心

```
命题本身：
  "实践是检验真理的唯一标准"
  → 不是本本（书本），不是权威（谁说的）
  → 是实践

历史意义：
  1978 年这篇文章=冲破"两个凡是"的思想禁锢
  → 直接推动了改革开放
```

### 文体
- 哲学论文

### 核心

```
"修辞立其诚"出自《周易》
  → 说话写文章要建立在"真诚"的基础上

```

## 5 怜悯是人的天性 — 卢梭

### 文体
- 哲学论文（法国启蒙思想家卢梭）

### 核心

```
卢梭的核心论证：
  人天生就有"怜悯心"
  → 看到别人受苦 → 自己也会难受
  
  这是道德的源头
  不是理性让人变好，是"天性"
  
与孟子的对比：
  孟子：人皆有不忍人之心 → 性善论
  卢梭：怜悯是人的天性 → 同样的思路！
```

## 6 人应当坚持正义 — 柏拉图

### 文体
- 对话体（柏拉图记录苏格拉底的对话）

### 核心

```
苏格拉底在监狱中：
  被判处死刑 → 朋友劝他逃跑
  苏格拉底坚持：不能逃跑

理由：
  "做人应该坚持正义"
  "逃跑 = 不义 = 破坏法律"
  "宁可受不义之害，不可行不义之事"

→ 这是"苏格拉底之死"的精髓
→ 也是西方哲学的核心命题：正义高于生命
```
