# 第三单元 · 史传文学

> 经典史传 + 史论——司马迁到贾谊的千年对话
> 3 课：屈原列传 / 苏武传 / 过秦论

---

## 单元定位

**核心任务：高中文言文的最高难度——长篇史传 + 史论。**

```
必修下册学了诸子散文 + 史传（鸿门宴）
选择性必修中册继续深化史传文学
  → 篇幅更长
  → 人物更复杂
  → 思想更深
```

## 11 屈原列传 — 司马迁

### 文体
- 史传（出自《史记·屈原贾生列传》）
- 屈原 = 中国第一位诗人

### 全文脉络

```
第一部分：屈原的出身和才华
  "博闻强志，明于治乱，娴于辞令"
  → 出身贵族 + 才华横溢

第二部分：被贬
  上官大夫进谗言 → 楚怀王疏远屈原
  "信而见疑，忠而被谤"
  → 忠诚却被怀疑，坦诚却被诽谤

第三部分：作《离骚》（最核心段落）
  司马迁对《离骚》的评价：
  "其文约，其辞微，其志洁，其行廉"
  → 文字简练、含义微妙、志向高洁、行为端正
  
  "其志洁，故其称物芳"
  → 所以他总用香草美人的意象

第四部分：楚国衰亡
  楚怀王客死秦国
  屈原被流放 → 行吟泽畔

第五部分：渔父对话
  渔父问：你怎么搞成这样？
  屈原答："举世皆浊我独清，众人皆醉我独醒，是以见放"
  
  渔父说：你为什么不随波逐流？
  屈原说："宁赴湘流，葬于江鱼之腹中"

第六部分：自投汨罗
  带着对国家灭亡的绝望 → 投江自杀
```

### 核心考点

- **"其文约，其辞微"的评价**——司马迁借屈原写自己
- **香草美人**的比兴传统
- **"信而见疑，忠而被谤"**——千古忠臣的共同命运
- **司马迁的"移情"**——写屈原 = 写自己的遭遇

## 12 苏武传 — 班固

### 文体
- 史传（出自《汉书》）

### 故事梗概

```
苏武奉命出使匈奴 → 被扣留
匈奴让他投降 → 苏武不从
→ 被关在地窖里（不给吃喝）
→ 被放逐到北海（贝加尔湖）放羊
→ 苏武始终手持汉朝的旄节
→ 19 年后回到长安

三个拷问投降的场景：
  ① 卫律的威逼利诱
  ② 李陵的以情动人（老母去世、妻子改嫁）
  ③ 单于的绝境考验（断绝粮食）
  
  苏武的回答只有一句话：我是汉朝人
```

### 核心考点

- **苏武形象**——民族气节的象征，"大丈夫有所为有所不为"
- **对比手法**：
  - 卫律（降将）vs 苏武（守节）
  - 李陵（降将+犹豫）vs 苏武（坚定）
- **细节描写**：
  - "杖汉节牧羊，卧起操持，节旄尽落"
  - → 连符节上的毛都掉光了
- **"始以强壮出，及还，须发尽白"**
  - → 出去时是壮年，回来时头发全白了

## 13 过秦论 — 贾谊

### 文体
- 史论（不是史传，是议论秦朝的兴亡）

### 全文论证

```
上篇：秦的兴起（百年的积累）
  秦孝公 → 商鞅变法 → 国富兵强
  历代延续 → 到秦始皇统一天下
  
  贾谊的笔法：先扬后抑
    把秦的强大写到了极致
    "席卷天下，包举宇内，囊括四海，并吞八荒"

中篇：秦的灭亡（短短的 15 年）
  秦的暴政：
    "焚百家之言，以愚黔首"
    "隳名城，杀豪杰"
    
  陈胜吴广起义：
    "瓮牖绳枢之子，氓隶之人"
    → 非常平凡的人 → 但一呼百应

下篇：总结教训（核心结论）
  "仁义不施而攻守之势异也"
  → 不是因为秦不够强大
  → 是因为统一之后没有实行仁义
  → 打天下和治天下是两个逻辑
```

### 核心考点

- **"仁义不施而攻守之势异也"**——全文核心论点
- **对比手法**：秦的强大（百年积累）vs 秦的灭亡（十五年间）
- **先扬后抑**的论证结构
- **气势磅礴的语言**——排比句的大量使用

## 单元总结

```
三篇都在说"气节"和"教训"：
  屈原：忠诚而死 → 对个人气节的坚守
  苏武：19 年不屈 → 对民族气节的坚守
  过秦论：秦的教训 → 对治国道理的总结
```
