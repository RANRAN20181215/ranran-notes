# 选择性必修中册（统编版）

> 史论与史传——历史思维的起点
> 年级：高二上学期（或下学期前半段）

---

## 一、整册定位

**核心任务：从"读故事"到"读历史"**

```
初中学历史 → 知道"发生了什么"
高中学史传 → 知道"谁，在什么情况下，做了什么"
高中读史论 → 分析"为什么会发生，有什么教训"
```

选择性必修中册的核心是**史传文学 + 史论**——中国传统文化中最有分量的一支。

### 第一单元：理论文章——最容易被忽略的难度

**核心：理论文本的阅读方法**

这个单元是"思辨性阅读"的升级版——读的不再是文学作品，而是理论文章。

| 篇目 | 核心观点 | 阅读难点 |
|:----|:---------|:--------|
| 社会历史的决定性基础 | 经济基础决定上层建筑 | 抽象理论 |
| 改造我们的学习 | 反对主观主义 | 文章结构（层层推进） |
| 实践是检验真理的唯一标准 | 实践第一性 | 历史背景（真理标准大讨论） |
| 修辞立其诚 | 修辞以诚信为本 | 文言色彩的议论 |
| 怜悯是人的天性 | 人性本善（卢梭） | 西方哲学 |

**学习建议：**
```
这个单元最适合"用逻辑学的方法读"：
  1. 找出核心论点（一句话）
  2. 找出分论点（每段的中心句）
  3. 看论证过程（用什么证据来证明）
  4. 评价论证（有没有漏洞）
```

### 第三单元：史传+史论——高二最难 ⚠️

**核心：中国历史叙事的两种基本模式**

```
┌───────────┐    ┌───────────┐
│   史传     │    │   史论     │
│  纪传体   │    │  论说体   │
│  写人     │    │  论事     │
│  列传     │    │  论史     │
│           │    │           │
│ 屈原列传  │    │  过秦论   │
│ 苏武传    │    │  五代史   │
│           │    │  伶官传序  │
└───────────┘    └───────────┘
```

#### 史传部分：屈原列传 + 苏武传

**司马迁写屈原，为什么不是在写传记，而是在写抒情诗？**

- 《屈原列传》里有大量的议论和抒情，和一般的史传完全不同
- 因为屈原的悲剧和司马迁自己的遭遇产生了共鸣
- "信而见疑，忠而被谤"——既是屈原，也是司马迁

**班固写苏武，塑造了什么样的英雄形象？**

- 苏武牧羊 19 年——核心不是"苦"，是"不动摇"
- 对比：卫律的投降 vs 苏武的坚守
- 苏武代表的不是个人气节，是**汉文化的精神符号**

#### 史论部分：过秦论 + 五代史伶官传序

**两篇文章回答同一个问题：朝代为什么兴亡？**

| | 过秦论 | 五代史伶官传序 |
|:----|:-------|:--------------|
| 论什么 | 秦朝兴亡 | 后唐兴亡 |
| 为什么兴 | 内立法度，外连衡而斗诸侯 | 忧劳可以兴国 |
| 为什么亡 | 仁义不施而攻守之势异也 | 逸豫可以亡身 |
| 论证特点 | 铺陈排比，气势磅礴 | 夹叙夹议，对比鲜明 |

**高考高频考点：**
```
1. 两篇史论的论证方法对比
2. "仁义不施"和"忧劳逸豫"的现实意义
3. 史论中的"假设推理"（如果当年……那么……）
```

## 五、给家长的提醒

1. **史传类文章是冉冉现在就可以打基础的**
   - 小学多读历史故事（林汉达、吴姐姐讲历史）
   - 初中学完基本文言文后，可以读《史记》选篇
   - 高中就不会对"列传"这种文体完全陌生

2. **过秦论是高中文言文的巅峰之一**
   - 全文背诵是基本功
   - 建议孩子到高中时，不仅背熟，还要能用自己的话分析"仁义不施"
   - 这是高考场上的"万能论据"

3. **理论文章阅读能力=高考论述类文本高分**
   - 这个能力不靠刷题，靠平时就多读"有观点的文章"
   - 新闻评论、社论、学术短文——高一就可以开始读
