# 第二单元 · 中国革命

> 从黑暗到黎明——中国革命文学的经典
> 4 课：包身工 / 荷花淀 / 小二黑结婚 / 党费

---

## 单元定位

**核心任务：了解中国革命文学——从"受压迫"到"站起来"的文学表达。**

```
四篇文章覆盖了革命文学的主要类型：
  报告文学（包身工）——揭露黑暗
  战争小说（荷花淀）——革命浪漫
  农村小说（小二黑结婚）——新旧交替
  革命故事（党费）——舍身为党
```

---

## 7 包身工 — 夏衍

### 文体
- 报告文学（1936 年发表）

### 核心

```
包身工 = 被工厂包吃包住的年轻女工
  → 实际上是"现代奴隶"
  → 没有自由、没有工资、没有人尊严

夏衍的写法：
  用记者的方式记录事实（报告）
  用文学的方式表达情感（文学）
  → 报告文学 = 事实+文学

名句：
  "黑夜，静寂得像死一般的黑夜！"
```

## 8 荷花淀 — 孙犁

### 文体
- 短篇小说，"荷花淀派"代表作

### 核心

```
战争 + 美 → 孙犁的特色
  别人写战争：残酷、惨烈
  孙犁写战争：美——荷花淀的美、人情的美

名段：
  女人编席的描写：
  "她像坐在一片洁白的雪地上，也像坐在一片洁白的云彩上。"
  → 把日常家务写成诗

  "水生嫂，回去看看吧，爹病了。"
  → 一群妻子找丈夫 → 在船上遇到敌人 → 一起战斗
  → 幽默+温情+勇敢
```

## 9 小二黑结婚 — 赵树理

### 文体
- 短篇小说，山药蛋派代表作

### 核心

```
小二黑+小芹 → 自由恋爱
二诸葛+三仙姑 → 封建家长

主题：
  新社会 vs 旧思想
  年轻人冲破封建枷锁
  农村的新变化

语言：口语化、土话、像说书
  "刘家峤有两个神仙，一个是二诸葛，一个是三仙姑。"
```

---

## 10 党费 — 王愿坚

### 文体
- 短篇小说

### 核心

```
背景：南方游击战争时期
故事：女党员黄新 → 用盐（党费）支援游击队
  → 被敌人发现 → 牺牲

"党费"的含义：
  不只是钱和物
  是忠诚、是牺牲、是信仰
```
