# 文言文阅读进阶

> 超越"逐字翻译"，直击新高考文言文五项核心能力
> 快速阅读·断句·简答·双文本比较·翻译踩分

---

## 一、考纲定位

| 项目 | 内容 |
|:----|:-----|
| 全国卷分值 | 20 分 |
| 题型构成 | 3 道选择题（9 分）+ 2 道翻译（8 分）+ 1 道简答（3 分） |
| 新趋势 | 从纯翻译到理解分析并重，新增文言简答题 |
| 试题选材 | 突破"二十四史"垄断，出现诸子散文、序跋文、书信 |
| 比较阅读 | 双文本对比成为新高考高频题型 |
| 命题逻辑 | 考"读懂"胜过考"逐字翻译" |

> 旧高考：你能翻译出来就得分
> 新高考：你读懂了还得会概括、会分析、会比较

## 二、快速阅读策略——5分钟读懂陌生文言文

> 大部分学生文言文失分不是因为不会，而是因为时间不够。
> 掌握这四步，陌生文言文也能快速锁定核心信息。

### 第一步：圈人名/地名/官名/时间词

读文言文第一遍，不是逐字翻译，而是**标记专有名词**。

| 标记对象 | 标记方式 | 示例 |
|:---------|:--------|:-----|
| 人名 | 方框 □ | 张良、沛公、项王 |
| 地名 | 下划线 __ | 沛县、霸上、鸿门 |
| 官名 | 波浪线 ~~ | 刺史、太守、侍郎 |
| 时间词 | 圆点 · | 初、始、及、后、久之、明年、顷之 |
| 年号 | 圆点 · | 元丰七年、庆历四年 |

> 专有名词不需要翻译，圈出来方便快速定位即可。
> 95% 的文言文选择题错误选项，都是在人名/地名/时间上做手脚。

### 第二步：找谓语动词

**文言文一句话的核心是谓语（动词），找到谓语就找到了句子的骨架。**

```
操作规则：
① 先扫一眼句子，找到最像动词的那个字
② 往前找主语（谁发出的动作）
③ 往后找宾语（动作作用的对象）
④ 剩下的修饰成分（状语/补语）自动归位

示例：
"（张良）出，要项伯"
  谓语"出"→ 主语张良 → 动作
  谓语"要"（邀）→ 宾语项伯 → 动作对象
```

### 第三步：标记"而""以""于""之""其"

> 这五个虚词是文言文的"路标"——看到它们，句子结构就清晰了。

| 虚词 | 结构作用 | 判断技巧 |
|:----|:--------|:--------|
| 而 | 连接前后两个动作/状态 | 前后平级→并列；前后接力→承接；前后相反→转折 |
| 以 | 引出工具/原因/目的 | 以+名词→用；以+动词→来/因为 |
| 于 | 引出地点/对象/比较 | 于+地点→在；于+人→对/向；于+比较对象→比 |
| 之 | 主谓之间取消独立性 | 主语+之+谓语 → 整个变成"一件事" |
| 其 | 推测/反问/祈使语气 | 其+谓语→大概/难道/还是 |

### 第四步：先看题再看文

> 效率最高策略：选择题→读文→翻译→简答

```
操作流程（15 分钟文言文）：

Step 1 [2 min]：看内容理解选择题的四个选项
   → 选项本身就是"翻译提示"
   → 四个选项覆盖了原文 80% 的内容
   → 标记选项中的关键人物和事件

Step 2 [5 min]：快速通读全文（用前三步）
   → 圈名词、找动词、看虚词
   → 确认选项中的信息点位置
   → 用"√×"在选项旁标注

Step 3 [5 min]：做断句+文化常识
   → 这两题不需要读完全文也能做
   → 回头看已标过的位置

Step 4 [3 min]：翻译+简答
   → 翻译：踩点翻译，不确定的按常识推断
   → 简答：从原文找信息，概括作答
```

> 实战经验：先看选项再读文，正确率提升 15-20%。

## 三、断句专项训练

> 断句不是"碰运气"，是逻辑推理。
> 现有笔记只有口诀，这里给出"七法验证"和系统训练方法。

### 断句七法

#### 1. 找名词/代词——名词前后通常断开

```
名词/代词作主语 → 前面断
名词/代词作宾语 → 后面断

示例：
  "项王军壁垓下/兵少食尽/汉军及诸侯兵围之数重"
  （"项王"主语 → 前面是完整的；"垓下"宾语 → 断）
  （"兵"新主语 → 断；"食尽"主谓 → 断）
  （"汉军"新主语 → 断；"之"宾语 → 断）
```

#### 2. 找虚词——句首发语词/句尾语气词

| 类别 | 常见虚词 | 位置 |
|:----|:--------|:----|
| 句首发语词 | 夫、惟、盖、且、故、然则 | 前面断 |
| 句尾语气词 | 也、矣、焉、耳、乎、哉、耶 | 后面断 |
| 句中关联词 | 而、则、以、然 | 看情况，通常前面断 |

```
示例：
  "夫/以铜为镜/可以正衣冠"
  （"夫"发语词 → 独立断开）

  "吾尝终日而思矣/不如须臾之所学也"
  （"矣"句尾 → 断；"也"句尾 → 断）
```

#### 3. 找对话标志——"曰/云/言/道"后断开

```
标志词 + 说话内容 = 断开

示例：
  "孔子曰/三人行/必有我师焉"
  "沛公曰/君安与项伯有故"
  "因笑谓迈曰/汝识之乎"

注意：
  - "曰"字前面如果是主语，主语前也要断
  - 如果"曰"连续出现（对话进行中），每句都要断
```

#### 4. 找固定结构——这些结构内部不断

| 结构 | 示例 |
|:----|:-----|
| 如……何 | 如太行、王屋何 |
| 奈……何 | 奈之何 |
| 不亦……乎 | 不亦说乎 |
| 何以……为 | 何辞为 |
| 得无……乎 | 得无楚之水土使民善盗耶 |
| 与……孰 | 吾与徐公孰美 |
| ……之谓也 | 其是之谓乎 |

```
示例：
  "求剑若此/不亦惑乎"
  （"不亦……乎"是固定结构 → 中间不断）
```

#### 5. 找对称结构——四六句式、对偶排比

> 古人写文章讲究"骈散结合"，遇到整齐的句子，基本上是并列或对仗。

```
示例：
  "不以物喜/不以己悲"
  （两个"不以"对称 → 之间断开）

  "居庙堂之高则忧其民/处江湖之远则忧其君"
  （"居……则……"和"处……则……"对称 → 断开）

  "燕赵之收藏/韩魏之经营/齐楚之精英"
  （三个并列结构 → 各自断开）
```

#### 6. 找转折/递进词——"然/而/但/且"前面常断

```
示例：
  "然/郑亡/子亦有不利焉"
  （"然"表转折 → 前面断）

  "臣虽愚/但知陛下圣明/而群臣莫及"
  （"但"表转折 → 前面断；"而"表递进 → 前面断）
```

#### 7. 语法分析——主谓之间、动宾之间不断

```
错误断句示例：
  "项王/军壁垓下" ✗
  （"项王军"是主语，"壁"是谓语 → 主谓之间不能断）

  "汉军及诸侯/兵围之数重" ✗
  （"汉军及诸侯兵"是主语 → 之间不能断）

正确断句：
  "项王军壁垓下/兵少食尽/汉军及诸侯兵围之数重"
```

### 七法验证流程

```
第一步：凭语感初断
  通读一遍，凭"读着顺不顺"先断一次

第二步：七法验证
  ① 名词前后 → 该断的断了吗？
  ② 虚词标志 → 句首/句尾的断了吗？
  ③ 对话标志 → "曰/云"后断了吗？
  ④ 固定结构 → 内部没断开吧？
  ⑤ 对称结构 → 对仗处断了吗？
  ⑥ 转折递进 → 前面断了吗？
  ⑦ 语法分析 → 主谓之间没断开吧？

第三步：排除法
  高考断句选择题：
  - 用七法排除 2 个明显错的
  - 剩下 2 个再仔细对比
```

### 训练方法

> 断句是"技能"不是"知识"，必须每天练。

| 阶段 | 方法 | 时长 | 材料 |
|:----|:----|:----|:----|
| 初期 | 找无标点文言文，先凭感觉断，再用七法验证 | 每天 1 段 | 《古文观止》短篇 |
| 中期 | 限时断句（2 分钟一段），然后对标准答案 | 每天 2 段 | 历年高考断句题 |
| 后期 | 断句+翻译联动，断完立即口译 | 每天 2 段 | 模拟题/真题 |

**训练注意：**
- 初期允许反复改，中期开始限时
- 断句不需要 100% 准确，断错 1-2 处很正常
- 重点关注"容易断错的地方"（主谓之间、动宾之间）
- 做高考真题时，先自己断，再看选项排除

## 四、文言简答细分题型

> 新高考文言文新增的 3 分简答，本质是"读懂之后的输出"。
> 和翻译不同——翻译考"字字落实"，简答考"概括分析"。

### 题型 1：概括人物形象（最常考）

**考查形式：**
```
文中人物的性格特点是什么？请简要概括。
文中体现了人物哪些品质？结合文本分析。
```

**答题模板：**
```
① 先用 2-4 个形容词概括
② 每个形容词后面跟一句文本依据
③ 格式：性格词 + "体现在……" + 具体表现

示例：
  勤政爱民：体现在亲自巡视灾区、减免赋税；
  清正廉洁：体现在拒绝下属送礼、主动退还额外俸禄。
```

**人物形象形容词库（积累专用）：**

| 类别 | 形容词 |
|:----|:-------|
| 为官 | 勤政爱民、清正廉洁、刚正不阿、秉公执法、体恤百姓、敢于直谏 |
| 品性 | 忠君爱国、孝顺友悌、宽容大度、知恩图报、诚实守信、志向高远 |
| 才能 | 足智多谋、知人善任、文武双全、治学严谨、博闻强识、善于辞令 |
| 性格 | 沉着冷静、临危不惧、坚韧不拔、淡泊名利、谦逊有礼、豪爽仗义 |
| 反面 | 贪生怕死、见利忘义、阿谀奉承、刚愎自用、徇私枉法、心胸狭隘 |

**从哪里找人物形象：**
```
① 人物直接描写（60%）
   语言 → 说了什么（"某曰……"）
   动作 → 做了什么（"某乃……"）
   神态 → 什么表情（"某大怒""某笑曰"）

② 侧面描写（25%）
   他人评价 → "时人谓之……""帝闻而嘉之"
   对比衬托 → "某不如也""皆莫及也"

③ 事件结果（15%）
   做的事最后怎么样了 → "郡中大治""由是知名"
```

### 题型 2：概括事件原因

**考查形式：**
```
……的原因是什么？请简要说明。
为什么……会成功/失败？结合文本分析。
```

**答题框架：主观 + 客观**

| 维度 | 具体内容 | 寻找方向 |
|:----|:--------|:--------|
| 主观原因 | 人物自身的品质、能力、决策 | 人物的语言/行动/选择 |
| 客观原因 | 外部环境、他人帮助、时局变化 | 文中"时/值/会/当是时"等信息 |

```
答题模式：
  原因一（主观）：……
  原因二（客观）：……
  若有三点，再加"原因三"

示例（问：贾谊被贬的原因是什么？）：
  原因一（主观）：贾谊过于锋芒毕露，提出改革触动了老臣利益；
  原因二（客观）：绛侯灌婴等旧臣排挤，文帝迫于压力疏远贾谊。
```

### 题型 3：分析作者观点态度

**考查形式：**
```
作者对……持什么态度？
文中哪句话体现了作者的观点？
作者在叙事中隐含了什么褒贬？
```

**寻找路径：**
```
① 文末议论句（最集中）
   "太史公曰……""异史氏曰……""呜呼……"
   "故曰/由此观之/可谓……"

② 文中评价性词语（看褒贬色彩）
   褒义：贤/忠/仁/良/善/能/智
   贬义：奸/佞/恶/暴/秽/骄/奢

③ 叙事中的倾向（从详略判断）
   详细写的事 → 作者重视/赞赏
   一笔带过 → 作者不认同
```

```
答题模式：
  作者对……持（肯定/否定/辩证）态度。
  文中"……"这句话直接表明了……
  同时作者通过详写……突出了……

示例：
  作者对范雎持肯定态度。
  开篇"范雎者，游说之士也"即定调，
  详写其远交近攻之策，可见作者欣赏其谋略。
```

### 题型 4：概括主要内容

**考查形式：**
```
请概括本文的主要内容（不超过 XX 字）。
文中写了哪几件事？

特别说明：
  新高考文言文选材有时是"多事一传"
  （一篇短文写了人物多件事），需要分段概括。
```

**答题模式：何人 + 何事 + 何果**

```
示例：
  原文：赵良弼为官清廉，任县令时不受贿赂；
  升任太守后，开办学校教化百姓；
  晚年归乡，仍以教书育人为乐。

  概括：赵良弼一生为官清廉、兴学化民，
  晚年仍致力于教育。
  （何人=赵良弼，何事=为官清廉+兴学+教书，
   何果=影响深远）

每件事用一个短句概括：
  ① 某年，做某事，结果如何
  ② 某年，做某事，结果如何
  ③ 某年，做某事，结果如何
```

### 简答题避坑清单

| 常见错误 | 正确做法 |
|:--------|:--------|
| 照抄原文 | 用自己的话重新组织，不要抄整句 |
| 只概括不分析 | "勇敢" → "勇敢，体现在面对敌军时亲自督战" |
| 不分点 | 一定要用 ①②③ 分条列出 |
| 答非所问 | 先看清问什么再答 |
| 过度解读 | 原文没说的不要加，宁缺毋滥 |

## 五、文言文双文本比较

> 新高考新增趋势：两篇文言文放在一起比着读。
> 可能是两个史传人物对比、两篇序言对比、同一事件不同记载对比。

### 比较维度与答题模板

#### 维度 1：人物形象比较

```
答题模板：
  相同点：两文中的人物都……（共同品质）
    A 文：体现在……（具体事例）
    B 文：体现在……（具体事例）

  不同点：A 文侧重……，B 文侧重……
    A 文：……（性格/行为特征）
    B 文：……（性格/行为特征）

示例（比较蔺相如和廉颇）：
  相同：两人都以国家利益为重。
    蔺相如——完璧归赵，维护赵国尊严；
    廉颇——负荆请罪，将相和好。
  不同：蔺相如以"智"胜，廉颇以"勇"称。
    前者善于外交辞令，后者善于攻城略地。
```

#### 维度 2：写作手法比较

```
答题模板：
  叙述角度不同：A 文以（第一/三人称）叙述，B 文以……叙述

  详略安排不同：A 文详写……，略写……；
    B 文详写……，略写……

  艺术效果不同：A 文……，B 文……
```

#### 维度 3：思想观点比较

```
答题模板：
  A 文主张/观点：……
    （从文中"……"可知）
  B 文主张/观点：……
    （从文中"……"可知）

  差异原因分析：
    ① 时代背景不同：……
    ② 作者身份不同：……
    ③ 写作目的不同：……

示例（比较贾谊《过秦论》和苏洵《六国论》）：
  相同：都认为秦灭亡的关键在于失去民心。
  不同：贾谊强调"仁义不施"，从秦自身找原因；
        苏洵强调"弊在赂秦"，从六国策略找原因。
        这与两人所处时代有关——贾谊在汉初反思秦亡教训，
        苏洵在宋面临辽夏威胁，借古讽今。
```

#### 维度 4：语言风格比较

| A 文风格 | B 文风格 | 比较角度 |
|:--------|:--------|:--------|
| 简洁凝练 | 铺陈细致 | 句子长短、修饰多少 |
| 气势磅礴 | 含蓄委婉 | 语气强弱、用词力度 |
| 客观平实 | 情感充沛 | 评价性词语多少 |
| 骈散结合 | 纯散句 | 句式整齐度 |

```
答题模板：
  A 文语言……（如简洁有力），
  体现为多用短句/四字结构；
  B 文语言……（如细腻生动），
  体现为长句多、修饰细。
  原因是 A 文为……（文体），B 文为……
```

### 双文本比较解题流程

```
Step 1：分别速读两文（各 2 分钟）
  圈人名/地名，确定两文的关系
  （同一人物？同一事件？同一主题？）

Step 2：锁定比较点（1 分钟）
  题目问什么比较维度？
  → 人物比较/手法比较/观点比较/语言比较

Step 3：回文定位（2 分钟）
  分别找到两文中对应的关键句
  用不同颜色标记两文各自的信息

Step 4：组织答案（2 分钟）
  先写相同点 → 再写不同点 → 分析差异原因
  每个点都要有文本依据
```

## 六、翻译进阶技巧

> 现有笔记已有基础翻译方法，这里聚焦"踩分意识"。
> 翻译题 8 分，阅卷按"得分点"给分——知道在哪踩分比翻译本身更重要。

### 六大得分点识别

每个翻译句通常设 3-4 个得分点，分布如下：

| 得分点类型 | 出现频率 | 每个分值 | 识别方法 |
|:----------|:--------|:--------|:--------|
| ① 关键实词 | 每句 2-3 个 | 1-2 分 | 课内学过的/多义词/生僻词 |
| ② 特殊句式 | 每句 0-1 个 | 1 分 | 判断/被动/倒装/省略标志 |
| ③ 词类活用 | 每句 0-1 个 | 0.5-1 分 | 名词作动词/意动/使动 |
| ④ 古今异义 | 每句 0-1 个 | 0.5 分 | 双音节词（妻子/交通/卑鄙） |
| ⑤ 通假字 | 每句 0-1 个 | 0.5 分 | 必须译出本字！ |
| ⑥ 固定结构 | 每句 0-1 个 | 0.5 分 | "所以""……之谓也"等 |

### 得分点实战识别

```
示例翻译题：
  "其李将军之谓也？"

逐词分析：
  "其" → 副词，表推测"大概"（虚词得分点）
  "李将军" → 人名，不译
  "之谓也" → 固定结构"……说的就是……"（句式得分点）

通译：大概说的是李将军吧？

得分点分布：
  ① 其（表推测）→ 1 分
  ② 之谓也（固定结构）→ 1 分
  ③ 语意通顺 → 0.5 分
```

```
示例翻译题：
  "王甚尊宠之，而平原君以为羞"

逐词分析：
  "尊宠" → 两个同义实词连用（尊崇宠信）→ 实词得分点
  "之" → 代词"他" → 虚词得分点
  "而" → 表转折"但是" → 虚词得分点
  "以为羞" → "以（之）为羞"，省略 + 意动"以……为羞" → 句式得分点

通译：赵王非常尊崇宠信他，但平原君认为这很羞耻。

得分点分布：
  ① 尊宠（关键实词）→ 1 分
  ② 而（转折）→ 0.5 分
  ③ 以为羞（意动+省略）→ 1 分
  ④ 语意通顺 → 0.5 分
```

### 翻译顺口溜

```
字字落实留删换
文从句顺调补贯
关键词语不放过
特殊句式要体现

解释：
  留：人名/地名/官名/年号保留不译
  删：发语词/衬字不译
  换：古今异义词换成现代说法
  调：倒装句调回正常语序
  补：省略句补出省略成分
  贯：整个句子要通顺连贯
```

### 翻译踩分自检清单

```
写完后，逐个问自己：

□ 每个课内学过的字都译出来了吗？
□ 多义词我选的义项对吗？
□ 判断句有没有加"是/就是"？
□ 被动句有没有加"被/受到"？
□ 倒装句调回正常语序了吗？
□ 省略的成分补充出来了吗？
□ 有词类活用吗？（名作动/意动/使动）
□ 有古今异义吗？（妻子/交通/卑鄙）
□ 有通假字吗？（说出本字）
□ 整个句子读起来通顺吗？
```

## 七、精品文化常识补充

> 现有笔记已有基础 40 条，这里补充高考最易错的"细节辨析"类。

### 官职任免术语辨析

| 词 | 本义 | 升降 | 示例 |
|:--|:----|:----|:-----|
| 迁 | 迁移 | 多数是升 | 迁为太史令（升）|
| 左迁 | 向左迁 | 降 | 左迁九江司马 |
| 徙 | 转移 | 平调 | 徙齐王为楚王 |
| 转 | 转换 | 平调 | 转丞相长史 |
| 出 | 外放 | 多为降 | 出为河南太守 |
| 入 | 进京 | 多为升 | 入为大司农 |
| 征 | 朝廷召 | 升 | 征拜尚书 |
| 辟 | 官府召 | 升 | 辟为掾属 |

> "迁"的升降判断：后面跟好官/升官词就是升，跟降官词就是降。单独出现时通常为升。

### 科举制度细节

| 层级 | 考试名 | 考中者 | 主考官 |
|:----|:------|:------|:------|
| 第一级 | 院试/县试 | 秀才 | 知县/知府 |
| 第二级 | 乡试 | 举人（第一名称"解元"） | 朝廷派 |
| 第三级 | 会试 | 贡士（第一名称"会元"） | 礼部 |
| 第四级 | 殿试 | 进士（一甲/二甲/三甲） | 皇帝 |

**易错辨析：**
- 一甲：状元/榜眼/探花（赐进士及第）→ 共 3 人
- 二甲：若干人（赐进士出身）
- 三甲：若干人（赐同进士出身）
- 连中三元 = 解元 + 会元 + 状元（极难）

### 皇帝称谓辨析

| 称谓类型 | 含义 | 举例 | 易错点 |
|:--------|:----|:----|:-------|
| 谥号 | 死后评定 | 汉武帝、隋炀帝 | 武/炀是谥号不是庙号 |
| 庙号 | 太庙供奉名 | 太宗、高祖 | 祖/宗是庙号标志 |
| 年号 | 纪年 | 贞观、开元 | 皇帝在位可改多个年号 |
| 尊号 | 生前尊称 | 太上皇 | 多为阿谀之词 |

**判断口诀：**
```
带"祖""宗"是庙号    （太祖/太宗/高宗）
带"帝"且是评价性字   （武帝/炀帝/文帝）
带"太"是尊号        （太上皇/太皇太后）
年号有具体含义       （贞观/开元/洪武）
```

|:--|:--------|:--------|:----|
| 揖 | 拱手行礼 | 最轻 | 日常见面 |

### 历法术语辨析

| 词 | 农历日期 | 典型例句 | 易错点 |
|:--|:--------|:--------|:------|

## 八、典型真题演示

### 真题 1：断句题（2023 全国甲卷）

```
原文（未标点）：
  母丧哀毁过礼服除用为右补阙时海内无事选人岁至四夷来贡

选项：
  A. 母丧/哀毁过礼/服除/用为右补阙/时海内无事/选人岁至/四夷来贡
  B. 母丧哀毁/过礼服/除用为右补阙/时海内无事选人/岁至/四夷来贡
  C. 母丧/哀毁过礼/服除用/为右补阙时/海内无事/选人岁至四夷/来贡
  D. 母丧哀毁/过礼服/除用为右补阙/时海内无事/选人岁至/四夷来贡
```

**解题过程：**
```
第一步：找名词
  "母"、"右补阙"（官名）、"海内"、"选人"、"四夷" → 名词

第二步：找固定结构
  "哀毁过礼"是固定搭配（因悲伤过度而超过礼制）

第三步：语法分析
  "服除" = 守丧期满 → 完整结构，不断则不通
  "用为右补阙" = 被任命为右补阙 → 动宾结构

第四步：排除法
  B 把"哀毁过礼"拆成"哀毁/过礼" → 错
  C "服除用/为右补阙时" → "服除用"不通 → 错
  D 同 B → 错
```

**答案：A**

### 真题 2：简答概括题（2024 新高考 I 卷）

```
原文（节选）：
  张璁、桂萼等以议礼骤贵，诸翰林耻之。
  璁、萼亦欲引用知名士，乃言于上曰：
  "杨慎，乃杨廷和子，天下才也。"
  遂令慎为翰林学士。
  慎曰："吾父为议礼得罪于先帝，今吾复为议礼之臣，
  是背父也。"固辞不受。
  闻者莫不壮其节。

问题：杨慎为什么拒绝担任翰林学士？请简要概括。
```

**参考答案：**
```
① 因为其父杨廷和因议礼得罪了先帝，
   杨慎认为再做议礼之臣就是背叛父亲；
② 杨慎坚守孝道和名节，不愿与张璁、桂萼等为伍。
```

**得分点分析：**
```
① 父亲得罪先帝（主观原因）→ 1 分
② 再做议礼之臣是背叛父亲（价值判断）→ 1 分
③ 坚守名节/不愿与张璁等同流（人物品质）→ 1 分
```

### 真题 3：翻译题（2024 全国乙卷）

```
句子："
  令行期年，秦民之国都言新令之不便者以千数。

注意：
  逐词标注得分点：
    令：新法令（实词，1 分）
    行：施行（实词，0.5 分）
    期年：满一年（时间词，0.5 分）
    秦民之……者：定语后置句式（句式，1 分）
    之：（第一个"之"）到/前往（实词，0.5 分）
    国都：都城（古今异义"国"=都城，0.5 分）
    以千数：用千来计算（固定结构，1 分）
```

**参考答案：**
```
新法施行满一年，秦国到国都去诉说新法不便的百姓，
数量要用千来计算。
```

**得分点标注：**
```
令（新法）行（施行）期年（满一年），
秦民（之……者）（到国都去……的百姓）
之国都（到都城）言新令之不便者以千数（用千来计算）。

总得分点数：6 个（满分 8 分中占 6 个得分点）
```

## 九、易错点速查

| 易错点 | 错误表现 | 正解 | 纠正方法 |
|:------|:--------|:----|:--------|
| 断句靠语感 | 读着顺就断，读不顺就不懂 | 用"七法"验证，每处断句都有依据 | 每天 1 段断句训练 |
| 简答抄原文 | 把原文一整句抄下来 | 用自己的话概括，保留关键信息即可 | 每次做完问"能更短吗" |
| 翻译漏得分点 | 大意对了但扣分 | 写完后逐词检查是否每个词都译了 | 用六个得分点清单自检 |
| 人物形象用词不准 | "他很好""他很厉害" | 用专用形容词库——勤政爱民/刚正不阿等 | 积累 20 个常用形容词 |
| 双文本比较只罗列 | A 是这样，B 也是那样 | 要分析"为什么有差异" | 加一句"差异原因" |
| 文化常识猜不出 | 看到生词就放弃 | 从字面+语境推测，排除法 | 积累"形声字推断法" |
| 虚词判断混淆 | "而"表转折还是表并列？ | 看前后语义关系：相反是转折，一致是并列 | 做虚词专项训练 |
| 省略句译不出 | 主语是谁？宾语是谁？ | 从前文找；找不到就用"某人/某事" | 翻译前先补主语 |
| 倒装句没还原 | "句读之不知"译成"句读不知道" | 调回正常语序"不知道句读" | 遇到"之""是"先检查倒装 |
| 通假字没认出 | 按字面义翻译 | 回忆课本出现过的通假字 | 背通假字高频表 |
