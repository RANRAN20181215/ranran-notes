# 高考作文专题

> 60 分——审题·结构·素材·升格，全攻略
> 全国卷 + 新高考卷通用

---

## 一、先搞清楚：高考作文到底在考什么

### 评分标准拆解

```
基础等级（40 分）：
  内容（20 分）——切合题意/中心突出/内容充实/思想健康
  语言（20 分）——语言流畅/结构完整/卷面整洁

发展等级（20 分）：
  深刻（5 分）——透过现象看本质
  丰富（5 分）——材料新鲜/形象丰满
  有文采（5 分）——词语生动/句式灵活
  有创意（5 分）——见解新颖/构思巧妙
```

**本质：高考作文不是在考"文采"，是在考"思维能力"。**

```
三类文（36-41）：能看懂材料，没有大错
二类文（42-49）：观点明确，结构清晰，语言通顺
一类文（50+）：  有深度/有新意/有文采
满分/标杆文（55+）：三项都出色
```

### 高考作文的"第一定律"

> **跑题 = 不及格（25-30 分）**
> 
> 60 分作文跑题直接掉到 25-30 分
> 比任何一道题都致命

所以整篇作文的**第一优先级不是文采，是审题。**

## 二、审题——作文的一切

### 审题四步法

```
第一步：读材料
  圈出关键词
  注意"但""不过""然而"后面的内容（往往是重点）

第二步：找任务
  材料结尾的任务要求是什么？
  "对此你怎么看"→ 议论文
  "给你怎样的启示"→ 结合自身体会
  "写一封信"→ 书信格式

第三步：定立意
  从材料中找到最核心的矛盾/问题
  确立自己的观点（一句话）

第四步：防跑题
  检查：你的观点是否回应了材料的核心问题？
```

### 六种常见材料类型

| 类型 | 特点 | 审题要点 |
|:----|:----|:--------|
| 社会现象 | 给一段社会热点 | 透过现象看本质——不要就事论事 |
| 哲理名言 | 一句/一段话 | 理解核心概念 + 联系现实 |
| 寓言故事 | 一段寓言/故事 | 找出寓意，不要只讲故事本身 |
| 漫画 | 一幅/组漫画 | 看标题 + 看文字 + 看画面细节 |
| 名言组合 | 2-3 句有矛盾的名言 | 找共同点 or 分析为什么不同 |
| 时事评论 | 给不同观点 | 选一个角度深入，不要面面俱到 |

### 审题实操案例

**材料：**
```
有人说："不要让孩子输在起跑线上。"
也有人说："人生是一场马拉松，不是短跑。"
对此，你怎么看？
```

**审题过程：**
```
Step 1：圈关键词
  "起跑线" vs "马拉松" = "短期竞争" vs "长期坚持"

Step 2：找矛盾
  两种说法看似矛盾，但核心都是"如何理解成长"

Step 3：定立意
  两者的关系不是对立——
  "起跑线"重要但有限，"马拉松"才是人生常态
  或者说：起跑线是起点，但终点取决于全程的努力

Step 4：防跑题
  不要只写"努力的重要性"（太宽泛）
  不要只写"内卷的坏处"（偏题）
  要扣住"起跑线"和"马拉松"的比喻
```

## 三、结构——议论文的骨架

### 经典结构：引-议-联-结

```
引（开头，150 字）：
  读材料 → 引出观点（一句话亮出你的态度）

议（主体，500 字）：
  分论点 1 + 论据 + 分析
  分论点 2 + 论据 + 分析
  分论点 3 + 论据 + 分析

联（联系，200 字）：
  联系现实 + 联系自身

结（结尾，150 字）：
  总结全文 + 升华主题
```

### 分论点的三种展开方式

**并列式（最简单）：**
```
分论点 1：从个人角度看……
分论点 2：从社会角度看……
分论点 3：从国家/时代角度看……
```

**递进式（最有力）：**
```
分论点 1：是什么（概念界定）
分论点 2：为什么（原因分析）
分论点 3：怎么做（对策/建议）
```

**对比式（最有深度）：**
```
分论点 1：如果不这样做 → 后果
分论点 2：如果这样做 → 好处
分论点 3：所以我们应该……（折中/选择）
```

### 开头黄金公式

```
① 引材料（1-2 句）
② 过渡（1 句）
③ 亮观点（1 句，全文中心论点）

示例：
材料中"起跑线"和"马拉松"的说法，反映了两种不同的人生观。
（引材料）
在我看来，这两种看法看似矛盾，实则互补。
（过渡）
人生既需要起跑线的准备，更需要马拉松的坚持。
（亮观点）
```

### 结尾黄金公式

```
① 总结（呼应开头/中心论点）
② 升华（联系时代/社会/人生）
③ 展望（有力量的一句话收束）

示例：
跑得快的人或许能赢在起跑线，但跑得久的人才能到达终点。
（总结）
在这个快速变化的时代，我们要警惕"起跑线焦虑"。
（升华）
人生没有白走的路，每一步都算数。
（展望）
```

## 四、素材——让作文有血有肉

### 素材运用的三个层次

```
劣：背一个名人的话，生硬地贴上去
  → "正如鲁迅所说……"（和论点没关系？）

中：选择贴切的事例 + 简单分析
  → "屠呦呦历经 190 次失败才提取出青蒿素"
  → "这说明成功需要坚持"（太浅）

优：事例 + 深度分析 + 链接论点
  → "屠呦呦的 190 次失败，不是简单的'坚持'
  → 而是每一次失败都在缩小可能性空间
  → 真正的坚持不是重复，是迭代"
```

### 高频分类素材库

#### 当代人物

| 人物 | 可用主题 | 一句话素材 |
|:----|:--------|:----------|
| 屠呦呦 | 坚持/创新/淡泊 | 190 次失败提取青蒿素，获诺奖后仍在一线 |
| 袁隆平 | 家国情怀/实干 | 一生只做一件事——让中国人吃饱饭 |
| 张桂梅 | 奉献/教育/女性 | 创办免费女高，让 2000+ 女孩走出大山 |
| 钟南山 | 担当/专业精神 | 两次疫情一线，84 岁逆行武汉 |
| 陈薇 | 科技创新/责任 | 研制埃博拉/新冠疫苗，女将军 |

#### 历史人物

| 人物 | 可用主题 | 一句话素材 |
|:----|:--------|:----------|
| 屈原 | 爱国/理想主义 | "虽九死其犹未悔"——理想主义的高贵 |

#### 当代现象

| 现象 | 可用主题 | 切入角度 |
|:----|:--------|:--------|
| 内卷 | 竞争/焦虑/意义 | 为什么越努力越焦虑？什么是有效努力 |
| 躺平 | 选择/妥协/反抗 | 躺平是对内卷的消极反抗吗 |
| 乡村振兴 | 发展/传统/根 | 从城市回到乡村——根在哪里 |
| 人工智能 | 科技/人文/伦理 | AI 来了，人还有什么优势 |
| 信息茧房 | 认知/选择/局限 | 算法推荐让我们越来越偏执 |

### 素材使用的两个原则

```
原则一：不为用而用
  不要为了凑一个"名人事例"硬塞
  没有合适的素材，宁可不举例，把道理讲透

原则二：要分析，不要讲故事
  "屠呦呦做了什么"不是素材
  "屠呦呦的做法说明了什么"才是素材
```

## 五、升格——从二类到一类

### 二类文常见问题

| 问题 | 表现 | 对策 |
|:----|:-----|:-----|
| 审题偏浅 | 只看到表面，没看到深层 | 多问一层"为什么" |
| 观点平庸 | 说的都是大家都知道的话 | 找一个"虽然……但是……"的角度 |
| 素材老套 | 司马迁/爱迪生/居里夫人 | 更新素材库，用当代人物 |
| 分析单薄 | 讲例子不讲道理 | 每个例子后加 2-3 句分析 |
| 语言死板 | 全是"我们要""应该" | 加比喻/排比/对比 |

### 提分最快的方法

```
最快的提分不是"语言优美"
是"不要犯错"

确保：
  不跑题（最重要）
  结构清晰（老师一眼能看到你的 3 个分论点）
  字迹工整（卷面分真的存在）
  字数够（写到 850-900 字最优）
  开头和结尾写好（给阅卷老师的第一印象和最后印象）
```

## 六、考场实战策略

### 时间分配（50 分钟）

```
0-5 分钟：审题 + 列提纲
  不要急着动笔
  想清楚再写，节省的时间远多于浪费的

5-10 分钟：写开头
  开头定调，决定老师的第一印象

10-40 分钟：写主体
  每段：观点句（段首）+ 论据 + 分析

40-45 分钟：写结尾
  呼应开头 + 升华

45-50 分钟：检查
  有没有错别字
  有没有病句
  标题有没有漏写
```

### 考前一个月怎么准备

```
每周训练：
  周一：读 3 篇高分范文（分析结构）
  周三：练 1 次审题（只写提纲，200 字）
  周五：完整写一篇（限时 50 分钟）
  周末：把这一周的素材整理到本子上

素材本怎么记：
  ┌──────────────────────────────┐
  │ 主题：坚持                    │
  │ 素材：屠呦呦 190 次失败        │
  │ 可用角度：坚持≠重复，坚持=迭代 │
  │ 摘抄好句：……                  │
  └──────────────────────────────┘
```

## 七、给家长的长期建议

对冉冉来说：

```
小学阶段：
  - 多读书（阅读量 = 作文素材的来源）
  - 坚持写日记（有话可说，不怕写）
  - 多问"为什么"（思辨能力的起点）

初中阶段：
  - 开始练议论文提纲（每周一次）
  - 积累人物素材（不用背，用的时候查）
  - 关注社会新闻（不只看，要学会分析）

高中阶段：
  - 高一：练审题，保证不跑题
  - 高二：练深度，从"是什么"到"为什么"
  - 高三：练速度，50 分钟完整写完
```

> **作文的真相：**
> 技巧能帮你从 42 分到 48 分
> 从 48 分到 52 分，靠的是阅读量
> 从 52 到 55+，靠的是思维能力
> 而这三点，都不是高三才开始的
