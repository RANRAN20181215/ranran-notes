# 上篇：乡土中国

## 一、这本书在说什么

**一句话概括：中国传统社会为什么是"这个样子的"**

费孝通 1947 年写了这本书，回答了当时中国人最困惑的一个问题：

> 为什么中国没有像西方那样发展出法治社会？为什么中国人讲"关系"不讲"规则"？

**他的核心判断：**
```
中国是"乡土社会"——从土地里长出来的社会
西方是"契约社会"——从商业里长出来的社会

→ 两种社会有不同的逻辑
→ 用西方的标准评判中国，怎么看怎么不对
→ 不是因为中国"落后"，是因为"底层代码不同"
```

---

## 二、核心概念辨析（必考）

### 概念 1：差序格局 vs 团体格局

| | 差序格局（中国） | 团体格局（西方） |
|:----|:---------------|:---------------|
| 比喻 | 一块石头扔进水里，一圈圈波纹 | 一捆柴，每根是独立的 |
| 关系 | 以自己为中心，亲疏有别 | 人人平等，但界限分明 |
| 道德 | 爱有差等（先爱家人→再爱邻居→再爱陌生人） | 博爱（对所有人都一样） |
| 问题 | 公私不分，缺乏公共精神 | 个人主义，缺乏温情 |

**考试常考：**
```
用"差序格局"分析社会现象：
  → "为什么中国人在外面讲关系不讲规则"
  → "为什么中国社会存在圈子文化"
```

### 概念 2：礼治秩序 vs 法治秩序

| | 礼治 | 法治 |
|:----|:----|:----|
| 基础 | 传统——祖祖辈辈这么做的 | 法律——白纸黑字写着的 |
| 维持 | 靠舆论/羞耻心/习惯 | 靠警察/法院/监狱 |
| 对象 | 对人的教化（让人不想做坏事） | 对行为的约束（让人不敢做坏事） |
| 后果 | 丢了面子 = 大事 | 违法 = 有事 |

**考试常考：**
```
"无讼"——为什么中国传统社会不提倡打官司？
  → 打官司 = 撕破脸 = 破坏了人情
  → 更倾向于"调解"而非"判决"
```

### 概念 3：长老统治

```
传统社会中，老人为什么有权威？
  → 在变化慢的社会里，过去的经验就是对的
  → 老人的经验 = 年轻人的教科书
  → "不听老人言，吃亏在眼前"

现代社会为什么"长老统治"失效了？
  → 社会变化太快，老人的经验不管用了
  → 这就是"代沟"的根源
```

### 概念 4：男女有别

```
乡土社会中，男女界限为什么那么严？
  → 不是封建思想，是"稳定高于一切"
  → 家庭需要稳定，而爱情（感情冲动）会破坏稳定
  → 所以"相敬如宾"比"相爱"更重要
```

### 完整概念表

| 概念 | 一句话定义 | 相反概念 |
|:----|:----------|:--------|
| 差序格局 | 以己为中心，亲疏有别的关系网 | 团体格局 |
| 礼治秩序 | 靠传统和教化维持的社会秩序 | 法治秩序 |
| 长老统治 | 老人因经验优势而获得权威 | 时势权力/法理权力 |
| 男女有别 | 为稳定家庭而限制两性感情表达 | 恋爱自由 |
| 无讼 | 不提倡打官司，倾向调解 | 诉讼社会 |
| 乡土本色 | 生于斯长于斯，不流动 | 流动社会 |
| 熟人社会 | 人与人长期相处，知根知底 | 陌生人社会 |

## 四、考试怎么考

### 题型 1：概念理解

**题目示例：**
> 请结合《乡土中国》中的"差序格局"概念，分析"各人自扫门前雪，莫管他人瓦上霜"的深层原因。

**答题思路：**
```
① 解释"差序格局"：以己为中心，亲疏有别
② 分析现象：在差序格局下，每个人的责任半径只到自家门口
③ 对比团体格局：在西方团体格局下，公共区域是"大家的"
```

### 题型 2：联系现实

**题目示例：**
> 《乡土中国》成书于 1947 年，书中描述的现象在今天的中国是否还存在？请举例说明。

**答题思路：**
```
① 有些消失了——城市化打破熟人社会
② 有些还在——差序格局依然在（过年走亲戚/职场圈子）
③ 有些转化了——从"礼治"到"法治"但人情仍在
```

# 下篇：红楼梦

## 一、这本书在说什么

**一句话概括：一个大家族的兴衰和一群人的命运**

看似在讲贾宝玉和林黛玉的爱情悲剧，其实讲的是三件事：

```
第一条线：爱情线
  宝黛爱情 → 被封建礼教扼杀 → 一个死一个走

第二条线：家族线
  贾府的繁华 → 一步步走向衰败 → 树倒猢狲散

第三条线：命运线
  金陵十二钗的命运 → 判词都已注定 → 千红一哭
```

---

## 四、高频考点

### 考点 1：人物性格分析

**林黛玉的性格特点及表现：**
```
① 多愁善感 — 葬花（花落=自己的命运）
② 才华横溢 — 诗社比赛屡次夺冠
③ 言语尖刻 — 讽刺宝钗、嘲笑刘姥姥
④ 情感专一 — 心中只有宝玉
⑤ 敏感多疑 — 因"金玉良缘"而不安
```

**薛宝钗的性格特点及表现：**
```
① 稳重端庄 — 言行得体，从不出格
② 精明世故 — 懂得讨长辈欢心
③ 博学多识 — 什么都懂，但不张扬
④ 冷 — 看到别人悲剧时能保持冷静
⑤ 功利 — 劝说宝玉读书科举
```

### 考点 2：重要意象

**"金玉良缘" vs "木石前盟"**

```
金玉良缘： 宝钗有金锁 + 宝玉有通灵玉 = 天作之合
木石前盟： 黛玉前身是绛珠仙草 + 宝玉是神瑛侍者 = 前世缘分

→ 表面：神话说（前世 vs 今生）
→ 实质：世俗成功（"金玉"代表利益联姻）vs 纯真爱情（"木石"代表本真）
```

### 考点 3：贾府衰败的原因

```
原因一：经济
  收入越来越少（地租收不上来）
  支出越来越大（维持排场/过年过节/宫里打点）
  → 入不敷出

原因二：政治
  元春失宠 → 没有政治靠山
  被对手参奏 → 抄家

原因三：内部
  男人不争气（贾珍/贾琏/贾赦荒淫无度）
  内斗不断（抄检大观园/上下离心）
  → 从内部烂起
```

### 考点 4：开篇五回的作用

```
第一回：神话缘起，全书基调——"一把辛酸泪"
第二回：冷子兴演说荣国府 → 人物关系总图（读前必看）
第三回：黛玉进府 → 主要人物陆续出场
第四回：葫芦僧判断葫芦案 → 社会背景（官官相护）
第五回：太虚幻境 → 金陵十二钗判词 = 命运总预告

前五回 = 全书的"使用说明书"
```

## 五、阅读建议

### 完整阅读计划

```
第一阶段（暑假/前期）：看 87 版电视剧
  先看电视剧，把人物认全

第二阶段（开学 1-4 周）：读完前 40 回
  重点回目精读：1-5/8/23/27/32-34
  其他回泛读

第三阶段（5-8 周）：读到 80 回
  重点：40-41（刘姥姥）/52-53（晴雯）/74-78（抄检）
  
第四阶段（9-12 周）：读完
  后 40 回快速读完，了解结局即可
```

### 考试应对策略

```
不会考"薛宝钗的丫鬟叫什么"
会考：
  - 林黛玉的"葬花"体现了什么性格
  - 贾府的衰败有哪些征兆
  - 红楼梦中的"梦"有什么含义
  - 对比分析宝钗和黛玉

所以不需要死记硬背细节
需要的是：理解人物+理解主题+能分析
```
