# 高考阅读答题模板

> 论述类·文学类·实用类·古诗文，全题型公式
> 全国卷 150 分，阅读占 70 分

---

## 一、论述类文本阅读（9 分，3 道选择）

### 题型本质

**不是考"读懂没读懂"，是考"文本有没有这么说"。**

```
做论述类文本的三重境界：
  初级：看懂了，凭印象选
  中级：回原文，逐字比对
  高级：每个选项都找到原文依据，再用"八大陷阱"核查
```

### 八大陷阱速查

| 陷阱 | 特征 | 标志词 |
|:----|:-----|:-------|
| 偷换概念 | 选项把 A 概念替换成了相近的 B | "也就是""即" |
| 以偏概全 | 把部分说成全部 | "所有""全部""都""全都" |
| 强加因果 | A 和 B 没有因果关系 | "因此""导致""因为" |
| 张冠李戴 | A 的特征安在 B 头上 | 注意主语 |
| 无中生有 | 原文没提到 | 任何选项都有原文依据才选 |
| 混淆时态 | 把未来说成已发生 | "了""已经""将" |
| 混淆是非 | 把原文的观点说反 | "不是 A 是 B" |
| 曲解文意 | 看起来差不多，但意思微妙地变了 | 最隐蔽，需要逐字比对 |

### 做题流程

```
三步法（8-10 分钟完成三题）：

Step 1：通读全文（2 分钟）
  - 标段落号
  - 圈出每段中心句（一般在段首/段尾）
  - 标注"但""然而""事实上"等转折词

Step 2：读第一题 + 定位（1 分钟）
  - 读选项 → 找到原文对应位置 → 打叉/打勾
  - 第一题通常在 1-2 段

Step 3：逐个排除（4-5 分钟）
  - 找到 3 个错的 → 剩下就是对的
  - 每个错误选项都要说出"什么陷阱"
```

## 二、文学类文本阅读（16 分）

### 小说（必考题型）

#### 题型 1：人物形象分析（4-6 分）

**答题公式：**

```
性格特征 + 文本依据（表现/细节/言行）

格式：XX（性格概括词）。文中通过……（具体表现），体现了……
```

**性格概括词库：**

| 正面 | 反面 |
|:----|:----|
| 勇敢/坚强/善良/勤劳/淳朴/正直/爱国/仁爱 | 自私/虚伪/懦弱/冷漠/贪婪/势利/残忍/偏执 |
| 豁达/乐观/执着/聪慧/含蓄 | 狭隘/悲观/固执/愚昧/外露 |

#### 题型 2：环境描写作用（4 分）

**四个维度：**

```
① 交代背景 —— 时间/地点/季节/时代
② 渲染氛围 —— 营造……气氛
③ 烘托心理 —— 表现人物……心情
④ 推动情节 —— 为下文……做铺垫
```

**答题模板：**

```
这段环境描写（概括内容），属于……描写。
①交代了……（背景）；②渲染了……（氛围）；
③烘托了人物……（心理）；④为下文……做了铺垫。
```

#### 题型 3：情节作用（4 分）

**五个维度（选 3-4 个答）：**

```
① 人物：塑造/丰富人物形象
② 情节：推动情节发展/为下文做铺垫/制造悬念
③ 环境：暗示社会环境
④ 主题：深化/揭示主题
⑤ 读者：吸引读者/引发思考
```

#### 题型 4：标题的含义和作用（6 分）

**含义 = 表层义 + 深层义**

**作用模板：**
```
① 概括文章主要内容
② 点明文章中心/写作对象
③ 设置悬念，激发读者阅读兴趣
④ 作为线索贯穿全文
⑤ 运用了……修辞（象征/比喻/双关）
```

#### 题型 5：叙事视角（近年高频）

| 视角 | 特点 | 效果 |
|:----|:----|:----|
| 第一人称（我） | 有限视角，有代入感 | 真实、亲切、限制信息 |
| 第二人称（你） | 对话感 | 拉近距离，便于抒情 |
| 第三人称（全知） | 上帝视角 | 自由切换，信息全面 |
| 第三人称（有限） | 只写一个人的所见所感 | 限制信息，制造悬念 |

### 散文（偶考）

#### 题型 1：句子赏析（4 分）

**三个角度：**

```
手法角度：用了什么修辞（比喻/拟人/排比等）
           或什么表现手法（象征/对比/衬托）
内容角度：写出了什么（对象特征）
情感角度：表达了什么（作者情感）
```

**模板：**

```
这句话运用了……（修辞/手法），
生动形象地写出了……（内容），
表达了作者……（情感）。
```

#### 题型 2：散文的"形"和"神"（6 分）

```
"形" = 文章写了哪些内容（材料/事例/景物）
"神" = 文章的中心思想/情感主线

问"形散神聚"：
  "形散"体现在：选取了……（多个材料），看似松散
  "神聚"体现在：都围绕着……（核心情感/思想）展开
```

## 三、实用类文本阅读（10 分）

### 非连续性文本（高考常考）

**题型 1：信息提取概括（4 分）**

**做题方法：**
```
① 看题干关键词（找到对应材料）
② 摘取原文关键句
③ 用自己的话概括（不要照抄）
④ 分点作答（①②③）
```

**题型 2：比较分析（6 分）**

**模板：**
```
对比角度：A 和 B 在……（方面）有共同点/不同点

共同点：都体现了……
A 体现为……；B 体现为……

不同点：A 侧重……；B 侧重……
```

**题型 3：图表分析**

注意要点：
```
① 看标题 → 图表在说什么
② 看趋势 → 上升/下降/波动/持平
③ 看极值 → 最高/最低点
④ 看关系 → 正相关/负相关/无关
```

## 四、古诗文阅读（35 分）

### 文言文阅读（20 分）

#### 断句（3 分）

**断句口诀：**
```
① 找名词 → 主语/宾语前后的断开
② 找虚词 → "夫/惟/盖/故/而/则/者/也/矣/焉/乎/耶/哉"常是标志
③ 找对话 → "曰""云""言"后断
④ 找句式 → 对称结构（四六句）
⑤ 排除法 → 排除一定错的
```

#### 文化常识（3 分）

**策略：**
```
知道就说知道 → 直接选
不知道就推理 → 
  - 看字面：左迁 = 往左走 = 降职（左为卑）
  - 看语境：从上下文推测
  - 排除法
```

#### 内容概括（3 分）

**和论述类一样的"回文比对法"：**
```
每个选项回到原文，找到对应句子
逐字比对，看有没有"强加因果/曲解文意/张冠李戴"
```

#### 翻译（8 分，2 句）

**踩点给分——每个字都可能值 0.5 分：**

```
翻译步骤：
① 通读全句，先理解大意
② 逐个实词翻译（尤其是课内学过的）
③ 虚词不能漏（之/其/以/而）
④ 特殊句式要还原语序（倒装→正常）
⑤ 补出省略成分（主语/宾语/介词）

三不原则：
  - 不随意加字
  - 不遗漏实词
  - 不改变原意
```

#### 简答（3 分，新题型）

**模板：**
```
① 从文中找信息（不要自己凭空想）
② 概括提炼（不要照抄原文）
③ 分点作答（①②③）
```

### 古诗词鉴赏（9 分）

#### 选择题（3 分）

**常见错误设置：**
```
① 手法判断错误（把比喻说成拟人）
② 情感解读错误（说成相反的情感）
③ 内容理解错误（把 A 说成 B）
④ 风格判断错误（豪放说成婉约）
```

#### 简答题（6 分）

**万能分析框架：**

```
意象 → 意境 → 手法 → 情感
```

**这个框架可以套在任何一首诗上。**

**常考题型模板：**

**题型 1：赏析某句/某联（6 分）**

```
① 翻译该句（写了什么画面/内容）
② 手法分析（用了什么手法）
③ 表达效果（好在哪里）
④ 情感分析（表达了什么情感）
```

**题型 2：分析全诗情感（6 分）**

```
① 逐联/逐层分析（每联的情感变化）
② 总体概括
③ 结合具体词句说明
```

**情感词汇速查：**

| 类型 | 常见情感 |
|:----|:--------|
| 思乡 | 思乡/怀人/羁旅漂泊/孤独寂寞 |
| 怀古 | 怀古伤今/物是人非/借古讽今/壮志未酬 |
| 送别 | 惜别/劝勉/牵挂/孤独 |
| 山水 | 寄情山水/归隐田园/闲适恬淡 |
| 边塞 | 建功立业/思乡念亲/战争残酷 |
| 忧国 | 忧国忧民/报国无门/壮志难酬 |

**题型 3：比较阅读（6 分，新趋势）**

```
同：两首诗都写了……（主题/意象/手法）
异：A 诗……（特点）；B 诗……（特点）
原因：因为两位诗人……（身份/处境/时代不同）
```

### 名句默写（6 分）

**新高考题型：理解性默写**

```
不考"补写上句"（死记硬背）
考"给语境，写句子"
```

**做题策略：**
```
① 读语境 → 理解在说什么
② 想篇目 → 对应的篇目是哪一篇
③ 写句子 → 注意别写错别字
```

**易错字自查：**
```
"得"和"德" — 师者所以传道受业解惑也（"受"不是"授"）
"生"和"升" — 无生万物（道德经特例）
"见"和"现" — 风吹草低见牛羊
"属"和"嘱" — 举酒属客
```
