## 二、高频虚词 15 例速查

### 1. 之

| 用法 | 例句 |
|:----|:-----|
| 代词（他/它/这） | 作《师说》以贻之 |
| 助词（的） | 古之学者必有师 |
| 助词（取消独立性） | 师道之不传也久矣 |
| 助词（宾语前置标志） | 句读之不知 |
| 助词（定语后置标志） | 马之千里者 |
| 动词（去/到） | 送杜少府之任蜀州 |

### 2. 而

| 用法 | 例句 |
|:----|:-----|
| 表并列 | 蟹六跪而二螯 |
| 表递进 | 君子博学而日参省乎己 |
| 表转折 | 青，取之于蓝，而青于蓝 |
| 表承接 | 锲而舍之，朽木不折 |
| 表修饰 | 吾尝终日而思矣 |
| 表因果 | 余亦悔其随之而不得极夫游之乐也 |

### 3. 以

| 用法 | 例句 |
|:----|:-----|
| 介词（用） | 愿以十五城请易璧 |
| 介词（因为） | 不以物喜，不以己悲 |
| 介词（凭借） | 以勇气闻于诸侯 |
| 连词（来） | 作《师说》以贻之 |
| 连词（因为） | 以其乃华山之阳名之也 |
| 动词（认为） | 皆以美于徐公 |

### 4. 其

| 用法 | 例句 |
|:----|:-----|
| 代词（他的/它的） | 爱其子，择师而教之 |
| 代词（其中的） | 少时，一狼径去，其一犬坐于前 |
| 副词（大概/或许） | 其皆出于此乎？ |
| 副词（难道） | 其孰能讥之乎？ |
| 副词（还是） | 吾其还也 |

### 5. 于

| 用法 | 例句 |
|:----|:-----|
| 介词（在） | 得双石于潭上 |
| 介词（从） | 青，取之于蓝 |
| 介词（比） | 青于蓝 |
| 介词（对/对于） | 于其身也，则耻师焉 |
| 介词（被） | 君幸于赵王 |

### 6-15：快速口诀

| 虚词 | 常考义 | 典型例句 |
|:----|:------|:---------|
| 为 | 作为/成为/替/因为 | 皆为龙舟；且君尝为晋君赐矣 |
| 乃 | 于是/竟然/是 | 乃不知有汉；当立者乃公子扶苏 |
| 因 | 于是/凭借/通过 | 因击沛公于坐；因宾客至蔺相如门谢罪 |
| 所 | ……的东西/处所 | 师者，所以传道受业解惑也；失其所与 |
| 者 | ……的人/提顿 | 古之学者必有师；廉颇者，赵之良将也 |
| 且 | 而且/尚且/暂且 | 且燕赵处秦革灭殆尽之际；臣死且不避 |
| 也 | 判断/解释/停顿 | 师者，所以传道受业解惑也；何也 |
| 焉 | 于何/于此/语气 | 且焉置土石；积水成渊，蛟龙生焉 |
| 乎 | 在/比/疑问语气 | 相与枕藉乎舟中；其闻道也固先乎吾 |
| 矣 | 了（已然/必然） | 则智者尽其谋；吾老矣 |

## 三、特殊句式

### 判断句

| 标志 | 例句 |
|:----|:-----|
| ……者，……也 | 师者，所以传道受业解惑也 |
| ……者，…… | 四人者：庐陵萧君圭君玉 |
| ……，……也 | 和氏璧，天下共传宝也 |
| 乃/即/则/是/非（否定） | 当立者乃公子扶苏；六国破灭，非兵不利 |
| 无标志判断 | 刘备天下枭雄 |

### 被动句

| 标志 | 例句 |
|:----|:-----|
| 于 | 而君幸于赵王 |
| 见 | 信而见疑 |
| 见……于 | 臣诚恐见欺于王而负赵 |
| 为 | 身死人手，为天下笑 |
| 为……所 | 为仲卿母所遣 |
| 被 | 被发行吟泽畔（通假为"披"） |
| 无标志 | 戍卒叫，函谷举 |

### 倒装句

| 类型 | 例句 | 正常语序 |
|:----|:-----|:--------|
| 宾语前置 | 句读之不知 | 不知句读 |
| 宾语前置 | 大王来何操 | 大王来操何 |
| 宾语前置（否定句） | 古之人不余欺也 | 古之人不欺余也 |
| 状语后置 | 青，取之于蓝 | 青，于蓝取之 |
| 状语后置 | 师不必贤于弟子 | 师不必于弟子贤 |
| 定语后置 | 马之千里者 | 千里马 |
| 定语后置 | 石之铿然有声者 | 铿然有声之石 |
| 主谓倒装 | 甚矣，汝之不惠 | 汝之不惠甚矣 |

### 省略句

| 类型 | 例句 | 补充 |
|:----|:-----|:----|
| 省主语 | （ ）见渔人，乃大惊 | 村中人 |
| 省谓语 | 一鼓作气，再（ ）而衰 | 鼓 |
| 省宾语 | 权起更衣，肃追（ ）于宇下 | 之（孙权） |
| 省介词 | 列坐（ ）其次 | 于 |
