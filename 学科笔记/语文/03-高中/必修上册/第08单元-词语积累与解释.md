# 第八单元 · 词语积累与解释

> 语言运用——从"会说话"到"懂语言"
> 无传统课文，以语言实践活动为主

---

## 单元定位

**核心任务：从"用词"到"懂词"——语言的理性认识。**

```
生活中：我们都用词语，但很少想"为什么这么用"
这个单元：让学生思考语言本身
  → 词语从哪里来
  → 词语怎么组合
  → 词语怎么演变
```

---

## 三种学习活动

### 活动一：词语的梳理与分类

```
学习内容：
  - 近义词辨析（美丽/漂亮/好看）
  - 成语积累与运用
  - 古语词、新词、外来词

学习方法：
  可以做一个"我的词语手册"
  → 分类整理：动词/名词/形容词
  → 同义词辨析：把相近的词放在一起比较
```

### 活动二：词语的运用

```
学习内容：
  - 词语的搭配
  - 词语的色彩（褒义/贬义/中性）
  - 词语的选用（为什么用这个词不用那个词）

常见题型：
  "填入最恰当的词语"（高考语用题）
  → 要考虑：搭配 / 感情色彩 / 语体风格
```

### 活动三：语言演变

```
学习内容：
  - 古今词义变化
  - 双音节词化
  - 词类的活用

重点例子：
  "走"——古代=跑，现代=行走
  "江"——古代=长江，现代=任何大江
  "河"——古代=黄河，现代=任何大河
  "妻子"——古代=妻+子，现代=妻子
```

---

## 考试价值

```
1. 语言文字运用模块的直接对应
   高考前两道选择题：词语辨析 + 病句修改
   
2. 文言文翻译的基础
   词义演变的理解直接影响文言文翻译

3. 作文的语言表达
   用词精准 = 高考作文加分项
```
