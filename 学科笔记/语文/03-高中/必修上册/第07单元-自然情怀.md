# 第七单元 · 自然情怀

> 散文的天地——不只是写景，更是写心
> 5 课：故都的秋 / 荷塘月色 / 我与地坛 / 赤壁赋 / 登泰山记

---

## 单元定位

**核心任务：从"读景"到"读情"——散文中的情与景。**

```
初中散文问：作者写了什么景色？表达了什么情感？
高中散文问：作者为什么选择这些景物？
             同一个景物，不同作者看到的为什么不同？
             景物的"主观化"——客观景物被主观情绪染上颜色
```

## 14 故都的秋 — 郁达夫

### 文体
- 现代散文，郁达夫 1934 年写于北平（北京）

### 核心分析

**郁达夫笔下"秋"的特点：不是丰收的秋，是"悲凉"的秋**

```
他选的景物：
  破屋 / 破壁腰 / 牵牛花的蓝朵
  槐树的落蕊 / 秋蝉的残声
  秋风秋雨 / 果树（枣树）

共同特征：静、冷、衰、残

为什么不选"香山的红叶""颐和园的美景"？
  → 因为郁达夫要的不是漂亮，是"悲凉"
  → 悲凉=秋的"味道"=他迷恋的东西
```

**名段赏析：**

```
"在北平即使不出门去吧，就是在皇城人海之中，
租人家一椽破屋来住着，早晨起来，泡一碗浓茶，
向院子一坐，你也能看到很高很高的碧绿的天色，
听得到青天下训鸽的飞声。"

→ 这不是在"写景"，是在写一种生活态度
→ 慵懒、悠闲、从容
→ "破屋"+"浓茶"+"一坐"——文人的雅趣

"秋的意境与姿态，看不饱，尝不透，赏玩不到十足。"

→ 秋的美是含蓄的，需要仔细品味
→ 这也是郁达夫本人的审美趣味
```

### 考试要点

- **选材的独特性**——故意避开了"热闹的秋天"，专写"悲凉的秋天"
- **对比手法**——对比南国之秋与北国之秋
- **"悲凉"的审美价值**——悲凉=美，这是中国传统文人的审美
- **首尾呼应**——开头说"要来北平看秋"，结尾说"愿意用生命换秋天"

## 15 荷塘月色 — 朱自清

### 文体
- 现代散文，朱自清 1927 年写于清华大学

### 逐段分析

**第一部分：去荷塘的原因（"这几天心里颇不宁静"）**

```
"这几天心里颇不宁静"
  → 全文的情感基调
  → 1927 年——大革命失败后的苦闷

"这一片天地好像是我的；我也像超出了平常的自己"
  → 月下的荷塘 = 暂时逃离现实的空间
  → 现实世界 vs 精神世界
```

**第二部分：月下的荷塘（名段）**

```
"曲曲折折的荷塘上面，弥望的是田田的叶子。
叶子出水很高，像亭亭的舞女的裙。"

"微风过处，送来缕缕清香，仿佛远处高楼上渺茫的歌声似的。"

"月光如流水一般，静静地泻在这一片叶子和花上。"

"塘中的月色并不均匀；但光与影有着和谐的旋律，
如梵婀玲上奏着的名曲。"

→ 通感的大量使用
  清香 → 歌声（听觉→嗅觉？嗅觉→听觉？）
  光与影的旋律 → 小提琴曲（视觉→听觉）
→ 这是朱自清最擅长的写法：调动所有感官
```

**第三部分：联想——采莲的江南**

```
"这真是有趣的事，可惜我们现在早已无福消受了。"

→ 从眼前的荷塘，想到江南的采莲
→ 思乡 + 对美好生活的向往

"于是又记起《西洲曲》里的句子：
采莲南塘秋，莲花过人头；低头弄莲子，莲子清如水。"
```

**结尾：回到现实**

```
"轻轻地推门进去，什么声息也没有，妻已睡熟好久了。"

→ 和开头形成闭环
→ 但"不宁静"解决了吗？没有
→ 只是暂时逃离了，最后还是回到现实
```

### 核心考点

- **通感手法**——用其他感官来描写声音/气味/光影
- **情景关系**——不宁静→去月下荷塘→获得片刻宁静→回到现实
- **出与入**——朱自清"走出"家门（现实）→ 荷塘（精神世界）→ "走回"家门
- **1927 年的背景**——大革命失败后知识分子的苦闷

## 16 我与地坛（节选）— 史铁生

### 文体
- 现代散文，史铁生写于 1990 年代
- 写在母亲去世之后

### 核心分析

**史铁生和地坛的关系：**

```
地坛 = 一个废弃的皇家祭坛
史铁生 = 一个瘫痪的年轻人
→ 两个"被遗弃"的存在相遇了

"我常觉得这中间有着宿命的味道：
仿佛这古园就是为了等我，
而历经沧桑在那儿等待了四百多年。"
```

**地坛给史铁生的启示：**

```
死是一件不必急于求成的事（第一段的核心）
→ 既然不必急着死，那就活活看吧

园子里的意象：
  蜜蜂/蚂蚁/瓢虫——微小的生命也在认真活着
  露水——"压弯了草叶轰然坠地摔开万道金光"
  → 最平凡的事物中也有壮丽
```

**关于母亲（第二段的重点）：**

```
"那时她的儿子还太年轻，还来不及为母亲想，
他被命运击昏了头，一心以为自己是世上最不幸的一个，
不知道儿子的不幸在母亲那儿总是要加倍的。"

"多年来我头一次意识到，这园中不单是处处都有过我的车辙，
有过我的车辙的地方也都有过母亲的脚印。"
```

### 考试要点

- **地坛的象征意义**——废弃的古园 = 绝望的史铁生，都在经历"荒芜"
- **命运的理解**——不是问"为什么是我"，而是"既然发生了，怎么活"
- **母亲的形象**——不张扬的爱、默默的守护、儿子的愧疚
- **语言风格**——平静克制，但情感深沉

## 17 赤壁赋 — 苏轼

### 文体
- 赋体文，苏轼 1082 年写于被贬黄州
- 注意：不是文言文阅读的尽头，但确实是苏文典范

### 全文结构

```
第一部分：月夜泛舟（赋的"铺陈"）
  "清风徐来，水波不兴"——开头宁静美好
  "举酒属客，诵明月之诗"——文人雅事
  "浩浩乎如冯虚御风"——飘飘欲仙

第二部分：客人的箫声（从乐到悲的转折）
  "正襟危坐而问客曰"→客人开始感叹
  客人说：
    曹孟德之诗（周郎赤壁）→ 英雄尚且如此
    "哀吾生之须臾，羡长江之无穷"
    → 人生太短暂，宇宙太永恒

第三部分：苏轼的回应（全文核心）
  "客亦知夫水与月乎？"
  逝者如斯，而未尝往也
  → 江水在流，但江水从未消失
  盈虚者如彼，而卒莫消长也
  → 月亮有圆缺，但月亮还是那个月亮
  
  变的角度：万物都在变
  不变的角度：万物都没有真正变化

  "惟江上之清风，与山间之明月"
  → 不要执着于"拥有"，享受当下的美好就够了

第四部分：结尾
  "客喜而笑，洗盏更酌"
  → 问题解决了？还是暂时放下了？
  → 苏轼的态度：既然解决不了，那就享受当下
```

### 核心考点

- **主客问答**——其实是苏轼和自己对话（客人=消极的苏轼，主人=积极的苏轼）
- **变与不变**——苏轼的哲学思考
  - "盖将自其变者而观之，则天地曾不能以一瞬"
  - "自其不变者而观之，则物与我皆无尽也"
- **"水与月"的比喻**——用眼前的景物来说道理
- **与念奴娇对比**——赤壁赋（潇洒）vs 念奴娇（感慨）

## 18 登泰山记 — 姚鼐

### 文体
- 游记，清代桐城派古文，姚鼐 1774 年写

### 全文脉络

```
第一部分：出发
  "余以乾隆三十九年十二月"——时间
  "自京师乘风雪"→ 历齐河、长清 → 至泰安

第二部分：登山
  从泰山南麓 → 中谷 → 越中岭 → 终于山顶
  "道中迷雾冰滑，磴几不可登"

第三部分：观日出 ★★（最精彩）
  "戊申晦，五鼓，与子颍坐日观亭"
  → 凌晨五点去看日出
  
  日出前：大风扬积雪击面
          亭东自足下皆云漫
  
  日出时：
    "稍见云中白若樗蒱数十立者，山也"
    "极天云一线异色，须臾成五彩"
    "日上，正赤如丹，下有红光动摇承之"

  日出后：
    "回视日观以西峰，或得日或否"
    "绛皓驳色，而皆若偻"

第四部分：下山
  参观了岱祠、碧霞元君祠等
```

### 桐城派的风格

```
姚鼐是桐城派代表人物
桐城派的风格：简洁、雅正、有章法

"同是写登山，姚鼐和苏轼完全不同：
  姚鼐：客观描写，一字不多——"道中迷雾冰滑，磴几不可登"
        没有感叹，没有抒情
  苏轼：主观感受，感情充沛——"浩浩乎如冯虚御风"
        有哲学思考，有情感变化
```

### 考试要点

- **简洁的语言风格**——桐城派"义理考据辞章"
- **日出的描写**——按时间顺序（日出前→日出时→日出后）
- **"皆若偻"**——把群山比作弯腰的人，拟人化
- **与赤壁赋的对比**——同是山水，赤壁赋写情，泰山记写景

## 单元综合

### 五篇散文的"情景关系"

| 篇目 | 景 | 情 |
|:----|:---|:---|
| 故都的秋 | 秋天景物 | 悲凉之美（个人审美） |
| 荷塘月色 | 月下荷塘 | 暂时的逃离（时代苦闷） |
| 我与地坛 | 废弃古园 | 对命运的理解（个人挣扎） |
| 赤壁赋 | 赤壁江月 | 变与不变的哲学（被贬得失） |
| 登泰山记 | 泰山日出 | 纯粹欣赏，不加议论 |

```
共性问题：这些景都是"主观的景"
  → 每个人看到的"景"都是自己的内心
  → 郁达夫在秋天里看到悲凉，朱自清在荷塘里找宁静
  → 史铁生在地坛里找到活下去的理由
  → 苏轼在赤壁找到了心灵的解脱
  → 姚鼐在泰山找到了"纯粹"的审美
```
