# 第四单元 · 家乡文化生活

> 实践活动——语文在课堂之外
> 无传统课文，以调查/访谈/写作为主

---

## 单元定位

**核心任务：让学生走出课堂，用语文的方式参与家乡文化。**

本单元没有传统意义上的"课文"，而是三个学习活动：
1. 记录家乡的人和物（访谈/调查）
2. 家乡文化生活现状调查（问卷调查/分析）
3. 参与家乡文化建设（建议/方案）

---

## 学习活动详解

### 活动一：记录家乡的人和物

**核心能力：访谈 + 写作**

```
访谈技巧：
  ① 提前准备问题清单
  ② 录音（需征得同意）
  ③ 先问"客观事实"，再问"主观感受"
  ④ 追问——"你能举个例子吗？"

写作形式：
  人物志 / 风物志 / 口述历史
```

### 活动二：家乡文化生活现状调查

**核心能力：调查 + 数据分析**

```
调查类型：
  ① 问卷调查（量化数据）
  ② 访谈调查（质性数据）
  ③ 实地观察

分析框架：
  现状描述 → 问题发现 → 原因分析 → 建议
```

### 活动三：参与家乡文化建设

**核心能力：建议 + 方案写作**

```
可以写的方向：
  - 保护家乡文化遗产的建议
  - 改善社区文化设施的方案
  - 传承家乡传统技艺的构想
```

---

## 考试价值

这个单元不直接出考题，但有以下隐藏价值：

```
1. 作文素材
   - 家乡人物/风物可以作为"生活中的素材"
   - 尤其是"家乡变化"类题目

2. 实用类文本写作
   - 调查报告/建议书/访谈记录
   - 这些文体在"语言文字运用"中可能出现

3. 思辨能力训练
   - 观察现象 → 发现问题 → 提出方案
   - 议论文写作的核心逻辑
```
