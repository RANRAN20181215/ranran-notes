## 逐章精析

### 第一章：乡土本色

**核心观点：中国社会是"乡土"的——从土里长出来的。**

```
关键句：
  "靠种地谋生的人才明白泥土的可贵。"
  "乡土社会是安土重迁的，生于斯、长于斯、死于斯。"

三个特征：
  ① 不流动——世世代代住在同一个地方
  ② 熟人社会——人与人之间极其熟悉
  ③ 礼俗社会——靠传统和习惯，而不是靠法律
```

### 第二章：文字下乡

**核心观点：乡下人不识字，不是因为笨，是因为不需要。**

```
关键论证：
  "在面对面社群里，连语言本身都是多余的。"
  "熟悉的地方可以没有文字——'眉目传情'就够了。"

费孝通想说的：
  不是"文字不重要"
  而是"不能因为乡下人不识字就说他们智力低下"
```

### 第三章：再论文字下乡

**核心观点：乡土社会不需要文字，因为经验靠"口耳相传"。**

```
关键对比：
  乡土社会：变化极慢 → 老人的经验=年轻人的教材
  → 不需要文字来记录
  
  现代社会：变化快 → 老人的经验失效
  → 需要文字来获取新知识
```

### 第四章：差序格局 ★★★

**核心概念——全书最重要的概念。**

```
原文比喻：
  "我们的格局不是一捆一捆扎清楚的柴，
  而是好像把一块石头丢在水面上所发生的一圈圈推出去的波纹。"

差序格局的特点：
  ① 以"我"为中心
  ② 关系越近越亲，越远越淡
  ③ 公私界限模糊（家=国，国=家）

团体格局（西方）的特点：
  ① 每个人是平等的个体
  ② 界限分明
  ③ 公私分得清楚
  
考试必考：
  用"差序格局"分析为什么中国人"讲关系"
```

### 第五章：系维着私人的道德

**核心观点：差序格局下的道德是"有差等的"。**

```
关键句：
  "一个差序格局的社会，是由无数私人关系搭成的网络。"

什么意思？
  在差序格局里：
  - 对家人 = 孝
  - 对朋友 = 义
  - 对陌生人 = 仁
  标准不同，因为关系不同

  西方团体格局里：
  - 对所有人都要"公正"
  标准相同，因为人人平等
```

### 第六章：家族

**核心观点：中国的"家"比西方的"家庭"大得多。**

```
中国的家（氏族）：
  - 不只是夫妻+孩子
  - 包括祖辈、叔伯、堂兄弟
  - 功能不只是情感，更是经济和政治
  
西方的家庭（核心家庭）：
  - 主要是夫妻+孩子
  - 功能以情感为主
```

### 第七章：男女有别

**核心观点：乡土社会限制男女情感表达，是为了"稳定"。**

```
关键句：
  "男女之间不谈恋爱、不表达情感，不是因为封建，
  是因为在乡土社会里，稳定高于一切。"

爱情 → 感情冲动 → 破坏家庭稳定
  ↓
不表达感情 → 家庭稳定 → 社会有序
```

### 第八章：礼治秩序 ★★★

**核心观点：中国不是"人治"，是"礼治"——靠传统维持秩序。**

```
礼治 vs 法治：

礼治：从小学一套规矩 → 内化为习惯 → 自觉遵守
  维持方式：舆论（"丢人"）+ 羞耻心（"不好意思"）

法治：制定法律 → 用警察/法院执行 → 强制遵守
  维持方式：国家暴力机器

费孝通想说的：
  礼治不是"低级"，而是"不同的维持秩序的方式"
```

### 第九章：无讼

**核心观点：中国传统社会不提倡打官司。**

```
关键句：
  "打官司是丢人的事。"

为什么不打官司？
  - 打官司 = 撕破脸 = 破坏了人情
  - 更倾向于调解
  - 调解人通常是长辈/族长

这和现代社会的区别：
  现代：打官司 = 维护权利
  传统：打官司 = 伤和气
```

### 第十章：无为政治

**核心观点：皇权不下县——天高皇帝远。**

```
关键句：
  "在人民的实际生活里，皇权是若有若无的。"

什么意思？
  传统中国，中央政府的权力只到县一级
  县以下由乡绅/族长/长老自治
  "交皇粮"就是普通人和皇权的全部接触
```

### 第十一章：长老统治 ★★★

**核心观点：老人为什么有权威？因为经验就是资本。**

```
在变化慢的社会里：
  老人 → 经验多 → 说的一定对
  → 年轻人必须听老人的
  → 因为不听老人的，自己摸索会吃亏

在现代社会：
  变化快 → 老人的经验可能过时
  → 权威被削弱
  → 这是"代沟"的根本原因
```

### 第十二章：血缘与地缘

**核心观点：血缘社会→熟人，地缘社会→商业。**

```
血缘社会：
  - 生在哪就是哪的人
  - 关系是固定的
  - 人与人靠亲情维系

地缘社会（商业社会）：
  - 可以自由迁徙
  - 陌生人之间做买卖
  - 靠契约/法律维系
```

### 第十三章：名实的分离

**核心观点：表面一套，背后一套——中国的变通智慧。**

```
关键句：
  "名是虚的，实是活的。"

比如：皇帝的诏书说"减税"，但地方加各种"杂费"
  → 名义上没变，实际上变了
  
这种"名实分离"是乡土社会应对变化的方式
  不否定旧规则，但在实践中变通
```

### 第十四章：从欲望到需要

**核心观点：现代社会用"理性计算"代替了"本能冲动"。**

```
乡土社会：饿了就想吃 → 吃
  → 欲望驱动

现代社会：计算卡路里 → 决定吃多少
  → 需要驱动（理性计算）

费孝通的判断：
  社会在从"欲望社会"走向"需要社会"
  从感性走向理性，从传统走向现代
```

## 考试题型

### 题型 1：概念解释

```
题目示例：
  "请解释费孝通提出的'差序格局'的概念。"

答题模板：
  ① 是什么：以自己为中心、亲疏有别的人际关系结构
  ② 比喻说明：像石头丢进水面，一圈圈推开
  ③ 对比说明：和西方"团体格局"的差异
```

### 题型 2：概念运用

```
题目示例：
  "用'差序格局'分析'任人唯亲'现象。"

答题模板：
  ① 差序格局的特征：以己为中心，亲疏有别
  ② 现象分析：在差序格局下，信任半径=血缘半径
  ③ 为什么：对自己人好是"应该的"
```

### 题型 3：联系现实

```
题目示例：
  "现代社会哪些现象还带有'乡土中国'的影子？"

答题方向：
  - 过年回家（血缘+地缘）
  - 托关系办事（差序格局）
  - 家族观念（氏族）
  - 不愿意打官司（无讼）
```
