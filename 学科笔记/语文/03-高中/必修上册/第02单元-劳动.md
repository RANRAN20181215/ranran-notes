# 第二单元 · 劳动

> 新闻通讯入门——事实中隐藏观点
> 4 课：喜看稻菽千重浪 / 心有一团火 / "探界者"钟扬 / 以工匠精神雕琢时代品质

---

## 单元定位

**核心任务：从"读故事"到"读新闻"——新闻通讯不是记叙文。**

```
记叙文：作者在"讲述"一个故事
新闻通讯：记者在"报道"一个事实，但事实的选择本身就在表达观点
```

## 4 喜看稻菽千重浪——记首届国家最高科技奖获得者袁隆平 — 沈英甲

### 文体
- 人物通讯：以事实为基础，但比新闻更详细、更有文学性
- 发表在 2001 年，袁隆平获首届国家最高科技奖时

### 内容结构

```
第一部分：2001 年春节刚过，袁隆平在田野里
  开头用"具体场景"切入——不是从获奖开始写

第二部分：挑战"无性杂交"学说
  袁隆平如何怀疑当时的主流观点
  → 科学精神=质疑

第三部分：寻找野生雄性不育株
  14 天寻找的过程
  → 科学精神=坚持

第四部分：为真理而斗争
  文革期间保护试验材料
  → 科学精神=勇气

第五部分：他的心愿
  让全世界的人吃饱饭
  → 科学精神=对人类的责任
```

### 核心考点

- **通讯的写法**：以具体场景开头（"2001 年春节刚过"），不是从生平介绍开始
- **选材的角度**：不是"袁隆平做了什么"，而是"袁隆平为什么能做成"
- **细节的作用**：14 天找一株稻穗——用细节体现坚持

### 考试常考

```
1. 文章为什么从"田野里的场景"开始写？
   → 让读者身临其境，感受科学家的日常工作
2. 文中的"无性杂交"学说起了什么作用？
   → 作为对比，突出袁隆平"敢于质疑"的科学精神
3. 标题中的"喜看稻菽千重浪"引用自谁的诗？
   → 毛泽东《七律·到韶山》，"喜看稻菽千重浪，遍地英雄下夕烟"
```

## 5 心有一团火，温暖众人心 — 林为民

### 文体
- 人物通讯，关于北京百货大楼售货员张秉贵

### 核心分析

**张秉贵的"一团火"是什么？**
```
"一团火" = 对工作的热情 + 对顾客的关心
  体现在：
    - 练就"一抓准"的本领（专业技能）
    - 记住老顾客的喜好（用心服务）
    - 大热天给顾客扇扇子（真情服务）
```

### 考试要点

- 标题的比喻——"一团火"象征热情
- 典型事例的选择——每个例子展示一个品质侧面
- 通讯和新闻的区别——通讯更详细，有文学性

## 6 "探界者"钟扬 — 叶雨婷

### 文体
- 人物通讯，关于复旦大学教授钟扬（2017 年去世）

### 核心分析

**"探界者"的"界"有几层？**

```
第一层：科学探索的边界——在青藏高原采集 4000 万颗种子
第二层：学科之间的边界——既是植物学家，也是科普作家
第三层：生命的边界——在 53 岁因车祸去世
第四层：高原的边界——多次攀登海拔 6000 米以上
```

**文章结构：用小标题分节**

```
"英雄"少年 —— 钟扬的少年时代
种子达人 —— 采集种子的执着
科学队长 —— 做科普的热情
"接盘"导师 —— 对学生的关怀
生命延续 —— 他的影响没有结束
```

### 考试要点

- **小标题的作用**：概括每节内容 + 吸引读者
- **"探界者"的含义**：不仅探索科学边界，也探索生命可能
- **选材特色**：不是按时间顺序写生平，而是围绕"探界"这个主题选材

## 7 以工匠精神雕琢时代品质 — 李斌

### 文体
- 新闻评论（不是通讯！）

### 核心分析

**全文脉络：**

```
第一段：什么是工匠精神？
  从"匠"的含义说起——精雕细琢、精益求精

第二段：工匠精神对个人的意义
  工作不只是谋生，是自我价值的实现

第三段：工匠精神对企业的意义
  产品品质=企业生命

第四段：工匠精神对时代的意义
  时代需要"专注""坚守""精益求精"的精神
```

### 对比：新闻通讯 vs 新闻评论

| | 新闻通讯 | 新闻评论 |
|:---|:--------|:--------|
| 目的 | 报道事实 | 表达观点 |
| 手法 | 描写/叙述 | 议论/论证 |
| 例子 | 袁隆平做了什么 | 为什么要学习袁隆平 |
| 语言 | 文学化 | 议论化 |

### 考试要点

- **论证方法**：举例论证（古今工匠的例子）+ 道理论证
- **"雕琢"的比喻意义**：不是简单的制作，是精心的打磨
- **文章结构**：是什么→为什么→怎么做（经典议论文结构）
