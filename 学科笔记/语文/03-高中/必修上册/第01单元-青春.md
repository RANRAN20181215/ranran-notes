# 第一单元 · 青春

> 诗歌入门——从"读懂意思"到"读懂意象"
> 5 课：沁园春·长沙 / 立在地球边上放号 / 红烛 / 峨日朵雪峰之侧 / 致云雀

---

## 单元定位

**核心任务：完成从初中诗歌阅读到高中诗歌鉴赏的转变。**

```
初中问：这首诗表达了什么情感？
高中问：这些意象组合在一起产生了什么效果？
       作者为什么选择这个意象而不是那个？
       语言的"陌生化"体现在哪里？
```

## 1 沁园春·长沙 — 毛泽东

### 文体
- 词牌"沁园春"：双调 114 字，上阕 13 句四平韵，下阕 12 句五平韵
- 写于 1925 年——毛泽东 32 岁，离开湖南前往广州前夕

### 逐句分析

**上阕：写景——"看"字领起七句**

```
独立寒秋，湘江北去，橘子洲头。
  → 点明时间（寒秋）、地点（橘子洲）、人物（独立）
  → "独立"二字已有孤高意味，不是一般的"站在那儿"

看万山红遍，层林尽染；漫江碧透，百舸争流。
鹰击长空，鱼翔浅底，万类霜天竞自由。
  → "看"字领起，从远到近、从上到下
  → 万山（远）→ 层林（中）→ 漫江（近）→ 百舸（水面）
  → 鹰（天上）→ 鱼（水下）
  → 最后收到一个"竞"字——万物都在自由地竞争

怅寥廓，问苍茫大地，谁主沉浮？
  → "怅"不是惆怅，是深思
  → 从写景到抒情的转折点
  → 问的是天下兴亡——谁来决定这片土地的命运？
```

**下阕：怀旧——"忆"字领起七句**

```
携来百侣曾游。忆往昔峥嵘岁月稠。
恰同学少年，风华正茂；书生意气，挥斥方遒。
指点江山，激扬文字，粪土当年万户侯。
  → "恰"字领起，写当年同窗的风采
  → "粪土万户侯"——不把权贵放在眼里

曾记否，到中流击水，浪遏飞舟？
  → 以问句收尾
  → 不是真的在问，而是在说：当年的豪情还在吗？
```

### 核心考点

- **意象群分析**："万山红遍"到"万类霜天竞自由"——一个"竞"字统摄全部意象
- **上下阕关系**：上阕写景（现在的湘江）→ 下阕忆事（过去的岁月）→ 结尾问句连接古今
- **"怅"的理解**：不是消极，是深沉地思考
- **写作背景**：1925 年国共合作时期，作者对革命前途的思考

## 2 立在地球边上放号 — 郭沫若

### 文体
- 现代自由诗，写于 1919 年五四运动时期
- "放号"= 放声呼喊

### 核心分析

```
无数的白云正在空中怒涌，
啊啊！好幅壮丽的北冰洋的晴景哟！
无限的太平洋提起他全身的力量来要把地球推倒。
啊啊！我眼前来了的滚滚的洪涛哟！
啊啊！不断的毁坏，不断的创造，不断的努力哟！
啊啊！力哟！力哟！
力的绘画，力的舞蹈，力的音乐，力的诗歌，力的Rhythm哟！
```

**这首诗在说什么？**
- 五四时期的"狂飙突进"精神
- 毁坏旧世界、创造新世界
- "力"——破坏的力量，也是创造的力量

**考试要点：**
- 排比和反复的运用（"啊啊""不断的""力的"）
- 浪漫主义风格——夸张、激情、想象力
- 时代背景：五四运动后的中国

## 3 红烛 — 闻一多

### 文体
- 现代诗，闻一多 1923 年出版第一本诗集《红烛》
- 化用李商隐"蜡炬成灰泪始干"

### 核心分析

```
红烛啊！
这样红的烛！
诗人啊！
吐出你的心来比比，
可是一般颜色？

红烛啊！
既制了，便烧着！
烧罢！烧罢！
烧破世人的梦，
烧沸世人的血——
也救出他们的灵魂，
也捣破他们的监狱！

红烛啊！
你流一滴泪，灰一分心。
灰心流泪你的果，
创造光明你的因。
```

**核心意象：红烛 = 奉献的诗人**
- "红" = 赤诚的心（"吐出你的心来比比，可是一般颜色"）
- "烧" = 燃烧自己、照亮他人（"烧破世人的梦，烧沸世人的血"）
- "流泪" = 牺牲的代价（"灰心流泪你的果，创造光明你的因"）

**考试要点：**
- 红烛的象征意义（奉献精神/自我牺牲/启蒙者）
- 化用的手法（"蜡炬成灰泪始干"的现代演绎）
- 诗人的自我认同（闻一多把自己比作红烛）

## 4 峨日朵雪峰之侧 — 昌耀

### 文体
- 现代诗，昌耀 1962 年写于青藏高原
- 峨日朵=青海的一座山峰

### 核心分析

```
这是我此刻仅能征服的高度了：
我小心翼翼探出前额，
惊异于薄壁那边
朝向峨日朵之雪彷徨许久的太阳
正决然跃入一片引力无穷的

山海。石砾不时滑坡，
引动棕色深渊自上而下的一派嚣鸣，
像军旅远去的喊杀声。
我的指关节铆钉一样楔入巨石的罅隙。
血滴，从撕裂的千层掌鞋底渗出。

呵，真渴望有一只雄鹰或雪豹与我为伍。
在锈蚀的岩壁，
但有一只小得可怜的蜘蛛
与我一同默享着这大自然赐予的
快慰。
```

**核心分析：**
- 攀登者 = 人的境遇——"这是我此刻仅能征服的高度了"
- 不是英雄主义的胜利，是"小心翼翼的试探"
- "血滴渗出"——付出的代价
- 结尾的"蜘蛛"——不是雄鹰雪豹，是小小的蜘蛛，但"与我一同默享"

**考试要点：**
- "蜘蛛"的象征意义——渺小但坚韧的生命
- 自我认知——承认自己的有限（"仅能征服的高度"）
- 诗中的两个方面：攀登的艰辛 vs 自然的壮美

## 5 致云雀 — 雪莱

### 文体
- 英国浪漫主义诗人雪莱代表作，写于 1820 年
- 云雀 = skylark，以其高飞和歌唱著称

### 核心分析

```
你好啊，欢乐的精灵！
你从不是飞鸟——
你是从天庭或近旁
撒下的一阵欢乐的甘霖，
你那源源溢出的
无羁无止的欢欣。

你像一朵云彩，
从地面升腾而起，
又飞腾着歌唱着
向碧蓝的高空飘去，
飞啊飞啊，
不停地飞，不停地唱。

我们瞻前顾后，
为了
不属于我们的愿望而忧愁
你发自内心的笑啊，
比我们的欢笑更加纯真——
比金银珠宝还要贵重。
```

**核心意象：云雀 = 自由的灵魂**
- "不是飞鸟"——云雀在诗中超越了鸟的范畴，成为"欢乐的精灵"
- 自由/欢乐/纯真的象征
- 对比：云雀的"无忧无虑" vs 人类的"瞻前顾后"

**考试要点：**
- 浪漫主义特征——自然崇拜 + 想象力 + 理想主义
- 比喻手法——云雀被比作"欢乐的精灵""云彩""甘霖"
- 人与云雀的对比——人对生活的忧虑 vs 云雀的纯粹欢乐

## 单元综合考点

```
1. 五首诗共同的"青春"主题
   - 沁园春·长沙：青春的壮志
   - 立在地球边上放号：青春的力量
   - 红烛：青春的奉献
   - 峨日朵雪峰之侧：青春的坚韧
   - 致云雀：青春的自由

2. 现代诗歌的鉴赏方法
   - 不追求"标准答案"式解读
   - 关注意象的选择
   - 关注语言的节奏和韵律
   - 关注诗人的情感态度
```
