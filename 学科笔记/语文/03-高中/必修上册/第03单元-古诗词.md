## 7 短歌行 — 曹操

### 文体
- 四言诗，汉乐府旧题
- 写作背景：赤壁之战前后，曹操求贤若渴

### 逐段分析

```
对酒当歌，人生几何！
譬如朝露，去日苦多。
慨当以慷，忧思难忘。
何以解忧？唯有杜康。
  → 开头看似感叹人生苦短
  → 但"忧"的不是个人寿命，是"求贤不得"

青青子衿，悠悠我心。
但为君故，沉吟至今。
  → 用典：《诗经·郑风·子衿》
  → 原诗写女子等情人，曹操借来写"等贤才"

呦呦鹿鸣，食野之苹。
我有嘉宾，鼓瑟吹笙。
  → 用典：《诗经·小雅·鹿鸣》
  → 意为：贤才来了，我一定好好招待

明明如月，何时可掇？
忧从中来，不可断绝。
越陌度阡，枉用相存。
契阔谈讌，心念旧恩。
  → "月"可掇=贤才可得？
  → 忧：贤才什么时候来

月明星稀，乌鹊南飞。
绕树三匝，何枝可依？
  → 景色描写，但暗示：贤才还在找可以依托的地方

山不厌高，海不厌深。
周公吐哺，天下归心。
  → 用典：周公"一饭三吐哺"
  → 结尾：我会像周公一样，天下贤才都会来归附
```

### 核心考点

- **三个典故**：青青子衿（诗经）/ 呦呦鹿鸣（诗经）/ 周公吐哺（史记）
  - 每个典故的出处 + 在诗中的用意
- **"忧"的本质**：不是人生苦短，而是求贤不得
- **情感转折**：从"对酒当歌"到"天下归心"——从个人感慨到宏图大志

## 8 归园田居（其一）— 陶渊明

### 文体
- 五言古诗，写于陶渊明辞官归隐之后

### 逐句分析

```
少无适俗韵，性本爱丘山。
误落尘网中，一去三十年。
  → "尘网"=官场（不是真的网，是比喻）
  → "三十年"——夸张，实际 13 年

羁鸟恋旧林，池鱼思故渊。
  → 比喻：自己过去做官 = 鸟在笼中、鱼在池中

开荒南野际，守拙归园田。
  → "守拙"=守住本分/本真（大巧若拙）

方宅十余亩，草屋八九间。
榆柳荫后檐，桃李罗堂前。
暧暧远人村，依依墟里烟。
狗吠深巷中，鸡鸣桑树颠。
  → 白描！不加修饰地写眼前景
  → 没有"美啊""好哇"——但画面感极强

户庭无尘杂，虚室有余闲。
久在樊笼里，复得返自然。
  → 呼应开头：从"尘网"到"樊笼"到"自然"
  → 一个完整的"逃离-回归"叙事
```

### 核心考点

- **白描手法**：不修饰、不夸张，用最朴素的语言写景
- **比喻系统**：尘网/羁鸟/池鱼/樊笼（被束缚）vs 旧林/故渊/自然（自由）
- **"守拙"的理解**：不是笨，是大巧若拙

## 9 梦游天姥吟留别 — 李白

### 具体文本分析见古诗词全集（第 4 首）

### 核心脉络

```
现实（开头）：海客谈瀛洲 → 引出天姥山
梦境（主体）：
  月光下飞 → 到剡溪 → 登天姥
  → 天黑 → 野兽叫 → 山崩 → 神仙出现
  → 忽然惊醒
现实（结尾）：回到人间 → 我为什么要向权贵低头？

关键三句：
  "我欲因之梦吴越"——进入梦境的入口
  "忽魂悸以魄动"——退出梦境
  "安能摧眉折腰事权贵"——全诗主旨
```

### 考试要点

- **虚实结合**：现实（开头结尾）vs 梦境（主体）
- **浪漫主义特征**：想象奇特 + 夸张 + 神话元素
- **结尾句**="安能摧眉折腰事权贵，使我不得开心颜"——李白精神的代表

## 10 登高 — 杜甫

### 文体
- 七言律诗，写于 767 年夔州
- 被称为"古今七言律第一"

### 逐句分析

```
风急天高猿啸哀，渚清沙白鸟飞回。
  → 首联写近景：风/天/猿/渚/沙/鸟——六个意象密集排列
  → "猿啸哀"= 三峡多猿，叫声凄厉

无边落木萧萧下，不尽长江滚滚来。
  → 颔联写远景：落叶（视觉）+ 长江（视觉+听觉）
  → "无边"+"不尽"——空间的无限 + 时间的永恒

万里悲秋常作客，百年多病独登台。
  → 颈联转到身世：万里 = 空间（离家远）
  → 悲秋 = 季节（秋）
  → 常作客 = 漂泊（时间久）
  → 百年 = 一生
  → 多病 = 身体
  → 独登台 = 孤独
  → 一句八个字 = 八重悲

艰难苦恨繁霜鬓，潦倒新停浊酒杯。
  → 尾联：穷困潦倒 + 因病戒酒
  → 连最后一点安慰（酒）都没了
```

### 核心考点

- **"一篇之中句句皆律"**——七律的格律巅峰
- **颈联的八重悲**——空间/季节/时间/人生/身体/孤独/国事/个人
- **家国之悲 vs 个人之悲**——杜甫悲的不只是自己，更是国家

## 11 琵琶行 — 白居易

### 文体
- 长篇叙事诗，七言歌行，写于 816 年白居易被贬江州

### 结构

```
第一部分："浔阳江头夜送客"——送别场景
第二部分："忽闻水上琵琶声"——偶遇琵琶女
第三部分：琵琶演奏（全诗最精彩部分）
第四部分："自言本是京城女"——琵琶女自述身世
第五部分："同是天涯沦落人"——引发共鸣
第六部分："座中泣下谁最多"——结尾
```

### 音乐描写的四种手法

```
1.比喻（最核心）
  "大弦嘈嘈如急雨"——声音=视觉形象
  "小弦切切如私语"
  "大珠小珠落玉盘"
  "银瓶乍破水浆迸，铁骑突出刀枪鸣"

2.通感
  "间关莺语花底滑"——听觉→视觉
  "幽咽泉流冰下难"——听觉→视觉

3.对比
  有声 vs 无声
  "凝绝不通声暂歇"→"此时无声胜有声"

4.侧面烘托
  "东船西舫悄无言，唯见江心秋月白"
  → 不直接说"弹得好"
  → 写听众的反应
```

### 核心考点

- **音乐描写的比喻体系**——这是中国文学史音乐描写的高峰
- **"同是天涯沦落人"**——琵琶女与诗人的双重身世
- **叙事结构**：送客→听曲→感怀→作诗
- **"江州司马青衫湿"**——青衫=八品官的官服

## 12 念奴娇·赤壁怀古 — 苏轼

### 逐句分析

```
大江东去，浪淘尽，千古风流人物。
  → 开篇气势极大：空间（大江）+ 时间（千古）
  → "浪淘尽"=历史像江水一样冲走了所有英雄

故垒西边，人道是，三国周郎赤壁。
乱石穿空，惊涛拍岸，卷起千堆雪。
  → 写景：乱石/惊涛/千堆雪——笔力雄健
  → "人道是"——苏轼知道这不是赤壁古战场

江山如画，一时多少豪杰。
  → 从写景过渡到怀古

遥想公瑾当年，小乔初嫁了，雄姿英发。
羽扇纶巾，谈笑间，樯橹灰飞烟灭。
  → 写周瑜：年轻/英俊/成功/从容
  → "谈笑间"——轻松就赢了

故国神游，多情应笑我，早生华发。
人生如梦，一尊还酹江月。
  → 回到现实：想象中在古战场神游
  → "多情应笑我"——自己笑自己太敏感
  → 周瑜成功 vs 苏轼不得志
  → "一尊还酹江月"——把酒洒进江中祭奠
```

### 核心考点

- **对比结构**：周瑜（年轻/成功/风流）vs 苏轼（年老/被贬/华发）
- **景物描写的空间感**：大江/乱石/惊涛/千堆雪
- **"人生如梦"的解读**：不是消极，是对历史沧桑的感慨

## 13 永遇乐·京口北固亭怀古 — 辛弃疾

### 逐句分析

```
千古江山，英雄无觅孙仲谋处。
  → 孙权曾在京口建功立业
  → "无觅"=现在找不到了

舞榭歌台，风流总被雨打风吹去。
  → 繁华已逝

斜阳草树，寻常巷陌，人道寄奴曾住。
想当年，金戈铁马，气吞万里如虎。
  → 寄奴=刘裕（宋武帝），曾从这里北伐
  → 追忆刘裕的强盛

元嘉草草，封狼居胥，赢得仓皇北顾。
  → 刘义隆（刘裕之子）仓促北伐 → 失败
  → 对比：刘裕的成功 vs 刘义隆的失败

四十三年，望中犹记，烽火扬州路。
  → 43 年前（1162 年）辛弃疾南归，当时北方在战火中

可堪回首，佛狸祠下，一片神鸦社鼓。
  → 佛狸祠=北魏太武帝拓跋焘的祠
  → 百姓在敌人的祠堂里祭祀——忘了亡国之痛？

凭谁问，廉颇老矣，尚能饭否？
  → 廉颇老了还能吃一斗米、十斤肉
  → 辛弃疾问：我老了，还有人用我吗？
```

### 五个典故的用意

| 典故 | 正面/反面 | 用意 |
|:----|:---------|:-----|
| 孙权 | 正面 | 曾经有能抵御外敌的君主 |
| 刘裕 | 正面 | 曾经有人成功北伐 |
| 刘义隆 | 反面 | 仓促北伐的教训 |
| 拓跋焘 | 反面 | 百姓忘了亡国之痛 |
| 廉颇 | 自比 | 我还能战斗，但没人用我 |

### 核心考点

- **用典集大成**——五个典故的出处 + 各自的作用
- **对比结构**：刘裕（成功北伐）vs 刘义隆（失败北伐）→ 对当下的暗示
- **廉颇的比喻**——辛弃疾到底想不想被启用？

## 14 声声慢 — 李清照

### 逐句分析

```
寻寻觅觅，冷冷清清，凄凄惨惨戚戚。
  → 14 个叠词——汉语史上著名的开头
  → 每一叠都在递进：寻觅（动作）→ 冷清（环境）→ 凄惨（感觉）→ 戚戚（情绪）

乍暖还寒时候，最难将息。
  → 天气忽冷忽热，最难调养

三杯两盏淡酒，怎敌他、晚来风急？
  → "淡酒"不是酒淡，是愁太浓
  → 借酒浇愁，但愁比酒浓

雁过也，正伤心，却是旧时相识。
  → 大雁飞过——以前她在北方也见过
  → 国破家亡后，连大雁都是"旧时相识"

满地黄花堆积，憔悴损，如今有谁堪摘？
  → 菊花落了满地 → 自己像菊花一样凋零
  → 女人如花，花谢了没人摘——自己老了

守着窗儿，独自怎生得黑？
  → 一个人坐在窗前，天怎么还不黑？
  → 孤独到了极点的表达

梧桐更兼细雨，到黄昏、点点滴滴。
这次第，怎一个愁字了得！
  → 梧桐+细雨 = 典型的悲秋意象
  → 结尾：一个"愁"字哪里说得完？
```

### 核心考点

- **14 叠词的效果**——音乐性 + 层层递进的情感 + 独创性
- **意象选择**——淡酒/晚风/过雁/黄花/梧桐/细雨——一体渲染
- **"愁"的独特性**——不是普通闺怨，是国破家亡夫死后的愁
- **刚柔并济**——李清照的语言柔美，但情感极有力量

## 单元总复习

### 诗歌类型鉴别

| 类型 | 特征 | 篇目 |
|:----|:-----|:-----|
| 四言诗 | 四字一句，古拙质朴 | 短歌行 |
| 五言古诗 | 五字一句，自由换韵 | 归园田居 |
| 七言歌行 | 七言为主，长短不拘 | 梦游天姥、琵琶行 |
| 七言律诗 | 八句四联，讲究对仗 | 登高 |
| 豪放词 | 视野开阔，气势雄健 | 念奴娇、永遇乐 |
| 婉约词 | 意境细腻，情感含蓄 | 声声慢 |
