# 第六单元 · 学习之道

> 议论性文言文——从"翻译"到"分析论证"
> 4 课：劝学 / 师说 / 反对党八股 / 拿来主义

---

## 单元定位

**核心任务：文言文阅读的第一个升级——从"读懂"到"分析怎么论证"。**

```
初中文言文要求：能翻译、能理解
高中文言文要求：除了翻译，还要分析论证方法
                → 每段在说什么
                → 段与段之间是什么关系
                → 全文是怎么论证的
```

## 10 劝学 — 荀子

### 文体
- 议论性文言文，出自《荀子》第一篇
- "劝"=鼓励、劝勉

### 全文论证结构

```
第一段：提出论点——"学不可以已"
  先声夺人，一句话亮出观点

第二段：论证——学习能改变人
  青出于蓝（提取）→ 冰寒于水（变化）
  → 木受绳则直（改造）→ 金就砺则利（打磨）
  → 君子博学而日参省乎己（人的改变）
  方法：类比论证（用自然现象类推到人）

第三段：论证——学习能借助外力
  登高而招 ≠ 臂非加长（顺风而呼 ≠ 声非加疾）
  → 假舆马 ≠ 利足（假舟楫 ≠ 能水）
  → 君子生非异也，善假于物也
  方法：对比论证（借助 vs 不借助的差异）

第四段：论证——学习需要积累+坚持+专注
  积土成山 → 积水成渊（积累）
  骐骥一跃 ≠ 十驾（坚持）
  锲而不舍 vs 锲而舍之（对比）
  蚯蚓 vs 螃蟹（对比）

  方法：比喻论证 + 对比论证
```

### 重点句子

| 句子 | 翻译 | 知识点 |
|:----|:----|:------|
| 青，取之于蓝，而青于蓝 | 靛青从蓝草中提取，但比蓝草更青 | 状语后置 + 两个"于"含义不同 |
| 木受绳则直，金就砺则利 | 木头用墨线量过就直，金属在磨刀石上磨就锋利 | "就"=接近 |
| 君子生非异也，善假于物也 | 君子的本性没有不同，善于借助外物罢了 | "生"通"性" |
| 锲而不舍，金石可镂 | 刻个不停，金属石头也能刻穿 | "锲"=刻；"镂"=雕刻 |

### 考试真题

```
1. 文章用了哪些论证方法？请结合文本分析。
   → 比喻论证（青出于蓝/冰寒于水）
   → 对比论证（骐骥一跃 vs 驽马十驾）
   → 类比论证（以自然现象类推）

2. "学不可以已"的"已"字含义是？
   → 停止（不是"已经"）

3. 荀子认为学习的本质是什么？
   → 借助外物来改变自己
```

## 11 师说 — 韩愈

### 文体
- 议论性文言文，韩愈 802 年写
- "师说"=关于"从师"的论述

### 全文论证结构

```
第一段：提出论点
  "古之学者必有师"
  老师的功能：传道受业解惑
  人非生而知之者 → 所以需要老师

第二段：批判"耻学于师"的社会风气
  对比一：古之圣人（从师）vs 今之众人（耻师）
  对比二：爱其子（择师）vs 于其身（耻师）
  对比三：巫医乐师百工（相师）vs 士大夫（耻师）
  方法：三重对比论证

第三段：举例——圣人尚且从师
  孔子师郯子、苌弘、师襄、老聃
  "三人行，则必有我师"
  方法：举例论证

第四段：写作原因——鼓励李蟠
  交代写作背景
```

### 核心概念

```
"师"不等于"学校老师"

韩愈说的"师" = 能传授道理、教授学业、解答疑惑的人
  ≠ 仅仅是学校里的老师
  ≠ 有官职的"老师"
  = "道之所存，师之所存也"
```

### 考试要点

- **三段对比论证**——这是最经典的论证结构
- **"师道之不传也久矣"**——"道"=从师的风尚
- **"道之所存，师之所存"**——核心观点，意思是"真理在哪里，老师就在哪里"
- **与劝学的对比**：
  - 劝学：强调学习的重要性
  - 师说：强调从师的重要性

## 12 反对党八股 — 毛泽东

### 文体
- 政论文（非文言文），毛泽东 1942 年在延安整风运动中的演讲

### "党八股"是什么

```
"八股"=明清科举的固定文体格式
"党八股"=革命队伍中的教条主义、形式主义文风

毛泽东列出了"党八股"的八大罪状：
  ① 空话连篇，言之无物
  ② 装腔作势，借以吓人
  ③ 无的放矢，不看对象
  ④ 语言无味，像个瘪三
  ⑤ 甲乙丙丁，开中药铺
  ⑥ 不负责任，到处害人
  ⑦ 流毒全党，妨害革命
  ⑧ 传播出去，祸国殃民
```

### 论证特色

```
1. 语言幽默讽刺
  "懒婆娘的裹脚——又长又臭"
  "语言无味，像个瘪三"

2. 层层推进
  每一条罪状 = 表现 + 危害 + 纠正方法

3. 通俗易懂
  不是学术文章，是演讲
  目的是让普通干部听懂
```

## 13 拿来主义 — 鲁迅

### 文体
- 杂文，鲁迅 1934 年写
- 讨论：如何对待外国文化和中国传统文化

### 全文脉络

```
第一部分：批判"闭关主义"
  中国过去：闭关锁国
  → 被侵略 → 变成了"送去主义"（送古董、送人才）

第二部分：引出"拿来主义"
  我们被"送来"的东西太多了（鸦片、枪炮）
  → 被送 = 被动，我们要"拿来" = 主动

第三部分：比喻——"大宅子"的三种态度
  怕被污染 → 不敢进（孱头）
  放火烧掉 → 彻底否定（昏蛋）
  全盘接受 → 连鸦片一起吸（废物）

  正确的做法：
  鱼翅 → 吃掉（好东西，吸收）
  鸦片 → 送药房（有用但有毒，辩证看待）
  烟枪烟灯 → 放博物馆（可留作纪念）
  姨太太 → 全部遣散（糟粕，彻底抛弃）
```

### 核心观点

```
"拿来主义" = 主动地、有选择地吸收外来文化

对中国文化：取其精华，去其糟粕
对外国文化：主动引进，但要有标准

"运用脑髓，放出眼光，自己来拿"
  = 用自己的判断力去选择
```

### 考试要点

- **比喻论证**："大宅子"比喻文化遗产
  - 孱头 = 逃避主义
  - 昏蛋 = 虚无主义
  - 废物 = 全盘接受
  - 正确的"拿来" = 批判继承
- **鲁迅杂文的语言特点**：讽刺 + 幽默 + 深刻
- **"拿来"和"送来"的区别**：主动 vs 被动

## 单元综合

### 四篇的共同主题

```
劝学：为什么要学习
师说：为什么要有老师
反对党八股：应该怎么写文章
拿来主义：应该怎么对待文化

四篇都在说"学习之道"
  但角度不同：个人学习→从师学习→文风学习→文化学习
```

### 论证方法对比

| 篇目 | 主要论证方法 |
|:----|:------------|
| 劝学 | 比喻论证、对比论证 |
| 师说 | 对比论证、举例论证 |
| 反对党八股 | 举例论证、讽刺 |
| 拿来主义 | 比喻论证、对比论证 |
