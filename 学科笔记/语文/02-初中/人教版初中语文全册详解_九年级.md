# 人教版初中语文全册详解 · 九年级上册

> **九年级定位提示**：九年级是中考前最关键的一年。从内容上看，古诗文篇数最多难度最大（岳阳楼记、出师表、鱼我所欲也等），现代文从"读懂"转向"分析"，作文从"写清楚"过渡到"有观点"。从学习策略上看——**古诗文篇篇过关，现代文掌握套路，作文先模仿再创新**。建议先用本册搭建知识框架，再用两本附录（中考模板 + 作文指导）查漏补缺。

---

## 第一单元 · 诗歌

> **单元引言**：九年级的诗歌单元不只是"读诗"——你要学习的是"如何读诗"。本单元四首诗词来自不同时代不同诗人：毛泽东的豪放、艾青的深沉、余光中的深情、以及（九下的）更多经典。读诗的方法就一个——**抓住意象，体会情感**。雪/土地/邮票/月亮——每一个意象背后都有一份独特的情感。
>
> **群文阅读**：本单元四首诗恰好代表四种不同的抒情方式：沁园春·雪（借景抒情）、我爱这土地（象征抒情）、乡愁（意象递进抒情）、可对比九下诗词单元的"用典抒情"。横向比较，你会发现"同样的情感可以有不同的表达方式"。

---

> **📍 本单元阅读地图：**
> 这个单元全是诗歌——跟散文完全不同的节奏，更需要你"用心听"。建议先读《沁园春·雪》——气势最大，读起来像站在山顶上；再读《我爱这土地》和《乡愁》——两首现代诗，情感真挚，可以放在一起慢慢读；剩下的诗歌可以快速翻翻，感受一下"诗的语言"——它不跟你说理，它给你画面和声音。
> 
> 读完想一想：同样是写情感，四首诗用的"工具"完全不一样——你发现了吗？

### 1 沁园春·雪 / 毛泽东

**词牌名：** 沁园春
**结构：**

```
上阕 写景（北国风光）
├── 总写：千里冰封，万里雪飘
├── 具体：望长城内外/大河上下/山舞银蛇/原驰蜡象
└── 想象：须晴日/红装素裹/分外妖娆

下阕 论史（评古论今）
├── 过渡：江山如此多娇→引无数英雄
├── 论古：惜秦皇汉武/略输文采
│        唐宗宋祖/稍逊风骚
│        成吉思汗/只识弯弓射大雕
└── 颂今：俱往矣/数风流人物/还看今朝
```

**重点手法：**

上阕"望"字统领：长城/大河/山/原——视野辽阔，气象恢宏。
"山舞银蛇，原驰蜡象"——比喻+化静为动（群山如银蛇舞动、高原如蜡象奔驰）

下阕"惜"字统领："惜"中含褒（肯定历史功绩）又含贬（不足——略输/稍逊/只识）

**名句：**
- "山舞银蛇，原驰蜡象，欲与天公试比高"——拟人
- "须晴日，看红装素裹，分外妖娆"——想象（虚写）
- "俱往矣，数风流人物，还看今朝"——主旨句

**主旨：** 赞美祖国壮丽山河，歌颂当代英雄

### 📚 1+X 延伸阅读
- 对比读：杜甫《春望》（同样是"借景抒怀"——杜甫的"感时花溅泪"和毛泽东的"山舞银蛇"——一个悲一个壮）
- 想了解词与诗的区别→找同一主题的唐诗和宋词对比读

|:----|:----|

**四个意象：** 邮票（少年）→船票（中年）→坟墓（生死）→海峡（两岸）

**主旨：** 乡愁从个人走向民族——从思念母亲到渴望祖国统一

## 第二单元 · 议论性文章

> **单元引言**：议论性文章——说白了就是"说服别人同意你的观点"。本单元的三篇课文是三种不同的"说服方式"：梁启超用经典和例子论证"敬业乐业"，利哈乔夫用自己的生活经验谈"教养"，鲁迅用"驳论"（先反驳再立论）论证"中国有脊梁"。读完本单元，你应该能说清楚"一篇好的议论文长什么样"。
>
> **群文阅读**：把《敬业与乐业》《论教养》《中国人失掉自信力了吗》放在一起读——它们都是议论文，但结构完全不同：总分总、递进、先破后立。对比结构，就是议论文写作最好的模板。

---

> **📍 本单元阅读地图：**
> 这是你第一次系统接触议论文——跟以前读故事的心态完全不同，这次要"跟作者吵架"。建议先读《敬业与乐业》——结构最清晰，读完你就知道"论点+论据+论证"是怎么回事；再读《就英法联军远征中国致巴特勒上尉的信》——这篇很特别，用讽刺来写议论文，读着读着你就会忍不住说一声"骂得好"。
> 读完想一想：议论文要"说服"你，但每篇的方法不一样——哪篇更打动你？

### 5 敬业与乐业 / 梁启超

**结构：**
```
提出论点（敬业乐业是人类生活的不二法门）
  ├── 有业（前提）——引孔子/百丈禅师证明
  ├── 敬业（专一）——"主一无适便是敬"
  └── 乐业（趣味）——"凡职业都是有趣味的"
总结：敬业即是责任心，乐业即是趣味
```

**论证方法：** 引证法（孔子/朱熹/老子）、例证法（百丈禅师）

### 8 论教养 / 利哈乔夫

**核心观点：** 真正的教养是发自内心的对他人的尊重，不是表面的礼貌礼仪。

## 第三单元 · 古诗文（中考重点单元）

> **单元引言**：九年级上册唯一一个古诗文单元，也是全册最"重"的单元。岳阳楼记、醉翁亭记、湖心亭看雪——这三篇都是"记"（一种文体），但写法完全不同：范仲淹写的是"议论型游记"，借楼写志；欧阳修写的是"叙事型游记"，借亭写乐；张岱写的是"抒情型游记"，借雪写痴。放在一起读，你就能明白什么叫"同一文体，千变万化"。
>
> **群文阅读**：三篇都是"记"，但情感完全不同。可以做一个对比表格：

> | 篇目 | 写什么 | 关键词 | 情感 |
> |:----|:------|:------|:----|
> | 岳阳楼记 | 洞庭湖 | 先忧后乐 | 政治理想 |
> | 醉翁亭记 | 滁州山 | 与民同乐 | 山水之乐 |
> | 湖心亭看雪 | 西湖雪 | 痴 | 遗世独立 |
> 
> 同一个文体，同一个朝代（都是宋），三种截然不同的精神世界。这就是"群文阅读"的魅力。

---

> **📍 本单元阅读地图：**
> 这个单元的三篇古文是中考最高频考点——岳阳楼记、醉翁亭记、湖心亭看雪。建议先读《岳阳楼记》——篇幅最长但结构最清晰，先吃透这一篇；再读《醉翁亭记》——注意那21个"也"字的用法；最后读《湖心亭看雪》——最短的一篇，但意境最深，可以慢下来收尾。这三篇一起读，你会发现它们都在回答同一个问题："人站在高处看到了什么？"
> 读完想一想：这三篇都在写"站在高处"——岳阳楼上、醉翁亭上、湖心亭上——可为什么看到的东西完全不一样？

### 10 岳阳楼记 / 范仲淹

**【全文逐句精讲】**

**庆历四年春，滕子京谪守巴陵郡。越明年，政通人和，百废具兴，乃重修岳阳楼。**
```
庆历：宋仁宗年号（1044）
谪：被贬官（封建时代官吏降职或远调）
守：做州郡的长官（名词作动词）
越：到
具：同"俱"，全/都
乃：于是
→ 交代重修岳阳楼的背景
```

**予观夫巴陵胜状，在洞庭一湖。衔远山，吞长江，浩浩汤汤，横无际涯；朝晖夕阴，气象万千。此则岳阳楼之大观也，前人之述备矣。**
```
胜状：好景色
衔：含（写洞庭与远山的关系）
吞：吞吐（写洞庭与长江的关系）
浩浩汤汤：水势盛大的样子
横：广阔
际涯：边
晖：日光
大观：雄伟景象
备：详尽
→ "衔远山，吞长江"——两个动词写出洞庭湖的壮阔
```

**然则北通巫峡，南极潇湘，迁客骚人，多会于此，览物之情，得无异乎？**
```
然则：既然这样，那么……
极：直达（古今异义）
迁客：被贬谪的官员
骚人：诗人（屈原《离骚》）
得无：恐怕/是不是（表揣测语气，常与"乎"搭配）
→ 过渡段——从写景过渡到写"迁客骚人"的两种览物之情
```

**若夫淫雨霏霏，连月不开，阴风怒号，浊浪排空；日星隐曜，山岳潜形；商旅不行，樯倾楫摧；薄暮冥冥，虎啸猿啼。**
```
淫雨：连绵的雨（淫，过度）
霏霏：雨雪繁密的样子
开：放晴（古今异义）
怒号：大声吼叫（拟人）
排空：冲向天空
隐曜：隐没光辉（曜，光芒）
潜形：隐藏形体
樯倾楫摧：桅杆倒下船桨折断（樯，桅杆；楫，桨）
薄暮：傍晚（薄，迫近）
冥冥：昏暗的样子
→ 典型的"悲"景
```

**登斯楼也，则有去国怀乡，忧谗畏讥，满目萧然，感极而悲者矣。**
```
斯：这
去国：离开国都（去，离开）
怀乡：怀念家乡
忧谗：担心（小人进）谗言
畏讥：惧怕（遭到）讥讽
萧然：萧条凄凉的样子
→ 迁客骚人的"悲"——因外物而悲
```

**至若春和景明，波澜不惊，上下天光，一碧万顷；沙鸥翔集，锦鳞游泳；岸芷汀兰，郁郁青青。**
```
景：日光（古今异义）
不惊：不起/平静（惊，起）
锦鳞：美丽的鱼（借代，以鳞代鱼）
岸芷汀兰：岸上的小草/小洲上的兰花
郁郁：形容香气浓郁
→ 典型的"喜"景
```

**而或长烟一空，皓月千里，浮光跃金，静影沉璧，渔歌互答，此乐何极！**
```
或：有时
一空：完全消散
浮光跃金：月光照在水面上如金光跳跃
静影沉璧：月影映在平静的水中如沉入的白玉
何极：哪有穷尽
→ "浮光跃金，静影沉璧"——对仗，一动一静
```

**登斯楼也，则有心旷神怡，宠辱偕忘，把酒临风，其喜洋洋者矣。**
```
心旷神怡：心胸开阔精神愉快
宠辱偕忘：荣耀和屈辱都忘了（偕，一起）
把：端着
临：迎着
→ 迁客骚人的"喜"——因外物而喜
```

**嗟夫！予尝求古仁人之心，或异二者之为。何哉？不以物喜，不以己悲。**
```
嗟夫：唉（感叹）
尝：曾经
求：探求
古仁人：古代品德高尚的人
或：或许
异：不同于
为：这里指心理活动/表现
以：因为
→ 全文核心——古仁人不同于迁客骚人：不因外物好坏/个人得失而喜悲
```

**居庙堂之高则忧其民，处江湖之远则忧其君。**
```
居庙堂之高：在朝廷做官（庙堂=朝廷）
处江湖之远：在偏远的地方（不在朝廷做官）
→ 无论做官还是不做官，都在"忧"
```

**是进亦忧，退亦忧。然则何时而乐耶？其必曰"先天下之忧而忧，后天下之乐而乐"乎！**
```
进：在朝廷做官（古今异义）
退：退居江湖（古今异义）
其：大概/他们
先：在……之前（名词作状语）
后：在……之后（名词作状语）
→ "先忧后乐"——全文主旨
```

**噫！微斯人，吾谁与归？**
```
噫：唉
微：没有（古今异义）
斯人：这种人（指古仁人）
谁与归：归谁/跟谁一道（宾语前置）
```

**【结构总结】**
```
作记缘由（滕子京重修）→ 总写（巴陵胜状/洞庭大观）→ 过渡（览物之情得无异乎）
→ 悲（淫雨霏霏/去国怀乡）
→ 喜（春和景明/心旷神怡）
→ 议论升华（不以物喜不以己悲/先忧后乐）
```

**【主旨】** "先天下之忧而忧，后天下之乐而乐"——忧国忧民的博大胸怀

### 11 醉翁亭记 / 欧阳修

**【全文逐句精讲】**

**环滁皆山也。其西南诸峰，林壑尤美。望之蔚然而深秀者，琅琊也。**
```
环：环绕
滁：滁州
诸：众/各
壑：山谷
尤：特别
蔚然：茂盛的样子
深秀：幽深秀丽
→ 由远及近：滁州→西南峰→琅琊
```

**山行六七里，渐闻水声潺潺，而泻出于两峰之间者，酿泉也。**
```
山：沿着山路（名词作状语）
潺潺：流水声
泻出：倾泻而出
酿泉：泉水名
→ 听觉（水声）引路
```

**峰回路转，有亭翼然临于泉上者，醉翁亭也。**
```
回：回环/曲折
翼然：像鸟张开翅膀一样（名词作状语——比喻）
临：居高面下
→ "翼然"——写出亭子翘角如飞鸟展翅
```

**作亭者谁？山之僧智仙也。名之者谁？太守自谓也。**
```
作：建造
名：命名（名词作动词）
自谓：用自己的号（来命名）
```

**太守与客来饮于此，饮少辄醉，而年又最高，故自号曰醉翁也。醉翁之意不在酒，在乎山水之间也。山水之乐，得之心而寓之酒也。**
```
辄：就
故：因此
意：意趣/情趣（古今异义，今义为"意思"）
得：领会
寓：寄托
→ 千古名句——"醉翁之意不在酒"
```

**若夫日出而林霏开，云归而岩穴暝，晦明变化者，山间之朝暮也。**
```
林霏：树林里的雾气
开：散开
归：聚拢
岩穴：山洞/山谷
暝：昏暗
晦明：明暗
→ 朝暮之景
```

**野芳发而幽香，佳木秀而繁阴，风霜高洁，水落而石出者，山间之四时也。**
```
芳：花
发：开放
秀：繁茂/茂盛
→ 四季之景：春（花）夏（木）秋（霜）冬（水落石出）
四个"而"字写出时间流转
```

**朝而往，暮而归，四时之景不同，而乐亦无穷也。**
```
无穷：没有穷尽
```

**至于负者歌于途，行者休于树，前者呼，后者应，伛偻提携，往来而不绝者，滁人游也。**
```
负者：背着东西的人
伛偻：弯腰曲背（指老人）
提携：牵扶（指小孩）
→ 滁州百姓出游场景——太平盛世的画卷
```

**临溪而渔，溪深而鱼肥；酿泉为酒，泉香而酒洌；山肴野蔌，杂然而前陈者，太守宴也。**
```
渔：捕鱼
洌：清
山肴：野味
野蔌：野菜
陈：摆放
```

**宴酣之乐，非丝非竹，射者中，弈者胜，觥筹交错，起坐而喧哗者，众宾欢也。**
```
酣：尽兴喝酒
丝竹：音乐（借代）
射：投壶
弈：下棋
觥筹交错：酒杯和酒筹交互错杂
→ 宴会之乐
```

**苍颜白发，颓然乎其间者，太守醉也。**
```
苍颜：苍老的容颜
颓然：倒下的样子（古今异义，今义为颓废）
→ 太守的醉态
```

**已而夕阳在山，人影散乱，太守归而宾客从也。树林阴翳，鸣声上下，游人去而禽鸟乐也。**
```
已而：不久
阴翳：形容枝叶茂密成荫（翳，遮盖）
去：离开
→ 宴散归去
```

**然而禽鸟知山林之乐，而不知人之乐；人知从太守游而乐，而不知太守之乐其乐也。**
```
乐其乐：以他们的快乐为快乐（乐，意动用法）
→ "乐其乐"——与民同乐
```

**醉能同其乐，醒能述以文者，太守也。太守谓谁？庐陵欧阳修也。**
```
述：记述
谓：为/是
→ 点明身份
```

**【主旨】** 与民同乐——醉翁之意不在酒，在乎山水之间，更在于百姓之乐。

**【21个"也"字的作用（考点）】**：判断句表肯定、解释句表说明、陈述句表描写——一唱三叹，增强抒情性。

### 12 湖心亭看雪 / 张岱

**【全文逐句精讲】**

**崇祯五年十二月，余住西湖。大雪三日，湖中人鸟声俱绝。**
```
崇祯：明思宗年号（1632年）——明已亡但张岱仍用明纪年，表达故国之思
俱：都
绝：消失
→ 大雪后的静寂
```

**是日更定矣，余拏一小舟，拥毳衣炉火，独往湖心亭看雪。**
```
是：这
更定：晚上八点左右（古时一夜分五更）
拏：撑/划
拥：裹着
毳衣：用皮毛做的衣服
独：独自
→ "独往"——孤独的文人雅兴
```

**雾凇沆砀，天与云与山与水，上下一白。湖上影子，惟长堤一痕、湖心亭一点、与余舟一芥、舟中人两三粒而已。**
```
雾凇：雾气和水汽结成的冰花
沆砀：白气弥漫的样子
一白：一片白色
惟：只有
痕：痕迹
芥：小草（比喻极小）
而已：罢了
→ 白描手法——"一痕、一点、一芥、两三粒"：由大到小，天地之阔和人之渺小
量词的运用："痕"→"点"→"芥"→"粒"——逐层缩小——对比
```

**到亭上，有两人铺毡对坐，一童子烧酒炉正沸。见余大喜曰："湖中焉得更有此人！"拉余同饮。**
```
毡：毛毡
焉得：哪能
更：还
→ 偶遇知音——原来世上还有和我一样痴的人
```

**余强饮三大白而别。问其姓氏，是金陵人，客此。**
```
强：尽力/勉强
大白：大酒杯
客此：客居在此（名词作动词，客居）
→ "问其姓氏……是金陵人"——金陵是明朝旧都，暗示故国之思
```

**及下船，舟子喃喃曰："莫说相公痴，更有痴似相公者！"**
```
舟子：船夫
喃喃：小声不停地念叨
相公：对士人的尊称
痴：痴迷（指对山水/对故国的执着）
→ 点睛之笔——"痴"字是全文之眼
```

**【主旨】** 遗世独立的孤傲 + 对故国的怀念。

### 13 诗词三首

**行路难 / 李白**

"直万钱"→"不能食"——对比（物质丰盛vs内心苦闷）
"冰塞川""雪满山"——比喻仕途艰难
"垂钓碧溪"——用吕尚典
"梦日边"——用伊尹典

**酬乐天扬州初逢席上见赠 / 刘禹锡**
巴山楚水凄凉地，二十三年弃置身。怀旧空吟闻笛赋，到乡翻似烂柯人。
沉舟侧畔千帆过，病树前头万木春。今日听君歌一曲，暂凭杯酒长精神。
```
"闻笛赋"——用向秀典（怀念故友）
"烂柯人"——用王质典（世事变迁）
"沉舟侧畔千帆过，病树前头万木春"——哲理名句：新事物取代旧事物

**水调歌头 / 苏轼**
明月几时有？把酒问青天。不知天上宫阙，今夕是何年。
我欲乘风归去，又恐琼楼玉宇，高处不胜寒。起舞弄清影，何似在人间。
转朱阁，低绮户，照无眠。不应有恨，何事长向别时圆？

## 第四单元 · 小说

> **单元引言**：九年级的小说单元和七八年级有什么不同？——不只是"读懂故事"，而是"分析手法"。莫泊桑的"对比"、曹文轩的"环境烘托"、以及九下的鲁迅/契诃夫——读完这个单元，你应该学会分析"作者是怎么讲这个故事的"，而不仅仅是"故事讲了什么"。
>
> **群文阅读**：把《我的叔叔于勒》和《孔乙己》（九下）放在一起读——两篇都是"旁观者视角"：莫泊桑通过孩子若瑟夫的眼睛看于勒，鲁迅通过小伙计的眼睛看孔乙己。为什么都选择"旁观者"而不是"当事人"来讲述？这是小说叙事视角的关键技法。

---

> **📍 本单元阅读地图：**
> 这个单元学的是小说——人物、情节、环境、主题四要素。建议先读《我的叔叔于勒》——故事性最强，最吸引人；再读《故乡》——鲁迅的小说，需要多想一想"闰土为什么变了"；最后读《孤独之旅》——相对轻松的一篇，可以读快一点。
> 读完想一想：小说里的"变"和"不变"——闰土变了，于勒变了，杜小康呢？

## 第五单元 · 议论

> **单元引言**：本单元只有一篇重点课文——鲁迅的驳论文。但这一篇就值得你好好读。它不是普通的"提出论点→证明论点"的议论文，而是先"树靶子"再"打靶子"——这就是"驳论文"。学会这个结构，你写议论文就有了"先破后立"的招数。
>
> **群文阅读**：把《中国人失掉自信力了吗》和《敬业与乐业》（第二单元）对比——一个立论（直接说"要敬业"），一个驳论（先反驳"失掉自信力"再立论"有脊梁"）。两篇放在一起，议论文的两种基本范式就清楚了。

---

> **📍 本单元阅读地图：**
> 这个单元只有一篇重点课文《中国人失掉自信力了吗》——鲁迅的驳论文。先搞明白"驳论文"是什么（先树靶子再打靶子），再读课文。读的时候注意鲁迅是怎么一步一步把对方的观点推翻的。
> 读完想一想：鲁迅是怎么"骂人"还让人心服口服的？

### 17 中国人失掉自信力了吗 / 鲁迅

**驳论文结构：**
```
树靶子（有人慨叹"中国人失掉自信力了"）
├── 驳论证：信"地"信"物"→他信力
│           求神拜佛→自欺力
│           →根本不是自信力
└── 立论点：我们有并不失掉自信力的中国人在
    └── 论点支撑：埋头苦干的人（广大劳动人民）
                 拼命硬干的人（改革者）
                 为民请命的人（正义者）
                 舍身求法的人（探索者）
                 → 这就是中国的脊梁
```

## 第六单元 · 古典小说

> **单元引言**：古典小说是中考的"必考课外阅读"。《智取生辰纲》来自《水浒传》，《范进中举》来自《儒林外史》。读这两篇的目的不只是"了解故事情节"——你要学会分析古典小说的"章回体结构"和"讽刺手法"。《水浒传》的"双线结构"（明线暗线交叉）和"儒林外史"的"讽刺艺术"都是中考高频考点。
>
> **群文阅读**：《智取生辰纲》和《范进中举》对比——一个"武"（劫取生辰纲的故事）、一个"文"（科举考试的故事），但都是对封建社会"官逼民反"和"科举毒害"的批判。可以对比两篇小说的"环境描写"和"讽刺手法"有何不同。

---

> **📍 本单元阅读地图：**
> 这个单元四篇都选自中国古典名著——水浒、儒林、三国、红楼，每一篇都是名著里最精彩的那一页。建议先读《智取生辰纲》——像在看一部劫匪电影，你可能在电视上见过这个情节，但原文读起来更有味道；再读《范进中举》——笑着笑着就笑不出来了；然后读《三顾茅庐》——风雪天的三次登门，读的时候想想：诸葛亮凭什么让刘备跑三趟？《刘姥姥进大观园》放最后——最轻松的一篇，当甜点吃。
> 读完想一想：古典名著里的人物，为什么过了几百年还像活的一样？

## 第二单元 · 小说

> **单元引言**：九下的小说是初中小说阅读的"升级版"。鲁迅的《孔乙己》用第一人称旁观者视角写一个读书人的悲剧，契诃夫的《变色龙》用夸张和讽刺写一个小人物的见风使舵。两篇都是世界短篇小说的经典——读它们，不只是为了考试，更是为了学会"看小说"的方法：叙事视角、人物塑造、讽刺手法。
>
> **群文阅读**：鲁迅《孔乙己》和契诃夫《变色龙》对比——同样写"小人物"，孔乙己是悲剧，奥楚蔑洛夫是喜剧（讽刺）。为什么一个让你心酸，一个让你发笑？因为鲁迅用的是"冷眼旁观，满怀同情"的笔法，契诃夫用的是"夸张漫画"的笔法。

---

> **📍 本单元阅读地图：**
> 这个单元的小说篇篇经典。建议先读《孔乙己》——鲁迅最经典的短篇小说之一，篇幅短但内涵深；再读《变色龙》——契诃夫的讽刺小说，读着读着就笑了，但笑完会想很多；剩下的可以快速浏览。
> 读完想一想：读完了，故事还在脑子里转——这就是短篇小说的魅力。你认为呢？

### 5 孔乙己 / 鲁迅

**叙事视角：** 酒店小伙计（第一人称，冷眼旁观，增强真实感和讽刺效果）

**人物形象：**
| 细节 | 含义 |
|:----|:----|
| "青白脸色""乱蓬蓬的花白胡子" | 穷困潦倒 |
| "排出九文大钱" | 穷酸还要面子 |
| "茴香豆的茴字有四种写法" | 迂腐、死读书 |
| "窃书不能算偷" | 自欺欺人 |
| "大约孔乙己的确死了" | "大约"（无人关心）+"的确"（必死） |

**对比：**
- 孔乙己——穿长衫站着喝酒（身份尴尬：想当读书人，实际和短衣帮一样穷）
- 短衣帮——嘲笑孔乙己（底层人的冷漠）
- 丁举人——打断孔乙己的腿（读书人之间同样残酷）

**主旨：** 封建科举制度摧残人性 + 社会的冷漠无情

### 📚 1+X 延伸阅读
- 对比读：鲁迅《祝福》（同样是写"别人对一个人的悲剧漠不关心"——孔乙己的"大约的确"和祥林嫂的反复讲述，都是写"被忽略的人"）
- 对鲁迅感兴趣→《呐喊》自序

### 6 变色龙 / 契诃夫

**核心：** 奥楚蔑洛夫对狗咬人的态度随狗的主人而变化
```
不知是谁的狗→要严惩
→有人说可能是将军的→改口说狗小/人自己弄伤
→有人说不是将军的→又改口严惩
→又听说可能是将军的→再改口说狗不咬人
→将军的哥哥的狗→夸狗是好狗，威胁被咬的人
```

**手法：** 对比/夸张/讽刺——"变色龙"成为见风使舵的代名词

## 第三单元 · 古诗文（中考最重点）

> **群文阅读**：本单元是九年级最重要的古诗文单元。六篇文章涵盖四种类型：孟子散文（鱼我所欲也）——逻辑严密的说理；《战国策》故事（唐雎不辱使命）——有人物/有对话/有情节的记叙；宋濂赠序（送东阳马生序）——现身说法的劝学；苏轼/辛弃疾/范仲淹/纳兰性德的词——抒情言志。横向对比：同样是"写志向"，孟子直接论辩，唐雎以行动证明，苏轼以词言志，哪种最打动人？

---

> **📍 本单元阅读地图：**
> 这个单元的古文是初中阶段最后的三篇"硬骨头"——但啃完你就毕业了。建议先读《送东阳马生序》——故事性最强，宋濂像一位老爷爷坐在你对面，讲他小时候怎么借书抄书、怎么在大雪天赶路去请教老师，你会觉得"原来古代人读书也这么难"；再读《鱼我所欲也》——孟子跟你辩论"什么比生命更重要"，需要一边读一边想"你同意吗"；最后读《唐雎不辱使命》——像看一场没有刀光剑影但刀刀见血的外交对决。
> 
> 这三篇都在说"怎么做人"，但说的方式完全不同——你更喜欢哪种？

### 9 鱼我所欲也 / 孟子

**【全文逐句精讲】**

**鱼，我所欲也；熊掌，亦我所欲也。二者不可得兼，舍鱼而取熊掌者也。**
```
所欲：想要的（所字结构）
亦：也
得兼：同时得到
舍：舍弃
取：选取
→ 比兴——以鱼和熊掌引出下文
```

**生，亦我所欲也；义，亦我所欲也。二者不可得兼，舍生而取义者也。**
```
生：生命
义：道义/正义
舍生取义：为了正义宁可牺牲生命
→ 全文中心论点
```

**生亦我所欲，所欲有甚于生者，故不为苟得也；死亦我所恶，所恶有甚于死者，故患有所不辟也。**
```
甚于：胜过/比……更重要
苟得：苟且取得（指苟且偷生）
恶：厌恶
患：祸患/灾难
辟：同"避"，躲避
→ 论证：为什么能舍生取义——因为有比生命更重要的（义）/有比死亡更可怕的（不义）
```

**如使人之所欲莫甚于生，则凡可以得生者何不用也？使人之所恶莫甚于死者，则凡可以辟患者何不为也？**
```
如使：假如/假使
莫：没有
凡：一切
何不用也：什么手段不能用（反问）
何不为也：什么事不能做（反问）
→ 反证：如果人只贪生怕死，就会不择手段
```

**由是则生而有不用也，由是则可以辟患而有不为也。是故所欲有甚于生者，所恶有甚于死者。**
```
由：通过
是：这
则：就
→ 有能活下去的办法却不去用——说明有比生命更重要的东西
```

**非独贤者有是心也，人皆有之，贤者能勿丧耳。**
```
非独：不仅/不只是
是心：这种本心（指羞恶之心）
勿丧：不丢失
耳：罢了
→ 强调"本心"人人都有，只看是否保持
```

**一箪食，一豆羹，得之则生，弗得则死。呼尔而与之，行道之人弗受；蹴尔而与之，乞人不屑也。**
```
箪：古代盛饭的竹器
豆：古代盛食物的器皿
呼尔：大声呼喝（尔，词尾，……的样子）
与：给
蹴尔：用脚踢
不屑：认为不值得
→ 举例论证——即使是快要饿死的人也不会接受侮辱性的施舍
```

**万钟则不辩礼义而受之，万钟于我何加焉！**
```
万钟：优厚的俸禄（钟，古代量器）
辩：同"辨"，辨别
何加：有什么益处（加，增益/好处）
→ 对比：一碗饭都讲尊严，万钟俸禄却不辨礼义→何加？
```

**为宫室之美、妻妾之奉、所识穷乏者得我与？**
```
宫室之美：住宅的华美
奉：侍奉
所识穷乏者：认识的穷苦人
得：同"德"，感恩
与：同"欤"，语气词
→ 为了这些物质享受而失掉本心吗？
```

**乡为身死而不受，今为宫室之美为之；乡为身死而不受，今为妻妾之奉为之；乡为身死而不受，今为所识穷乏者得我而为之：是亦不可以已乎？此之谓失其本心。**
```
乡：同"向"，先前/从前
已：停止
本心：本性/羞恶之心
→ 排比——"乡……今……"对比，揭示见利忘义
→ "失其本心"——本文主旨
```

**【结构】**
```
提出论点（舍生取义）→ 正面论证（所欲有甚于生/所恶有甚于死）
→ 反面论证（如使……何不用也）→ 举例论证（食/豆）
→ 对比论证（乡vs今）→ 结论（此之谓失其本心）
```

**【成语】** 舍生取义

### 11 送东阳马生序 / 宋濂

**【全文逐句精讲】**

**余幼时即嗜学。家贫，无从致书以观，每假借于藏书之家，手自笔录，计日以还。**
```
即：就
嗜：特别喜欢
无从：没有办法
致：得到（古今异义）
假借：借（假=借，古今异义，今义假≠借）
手自：亲手
笔：用笔（名词作状语）
录：抄写
计日：计算日期
→ 读书条件之艰苦：无书→借书→抄书
```

**天大寒，砚冰坚，手指不可屈伸，弗之怠。**
```
砚冰坚：砚台里的墨冻成了坚冰
弗之怠：不懈怠（宾语前置，即"弗怠之"）
→ 天气寒冷也不放松——刻苦
```

**录毕，走送之，不敢稍逾约。以是人多以书假余，余因得遍观群书。**
```
走：跑（古今异义，今义为"走"）
逾约：超过约定的期限
以是：因此（以，因为；是，这）
得：能够
→ 守信→书主愿意借→能读更多的书
```

**既加冠，益慕圣贤之道。又患无硕师名人与游，尝趋百里外，从乡之先达执经叩问。**
```
既：已经
加冠：二十岁（古时男子二十岁行冠礼）
益：更加
慕：仰慕
患：担心
硕师：大师/名师（硕，大）
趋：奔赴
先达：有德行学问的前辈

→ 无师→百里外求学
```

**先达德隆望尊，门人弟子填其室，未尝稍降辞色。余立侍左右，援疑质理，俯身倾耳以请。**
```
德隆望尊：道德高声望高（隆，高）
填：挤满
未尝：从来没有
降：缓和
辞色：言辞和脸色
援疑质理：提出疑难询问道理（援，引/提出；质，询问）
俯身：弯下身子
倾耳：侧着耳朵
→ 老师的严厉 + 自己的恭敬
```

**或遇其叱咄，色愈恭，礼愈至，不敢出一言以复。俟其欣悦，则又请焉。**
```
或：有时
叱咄：训斥/呵斥（咄，呵叱）
愈：更加
至：周到
复：回答/还嘴
俟：等待
欣悦：高兴
→ 老师发脾气时越恭敬，等高兴了再问
```

**故余虽愚，卒获有所闻。**
```
卒：最终
所闻：学问/见识
→ 总结：虽然天资差，但因为勤奋，最终有所收获
```

**当余之从师也，负箧曳屣，行深山巨谷中，穷冬烈风，大雪深数尺，足肤皲裂而不知。**
```
负：背着
箧：书箱
曳：拖着
屣：鞋
穷冬：深冬
皲裂：皮肤因寒冷干燥而开裂
→ 环境艰苦→求学的艰辛
```

**至舍，四支僵劲不能动，媵人持汤沃灌，以衾拥覆，久而乃和。**
```
舍：学舍
支：同"肢"（通假字）
僵劲：僵硬
媵人：服侍的人（媵，陪嫁的人，这里指旅舍中的仆役）
汤：热水（古今异义，今义为"汤"）
沃灌：浇洗
衾：被子
拥覆：盖
和：暖和
→ 生活条件之艰苦
```

**寓逆旅，主人日再食，无鲜肥滋味之享。**
```
寓：寄居
逆旅：旅店（逆，迎接）
日再食：每天只吃两顿饭（再，两次）
→ 饮食条件之艰苦
```

**余则缊袍敝衣处其间，略无慕艳意。以中有足乐者，不知口体之奉不若人也。**
```

敝：破

慕艳：羡慕（慕，羡慕；艳，羡慕）

→ **核心句**：内心有足以快乐的事（读书），就不觉得物质条件差了

### 22 出师表 / 诸葛亮

**【全文逐句精讲】**（节选核心段落）

**先帝创业未半而中道崩殂，今天下三分，益州疲弊，此诚危急存亡之秋也。**
```
先帝：指刘备
崩殂：去世（崩，帝王死；殂，死亡）
疲弊：人力物力困乏
诚：实在/确实
秋：时刻/时期
→ 开篇分析形势：危急存亡之秋
```

**然侍卫之臣不懈于内，忠志之士忘身于外者，盖追先帝之殊遇，欲报之于陛下也。**
```
不懈：不松懈
忘身：奋不顾身
盖：因为（连词，表原因）
追：追念
殊遇：特殊的待遇/厚遇
→ 转笔：虽然形势危急，但有忠臣志士
```

**诚宜开张圣听，以光先帝遗德，恢弘志士之气，不宜妄自菲薄，引喻失义，以塞忠谏之路也。**
```
开张圣听：扩大圣明的听闻（广开言路）
光：发扬光大（名词作动词）
恢弘：发扬/振奋
妄自菲薄：过分看轻自己
引喻失义：说话不当（引喻，称引/比喻；失义，不合道理）
→ 第一条建议：开张圣听（广开言路）
```

**宫中府中，俱为一体，陟罚臧否，不宜异同。**
```
宫中：皇宫中（指侍臣）
府中：丞相府中（指官员）
陟：提拔
罚：处罚
臧否：善恶/好的坏的
异同：不同
→ 第二条建议：赏罚公平
```

**亲贤臣，远小人，此先汉所以兴隆也；亲小人，远贤臣，此后汉所以倾颓也。**
```
亲：亲近（形容词作动词）
远：疏远（形容词作动词）
所以：……的原因（古今异义）
兴隆：兴盛
倾颓：倾覆衰败
→ 第三条建议：亲贤远佞
```

**臣本布衣，躬耕于南阳，苟全性命于乱世，不求闻达于诸侯。**
```
布衣：平民
躬：亲自
苟全：姑且保全
闻达：闻名显达（闻，出名；达，显达）
→ 自述生平——为后面"出山"铺垫
```

**先帝不以臣卑鄙，猥自枉屈，三顾臣于草庐之中，咨臣以当世之事，由是感激，遂许先帝以驱驰。**
```
以：认为
卑鄙：身份低微见识短浅（古今异义）
猥：辱（自谦词）
枉屈：屈尊
顾：拜访
咨：咨询
感激：感动奋发（古今异义）
驱驰：奔走效劳
→ "三顾茅庐"——知遇之恩，所以愿效犬马之劳
```

**受任于败军之际，奉命于危难之间，尔来二十有一年矣。**
```
尔来：从那时以来
有：同"又"
→ 回顾追随先帝以来的艰难岁月
```

**先帝知臣谨慎，故临崩寄臣以大事也。**
```
寄：委托
大事：指辅佐后主/统一天下
→ 受命于先帝临终
```

**受命以来，夙夜忧叹，恐托付不效，以伤先帝之明，故五月渡泸，深入不毛。**
```
夙夜：早晚（夙，早）
忧叹：忧愁叹息
效：成效/实现
不毛：不毛之地（毛，草木/庄稼）
→ 日夜操劳，怕辜负先帝
```

**今南方已定，兵甲已足，当奖率三军，北定中原，庶竭驽钝，攘除奸凶，兴复汉室，还于旧都。**
```
奖率：鼓励率领
庶：希望
竭：用尽
驽钝：平庸的才能（自谦）
攘除：排除/铲除
奸凶：奸邪凶恶的人（指曹魏）
→ 北伐的打算
```

**此臣所以报先帝而忠陛下之职分也。至于斟酌损益，进尽忠言，则攸之、祎、允之任也。**
```
职分：职责本分
斟酌：反复考虑（斟，斟酒/考虑；酌，酌酒/考虑）
损益：利弊/兴利除弊
攸之、祎、允：郭攸之/费祎/董允（诸葛亮推荐的贤臣）
```

**愿陛下托臣以讨贼兴复之效，不效，则治臣之罪，以告先帝之灵。**
```
→ 立军令状——不成功就治罪
```

**今当远离，临表涕零，不知所言。**
```
临：面对
涕零：流泪（涕，古代指眼泪）
→ 结尾——"涕零""不知所言"，言辞恳切
```

# 附录：作文指导与范文

## 一、申怡·温儒敏视角

### 申怡：议论文 = 用阅读材料做"证明题"
九年级的核心变化：从"讲故事"变成"讲道理"。这是很多孩子最怕的转型——但申怡说，议论文就是一道证明题。

**群文阅读**：九年级议论文单元的编排本身就是最好的议论文写作课：
- 《敬业与乐业》：论点明确、分论点清晰、结构完整——议论文的"标准模板"
- 《中国人失掉自信力了吗》：驳论文——先破后立
- 《怀疑与学问》：提出问题→分析问题→解决问题的完整演示

把这三篇放在一起读，就是议论文写作的三套"公式"。

**理科思维**：写议论文前先画"逻辑链"——论点是什么、论据有哪几个、每个论据怎么支撑论点。一画清楚，文章结构就出来了。

### 温儒敏：议论文的"兜底"与"拔高"

**兜底**：中考议论文不需要多么深刻的见解。把论点说明白了、论据用对了、结构理清楚了——这就是一类文（36-40分/40分）的起点。

**守正**：议论文最怕"大而空"——"时代在召唤""我们要奋斗"。"从一篇具体的课文找到一个具体的观点，用一篇具体的阅读材料做论据"——这叫"守正"。用课内的《鱼我所欲也》论证"舍生取义"，用《出师表》论证"忠诚"，这是最稳的素材。不用去背"万能素材库"，课文就是最好的素材库。

**读书为要**：九下的《儒林外史》《简爱》是中考高频考点。但不要只为了考试读——这两本书本身就提供了大量的议论文素材。范进的故事（虚荣/科举制度的弊病）、简爱的独白（平等/独立/尊严）——读透了，写什么作文都有话说。

## 二、九年级写作重点：议论文——从"讲故事"到"讲道理"

### 课内写法借鉴

| 课文 | 可学的写作技巧 | 适用场景 |
|:----|:-------------|:--------|
| 《敬业与乐业》 | 分论点结构（总→分→总） + 引用论证 | 议论文框架 |
| 《中国人失掉自信力了吗》 | 驳论（先树靶子再打） | 辩论类/观点反驳 |
| 《怀疑与学问》 | 层层递进 | 求知类议论文 |
| 《鱼我所欲也》 | 对比论证（舍生 vs 贪生） | 价值选择类 |
| 《唐雎不辱使命》 | 对话中的逻辑较量 | 沟通/谈判类 |
| 《送东阳马生序》 | 现身说法（用自己的经历证明观点） | 劝学类 |
| 《曹刿论战》 | 强逻辑推理（一鼓作气/再而衰/三而竭） | 策略分析类 |
| 《邹忌讽齐王纳谏》 | 类比推理（以自身小事类推治国大事） | 沟通方法类 |
| 《出师表》 | 情理交融（动之以情+晓之以理） | 建言/建议类 |

### 议论文通用公式

**标准议论文结构**：
```
开头(1段)：提出中心论点（100-120字）
  第一分论点(1段)：分论点+论据1+分析（180-200字）
  第二分论点(1段)：分论点+论据2+分析（180-200字）
  第三分论点(1段)：分论点+论据3+分析（180-200字）
结尾(1段)：总结+升华（100-120字）
```

**论据选择顺序**：课内素材 → 名著素材 → 时事素材 → 名言警句
先保证课内的用对用准，再向外扩展。

### 范文：谈"责任"（中考风格）

> 梁启超先生在《敬业与乐业》中说："因自己的才能、境地，做一种劳作做到圆满，便是天地间第一等人。"这便是"责任"最朴素也最深刻的解读。
>
> 责任是范仲淹的"先忧后乐"。庆历六年，范仲淹在《岳阳楼记》中写下"先天下之忧而忧，后天下之乐而乐"，这不只是一句千古名言，更是一个政治家的毕生信念。他主持庆历新政、戍守边疆、兴办教育——句句有据，字字落地。真正的"责任"，不是挂在嘴边的口号，而是行动上的担当。
>
> 责任是唐雎的"不辱使命"。面对秦王的威胁，安陵国的使臣唐雎以"士之怒"据理力争，最终保全了安陵。一个小小的使臣，面对强秦的威压，他没有退缩——不是因为不怕死，而是因为"受命"二字重于千钧。他的责任，是对国家的忠诚，更是对使命的坚守。
>
> 责任是诸葛亮的"鞠躬尽瘁"。《出师表》中，诸葛亮对后主刘禅谆谆告诫，字字恳切。他本可以安享晚年，却选择"夙夜忧叹，恐托付不效"。他写"今当远离，临表涕零，不知所言"——这"不知所言"四字里，藏着多少说不尽的忧虑与责任？
>
> 先贤们早已用行动告诉我们：责任，是对自己能力的不辜负，是对他人信任的不辜负，更是对这个时代的不辜负。今天，坐在考场上写这篇作文的我，也在承担着对自己未来的责任——认真写完每一个字，就是对"责任"最好的诠释。

**点评（申怡视角）**：这篇议论文的亮点在于"课文就是最好的论据库"——范仲淹、唐雎、诸葛亮，全部来自九年级课文，没有一个"万能素材"。这就是"群文阅读"的写作应用——把读过的课文变成你的论证力量。

**点评（温儒敏视角）**：守正——结构标准（总分总），论据扎实（全部来自课文经典），论点清晰（责任是什么）。创新——最后一段把"古人"和"今天的我"巧妙勾连，提高了文章的层次。这就是"守正创新"的作文范例。

## 三、中考作文冲刺指南

### 1. 中考作文评分标准（温儒敏视角）
- **内容（40%）**：中心是否明确、素材是否具体、感情是否真实
- **结构（30%）**：层次是否清晰、过渡是否自然
- **语言（20%）**：表达是否准确流畅（不是"有文采"）
- **卷面（10%）**：字迹工整、标点正确

关键点：**文笔不是第一要义**。内容实在、结构清楚、字迹工整——三类文的底线，做好了就是二类文甚至一类文。

### 2. 考场作文"三步急救"

**3分钟审题**：
- 圈出题目中的关键词（是什么文体/要写谁/用什么写法）
- 想三个能用的素材（优先课内，再想课外）
- 确定中心论点

**35分钟写作**：
- 开头要快（直接点题，不绕弯）
- 主体要实（每个段落都有具体内容）
- 结尾要稳（呼应开头，自然收束）

**2分钟检查**：
- 有没有跑题？
- 有没有字明显写错？
- 标点有没有明显的错误？

### 3. 申怡提示：考场作文的高分密码

**审题**：看清题目给的"限制条件"和"开放空间"。限制条件决定了不能写什么，开放空间决定了可以写什么。

**立意**：不要追求"标新立异"——把平凡的事写出真情，比写一个自己都不信的大道理强百倍。

**选材**：选你真正熟悉的事。写母爱就写妈妈的一个具体动作；写成长就写一次具体的失败。

**结构**：五段式最保险（开头-段1-段2-段3-结尾），不要求在考场上创新结构。

**语言**：能用短句不用长句，能用动词不用形容词。

### 4. 温儒敏提示：中考作文的"兜底"
中考作文不怕写得"太普通"——怕的是"假"、"空"、"套"。
- "光阴似箭日月如梭"——不要
- "我一定努力学习报效祖国"——不要
- "这件事让我明白了……"——可以，但后面要有具体的话
- "妈妈的爱就像一盏灯"——可以，但这盏灯要具体点亮过什么

说真话，写真情，用真心——这三"真"就是中考作文的"基本口粮"。守住了，作文不会差。
