# 中考阅读答题模板

> 记叙文·说明文·议论文·文言文·古诗词 五类全题型
> 答题公式+术语+注意事项

---

## 一、现代文阅读通用方法

### 审题三步
1. **圈关键词**：题干中的"作用""含义""赏析""概括"等
2. **定题型**：作用题？含义题？赏析题？概括题？
3. **找答题区间**：根据题干定位段落

### 答题总原则
- **问什么答什么**，不跑偏
- **分条作答**（①②③），每条一个知识点
- **术语先行，分析在后**（先给概念，再结合文本）
- **问"作用"必答内容和结构两方面**

### 看分答题
- 2分 → 1个要点或2个要点（各1分）
- 3分 → 3个要点
- 4分 → 2个或4个要点
- 6分 → 3个要点（各2分）

## 二、记叙文阅读

### 题型1：概括文章内容/情节

**公式**：
```
人物 + 事件（起因→经过→结果） + 时间/地点（如需要）
```

**示例**：
- 鲁迅在百草园中（人物）夏天听蟋蟀、冬天捕鸟（事件），度过了快乐的童年（结果）

**变式：概括故事情节**
按"开端→发展→高潮→结局"梳理，用"谁+做了什么"的句式分条

---

### 题型2：标题的含义和作用

**含义题公式**：
```
表层含义（字面意思）+ 深层含义（象征/比喻/主旨）
```

**作用题公式**（从以下点对应选择）：
```
① 概括文章主要内容
② 点明文章主旨/中心
③ 作为线索贯穿全文
④ 设置悬念，吸引读者
⑤ 运用修辞，生动形象
⑥ 交代写作对象/时间/地点
```

---

### 题型3：赏析句子/加点词

**词语赏析公式**：
```
本义 + 语境义 + 写出了什么 + 表达什么情感
```

格式："XX词原指……，这里指……，生动地写出了……，表达了……"

**句子赏析公式**：
```
手法 + 手法效果 + 写出了什么 + 表达什么情感
```

**常见手法术语**：
- 修辞手法：比喻/拟人/排比/夸张/对偶/反问/设问/反复/对比
- 描写手法：肖像/语言/动作/心理/神态/环境/细节
- 表现手法：衬托/对比/象征/借景抒情/托物言志/欲扬先抑/以小见大/虚实结合/动静结合

**答题格式示例**：
"运用比喻的修辞手法，把……比作……，生动形象地写出了……，表达了作者……的情感。"

---

### 题型4：分析人物形象

**公式**：
```
从……（具体依据）可以看出XX是……的人（形容词/概括词）
```

**常用词汇**：
| 正面 | 反面 |
|------|------|
| 善良/勤劳/勇敢/乐观/坚强/朴实/真诚/感恩/孝顺 | 自私/虚伪/懦弱/冷漠 |
| 执着/细心/有责任心/爱国/爱民/关爱子女 | 骄傲/贪婪/阴险 |
| 聪慧/机智/博学/有远见 | 固执/愚昧 |

**找依据的角度**：
① 人物描写（肖像/语言/动作/心理/神态）
② 具体事件
③ 他人评价/作者评价

---

### 题型5：分析环境描写的作用

**公式**（从以下点对应选择）：
```
① 交代故事发生的时间/地点/背景
② 渲染……的气氛
③ 烘托人物……的心情
④ 推动情节发展（为下文做铺垫）
⑤ 暗示人物命运/性格
⑥ 深化主题
```

---

### 题型6：理解重点句子的含义

**公式**：
```
句子中关键词的含义 → 句子整体意思 → 表达了什么（主旨/情感）
```

关键点：
- 找出句子中的"特殊词"（比喻义/象征义/双关语）
- 联系上下文理解
- 联系全文主旨

---

### 题型7：段落的作用

**开头段公式**：
```
① 开篇点题/引出下文
② 设置悬念，吸引读者
③ 交代写作背景/人物
④ 奠定全文……的感情基调
```

**中间段公式**：
```
① 承上启下（过渡）
② 为下文做铺垫/埋伏笔
③ 补充交代……内容
```

**结尾段公式**：
```
① 总结全文/点明主旨
② 照应标题/开头（首尾呼应）
③ 深化中心/升华主题
④ 留白，引人深思
```

---

### 题型8：记叙顺序及作用

| 顺序 | 作用 |
|------|------|
| 顺叙 | 脉络清晰，层次分明 |
| 倒叙 | 设置悬念，吸引读者 |
| 插叙 | 补充交代……，使内容更充实/人物形象更丰满 |
| 补叙 | 补充说明……，使情节更完整 |

---

### 题型9：表达方式辨析

五种表达方式及常见作用：

| 表达方式 | 作用 |
|----------|------|
| 记叙 | 交代事件/人物活动 |
| 描写 | 刻画形象，使画面感强 |
| 抒情 | 直接或间接抒发情感 |
| 议论 | 揭示主旨，表明观点 |
| 说明 | 解释说明事物的特点 |

---

### 题型10：句子的表达效果

**从以下角度任选**：
```
① 用词角度：动词/形容词/叠词/拟声词 的运用效果
② 句式角度：长短句/整散句/反问/排比句的效果
③ 修辞角度：具体修辞手法的效果
④ 描写角度：具体描写方法的效果
⑤ 感官角度：视觉/听觉/嗅觉/触觉/味觉 多感官描写
```

## 三、说明文阅读

### 题型1：概括说明对象/特征

**公式**：
```
① 说明对象：+ 事物名/事理名（在标题或首段找）
② 特征：从文中逐段提炼关键词
```

答题格式："本文介绍了……的……特点"

---

### 题型2：说明方法及作用

| 说明方法 | 标志词 | 作用公式 |
|----------|--------|----------|
| 列数字 | 数据 | 具体准确地说明了…… |
| 举例子 | 例如/比如 | 具体有力地说明了…… |
| 打比方 | 像/仿佛/如同 | 生动形象地说明了…… |
| 作比较 | 比/相对于 | 突出强调了…… |
| 分类别 | 一类/另一类 | 条理清晰地说明了…… |
| 下定义 | 是/叫/叫做 | 科学准确地揭示了……的本质 |
| 作诠释 | 指/就是说 | 通俗易懂地解释了…… |
| 摹状貌 | 描写外貌/状态 | 具体形象地描摹了…… |
| 引资料 | 引用/据记载 | 更有说服力地说明了…… |
| 画图表 | 图表形式 | 直观明了地说明了…… |

**通用公式**：
```
运用了XX的说明方法，XX地说明了……（说明对象+特征）
```

---

### 题型3：说明文语言特点

**加点词能否删除**：
```
① 不能
② 解释词义（XX词意思是……）
③ 句中作用：限制/强调/修饰了……
④ 删除后变成……（太绝对/不准确）
⑤ 体现了说明文语言的准确性/科学性
```

**常见限制词**：
- 表程度：几乎/比较/相当/最
- 表范围：主要/大部分/大多数/一般
- 表时间：目前/至今/已经/将要
- 表估计：大约/左右/上下/可能/估计
- 表频率：经常/有时/通常

---

### 题型4：说明顺序

| 顺序 | 特征 | 标志性词语 |
|------|------|-----------|
| 时间顺序 | 按时间发展 | 从……到……/最早/后来 |
| 空间顺序 | 按空间位置 | 从上到下/从左到右/从远到近 |
| 逻辑顺序 | 按事理关系 | 从主到次/从因到果/从现象到本质 |

**作用公式**：
```
运用了XX说明顺序，符合人们认识事物的规律，使说明更有条理性
```

---

### 题型5：段落能否调换

**公式**：
```
① 不能调换
② 这几段分别写了……（概括内容）
③ 它们之间是……关系（递进/并列/因果）
④ 调换后不符合逻辑/违反人们认识规律
```

---

## 四、议论文阅读

### 题型1：找中心论点

**位置优先顺序**：
```
标题 → 开头段 → 结尾段 → 中间过渡段
```

**判断标准**：
① 是一个完整的判断句（不能是疑问句/比喻句/短语）
② 是作者对论述问题的明确观点
③ 能统率全文

---

### 题型2：找论据及作用

**论据类型**：
- 事实论据：具体事例/史实/数据/现象
- 道理论据：名言警句/科学原理/公理/俗语

**作用公式**：
```
运用了XX论据，具体有力地/充分有力地论证了……（分论点/中心论点）
```

---

### 题型3：论证方法及作用

| 论证方法 | 特征 | 作用公式 |
|----------|------|----------|
| 举例论证 | 举具体事例 | 具体有力地论证了…… |
| 道理论证 | 引名言/原理 | 权威有力地论证了…… |
| 对比论证 | 正反两方面对比 | 突出强调了…… |
| 比喻论证 | 用比喻说理 | 生动形象地论证了…… |
| 类比论证 | 同类事物比较 | 通俗易懂地论证了…… |

**通用公式**：
```
运用了XX论证方法，XX地论证了……，使论证更……（有说服力/形象/突出）
```

---

### 题型4：论证结构

| 结构 | 特征 |
|------|------|
| 总分式 | 总→分 / 分→总 / 总→分→总 |
| 并列式 | 各层次并列，无主次 |
| 递进式 | 层层深入，由表及里 |
| 对照式 | 正反对比 |

**作用公式**：
```
采用XX式结构，思路清晰，层次分明，论证严密
```

---

### 题型5：议论文语言特点

**答题角度**：
```
① 严密性：用词准确（如"最""之一""几乎"等）
② 逻辑性：关联词（如"因此""然而""但是"）
③ 概括性：语言精炼，高度概括
④ 鲜明性：观点鲜明，语气肯定/否定
```

---

### 题型6：某段能否删除

**公式**：
```
① 不能删除
② 该段论证了……观点
③ 与前后文构成……关系
④ 删除后论证不严密/不完整
```

## 五、文言文阅读

### 题型1：解释实词

**方法**：
```
① 课内迁移法：联系课内学过的词语
② 上下文推断法：根据语境猜词义
③ 成语印证法：联想到含有此字的成语
④ 语法分析法：看词性（名/动/形）
```

### 题型2：翻译句子

**公式**：
```
关键实词（逐字译）+ 关键虚词（补出省略成分）+ 调整语序（倒装句还原）
```

**原则**：信（准确）达（通顺）雅（有文采）

**标准要求**：
- 留：人名/地名/官名/年号等专有名词保留不译
- 删：无实义的虚词删去
- 补：补出省略的主语/宾语/介词
- 换：把古词换成现代汉语
- 调：调整倒装句语序

---

### 题型3：断句（划分朗读节奏）

**规律**：
```
① 主谓之间要停顿：如"食马者/不知其能千里而食也"
② 动宾之间要停顿：如"刻/唐贤今人诗赋于其上"
③ 状语后置前要停顿：如"受任/于败军之际"
④ 发语词/关联词后要停顿：如"夫/环而攻之"
⑤ 按句意划分，不要拆散双音节词
```

---

### 题型4：概括文章内容

**公式**：
```
写了什么（事件/场面） + 表达了什么（主旨/情感/道理）
```

---

### 题型5：分析人物特点

**与记叙文人物分析相同**，从语言/动作/事件中提取人物特征

---

### 题型6：分析写作手法

**常见手法**：
```
① 对比（如：得道多助失道寡助）
② 层层递进（如：生于忧患"
③ 并列论证（如：鱼我所欲也）
④ 托物言志（如：爱莲说）
⑤ 借事说理（如：伤仲永）
```

---

### 题型7：谈启示/感悟

**公式**：
```
文中道理/人物品质 + 结合自身 + 在今后的学习/生活中怎么做
```

## 六、古诗词鉴赏

### 题型1：描绘画面

**公式**：
```
时间/地点 + 选取了……意象 + 描绘了……的画面 + 营造了……的意境
```

**要求**：
- 用自己的语言描述，不能直接翻译
- 要加入适当的修饰语（形容词/动词）
- 要体现画面感

**常见意境术语**：
```
雄浑壮阔 / 苍凉悲壮 / 清新优美 / 幽静恬淡
凄清冷寂 / 繁华热闹 / 萧瑟荒凉 / 空灵悠远
```

---

### 题型2：赏析名句

**公式**：
```
手法 + 写出了什么 + 表达了什么 + 为什么是名句（哲理/情感/境界）
```

**示例**：
"运用比喻，以梨花喻雪花，写出了胡天八月的壮美雪景，表达了惊喜之情，比喻新颖奇特。"

---

### 题型3：分析炼字

**公式**：
```
XX字的意思是……，此处用了……手法，写出了……，表达了……，富有表现力
```

**示例**：
"'悦'字意思是使……愉悦，此处用了使动用法，写出山光使鸟儿愉悦的情景，表现了诗人对自然之趣的向往。"

---

### 题型4：分析思想感情

**常用情感概括**：

| 类型 | 常见情感 |
|------|----------|
| 送别诗 | 依依不舍 / 祝福安慰 / 孤独寂寞 |
| 思乡诗 | 思念家乡 / 羁旅之愁 / 渴望归乡 |
| 边塞诗 | 建功立业 / 思乡怀亲 / 厌恶战争 |
| 怀古诗 | 借古讽今 / 昔盛今衰 / 感时伤世 |
| 咏物诗 | 托物言志 / 怀才不遇 / 坚守节操 |
| 山水田园诗 | 热爱自然 / 归隐之志 / 闲适恬淡 |
| 爱国诗 | 忧国忧民 / 杀敌报国 / 壮志未酬 |
| 闺怨诗 | 思念离人 / 青春易逝 / 孤独愁闷 |

---

### 题型5：分析写作手法

| 手法 | 特征 | 作用 |
|------|------|------|
| 借景抒情 | 写景+抒情 | 情景交融，含蓄蕴藉 |
| 托物言志 | 通过物写志向 | 含蓄深刻 |
| 虚实结合 | 实景+幻想回忆 | 丰富意境，拓展空间 |
| 动静结合 | 静景+动景 | 生动有趣 |
| 用典 | 引用历史故事 | 含蓄典雅 |
| 对比 | 两事物对照 | 突出强调 |
| 衬托 | 正衬/反衬 | 突出主体 |
| 以小见大 | 小细节写大主题 | 具体可感 |
| 象征 | 物象征某种精神 | 含蓄深刻 |
| 抑扬 | 先抑后扬/先扬后抑 | 出人意料 |

---

### 题型6：对比两首诗

**公式**：
```
相同点（题材/手法/情感）+ 不同点（具体差异）
```

**答题格式模板**：
```
① 两首诗都……（共同点）
② 不同之处在于：A诗……，B诗……
③ 造成差异的原因是……（作者经历/时代背景）
```

## 七、作文通用模板

（详见各年级详解附录中的作文指导，以下仅列核心公式）

### 记叙文结构公式
```
开头（点题+设置悬念/引人入胜）
→ 起因（简略）
→ 经过（详写，具体细节+描写）
→ 结果（简略）
→ 结尾（点明主旨+升华）
```

### 议论文结构公式
```
引论（提出论点）
→ 本论（分论点1+论据+论证 / 分论点2+论据+论证 / 分论点3+论据+论证）
→ 结论（重申论点+升华）
```

### 中考作文得分点
```
① 切题（不跑题，扣住关键词）——基础分
② 结构（条理清晰，层次分明）——加分
③ 内容（具体充实，有真情实感）——加分
④ 语言（有亮点句子，有描写）——高分
⑤ 卷面（字迹工整，无涂改）——印象分
```

---

> 本模板可配合各单元课文和往年中考真题使用，练习时对照模板找到对应题型，反复训练至熟练。
> 实战中注意：模板是骨架，具体分析有机还原文本细节的支持才是得分关键。
