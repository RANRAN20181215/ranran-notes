# 人教版初中语文全册详解 · 八年级下册

---

## 第一单元 · 民俗文化

> **为什么要学这个单元？**
> 你有没有在村里看过戏？或者跟一群小伙伴出去玩，回来路上偷偷摘过别人家的瓜果？这个单元写的都是"民俗"——社戏、信天游、腰鼓、灯笼——听起来很"土"，但鲁迅、贺敬之、刘成章、吴伯箫这些作家，偏偏从这些"土"东西里写出了最深的情感。为什么呢？因为这些民俗里藏着一个地方的灵魂：陕北人为什么吼信天游？黄土高原的人为什么打腰鼓？**每一个民俗后面，都站着一群人的性格和命运。**
>
> > **📍 本单元阅读地图：**
> > 这个单元带你体验不同地方的"热闹"。建议先读《社戏》——鲁迅写看戏，篇幅长但故事性强，最有代入感；再读《安塞腰鼓》——短，但节奏极快，适合一口气读完；然后读《回延安》——民歌体，可以试着用朗读的感觉读；《灯笼》放最后——最安静的一篇，需要静下心品。
> > 读完后问问自己：写民俗的文章，到底是在写"热闹"还是在写"人"？

### 🎙️ 这个单元怎么读

这个单元的课文**最适合大声读**——社戏的月夜行船、回延安的民歌节奏、安塞腰鼓的排山倒海，不读出来就损失了一半。

**语文课代表的话：** 别急着看笔记，先把课文读三遍。

**每篇课文建议的朗读节奏：**
- 《社戏》——叙事部分亲切自然，像在讲故事。月夜行船那段（"两岸的豆麦……"）要读慢一点，让画面在脑子里展开
- 《回延安》——这是民歌体信天游，**要读出节奏感**。试着打拍子读："杜甫川 / 唱来 / 柳林铺 / 笑"。如果会唱民歌，可以用唱的感觉读
- 《安塞腰鼓》——**越读越快、越读越有劲**。注意短句（"咝溜溜的南风吹动了高粱叶子"）要干脆有力，排比句要一口气推上去
- 《灯笼》——读慢、读轻，像在回忆什么。跟安塞腰鼓形成强烈对比——一篇是火，一篇是灯

**最重要的事**：安塞腰鼓和回延安这两篇，读出声和默读是完全不同的体验——试试看。

### 1 社戏 / 鲁迅

**选材：** 选自小说集《呐喊》（注意：不是散文）

**情节概要：**
平桥村是我的乐土→盼望去赵庄看戏→没船→双喜提议借八公公的船→月夜行船→赵庄看戏→归航偷罗汉豆→六一公公送豆→再也没有吃过那夜的好豆

**重点段落分析：**

**月夜行船（第11-12段）：**
"两岸的豆麦和河底的水草所发散出来的清香，夹杂在水气中扑面的吹来……"
"淡黑的起伏的连山，仿佛是踊跃的铁的兽脊似的，都远远的向船尾跑去了……"

- 多感官描写：嗅觉（清香）、触觉（扑面）、视觉（连山后退）、听觉（歌吹）
- 比喻：连山=兽脊"踊跃"——用动写静，以景衬人（急切的心情）
- 以"我"的错觉（山在跑）写船速之快

**人物形象：**
| 人物 | 特点 | 关键表现 |
|:----|:----|:--------|
| 双喜 | 聪明能干、有领导力 | 提议借船、打包票 |
| 阿发 | 憨厚老实 | "偷我们的罢，我们的大得多呢" |
| 六一公公 | 淳朴好客 | 豆被偷不生气还送豆 |

**"再也没有吃到那夜似的好豆"——含义（考点）：**
不是豆真的好吃，而是怀念童年的纯真和自由。豆=乡愁的寄托。

### 📚 1+X 延伸阅读
- 鲁迅《故乡》（同一作者笔下的"童年与成年"对比——闰土的变化会让你沉默）
- 鲁迅《呐喊》整本书（《社戏》选自《呐喊》——读完课文试试读整本）

### 2 回延安 / 贺敬之

**文体：** 陕北信天游（民歌体）

**手法：** 比喻、拟人、夸张
"杜甫川唱来柳林铺笑"——拟人
"白羊肚手巾红腰带"——地域特色
"母亲延安"——把延安比作母亲

**结构：**
```
一、回延安（激动）
二、忆延安（养育之恩）
三、亲人相见（热情）
四、延安新貌（喜悦）
五、展望未来（决心）
```

### 📚 1+X 延伸阅读
- 贺敬之《白毛女》（歌剧剧本——了解贺敬之的另一代表作）
- 陕北民歌选读（信天游是陕北民歌的一种——听听原汁原味的陕北民歌，感受方言的魅力）

---

### 3 安塞腰鼓 / 刘成章

**手法：** 排比、短句、节奏强烈

**重点：** "这腰鼓，使冰冷的空气立即变得燥热了，使恬静的阳光立即变得飞溅了……"
——排比+对比，写出安塞腰鼓的力量和冲击力

**主旨：** 赞美黄土高原人民的生命力和阳刚之气

### 📚 1+X 延伸阅读
- 刘成章散文集《羊想云彩》（感受陕西作家的文字魅力）
- 贾平凹《秦腔》（同写陕西民俗——对比两位作家笔下不同的陕西）

---

### 4 灯笼 / 吴伯箫

以小见大——由灯笼写到家国情怀

### 📚 1+X 延伸阅读
- 吴伯箫散文集《北极星》（《灯笼》选自其中——感受作者的散文风格）
- 冰心《小桔灯》（同写"灯"，但一个是乡愁，一个是希望——对比阅读）

### 📖 群文阅读：民俗里，藏着一方人的性格

本单元写的都是"民俗"，但每个地方的民俗气质完全不同：

| 对比维度 | 社戏(鲁迅) | 回延安(贺敬之) | 安塞腰鼓(刘成章) | 灯笼(吴伯箫) |
|---------|----------|-------------|---------------|-----------|
| 地域背景 | 浙江绍兴水乡 | 陕北延安 | 陕西安塞 | 全国（家国情怀） |
| 核心民俗 | 看戏/偷豆 | 信天游/回延安 | 腰鼓表演 | 灯笼文化 |
| 主要情感 | 怀念童年纯真 | 对延安的深情 | 赞美生命力量 | 家国情怀 |
| 写作风格 | 叙事+细节 | 民歌体抒情 | 排比+强烈节奏 | 以小见大 |
| 读后问一问 | 你童年有类似"好豆"的回忆吗？ | 为什么说延安是"母亲"？ | 你见过什么让你震撼的场面？ | 灯笼还能象征什么？ |
| **语言风格** | 鲁迅式克制——情感很深但文字很淡 | 信天游民歌体——节奏明快、口语化 | 排山倒海式——短句、排比、力量感 | 朴素含蓄——以小见大、不张扬 |

## 第二单元 · 科技说明文

> **为什么要学这个单元？**
> 你有没有注意过，每年春天燕子什么时候飞回来？桃花什么时候开？这些看起来平常的自然现象，其实是一种"语言"——大自然在用花开花落、燕去燕归跟我们说话。竺可桢爷爷用一辈子的时间听懂了这种语言，创立了中国的"物候学"。这个单元不教你写作文，而是教你一种叫"说明文"的本事——**把复杂的科学道理，用普通人听得懂的话说清楚。**
>
> > **📍 本单元阅读地图：**
> > 这个单元两篇事理说明文，学的是"怎么把一个道理说清楚"。《大自然的语言》讲物候学——从现象到原因到意义，逻辑很清楚，适合精读；《阿西莫夫短文两篇》用恐龙灭绝的例子讲科学推理——像破案一样，读起来有意思，可以读快一点。
> > 读完想一想：科学的道理这么复杂，作者是怎么让普通人读懂的？

---

### 5 大自然的语言 / 竺可桢

**说明对象：** 物候学
**说明顺序：** 逻辑顺序（现象→原因→意义）

**说明方法：**
- 举例子（北京物候记录、南京刺槐开花）
- 列数字（1962年花期比1961年迟十天）
- 作比较（南方vs北方物候差异）

### 📚 1+X 延伸阅读
- 竺可桢《天道与人文》（竺可桢的科普文集——了解物候学背后的故事）
- 科普读物《寂静的春天》（卡逊著——另一本改变世界的科普经典，看看科普写作的力量）

---

### 📖 群文阅读：说明文也能读出新知

| 对比维度 | 大自然的语言 |
|---------|-----------|
| 说明对象 | 物候学——自然现象与气候的关系 |
| 说明顺序 | 现象→原因→意义（逻辑顺序） |
| 说明方法 | 举例子、列数字、作比较 |
| 最大收获 | 大自然原来在用这种方式和我们说话 |

（本单元只有一篇课文——试着用学到的说明方法，向同学介绍你观察到的"大自然的语言"）

## 第三单元 · 古诗文（古人眼中的理想生活）

> **为什么要学这个单元？**
> 你有没有想过，什么样的人生算是最好的？陶渊明说，最好的人生是"世外桃源"——没有战争、没有压迫、人人安居乐业；柳宗元说，最好的人生是在小石潭边坐一坐，听水声、看游鱼；《诗经》里的人说，最好的人生是和心爱的人在一起。这个单元的古人，生活在几百上千年前，但他们思考的问题和今天的我们一样：**人应该怎样生活？什么才是真正的快乐？**
>
> > **📍 本单元阅读地图：**
> > 这个单元全是古文——游记、说明文、诗歌，是八下最需要花时间的单元。建议先读《桃花源记》——故事性最强，最容易读进去；再读《小石潭记》——同为游记，但情感完全不同，可以和《桃花源记》对比着读；然后读《核舟记》——说明性的古文，换一种节奏；《诗经》二首放最后——古人的情歌，可以读得轻松一点。
> > 读完后问问自己：古人出门旅游，为什么回来写的不是攻略而是千古名篇？

### 9 桃花源记 / 陶渊明

**【全文逐句精讲】**

**晋太元中，武陵人捕鱼为业。缘溪行，忘路之远近。**
```
太元：东晋孝武帝年号（376-396）
武陵：今湖南常德一带
缘：沿着/顺着
行：走
→ 开头交代时间、地点、人物
"忘路之远近"——无意中入桃花林（偶然性）
```

**忽逢桃花林，夹岸数百步，中无杂树，芳草鲜美，落英缤纷。**
```
忽：突然
逢：遇到
夹岸：两岸
杂：别的/其他的
芳草：芬芳的草
鲜美：鲜艳美丽（古今异义）
落英：落花
缤纷：繁多的样子
→ 意境：桃花林的美，令人向往。为后文做铺垫。
```

**渔人甚异之，复前行，欲穷其林。**
```
甚：很/非常
异：对……感到惊异（形容词的意动用法）
复：又
前行：向前走
穷：走完（形容词作动词）
```

**林尽水源，便得一山，山有小口，仿佛若有光。便舍船，从口入。**
```
尽：到尽头（形容词作动词）
水源：溪水的源头
仿佛：隐隐约约（古今异义）
若：好像
舍：舍弃/丢下
→ "小口有光"——隐喻通向新世界的大门
```

**初极狭，才通人。复行数十步，豁然开朗。**
```
初：开始
极：非常
狭：狭窄
才：仅仅
通人：让人通过（使动用法）
豁然：开阔敞亮的样子
→ "豁然开朗"成语出处——由暗到明/由狭到阔
```

**土地平旷，屋舍俨然，有良田、美池、桑竹之属。阡陌交通，鸡犬相闻。**
```
平旷：平坦开阔
俨然：整齐的样子
良田：肥沃的田地
属：类
阡陌：田间小路（南北为阡、东西为陌）
交通：交错相通（古今异义）
相闻：互相听到
→ 环境描写：秩序井然、安宁祥和
```

**其中往来种作，男女衣着，悉如外人。黄发垂髫，并怡然自乐。**
```
种作：耕种劳作
衣着：穿戴
悉：都
外人：桃花源以外的人
黄发：老人（借代，老人发白转黄）
垂髫：小孩（借代，小孩垂发）
并：都
怡然：高兴的样子
→ 社会状态：人人安居乐业
```

**见渔人，乃大惊，问所从来。具答之。便要还家，设酒杀鸡作食。**
```
乃：竟然（古今异义，今义为"是"）
所从来：从哪里来
具：同"俱"，全都（通假字）
要：同"邀"，邀请（通假字）
设：摆
作食：做饭
→ 桃花源人的好客
```

**村中闻有此人，咸来问讯。**
```
咸：都
问讯：打听消息
```

**自云先世避秦时乱，率妻子邑人来此绝境，不复出焉，遂与外人间隔。**
```
自云：自己说
先世：祖先
率：带领
妻子：妻子和儿女（古今异义，今义仅指妻子）
邑人：同乡
绝境：与世隔绝的地方（古今异义，今义指绝望的境地）
焉：兼词，"于之"（从这里）
遂：于是
间隔：隔绝/不通音信（古今异义）
```

**问今是何世，乃不知有汉，无论魏晋。**
```
乃：竟然
无论：不要说/更不必说（古今异义）
→ 可见桃花源的人与外界隔绝之久
```

**此人一一为具言所闻，皆叹惋。余人各复延至其家，皆出酒食。停数日，辞去。**
```
为：给/向
具言：详细地说
叹惋：感叹惋惜
延：邀请
辞去：告辞离开
```

**此中人语云："不足为外人道也。"**
```
语：告诉
不足：不值得/不必
为：向/对
道：说
→ 嘱咐保密，为后文做伏笔
```

**既出，得其船，便扶向路，处处志之。**
```
既：已经
得：找到
扶：沿着/顺着（古今异义）
向：先前/原来的
志：做标记（名词作动词）
```

**及郡下，诣太守，说如此。太守即遣人随其往，寻向所志，遂迷，不复得路。**
```
及：到了
郡下：郡城
诣：到/往（特指到尊长那里去）
说如此：说了如此这般的情况
即：立即
遣：派遣
寻向所志：寻找先前所做的标记
遂：竟然
迷：迷路
→ 再也找不到了——桃源不可复得
```

**南阳刘子骥，高尚士也，闻之，欣然规往。未果，寻病终。后遂无问津者。**
```
刘子骥：东晋隐士（真实人物）
规：计划
未果：没有实现
寻：不久
问津：问路，这里指探访（津，渡口）
→ 结尾虚实结合，增加桃花源的神秘感和真实性
```

**【全篇结构】**
```
发现桃花林→进入桃花源→在桃花源做客→离开→再寻不得
（渔人行踪为线索）
```

**【主旨】**
表达对黑暗现实的不满和对理想社会的向往。

**【成语积累】**
- 世外桃源：不受外界影响的理想世界
- 豁然开朗：由狭窄昏暗变为开阔明亮
- 无人问津：没人过问
- 不足为外人道：不必向外人说起
- 怡然自乐：愉快而满足

**【常考题型】**
1. 桃花源"美"在哪里？
   → 环境优美（土地平旷/屋舍俨然）、社会安定（黄发垂髫怡然自乐）、民风淳朴（设酒杀鸡作食）

2. 桃花源为什么要"不足为外人道"？
   → 不愿被外界打扰，保持独立安宁

3. 结尾"不复得路"的用意？
   → 桃花源是理想而非现实，给人留下回味空间

### 📚 1+X 延伸阅读
- 陶渊明《归园田居》（五首——读完《桃花源记》再读这些诗，你会更懂陶渊明的理想）
- 陶渊明《五柳先生传》（陶渊明写自己——看看他心中的理想人格是什么样的）

### 📖 字词见面记录 - 桃花源记
- **之**：第七次见面（本课大量出现——"忘路之远近""渔人甚异之"——助词/代词均已熟练掌握）
- **其**：首次见面（"欲穷其林"做"那/这"——将在本课及以后大量出现）
- **以**：第四次见面（本课未见新用法）
- **于**：第四次见面（本课未见）
- **而**：频繁见面（本课"豁然开朗"中的连词用法——已熟悉）
- **者**：第三次见面（本课"捕鱼为业"无"者"——已在八上见过）
- **乃**：首次见面（"乃大惊"做"竟然"——古今异义注意）
- **妻子/绝境/无论/交通**：首次见面（四个古今异义词——注意今义和古义的区别）

### 10 小石潭记 / 柳宗元

**【作者与背景】**
柳宗元（773-819），唐代文学家，"唐宋八大家"之一。写于被贬永州时期，"永州八记"之一。

**【逐句精讲】**

**从小丘西行百二十步，隔篁竹，闻水声，如鸣珮环，心乐之。**
```
西：向西（名词作状语）
篁竹：竹林
珮环：玉制的装饰品（古人佩在腰上的玉）
乐：以……为乐（意动用法）
→ 未见其潭，先闻其声，以声引景
比喻：水声如珮环——清脆悦耳
```

**伐竹取道，下见小潭，水尤清冽。**
```
伐：砍
取道：开辟出道路
清冽：清凉（冽，寒冷）
→ "伐竹取道"四字写出探索过程
```

**全石以为底，近岸，卷石底以出，为坻，为屿，为嵁，为岩。**
```
全石以为底：以整块石头为底（"以全石为底"的倒装）
近岸：靠近岸边
卷石底以出：石底有些部分翻卷着露出水面（以，连词，相当于"而"）
坻：水中高地
屿：小岛
嵁：不平的岩石
岩：岩石
→ 四种形态写出石头的千姿百态
```

**青树翠蔓，蒙络摇缀，参差披拂。**
```
青树：青葱的树木
翠蔓：翠绿的藤蔓
蒙络：覆盖缠绕（蒙，覆盖；络，缠绕）
摇缀：摇动下垂
参差：长短不齐
披拂：随风飘拂
→ 十二个字写出树木藤蔓的形态：静→动
```

**潭中鱼可百许头，皆若空游无所依。日光下澈，影布石上。**
```
可：大约
许：左右
空游：在空中游动（比喻——水清澈得像空气）
依：依靠
下澈：向下照到水底
布：映照/散布
→ 正写鱼，侧写水之清。"空游无所依"——鱼像在空气中游
```

**佁然不动，俶尔远逝，往来翕忽。**
```
佁然：静止不动的样子
俶尔：忽然
远逝：向远处游去
翕忽：轻快迅疾的样子
→ 动静结合：静→动→再动（先写静止，后写游动）
```

**似与游者相乐。**
```
→ 鱼也通人性——拟人，与"心乐之"呼应
```

**潭西南而望，斗折蛇行，明灭可见。**
```
西南：向西南（名词作状语）
斗折：像北斗星那样曲折（名词作状语）
蛇行：像蛇那样蜿蜒前行（名词作状语）
明灭：时隐时现
→ 比喻写溪流：斗折（静态曲折）蛇行（动态蜿蜒）
```

**其岸势犬牙差互，不可知其源。**
```
犬牙：像狗牙一样（名词作状语）
差互：互相交错
→ 岸势：犬牙交错→幽深莫测
```

**坐潭上，四面竹树环合，寂寥无人，凄神寒骨，悄怆幽邃。**
```
环合：环绕合拢
寂寥：寂静空旷
凄：使……感到凄凉（使动用法）
寒：使……感到寒冷（使动用法）
悄怆：忧伤的样子
幽邃：幽静深远
→ 由乐转忧——"凄神寒骨"写内心的寒意
```

**以其境过清，不可久居，乃记之而去。**
```
以：因为
清：凄清/冷清（古今异义）
居：停留
乃：于是
去：离开
→ 为什么"不可久居"——清冷的环境触发了被贬的忧伤
```

**【情感变化（考点）】**
```
闻水声→心乐之（快乐）
看游鱼→相乐（快乐）
坐潭上→凄神寒骨（忧伤）
离去→不可久居（忧伤占主导）
```
→ 由乐转忧。快乐只是表面的，忧伤才是内心深处的——寄情山水只能暂时忘忧

### 12 《诗经》二首

#### 关雎

**关关雎鸠，在河之洲。窈窕淑女，君子好逑。**
```
雎鸠：水鸟，雌雄情意专一
洲：水中的陆地
窈窕：体态美好的样子
好逑：好的配偶
→ 比兴——以雎鸠的和鸣引出对淑女的追求
```

**参差荇菜，左右流之。窈窕淑女，寤寐求之。**
```
流：捞取
寤寐：日日夜夜（寤，醒；寐，睡）
→ 追求之执着
```

**求之不得，寤寐思服。悠哉悠哉，辗转反侧。**
```
思服：思念
悠：忧思的样子
→ 失恋后的痛苦与煎熬
```

**参差荇菜，左右采之。窈窕淑女，琴瑟友之。**
**参差荇菜，左右芼之。窈窕淑女，钟鼓乐之。**
```
琴瑟：弹琴鼓瑟（名词作动词）
友：亲近（名词作动词）
芼：挑选
钟鼓：敲钟击鼓（名词作动词）
乐：使……快乐（使动用法）
→ 从"寤寐求之"到"琴瑟友之""钟鼓乐之"——从痛苦追求到和谐共处
```

#### 蒹葭

**蒹葭苍苍，白露为霜。所谓伊人，在水一方。溯洄从之，道阻且长。溯游从之，宛在水中央。**
```
蒹葭：芦苇
苍苍：茂盛的样子
伊人：那个人
溯洄：逆流而上
溯游：顺流而下
宛：仿佛/好像
→ 可望而不可即——写对美好理想的执着追求
```

**重章叠唱：** 三章只换几个字（苍苍→凄凄→采采；霜→晞→已；长→跻→右等）

**意境：** 朦胧、凄清、迷离。求而不得的惆怅。

## 第四单元 · 演讲

> **为什么要学这个单元？**
> 你有没有在某个时刻，特别想站起来说几句话？这个单元教你"好好说话"——不是平时聊天的那种说话，而是站在台上、面对很多人说话。闻一多在李公朴追悼会上做了一次演讲，当天下午就被暗杀了——他的演讲是用生命写的；丁肇中讲"格物致知"，告诉你科学精神是什么。这个单元不只是教你怎么演讲，更是要告诉你：**有些话值得大声说出来。**
>
> > **📍 本单元阅读地图：**
> > 这个单元学的是"演讲词"——写出来是文章，说出来是演讲。建议先读《最后一次讲演》——闻一多的演讲，情感最激烈，最能让你感受到"演讲的力量"；再读《应有格物致知精神》——丁肇中的演讲，理性的，正好对比。如果你有兴趣，可以试着把这两篇都朗读一遍——读出声来，感受完全不同。
> > 读完想一想："说"出来的文章和"写"出来的文章，读起来感觉有什么不同？

### 13 最后一次讲演 / 闻一多

**文体：** 演讲词
**背景：** 李公朴被暗杀后，闻一多在追悼会上做此演讲，当天下午也被暗杀。

**特点：** 强烈的感情色彩、口语化、反问/感叹句

**名句：** "你们杀死一个李公朴，会有千百万个李公朴站起来……"
"我们随时像李先生一样，前脚跨出大门，后脚就不准备再跨进大门！"

## 第五单元 · 游记

> **为什么要学这个单元？**
> 你出去旅游的时候，会怎么记录你的行程？拍照发朋友圈？这个单元的作家不是这样的——他们去一个地方，不是"打卡"，而是"和那个地方对话"。梁衡站在壶口瀑布前，看到的不是"好大的水"，而是黄河的性格和中华文明的精神；马克·吐温登上勃朗峰，看到的不是"好高的山"，而是一路上的趣人趣事。这个单元要告诉你的就是：**真正的旅行，是用心去看，而不是用眼睛去扫。**
>
> > **📍 本单元阅读地图：**
> > 这个单元的文章都是"游记"——去一个地方，用自己的眼睛看、用心感受。建议先读《壶口瀑布》——描写最精彩，读完想去现场看看；再读《在长江源头各拉丹东》——在冰川上的经历，跟壶口瀑布完全不同；后面的课文可以快速浏览，了解"游记三要素"怎么写就够了。
> > 读完后问问自己：同样去一个地方，为什么不同的人看到的完全不一样？

### 17 壶口瀑布 / 梁衡

**手法：** 定点换景（站在壶口）→写水的各种形态

**结构：** 雨季→枯水季→联想（黄河的性格→人的精神）

**主旨：** 黄河的博大宽厚的品质——"正像一个人，经历了许多磨难便有了自己的个性"

美国作家马克·吐温的游记，幽默风趣的文风。

本单元课文都在写"游"，但写法千差万别：

## 第六单元 · 古诗文（先哲的智慧）

> **为什么要学这个单元？**
> 庄子说，有一条叫鲲的鱼，有几千里大，变成一只叫鹏的鸟，翅膀像天边的云——你敢信吗？韩愈说，千里马常有，但伯乐不常有——你遇到过赏识你的人吗？这个单元的四位思想家——庄子、戴圣、韩愈、杜甫——生活在两千年前到一千年前之间，但他们问的问题，今天的你也会问：什么是真正的自由？什么是好的教育？人才为什么会被埋没？这个单元可能会让你发现：**古人的智慧，比你想象的要"现代"得多。**
>
> > **📍 本单元阅读地图：**
> > 这个单元的文言文很深——庄子、礼记、韩愈，都是"硬骨头"。建议先读《马说》——最短，故事性强，最好啃；再读《庄子二则》——庄子的故事很有意思，可以当寓言读；然后读《礼记二则》——议论性的，需要慢慢想；唐诗三首放最后——每次读一首，作为"休息站"。
> > 读完想一想：庄子讲故事、礼记讲道理、韩愈发牢骚——你更愿意听谁说话？

### 20 庄子二则

#### 北冥有鱼

**北冥有鱼，其名为鲲。鲲之大，不知其几千里也。化而为鸟，其名为鹏。鹏之背，不知其几千里也。怒而飞，其翼若垂天之云。**
```
北冥：北海（冥，同"溟"，海）
鲲：传说中的大鱼
化：变化（古代认为自然万物可以变化）
鹏：大鸟
怒：振奋/鼓翅（古今异义）
垂天之云：天边的云（垂，同"陲"，边际）
→ 鲲化为鹏——庄子想象力的极致
夸张：不知几千里
```

**是鸟也，海运则将徙于南冥。南冥者，天池也。**
```
海运：海动（海动时必然起大风，鹏借风南飞）
徙：迁移
天池：天然形成的大水池
```

**《齐谐》者，志怪者也。《谐》之言曰："鹏之徙于南冥也，水击三千里，抟扶摇而上者九万里，去以六月息者也。"**
```
志：记载
怪：怪异的事物
水击：在水面上拍击（水，名词作状语）
抟：盘旋飞翔
扶摇：旋风
去：离开
以：凭借
六月息：六月的大风（息，气息/风）
→ 鹏高飞九万里，借六月大风之力
```

**野马也，尘埃也，生物之以息相吹也。**
```
野马：山野中的雾气（像奔马，所以叫"野马"）
以：用
息：气息
→ 万物皆有所凭借（都不是真正自由）
```

**天之苍苍，其正色邪？其远而无所至极邪？其视下也，亦若是则已矣。**
```
苍苍：深蓝色（古今异义，今义为"灰白色"）
其……邪：是……还是……（选择问句）
正色：真正的颜色
至极：到尽头
视下：向下看
若是：像这样
则已矣：罢了
→ 庄子从大鹏的视角看世界，视角的转换
```

#### 庄子与惠子游于濠梁之上

**庄子曰："鲦鱼出游从容，是鱼之乐也。"**
```
从容：悠闲自得（古今异义）
是：这
乐：快乐
```

**惠子曰："子非鱼，安知鱼之乐？"**
```
子：你
非：不是
安：怎么
→ 著名的"濠梁之辩"
```

**庄子曰："子曰'汝安知鱼乐'云者，既已知吾知之而问我，我知之濠上也。"**
```
云者：如此如此（助词，表示提顿）
既：已经
知：知道
之：代词
濠上：濠水的桥上
→ 庄子的诡辩——"安"有两个意思：①怎么（惠子用的意思）②哪里（庄子偷换概念）
```

**主旨：** 庄子善于从艺术的角度欣赏万物，惠子则是逻辑思考。

- **其**：第五次见面（本课"其名为鲲"做"它的"——已熟练掌握）
- **之**：第十一次见面（本课"鹏之背""鲲之大"——助词"的"和取独用法已熟练掌握）
- **而**：频繁见面（本课"化而为鸟"——连词）
- **以**：第六次见面（本课"去以六月息"做"凭借/依靠"）

- **之（取独）**：首次系统讲"之"的取独用法——注意"鹏之徙于南冥"中"之"取消句子独立性

### 21 《礼记》二则

#### 虽有嘉肴

**虽有嘉肴，弗食，不知其旨也；虽有至道，弗学，不知其善也。**
```
虽：即使
嘉肴：美味的菜肴（嘉，好；肴，菜）
弗：不
旨：味美/甘美
至道：最好的道理
善：好处/妙处
→ 比兴——用嘉肴比喻至道
```

**是故学然后知不足，教然后知困。知不足，然后能自反也；知困，然后能自强也。故曰：教学相长也。**
```
是故：因此
困：困惑
自反：自我反思
自强：自我勉励
教学相长：教和学互相促进（长，促进）
```

#### 大道之行也

**大道之行也，天下为公。选贤与能，讲信修睦。**
```
大道：古代政治上的最高理想
行：实行
天下为公：天下是公共的
与：同"举"，选拔
修睦：培养和睦
```

**老有所终，壮有所用，幼有所长，矜、寡、孤、独、废疾者皆有所养。**
```
矜：同"鳏"，老而无妻
寡：老而无夫
孤：幼而无父
独：老而无子
废疾者：残疾人
→ 儒家大同社会的理想
```

### 22 马说 / 韩愈

**作者：** 韩愈（768-824），唐代文学家，"唐宋八大家"之首。

**全文逐句详解：**

**世有伯乐，然后有千里马。千里马常有，而伯乐不常有。**
```
伯乐：春秋时善相马的人（这里指识别人才的人）
然后：这样以后
而：连词，表转折
→ 名句。伯乐比千里马更难得——人才需要被发现
```

**故虽有名马，祗辱于奴隶人之手，骈死于槽枥之间，不以千里称也。**
```
故：所以
虽：即使
祗：同"只"，只是（通假字）
辱：受屈辱
奴隶人：奴仆/普通人（古今异义，今义指丧失自由的人）
骈死：并列而死（骈，两马并驾）
槽枥：马槽和马厩
以：用
称：称呼/著称
→ 千里马悲惨的命运：没被识别→被埋没→平凡地死去
```

**马之千里者，一食或尽粟一石。食马者不知其能千里而食也。**
```
一食：吃一顿
或：有时
尽：吃完
粟一石：一石粮食
食马者：喂马的人（食，同"饲"，喂养）
→ 千里马食量大，但养马人不知道
```

**是马也，虽有千里之能，食不饱，力不足，才美不外见，且欲与常马等不可得，安求其能千里也？**
```
是：这
能：能力
食：吃
才美：才能/优点
外见：表现在外面（见，同"现"，显露）
且：尚且
等：等同/一样
安：怎么（反问副词）
→ 吃不饱→力气不够→才能表现不出来→和普通马一样
一连串因果递进：千里马的悲剧
```

**策之不以其道，食之不能尽其材，鸣之而不能通其意，执策而临之，曰："天下无马！"**
```
策：用鞭子打（名词作动词）/马鞭
以：按照
道：正确的方法
尽其材：发挥它的才能（材，同"才"）
鸣：嘶鸣
通：了解
执策：拿着马鞭
临：面对
→ 养马人方法不对→不给吃饱→听不懂马叫→还说"没有千里马"！
辛辣讽刺——不是没有人才，是没有发现人才的人
```

**呜呼！其真无马邪？其真不知马也。**
```
呜呼：唉（感叹）
其……邪：难道……吗（反问）
其……也：大概……吧（推测）
→ 不是没有千里马，而是不识千里马！
```

**主旨：** 借千里马喻人才，批判统治者不识人才、埋没人才。

### 📚 1+X 延伸阅读

- 《古文观止》选读（《马说》被收录其中——读读那些流传千年的古文）

### 📖 字词见面记录 - 马说

- **其**：第七次见面（本课"其真无马邪"——注意"其"表反问"难道……吗"的新用法）
- **而**：频繁见面（本课"千里马常有，而伯乐不常有"做"但是/却"）

# 附录：作文指导与范文

## 一、申怡·温儒敏视角

### 申怡：游记写作 = 移动的群文阅读
八下第一单元是"民俗"（社戏/回延安/安塞腰鼓），第五单元是"游记"（壶口瀑布/滴水岩）。这两类文章的共同点是"一个人在特定场景中的感受"。

**群文阅读法教游记**：把《壶口瀑布》《在长江源头各拉丹冬》《登勃朗峰》《一滴水经过丽江》四篇放在一起读——四种不同的游记写法。有的重点在景（壶口瀑布），有的重点在人（登勃朗峰），有的视角独特（一滴水）。孩子的游记写不好，往往是因为只看了一种写法。

**三通之生活通**：写游记不是非得去名山大川。一次去乡下奶奶家、一次周末去公园、甚至一次去菜市场的经历——只要"用心看、用心感受"，都能写成好游记。

### 温儒敏：演讲写作的"降降温"
八下有一个"活动·探究"单元是演讲。温儒敏提醒：演讲是"综合语言活动"，不是"作文比赛"。不要把它搞得太正式太技术化——让孩子先敢说、再说好。

**读书为要**：《傅雷家书》《钢铁是怎样炼成的》是八下的名著。写读后感之前，先让孩子把整本"连滚带爬"地读完。读后感最忌讳的是一本书没读完就开始写感想——那只能写出空洞的套话。

## 二、八下写作重点：游记 + 读后感 + 演讲词

### 课内写法借鉴

| 课文 | 可学的写作技巧 | 适用作文类型 |
|:----|:-------------|:-----------|
| 《社戏》 | 童年回忆 + 真实细节（偷豆/揉船） | 难忘经历类 |
| 《回延安》 | 用地方特色元素（信天游/宝塔山）写故乡情 | 故乡类/地域类 |
| 《安塞腰鼓》 | 排比+短句+节奏感（描写动态场景的神技） | 场面描写类 |
| 《壶口瀑布》 | 定点观察（站在一个位置看/听/感受) | 游记 |
| 《在长江源头各拉丹冬》 | 移步换景（边走边看，地点变化→景色变化） | 游记 |
| 《登勃朗峰》 | 写景+写人交替（风景+登山的有趣人物） | 游记 |

### 八下新增难度：游记 + 读后感 + 演讲

**游记写作公式**：
```
去哪（时间地点人物）→ 沿途看到了什么（详写）→ 最难忘的一个画面（最详）→ 这个地方/经历给我的感受（自然升华）
```

**读后感写作公式**：
```
这本书/这篇文章讲了什么（简要概括）→ 最打动我的是哪一部分（详写）→ 联系自己的经历（最重要的一步）→ 这本书改变了我什么
```

### 范文：一次别离（成长类·八下风格）

> 我第一次真正理解"离别"，是在十三岁那年秋天。
>
> 那是我在镇小学的最后一个学期。开学第一天，班主任李老师走进教室，沉默了一会儿，然后说："同学们，这学期是我教你们的最后一学期了。我要调到县城的学校去。"
>
> 教室里突然安静了。窗外泡桐树的叶子开始变黄，有一片飘落下来，贴在窗玻璃上。
>
> 李老师教了我们整整四年。一年级的时候，她手把手教我们写自己的名字；二年级的时候，她给我们讲《西游记》，讲到孙悟空被压在五行山下，我们都哭了；三年级的时候，她发现我写字好看，让我当板报小组长——那是我第一次觉得自己"有用"。
>
> 最后一节课上的是《背影》。李老师读课文的时候，声音有些哽咽。我第一次发现，原来"爸爸爬月台"这个背影里，藏着那么多说不出口的爱。
>
> 下课铃响了，没有人动。
>
> 班长站起来大喊了一声："起立！"全班齐刷刷地站起来，声音比哪次都响亮——"老师再见！"
>
> 李老师的眼圈红了。她鞠了一躬，转身走出教室。那个背影——微胖的身材，蓝色的连衣裙，在阳光下拖出一道长长的影子——至今还在我眼前。
>
> 那一年我十三岁，第一次懂得了什么叫"离别"。也是第一次懂得：离别不是结束，而是以另一种方式继续存在。

**点评（申怡视角）**：这篇文章的成功在于"留得住"——每个细节都写得从容，不赶时间。"泡桐叶子贴在窗玻璃上""一年级手把手写名字""全班起立喊老师再见"——这些画面像电影镜头一样，一个一个定在那里，让读者记住了。

**点评（温儒敏视角）**：八年级的孩子能写出这样的文章，说明"读"的效果出来了。注意文中提到了《背影》——这就是"读书为要"的例子，读过的书会沉淀在想写的东西里。

## 三、八下写作方法指南

### 1. 游记：两种基本写法
**定点观察**（站定一个位置观察）：
```
选择一个位置 → 环绕式描写（左/右/前/后/上/下）→ 远/近交替 → 最突出的那个点详写
```

**移步换景**（边走边看）：
```
起点（在哪开始）→ 到第一处（看到了什么）→ 到第二处（又看到了什么）→ 终点（总的感受）
```

### 2. 读后感：别写成"内容简介"
```
× 错误写法：这本书讲了什么什么什么……（整篇全是概括）
✓ 正确写法：
  - 一句话概括：这本书讲的是XX的故事
  - 选一个点：XX这个人物/XX这个情节/XX这句话最打动我
  - 为什么打动我：因为我想到了自己的XX经历
  - 这本书改变了我什么：从今以后我遇到XX会怎么做
```

### 3. 申怡提示："三通"写游记
- **通课文**：去一个地方之前，先读读别人是怎么写这个地方的
- **通学科**：游记里可以加点地理知识（这个地方为什么形成这样的地貌）、历史知识（这个地方有什么历史故事）
- **通生活**：旅行中的见闻、当地人说的话、吃到的特别的食物——这些都是独一无二的素材

### 4. 温儒敏提示：降降温
**对游记**：不是非要写"心灵净化"。一次平常的出游，写了一篇平常的游记，这就很好。要求普通的也能写、还能写清楚，这就是"兜底"。

**对读后感**：不要要求每本书都写读后感。读一本写一本，阅读的乐趣就没了。十本里挑最有感觉的写一本，足够了。
