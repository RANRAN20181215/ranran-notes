## 三、病句修改

### 六大病句类型

#### 1. 语序不当

**常见错误**：
- 多层定语语序不当：表领属→表时间→数量词→动词短语→形容词→名词
  - 错例：他是我们学校的（表领属）一位（数量）有着30年教龄的（动词短语）优秀的（形容词）语文（名词）老师
- 前后对应语序不当：从……到…… / 不但……而且……
- 否定词位置不当

**修改方法**：把颠倒的词语调换到正确位置

---

#### 2. 搭配不当

| 类型 | 错例 | 修改 |
|------|------|------|
| 主谓搭配不当 | 他的写作水平明显增强了 | 水平提高 |
| 动宾搭配不当 | 我们要养成思考 | 养成习惯 |
| 主宾搭配不当 | 北京是城市之一 | 北京是城市 |
| 修饰语与中心语搭配不当 | 留下了深刻的画面 | 深刻的印象 |
| 关联词搭配不当 | 不但……而且是…… | 不但……而且 |

**修改方法**：改一个词使搭配得当

---

#### 3. 成分残缺或赘余

**成分残缺**：
- 缺主语："通过这次活动，使我们受到了教育。" → 删"通过"或"使"
- 缺宾语："学校开展了向雷锋同志学习。" → 加"的活动"
- 缺谓语："我们去年种的树。" → 加"长大了"

**成分赘余**：
- 重复啰嗦："大约有500人左右" → 删"大约"或"左右"
- "忍俊不禁地笑了" → 删"忍俊不禁"或"笑了"
- "国际间" "悬殊很大" "目的为了" "是因为……的原因"

**修改方法**：缺什么补什么，多余就删

---

#### 4. 结构混乱

**常见类型**：
- 句式杂糅："是由于……的原因" → "是由于……"或"……是……的原因"
- 常见的杂糅结构：
  - "本着……为原则" → "本着……的原则"或"以……为原则"
  - "对于……问题上" → "对于……问题"或"在……问题上"
  - "是由于……的结果" → "是由于……"或"是……的结果"
  - "原因是……造成的" → "原因是……"或"是由……造成的"
  - "被……所感动" → "被……感动"或"为……所感动"

**修改方法**：只保留一种表达方式

---

#### 5. 表意不明

**常见类型**：
- 指代不明："小明和小刚在打篮球，他赢了" → 他是谁？
- 歧义句："三个学校的校长" → 三个学校/三个校长？
- 多义词造成的歧义："他走了一个小时" → 走路/离开？

**修改方法**：把不明确的地方说清楚

---

#### 6. 不合逻辑

| 类型 | 错例 | 修改 |
|------|------|------|
| 前后矛盾 | 他是北方人，从不怕热 | 逻辑矛盾 |
| 否定不当 | 谁也不能否认这不是好事情 | 删一个否定 |
| 范围不清 | 他来书店买了书和文具 | 有交叉关系 |
| 主客颠倒 | 这本书对我很感兴趣 | 我对这本书很感兴趣 |
| 多重否定不当 | 难道能否定这次讨论没有意义吗 | 注意奇数否定表否定 |

**双重否定表肯定的常见结构**：
- 没有……不……
- 不能不……
- 不会不……
- 难道……不……

**修改方法**：调整逻辑关系

---

### 病句修改口诀

```
一看语序通不通（语序不当）
二看搭配对不对（搭配不当）
三看成分缺不缺（成分残缺）
四看结构杂不杂（结构混乱）
五看有没有歧义（表意不明）
六看逻辑顺不顺（不合逻辑）
```

---

### 病句修改步骤

```
第一步：通读句子，凭语感找出问题
第二步：提取主干（主谓宾），检查搭配
第三步：看枝叶（定状补），检查修饰是否恰P
第四步：看关联词、否定词，检查逻辑
第五步：确定病句类型，对症修改
```

## 四、修辞手法

### 九种常考修辞

#### 1. 比喻

**定义**：用相似的事物打比方

**结构**：本体 + 比喻词（像/仿佛/如同/似的/一样）+ 喻体

**分类**：
- 明喻：像/仿佛/如同（"月光如流水一般"）
- 暗喻：是/成为/变成（"那又浓又翠的景色，简直是一幅青绿山水画"）
- 借喻：不出现本体和比喻词（"最可恨那些毒蛇猛兽"）

**作用公式**：
```
把……比作……，生动形象地写出了…………的特征，表达了……情感
```

**注意**：有"像"不一定都是比喻（比较/举例/猜测不算）

---

#### 2. 拟人

**定义**：把物当人写，赋予物人的动作/情感/语言

**作用公式**：
```
赋予……人的……（动作/情感），生动形象地写出了……，表达了……情感
```

---

#### 3. 排比

**定义**：三个或三个以上结构相同/相似、语气一致的句子

**作用公式**：
```
句式整齐，节奏感强，增强了语言的气势，强调了……
```

---

#### 4. 夸张

**定义**：故意放大或缩小事物的特征

**分类**：
- 扩大夸张："危楼高百尺，手可摘星辰"
- 缩小夸张："五岭逶迤腾细浪"
- 超前夸张："还没喝到嘴里就醉了"

**作用公式**：
```
突出了……的特征，给读者留下鲜明深刻的印象
```

---

#### 5. 对偶

**定义**：字数相等、结构相同、意义相关的两个句子

**作用公式**：
```
句式整齐，音韵和谐，读来朗朗上口，富有韵律美
```

**示例**："两个黄鹂鸣翠柳，一行白鹭上青天"

---

#### 6. 反问

**定义**：用疑问形式表达确定的意思，不需要回答

**作用公式**：
```
加强了语气，强调了……，引发读者思考
```

**示例**："难道这不是真理吗？"

---

#### 7. 设问

**定义**：自问自答

**作用公式**：
```
引起读者的注意和思考，引出下文/突出强调……
```

**示例**："这是什么精神？这是共产主义精神。"

**区别**：设问是自问自答，反问是问而不答

---

#### 8. 反复

**定义**：同一个词/句重复出现

**作用公式**：
```
强调……，增强了语气，表达了强烈的……情感
```

---

#### 9. 对比

**定义**：把相反或相对的事物放在一起比较

**作用公式**：
```
把……和……对比，突出强调了……，使……更鲜明
```

---

| 修辞 | 关键词 | 作用 |
|------|--------|------|
| 比喻 | 像/仿佛/是/成为 | 生动形象 |
| 拟人 | 赋予人的动作/情感 | 生动形象 |
| 排比 | 三个相同句式 | 增强气势 |
| 夸张 | 夸大的表述 | 突出特征 |
| 对偶 | 对仗的两句 | 音韵和谐 |
| 反问 | 难道……吗/怎能…… | 加强语气 |

| 反复 | 重复出现 | 强调突出 |
| 对比 | 正反两方面 | 突出特征 |
| 借代 | 以特征代事物 | 鲜明简练 |
| 互文 | 前后补充 | 内容完整 |

## 五、标点符号

### 常考标点用法

#### 句号（。）
表陈述语气，用于陈述句末尾

#### 问号（?）
- 用于疑问句末尾
- **注意**：选择问句中间用逗号，最后用问号（"是去北京，还是去上海？"）
- **注意**：有疑问词但不是问句不用问号（"我不知道他去不去。"）

#### 叹号（!）
表强烈感情

---

#### 逗号（,）
- 句子内部停顿
- 主谓之间/动宾之间如需停顿可用

#### 顿号（、）
- 并列的词或短语之间
- 标有引号的并列成分之间通常不用顿号（可用逗号）
- 序次语后：第一、/第二、/首先、/其次、/A./B. 等用顿号

#### 分号（;）
- 并列关系的分句之间
- 分句内部已有逗号时，分句间用分号

---

#### 冒号（:）
- 引出解释/说明/列举
- 引出引语
- **注意**："某某说"在引文前用冒号，在引文中用逗号，在引文后用句号

#### 引号（"" ''）
- 直接引用
- 特殊含义/特殊称谓/反语
- **注意**：引文独立成句，句末标点在引号内；引文是句子的一部分，句末标点在引号外
- 引用之内的引用用单引号（''）

#### 括号（（））
- 文中注释/补充说明
- **注意**：句内括号紧跟在被注释词语后；句外括号放在句末标点后

---

#### 破折号（——）
- 解释说明
- 话题转折
- 声音延长
- 列举分承

#### 省略号（……）
- 表示列举的省略
- 表示说话断断续续
- 表示话没说完
- **注意**：省略号后不能再加"等"/"等等"
- **注意**：省略号前后一般不用点号

#### 书名号（《》）
- 书名/篇名/报刊名/歌曲名/影视名
- **注意**：不能用于课程名/活动名/奖项名/证件名

---

### 标点易错点总结

```
1. 有疑问词但不是问句 → 不用问号
2. 选择问句中间 → 逗号，最后用问号
3. 并列引号之间 → 可以不用顿号
4. 并列书名号之间 → 可以不用顿号
5. 省略号和"等/等等" → 不能同时用
6. 引文独立成句 → 句号在引号内
7. 引文作句子成分 → 句号在引号外
8. 冒号管到句末 → 不能跨句管
```

### 文学体裁常识

**古代文体**：
- 铭：刻在器物上的文字（《陋室铭》）
- 说：议论性文体（《爱莲说》《马说》）
- 记：叙事/写景/状物（《桃花源记》《小石潭记》）
- 表：臣子向皇帝上书（《出师表》）
- 序：赠言/评价（《送东阳马生序》）
- 书：书信（《答谢中书书》）

**古今诗歌**：
- 古体诗：自由，不限格律
- 近体诗：律诗（8句）/绝句（4句），讲格律
- 词：长短句，有词牌名
- 曲：散曲/杂剧

**四种文学体裁**：
- 诗歌：高度凝练，富有韵律
- 散文：形散神聚，自由灵活
- 小说：人物+情节+环境
- 戏剧：对话为主，舞台表演
