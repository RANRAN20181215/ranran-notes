## 第一单元 · 活动·探究（新闻）

> **为什么要学这个单元？**
> 你有没有在手机上看过新闻？那些短短几百字的消息，背后藏着什么写作套路？这个单元会带你走进新闻的世界——你会发现，一条好新闻不是随便写出来的，它有自己的"骨架"：标题吸引你点开，导语告诉你发生了什么，主体慢慢展开细节。学会读新闻，你就不会被标题党骗；学会写新闻，你就掌握了"用最少的字说清一件事"的本事。
>
> > **📍 本单元阅读地图：**
> > 这个单元是活动探究单元，不按常规方式学课文。四篇文章从消息到特写到通讯，越来越详细、越来越有文学性。建议按顺序读：先读两则消息，知道"新闻的基本样子"；再读《"飞天"凌空》——新闻特写，聚焦一个瞬间；最后读《一着惊海天》——通讯，最接近文学作品。读完后，可以试试自己写一则消息。
> > 读完想一想：同样一件事，消息、特写、通讯各是怎么写的？

【单元说明】本单元是活动探究单元——阅读新闻→采访→写作

### 🎙️ 这个单元怎么读

新闻单元的朗读跟散文完全不同——**不需要"有感情"，需要"有信息"**。读新闻的核心是：把事实说清楚，让听众一次听明白。

**语文课代表的话：** 别急着分析新闻结构，先把课文读两遍——用"播新闻"的语气读。

**每篇课文建议的朗读节奏：**
- 《消息二则》——读得清晰、有力。注意数字（"三十万大军"）要加重，地点要读清楚，整体语速比平时稍快——像新闻联播
- 《"飞天"凌空》——可以读出画面感。"轻舒双臂""轻轻一蹬"要读得轻盈，"咔嚓""沸腾"突然加速，像体育解说
- 《一着惊海天》——读得稳，像纪录片旁白。关键瞬间（"着舰！"）要停顿一下再读出结果

**课外可以试试**：找一篇手机上的新闻，用"播报"的语气读给家里人听。

### 1 消息二则 / 毛泽东

**我三十万大军胜利南渡长江（1949.4.22）**

**结构分析：**
- 标题：正题（谁+做了什么）
- 电头：新华社长江前线22日2时电
- 导语：英勇的人民解放军……渡过长江
- 主体：渡江的时间、地点、过程
- 结语：人民解放军正以自己的英雄式的战斗，坚决地执行毛主席朱总司令的命令

**人民解放军百万大军横渡长江（1949.4.24）**

三个层次（按地点）：中路军→西路军→东路军（详写）

**消息的知识点（必考）：**
1. **六要素：** 何时、何地、何人、何事、何故、如何
2. **结构：** 标题（引题+正题+副题）→电头→导语→主体→结语
3. **特点：** 及时性、真实性、简明性
4. **导语：** 消息的第一句话或第一段（最核心的内容）
5. **倒金字塔：** 最重要→次重要→最不重要（按重要性递减）

### 📖 群文阅读：同一事件，不同写法

同样是中国航母舰载机着舰这件大事，本单元用消息、特写、通讯三种版本呈现。试着对比一下：

| 对比维度 | 消息（第1课） | 新闻特写（第3课） | 通讯（第4课） |
|---------|------------|----------------|------------|
| 关注焦点 | 事件整体"谁+做了什么" | 一个瞬间（吕伟跳水那一刻） | 过程的完整性 |
| 时间跨度 | 结果出来立刻发 | 同一事件中的"一秒" | 事件全程 |
| 语言风格 | 简洁、客观 | 生动、细致、画面感 | 详细、可以有文学描写 |
| 读者感受 | 知道发生了什么事 | 仿佛亲眼看到了那一刻 | 仿佛亲历了整个过程 |

**想一想**：如果你要给没看比赛的人讲吕伟夺冠，你会用消息还是特写？为什么？

## 第二单元 · 回忆性散文和传记

> **为什么要学这个单元？**
> 你有没有想过，一个人死后，为什么还有人要写他？这个单元的三个人——藤野先生、朱德的母亲、列夫·托尔斯泰——他们之间毫无关系，但都因为某种品质被人深深记住。鲁迅写藤野先生，不是为了说"这个老师对我好"，而是在写一种超越国界的人格力量；朱德写母亲，不是在列母亲的功劳簿，而是在写劳动人民的坚韧。读完这个单元，你可能会发现：**一个人能被别人记住，从来不是因为他的地位，而是因为他的人格。**
>
> > **📍 本单元阅读地图：**
> > 这个单元三篇文章写三个人，但写法完全不同。建议先读《藤野先生》——鲁迅的文章，篇幅最长但故事性最强；再读《回忆我的母亲》——朱德写的，语言朴素，读起来很快；最后读《列夫·托尔斯泰》——这篇最特别，茨威格从肖像入手写一个人，写法很"洋气"，需要适应一下。
> > 读完后问问自己：写"别人"的文章，其实也是写"我"眼中的别人——你同意吗？

### 5 藤野先生 / 鲁迅

选自《朝花夕拾》。

**结构：**
```
第一部分（第1-3段）：东京见闻——"东京也无非是这样"→失望
第二部分（第4-35段）：在仙台
  ├── 去仙台途中——"日暮里""水户"（爱国情结）
  ├── 初见藤野先生——"黑瘦""八字须""戴着眼镜"
  ├── 藤野先生为"我"改讲义——认真负责
  ├── 藤野先生关心"我"的解剖——无民族偏见
  ├── 藤野先生问中国女人裹脚——求真知
  └── 幻灯片事件→弃医从文
第三部分（第36-38段）：与藤野先生的告别
第四部分（第39段）：对藤野先生的怀念和激励
```

**藤野先生形象：**
- 生活朴素（穿旧制服）
- 治学严谨（改讲义）
- 没有狭隘的民族偏见（关心中国留学生）
- 认真负责、正直热忱

**弃医从文的原因（考点）：**
- 看电影事件：中国人给俄国人当侦探被处死，围观的中国学生却欢呼
- "我的意见却变化了"：医学治不了中国人的精神麻木
- → 决定用文学唤醒国民

**名句：**
"他的性格，在我的眼里和心里是伟大的，虽然他的姓名并不为许多人所知道。"
"每当夜间疲倦……我总还要时时记起他……继续写些为'正人君子'之流所深恶痛疾的文字。"

### 📚 1+X 延伸阅读
- 《朝花夕拾》整本书（《藤野先生》是其中一篇——读完课文后试试读整本）
- 鲁迅《〈呐喊〉自序》（了解"弃医从文"的完整背景）

### 6 回忆我的母亲 / 朱德

**母亲的品质：** 勤劳、俭朴、宽厚、仁慈、坚强、有远见

**结构：** 按时间顺序——从童年到母亲去世

**名句：** "母亲最大的特点是一生不曾脱离过劳动"

### 📚 1+X 延伸阅读
- 邹韬奋《我的母亲》（同主题散文，对比两位不同的母亲形象）
- 史铁生《合欢树》（另一篇写母亲的当代散文）

### 8 列夫·托尔斯泰 / 茨威格

**手法：** 欲扬先抑（先写肖像的丑陋→再写眼睛的深邃）

**外貌描写：** 须发茂密、面容粗鄙、长相平庸
**眼睛描写（重点）：** "这道目光就像一把锃亮的钢刀刺了过来，又稳又准，击中要害"
**名言：** "看透事物的本质"

### 📚 1+X 延伸阅读
- 茨威格《三大师》（《列夫·托尔斯泰》选自这本书——包含巴尔扎克、狄更斯、陀思妥耶夫斯基等）
- 托尔斯泰《战争与和平》选读（感受托尔斯泰笔下宏大的世界）

### 📖 群文阅读：什么样的人值得被记住

本单元三篇课文都在写"人"，但写法完全不同：

| 对比维度 | 藤野先生(鲁迅) | 回忆我的母亲(朱德) | 列夫·托尔斯泰(茨威格) |
|---------|--------------|------------------|-------------------|
| 写作对象 | 日本老师 | 自己的母亲 | 俄国文学巨匠 |
| 核心品质 | 治学严谨、无民族偏见 | 勤劳俭朴、宽厚仁慈 | 深邃的思想、锐利的目光 |
| 叙事视角 | "我"的亲身经历 | 时间顺序回忆一生 | 肖像描写入手 |
| 主要手法 | 白描、对比、选材典型 | 朴素叙述、细节感人 | 欲扬先抑、夸张比喻 |
| 读后问一问 | 哪些细节让藤野先生"伟大"？ | 母亲对朱德最大的影响是什么？ | 为什么要先写丑再写眼睛？ |
| **语言风格** | 鲁迅式冷峻——讽刺中见深情 | 朱德式朴素——大白话、真情实感 | 茨威格式浓烈——铺陈排比、夸张渲染 |

## 第三单元 · 山水美景

> **为什么要学这个单元？**
> 你有没有过这样的经历——站在一座山顶上，或者走在一条溪边，突然觉得"太美了，但我说不出来美在哪"？这个单元的古人也有过同样的感受，而且他们写下来了。郦道元写三峡，短短一百多字就让人仿佛听到了猿声；苏轼在承天寺的月色中散了散步，留下了一篇仅85字的千古名文。这个单元带你去看看：古人面对山水时，是怎么用文字"画"出风景的。读完你可能也会想拿起笔，写写你看到过的风景。
>
> > **📍 本单元阅读地图：**
> > 这个单元全是文言文写景——古人怎么描写山水。建议先读《三峡》——郦道元写三峡，像纪录片解说词，好读；再读《答谢中书书》和《记承天寺夜游》——两篇都短，可以一口气读完；然后读《与朱元思书》——稍长一些，但写得极美；唐诗五首放最后——每次读一首，不要贪多。
> > 读完想一想：古人写山水不只是画风景——他们在山水里藏了什么？

### 9 三峡 / 郦道元

**作者与来源：** 郦道元（约470-527），北魏地理学家。《三峡》选自《水经注》。

**全文逐句详解：**

**自三峡七百里中，两岸连山，略无阙处。**
```
自：在（古今异义）
七百里：约今200公里
连山：连绵的山
略无：完全没有
阙：同"缺"，空隙/缺口
→ 在三峡七百里当中，两岸都是相连的山，完全没有中断的地方。
```

**重岩叠嶂，隐天蔽日，自非亭午夜分，不见曦月。**
```
重岩叠嶂：重重的悬崖，层层的峭壁
隐：遮蔽
自非：如果不是（自，如果）
亭午：正午
夜分：半夜
曦：日光，这里指太阳
→ 重重的悬崖，层层的峭壁，遮天蔽日，如果不是正午和半夜，就看不见太阳和月亮。
```

**至于夏水襄陵，沿溯阻绝。**
```
至于：到了（古今异义）
襄：上、冲上
陵：山陵、土山
沿：顺流而下
溯：逆流而上
阻绝：阻断
→ 到了夏天江水漫上山陵的时候，下行和上行的航道都被阻断不能通航。
```

**或王命急宣，有时朝发白帝，暮到江陵，其间千二百里，虽乘奔御风，不以疾也。**
```
或：有时
王命：皇帝的诏令
宣：宣布/传达
朝：早晨
发：出发
暮：傍晚
其间：从白帝到江陵之间
虽：即使（古今异义）
乘奔：骑着奔马（奔，飞奔的马，动词作名词）
御风：驾着风
以：认为/觉得
疾：快
→ 有时遇到皇帝的诏令要紧急传达，早晨从白帝城出发，傍晚就到了江陵，这中间有一千二百里，即使骑着奔马驾着风，也不认为这样快。
```

**春冬之时，则素湍绿潭，回清倒影。**
```
素湍：白色的急流（素，白色的；湍，急流）
绿潭：碧绿的深潭
回清：回旋的清波
倒影：倒映（的影子）
→ 春冬季节，白色的急流碧绿的深潭，回旋的清波倒映着影子。
```

**绝巘多生怪柏，悬泉瀑布，飞漱其间，清荣峻茂，良多趣味。**
```
绝巘：极高的山峰（巘，山峰）
悬泉：从山崖上流下的泉水
飞漱：飞速地冲荡
清荣峻茂：水清/树荣/山峻/草茂（一字一意）
良：确实/很
→ 极高的山峰上长着许多奇形怪状的柏树，悬泉瀑布飞速地冲荡在山峰之间，水清树荣山峻草茂，实在是很有趣味。
```

**每至晴初霜旦，林寒涧肃，常有高猿长啸，属引凄异。**
```
晴初：天刚放晴
霜旦：下霜的早晨
林寒涧肃：树林和山涧显出一片清寒肃杀
啸：叫
属引：连续延长（属，连接；引，延长）
凄异：凄惨异常
→ 每到天刚放晴或下霜的早晨，树林和山涧清冷肃静，常有高处的猿猴拉长声音啼叫，声音连续不断，凄惨异常。
```

**空谷传响，哀转久绝。故渔者歌曰："巴东三峡巫峡长，猿鸣三声泪沾裳。"**
```
传响：传来回声
哀转：声音悲凉婉转
绝：消失
渔者：打鱼的人
三声：几声（三，泛指多）
沾：沾湿
裳：古代指下衣
→ 在空旷的山谷中传来回声，声音悲凉婉转，很久才消失。所以打鱼的人唱道："巴东三峡巫峡长，猿鸣三声泪沾裳。"
```

### 写作特色
① 动静结合：山（静）→水（动/静）
② 正面侧面结合：侧面（"自非亭午夜分，不见曦月"写山高）→正面
③ 大笔点染：不细写，宏观勾勒
④ 语言精炼：一字一意（清荣峻茂）

### 常考题型
1. "素湍绿潭，回清倒影"——对仗，动静结合
2. 侧面写山高的句子——"自非亭午夜分，不见曦月"
3. "清荣峻茂"四个字各写什么？
4. 结尾引用渔歌的作用——侧面渲染秋的凄凉

### 📚 1+X 延伸阅读
- 郦道元《水经注》选读（《三峡》只是其中一篇——感受古代地理学家的文笔）
- 余光中《三峡》（现代作家笔下的三峡，对比古今写法）

### 📖 字词见面记录
- **自**：第二次见面（七上《论语》"有朋自远方来"做"从"→本课"自三峡"做"在"）
- **或**：第二次见面（七上"或"未出现，本课"或王命急宣"做"有时"——古今异义）
- **虽**：第三次见面（七下《孙权劝学》"虽"→本课"虽乘奔御风"做"即使"）
- **于**：第二次见面（七下《狼》"其一犬坐于前"做"在"→本课未见"于"新用法）

### 10 短文二篇

#### 10-1 答谢中书书 / 陶弘景

**作者与文体：** 陶弘景（456-536），南朝齐梁时思想家。书：书信。

**原文与翻译：**

```
山川之美，古来共谈。
→ 山川景色的美丽，自古以来就是文人雅士共同赞叹的。

高峰入云，清流见底。
→ 巍峨的山峰插入云端，清澈的溪流可以看到底。

两岸石壁，五色交辉。
→ 两岸石壁色彩斑斓，交相辉映。

青林翠竹，四时俱备。
→ 青葱的树林翠绿的竹子，四季都有。

晓雾将歇，猿鸟乱鸣；
→ 清晨的薄雾将要消散，猿和鸟此起彼伏地鸣叫；

夕日欲颓，沉鳞竞跃。
→ 夕阳快要落山了，水中潜游的鱼争相跳出水面。

实是欲界之仙都。
→ 这实在是人间的仙境啊。

自康乐以来，未复有能与其奇者。
→ 自从谢灵运以来，再也没有能参与到这奇妙山水（领略其中乐趣）的人了。
```

**重点词：**
- 四时：四季
- 歇：消散
- 颓：坠落（古今异义）
- 沉鳞：潜游在水中的鱼（借代，以"鳞"代鱼）
- 欲界：佛教指人世间
- 仙都：神仙居住的美好世界
- 康乐：谢灵运（袭封康乐公，喜好游览山水）
- 与：参与/置身其中（古今异义）

**结构：**
```
总（山川之美）→分（仰视高峰/俯看清流/平视两岸/四季/晨昏）→总（欲界仙都）
```

#### 10-2 记承天寺夜游 / 苏轼

**作者与背景：** 苏轼（1037-1101），字子瞻，号东坡居士，北宋文学家。写于被贬黄州时期。

**全文逐句详解：**

```
元丰六年十月十二日夜，解衣欲睡，月色入户，欣然起行。
元丰六年：1083年（苏轼被贬黄州的第四年）
户：门（古今异义，今义为"窗户"）
欣然：高兴的样子
起行：起身散步
→ 元丰六年十月十二日夜晚，我解开衣服准备睡觉，月光照进门里，高兴地起来出门散步。
```

```
念无与为乐者，遂至承天寺寻张怀民。
念：考虑/想到
无与为乐者：没有和我共同游乐的人
遂：于是
至：到
→ 想到没有人和我一起游乐，于是到承天寺寻找张怀民。
```

```
怀民亦未寝，相与步于中庭。
亦：也
寝：睡觉
相与：共同/一起
步：散步（名词作动词）
于：在
中庭：院子里
→ 张怀民也没有睡觉，我们一起在院子里散步。
```

```
庭下如积水空明，水中藻、荇交横，盖竹柏影也。
空明：形容水的澄澈
藻荇：水草
交横：交错纵横
盖：原来（连词，表原因）
→ 月光照在庭院里像积满了水一样澄澈透明，水中水草交错纵横，原来是竹子和柏树的影子。
```

**【重点赏析】"庭下如积水空明，水中藻、荇交横，盖竹柏影也。"**
- 手法：比喻（月光→积水，竹柏影→藻荇）
- 正面写月光却不出现"月"字
- 先写错觉（像有水）→再写真相（是竹柏影）
- 意境：澄澈、空灵、高雅

```
何夜无月？何处无竹柏？但少闲人如吾两人者耳。
但：只是
闲人：清闲的人（一语双关）
耳：罢了
→ 哪一个夜晚没有月光？哪个地方没有竹柏？只是缺少像我们两个这样清闲的人罢了。
```

**"闲人"的含义（考点）：**
① 被贬的失意——有职无权
② 闲适的从容——虽遭贬谪仍能欣赏美景
③ 自嘲——既是无奈也是豁达

**主旨：** 在贬谪中保持豁达的人生态度。

**结构：**
```
叙事（起行）→写景（月光/竹柏影）→议论（闲人）
```

### 11 与朱元思书 / 吴均

**作者与文体：** 吴均（469-520），南朝梁文学家。书：书信。

**逐句详解：**

**风烟俱净，天山共色。从流飘荡，任意东西。**
```
风烟：烟雾（风，指景物；烟，指云雾）
俱：都
净：消散/干净（形容词作动词）
共色：同样的颜色
从：顺从/随
流：水流
飘荡：漂流
任意：随心所欲
东西：向东向西（名词作状语）
→ 没有一丝风，烟雾也都消散干净，天空和山峦呈现同样的颜色。我随水流飘荡，任意地东西漂流。
```

**自富阳至桐庐一百许里，奇山异水，天下独绝。**
```
自：从
至：到
许：表示约数，相当于"左右"
奇：奇特
异：奇异
独绝：独一无二
→ 从富阳到桐庐大约一百里左右，奇山异水，天下独一无二。
```
总括句——总写"奇山异水"

**水皆缥碧，千丈见底。游鱼细石，直视无碍。**
```
皆：全/都
缥碧：青白色（缥，青白色）
千丈：夸张写法
直视：直接看下去
无碍：没有障碍
→ 水都是青白色的，千丈之深也能看到底。游动的鱼和细小的石子，一直看下去可以看得清清楚楚。
```
**写水之美：** 清（见底/直视无碍）+ 碧（缥碧）

**急湍甚箭，猛浪若奔。**
```
急湍：急流
甚箭：比箭还快（甚，超过；省略"于"，比）
猛浪：汹涌的波浪
若：好像
奔：飞奔的马（动词作名词）
→ 湍急的水流比箭还要快，凶猛的巨浪像奔腾的骏马。
```
**对比前文：** 前两句静→后两句动。动静结合写水之美。

**夹岸高山，皆生寒树。负势竞上，互相轩邈，争高直指，千百成峰。**
```
夹岸：两岸
寒树：耐寒常绿的树
负：凭借/依仗
势：山势
竞：争着
上：向上（名词作动词）
轩邈：向高处远处伸展（轩，高；邈，远。形容词作动词）
直指：笔直地向上
千百：成百上千
成峰：形成山峰
→ 两岸的高山上，都生长着四季常青的树。它们凭借地势争相向上，互相比高比远，争着向上笔直地冲向天空，形成千百座山峰。
```
**"负势竞上"——拟人，山也有了生命。**

**泉水激石，泠泠作响；好鸟相鸣，嘤嘤成韵。**
```
激：冲击
泠泠：拟声词，形容水声清越
相鸣：互相鸣叫
嘤嘤：拟声词，鸟鸣声
成韵：形成和谐的声音（韵，和谐的声音）
→ 泉水冲击石头，发出泠泠的响声；美丽的鸟彼此和鸣，鸣声嘤嘤，和谐动听。
```
**前文视觉→这一段听觉（泉声/鸟声/蝉声/猿声）——多感官**

**蝉则千转不穷，猿则百叫无绝。**
```
千转：长久不断地叫（转，同"啭"，鸟叫，这里指蝉鸣；千，泛指多）
穷：穷尽
百叫：不停地叫
无绝：不绝（不断）
→ 蝉不停地叫着，猿不停地啼着。
```

**鸢飞戾天者，望峰息心；经纶世务者，窥谷忘反。**
```
鸢飞戾天：老鹰飞到天上（鸢，一种猛禽；戾，至/到达）
——比喻追求功名利禄的人
息心：平息追逐名利的心
经纶世务：治理国家大事（经纶，筹划/治理）
窥：看
谷：山谷
反：同"返"，返回（通假字）
→ 那些像老鹰一样飞到天上追逐名利的人，看到这些山峰也会平息追逐名利的心；那些治理政务的人，看到这些幽美的山谷也会流连忘返。
```
**主旨句——借山水之美劝慰世人淡泊名利**

**横柯上蔽，在昼犹昏；疏条交映，有时见日。**
```
横柯：横斜的树枝（柯，树木的枝干）
上：在上面（名词作状语）
蔽：遮蔽
昼：白天
昏：昏暗
疏条：稀疏的枝条
交映：互相掩映
→ 横斜的树枝在上面遮蔽着，白天也像黄昏一样昏暗；稀疏的枝条互相掩映，有时能见到阳光。
```

**重点词总结：**
| 词 | 义 |
|:--|:--|
| 俱 | 都 |
| 共色 | 同样的颜色 |
| 许 | 大约 |
| 缥碧 | 青白色 |
| 甚箭 | 比箭还快 |
| 奔 | 飞奔的马 |
| 负 | 凭借 |
| 竞 | 争着 |
| 轩邈 | 向高处远处伸展 |
| 泠泠 | 清脆的流水声 |
| 转 | 同"啭" |
| 穷 | 尽 |
| 戾 | 至 |
| 息 | 平息 |
| 经纶 | 治理 |
| 反 | 同"返" |
| 柯 | 树枝 |
| 蔽 | 遮蔽 |

**结构与写法：**
```
总（奇山异水/天下独绝）
  ├── 异水：静（清/碧）→动（急/猛）
  └── 奇山：形（争高直指）→声（泉/鸟/蝉/猿）→情（息心/忘反）
```

**野望 / 王绩**
东皋薄暮望，徙倚欲何依。树树皆秋色，山山唯落晖。
牧人驱犊返，猎马带禽归。相顾无相识，长歌怀采薇。
→ 首联叙事（傍晚独望）→颔联颈联写景（秋色/落晖/牧归/猎归）→尾联抒情（孤独/怀念隐士）

**黄鹤楼 / 崔颢**
昔人已乘黄鹤去，此地空余黄鹤楼。黄鹤一去不复返，白云千载空悠悠。
晴川历历汉阳树，芳草萋萋鹦鹉洲。日暮乡关何处是？烟波江上使人愁。
→ 前四句怀古（虚，空余黄鹤的惆怅）→后四句写景抒情（实，乡愁）

**使至塞上 / 王维**
单车欲问边，属国过居延。征蓬出汉塞，归雁入胡天。
大漠孤烟直，长河落日圆。萧关逢候骑，都护在燕然。
→ "大漠孤烟直，长河落日圆"——千古名句。"直"写出烟的挺拔，"圆"写出落日之苍茫

**渡荆门送别 / 李白**
渡远荆门外，来从楚国游。山随平野尽，江入大荒流。
月下飞天镜，云生结海楼。仍怜故乡水，万里送行舟。
→ "山随平野尽，江入大荒流"——从蜀地到楚地，地势的转换

**钱塘湖春行 / 白居易**
孤山寺北贾亭西，水面初平云脚低。几处早莺争暖树，谁家新燕啄春泥。
乱花渐欲迷人眼，浅草才能没马蹄。最爱湖东行不足，绿杨阴里白沙堤。
→ 行踪：孤山寺→贾亭→湖东→白沙堤
"争暖树""啄春泥""渐欲""才能"——扣住"早"字写初春

## 第四单元 · 散文（情感哲思）

> **为什么要学这个单元？**
> 你有没有在某个瞬间，突然被一个画面击中——比如爸爸弯腰系鞋带的样子，或者妈妈转身时的一个侧影？这个单元的散文，就是从这些"小小的画面"开始的。朱自清写了父亲的背影，茅盾看了白杨树，汪曾祺想念昆明的雨——他们写的都不是惊天动地的大事，但每一篇都能打动你。为什么呢？因为这个单元的作家都掌握了一个秘密：**把最普通的感受，写出最不普通的文字。**
>
> > **📍 本单元阅读地图：**
> > 这个单元的文章都跟"情感"有关，但表达方式各不相同。建议先读《背影》——最经典的一篇，需要慢慢读，尤其是父亲爬月台那段；再读《白杨礼赞》——学会"托物言志"是怎么回事；然后读《散文两篇》——议论性的散文，比较"干"，可以读快一点；最后读《昆明的雨》——轻松收尾。
> > 读完后问问自己：同样是"感物抒怀"，四篇散文抒的情一样吗？

### 13 背影 / 朱自清

**结构：**
```
第一部分（第1段）：最不能忘记的是父亲的背影——点题
第二部分（第2-3段）：祖母去世→父亲失业→回家奔丧——背景
第三部分（第4-5段）：南京分别（父亲送"我"上火车/叮嘱/托茶房照应）
第四部分（第6段）：父亲爬月台买橘子——**重点**
第五部分（第7段）：读父亲来信→流泪——思念
```

**四次背影（考点）：**
```
① 惦念背影——开头"我最不能忘记的是他的背影"
② 刻画背影——父亲爬月台买橘子
③ 惜别背影——父亲混入人群
④ 思念背影——读父亲来信
```

**四次流泪：**
① 看祖母去世/回家（悲伤）
② 看父亲爬月台（感动）
③ 与父亲分别（不舍）
④ 读父亲来信（思念）

**父亲爬月台的动词分析（重点）：**
"他用两手攀着上面，两脚再向上缩；他肥胖的身子向左微倾，显出努力的样子。"
- 攀/缩/倾——三个动词写爬月台的艰难
- "蹒跚"——走路的缓慢摇晃
- "肥胖"——更显吃力

**主旨：** 父爱深沉，含蓄而感人。

### 📚 1+X 延伸阅读
- 朱自清《荷塘月色》（同一位作家，另一种风格——从朴素深沉到清丽典雅）

## 第五单元 · 说明文

> **为什么要学这个单元？**
> 你肯定有过这样的经历——别人问你"这个东西是什么样的"，你说了半天人家还是不明白。说明文就是帮你解决这个问题的：怎么把一个事物说清楚、说准确。茅以升讲石拱桥，先讲特点再举例子；叶圣陶说苏州园林，先给总印象再分点细说；法布尔写蝉，从卵到成虫一路讲下来。这个单元不教你怎么"写得美"，而是教你怎么"写得清楚"。**清楚，有时候比"美"更厉害。**
>
> > **📍 本单元阅读地图：**
> > 这个单元是说明文专场——跟前面的散文完全不同的文体。建议先读《中国石拱桥》——最标准的说明文，先熟悉"说明方法"；再读《苏州园林》——也是说明文，但更有文学味；《蝉》放最后——法布尔的科普文章，像在听一个老爷爷讲昆虫的故事，最轻松。
> > 读完想一想：说明文要说"清楚"，但每篇说清楚的方式不一样——哪里不一样？

### 17 中国石拱桥 / 茅以升

**说明对象：** 中国石拱桥
**说明文类型：** 事物说明文

**结构：** 概括（石拱桥的特点/形式优美/结构坚固/历史悠久）→具体（赵州桥/卢沟桥）→成就原因→发展

**说明方法：**
| 句子 | 说明方法 |
|:----|:--------|
| 石拱桥的桥洞成弧形，就像虹 | 打比方 |
| 赵州桥长50.82米，两端宽9.6米 | 列数字 |
| 永定河发水时来势很猛……这座桥却极少出事 | 举例子 |
| 我国的石拱桥几乎到处都有……其中最著名的当推河北赵县的赵州桥 | 举例子 |
| 石拱桥的桥洞成弧形，就像虹 | 引用（神话） |

**说明语言（考点）：**
"大约""可能""几乎"——体现了说明文语言的准确性

## 第六单元 · 古诗文（品格与志向）

> **为什么要学这个单元？**
> 这个单元的人和事，都和我们今天的生活有点"远"——大丈夫、愚公、周亚夫、陶渊明、杜甫、李清照……他们生活在几百上千年前，但他们面对的问题，我们今天依然要面对：什么是真正的勇敢？什么是坚持？什么是人格的尊严？孟子说大丈夫要"富贵不能淫，贫贱不能移，威武不能屈"，愚公说"子子孙孙无穷匮也"，周亚夫面对皇帝都不肯下跪——这些人未必有权有势，但他们都有一种东西：**人格的力量。** 这个单元，就是让你认识这些"有骨头"的人。
>
> > **📍 本单元阅读地图：**
> > 这个单元四篇文言文+五首诗词，是八年级最"重"的单元。建议先读《孟子三章》——议论性的文言文，需要一边读一边想；再读《愚公移山》——故事性强，好读；然后读《周亚夫军细柳》——历史故事，读起来像看小电影；诗词五首可以穿插在读文言文的间隙里读，换换脑子。
> > 读完后问问自己：孟子讲道理、愚公讲故事、周亚夫做给你看——三种说服人的方式，哪种最打动人？

### 21 《孟子》二章

#### 富贵不能淫

**景春曰："公孙衍、张仪岂不诚大丈夫哉？一怒而诸侯惧，安居而天下熄。"**
```
岂不诚大丈夫哉：难道不真正是大丈夫吗（反问）
诚：真正
一：一旦
安：安定
熄：战火熄灭/太平
```

**孟子曰："是焉得为大丈夫乎？** 
```
是：这
焉得：怎么能/哪里算得上
```

**"子未学礼乎？丈夫之冠也，父命之；女子之嫁也，母命之，往送之门，戒之曰：'往之女家，必敬必戒，无违夫子！'"**
```
冠：行冠礼（名词作动词）
命：训导/教诲
往：去/到
女家：你的夫家（女，同"汝"，你）
戒：谨慎
违：违背
夫子：丈夫
```

**"以顺为正者，妾妇之道也。"**
```
顺：顺从
正：标准/原则
→ 把顺从作为标准，是妇人女子的道理。
```

**"居天下之广居，立天下之正位，行天下之大道。得志，与民由之；不得志，独行其道。富贵不能淫，贫贱不能移，威武不能屈。此之谓大丈夫。"**
```
广居/正位/大道：仁/礼/义（儒家核心）
得志：实现志向
由：遵循
独行其道：独自走自己的道路
淫：使……迷惑（使动用法）
移：使……改变（使动用法）
屈：使……屈服（使动用法）
→ 大丈夫：富贵不能使他迷惑，贫贱不能使他动摇，威武不能使他屈服。
```

#### 生于忧患，死于安乐

**"故天将降大任于是人也，必先苦其心志，劳其筋骨，饿其体肤，空乏其身，行拂乱其所为，所以动心忍性，曾益其所不能。"**
```
故：所以
降：下达/赋予
大任：重大的使命
是：这
苦/劳/饿/空乏：使动用法（使……受苦/劳累/受饿/穷困）
拂乱：扰乱（拂，违背）
所以：用来（古今异义）
动心忍性：使内心受到震撼/使性格变得坚韧（使动用法）
曾：同"增"
```

**"人恒过，然后能改；困于心，衡于虑，而后作；征于色，发于声，而后喻。"**
```
恒：经常
过：犯过错（名词作动词）
困：困扰
衡：同"横"，梗塞/不顺
作：奋起
征：表现
色：脸色
发：流露
喻：了解
```

**"入则无法家拂士，出则无敌国外患者，国恒亡。然后知生于忧患而死于安乐也。"**
```
入：在国内
法家：坚持法度的大臣
拂士：辅佐君主的贤士（拂，同"弼"，辅佐）
出：在国外
敌国：实力相当的国家
外患：外来的祸患
恒：往往/常常
→ 忧愁祸患使人谋求生存，安逸享乐导致灭亡。

### 📚 1+X 延伸阅读

- **于**：第二次见面（本课未出现新用法）
- **而**：第三次见面（本课"一怒而诸侯惧"做"就/便"）

### 22 愚公移山 / 《列子》

**逐句精讲重点：**

**"太行、王屋二山，方七百里，高万仞。"**
```
方：方圆（古今异义）
仞：古代长度单位，约合七八尺
→ 夸张手法，写出山的高大，反衬移山之难。
```

**"年且九十"**
```
且：将近
```

**"以君之力，曾不能损魁父之丘"**
```
曾：用在"不"前加强否定语气，连……都……
损：削减
→ 妻子（献疑）不是反对，而是关心
```

**"甚矣，汝之不惠！"**
```
倒装句——"汝之不惠甚矣"（主谓倒装）
惠：同"慧"，聪明
```

**"汝心之固，固不可彻"**
```
心：思想
固：顽固
彻：通达
```

**"子子孙孙无穷匮也，而山不加增，何苦而不平？"**
```
穷匮：穷尽
加增：增加
何苦：何愁/哪怕
→ 愚公的核心论据
```

**河曲智叟亡以应。**
```
亡：同"无"
亡以应：没有话来回答
```

**"自此，冀之南，汉之阴，无陇断焉。"**
```
陇断：同"垄断"，山冈阻隔
→ 结局：山被天神搬走了——神话结尾，体现了古代劳动人民的理想和愿望
```

**主旨：** 知难而进、坚持不懈、人定胜天

### 📖 字词见面记录 - 愚公移山
- **之**：第六次见面（本课大量使用"之"——"汝心之固""魁父之丘"等——已在各用法中熟练掌握）

### 25 诗词五首

**饮酒（其五）/ 陶渊明**
结庐在人境，而无车马喧。问君何能尔？心远地自偏。
采菊东篱下，悠然见南山。此中有真意，欲辨已忘言。
→ "采菊东篱下，悠然见南山"——物我两忘、天人合一的境界
"心远地自偏"——精神自由不受环境干扰

**春望 / 杜甫**
国破山河在，城春草木深。感时花溅泪，恨别鸟惊心。
烽火连三月，家书抵万金。白头搔更短，浑欲不胜簪。
→ 以乐景写哀情（花/鸟本是美景，却因国破而令人悲痛）
"家书抵万金"——战乱中家书的珍贵

**雁门太守行 / 李贺**
黑云压城城欲摧，甲光向日金鳞开。角声满天秋色里，塞上燕脂凝夜紫。
半卷红旗临易水，霜重鼓寒声不起。报君黄金台上意，提携玉龙为君死。
→ "黑云压城"——敌军攻城的气势（比喻）
"黄金台"——用典，燕昭王筑台招贤

**赤壁 / 杜牧**
折戟沉沙铁未销，自将磨洗认前朝。东风不与周郎便，铜雀春深锁二乔。
→ "东风"——指赤壁之战的关键（借代周瑜的成功）
以小见大（"二乔"的命运→国家命运）

**渔家傲 / 李清照（天接云涛连晓雾）**
天接云涛连晓雾，星河欲转千帆舞。仿佛梦魂归帝所，闻天语，殷勤问我归何处。
我报路长嗟日暮，学诗谩有惊人句。九万里风鹏正举。风休住，蓬舟吹取三山去。
→ 这首词风格豪放，不同于李清照婉约词风
"九万里风鹏正举"——用《庄子·逍遥游》大鹏的典故，表达对自由的追求
```
