## 1 邓稼先 / 杨振宁

### 作者与文体
杨振宁，美籍华裔物理学家，诺贝尔物理学奖得主。邓稼先是中国两弹元勋。
文体：人物传记。

### 结构
```
第一部分：从"任人宰割"到"站起来了"——历史背景
第二部分："两弹"元勋——邓稼先的生平贡献
第三部分：邓稼先与奥本海默——对比（民族性格/为人处世/贡献）
第四部分：邓稼先在"文革"中的抉择
第五部分：邓稼先的远见（"不要让人家把我们落得太远"）
第六部分：永恒的骄傲——诗歌《中国男儿》赞邓稼先
```

### 对比手法
| 邓稼先 | 奥本海默 |
|:------|:--------|
| 中国原子弹之父 | 美国原子弹之父 |
| 忠厚平实、淳朴 | 锋芒毕露 |
| 默默奉献、不求名利 | 性格张扬 |
| 团队式合作 | 个人式突出 |

### 人物形象
邓稼先：忠诚、朴实、无私奉献、鞠躬尽瘁、有远见

### 语言特色
- 采用小标题形式，结构清晰
- 叙述、议论、抒情相结合
- 引用古诗（《中国男儿》）增强感染力

## 2 说和做——记闻一多先生言行片段 / 臧克家

### 作者与文体
臧克家，现代诗人。闻一多，诗人、学者、民主战士。

### 结构
```
第一部分（第1-7段）：作为学者的"做了再说"——潜心研究
  ├── 写了《唐诗杂论》《楚辞校补》《古典新义》
  └── 足不下楼、目不窥园、专心治学
第二部分（第8-18段）：作为革命家的"说了就做"
  ├── 拍案而起（李公朴被暗杀后）
  ├── 敢说敢做、视死如归
  └── 最后一次演讲
第三部分（第19-20段）：总结——口的巨人、行的高标
```

### 名句
"做了再说，做了不说"——作为学者
"说了就做，言论与行动完全一致"——作为革命家
"他，是口的巨人。他，是行的高标。"

### 细节分析
"目不窥园，足不下楼"——专心致志
"一个又一个大的四方竹纸本子，写满了密密麻麻的小楷"——治学严谨
"昂首挺胸，长须飘飘"——革命者的气概

## 3 回忆鲁迅先生 / 萧红

### 作者与文体
萧红，原名张乃莹，现代女作家。回忆性散文。

### 特点
不同于一般纪念文章写鲁迅的"伟大"，而是通过日常生活细节写鲁迅的平凡和亲切。
- 鲁迅笑的样子（"明朗的笑"）
- 走路姿势（"刚抓起帽子来往头上一扣"）
- 工作到深夜等

### 写作特色
以小见大——日常琐事写出伟人的另一面（也有人情味、也爱吃、也爱笑）

## 4 孙权劝学 / 《资治通鉴》

### 作者与来源
《资治通鉴》是北宋司马光主持编纂的一部编年体通史。

### 逐句详解

**初，权谓吕蒙曰："卿今当涂掌事，不可不学！"**
```
初：当初（追述往事）
权：孙权（三国时吴国建立者）
谓……曰：对……说
吕蒙：孙权手下大将
卿：你（古代君对臣或朋友间的爱称）
当涂：当道、当权
掌事：掌管事务
不可不学：双重否定，强调必须学
```

**蒙辞以军中多务。**
```
蒙：吕蒙
辞：推托
以：用/拿（介词）
军中：军队中
多务：事务繁多
→ 吕蒙用军中事务繁多来推托。（状语后置句，正常语序：蒙以军中多务辞）
```

**权曰："孤岂欲卿治经为博士邪！但当涉猎，见往事耳。"**
```
孤：古代王侯自称
岂……邪：难道……吗（反问句式，邪通"耶"）
治经：研究儒家经典
博士：古代专掌经学传授的学官（古今异义）
但：只是（古今异义，今义为转折）
涉猎：粗略地阅读
见：了解
往事：历史（古今异义）
耳：罢了
```

**"卿言多务，孰若孤？孤常读书，自以为大有所益。"**
```
孰若：哪里比得上
自：自己
以：认为
所益：好处
```

**蒙乃始就学。**
```
乃：于是、就
始：开始
就学：从事学习、开始学习
```

**及鲁肃过寻阳，与蒙论议，大惊曰："卿今者才略，非复吴下阿蒙！"**
```
及：到了……的时候
过：经过
论议：谈论、议论
今者：如今、现在
才略：才干和谋略
非复：不再是
吴下：指吴地
阿蒙：吕蒙的昵称（阿，前缀）
```

**蒙曰："士别三日，即更刮目相待，大兄何见事之晚乎！"**
```
士：读书人
三日：形容时间短
即：就
更：重新
刮目相待：用新的眼光来看待（刮，擦拭）
大兄：长兄，这里是对朋友辈的敬称
何……之……：为什么……这么……（感叹句式）
见事：了解事物/认清事物
晚：迟
乎：语气词，相当于"呢"
```

**肃遂拜蒙母，结友而别。**
```
遂：于是
拜：拜见
而：连词，表顺承
别：告别
```

### 主旨
孙权劝吕蒙学习→吕蒙学有所成→鲁肃刮目相看
告诉我们要多看多学，开卷有益。

### 考查重点
1. "刮目相待""吴下阿蒙"两个成语的出处和含义
2. 双重否定"不可不学"的表达效果
3. 五个反问句的表达效果（强调、劝谏有说服力）

## 5 黄河颂 / 光未然

### 文体
组诗《黄河大合唱》的第二乐章，歌词。

### 结构
```
朗诵词（铺垫）→ 歌词主体
  ├── 望黄河（"我站在高山之巅……"）——写景
  └── 颂黄河（"啊！黄河！……"）——抒情
    ├── 你是中华民族的摇篮
    ├── 你是五千年的古国文化
    └── 你像巨人一样保卫中华民族
```

### 手法
比喻（黄河=摇篮/巨人）、反复（"啊！黄河！"）、拟人、排比

### 主旨
赞美黄河的伟大坚强，激发民族自豪感和爱国热情。

## 6 最后一课 / 都德

### 作者与背景
都德（1840-1897），法国小说家。背景：普法战争法国战败，阿尔萨斯和洛林被割让给普鲁士。

### 情节
小弗郎士上学迟到→得知这是最后一节法语课→韩麦尔先生上完最后一课→写下"法兰西万岁"

### 人物分析

**小弗郎士（"我"）的心理变化：**
- 怕迟到想逃学 → 懊悔以前没好好学习 → 理解了母语的重要性 → 变得爱国

**韩麦尔先生形象：**
- 爱国——穿了只有特殊日子才穿的礼服
- 激动——最后一课充满激情
- 悲愤——下课时的"脸色惨白"，写不出字来
- 奉献——在这里教了40年书

### 重点句子
"法语是世界上最美丽的语言"
"亡了国当了奴隶的人民，只要牢牢记住他们的语言，就好像拿着一把打开监狱大门的钥匙"
——语言＝民族的根＝监狱大门的钥匙

### 细节描写
- 小弗郎士进教室时的安静（与平日不同）
- 韩麦尔先生的服装（绿色礼服）
- 学生的纪律出奇的好
- 后排坐着村里的老人
- 结尾：韩麦尔先生说不出话，只在黑板上写了"Vive la France！"（法兰西万岁）

## 7 土地的誓言 / 端木蕻良

### 作者与背景
端木蕻良（1912-1996），现代作家。"九一八"事变后东北沦陷，表达对故乡的思念和誓死收复的决心。

### 手法
- 呼告（"土地，原野，我的家乡……"）
- 排比（"当我……当我……当我……"）
- 拟人（土地=母亲）
- 景物铺陈（白桦林、马群、大豆、高粱——东北特有风物）

### 主语变换（考点）
人称从"她"→"你"→"你"（更直接、更强烈）

## 8 木兰诗

### 文体
北朝民歌，长篇叙事诗。属于乐府诗（收录于《乐府诗集》）。

### 结构
```
一、决定代父从军
二、踏上征途（"旦辞爷娘去……但闻黄河流水鸣溅溅"）
三、十年征战（"将军百战死，壮士十年归"）
四、辞官还乡（"愿驰千里足，送儿还故乡"）
五、重着女儿装（"当窗理云鬓，对镜帖花黄"）
六、伙伴惊忙（"同行十二年，不知木兰是女郎"）
七、双兔喻（"双兔傍地走，安能辨我是雄雌"）
```

### 逐句详解重点

**"不闻爷娘唤女声，但闻黄河流水鸣溅溅"**
- 对比——昔日的亲情温暖 vs 今日的战场悲凉
- 对仗——"不闻"对"但闻"，"爷娘唤女"对"黄河流水"

**"万里赴戎机，关山度若飞。朔气传金柝，寒光照铁衣。"**
- 万里——夸张（征程遥远）
- 戎机——战争
- 度——跨越
- 朔气——北方的寒气
- 金柝——古时军中守夜打更用的器具
- 寒光——清冷的月光
- 铁衣——铠甲
- 简练的笔法写出十年征战

**"将军百战死，壮士十年归"**——互文
- 不是将军死了壮士回来了
- 是将军和壮士都经历了百战死伤，十年后才回来
- 互文见义

**"开我东阁门，坐我西阁床。脱我战时袍，著我旧时裳。当窗理云鬓，对镜帖花黄。"**
- 一连串动作——写出木兰回家后的喜悦
- 铺陈手法

**"雄兔脚扑朔，雌兔眼迷离；双兔傍地走，安能辨我是雄雌？"**
- 以兔为喻——木兰是男是女呢？（巧妙回答同伴的疑问）
- 扑朔：爬搔
- 迷离：眯着眼
- 傍地走：贴着地面跑
- 安能：怎能（反问）

### 木兰形象
孝顺（代父从军）、勇敢（奔赴战场）、淡泊名利（辞官）→ 女儿心英雄胆

### 修辞手法
- 互文：将军百战死，壮士十年归 / 开我东阁门，坐我西阁床
- 对仗：朔气传金柝，寒光照铁衣
- 顶真：军书十二卷，卷卷有爷名
- 比喻：双兔傍地走
- 夸张：万里赴戎机

### 详略安排（考点）
- 从军原因（详写）——突出木兰孝顺
- 征战过程（略写"十年"只用四句）——不渲染战争残酷
- 辞官回乡（详写）——突出淡泊名利
- 重着女装（详写）——突出女儿情态

## 9 阿长与《山海经》 / 鲁迅

选自《朝花夕拾》。

### 结构
```
第一部分（第1-17段）抑——阿长的缺点
  ├── 名字由来
  ├── 切切察察（说闲话）
  ├── 睡觉摆"大"字（没有教养）
  ├── 逼我吃福橘（迷信）
  └── 讲长毛的故事（无知自大）
第二部分（第18-27段）扬——阿长买《山海经》
  ├── 哥儿，有画儿的"三哼经"
  ├── 震悚——从未有过的敬意
  └── 别人不肯做或不能做的她却做到了
第三部分（第28-30段）怀念——仁厚黑暗的地母呵，愿在你怀里永安她的魂灵
```

### 欲扬先抑
前面写阿长的各种缺点（抑），后面写她买《山海经》的伟大（扬），两相对比更突出阿长朴实善良的一面。

### 人物形象
粗俗、迷信、没文化——但善良、朴实、真心爱鲁迅

### 重点句子
"我似乎遇着了一个霹雳，全体都震悚起来……"
——震惊的原因：别人不肯做或不能做的，阿长做到了（一个没读过书的人）。

## 10 老王 / 杨绛

### 作者与背景
杨绛（1911-2016），作家、翻译家。选自《杨绛散文》。

### 情节
老王（三轮车夫）送"我"看病→老王送冰→老王送鸡蛋和香油→老王死后"我"的愧疚

### 人物形象

**老王：**
- 穷苦（破三轮、只有一只眼）
- 善良（送冰不肯要钱、送人看病不要钱）
- 孤独（没亲人）
- 知恩图报（临死前送香油和鸡蛋）

**"我"：**
- 善良（关心老王）
- 但给了钱后感到"愧怍"——因为老王把"我"当亲人，"我"却只是用钱回报

### 名句
"那是一个幸运的人对一个不幸者的愧怍。"
——全文主旨，"愧怍"即惭愧。

## 12 卖油翁 / 欧阳修

### 作者与来源
欧阳修（1007-1072），北宋文学家，"唐宋八大家"之一。选自《归田录》。

### 逐句详解

**陈康肃公善射，当世无双，公亦以此自矜。尝射于家圃。**
```
善射：善于射箭
当世：当代
亦：也
以：凭借
自矜：自夸（矜，夸耀）
尝：曾经
于：在
家圃：家里（射箭的）场地
```

**有卖油翁释担而立，睨之久而不去。见其发矢十中八九，但微颔之。**
```
释担：放下担子
而：连词，表顺承
睨之：斜着眼看他（"睨"是斜眼看，表示不在意的样子）
久：很久
去：离开（古今异义）
发矢：射箭
中：射中
但：只是（古今异义）
微：微微
颔：点头（名词作动词）
之：代词（指射箭这件事）
```

**康肃问曰："汝亦知射乎？吾射不亦精乎？"**
```
汝：你
知：懂得
射：射箭（名词）
不亦……乎：难道不……吗（反问句式，表强调）
精：精湛
```

**翁曰："无他，但手熟尔。"**
```
无他：没有别的（奥妙）
但：只是
熟：熟练
尔：同"耳"，罢了（通假字）
```

**康肃忿然曰："尔安敢轻吾射！"**
```
忿然：气愤的样子
尔：你
安：怎么（反问副词）
轻：轻视（形容词作动词）
射：射箭的本领（名词）
```

**翁曰："以我酌油知之。"**
```
以：凭
酌油：倒油
之：代词（这个道理）
```

**乃取一葫芦置于地，以钱覆其口，徐以杓酌油沥之，自钱孔入，而钱不湿。**
```
乃：于是
取：拿
置：放
于：在
以：用
钱：铜钱
覆：盖
其：它的
徐：慢慢地
以：用
杓：同"勺"
沥：下滴
自：从
孔：孔眼
而：连词，表转折
湿：沾湿
```

**因曰："我亦无他，惟手熟尔。"**
```
因：于是
亦：也
惟：只是
```

**康肃笑而遣之。**
```
笑：笑着（心服口服）
而：连词，表修饰
遣：打发
之：代词（卖油翁）
```

### 主旨
熟能生巧——技艺再高也离不开熟练。

### 人物形象
- 陈尧咨：骄傲自矜→最后"笑而遣之"（知错能改）
- 卖油翁：淡然自信、不卑不亢、用行动说话

## 13 叶圣陶先生二三事 / 张中行

### 结构
```
第一部分：总写叶圣陶的品德
第二部分：待人厚——修改文章、送客等
第三部分：律己严——追求文字的准确完美
第四部分：崇高评价
```

## 14 驿路梨花 / 彭荆风

### 情节
"我"和老余在山中投宿→小茅屋里有人提供食宿→以为是瑶族老人→老人说是哈尼小姑娘→小姑娘说"学习雷锋精神"

### "梨花"的含义
① 自然界的梨花（景物）
② 哈尼小姑娘梨花

## 15 短文两篇

### 15-1 陋室铭 / 刘禹锡

### 作者与文体
刘禹锡（772-842），唐代文学家，"诗豪"。铭：古代刻在器物上用来警戒自己或称述功德的文字，后来成为一种文体。

### 逐句详解

**山不在高，有仙则名。水不在深，有龙则灵。**
```
在：在于
有仙：有仙人
则：就
名：出名（名词作动词）
龙：古代传说中能兴云致雨的神异动物
灵：有灵气（形容词作动词）
```
修辞：比兴（先写山水起兴，引出陋室）

**斯是陋室，惟吾德馨。**
```
斯：这
惟：只
吾：我
德馨：品德高尚（馨，能散布很远的香气，这里指品德高尚）
→ 主旨句：房子虽简陋，但主人的品德使它芬芳。
```

**苔痕上阶绿，草色入帘青。**
```
上：长上（名词作动词）
阶：台阶
入：映入
帘：门帘
→ 环境描写：陋室台阶长满青苔，草色映入帘中。→ 幽静雅致
```
对仗工整："苔痕"对"草色"，"上阶"对"入帘"，"绿"对"青"

**谈笑有鸿儒，往来无白丁。**
```
鸿儒：博学的人（鸿，大；儒，有学问的人）
白丁：平民，指没有功名的人（"白丁"不等于没文化，指没有官职的人）
→ 交往之雅：来往的都是饱学之士
```

**可以调素琴，阅金经。**
```
调：弹奏
素琴：不加装饰的琴
金经：佛经（古代用泥金书写的佛经）
→ 高雅的生活情趣
```

**无丝竹之乱耳，无案牍之劳形。**
```
丝竹：弦乐器+管乐器，这里指世俗的音乐（借代）
乱：使……扰乱（使动用法）
案牍：官府的公文（借代）
劳：使……劳累（使动用法）
形：身体
→ 没有世俗的嘈杂，没有官场的烦扰
```

**南阳诸葛庐，西蜀子云亭。**
```
诸葛：诸葛亮，隐居南阳时住茅庐
子云：扬雄，字子云，西汉辞赋家
→ 用典：把自己的陋室比作诸葛庐和子云亭
```

**孔子云：何陋之有？**
```
引用孔子的话——"君子居之，何陋之有？"
何陋之有：有什么简陋的？（宾语前置句，即"有何陋"）
→ 反问收束，呼应开头"惟吾德馨"
```

### 结构
```
起兴（山/水）→ 主旨（德馨）→ 环境（苔痕/草色）→ 交往（鸿儒）→ 情趣（素琴/金经）→ 反衬（无丝竹/案牍）→ 用典（诸葛/子云）→ 反问（何陋之有）
```

### 主旨
表达作者高洁傲岸的情操和安贫乐道的情趣。

### 15-2 爱莲说 / 周敦颐

### 作者与文体
周敦颐（1017-1073），北宋哲学家，理学奠基人。说：一种议论性的文体。

### 逐句详解

**水陆草木之花，可爱者甚蕃。**
```
水陆：水中和陆地上
之：的
可爱：值得喜爱
甚：很、非常
蕃：多
```

**晋陶渊明独爱菊。自李唐来，世人甚爱牡丹。**
```
独：唯独
自：从
李唐：唐朝（皇帝姓李）
世人：世人
甚：非常
```
对比：陶渊明爱菊（隐逸）→ 世人爱牡丹（富贵）→ "予独爱莲……"（君子）

**予独爱莲之出淤泥而不染，濯清涟而不妖**
```
予：我（古今异义）
之：取消句子独立性（不译）
出：生长
于：从（省略）
淤泥：污泥
而：连词，表转折
染：沾染（污秽）
濯：洗
清涟：清水
妖：艳丽
→ 从淤泥里长出来却不被污染，在清水里洗涤却不显得妖媚
```

**中通外直，不蔓不枝**
```
中：茎内
通：贯通
外：外部
直：挺直
蔓：生藤蔓（名词作动词）
枝：长枝节（名词作动词）
→ 莲茎中间贯通外部挺直，不牵牵连连不枝枝节节
```

**香远益清，亭亭净植**
```
香：香气
远：远播（形容词作动词）
益：更加
清：清幽
亭亭：耸立的样子
净：洁净
植：竖立（古今异义）
→ 香气远播更加清幽，洁净地竖立在那里
```

**可远观而不可亵玩焉。**
```
可：可以
远观：远远地观赏
而：连词，表转折
亵玩：靠近玩弄（亵，亲近而不庄重）
焉：语气词
→ 可以在远处观赏却不能靠近去玩弄
```

**予谓菊，花之隐逸者也；牡丹，花之富贵者也；莲，花之君子者也。**
```
谓：认为
隐逸：隐居避世的人
富贵：富贵的人
君子：品德高尚的人
→ 用三个判断句"……者也"
```
**写作目的：** 以花喻人

**菊之爱，陶后鲜有闻。莲之爱，同予者何人？牡丹之爱，宜乎众矣！**
```
之：结构助词，的
鲜：少（古今异义）
闻：听说
同：相同/和……一样
予：我
宜：应当
众：多
→ 对菊花的喜爱，陶渊明以后很少听到了。对莲花的喜爱，像我一样的还有谁呢？对牡丹的喜爱，当然很多了。
```

### 核心考点

**莲的君子形象（莲→君子对应关系）：**
| 莲的特点 | 君子的品质 |
|:--------|:----------|
| 出淤泥而不染 | 不与世俗同流合污 |
| 濯清涟而不妖 | 质朴自然不献媚 |
| 中通外直 | 内心通达行为正直 |
| 不蔓不枝 | 不攀附权贵 |
| 香远益清 | 美名远扬 |
| 亭亭净植 | 品行高洁 |
| 可远观不可亵玩 | 庄重凛然不可侵犯 |

**三种花三种人：**
| 花 | 象征 | 作者态度 |
|:--|:----|:-------- |
| 菊 | 隐逸者 | 惋惜（鲜有闻） |
| 牡丹 | 富贵者 | 鄙视（宜乎众矣） |
| 莲 | 君子 | 赞美（予独爱） |

## 24 河中石兽 / 纪昀

### 作者
纪昀（1724-1805），字晓岚，清代学者。主持编纂《四库全书》。选自《阅微草堂笔记》。

### 逐句详解

**沧州南一寺临河干，山门圮于河，二石兽并沉焉。**
```
临：靠近
河干：河岸（干，岸边）
山门：寺庙的大门
圮：倒塌
于：在/到
并：一起
沉：沉没
焉：兼词，"于之"（在那里）
```

**阅十余岁，僧募金重修，求二石兽于水中，竟不可得。**
```
阅：经过/经历（古今异义，今义为"阅读"）
岁：年
募金：募集钱财
求：寻找
竟：最终
得：找到
```

**以为顺流下矣，棹数小舟，曳铁钯，寻十余里无迹。**
```
以为：认为
下：往下游（名词作动词，往下游去）
棹：划船（名词作动词）
曳：拖
铁钯：铁制耙子
迹：踪迹
```

**一讲学家设帐寺中，闻之笑曰：**
```
讲学家：学者
设帐：设馆教书
```

**"尔辈不能究物理，是非木杮，岂能为暴涨携之去？"**
```
尔辈：你们这些人
究：推究/研究
物理：事物的道理/规律（古今异义）
是：这（古今异义）
木杮：木片
岂……为……：怎么能被（反问）
暴涨：暴涨的洪水（形容词作名词）
携：带
去：离开
→ 你们这些人不能推究事物的道理。这不是木片，怎么能被洪水冲走呢？
```

**"乃石性坚重，沙性松浮，湮于沙上，渐沉渐深耳。"**
```
乃：是（副词）
坚重：坚硬沉重
松浮：松散轻浮
湮：埋没
于：在
耳：罢了
→ 石头特性坚硬沉重，沙子特性松散轻浮，石兽埋没在沙上，越沉越深罢了。
```

**"沿河求之，不亦颠乎？"众服为确论。**
```
沿：顺
颠：颠倒/荒唐
服：佩服
确论：精当的言论
→ 沿着河去找，难道不荒唐吗？大家佩服认为是正确的论断。
```

**一老河兵闻之，又笑曰：**
```
河兵：巡河/治河的士兵
→ 一个老河兵听说了，又笑着说。
```

**"凡河中失石，当求之于上游。"**
```
凡：凡是
失石：丢失的石兽
当：应当
求：寻找
于：到
→ 凡是河中丢失的石兽，应当到上游去找。
```

**"盖石性坚重，沙性松浮，水不能冲石，其反激之力，必于石下迎水处啮沙为坎穴。"**
```
盖：原来（表原因）
其：它的
反激之力：反冲的力量
于：在
迎水处：迎着水流的地方
啮：咬/冲刷（古今异义）
为：成为
坎穴：坑穴
```

**"渐激渐深，至石之半，石必倒掷坎穴中。"**
```
至：到
之：的
半：一半
倒掷：倾倒
```

**"如是再啮，石又再转。转转不已，遂反溯流逆上矣。"**
```
如：像
是：这样（古今异义）
已：停止
遂：于是/就
反溯流：反而逆流
逆上：向上游
→ 像这样再冲刷，石头又再翻转。翻转不停，于是就反而逆流到上游去了。
```

**"求之下流，固颠；求之地中，不更颠乎？"**
```
之：代词（石兽）
固：固然/当然
颠：荒唐
→ 到下游去找，当然荒唐；在原地找，不更荒唐吗？
```

**如其言，果得于数里外。**
```
如：按照
其：他的
果：果然
得于数里外：在几里外找到了
```

### 主旨
凡事不能只凭主观臆断，要实践（"然则天下之事，但知其一，不知其二者多矣，可据理臆断欤？"）

### 三种态度
| 人 | 观点 | 对错 |
|:--|:----|:----|
| 僧人 | 顺流而下 | 错 |
| 讲学家 | 沉于沙中 | 半对（忽略了水的反冲力） |
| 河兵 | 在上游 | 对（有实践经验） |

# 附录：作文指导与范文

## 一、申怡·温儒敏视角

### 申怡：群文阅读 → 写作素材
七下的课文编排本身就是最好的写作教材。第一单元（邓稼先/闻一多/孙权劝学）都在写"杰出人物"——把这三篇放在一起读，就是一篇完整的"如何写人"的写作课。

**群文写作法**：写一个人物时，想想邓稼先怎么写的（对比+事例）、闻一多怎么写的（先抑后扬）、孙权劝学怎么写的（对话推动）。用"对比阅读"来积累写作手法，比背范文有效一百倍。

**三通应用**：学《木兰诗》时，通通历史（南北朝背景）、通通地理（从军路线）、通通生活中的"女性力量"话题——打通了，素材自然就有了，不用硬背作文素材库。

### 温儒敏：整本书阅读要降降温
《骆驼祥子》《海底两万里》是七下的整本书阅读要求。但温儒敏说"整本书阅读切忌过度课程化"——不要每章都要做笔记、写分析。让孩子先"连滚带爬"读完，喜欢再说。

**关于作文**：七下的作文比七上难了一个台阶——不再只是"把一件事说清楚"，还要"说得有层次"。但还是要守住"基本口粮"的底线：写不出来不要硬逼，先读，读够了自然写得出来。

## 二、七下写作重点：写人记事进阶 + 托物言志

### 课内写法借鉴

| 课文 | 可学的写作技巧 | 适用作文题 |
|:----|:-------------|:---------|
| 《邓稼先》 | 用对比凸显人物（邓稼先 vs 奥本海默） | 写杰出人物 |

| 《黄河颂》 | 象征手法 + 呼告 | 爱国类 |
| 《最后一课》 | 以小见大（一堂课写民族情感） | 家国情怀 |
| 《土地的誓言》 | 铺陈 + 排比 + 强烈抒情 | 思乡类 |
| 《阿长与山海经》 | 先抑后扬（讨厌→感动→怀念） | 写普通人 |
| 《老王》 | 平实的语言写不平凡的人 | 写身边人 |
| 《紫藤萝瀑布》 | 托物言志（物→情→理三层递进） | 咏物+感悟 |
| 《一棵小桃树》 | 双线结构（树的经历=我的成长） | 成长类 |

### 七下新增难度：托物言志
七上以"写人记事"为主，七下增加了"托物言志"——通过写一个物来表达情感或道理。

**写作公式**：
```
选物（紫藤萝/小桃树/台阶）→ 描写物（形/色/态）→ 物的经历（变化/挫折/生机）→ 联想到人 → 人生感悟
```

### 范文：台阶（成长类）

> 我家老屋的台阶，是我童年爬过的最高的山。
>
> 五岁那年，我站在台阶下，仰头望着那三级青石阶，觉得它们像三座大山。我颤巍巍地抬起脚，扶着门框，一步一步地往上爬，爬完三级，满头大汗，却得意地回头喊："妈妈你看，我爬上来了！"
>
> 十岁那年，台阶是我写作业的地方。夏天的傍晚，我把小板凳搬到台阶上，就着夕阳的光写数学题。有时候写着写着，抬头看看天边的火烧云，觉得自己特别了不起——"天将降大任于斯人也"嘛。
>
> 十五岁那年，我离开家去镇上读初中。走的那天，我背着行李站在台阶前，回头看了一眼。那三级台阶依然在那里，纹丝不动——像极了我的父母，沉默地守着这个家，等着我每个周末回来。
>
> 如今老屋拆了，台阶也不在了。可是每次遇到困难想退缩的时候，我就会想起它——迈上去，一级一级地迈上去，再高的山也会被踩在脚下。

**点评（申怡视角）**：这篇好在哪里？好在"一个物，一条线，三个时间点"——台阶就是那条线，五岁、十岁、十五岁串起了成长。"三通"在这里用上了：物的描写（通感官） + 时间线索（通叙事） + 结尾升华（通道理）。

**点评（温儒敏视角）**：这就是"读书为要"的成果——读多了，自然知道"托物言志"怎么用。不需要背概念，读《台阶》《紫藤萝瀑布》《一棵小桃树》之后，"借物抒情"就是自然而然的事了。

## 三、七下写作方法指南

### 1. 写人进阶：先抑后扬
七上写人用的是"直接写好的"，七下可以学"先写不好再写好"。
```
先抑（写缺点/误会/讨厌）
   → 转折（发生了一件事，改变看法）
     → 后扬（感动/敬佩/明白了）
```

### 2. 托物言志三步走
- **第一步**：选一个和你有故事的"物"（不是随便选，要有感情）
- **第二步**：把这个物的形状/颜色/变化写具体
- **第三步**：自然地过渡到你的人生感悟（不要硬拔高）

### 3. 申怡提示：三通素材法
写什么没素材？
- **通课文**：学过的课文就是最好的素材库（《邓稼先》写奉献《老王》写普通人）
- **通生活**：身边小事、新闻时事、校园活动
- **通阅读**：你读过的名著就是你最独特的素材

### 4. 温儒敏提示：不要"假大空"
七下最容易犯的毛病是——开头"光阴似箭日月如梭"，结尾"我一定要努力学习报效祖国"。
**温儒敏说**：文笔不是第一要义。先写真实的事、真实的感受。说真话，哪怕说得不好，也比说假话强。教育要"兜底"——作文的底线是说真话。
