## 1 春 / 朱自清

### 一、作者与文体
朱自清（1898-1948），字佩弦，现代散文家、诗人。代表作《背影》《荷塘月色》《匆匆》。
文体：写景抒情散文。

### 二、段落结构
```
第一部分（第1段）  盼春——"盼望着，盼望着"
第二部分（第2-7段）绘春——五幅图
  ├── 春草图（第2段）："小草偷偷地从土里钻出来"
  ├── 春花图（第3段）："桃树、杏树、梨树，你不让我，我不让你"
  ├── 春风图（第4段）："吹面不寒杨柳风"
  ├── 春雨图（第5段）："像牛毛，像花针，像细丝"
  └── 迎春图（第6-7段）："一年之计在于春"
第三部分（第8-10段）颂春——三个比喻
  ├── "春天像刚落地的娃娃"——新
  ├── "春天像小姑娘"——美
  └── "春天像健壮的青年"——力
```

### 三、重点句子赏析

**1. "盼望着，盼望着，东风来了，春天的脚步近了"**
- 修辞：反复（"盼望着"重复）+ 拟人（"脚步近了"）
- 效果：写出人们对春天急切盼望的心情

**2. "小草偷偷地从土里钻出来，嫩嫩的，绿绿的"**
- "偷偷"拟人——不让人察觉
- "钻"——写出小草顽强的生命力
- "嫩嫩的，绿绿的"——叠词，写出质感色彩
- 正常语序应为"嫩嫩的、绿绿的草"——定语后置，强调

**3. "桃树、杏树、梨树，你不让我，我不让你，都开满了花赶趟儿"**
- 拟人——花也争春
- 写出了花之多、花之盛

**4. "红的像火，粉的像霞，白的像雪"**
- 比喻+排比——三种颜色三种比喻
- 从视觉角度写花

**5. "花下成千成百的蜜蜂嗡嗡地闹着"**
- "闹"字——有声有色，既写声音又有热闹感
- 侧面烘托（以蜂写花之盛）

**6. "吹面不寒杨柳风"——引用**
- 引用南宋志南和尚的诗句
- 从触觉角度写春风

**7. "像母亲的手抚摸着你"**
- 比喻+拟人——春风的温柔

**8. "像牛毛，像花针，像细丝"**
- 三个比喻写出春雨的三个特点：
  - 牛毛——多而密
  - 花针——细而亮
  - 细丝——细而长

**9. 结尾三段比喻：**
- 娃娃——春天是新生命的开始（"新生"）
- 小姑娘——春天是美丽的（"娇美"）
- 青年——春天有无穷的力量（"力量"）

### 四、艺术特色
① 多角度描写：视觉、听觉、嗅觉、触觉
② 修辞丰富：比喻、拟人、排比、反复、引用
③ 语言特点：口语化、短句、叠词
④ 情景交融：在写景中融入对春天的赞美

### 五、常考题型
1. 结尾三段比喻的含义和顺序能否调换？
   → 不能。层层递进：娃娃→小姑娘→青年，从新到美到力。
2. "闹"字能否换成"叫"？
   → 不能。"闹"不仅有声音，还有热闹的氛围；"叫"只写声音。

## 2 济南的冬天 / 老舍

### 一、作者与文体
老舍（1899-1966），原名舒庆春，字舍予，北京人，现代著名作家。代表作《骆驼祥子》《茶馆》《四世同堂》。
文体：写景抒情散文。

### 二、结构分析
```
第一部分（第1段）  总写——济南冬天"温晴"的特点（对比）
第二部分（第2-4段）分写
  ├── 阳光下的山（第2段）：慈祥、暖和
  ├── 薄雪覆盖的山（第3段）：秀气、可爱
  └── 城外远山（第4段）：水墨画
第三部分（第5段）  写水——"蓝水晶"般的水
第四部分（第6段）  总结——"这就是冬天的济南"
```

### 三、对比手法（第1段核心）
| 地点 | 天气特点 | 对比目的 |
|:----|:--------|:--------|
| 北平（北京） | 风大 | 济南无风 |
| 伦敦 | 阴郁 | 济南晴 |
| 热带 | 日光毒 | 济南温 |
| **济南** | **温晴** | **结论** |

### 四、重点句子赏析

**1. "一个老城，有山有水，全在天底下晒着阳光，暖和安适地睡着"**
- 拟人——把济南写成沉睡的老人
- "晒""睡"——悠闲、安适

**2. "这一圈小山在冬天特别可爱，好像是把济南放在一个小摇篮里"**
- 比喻——小山=摇篮，济南=孩子
- 写出济南被山环抱的地形特点

**3. "最妙的是下点小雪呀"**
- 空间顺序：山尖→山坡→山腰（由上到下）
- "一道儿白，一道儿暗黄"——色彩的对比
- "那点薄雪好像忽然害了羞，微微露出点粉色"——拟人

**4. "就凭这些绿的精神，水也不忍得冻上"**
- 拟人——"不忍得"写出水对济南的喜爱

**5. "这就是冬天的济南"**
- 呼应开头，点明中心

### 五、语言特色
- 老舍风格的京味儿：口语化、亲切、自然
- 如"慈善的""暖和安适""不忍得"

## 3 雨的四季 / 刘湛秋

### 结构：春雨 → 夏雨 → 秋雨 → 冬雨
- 春雨：温柔、细密——"驱走了冬天，才使世界改变了姿容"
- 夏雨：热烈、粗犷——"粗犷而豪放"
- 秋雨：沉静、端庄——"端庄而沉思"
- 冬雨：自然、平静——"干净而自然"

### 手法：多感官描写（视+听+嗅+触）+ 欲扬先抑

## 4 古代诗歌四首（逐首详解）

### 4-1 观沧海 / 曹操

**作者：** 曹操（155-220），字孟德，东汉末年政治家、军事家、诗人。建安文学代表人物。

**诗句详解：**
```
东临碣石，以观沧海。
→ 东行登上碣石山，来观看大海。
①东——名词作状语，向东
②临——登上
③以——连词，来

水何澹澹，山岛竦峙。
→ 海水多么宽阔浩荡，山岛高高地挺立。
①何——多么（程度副词）
②澹澹——水波摇动的样子
③竦峙——高高耸立

树木丛生，百草丰茂。
→ 树木丛生，百草丰茂。（静态写山岛）

秋风萧瑟，洪波涌起。
→ 秋风萧瑟，巨浪翻涌。（动态写大海）

日月之行，若出其中；星汉灿烂，若出其里。
→ 日月的运行，好像从海中升起；银河灿烂，好像从海中产生。
①若——好像（比喻/想象）
②其中/其里——指大海
③"若"两次出现：虚实结合的手法
```

**考点：**
1. 前八句实写（眼前实景），后四句虚写（想象之景）
2. 借景抒情——借大海的壮阔表达统一天下的雄心
3. 名句默写："日月之行，若出其中；星汉灿烂，若出其里"

### 4-2 次北固山下 / 王湾

**作者：** 王湾，唐代诗人（生卒年不详），此诗为其代表作。

**诗句详解：**
```
客路青山外，行舟绿水前。
→ 旅人前行的路延伸在青山之外，行船在绿水之前。
①客路——旅途
②对仗："客路"对"行舟"，"青山"对"绿水"，"外"对"前"

潮平两岸阔，风正一帆悬。
→ 潮水涨平，两岸之间更显宽阔；顺风而行，一片船帆高悬。
①阔——形容词作动词，变得宽阔
②悬——高挂

海日生残夜，江春入旧年。
→ 红日从残夜中升起，江上的春天闯入旧年。
①生——升起
②入——进入、闯入
③千古名句：新事物从旧事物中萌生

乡书何处达？归雁洛阳边。
→ 家书送到哪里去呢？希望北归的大雁捎到洛阳。
①乡书——家信
②归雁——北归的大雁（古有鸿雁传书的说法）
③设问句——自问自答，更加突显思乡之情
```

### 4-3 闻王昌龄左迁龙标遥有此寄 / 李白

**背景：** 王昌龄被贬为龙标尉，李白写此诗寄慰。

**诗句详解：**
```
杨花落尽子规啼，闻道龙标过五溪。
→ 杨花落尽，杜鹃在啼叫；听说你被贬到龙标，要经过五溪。
①杨花——柳絮，象征飘零
②子规——杜鹃鸟，叫声哀切（"不如归去"）
③首句借景抒情——飘零的杨花+哀啼的子规 = 悲凉氛围
④龙标——地名，即今湖南黔阳
⑤五溪——五条溪流的总称（偏远之意）

我寄愁心与明月，随君直到夜郎西。
→ 我把忧愁的心寄托给明月，让它伴随你直到夜郎西。
①寄——寄托
②与——给
③拟人——把明月当成可以托付的人
④抒情方式：托月寄情
```
**考点：** 为什么托月寄情？
- 明月跨越时空，无论你在哪里都能共同看到
- 明月代表纯洁、真诚的友情

### 4-4 天净沙·秋思 / 马致远

**作者：** 马致远，元代戏曲家、散曲家，号东篱。"天净沙"是曲牌名，"秋思"是题目。

**诗句详解：**
```
枯藤老树昏鸦，小桥流水人家，古道西风瘦马。
→ 三个"名词+名词+名词"的意象叠加
①九种意象（枯藤/老树/昏鸦/小桥/流水/人家/古道/西风/瘦马）
②白描手法——不用任何关联词，直接罗列
③对比："枯藤老树昏鸦"（衰败）vs "小桥流水人家"（温馨）
④以乐景写哀情——"小桥流水人家"的温馨反衬游子的孤独

夕阳西下，断肠人在天涯。
→ 夕阳西下，悲痛到了极点的游子漂泊在天涯。
①断肠人——形容悲痛到了极点的人
②天涯——天边，极远的地方
③主旨句——点明游子思乡的主题
```

## 5 秋天的怀念 / 史铁生

### 一、作者与文体
史铁生（1951-2010），当代作家。双腿瘫痪，代表作《我与地坛》《病隙碎笔》。
文体：回忆性散文。

### 二、段落结构
```
第一部分（第1段）：双腿瘫痪，脾气暴躁，母亲安慰
第二部分（第2段）：母亲藏病，央求"我"看花
第三部分（第3-5段）："我"答应后母亲喜出望外—母亲病逝
第四部分（第6-7段）：妹妹推"我"看菊花，"我"懂了"好好儿活"
```

### 三、人物形象

**母亲：**
- 隐忍——"母亲就悄悄地躲出去""她又悄悄地进来"
- 坚强——自己得了绝症却不动声色
- 细心——"母亲喜欢花，可自从我的腿瘫痪后，她侍弄的那些花都死了"
- 无私——临终还牵挂子女（"我那个有病的儿子和我那个还未成年的女儿"）

**"我"：**
- 开始时暴躁绝望——"突然把面前的玻璃砸碎""猛地把东西摔向墙壁"
- 结尾时理解了母亲——"妹妹推我去北海看了菊花"
- 心理变化：痛苦→麻木→理解→坚强

### 四、重点词句

**"母亲扑过来抓住我的手，忍住哭声说"**
- 扑/抓/忍——三个动词连用
- "扑"——速度快，怕我出事
- "抓"——用力，急切
- "忍"——自己病重还要安抚我

**"她出去了，就再也没回来"**
- 淡淡的叙述中蕴含着巨大的悲痛
- 言简意深

**"我那个有病的儿子和我那个还未成年的女儿"**
- 母亲临终前最后一句话——至死不放心孩子

**"要好好儿活……"**
- 开头母亲说"咱娘儿俩在一块儿，好好儿活……"
- 结尾"我"懂了"要好好儿活"
- 首尾呼应

### 五、题目解读
"秋天的怀念"：
① 事情发生在秋天（看菊花）
② 母亲在秋天去世
③ "秋"的萧瑟与追悼的悲伤氛围吻合

## 6 散步 / 莫怀戚

### 一、文体与手法
散文，运用"以小见大"手法——散步这件小事折射出尊老爱幼的传统美德。

### 二、结构
```
交代：一家四口在南方初春的田野上散步
分歧：母亲要走大路（平顺），儿子要走小路（有意思）
解决：母亲说"走小路吧"→因为走不过去时儿子会背她
升华："我背母亲，妻背儿子，加起来就是整个世界"
```

### 三、对称句式（特色）
① "母亲要走大路，大路平顺；我的儿子要走小路，小路有意思"
② "我的母亲老了，她早已习惯听从她强壮的儿子；我的儿子还小，他还习惯听从他高大的父亲"
③ "我蹲下来，背起了母亲；妻子蹲下来，背起了儿子"

**作用：** 句式整齐、音韵和谐、对比鲜明

### 四、环境描写的作用
"这南方初春的田野，大块小块的新绿随意地铺着……"
- 交代时间地点
- 烘托一家人散步时愉快的心情
- 象征新生命、新希望

## 7 散文诗二首

### 金色花 / 泰戈尔

**文体：** 散文诗。泰戈尔（1861-1941），印度诗人，诺贝尔文学奖得主。

**内容：** 孩子变成金色花，和母亲捉迷藏——在树上笑、在新叶上跳舞、投影在母亲的书页上。

**手法：** 想象（变金色花）、拟人
**主旨：** 母子之爱的温馨与纯真

### 荷叶·母亲 / 冰心

**作者：** 冰心（1900-1999），原名谢婉莹，现代女作家。

**内容：** 雨中荷叶护莲 → 母亲护我
**手法：** 借物喻人（荷叶=母亲，红莲=我）
**名句：** "母亲啊！你是荷叶，我是红莲。心中的雨点来了，除了你，谁是我在无遮拦天空下的荫蔽？"
**主旨：** 赞美母爱

## 8 《世说新语》二则

### 8-1 咏雪

**原文：**
```
谢太傅寒雪日内集，与儿女讲论文义。
俄而雪骤，公欣然曰："白雪纷纷何所似？"
兄子胡儿曰："撒盐空中差可拟。"
兄女曰："未若柳絮因风起。"
公大笑乐。
```

**逐字解析：**
| 词 | 义 | 备注 |
|:--|:--|:-----|
| 谢太傅 | 谢安 | 东晋政治家 |
| 内集 | 家庭集会 | 内，家人 |
| 儿女 | 子侄辈 | 古今异义（今义：子女） |
| 俄而 | 不久，一会儿 | 时间副词 |
| 骤 | 急 | 古今异义（今义：突然） |
| 欣然 | 高兴的样子 | 然——……的样子 |
| 何所似 | 像什么 | 何（什么），似（像） |
| 胡儿 | 谢朗 | 谢安兄长的儿子 |
| 差可拟 | 差不多可以相比 | 差（大致），拟（相比） |
| 未若 | 不如 | 未（不），若（如） |
| 因风起 | 乘风飘起 | 因（趁、乘） |

**考点：** 谁的比喻更好？为什么？
- 谢道韫（兄女）的"柳絮因风起"更好
- 理由：柳絮轻盈、洁白，随风飘飞，更贴近雪花纷飞的动态美
- 撒盐只有形似（颜色），缺乏神似

### 8-2 陈太丘与友期行

**原文：**
```
陈太丘与友期行，期日中。
过中不至，太丘舍去，去后乃至。
元方时年七岁，门外戏。
客问元方："尊君在不？"答曰："待君久不至，已去。"
友人便怒曰："非人哉！与人期行，相委而去。"
元方曰："君与家君期日中。日中不至，则是无信；对子骂父，则是无礼。"
友人惭，下车引之。元方入门不顾。
```

**逐字解析：**
| 词 | 义 | 备注 |
|:--|:--|:-----|
| 期行 | 约定同行 | 期（约定） |
| 期日中 | 约定正午 | 日中（正午） |
| 舍去 | 丢下（他）离开 | 古今异义（今义：舍弃） |
| 去后乃至 | 离开后才到 | 去（离开），乃（才），至（到） |
| 时年 | 当时年龄 | |

## 9 从百草园到三味书屋 / 鲁迅

### 一、作者与背景
鲁迅（1881-1936），原名周树人，浙江绍兴人。现代文学的奠基人。选自《朝花夕拾》。

### 二、结构
```
第一部分（第1-8段）：百草园的欢乐
  ├── 百草园的景物（不必说……也不必说……单是……）
  ├── 美女蛇的故事
  └── 雪地捕鸟
第二部分（第9段）：过渡段——"我不知道为什么家里的人要将我送进书塾里去了"
第三部分（第10-24段）：三味书屋的生活
  ├── 入学时的仪式（拜孔子/拜先生）
  ├── 先生的形象
  └── 课外的乐趣
```

### 三、百草园部分（重点）

**"不必说……也不必说……单是……"句式分析：**
- "不必说"（先说一般的、大的）
- "也不必说"（再说也较常见的）
- "单是"（最后聚焦一点，突出有趣）
- 由整体到局部的写景顺序

**景物描写角度：**
| 景物 | 特征词 | 感官角度 |
|:----|:-------|:--------|
| 菜畦 | 碧绿（颜色） | 视觉 |
| 石井栏 | 光滑（质地） | 触觉 |
| 皂荚树 | 高大（形状） | 视觉 |
| 桑葚 | 紫红（颜色） | 视觉 |
| 鸣蝉 | 长吟（声音） | 听觉 |
| 黄蜂 | 肥胖（形状） | 视觉 |
| 叫天子 | 直窜（动态） | 视觉 |
| 油蛉 | 低唱（声音） | 听觉 |
| 蟋蟀 | 弹琴（拟人） | 听觉 |

**美女蛇故事的作用：** 增加百草园的神秘色彩和吸引力

**雪地捕鸟的动词：** 扫/露/支/撒/系/牵/拉——一连串动词写出捕鸟的全过程

### 四、三味书屋部分

**先生形象：**
- 方正、质朴、博学
- 严厉（有戒尺但不常用）
- 读书入神时的神态描写（"微笑起来，而且将头仰起，摇着"）

**三味书屋的乐趣：** 折蜡梅、寻蝉蜕、捉苍蝇喂蚂蚁、描绣像

### 五、主旨
怀念自由快乐的童年 + 批判封建教育束缚儿童天性

### 六、常考题型
1. "不必说……也不必说……单是"的作用？
→ 从整体到局部，用对比突出"单是"部分，强调百草园处处有趣。

2. 写美女蛇故事的目的？
→ 增添神秘色彩，表现百草园对儿童的吸引力。

3. 三味书屋的先生是怎样的人？
→ 方正质朴博学，但慈祥中带着严厉。

## 11 《论语》十二章（详解）

### 孔子简介
孔子（前551-前479），名丘，字仲尼，春秋时期鲁国人，儒家学派创始人。核心思想：仁、礼。
《论语》是记录孔子及其弟子言行的书，共20篇，语录体。

### 逐章解析

**第一章：**
```
子曰："学而时习之，不亦说乎？有朋自远方来，不亦乐乎？
人不知而不愠，不亦君子乎？"
```
- 时：按时（名词作状语）
- 习：温习、实践
- 说：同"悦"，愉快（通假字）
- 愠：生气、恼怒
- 不亦……乎：不也是……吗（反问句式）
- 三层：学习之乐 → 交友之乐 → 君子之修养

**第二章：**
```
曾子曰："吾日三省吾身：为人谋而不忠乎？与朋友交而不信乎？传不习乎？"
```
- 曾子（前505-前436），名参，孔子的弟子
- 日：每天（名词作状语）
- 三省：多次反省（三，泛指多次）
- 忠：尽心尽力
- 信：诚信
- 传：老师传授的知识

**第三章：**
```
子曰："吾十有五而志于学，三十而立，四十而不惑，
五十而知天命，六十而耳顺，七十而从心所欲，不逾矩。"
```
- 有：同"又"（用于整数和零数之间）
- 立：站立，指能自立于社会
- 不惑：不迷惑
- 天命：上天的意志/规律
- 耳顺：能听进不同意见
- 从心所欲：顺从心意
- 逾矩：超越规矩
- 孔子一生的学习历程（十五→七十，递进）

**第四章：**
```
子曰："温故而知新，可以为师矣。"
```
- 温：温习
- 故：旧知识
- 新：新理解/新体会
- 以：凭借

**第五章：**
```
子曰："学而不思则罔，思而不学则殆。"
```
- 罔：迷惑，感到迷茫
- 殆：疑惑/懈怠
- 学与思的辩证关系

**第六章：**
```
子曰："贤哉，回也！一箪食，一瓢饮，在陋巷，人不堪其忧，回也不改其乐。贤哉，回也！"
```
- 箪：古代盛饭的竹器
- 堪：忍受
- 回：颜回，孔子的得意弟子
- 主旨：安贫乐道——物质贫困不影响精神的快乐

**第七章：**
```
子曰："知之者不如好之者，好之者不如乐之者。"
```
- 之：代词，指学问/事业
- 知：知道/了解
- 好：喜欢/爱好
- 乐：以……为乐
- 三层递进：知→好→乐

**第八章：**
```
子曰："饭疏食，饮水，曲肱而枕之，乐亦在其中矣。不义而富且贵，于我如浮云。"
```
- 饭：吃（名词作动词）
- 疏食：粗粮
- 水：古代"水"指冷水，"汤"指热水
- 曲肱：弯着胳膊
- 枕：枕着（名词作动词）
- 不义：不正当的手段
- 于：对
- 核心：重义轻利

**第九章：**
```
子曰："三人行，必有我师焉。择其善者而从之，其不善者而改之。"
```
- 三：泛指多个
- 行：同行
- 焉：兼词，于之（在其中）
- 善者：优点
- 从：跟从/学习
- 核心：虚心向别人学习

**第十章：**
```
子在川上曰："逝者如斯夫，不舍昼夜。"
```
- 川：河
- 逝者：流逝的（时光）
- 斯：这（指河水）
- 舍：停止
- 主旨：珍惜时间

**第十一章：**
```
子曰："三军可夺帅也，匹夫不可夺志也。"
```
- 三军：军队的通称
- 夺：改变/夺取
- 匹夫：普通人
- 主旨：坚守志向

**第十二章：**
```
子夏曰："博学而笃志，切问而近思，仁在其中矣。"
```
- 子夏：孔子的弟子
- 笃：坚定
- 切：恳切
- 近思：思考当前的问题
- 主旨：仁在广博学习+坚定志向+恳切提问+关注当下之中

## 15 诫子书 / 诸葛亮

### 作者与背景
诸葛亮（181-234），字孔明，三国时蜀汉丞相。《诫子书》是写给儿子诸葛瞻的家书。

### 逐句详解

**"夫君子之行，静以修身，俭以养德。"**
```
夫：发语词，无实义
君子：品德高尚的人
行：操守、品行
静：屏除杂念、宁静专一
以：连词，表目的，来
修：修养
身：身心
俭：节俭
养：培养
德：品德
→ 君子的操守，以宁静来修养身心，以节俭来培养品德。
```

**"非淡泊无以明志，非宁静无以致远。"**
```
淡泊：内心恬淡，不慕名利（古今异义：今义指不追求）
无以：没有用来……的办法
明：明确、使……明确（使动用法）
志：志向
致：达到
远：远大目标（形容词作名词）
→ 不恬淡寡欲就无法明确志向，不宁静就无法达到远大目标。
```
**【考点】** 这是全文最著名的两句，常考默写。

**"夫学须静也，才须学也，非学无以广才，非志无以成学。"**
```
须：必须
广才：增长才干（广，使动用法，使……广）
成：完成、成就
→ 学习必须宁静，才干必须学习，不学习就无法增长才干，没有志向就无法学有所成。
```
核心逻辑：学→才，志→学，静→学

**"淫慢则不能励精，险躁则不能治性。"**
```
淫慢：放纵懈怠（淫，放纵；慢，懈怠）
则：就
励精：振奋精神（励，振奋）
险躁：轻薄浮躁（险，轻浮）
治性：修养性情
→ 放纵懈怠就无法振奋精神，轻薄浮躁就无法修养性情。
```

**"年与时驰，意与日去，遂成枯落，多不接世，悲守穷庐，将复何及！"**
```
与：跟随
驰：疾行、飞驰（古今异义）
意：意志
去：消逝、消失（古今异义：今义指离开）
遂：最终
枯落：凋零、衰败（比喻衰老）
接世：对社会有用/接触社会
穷庐：简陋的房舍
将复何及：又怎么来得及
→ 年纪随同时光飞驰，意志随同岁月消逝，最终凋零衰败，大多对社会没有用处，悲哀地守着破屋，又怎么来得及！
```

### 全文主旨
告诫儿子要宁静、节俭、学习、立志——四字核心：**静、俭、学、志**。

### 常考题型
1. 本文的中心论点是什么？
   → "静以修身，俭以养德"。

2. "非淡泊无以明志，非宁静无以致远"在文中的作用？
   → 强调淡泊和宁静对修身治学的重要性。

3. 你对"静"和"俭"的理解？
   → 静——排除杂念，专心致志；俭——生活节俭，不追求物质享受。

## 18 狼 / 蒲松龄

### 作者与来源
蒲松龄（1640-1715），清代文学家，字留仙，号柳泉居士。代表作《聊斋志异》。

### 逐句翻译解析

**第一段：遇狼**
```
一屠晚归，担中肉尽，止有剩骨。
→ 一个屠夫傍晚回家，担子里肉已经卖完了，只有剩下的骨头。
屠：屠夫，宰杀牲畜卖肉的人
晚：傍晚
归：回家
担：担子（古今异义：今义指挑）
止：同"只"（通假字）

途中两狼，缀行甚远。
→ 路上遇到两只狼，紧跟着他走了很远。
缀：紧跟
行：走
甚：很、非常
```

**第二段：投骨**
```
屠惧，投以骨。
→ 屠夫害怕了，把骨头扔给（狼）。
惧：害怕
投以骨：以骨投之（状语后置）

一狼得骨止，一狼仍从。
→ 一只狼得到骨头停下了，另一只仍然跟从。
止：停止
仍：仍然
从：跟从

复投之，后狼止而前狼又至。
→ 屠夫再扔骨头，后面那只狼停下了，前面那只狼又到了。
复：再
之：代词（指骨头）
而：连词，表顺承
至：到

骨已尽矣，而两狼之并驱如故。
→ 骨头已经扔完了，然而两只狼像原来一样一起追赶。
尽：完
而：连词，表转折
之：取消句子独立性，不译
并驱：一起追赶
如故：像原来一样
```

**第三段：窘迫**
```
屠大窘，恐前后受其敌。
→ 屠夫非常困窘，担心前后都受到狼的攻击。
窘：困窘，处境危急
恐：担心
受其敌：受到它们的攻击（敌，攻击）

顾野有麦场，场主积薪其中，苫蔽成丘。
→ 看到野地里有个打麦场，场主把柴草堆在场中，覆盖成小山似的。
顾：回头看，这里指往旁边看
积薪：堆积柴草
苫蔽：覆盖、遮盖

屠乃奔倚其下，弛担持刀。
→ 屠夫就跑过去靠在柴草堆下面，放下担子拿起刀。
乃：于是
奔：跑过去
倚：靠
弛：解除、卸下
持：拿着

狼不敢前，眈眈相向。
→ 两只狼不敢上前，瞪着眼朝着屠夫。
前：上前（名词作动词）
眈眈：瞪眼注视的样子
相：偏指一方（这里指屠夫）
向：朝着
```

**第四段：杀狼**
```
少时，一狼径去，其一犬坐于前。
→ 一会儿，一只狼径直走开了，另一只像狗一样蹲坐在前面。
少时：一会儿
径去：径直离开
犬坐：像狗一样蹲坐（名词作状语）

久之，目似瞑，意暇甚。
→ 时间长了，那只狼眼睛好像闭上了，神情很悠闲。
久之：时间长了
瞑：闭上眼睛
意：神情、态度
暇：悠闲
甚：很、非常

屠暴起，以刀劈狼首，又数刀毙之。
→ 屠夫突然跳起，用刀劈狼头，又连砍几刀杀死了它。
暴：突然
以：用
首：头
数：几
毙：杀死
之：代词（狼）

方欲行，转视积薪后，一狼洞其中，意将隧入以攻其后也。
→ 刚要走，转身看柴草堆后面，一只狼正在里面打洞，想要从通道进入来攻击他的身后。
方：刚
洞：打洞（名词作动词）
意：打算
隧：从通道（名词作状语）
以：连词，来

身已半入，止露尻尾。
→ 身体已经进去一半了，只露出屁股和尾巴。
半入：进去一半
止：同"只"
尻：屁股（古今异义）

屠自后断其股，亦毙之。
→ 屠夫从后面砍断它的大腿，也杀死了它。
自：从
断：砍断
股：大腿（古今异义）
亦：也

乃悟前狼假寐，盖以诱敌。
→ 这才明白前面的狼假装睡觉，原来是用来诱惑敌人。
乃：才
悟：明白
假寐：假装睡觉（寐，睡觉）
盖：原来（连词，表原因）
诱：诱惑
```

**第五段：议论**
```
狼亦黠矣，而顷刻两毙，禽兽之变诈几何哉？止增笑耳。
→ 狼也太狡猾了，但一会儿两只都被杀死了，禽兽的欺诈手段能有多少呢？只是增加笑料罢了。
黠：狡猾
顷刻：一会儿
毙：被杀死
变诈：欺诈手段
几何：多少
止：同"只"
耳：罢了
```

### 文言虚词总结
**之：** ①代词（投以骨"之"=骨头；毙"之"=狼）②取消独立性（两狼之并驱如故）③结构助词（禽兽"之"变诈=的）
**其：** ①代词（"其"一=其中一只；"其"后=他的）
**以：** ①介词（投"以"骨=把；"以"刀=用）②连词（"以"攻其后=来）
**而：** ①转折（后狼止"而"前狼又至）②顺承（"而"顷刻两毙）

### 主旨
狼再狡猾也斗不过人的智慧。对狼一样的恶势力不要心存幻想，要勇敢斗争。

# 附录：作文指导与范文

## 一、申怡·温儒敏视角

### 申怡：语文是黑箱，阅读是钥匙
一切语文问题归根结底都是阅读问题。写作的问题，不要先问"怎么写"，先问"读了吗、读懂了吗"。七上的作文训练重点——写人记事，要先从阅读中积累素材。

**群文阅读视角**：七上第一单元《春》《济南的冬天》《雨的四季》三篇写景散文放在一起，就是一个完整的"如何写景"的写作课。朱自清写了什么、老舍怎么写、刘湛秋又从什么角度——在对比中理解"写景的层次"。

**三通**：学课文的时候问问——这篇课文能给我的写作什么启发？《散步》的结构可以用到亲情作文上，《春》的比喻可以用到描写上。

### 温儒敏：读书为要是"牛鼻子"
作文写不好，根子在读书少。读多了自然能写——不是直接模仿，而是"浸泡"出来的语感和思路。

**连滚带爬地读**：七上的名著《朝花夕拾》《西游记》，不要要求孩子逐字精读，可以先"连滚带爬"地读完，知道讲了什么故事、喜欢什么人物就行。

**兜底思维**：七上的作文，要求是"能把一件事说清楚，让别人看懂"。不是说要多有文采、多用修辞，先把"把话说清楚"这个基本功练好。

## 二、七上写作重点：写人记事

### 课内写法借鉴

| 课文 | 可学的写作技巧 | 适用作文题 |
|:----|:-------------|:---------|
| 《春》 | 多感官描写（视/听/触/味）+ 比喻/拟人 | 写景类 |
| 《散步》 | 以小见大 + 对称句式 | 亲情类 |
| 《秋天的怀念》 | 细节描写（动作/语言/神态）+ 欲扬先抑 | 写人（母亲）类 |
| 《从百草园到三味书屋》 | 不必说……也不必说……单是 | 童年回忆类 |
| 《再塑生命的人》 | 心理变化线索 | 写师恩类 |
| 《走一步再走一步》 | 大困难分解成小困难 | 成长类 |

### 七上常考作文类型
1. **写人**：我的母亲/父亲/老师/朋友——关键在于"一件具体的事"
2. **记事**：难忘的一天/第一次XX——关键在于"写清楚过程"
3. **写景**：家乡的XX/校园的XX——关键在于"多感官+有顺序"

### 范文：我的母亲（亲情类）

> 母亲是个再普通不过的人。走在人群里，你一眼不会注意到她——个子不高，皮肤有点黑，常年穿一件洗得泛白的蓝布衫。
>
> 可就是这双手，撑起了我们的家。
>
> 记得那年我上小学三年级，冬天特别冷。母亲每天天不亮就起来，先给我热好早饭，再往我的书包里塞一个热水袋。我说"学校有暖气"，她笑着说："路上冷，揣着暖和些。"
>
> 有一次放学，天下了大雨。别的同学都被家长接走了，我一个人站在校门口等。雨越下越大，我快哭了。这时我看见雨里跑来一个人——是母亲。她浑身湿透了，头发贴在脸上，手里紧紧攥着一把伞。
>
> "妈你怎么不打伞？"
>
> "打了伞跑不快，怕你等急了。"
>
> 那一刻我鼻子一酸。回家路上，她把伞全撑在我这边，自己的半边身子露在雨里。
>
> 如今我长大了，母亲的白发也多了。每当想起那个雨天的身影，我就在心里默默地想：妈妈，您是我的全部。

**点评（申怡视角）**：这篇作文好在"具体"——没有一个空话，全是细节。"雨越下越大""浑身湿透了""伞全撑在我这边"——用事实说话，不用喊"母亲伟大"。七年级的孩子能做到"用具体的事写一个人"，就是好作文。

**点评（温儒敏视角）**：这就是"基本口粮"的范例——不刻意追求文采，把一件事说清楚、说真诚了，就是合格的作文。文笔可以慢慢练，真诚是第一位的。

## 三、七上写作方法指南

### 1. 写人三板斧
- **选一件事**：写人不要写"我的妈妈勤劳善良"——用一件事来证明
- **写好细节**：妈妈的动作、语言、神态——用动词不用形容词
- **加一点感受**：这件事让我怎么了（感动/愧疚/明白）

### 2. 记事四步法
- **开头**：时间+地点+人物+发生了什么事（一两句）
- **经过**：按顺序写，每一步写清楚（详写）
- **高潮**：最精彩/最关键的部分（最详）
- **结尾**：这件事让我明白了什么（一两句，不能喊口号）

### 3. 申怡提示：用理科思维写作文
写作文前先搭框架——用"公式"想清楚再动笔：
```
写人文：开头(1句引出人物) → 事件起因 → 经过(详) → 高潮(最详) → 感受(1-2句)
写景文：整体(远看) → 局部(近看) → 细节(最特别的地方) → 感受
记事文：何时何地何事 → 发生了什么(按顺序) → 最后怎样了 → 我学到了什么
```

### 4. 温儒敏提示：先读后写
不要一上来就让写。写之前先读两篇同类的好文章：
- 写母亲 → 读《秋天的怀念》→ 注意史铁生怎么写的
- 写老师 → 读《再塑生命的人》→ 注意海伦·凯勒怎么写的
- 写景 → 读《春》→ 注意朱自清用了哪些感官

"读了三篇还不会写"——正常。读三十篇再看看？
