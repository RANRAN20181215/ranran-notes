# 21 狐假虎威

> 第3/4篇 · 想象 · 上篇《雪孩子》与此篇同属第七单元，下篇《狐狸分奶酪》与此篇同属第七单元

> 部编版二上第21课
> **阅读重点**：展开想象，获得初步的情感体验
> **写话目标**：展开想象写几句话

---

### 📖 □核心 课文一瞥

| 核心问题 | 主要内容 |
|:---------|:---------|
| 狐狸用了什么办法从老虎口中逃走？ | 狐狸说"我是老天爷派来管百兽的"，借老虎的威风吓跑了百兽 |

**一句话速览**：老虎抓住狐狸要吃掉它，狐狸说："你敢吃我？我是老天爷派来管你们百兽的！"老虎不信，就跟在狐狸后面走。结果野兽们吓得全跑了——老虎真以为狐狸厉害，其实是借了老虎自己的威风！

**□储备 单元关联**：本单元主题"想象"。《雾在哪里》把自然现象写成淘气的孩子，《雪孩子》把科学知识藏在童话里，《狐狸分奶酪》用故事讲信任与合作。读这篇时想一想——狐狸的"聪明"和雪孩子的"善良"，你觉得哪个更重要？

### 🏗️ □核心 文章结构

```
老虎抓住狐狸
  ↓
狐狸说：我是老天爷派来的，百兽都怕我
  ↓
老虎半信半疑，跟在狐狸后面走
  ↓
百兽看见老虎都吓跑了（老虎以为是怕狐狸）
  ↓
老虎信以为真 → 狐狸借了老虎的威风
```

**层层推进**：危机→骗术→验证→结果，像一幕小戏。

### 🌿 □了解 重点词语

| 词语 | 解释 | 例句 |
|:----|:-----|:-----|
| **狐假虎威** | 借别人的威风吓唬人 | 狐狸借老虎的威风骗了百兽。 |
| **假** | 借（在此处是借的意思） | 狐假虎威——狐狸借老虎的威风。 |
| **老虎** | 大型猫科动物 | 老虎是森林之王。 |
| **狐狸** | 狡猾的动物 | 狐狸非常狡猾。 |
| **逮住** | 抓住（动物） | 老虎逮住了一只狐狸。 |
| **违抗** | 不服从 | 谁敢违抗我的命令？ |
| **派** | 派遣、安排 | 我是老天爷派来管你们的。 |
| **管理** | 管、治理 | 让我来管理你们百兽。 |
| **胆子** | 胆量、勇气 | 你的胆子真不小。 |
| **神气活现** | 得意忘形的样子 | 狐狸神气活现地走在前面。 |
| **摇头摆尾** | 得意的样子 | 老虎跟在后面摇头摆尾。 |
| **半信半疑** | 有点信有点不信 | 老虎半信半疑地跟在后面。 |
| **东张西望** | 到处看 | 百兽们东张西望，看到老虎就跑。 |
| **威风** | 气势、气派 | 老虎的威风被狐狸借走了。 |
| **撒腿就跑** | 拔腿就跑 | 百兽看见老虎，撒腿就跑。 |

### ⚠️ □了解 易错字提醒

| 字 | 易错点 | 记忆口诀 |
|:---|:-------|:---------|
| **狐** | 右边是"瓜"，不是"爪" | 反犬旁+"瓜"=狐狸 |
| **假** | 右边是"叚"，不是"段" | 单人旁+"叚"=真假 |
| **威** | 里面有一横 | 戊+女（里有一横）=威 |
| **派** | 右边是"辰"+"长"少一竖 | 三点水+"厈"+"长"少一竖=派 |
| **野** | 右边是"予"，不是"矛" | 里+予=野 |

### 📝 □了解 词语采蜜集

**四字词语**：狐假虎威、神气活现、摇头摆尾、半信半疑、东张西望、撒腿就跑
