# 3 植物妈妈有办法

> 第3/3篇 · 大自然的秘密 · 上篇《我是什么》与此篇同属第1单元，是第1单元末篇

> 部编版二上第3课
> **阅读重点**：积累并运用表示动作的词
> **写话目标**：用表示动作的词写几句话

---

### 📖 □核心 课文一瞥

| 核心问题 | 主要内容 |
|:---------|:---------|
| 蒲公英、苍耳、豌豆的种子怎么传播？ | 风→蒲公英，动物→苍耳，太阳晒→豌豆炸开 |

**一句话速览**：蒲公英的种子像小伞，风一吹飞到各地；苍耳穿带刺的铠甲，挂住动物皮毛去旅行；豌豆晒在太阳下，豆荚炸开蹦出来——植物妈妈各有办法！

**□储备 单元关联**：本单元主题"大自然的秘密"。《小蝌蚪找妈妈》讲动物成长的变化，《我是什么》讲水的各种变化。读这篇时想一想——植物妈妈们的"办法"算不算一种"变化"？

### 🌿 □了解 重点词语

| 词语 | 解释 | 例句 |
|:----|:-----|:-----|
| **旅行** | 出门远行 | 蒲公英的孩子要去旅行。 |
| **蒲公英** | 种子带绒毛的植物 | 蒲公英的种子像小伞兵。 |
| **降落伞** | 从空中慢慢下降的伞 | 蒲公英的种子像一个小降落伞。 |
| **苍耳** | 种子带刺的植物 | 苍耳的小刺能挂住动物的皮毛。 |
| **豌豆** | 豆荚成熟后会炸开 | 豌豆妈妈让豆荚晒在太阳底下。 |
| **炸开** | 突然裂开 | 豆荚被太阳晒得炸开了。 |
| **纷纷** | 多而杂乱地 | 种子纷纷从豆荚里蹦出来。 |
| **山洼** | 山里的低处 | 蒲公英的种子落在山洼里。 |
| **铠甲** | 古代战士的护甲 | 苍耳穿上带刺的铠甲。 |
| **知识** | 知道和了解的事物 | 植物妈妈的办法真多。 |
| **仔细** | 认真、细心 | 只要仔细观察，就能发现植物的秘密。 |
| **粗心** | 不细心 | 粗心的小朋友却得不到它。 |

### ✨ □核心 读写深挖

| 写法亮点 | 课文内容 | 学到什么 |
|:---------|:---------|:---------|
| **总分结构** | "植物妈妈有办法"+三种植物 | 先总说后分说，条理清楚 |
| **拟人生动** | "妈妈""孩子""旅行" | 把植物当人写，有趣又好记 |
| **精准动词** | 乘风出发、挂住皮毛、晒炸蹦出 | 不同植物用不同动作 |

### ⚠️ □了解 易错字提醒

| 字 | 易错点 | 记忆口诀 |
|:---|:-------|:---------|
| **旅** | 右边是"氏"加撇，不是"辰" | 方人"氏"一起旅行 |
| **蒲** | 草字头+"浦"，不要漏草字头 | 草字头下"浦"公"英" |
| **豌** | 左边是"豆"，右边是"宛" | "豆"+"宛"=豌豆 |
| **植** | 右边里面是三横 | 木字旁+"直"（直里三横） |
| **备** | 上面是"夂"（折文），不是"文" | 折文压"田"有准"备" |

### 🔍 □了解 形近字辨析

| 字 | 组词 | 易混字 | 组词 | 区分方法 |
|:---|:-----|:-------|:-----|:---------|
| **法** | 办法 | **去** | 来去 | 三点水+去=法 |
| **知** | 知道 | **如** | 如果 | 口在前是"知"，女在旁是"如" |
| **娃** | 娃娃 | **蛙** | 青蛙 | 女字旁是女娃，虫字旁是青蛙 |
| **纷** | 纷纷 | **芬** | 芬芳 | 丝线（纟）纷纷，草（艹）芬芳 |

| 字 | 读音 | 组词 | 读音 | 组词 |

| **为** | wéi | 成为 | wèi | 因为 |
| **得** | dé | 得到 | de | 跑得快 | děi | 得努力 |
| **更** | gèng | 更加 | gēng | 更新 |

### 🧩 □了解 偏旁归类

| 偏旁 | 字 | 说明 |
|:-----|:---|:-----|
| **艹**（草字头） | 蒲、英、苍、草、花 | 都和植物有关 |
| **木**（木字旁） | 植、树、根、枝、梢 | 都和树木有关 |
| **豆**（豆字旁） | 豌、豆、豉 | 都和豆类有关 |
| **身**（身字旁） | 旅、躺、射 | 都和身体、动作有关 |

### 📝 □了解 词语采蜜集

**四字词语**：四海为家、纷纷出发、许许多多、粗心大意

**近义词**：办法—方法、仔细—认真、旅行—旅游

**反义词**：仔细—粗心、轻—重、快—慢、高—低

### 🤔 □核心 想一想

- 蒲公英、苍耳、豌豆——它们的种子分别是怎么出发的？你最喜欢哪种方式？
- 课文说"粗心的小朋友却得不到它"——这里的"它"是什么？怎么才能不粗心？

### ✏️ □了解 写话练习

用"只要……就……"说一句话。
例如："只要仔细观察，就能发现大自然的奥秘。"
先说出来，再写下来。再想一想：你观察过什么植物？它的种子长什么样？
