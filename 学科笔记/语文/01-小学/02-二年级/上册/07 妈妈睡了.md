# 7 妈妈睡了

> 第4/4篇 · 儿童生活 · 上篇《一封信》与此篇同属第3单元，是第3单元末篇

> 部编版二上第7课 · 体会细节描写，感受母爱 | 写话：用细节写人物

---

### 📖 □核心 课文一瞥

| 核心问题 | 主要内容 |
|:---------|:---------|
| 妈妈睡着时是什么样子？ | 睡梦中的妈妈真美丽、好温柔、好累 |

**一句话速览**：妈妈睡着了，她真美丽——眼睛弯弯，微微笑着；好温柔——在睡梦中也想念着孩子；她好累——呼吸那么沉，头发粘在额头上。我爱妈妈。

**□储备 单元关联**：本单元主题"儿童生活"。《曹冲称象》讲遇到难题动脑筋，《玲玲的画》讲动脑筋把坏事变好事，《一封信》讲用不同方式表达爱。读这篇时想一想——你用心观察过家人的什么？

### 🌿 □了解 重点词语

| 词语 | 解释 | 例句 |
|:----|:-----|:-----|
| **美丽** | 好看、漂亮 | 睡梦中的妈妈真美丽。 |
| **温柔** | 温和、柔软 | 妈妈对我很温柔。 |
| **呼吸** | 吸气呼气 | 妈妈的呼吸那么沉。 |
| **深沉** | 声音大而稳 | 妈妈的呼吸很深沉。 |
| **额头** | 眉毛以上的部分 | 汗水粘在妈妈的额头上。 |
| **紧紧** | 很用力地 | 她紧紧地闭着眼睛。 |
| **好像** | 仿佛、似乎 | 妈妈好像在做梦。 |
| **微微** | 一点点 | 妈妈微微地笑着。 |
| **嘴巴** | 嘴 | 妈妈的嘴巴微微张开。 |
| **润湿** | 又湿又润 | 妈妈的头发润湿了。 |
| **劳累** | 很累、辛苦 | 妈妈每天都很劳累。 |
| **乏了** | 累了、疲倦了 | 妈妈干了好多活，乏了。 |

### ✨ □核心 读写深挖

| 写法亮点 | 课文内容 | 学到什么 |
|:---------|:---------|:---------|
| **细节描写** | 呼吸沉、头发粘额头 | 小细节写出"妈妈累了" |
| **排比段** | "睡梦中的妈妈真美丽/好温柔/好累" | 每个段开头一样，条理清楚 |
| **情感真挚** | "我爱妈妈"结尾 | 用真情实感打动人 |

### ⚠️ □了解 易错字提醒

| 字 | 易错点 | 记忆口诀 |
|:---|:-------|:---------|
| **闭** | 里面是"才"，不是"木" | 门里藏"才"=关闭 |
| **额** | 右边是"页"，不是"贝" | 客人的"页"=额头 |
| **沉** | 右边是"冖+几"，不是"冗" | 三点水+"冖几"=沉 |
| **累** | 上面是"田"，下面是"糸" | 田里种"糸"=累 |
| **紧** | 上面是"丨+又"，下面是"糸" | "又"+"糸"=紧紧 |

### 📝 □了解 词语采蜜集

**AAB式词语**：微微笑、紧紧抱、慢慢走、轻轻说

**近义词**：美丽—漂亮、温柔—温和、深沉—深厚

**反义词**：美丽—丑陋、温柔—粗暴、紧—松
