# 22 狐狸分奶酪

> 第4/4篇 · 想象 · 上篇《狐假虎威》与此篇同属第七单元，是第七单元末篇

> 部编版二上第22课
> **阅读重点**：展开想象，获得初步的情感体验
> **写话目标**：展开想象写几句话

---

### 📖 □核心 课文一瞥

| 核心问题 | 主要内容 |
|:---------|:---------|
| 狐狸怎么"帮"两只小熊分奶酪？ | 先咬一口这边→再咬一口那边→左一口右一口→奶酪吃光了 |

**一句话速览**：两只小熊捡到一块奶酪，不知道怎么分。狐狸来了，说帮它们分，左一口右一口，最后奶酪全进了狐狸的肚子。两只小熊傻眼了——谁让你们不自己分呢！

**□储备 单元关联**：本单元主题"想象"。《雾在哪里》把自然现象写成淘气的孩子，《雪孩子》把科学知识藏在童话里，《狐假虎威》用故事讲辨别真假。读这篇时想一想——两只小熊为什么会被狐狸骗了？

### 🌿 □了解 重点词语

| 词语 | 解释 | 例句 |
|:----|:-----|:-----|
| **奶酪** | 用奶做的食品 | 两只小熊捡到一块奶酪。 |
| **拌嘴** | 争吵 | 两只小熊在拌嘴，谁分都不行。 |
| **摔碎** | 掉到地上摔破了 | 奶酪差点被它们摔碎了。 |
| **吵架** | 大声争吵 | 为了一点小事吵架不值得。 |
| **方便** | 对谁便利 | 狐狸说："我分得正方便。" |
| **公平** | 对大家都一样 | 它们要求分得公平。 |
| **大块** | 很大的一块 | 狐狸咬了一大块奶酪。 |
| **嚷** | 大声喊叫 | 小熊嚷着说："你分得不公平！" |
| **轮流** | 一个接一个 | 它们轮流咬都不行。 |
| **剩下** | 还留下 | 奶酪被狐狸吃得只剩一点了。 |
| **整块** | 完整的一块 | 原来是一整块奶酪。 |
| **一点点** | 很少很少 | 最后只剩下一小丁点了。 |

### ✨ □核心 读写深挖

| 写法亮点 | 课文内容 | 学到什么 |
|:---------|:---------|:---------|
| **对话生动** | "你分得不公平！""我分得正方便！" | 狐狸和小熊的话各有特色 |
| **递减变化** | 大块→小块→一小点→没了 | 奶酪越来越小，紧张感越来越强 |
| **聪明反被聪明误** | 小熊：谁让你们不信任对方呢 | 结尾点出教训 |

### ⚠️ □了解 易错字提醒

| 字 | 易错点 | 记忆口诀 |
|:---|:-------|:---------|
| **奶** | 右边是"乃"，不是"及" | 女+"乃"=奶奶 |
| **酪** | 右边是"各"，不是"洛" | 酉+"各"=奶酪 |
| **吵** | 右边是"少"，不是"沙" | 口+"少"=吵架 |
| **第** | 上面是"⺮"头，下面是"弟" | "⺮"+"弟"=第一 |
