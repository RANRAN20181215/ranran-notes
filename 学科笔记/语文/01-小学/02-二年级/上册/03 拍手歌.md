# 3 拍手歌

> 第3/4篇 · 识字 · 上篇《树之歌》与此篇同属第2单元，下篇《田家四季歌》与此篇同属第2单元

> 部编版二上识字第3课 · 读拍手歌，认识动物 | 写话：用押韵写短句

---

### 📖 □核心 课文一瞥

| 核心问题 | 主要内容 |
|:---------|:---------|
| 课文用拍手歌介绍了哪些动物？ | 孔雀、锦鸡、雄鹰、大雁、老虎、百灵、熊猫 |

**一句话速览**：你拍一我拍一，动物世界很新奇。孔雀锦鸡是伙伴，雄鹰大雁飞得高，黄鹂百灵唱得好，虎隐丛林熊猫在——动物朋友要保护！

**□储备 单元关联**：本单元主题"识字"。《场景歌》用量词画场景，《树之歌》用特点写树木，《田家四季歌》用四季说农事。读这篇时想一想——拍手歌里介绍了哪些动物朋友？

### 🌿 □了解 重点词语

| 词语 | 解释 | 例句 |
|:----|:-----|:-----|
| **保护** | 小心爱护 | 我们要保护动物。 |
| **动物** | 鸟兽虫鱼的总称 | 动物是我们人类的朋友。 |
| **自由** | 不受约束 | 小鸟在天空中自由地飞翔。 |
| **朋友** | 友好的人或事物 | 动物和人类是朋友。 |
| **新奇** | 新鲜奇特 | 动物世界很新奇。 |
| **孔雀** | 尾羽很漂亮的鸟 | 孔雀的尾巴像一把大扇子。 |
| **锦鸡** | 羽毛很美的鸟 | 锦鸡的羽毛五颜六色。 |
| **雄鹰** | 大而勇猛的鹰 | 雄鹰在蓝天上飞翔。 |
| **大雁** | 排成人字飞的鸟 | 大雁秋天飞到南方去。 |
| **百灵** | 歌声很好听的鸟 | 百灵鸟的歌声真动听。 |
| **嬉戏** | 游戏、玩耍 | 动物们在森林里嬉戏。 |
| **丛林** | 茂密的树林 | 丛林深处有老虎。 |

### ⚠️ □了解 易错字提醒

| 字 | 易错点 | 记忆口诀 |
|:---|:-------|:---------|
| **保** | 右边是"呆"，不是"朵" | 站人旁+"呆"=保护 |
| **护** | 右边是"户"，不是"卢" | 提手旁+"户"=爱护 |
| **猴** | 右边是"侯"，不是"候" | 反犬旁+"侯"=猴子 |
| **虎** | 第三笔是横钩，不是撇 | "虍"字头要记住 |
| **雀** | 上面是"小"，下面是"隹" | "小"+"隹"=孔雀 |

### 🔍 □了解 形近字辨析

| 字 | 组词 | 易混字 | 组词 | 区分方法 |
|:---|:-----|:-------|:-----|:---------|
| **鹰** | 雄鹰 | **雁** | 大雁 | 广字头是鹰，厂字头是雁 |
| **歌** | 唱歌 | **喝** | 喝水 | 欠字旁是唱歌，口字旁是喝水 |
| **丛** | 丛林 | **从** | 从前 | 一横加"从"是丛林 |
| **拍** | 拍手 | **怕** | 害怕 | 提手旁是拍，竖心旁是怕 |

### 🧩 □了解 偏旁归类

| 偏旁 | 字 | 说明 |
|:-----|:---|:-----|
| **鸟**（鸟字旁） | 鸽、鹅、鸭、鸡 | 都和鸟类有关 |
| **隹**（隹字旁） | 雀、雁、雄、鹰 | 也是鸟类的意思 |
| **豸**（反犬旁） | 猴、狮、猫、狗 | 都和兽类有关 |
| **攵**（反文旁） | 敢、散、收、放 | 和手的动作有关 |

### 📝 □了解 词语采蜜集

**四字词语**：三五成群、自由自在

**近义词**：保护—爱护、新奇—新鲜、嬉戏—玩耍

**反义词**：保护—伤害、新—旧、深—浅

### 🤔 □核心 想一想

- 课文里写了孔雀、锦鸡、雄鹰、大雁……你认识哪些？你最喜欢什么动物？
- "保护动物是大事"——你觉得我们能做哪些小事来保护动物？

### ✏️ □了解 写话练习

用"你拍一，我拍一"的格式，自己编一小段拍手歌。
例如："你拍一，我拍一，保护动物要牢记。"
先说出来，再写下来。
