## 12 坐井观天

> ⏰ 先读课文三遍，再往下看

### 📖 □核心 课文一瞥

| 核心问题 | 主要内容 |
|:---------|:---------|
| 青蛙和小鸟在争论什么？谁对？ | 青蛙说天只有井口大，小鸟说天无边无际 |

**一句话速览**：青蛙坐在井底问小鸟："你从哪儿来？"小鸟说飞了一百多里。青蛙不信："天只有井口那么大！"小鸟笑了："天无边无际，你跳出来看看吧！"

### 🏗️ □核心 文章结构

```
青蛙：天只有井口大（错）
  ↕ 争论天有多大 ↕
小鸟：天无边无际（对）
    ↓
道理：看问题要全面
```

**对话推进**：青蛙和小鸟你说一句我说一句，在争论中体现寓意。

### 🌿 □了解 重点词语

| 词语 | 解释 | 例句 |
|:----|:-----|:-----|
| **坐井观天** | 坐在井里看天，比喻眼光窄 | 坐井观天的人看不到世界有多大。 |
| **观** | 看、观察 | 我们坐在窗前观风景。 |
| **井沿** | 井口边沿 | 小鸟落在井沿上。 |
| **回答** | 回应问题 | 青蛙回答小鸟的问题。 |
| **无边无际** | 没有边际，非常大 | 天空无边无际。 |
| **一百多里** | 很远的路程 | 小鸟飞了一百多里。 |
| **大话** | 夸张不实的话 | 青蛙说小鸟在说大话。 |
| **弄错** | 搞错了 | 你弄错了，天不是那么小。 |
| **抬头** | 把头抬起来 | 青蛙抬头看天。 |
| **相信** | 认为真实 | 青蛙不相信小鸟的话。 |
| **错** | 不正确 | 天无边无际，你说错啦。 |

### ✨ □核心 读写深挖

| 写法亮点 | 课文内容 | 学到什么 |
|:---------|:---------|:---------|
| **对比** | 井口大 vs 无边无际 | 对比让人明白谁对谁错 |
| **对话推动** | 青蛙↔小鸟你一句我一句 | 用对话写争论 |
| **寓意藏在故事里** | 不说"要全面看问题"而是讲故事 | 好故事不用说教 |

## 13 寒号鸟

> ⏰ 先读课文三遍，再往下看

### 📖 □核心 课文一瞥

| 核心问题 | 主要内容 |
|:---------|:---------|
| 寒号鸟为什么会被冻死？ | 喜鹊劝它做窝，它不听，冻死在寒冬夜里 |

**一句话速览**：喜鹊劝寒号鸟："趁天晴快做窝！"寒号鸟说："傻喜鹊，别啰嗦，天气暖和，得过且过。"冬天到了，喜鹊在温暖的窝里，寒号鸟冻死在石缝里——懒惰真可怕！

### 🏗️ □核心 文章结构

```
秋天：喜鹊做窝 ↔ 寒号鸟玩
  ↓
冬天到了：喜鹊温暖 ↔ 寒号鸟哆嗦
  ↓
寒冬夜：喜鹊睡着 ↔ 寒号鸟冻死
  ↓
道理：懒惰没有好结果
```

**对比推进**：喜鹊勤劳↔寒号鸟懒惰，一个活一个死，对比强烈。

### 🌿 □了解 重点词语

| 词语 | 解释 | 例句 |
|:----|:-----|:-----|
| **山脚** | 山的脚下 | 喜鹊住在山脚的杨树上。 |
| **石崖** | 陡峭的石壁 | 寒号鸟住在石崖的缝里。 |
| **当作** | 看成、当成 | 他把石头当作凳子坐。 |
| **得过且过** | 能过一天算一天 | 寒号鸟整天得过且过。 |
| **清早** | 清晨、一大早 | 清早，喜鹊就飞出去找吃的。 |
| **枯草** | 干枯的草 | 喜鹊衔来枯草做窝。 |
| **懒惰** | 不爱干活 | 寒号鸟太懒惰了。 |
| **劝告** | 劝说、告诉 | 喜鹊再三劝告它。 |
| **哆嗦** | 发抖 | 寒号鸟冻得直哆嗦。 |
| **晴朗** | 没有云、天气好 | 天气晴朗，正好做窝。 |
| **寒冬腊月** | 非常冷的冬天 | 寒冬腊月，大雪纷飞。 |
| **冻死** | 因冷而死 | 寒号鸟被冻死了。 |

| **反复劝说** | 喜鹊劝了两次，寒号鸟都拒绝了 | 重复写出别人的好意和它的固执 |
| **天气变化** | 秋天→冬天→寒冬腊月 | 天气越来越冷，越来越紧张 |

## 14 我要的是葫芦

> ⏰ 先读课文三遍，再往下看

### 📖 □核心 课文一瞥

| 核心问题 | 主要内容 |
|:---------|:---------|
| 种葫芦的人为什么没收到葫芦？ | 叶上长蚜虫不管→叶子枯了→葫芦落了 |

**一句话速览**：有个人种了葫芦，叶子上长了蚜虫，邻居劝他治虫，他说："我要的是葫芦，又不是叶子！"结果叶子枯了，小葫芦也落了——什么也没收到。

### 🏗️ □核心 文章结构

```
种葫芦 → 开花 → 结小葫芦 → 长蚜虫 → 不治 → 葫芦落了
                                        ↓
                                    邻居劝他也不听
                                        ↓
                                    道理：做事要联系地看问题
```

**因果关系**：因为不治虫→所以葫芦落了。

### 🌿 □了解 重点词语

| 词语 | 解释 | 例句 |
|:----|:-----|:-----|
| **葫芦** | 一种瓜果，可做容器 | 藤上挂了几个小葫芦。 |
| **一些** | 一部分 | 叶子上有一些蚜虫。 |
| **蚜虫** | 吃叶子的小虫 | 蚜虫会伤害植物的叶子。 |
| **盯着** | 一直看着 | 那个人盯着小葫芦看。 |
| **邻居** | 住在旁边的人 | 邻居劝他快治蚜虫。 |
| **藤** | 植物的细茎 | 葫芦藤上开出了小白花。 |
| **奇怪** | 跟平常不一样 | 邻居很奇怪，他为什么不治虫？ |
| **自言自语** | 自己跟自己说话 | 他自言自语地说："快长啊！" |
| **可爱** | 让人喜欢 | 小葫芦真可爱！ |
| **赛过** | 超过、比……好 | 赛过大南瓜才好。 |
| **慢慢地** | 一点一点变化 | 葫芦慢慢地变黄落了。 |
| **盯** | 集中注意力看 | 他目不转睛地盯着葫芦。 |
| **谢** | 花落了枯萎 | 花谢了以后长出小葫芦。 |

### ✨ □核心 读写深挖

| 写法亮点 | 课文内容 | 学到什么 |
|:---------|:---------|:---------|
| **人物态度** | 两次说"我要的是葫芦" | 一句话重复说，刻画出固执 |
| **旁人的话** | 邻居提醒→他不听 | 用旁人的话衬托主角的错误 |
| **结果对比** | 别人有葫芦 ↔ 他什么也没有 | 对比不言而喻 |

## ✍️ 写话：用几句话写一个简单的道理

### 🎯 □核心 目标

**写一件小事，让人明白一个道理。**

要求：先写一件小事，最后写出道理。

### 📐 □了解 写作框架

1. **开头**：写一件小事（什么事/谁）
2. **经过**：事情的经过是怎样的
3. **道理**：从这件事中明白了什么

### 🧩 □了解 词语小宝库

**写故事开头**
| 类别 | 词语 |
|:-----|:-----|
| 时间 | 有一天、昨天、记得那次 |
| 人物 | 我、我和同学、我和妈妈 |

**写道理**
- 明白了……
- 这让我懂得……
- 原来……真的会……

### 📝 □了解 示例

> **不做"寒号鸟"**
> 老师布置了周末作业，我心想：还有两天呢，不急！周六我玩了一天，周日早上又想：下午再做也来得及。到了周日下午，我看作业还有一大堆，急得直哭。妈妈陪我写到晚上11点才写完。
> **这件事让我明白：不能"得过且过"，事情要提前做！**

### ⚠️ □了解 常见问题

1. ❌ 只说道理没故事 → ✅ 一定要先写一件事
2. ❌ 道理和事情没关系 → ✅ 道理从事情中来

## 🔁 □了解 老朋友回来啦

本单元学了一些新字新词，其中有些是之前学过的"老朋友"。挑1-2个之前学过的生字，和爸妈一起说说"这个字之前在哪篇课文里见过？那个课文讲了什么？"

| 老朋友 | 在哪见过 | 复习提示 |
|:-------|:---------|:---------|
| （举例：青） | 一年级上册《青蛙写诗》 | "青蛙"用"青"+"蛙"组成，颜色家族（青→蓝/绿） |
