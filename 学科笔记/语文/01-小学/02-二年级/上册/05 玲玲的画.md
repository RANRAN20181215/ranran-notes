# 5 玲玲的画

> 第2/4篇 · 儿童生活 · 上篇《曹冲称象》与此篇同属第3单元，下篇《一封信》与此篇同属第3单元

> 部编版二上第5课 · 体会心情变化，读懂"坏事变好事" | 写话：写清一波三折

---

### 📖 □核心 课文一瞥

| 核心问题 | 主要内容 |
|:---------|:---------|
| 玲玲的画怎么了？最后怎么办的？ | 画被弄脏了→在脏处画只小花狗→画更好看了 |

**一句话速览**：玲玲画了一幅《我家的一角》，第二天要参加评奖。不小心把画弄脏了！她急得哭了——爸爸说，别哭，在脏的地方画点什么。玲玲画了一只小花狗，哇，比原来更好看了！

**□储备 单元关联**：本单元主题"儿童生活"。《曹冲称象》讲遇到难题动脑筋，《一封信》讲用不同方式表达爱，《妈妈睡了》讲用心观察家人的日常。读这篇时想一想——玲玲的"坏事变好事"靠的是什么？

### 🏗️ □核心 文章结构

```
画好 → 弄脏 → 哭了 → 爸爸出主意 → 画狗 → 更好
  ↓        ↓        ↓            ↓         ↓
 高兴     着急     伤心          想办法    满意
```

**一波三折**：高兴→难过→转机→更好，故事有起伏。

### 🌿 □了解 重点词语

| 词语 | 解释 | 例句 |
|:----|:-----|:-----|
| **评奖** | 评比谁最好 | 玲玲的画要参加评奖。 |
| **参加** | 加入某种活动 | 很多同学参加了画画比赛。 |
| **催促** | 催别人赶快 | 爸爸在一旁催促她。 |
| **满意** | 很满足、觉得好 | 玲玲满意地笑了。 |
| **糟糕** | 情况很不好 | 糟糕！画被弄脏了！ |
| **脑筋** | 思考的能力 | 玲玲动脑筋想办法。 |
| **弄脏** | 搞脏了 | 画被弄脏了，玲玲哭了。 |
| **肯定** | 确定、一定 | 爸爸肯定会称赞她。 |
| **懒洋洋** | 没精神的样子 | 小花狗懒洋洋地趴在画上。 |

| **好多事情** | 很多事 | 好多事情没有想象的那么糟。 |
| **坏事** | 不好的事情 | 坏事也能变成好事。 |

### ⚠️ □了解 易错字提醒

| 字 | 易错点 | 记忆口诀 |
|:---|:-------|:---------|
| **奖** | 下面是"大"，不是"犬" | 右上"夕"+"大"=奖 |
| **脏** | 左边是"月"，不是"贝" | 月字旁+"庄"=脏了 |
| **催** | 右边是"崔"，上面是"山" | 单人旁+"崔"=催促 |
| **懒** | 右边是"赖"，不是"懒"自己 | 竖心旁+"赖"=懒洋洋 |
| **糟** | 左边是"米"，右边是"曹" | 米+"曹"=糟糕 |

### 📝 □了解 词语采蜜集

**ABB式词语**：懒洋洋、笑眯眯、急匆匆、水灵灵

**近义词**：满意—满足、催促—催促、伤心—难过

**反义词**：满意—失望、坏事—好事、参加—退出

**好句**：好多事情并不像我们想象的那么糟。只要肯动脑筋，坏事也能变成好事。
