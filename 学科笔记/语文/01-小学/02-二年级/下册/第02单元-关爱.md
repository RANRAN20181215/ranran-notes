# 第二单元 · 关爱

> 雷锋叔叔在哪里？千人糕是怎么来的？一匹出色的马是什么？——这些故事里，藏着人与人之间的关爱。
> **阅读重点**：读句子，想画面
> **写话目标**：写清楚一件简单的事

## ✍️ 写话：写清楚一件简单的事

### 🎯 □核心 目标

用几句话写一件小事，把谁、什么时间、在哪里、做什么写清楚。
### 📐 写作支架

1. **时间**：什么时候
2. **人物**：谁
3. **地点**：在哪里
4. **事情**：做什么
5. **感受**：怎么样

### 🧩 □了解 词语小宝库
| 类别 | 词语 |
|:-----|:-----|
| 时间词 | 星期六、今天、放学后、一天 |
| 人物 | 我、妈妈、爸爸、同学、爷爷 |
| 地点 | 学校、家里、公园、路上 |
| 动作 | 帮忙、打扫、捡到、送给 |
| 感受 | 开心、温暖、自豪、高兴 |

### 📝 □了解 示例

> 星期六，我和妈妈去公园玩。我看见一位老奶奶提着重重的袋子，就走过去帮她提袋子。奶奶笑着说："谢谢你，小朋友！"我心里可高兴了。

### ⚠️ □了解 常见问题

1. ❌不写时间 → ✅"星期六""放学后"
2. ❌只写做什么没写感受 → ✅"心里暖暖的"

## 🗣️ 语文生活

**选做（任选一项）：**

1. **说一说**：和爸妈分享这个单元你觉得最有意思的一篇课文
2. **画一画**：为单元里最喜欢的故事画一幅插图，旁边写一两句话
3. **做一做**：在生活中找一找和本单元相关的内容，拍下来或记下来
4. **写一写**：用本单元学到的词语写一两句话
