# 第一单元 · 春天

> 春天来了——读古诗里的柳树和风筝，找田野里的春天，看开满鲜花的小路，听邓小平爷爷植树的故事。

## ✍️ 写话：用积累的词语写春天

### 🎯 □核心 目标

用本单元学到的词语，写一段关于春天的话。
### 🧩 □了解 词语小宝库
| 类别 | 词语 |
|:----|:-----|
| 天气 | 温暖、和煦、明媚 |
| 植物 | 嫩芽、柳枝、野花、小草 |
| 颜色 | 碧绿、粉红、嫩黄、湛蓝 |
| 动物 | 燕子、黄莺、蜜蜂、蝴蝶 |
| 四字词 | 绚丽多彩、兴致勃勃、引人注目 |

### 📐 写作支架

1. **开头**：春天来了/ 春天到了
2. **中间**：小草、野花、小鸟……写得越细越好
3. **结尾**：我喜欢春天

### 📝 □了解 示例

> 春天来了。小草从地下探出头来，嫩绿嫩绿的。野花开了，有红的、黄的、紫的，好看极了。小鸟在枝头叽叽喳喳地唱歌。温暖的阳光照在身上，真舒服呀！

### ⚠️ □了解 常见问题

1. 只写天气不写景物 → 可以写具体的东西：草、花、树、鸟
2. 只用"很漂亮、很好看" → 用具体词：碧绿、绚丽多彩、嫩绿
