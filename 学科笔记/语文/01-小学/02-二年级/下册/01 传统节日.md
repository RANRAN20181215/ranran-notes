# 1 传统节日

> 第1/3篇 · 传统文化 · 下篇《贝的故事》与此篇同属第三单元，是第三单元首篇

> 部编版二下识字第1课
> **阅读重点**：形声字归类识字
> **写话目标**：用词语写句子

---

### 📖 □核心 课文一瞥

| 核心问题 | 主要内容 |
|:---------|:---------|
| 一年中有哪些传统节日？每个节日做什么？ | 春节到元宵到清明……每个节日习俗不同 |

**一句话速览**：春节贴窗花放鞭炮，元宵看花灯吃汤圆，清明扫墓踏青，端午赛龙舟吃粽子，中秋赏月吃月饼，重阳登高赏菊——一年到头热热闹闹。

**□储备 单元关联**：本单元主题"传统文化"。《"贝"的故事》讲汉字里的文化密码，《中国美食》讲饮食里的文化。读这篇时想一想——传统节日为什么能一代代传下来？

### 🏗️ □核心 文章结构

```
节日时间线：
春节 → 元宵 → 清明 → 端午 → 七夕 → 中秋 → 重阳
（按时间顺序排列）
```

### 🌿 □了解 重点词语

| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **传统** | 从古流传下来的 | 春节是中国最重要的传统节日。 |
| **团圆** | 一家人聚在一起 | 除夕夜全家团圆吃年夜饭。 |
| **热闹** | 人很多、很欢乐 | 元宵节的大街上真热闹。 |
| **祭扫** | 祭祀、扫墓 | 清明节全家人去祭扫。 |
| **乞巧** | 向织女乞求巧手 | 七夕节女孩们穿针乞巧。 |
| **赏菊** | 观赏菊花 | 重阳节去赏菊。 |
| **登高** | 爬高 | 重阳节人们登高望远。 |

### 💡 节日时间线

| 节日 | 时间 | 做什么 |
|:----|:----|:-------|
| 春节 | 正月初一 | 贴窗花、放鞭炮 |
| 元宵节 | 正月十五 | 看花灯、吃元宵 |
| 清明节 | 4月5日左右 | 祭扫、踏青 |
| 端午节 | 五月初五 | 赛龙舟、吃粽子 |
| 七夕节 | 七月初七 | 乞巧 |
| 中秋节 | 八月十五 | 赏月、吃月饼 |
| 重阳节 | 九月初九 | 登高、赏菊 |
