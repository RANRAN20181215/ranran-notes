# 21 古诗三首

> 部编版四上第7单元 | 阅读重点：关注主要人物和事件，把握课文主要内容 | 习作目标：写信（应用文）

### 📖 课文讲了什么

三首古诗分别表达了王昌龄叹边关无良将、王翰写征战之豪迈、李清照讽南宋朝廷的家国情怀。

### ❤️ □了解 中心思想（给大人参考，不需要让孩子背诵）

**通过描写边塞生活和历史人物，表达了诗人的爱国情怀和忧国忧民之情。**

> 💡 读着玩——读顺了就好，感受节奏和画面。下面的分析内容是给大人参考的，孩子感兴趣就看，不感兴趣跳过。

### 👤 诗人与背景

| 项目 | 内容 |
|:-----|:-----|
| **王昌龄《出塞》** | |
| **作者** | 王昌龄（698-757），字少伯，盛唐边塞诗人 |
| **称号** | "七绝圣手"，以边塞诗和闺怨诗著称 |
| **代表作** | 《出塞》《从军行》《芙蓉楼送辛渐》 |
| **写作背景** | 王昌龄站在边关，看到秦汉时期的明月和关隘——从秦汉到唐代几百年了，边关的战事从未停息。那些远征的将士们，有多少人还能活着回家？他渴望有李广那样的"飞将军"来保卫边疆。这首诗被称为"唐人七绝的压卷之作"。 |
| **诗意** | 秦汉时的明月还是秦汉时的关，远征万里的将士还没回来。只要龙城飞将军李广还在，就不会让敌人骑兵越过阴山。 |
| **王翰《凉州词》** | |
| **作者** | 王翰（687-726），字子羽，盛唐边塞诗人 |
| **写作背景** | 凉州是边塞重镇，将士们在出征前痛饮美酒——"醉卧沙场君莫笑，古来征战几人回？"这种悲壮和豪放交织在一起，让人读罢热血沸腾又鼻头发酸。 |
| **诗意** | 精美的酒杯盛满了葡萄酒，正要喝时琵琶声响催人出发。醉倒在战场上你别笑——从古至今有几个人能活着回来？ |
| **李清照《夏日绝句》** | |
| **作者** | 李清照（1084-1155），号易安居士，宋代女词人 |
| **称号** | "千古第一才女"，婉约词派代表 |
| **代表作** | 《如梦令》《声声慢》《一剪梅》《夏日绝句》 |
| **写作背景** | 李清照生活在北宋末年，朝廷偏安江南，不思北伐。她想起项羽——兵败后无颜见江东父老，在乌江自刎。她用项羽的"宁死不屈"讽刺南宋朝廷的"苟且偷生"：活着要做人中豪杰，死了也要做鬼中英雄。 |
| **诗意** | 活着要做人中豪杰，死了也要做鬼中英雄。直到今天还思念项羽——他不肯回江东苟活。 |

### ✨ 写作亮点

| 序号 | 亮点 | 说明 |
|:-----|:-----|:-----|
| 1 | **互文手法** | "秦时明月汉时关"，两个词交叉表达 |
| 2 | **以乐写悲** | 葡萄美酒夜光杯，越是欢乐越显悲壮 |
| 3 | **借古讽今** | 说项羽不肯过江东，骂南宋朝廷逃跑 |
| 4 | **对仗有力** | "生当作人杰，死亦为鬼雄"，生死对仗 |

### 词语解释

| 词语 | 画面式解释 |
|:-----|:----------|
| 出塞 | 想象一下，一群将士骑着马走出边关的大门，走向一望无际的大沙漠，去保卫国家 |
| 秦 | 想象一下，你现在看到的月亮，在很久很久以前的秦朝，也是这样照着边关的将士们 |
| 征 | 想象一下，将士们告别家乡和亲人，走过千山万水，到遥远的边疆去打仗 |
| 人杰 | 想象一下，人群中最厉害的那个人——大家都佩服他，把他当作榜样 |
| 鬼雄 | 想象一下，就算变成了鬼，也是最勇敢的鬼，在另一个世界也是英雄好汉 |
