# 部编版六年级语文笔记

> 六年级是小学收官之年——阅读深度和写作难度都达到小学最高峰。
> 
> **识字量目标**：累计会认约3000+字、会写约2500+字。小学识字量到此封顶，初中不再教识字。六年级的词汇重点在于：理解文言文中的古今异义、掌握成语和熟语的准确用法。
> 涉及小说、散文、议论文、文言文、非连文本、革命题材、鲁迅作品等。

## 六年级写作进阶

| 学期 | 新高度 | 字数要求 |
|:---:|:-------|:---------|
| 上册 | 变形记、场面描写、微小说、倡议书、立意训练 | 450-500字 |
| 下册 | 风俗、梗概、真情、心愿、科幻、毕业告别 | 500-600字 |

> 六年的语文学习，从"识字写字"到"阅读写作"到"独立表达"——恭喜你走到小学的终点。
