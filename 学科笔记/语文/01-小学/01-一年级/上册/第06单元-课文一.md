# 第六单元 · 课文（一）

> 影子是好朋友，比尾巴真热闹，青蛙是个小诗人，雨点儿在空中聊天。
> **学习重点**：朗读问句和感叹句、认识拟人和比喻、理解自然现象
> **写话目标**：用"……像……"写一个比喻句

## 📌 单元总结

### 🔴 易错字提醒

| 字 | 易错点 | 口诀 |
|:--:|:-------|:-----|
| **在** | 里面是"土"不是"士" | 他在家，土地在家 |
| **后** | 里面是"口"不是"古" | 后面跟着口 |
| **我** | 笔顺：撇、横、竖钩、提、撇、竖钩、撇、点 | 我有戈，我会写 |
| **长** | 笔顺：撇、横、竖提、捺 | 长字一笔长 |
| **好** | 左边"女"的横变成提 | 女孩好，写字也要好 |
| **比** | 笔顺：横、竖提、撇、竖弯钩 | 比一比，不一样 |
| **巴** | 尾巴的"巴"封口 | 巴字封口，把字也封口 |
| **下** | 横要长，竖在横中间 | 下车了，横长长 |

### 🔀 形近字辨析

- **左**（左边）— **右**（右边）
- **后**（后面）— **石**（石头）
- **巴**（尾巴）— **把**（把手）
- **雨**（下雨）— **两**（两个）
- **问**（问号）— **同**（同学）

### 💬 句式积累

- **"……就像……"**：比喻句式——"影子就像一条小黑狗"
- **"谁的……？……的……"**：一问一答——"谁的尾巴长？猴子的尾巴长"
- **"……是……的"**：判断句式——"青蛙写诗的时候，小蝌蚪是逗号"
- **"……从……"**：来源句式——"雨点儿从云彩里飘落下来"
- **"数不清"**：表示很多——"数不清的雨点儿"

### 💭 道理与思辨

本单元是第一次正式进入"课文"学习，主题是**自然和想象**。《影子》用孩子的视角解释了影子和光的关系——有光才有影子，影子跟着人走。《比尾巴》用一问一答的形式介绍不同动物尾巴的特点。《青蛙写诗》最有创意——把大自然里的东西（小蝌蚪、水泡泡、荷叶上的水珠）想象成标点符号，让孩子在故事中认识标点。《雨点儿》用大小雨点儿的对话简单介绍了雨水的循环。

**想一想**：你观察过自己的影子吗？什么时候影子长，什么时候影子短？你还知道哪些动物的尾巴有什么作用？

### 🔗 跨文本对比

| 课文 | 主题 | 核心知识 | 写作手法 |
|:-----|:-----|:---------|:---------|
| 《影子》 | 光与影 | 前后左右方位 | 比喻"就像" |
| 《比尾巴》 | 动物特征 | 不同尾巴的特点 | 一问一答 |
| 《青蛙写诗》 | 标点符号 | 逗号、句号、省略号 | 拟人+想象 |
| 《雨点儿》 | 雨水循环 | 雨从哪里来到哪里去 | 对话+对比 |

四篇课文都充满了童趣和想象力，把自然现象用孩子能理解的方式表现出来，让孩子在阅读中学会观察自然、认识世界。

## 📝 写话：用"……像……"写一个比喻句

### 🎯 □核心 目标

学会用"像"字写出比喻句，把一样东西比作另一样东西。

### 📝 □了解 示例

> 影子就像一条小黑狗。

> 松鼠的尾巴好像一把伞。

> 彩虹像一座小桥。

### 🧩 □了解 词语小宝库

| 被比喻的事物 | 像什么 |
|:-------------|:-------|
| 影子 | 一条小黑狗 |
| 松鼠的尾巴 | 一把伞 |
| 月亮 | 小船、弯弯的香蕉 |
| 星星 | 宝石、眼睛 |
| 太阳 | 大火球 |
| 彩虹 | 小桥、彩带 |

### 📐 □了解 写作框架

1. **选一个事物**（月亮、星星、影子……）
2. **选一个相似的事物**（小船、宝石、小黑狗……）
3. **用"像"连接起来**

______像______。

### ⚠️ □了解 常见问题

1. ❌ 没有相似之处 → ✅ 月亮像小船（都是弯弯的），不能说"月亮像苹果"
2. ❌ 忘了加"像" → ✅ "……像……"，"像"字不能少
3. ❌ 比喻不生动 → ✅ 选孩子熟悉的东西来比

## □核心 字词句运用

认识标点符号：
- 问号（？）：表示疑问——"你是谁？"
- 感叹号（！）：表示强烈感情——"真好呀！"

读一读，读出不同的语气：
- 影子是我的好朋友。（陈述）
- 影子在哪里？（疑问）
- 影子真好玩！（感叹）
