# 4 d t n l

> 部编版一上

### 📖 □核心 课文一瞥

| 学什么 | 内容 |
|:-------|:-----|
| 4个声母 | d、t、n、l |
| 两拼音节 | 声母+韵母拼读 |

**口诀**：马蹄声响 d d d，伞把弯弯 t t t，一个门洞 n n n，一根木棍 l l l。

---

### 🔤 □了解 声母 + 拼读

| 声母 | 口诀 | 拼读练习 |
|:----:|:-----|:---------|
| d | 马蹄声响 d d d | dā（搭）、dá（答）、dì（地）、dú（读） |
| t | 伞把弯弯 t t t | tā（他）、tǔ（土）、tī（踢）、tù（兔） |
| n | 一个门洞 n n n | nǎ（哪）、nǚ（女）、ní（泥）、nú（奴） |
| l | 一根木棍 l l l | lā（拉）、lǜ（绿）、lǐ（里）、lù（路） |

---

### 📋 □了解 自评表

| 评价维度 | 我能…… | ⭐⭐⭐ |
|:---------|:-------|:------|
| **读** | 正确读出d t n l | □ |
| **拼** | 用d t n l和韵母拼读 | □ |
| **写** | 在四线格中正确书写 | □ |
| **特别** | 能分清d和b（方向不同） | □ |

### 🤔 □核心 想一想

- d和b长得像不像？你怎么区分它们？
- n和l发音不一样，你分得清吗？试试读"牛"和"刘"。
- d和b长得这么像，你有什么好办法分清它们？

### 🔗 □储备 单元关联

本单元（拼音二）继续学声母。d t n l 和上一课的 b p m f 都是声母。你发现了吗？d和b长得有点像——都是圆圈加竖，只是方向不同。你能分清吗？试试看，dǐ 和 bǐ 读起来有什么不一样？

### 🗣️ □了解 拼一拼

d-ì→dì（地） t-ǔ→tǔ（土） n-ǚ→nǚ（女） l-ǜ→lǜ（绿）
用这些字说一句话："地上有绿色的土地。"试试看！
