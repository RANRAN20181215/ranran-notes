# 7 z c s

> 部编版一上

### 📖 □核心 课文一瞥

| 学什么 | 内容 |
|:-------|:-----|
| 3个声母 | z、c、s |
| 两拼音节 | 声母+韵母拼读 |

**口诀**：娃娃写字 z z z，刺猬弯腰 c c c，蚕儿吐丝 s s s。

---

### 🔤 □了解 声母 + 拼读

| 声母 | 口诀 | 拼读练习 |
|:----:|:-----|:---------|
| z | 娃娃写字 z z z | zì（字）、zǔ（组）、zuò（做） |
| c | 刺猬弯腰 c c c | cā（擦）、cū（粗）、cuò（错） |
| s | 蚕儿吐丝 s s s | sī（丝）、sù（速）、suǒ（所） |

---

### 📋 □了解 自评表

| 评价维度 | 我能…… | ⭐⭐⭐ |
|:---------|:-------|:------|
| **读** | 正确读出z c s | □ |
| **拼** | 用z c s和韵母拼读 | □ |
| **写** | 在四线格中正确书写 | □ |
| **特别** | 知道舌头是平的（平舌音） | □ |

### 🤔 □核心 想一想

- z c s 的舌头放在哪里？和后面要学的 zh ch sh（翘舌音）有什么不同？
- "字"和"子"的拼音分别是 zì 和 zǐ——声调不一样，意思就不一样。
- 平舌音和翘舌音的区别你觉得难吗？你打算用什么办法记住它？

### 🔗 □储备 单元关联

本单元（拼音二）继续学声母。z c s 读的时候舌头是放在哪里的？是平的还是翘起来的？试试看，读z的时候舌尖顶着哪儿？后面要学的 zh ch sh 和它们不一样哦。你能提前猜猜看，翘舌音和平舌音的区别在哪吗？

### 🗣️ □了解 拼一拼

z-ì→zì（字） c-ā→cā（擦） s-ī→sī（丝）
用"擦"说一句话："我擦桌子。"用"字"说一句话："我认识很多字。"
