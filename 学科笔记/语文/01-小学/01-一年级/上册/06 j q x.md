# 6 j q x

> 部编版一上

### 📖 □核心 课文一瞥

| 学什么 | 内容 |
|:-------|:-----|
| 3个声母 | j、q、x |
| 两拼音节 | 声母+韵母拼读 |

**口诀**：鸡追蝴蝶 j j j，七个气球 q q q，刀切西瓜 x x x。

---

### 🔤 □了解 声母 + 拼读

| 声母 | 口诀 | 拼读练习 |
|:----:|:-----|:---------|
| j | 鸡追蝴蝶 j j j | jī（鸡）、jú（菊）、jǔ（举）、jù（句） |
| q | 七个气球 q q q | qī（七）、qí（骑）、qǔ（取）、qù（去） |
| x | 刀切西瓜 x x x | xī（西）、xí（习）、xǐ（洗）、xì（戏） |

---

### 📋 □了解 自评表

| 评价维度 | 我能…… | ⭐⭐⭐ |
|:---------|:-------|:------|
| **读** | 正确读出j q x | □ |
| **拼** | 用j q x和韵母拼读 | □ |
| **知** | 知道j q x和ü相拼要去掉两点 | □ |
| **特别** | j q x和ü拼时能正确去掉两点 | □ |

### 🤔 □核心 想一想

- j q x 和 ü 相拼时去掉两点，但 ü 还是读 ü，不是 u。你觉得为什么这样规定？
- j-ǘ 拼出来是 jú（菊），如果不去掉两点写成 j-ǘ→jú，你觉得方便吗？
- j q x 和 ü 的拼写规则有点绕，你觉得自己掌握了吗？有什么办法帮自己记住？

### 🔗 □储备 单元关联

本单元（拼音二）声母 j q x 非常特别。还记得之前在 i u ü 课里提到过"ü碰到j q x要去掉两点"吗？现在你见到 j q x 本人了，试试拼一拼 j-ǘ 和 j-ú，感觉一下去掉两点的规则是方便了我们还是为难了我们？

### 🗣️ □了解 拼一拼

j-ǘ→jú（菊） q-ù→qù（去） x-ǚ→xǔ（许）
x-ī→xī（西） j-ī→jī（鸡） q-ī→qī（七）
用"七"和"鸡"说一句话："七只小鸡在草地上。"
