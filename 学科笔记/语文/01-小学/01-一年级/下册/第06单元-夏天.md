# 第六单元 · 夏天

> 古诗二首、荷叶圆圆、要下雨了、浪花——夏天的池塘边，藏着好多小秘密。
> **阅读重点**：感受夏天的美好，体会比喻句的生动
> **写话目标**：用几句话描写夏天的景色或事物

## 📌 单元总结

### 🔴 易错字提醒

| 字 | 易错点 | 口诀 |
|:--:|:-------|:-----|
| **首** | 上面是"丷" + 一横，不是两点一横 | 头上两笔是头发 |
| **采** | 上面是"爪"（爫），不是"一" | 用手（爪）在树上采 |
| **树** | 中间是"又"，不要漏了 | 树（木+又+寸）要细心 |
| **爱** | 下面是"友"，不是"又" | 爱（爫+冖+友）要有朋友 |
| **尖** | 上面是"小"，下面是"大" | 上小下大就是尖 |
| **角** | 笔顺：撇、横撇、撇、横折钩、横、横、竖 | 牛的角是弯的 |
| **鱼** | 下面是"一"，不是"工" | 鱼尾巴摆一摆 |

### 🔀 形近字辨析

- **首**（首先）— **道**（道路）
- **采**（采花）— **菜**（白菜）
- **树**（大树）— **对**（对错）
- **爱**（爱护）— **受**（接受）
- **角**（角落）— **用**（有用）
- **浪**（浪花）— **娘**（姑娘）
- **加**（加法）— **架**（书架）

### 📚 词语采蜜集

| 类别 | 词语 |
|:-----|:------|
| 夏天景物 | 荷叶、荷花、泉眼、浪花、池塘 |
| 昆虫动物 | 蜻蜓、青蛙、小鱼、燕子、蚂蚁 |
| 动作 | 采莲、歌唱、游水、搬家、奔跑 |

| 象声词 | 哗哗、咕咚、呱呱 |

### 💬 句式积累

- **"……像……"比喻句式**："浪花像调皮的娃娃。"——把浪花比作人
- **"……的……的……"句式**："荷叶圆圆的，绿绿的。"——两个"的"连用，生动具体
- **"因为……所以……"（暗含）**：因为要下雨了，所以燕子低飞——因果关系
- **"……来……去"句式**："鱼儿游来游去"——动作反复

### 💭 道理与思辨

本单元带领学生走进夏天。《古诗二首》展现了夏日池塘的**画面美**——小娃偷莲的童趣，泉眼细流的宁静；《荷叶圆圆》用**童话的眼光**看荷叶——它既是摇篮又是停机坪；《要下雨了》是**自然科普**——燕子低飞、鱼游水面、蚂蚁搬家都是下雨前的征兆；《浪花》用**拟人的手法**写海浪——把浪花比作调皮的娃娃。

夏天不仅有炎热，更有生机勃勃的美。大自然也是一本"书"，教会我们许多知识。

**想一想**：下雨前你还见过哪些现象？你觉得荷叶还像什么？你见过大海吗？浪花是什么样子的？

### 🔗 跨文本对比

| 课文 | 体裁 | 描写对象 |
|:-----|:-----|:---------|
| 《古诗二首》 | 古诗 | 池塘夏日景致 |
| 《荷叶圆圆》 | 散文 | 荷叶与小动物的关系 |
| 《要下雨了》 | 科普童话 | 下雨前的自然现象 |
| 《浪花》 | 散文 | 海浪的调皮可爱 |

四篇课文从"古→今""静→动""景→物"，多角度展现了夏天的美好。

## 📝 写话：描写夏天

### 🎯 目标

用"荷叶/浪花/池塘"等词语，写两三句描写夏天的话。

### 📝 示例

> 夏天到了，池塘里的荷叶圆圆的、绿绿的。青蛙在荷叶上呱呱叫，小鱼在水里游来游去。夏天的池塘真美呀！

### 🧩 词语小宝库

| 夏天的东西 | 用哪些词形容 |
|:-----------|:------------|
| 荷叶 | 圆圆的、绿绿的、像一把伞 |
| 荷花 | 粉红的、香香的、开了 |
| 太阳 | 红红的、火辣辣的 |
| 池塘 | 清清的、凉凉的 |
| 浪花 | 白白的、调皮的、哗哗响 |

### ⚠️ 常见问题

1. ❌ 只说"夏天很热"太简单 → ✅ 写出夏天特有的景物（荷叶、荷花、浪花）
2. ❌ 忘记用叠词 → ✅ 多用"圆圆的、绿绿的、清清的"更生动
