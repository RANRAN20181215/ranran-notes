> 动物儿歌、古对今、操场上、人之初——在有趣的儿歌和对韵中快乐识字。

## 📌 单元总结

### 🔴 易错字提醒

| 字 | 易错点 | 口诀 |
|:--:|:-------|:-----|
| **间** | 里面是"日"，不是"目" | 门里有太阳（日） |
| **迷** | 里面是"米"，不是"来" | 迷路的人找米吃 |
| **运** | 里面是"云"，不是"去" | 运东西就像云飘走 |
| **网** | 里面是"××"，不要漏了叉 | 网里有叉叉 |
| **古** | 上面是"十"，下面是"口" | 十张口讲古代故事 |
| **身** | 笔顺复杂，中间两横不封口 | 身体是立着的 |
| **之** | 一笔点，二笔横撇，三笔捺 | 之字形，像小路 |

### 🔀 形近字辨析

- **间**（中间）— **问**（问好）
- **迷**（迷人）— **迹**（足迹）
- **网**（上网）— **门**（门口）
- **古**（古代）— **故**（故事）
- **凉**（凉水）— **惊**（吃惊）
- **跑**（跑步）— **抱**（拥抱）
- **体**（身体）— **休**（休息）

### 🔊 多音字

| 字 | 读音与用法 | 例句 |
|:--:|:-----------|:------|
| **空** | kōng（天空）、 kòng（有空） | 蜻蜓半空(kōng)展翅飞 |
| **结** | jiē（结果）、 jié（结网） | 蜘蛛结(jié)网忙 |
| **教** | jiào（教师）、 jiāo（教书） | 玉不琢，不成器，人不学，不知义——教(jiào)育很重要 |
| **处** | chù（到处）、 chǔ（处理） | 到处(chù)都是快乐 |

### 🏷️ 偏旁归类

| 偏旁 | 汉字 | 表义特点 |
|:----:|:-----|:---------|
| **虫**（虫字旁） | 蜻、蜓、蚂、蚁、蜘、蛛 | 和昆虫有关 |
| **扌**（提手旁） | 拔、拍、打、找 | 和手的动作有关 |
| **⻊**（足字旁） | 跑、跳、踢、路 | 和脚的动作有关 |
| **辶**（走之底） | 运、迷、造、过 | 和行走/移动有关 |
| **冫**（两点水） | 凉、冰、冷 | 和寒冷有关 |
| **氵**（三点水） | 池、澡、洗 | 和水有关 |

### 📚 词语采蜜集

| 类别 | 词语 |
|:-----|:------|
| 动物 | 蜻蜓、蝴蝶、蚯蚓、蚂蚁、蝌蚪、蜘蛛 |
| 自然 | 严寒、酷暑、春暖、秋凉、朝霞、夕阳 |
| 运动 | 打球、跑步、踢足球、跳高、拔河、拍皮球 |
| 三字经 | 人之初、性本善、习相远、贵以专 |
| 对对子 | 古对今、圆对方、严寒对酷暑、春暖对秋凉 |

### 💬 句式积累

- **"谁+在哪儿+干什么"句式**："蜻蜓半空展翅飞，蝴蝶花间捉迷藏。"——完整的叙事句子
- **对偶句式**："古对今，圆对方。严寒对酷暑，春暖对秋凉。"——工整的对仗
- **三字经句式**："人之初，性本善。性相近，习相远。"——三字一句，朗朗上口
- **"……真……"句式**："操场上真热闹。"——表达感受

### 💭 道理与思辨

本单元是第二个识字单元，识字量更大，识字方法更丰富。《动物儿歌》运用**形声字规律**——虫字旁加上不同的声旁就能认识一串昆虫的名字；《古对今》在**对韵中识字**——对仗工整、朗朗上口；《操场上》**按偏旁归类**——提手旁和足字旁带出与动作相关的字；《人之初》选自**《三字经》**——诵读经典，识字的同时学做人的道理。

"玉不琢，不成器，人不学，不知义。"——学习很重要，要从小养成好习惯。

**想一想**：你还能举出其他形声字吗？（比如"包"字加偏旁：泡、炮、跑、抱……）你在操场上喜欢玩什么？为什么？

### 🔗 跨文本对比

| 课文 | 识字内容 | 识字方法 |
|:-----|:---------|:---------|
| 《动物儿歌》 | 昆虫名称 | 形声字（虫字旁） |
| 《古对今》 | 自然现象、事物 | 对韵中识字 |
| 《操场上》 | 体育活动相关字 | 偏旁归类（扌/⻊） |
| 《人之初》 | 经典语句中的字 | 诵读识字 |

四篇课文从"动物→自然→运动→做人"，内容从具体到抽象，识字方法也从形声规律到经典诵读。

## 📝 写话：用"谁在什么地方干什么"写几句话

### 🎯 目标

模仿《动物儿歌》的句式，用"谁在什么地方干什么"写两三句话。

### 📝 示例

> 小鸟在树上唱歌。小鱼在水里游来游去。小朋友在操场上跑步。大家都很开心。

### 🧩 词语小宝库

| 谁 | 在什么地方 | 干什么 |
|:---|:-----------|:-------|
| 小鸟 | 树上 | 唱歌、做窝 |
| 小鱼 | 水里 | 游来游去、吐泡泡 |
| 小朋友 | 操场上 | 跑步、跳绳、踢球 |
| 小猫 | 房间里 | 睡觉、追毛线球 |

### ⚠️ 常见问题

1. ❌ 忘记写"在什么地方" → ✅ 谁+在哪儿+干什么，三个部分缺一不可
2. ❌ 每句话太雷同 → ✅ 换不同的"谁"和不同的动作
