# 第二单元 · 心愿

> 吃水不忘挖井人、我多想去看看、四个太阳——每个人的心里都藏着一个美好的心愿。
> **阅读重点**：读好长句子，体会人物的情感
> **写话目标**：用"我多想……"写一个小愿望

## 📌 单元总结

### 🔴 易错字提醒

| 字 | 易错点 | 口诀 |
|:--:|:-------|:-----|
| **吃** | 右边是"乞"，不是"气" | 吃（口+乞）东西要张口 |
| **忘** | 上面是"亡"，下面是"心" | 忘记是因为没放在心上 |
| **井** | 两横一竖撇，没有捺 | 水井挖得直直的 |
| **想** | 下面是"心"字底 | 用心去想 |
| **太** | 比"大"多一点 | 太阳比"大"还要多一点 |
| **阳** | 左边是"阝"（左耳旁） | 太阳在左边升起 |

### 🔀 形近字辨析

- **吃**（吃饭）— **渴**（口渴）
- **井**（水井）— **开**（开心）
- **叫**（大叫）— **听**（听见）
- **主**（主人）— **王**（大王）
- **以**（以后）— **从**（从前）
- **这**（这里）— **过**（过去）

### 🔊 多音字

| 字 | 读音与用法 | 例句 |
|:--:|:-----------|:------|
| **觉** | jué（觉得）、 jiào（睡觉） | 我觉(jué)得春天很美丽 |
| **只** | zhǐ（只有）、 zhī（一只） | 我只(zhǐ)想画一个太阳 |
| **为** | wèi（因为）、 wéi（作为） | 因为(wèi)有太阳，世界才光明 |

### 🏷️ 偏旁归类

| 偏旁 | 汉字 | 表义特点 |
|:----:|:-----|:---------|
| **⻊**（足字旁） | 路、跑、跳 | 和脚的动作有关 |
| **心**（心字底） | 想、忘、念 | 和心理活动有关 |
| **阝**（左耳旁） | 阳、阴、队 | 和地形/位置有关 |
| **⻌**（走之底） | 这、过、道 | 和行走/移动有关 |
| **日**（日字旁） | 阳、时、暖 | 和太阳/光亮有关 |

### 📚 词语采蜜集

| 类别 | 词语 |
|:-----|:------|
| 感恩 | 吃水不忘挖井人、想念、感谢 |
| 心愿 | 多想、想去、希望、愿望 |
| 颜色 | 绿绿的、金黄的、红红的、彩色的 |
| 四季 | 春天、夏天、秋天、冬天、温暖 |

### 💬 句式积累

- **"我多想……"句式**："我多想去看看，我多想去看看！"——表达强烈愿望
- **"因为……所以……"句式（暗含）**：因为想吃果子→所以画个太阳
- **"……的……"短语**：弯弯的小路、遥远的北京城、雄伟的天安门
- **"AABB式"重叠**：安安静静、快快乐乐

### 💭 道理与思辨

本单元的主题是"心愿"。《吃水不忘挖井人》告诉我们**饮水思源**——得到了帮助要记得感恩；《我多想去看看》表达了对外面世界的**向往**——每个人都有自己想去的地方；《四个太阳》充满了**想象力**——把美好的愿望画进四季里。

三个心愿各不相同：一个是感恩的心愿，一个是探索的心愿，一个是分享的心愿。心愿不分大小，都是心里最美好声音。

**想一想**：你有什么心愿？你最想去哪里看看？如果你画一个太阳，你会画什么颜色的？

### 🔗 跨文本对比

| 课文 | 主题 | 情感 |
|:-----|:-----|:------|
| 《吃水不忘挖井人》 | 感恩与奉献 | 温暖、感激 |
| 《我多想去看看》 | 向往与探索 | 期盼、渴望 |
| 《四个太阳》 | 想象与关怀 | 快乐、分享 |

三篇课文从"记得别人的好→想去没去过的地方→把美好分给四季"，展现了心愿的不同层次。

## 📝 写话：用"我多想……"写一个小愿望

### 🎯 目标

用"我多想……"写几句话，表达自己的一个小愿望。

### 📝 示例

> 我多想快点儿长大。长大了就可以自己出去玩了，可以去看大海，还可以去爬长城。我多想快点儿长大呀！

### 🧩 词语小宝库

| 想去哪里 | 为什么 |
|:---------|:-------|
| 北京/天安门 | 看看升国旗 |
| 大海 | 看看浪花、捡贝壳 |
| 公园 | 放风筝、划船 |
| 外婆家 | 吃好吃的 |

### ⚠️ 常见问题

1. ❌ 只说"我多想……"不说明白 → ✅ "我多想……"+"因为/就可以……"
2. ❌ 句子太短没写具体 → ✅ 用一两句话说说"想做什么"
