# 9 古诗三首

> 第1/4篇 · 中华传统文化 · 下篇《纸的发明》与此篇同属第3单元，是第3单元首篇

> 部编版三下第9课
> **阅读重点**：围绕一个意思把一段话写清楚
> **习作目标**：中华传统节日（综合性学习）

### 📖 □核心 课文讲了什么

三首古诗分别描写了三个传统节日——王安石写春节除旧迎新，杜牧写清明雨中问路，王维写重阳思念家乡。

**一句话速览**：王安石化用春风表达改革决心、杜牧借清明写行人的愁绪、王维在重阳节思念远方的兄弟。

**□储备 单元关联**：本单元主题"传统文化"。《纸的发明》讲古人的科技智慧，《赵州桥》讲古人的建筑智慧，《一幅名扬中外的画》讲古人的艺术智慧。读这篇时想一想——三首古诗分别写了哪三个传统节日？

---

### 💬 □核心 作者想说的话
- 想想：3首古诗都写传统节日，但诗人的情感各有侧重——你最直接感受到了哪一种？
- 核心信息：

**《元日》** 借春节放爆竹、饮屠苏、换桃符的习俗，暗含王安石推行新政的抱负——除旧迎新，万象更新。
**《清明》** 写清明雨中的行人愁绪，不着一个"愁"字，却让哀思弥漫在字里行间。
**《九月九日忆山东兄弟》** 抒写异乡游子在重阳节的孤独感，"每逢佳节倍思亲"道尽千古游子的心声。

> 三首诗都写传统节日，但诗人的情感各有侧重：王安石借节日言志，杜牧写节日的忧伤，王维写节日里的思念。**避免笼统概括为"热爱传统文化"。**

> 💡 **进阶阅读**（可跳过）—— 感兴趣再读，不影响孩子理解诗意
### 👤 诗人档案

**王安石《元日》**：

| 项目 | 内容 |
|:-----|:-----|
| **作者** | 王安石（1021–1086），字介甫，号半山，北宋政治家、文学家 |
| **称号** | "唐宋八大家"之一 |
| **代表作** | 《泊船瓜洲》《梅花》《登飞来峰》 |
| **写作背景** | 王安石被宋神宗重用，开始推行"熙宁变法"。这一年春节，他心情激动——新法就像新年换桃符一样，辞旧迎新。这首诗表面写春节习俗：放爆竹、喝屠苏酒、换桃符，实际上写的是政治改革 |
| **诗意** | 爆竹声中旧一年过去了，春风送暖喝着屠苏酒。千家万户沐浴在初升的太阳里——每年都用新桃符换下旧的 |

**杜牧《清明》**：

| 项目 | 内容 |
|:-----|:-----|
| **作者** | 杜牧（803–852），字牧之，详见三上第4课 |
| **写作背景** | 杜牧在清明时节出门踏青，偏偏遇上了绵绵春雨。路上的行人被雨淋湿，又思念逝去的亲人，心情更加忧伤。这时他遇到一个牧童——"请问哪里有酒家？"牧童指了指远处的杏花村。这首诗没有用一个"愁"字，但忧伤全在其中 |
| **诗意** | 清明时节细雨纷纷，路上的行人好像断了魂一样。问牧童哪里有酒家，牧童指了指远处的杏花村 |

**王维《九月九日忆山东兄弟》**：

| 项目 | 内容 |
|:-----|:-----|
| **作者** | 王维（701–761），字摩诘，唐代山水田园诗人 |
| **称号** | "诗佛"，与孟浩然并称"王孟" |
| **代表作** | 《山居秋暝》《使至塞上》《鸟鸣涧》《送元二使安西》 |
| **写作背景** | 王维17岁那年独自在长安漂泊。九月九日重阳节，兄弟姐妹们都在老家登高、插茱萸，只有他一个人在异乡。他写下"每逢佳节倍思亲"——这句话后来成了中国文化中最经典的思乡诗句 |
| **诗意** | 独自在异乡做异客，每到节日就加倍思念亲人。想到兄弟们登高插茱萸——只有我一个人不在 |

### 🖼️ 词语解释

| 词语 | 画面式解释 |
|:-----|:----------|
| 屠苏 | 想象一下，全家围在一起，每人端起一杯暖暖的酒，"咕咚"喝下一口，身子一下就热了 |
| 曈曈 | 想象一下，初升的太阳把金光洒在每家的屋顶上，整个世界都亮堂堂的 |
| 桃符 | 想象一下，家家户户门框两边贴着红色的春联，崭新崭新的，在晨光里格外鲜艳 |
| 纷纷 | 想象一下，细细密密的雨丝飘下来，像一层薄薄的雾，打在脸上凉凉的 |
| 断魂 | 想象一下，行人低着头走在雨里，心里闷闷的、酸酸的，好像丢了什么东西 |
| 借问 | 想象一下，诗人弯下腰，客气地跟路边的小孩打听："小朋友，附近有喝酒的地方吗？" |
| 异客 | 想象一下，一个少年孤零零地站在陌生的街头，周围的一切都不认识，心里空落落的 |
| 倍 | 想象一下，平时也会想家，可一到过节，想念就像潮水一样涌上来，比平时多得多 |
| 茱萸 | 想象一下，兄弟们都摘下一枝带香味的紫色小果子插在头上，热闹地往山上走 |

### □储备 1️⃣ 元日 · 王安石

#### 🎙️ 朗读提示

| 方面 | 指导 |
|:-----|:-----|
| **基调** | 喜庆欢快，充满希望 |
| **节奏** | 爆竹/声中/一岁除，春风/送暖/入屠苏。千门/万户/曈曈日，总把/新桃/换旧符。 |
| **重音** | 一岁除、送暖、入屠苏、曈曈日、换旧符 |
| **语气** | 前两句欢快热烈——读"爆竹声中"稍快，营造热闹气氛；第三句开阔明亮，"曈曈日"拉长，仿佛太阳升起；末句昂扬有力，"换旧符"一字一顿，读出除旧迎新的决心 |
| **🍃 读着玩** | 先读顺了，其他再说 |

#### ✨ 写法分析：感官并用+一语双关

| 阅读要点 | 写法分析 | 写作小技巧 |
|:---------|:---------|:-----------|
| 爆竹声（听觉）、春风暖（触觉）、曈曈日（视觉） 🎆 | 多感官描写节日气氛 | 写节日要调动多种感官 |
| "新桃换旧符" 🔄 | 既写习俗又写改革 | 可以一语双关 |

### □储备 2️⃣ 清明 · 杜牧

#### 🎙️ 朗读提示

| 方面 | 指导 |
|:-----|:-----|
| **基调** | 忧伤低沉，含蓄哀愁 |
| **节奏** | 清明/时节/雨纷纷，路上/行人/欲断魂。借问/酒家/何处有，牧童/遥指/杏花村。 |
| **重音** | 雨纷纷、欲断魂、何处有、遥指、杏花村 |
| **语气** | 前两句低沉缓慢——"雨纷纷"轻读，如细雨绵绵；"欲断魂"放慢，读出黯然神伤。第三句略扬，带着一丝急切（想找个地方避雨解愁）；末句渐慢，"遥指"后稍作停顿，"杏花村"轻收，余韵悠长 |
| **🍃 读着玩** | 先读顺了，其他再说 |

#### ✨ 写法分析：情景交融+问答结构

### ✍️ 本单元习作：中华传统节日（综合性学习）

**习作目标**：选一个传统节日，收集资料，了解节日的来历、习俗，写一篇介绍文章。

**写作框架**：
1. 节日名称和时间
2. 节日的来历
3. 节日的习俗
4. 我是怎么过节的
5. 节日感受

**范文**：

> **热闹的春节**
>
> "爆竹声中一岁除，春风送暖入屠苏。"我最喜欢的节日就是春节。它在每年的正月初一。
>
> 传说古时候有一种叫"年"的怪兽，每年除夕出来伤害百姓。后来人们发现它怕红色和响声，于是就有了贴春联、放鞭炮的习俗。
>
> 春节的习俗可多了！大年三十，我和爸爸一起贴春联、挂灯笼。奶奶包了好多饺子，还在里面藏了一枚硬币——谁吃到谁就有好运！晚上全家人围在一起看春晚，守岁到十二点。
>
> 大年初一，我穿上新衣服给长辈拜年，收到好多红包。院子里噼里啪啦的鞭炮声响个不停，到处喜气洋洋。
>
> 春节是最热闹、最温暖的节日，我喜欢春节！ |
