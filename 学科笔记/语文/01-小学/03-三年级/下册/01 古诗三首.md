# 1 古诗三首

> 第1/4篇 · 可爱的生灵 · 下篇《燕子》与此篇同属第1单元，是第1单元首篇

> 部编版三下第1课
> **阅读重点**：边读边想象画面
> **习作目标**：我的植物朋友（观察卡片→作文）
> 💡 读着玩——读顺了就好，感受节奏和画面

---

### 📖 □核心 课文讲了什么

三首古诗分别描写了春天和初夏的美丽景象——杜甫写春日燕子鸳鸯，苏轼题画中春江鸭戏，曾几记初夏山行绿荫。

**一句话速览**：杜甫写春日暖阳燕子飞、苏轼题画中春江鸭戏水、曾几记初夏山行绿荫添黄鹂。

**□储备 单元关联**：本单元主题"可爱的生灵"。《燕子》写燕子轻盈的身姿，《荷花》写荷花的千姿百态，《昆虫备忘录》写昆虫的奇妙。读这篇时想一想——三位诗人写的"生灵"有什么相同和不同？

### 🎤 朗读提示

**绝句 · 杜甫**

| 要素 | 建议 |
|:-----|:-----|
| **基调** | 明快温暖，宁静喜悦 |
| **节奏** | 迟日/江山/丽，春风/花草/香。泥融/飞燕子，沙暖/睡鸳鸯 |
| **重音** | 丽、香、飞、睡 |
| **语气** | 前两句舒展，读出春风拂面的温暖感；后两句一动一静，"飞"轻快"睡"轻柔 |
| **🍃 读着玩** | 先读顺了，其他再说 |

**惠崇春江晚景 · 苏轼**

| 要素 | 建议 |
|:-----|:-----|
| **基调** | 清新自然，充满生机 |
| **节奏** | 竹外/桃花/三两枝，春江/水暖/鸭先知。蒌蒿/满地/芦芽短，正是/河豚/欲上时 |
| **重音** | 三两枝、鸭先知、芦芽短、欲上时 |
| **语气** | 前两句轻松活泼，读出发现春天的小惊喜；后两句稍平稳，"欲上时"略扬——想到河豚逆流而上，充满期待 |
| **🍃 读着玩** | 先读顺了，其他再说 |

**三衢道中 · 曾几**

| 要素 | 建议 |
|:-----|:-----|
| **基调** | 轻松愉悦，明快悠然 |
| **节奏** | 梅子/黄时/日日晴，小溪/泛尽/却山行。绿阴/不减/来时路，添得/黄鹂/四五声 |
| **重音** | 日日晴、却山行、不减、四五声 |
| **语气** | 前两句读出出行顺利的轻松——本担心梅雨天却日日晴；后两句读出惊喜——绿阴不减还多了黄鹂声，"四五声"读得轻快 |
| **🍃 读着玩** | 先读顺了，其他再说 |

### 🖼️ 词语解释

| 词语 | 画面式解释 |
|:-----|:----------|
| 迟日 | 想象一下，春天的太阳暖暖的，在天上待得特别久，好像舍不得下山 |
| 泥融 | 想象一下，春雨过后，泥土软软的、湿湿的，燕子用嘴一啄就能叼起一小块 |
| 鸳鸯 | 想象一下，一对彩色的水鸟挨在一起，在温暖的沙滩上闭着眼打盹 |
| 蒌蒿 | 想象一下，江边的地上长满了嫩绿的野草，一片一片的，铺得满地都是 |
| 芦芽 | 想象一下，水边冒出一根根细细的、尖尖的芦苇嫩芽，像一根根绿色的小铅笔 |
| 河豚 | 想象一下，胖胖的河豚正从大海往上游游去，肚子鼓鼓的，正要产小宝宝 |
| 泛尽 | 想象一下，小船沿着小溪一直划呀划，划到了溪水的尽头，再也划不动了 |
| 却山行 | 想象一下，船到尽头了，诗人下了船，转身走上山间小路 |
| 绿阴 | 想象一下，两旁的树又高又密，阳光只能从树叶的缝隙里漏下来，地上全是绿色的影子 |

### 👤 诗人档案

**杜甫《绝句》**：

| 项目 | 内容 |
|:-----|:-----|
| **作者** | 杜甫（712–770），字子美，唐代伟大的现实主义诗人 |
| **称号** | "诗圣"，与李白并称"李杜" |
| **代表作** | 《春望》《茅屋为秋风所破歌》《三吏》《三别》 |
| **创作风格** | 沉郁顿挫，忧国忧民，但写景诗也清新明丽 |
| **写作背景** | 杜甫晚年漂泊到成都，在浣花溪畔建了草堂。一个春日，他看到泥土被春雨濡湿，燕子衔泥筑巢；沙滩被太阳晒暖，鸳鸯悠闲入睡。战乱中的片刻安宁让他写下了这首明快的小诗 |
| **诗意** | 迟日江山沐浴着春光，春风送来花草的芬芳。泥土湿润燕子飞来飞去，沙滩温暖鸳鸯成对睡觉 |

**苏轼《惠崇春江晚景》**：

| 项目 | 内容 |
|:-----|:-----|
| **作者** | 苏轼（1037–1101），字子瞻，号东坡居士 |
| **称号** | "唐宋八大家"之一 |
| **写作背景** | 这是一首"题画诗"——苏轼的朋友惠崇和尚画了一幅《春江晚景》，苏轼在画上题了这首诗。画是静止的，但苏轼写活了：鸭子最先感受到春江水暖，河豚正要逆流而上。可惜这幅画后来失传了，但诗留了下来 |
| **诗意** | 竹林外两三枝桃花初放，春天的江水里鸭子最先知道。满地的蒌蒿和初生的芦芽——正是河豚逆流而上的时节 |

**曾几《三衢道中》**：

| 项目 | 内容 |
|:-----|:-----|
| **作者** | 曾几（1084–1166），字吉甫，号茶山居士，南宋诗人 |
| **代表作** | 曾几是陆游的老师，诗风清新自然 |
| **写作背景** | 曾几晚年住在浙江，初夏时节和朋友到三衢山游玩。刚开始担心下雨，结果梅子黄时反而放晴了。走在山路上绿树成荫，黄鹂声声——比来时的景色更美。这首诗写的就是"意外之喜" |
| **诗意** | 梅子黄透了天天都是晴天，坐小船到溪尽头再走山路。山路上绿荫和来时一样，只是多了四五声黄鹂的啼叫 |

## ✨ 阅读与写作：深挖课文"宝藏"

### □储备 1️⃣ 绝句 · 杜甫 —— 动静结合+多感官

| 阅读要点 | 写法分析 | 写作小技巧 |
|:---------|:---------|:-----------|
| "飞"燕子＋"睡"鸳鸯 🐦 | 一动一静，画面有生气 | 写景时可以动静结合 |
| 丽（视觉）、香（嗅觉）、暖（触觉） 🌸 | 多感官并用，如临其境 | 写景要调动多种感官 |

### □储备 2️⃣ 惠崇春江晚景 · 苏轼 —— 由近及远+想象

| 阅读要点 | 写法分析 | 写作小技巧 |
|:---------|:---------|:-----------|
| 竹外桃花→春江→蒌蒿芦芽 🎋 | 空间顺序，层次分明 | 按空间顺序写景 |
| "正是河豚欲上时" 🐟 | 由景物联想到时令 | 可以加入合理想象 |

### □储备 3️⃣ 三衢道中 · 曾几 —— 移步换景+以声衬静

| 阅读要点 | 写法分析 | 写作小技巧 |
|:---------|:---------|:-----------|
| "添得黄鹂四五声" 🎵 | 用声音写出山林的生机 | 以声衬静让画面更美 |
| "日日晴"vs梅雨季 ☀️ | 意外之喜，心情更好 | 对比可以突出惊喜 |

### ✍️ 本单元习作：我的植物朋友

**习作目标**：选一种植物，先用观察卡片记录，再写成作文。

**写作框架**：
1. 开头：我的植物朋友是谁 + 在哪里
2. 外形：按顺序写（整体→部分）
3. 特点：它有什么特别之处
4. 互动：我怎么照顾它 + 它给我的快乐

**范文**：

> **我的植物朋友——向日葵**
>
> 我家小院里种了一棵向日葵，它是我的好朋友。
>
> 它的茎又粗又直，像一根绿色的棍子。叶子大大的，像一把把蒲扇。最引人注目的是它的花——金黄色的花瓣围着一圈棕色的花盘，像一个灿烂的太阳。
>
> 我发现向日葵有个秘密：它的花盘会跟着太阳转！早上它面向东方，中午抬起头朝向天空，傍晚又转向西方。难怪它叫"向日葵"！
>
> 秋天到了，向日葵的花盘里长满了瓜子。我剥了一颗尝了尝——又香又脆！
>
> 向日葵不仅美丽，还给我带来了好吃的瓜子，我特别喜欢它。 |
