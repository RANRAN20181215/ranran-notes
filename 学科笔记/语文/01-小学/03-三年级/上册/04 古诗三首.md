# 4 古诗三首

> 第1/4篇 · 金秋时节 · 下篇《铺满金色巴掌的水泥道》与此篇同属第2单元，是第2单元首篇

> 部编版三上第二单元
> **阅读重点**：运用多种方法理解词语
> **习作目标**：写日记

---

## 📖 课文讲了什么

三首古诗分别写了不同的秋景：杜牧写山行红叶胜春花，苏轼写秋日橙黄橘绿好风景，叶绍翁写秋夜看儿童捉蟋蟀。

**一句话速览**：杜牧写山行红叶胜春花，苏轼写秋日橙黄橘绿正当时，叶绍翁写秋夜儿童捉蟋蟀勾起思乡情。

**□储备 单元关联**：本单元主题"金秋时节"。《铺满金色巴掌的水泥道》写秋天的落叶，《秋天的雨》写秋天的色彩，《听听，秋的声音》写秋天的声音。读这篇时想一想——三首诗写的是同一种"秋天"吗？有什么不同？

---

## ❤️ 中心思想

**《山行》** 描绘深秋山林美景，以"霜叶红于二月花"赞美秋天比春天更绚烂。
**《赠刘景文》** 借"荷尽菊残"却"橙黄橘绿"的秋景，劝勉朋友：人生的每个阶段都有独特的美好。
**《夜书所见》** 写秋夜的萧瑟和儿童的嬉戏，抒发漂泊在外的思乡之情。

> 三首诗虽都写"秋天"，角度截然不同——杜牧赞美秋色，苏轼鼓励朋友，叶绍翁借秋思乡。读的时候注意区分每首诗独特的情感。**不要笼统地说"热爱秋天"。**

> 💡 **进阶阅读**（可跳过）—— 感兴趣再读，不影响孩子理解诗意
### 👤 诗人档案

#### 🍁 杜牧《山行》
| 项目 | 内容 |
|:-----|:-----|
| **作者** | 杜牧（803–852），字牧之，晚唐著名诗人 |
| **称号** | "小李杜"之一（与李商隐并称），人称"杜紫薇" |
| **代表作** | 《江南春》《赤壁》《泊秦淮》《阿房宫赋》 |
| **创作风格** | 语言清丽，意境深远，咏史和写景都很出色 |
| **写作背景** | 杜牧晚年隐居山林，深秋登山远眺，看到满山红叶比春花还艳，有感而发写下这首诗。他不写秋天的萧瑟，反写秋天的热烈 |

**诗意**：一条石头小路弯弯曲曲伸向深秋的山顶，白云缭绕的地方隐约有几户人家。停下车来欣赏枫林晚景——那经霜的枫叶比二月的春花还要红艳！

#### 🍊 苏轼《赠刘景文》
| 项目 | 内容 |
|:-----|:-----|
| **作者** | 苏轼（1037–1101），字子瞻，号东坡居士，北宋大文豪 |
| **称号** | "唐宋八大家"之一，与父亲苏洵、弟弟苏辙合称"三苏" |
| **代表作** | 《水调歌头》《念奴娇·赤壁怀古》《题西林壁》 |
| **创作风格** | 豪放洒脱，旷达乐观，诗词文赋样样精通 |
| **写作背景** | 这首诗是苏轼送给朋友刘景文的。刘景文时年已老但仕途不顺，苏轼用"橙黄橘绿"的秋景鼓励他：秋天虽然荷花枯了菊花残了，但正是橙黄橘绿的好时节。人生也是一样，每个阶段都有独特的美好 |

**诗意**：荷花凋谢了，连擎雨的荷叶也枯萎了；菊花虽然开败了，但依旧傲霜挺立。一年中最好的季节是哪个？就是现在——橙子金黄、橘子青绿的秋天啊！

#### 🦗 叶绍翁《夜书所见》
| 项目 | 内容 |
|:-----|:-----|
| **作者** | 叶绍翁（1194–1269？），字嗣宗，号靖逸，南宋诗人 |
| **代表作** | 《游园不值》（"春色满园关不住，一枝红杏出墙来"） |
| **创作风格** | 语言清丽，善于从日常生活中发现诗意 |
| **写作背景** | 叶绍翁漂泊异乡，深秋的夜晚独自一人，看到远处篱笆边有灯火闪烁——原来是有孩子在捉蟋蟀。这一幕勾起他的思乡之情：自己的家乡是否也有孩子在秋夜玩耍呢？ |

**诗意**：萧萧秋风吹动梧桐叶，送来阵阵寒意。我漂泊在外，不禁思念起家乡。忽然看到远处篱笆下灯火闪动——原来是有小孩子在捉蟋蟀呢。

## 🏗️ 文章结构：超清晰！

### 山行 · 杜牧

> 远上寒山石径斜，白云生处有人家。
> 停车坐爱枫林晚，霜叶红于二月花。

> 💡 读着玩——读顺了就好，感受节奏和画面

**📜 写作背景**：公元835年前后，杜牧在长安做官。一个深秋的午后，他独自驾车出城，沿着寒山石径缓缓而上。远处的白云深处隐约有人家，路边枫林像火烧云般绚烂——他看呆了，索性停下马车，在山道上久久不愿离去。

**🔑 词语解释**

| 词语 | 画面式解释 |
|:-----|:----------|
| 山行 | 想象一下，诗人走在深秋的山路上，脚下是落叶沙沙响 |
| 寒山 | 想象一下，深秋的山凉飕飕的，石头上长着青苔，空气里带着冷意 |
| 石径 | 想象一下，一条弯弯曲曲的小路，用一块块石头铺成，一直通向大山深处 |
| 坐 | 这里的"坐"不是坐下来，而是"因为"——因为太喜欢枫林了，诗人停下了马车 |
| 霜叶 | 想象一下，枫叶被霜打过之后，红得像一团团火，比春天的花还要鲜艳 |
| 红于 | 想象一下，秋天的枫叶比二月的春花还要红、还要艳，红得发亮 |

**✨ 写作亮点**

| 写法亮点 | 课文内容 | 写作技巧 |
|:---------|:---------|:---------|
| **反向赞美** | "霜叶红于二月花" | 秋叶比春花更红，赞美秋天 |
| **远近结合** | 远山→白云→人家→枫林 | 由远及近，画面层次分明 |
| **情感真挚** | "停车坐爱" | 因为太爱，所以停下 |

**🎙️ 朗读提示**

| 方面 | 指导 |
|:-----|:-----|
| **基调** | 明快热烈，赞美秋天 |
| **节奏** | 远上/寒山/石径斜，白云/生处/有人家。停车/坐爱/枫林晚，霜叶/红于/二月花。 |
| **重音** | 寒山、斜、有人家、坐爱、红于、二月花 |
| **语气** | 前两句平缓叙述（远景）；第三句"停车"稍顿、"坐爱"放慢（陶醉）；末句上扬、重读"红于"，读出由衷赞美 |
| **🍃 读着玩** | 先读顺了，其他再说 |

### 赠刘景文 · 苏轼

> 荷尽已无擎雨盖，菊残犹有傲霜枝。
> 一年好景君须记，最是橙黄橘绿时。

> 💡 读着玩——读顺了就好，感受节奏和画面

**📜 写作背景**：好朋友刘景文那年58岁了，一生不得志，刚被提拔又遭贬谪，心情灰暗。苏轼在杭州做知州，特意写了这首诗送给他——不是廉价的同情，而是铿锵的鼓励：人生的"秋天"也很美。

**🔑 词语解释**

| 词语 | 画面式解释 |
|:-----|:----------|
| 擎雨盖 | 想象一下，夏天的荷叶又大又圆，像一把把绿色的伞撑在水面上 |
| 菊残 | 想象一下，菊花的花瓣枯萎了，耷拉着脑袋，但它还站在寒风里，不肯倒下 |
| 犹有 | 想象一下，菊花虽然开败了，但枝干还在——还有不怕冷的枝条挺立着 |
| 傲霜枝 | 想象一下，寒霜打在菊花上，枝条却不低头，昂首挺胸地站在那里 |
| 君 | 这里的"君"就是你——苏轼在跟好朋友刘景文面对面说话 |
| 橙黄橘绿 | 想象一下，橙子金黄金黄的，橘子碧绿碧绿的，挂满了枝头，丰收了 |

**✨ 写作亮点**

| 写法亮点 | 课文内容 | 写作技巧 |
|:---------|:---------|:---------|
| **先抑后扬** | 荷尽菊残→橙黄橘绿 | 先写衰败，再写丰收 |
| **哲理深意** | "一年好景君须记" | 秋天也是好时节 |
| **鼓励朋友** | 送给失意的刘景文 | 用景色鼓励人生 |

**🎙️ 朗读提示**

| 方面 | 指导 |
|:-----|:-----|
| **基调** | 豁达乐观，劝勉鼓励 |
| **节奏** | 荷尽/已无/擎雨盖，菊残/犹有/傲霜枝。一年/好景/君须记，最是/橙黄/橘绿时。 |
| **重音** | 已无、犹有、傲霜枝、好景、须记、最是 |
| **语气** | 前两句平缓略带惋惜（"已无"轻读，"犹有"稍稍扬起）；第三句转向朋友、语气诚恳；末句坚定有力，"最是"拉长，读出热情推荐 |
| **🍃 读着玩** | 先读顺了，其他再说 |

### 夜书所见 · 叶绍翁

> 萧萧梧叶送寒声，江上秋风动客情。
> 知有儿童挑促织，夜深篱落一灯明。

> 💡 读着玩——读顺了就好，感受节奏和画面

**📜 写作背景**：南宋的一个秋夜，叶绍翁漂泊在外，借宿在一处旅舍。窗外秋风萧瑟，梧桐叶沙沙作响。他辗转难眠，走到窗前——却看见篱笆下亮着一盏灯，几个小孩正蹲在地上捉蟋蟀。他想起了自己的童年。

**🔑 词语解释**

| 词语 | 画面式解释 |
|:-----|:----------|
| 萧萧 | 想象一下，秋风"呼呼"地吹着梧桐叶，叶子发出"沙沙沙"的声音，听着就觉得冷 |
| 梧叶 | 想象一下，大片的梧桐叶在风里飘落，像一只只黄色的蝴蝶转着圈掉下来 |
| 客情 | 想象一下，诗人一个人住在外面，听到风声，心里酸酸的，想起了远方的家 |
| 挑 | 想象一下，小孩蹲在地上，手里拿根小棍子，轻轻拨开草丛找蟋蟀 |
| 促织 | 想象一下，一只黑亮的小虫子躲在石头缝里，"瞿瞿瞿"地叫着——那就是蟋蟀 |
| 篱落 | 想象一下，一排竹条编成的篱笆下面，一盏小灯在夜色里闪着温暖的光 |

**✨ 写作亮点**

| 写法亮点 | 课文内容 | 写作技巧 |
|:---------|:---------|:---------|
| **以乐写哀** | 儿童玩得开心，诗人更想家 | 反衬手法 |
| **动静结合** | 秋风萧瑟（动）→一灯明亮（静） | 对比营造氛围 |
| **情景交融** | 秋风+客情 | 景物和心情融为一体 |

**🎙️ 朗读提示**

| 方面 | 指导 |
|:-----|:-----|
| **基调** | 孤独思乡，略带伤感 |
| **节奏** | 萧萧/梧叶/送寒声，江上/秋风/动客情。知有/儿童/挑促织，夜深/篱落/一灯明。 |
| **重音** | 萧萧、寒声、动客情、挑促织、一灯明 |
| **语气** | 前两句低沉缓慢，读出秋风寒意；第三句稍扬，带着意外的温暖（发现儿童）；末句渐慢、轻读"一灯明"，余韵悠长，留下思乡的惆怅 |
| **🍃 读着玩** | 先读顺了，其他再说 |
