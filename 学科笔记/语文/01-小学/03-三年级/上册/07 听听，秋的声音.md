# 7* 听听，秋的声音（略读）

## 📖 课文讲了什么

听听秋的声音——大树抖手臂（落叶唰唰），蟋蟀振动翅膀（㘗㘗），大雁追上白云（叮咛），秋风掠过田野（歌吟）……

**一句话速览**：秋天有各种美妙的声音——大树抖手臂、蟋蟀振翅膀、大雁追白云——走进秋天去听听吧。

**□储备 单元关联**：本单元主题"金秋时节"。《古诗三首》写秋的视觉之美，《铺满金色巴掌的水泥道》写秋的触觉之美，《秋天的雨》写秋的色彩和气味。读这篇时想一想——为什么说秋天的声音值得"听听"？

> 💡 提示：试试用本单元学到的方法——"运用多种方法理解词语"来读这篇。

## ❤️ 中心思想

**用优美的语言和拟声词，展现了秋天各种美妙的声音，表达了对秋天的热爱。**

### 👤 □了解 作者背景
| 项目 | 内容 |
|:-----|:-----|
| **作者** | 毕国瑛，中国当代诗人、儿童文学作家 |
| **创作风格** | 擅长用耳朵"看"世界，从声音中发现诗意，语言简洁有节奏感 |
| **写作背景** | 作者在秋天漫步田野时，听到树叶沙沙、蟋蟀㘗㘗、大雁鸣叫——这些秋天独有的声音像一首交响乐，于是写下这首现代诗 |

| 部分 | 自然段 | 内容 | 作用 |
|:-----|:-------|:-----|:-----|
| **第一部分 🎬** | 1-2 | 大树抖手臂、落叶唰唰 | 引出声音 |

## ✍️ 本单元习作：写日记

### 🎯 □核心 目标
学会日记格式，记录一天中有意思的事。

### 📐 日记格式

```
9月15日　　星期二　　晴

　　今天放学路上，我发现了一件有趣的事……
```

**三要素**：日期 + 星期 + 天气（缺一不可！）

### 📝 写什么（选材指南）

| 类型 | 例子 |
|:-----|:-----|
| 一件小事 | 今天学会系鞋带了 |
| 一个新发现 | 原来蜗牛有上万颗牙齿 |
| 一个心情 | 今天被老师表扬了/和好朋友吵架了 |
| 一个观察 | 窗台上的花开了 |
| 一个想法 | 读完《卖火柴的小女孩》我哭了 |

### 📝 □了解 范文

> 9月20日　　星期五　　晴
>
> 今天语文课上，老师让我们用"五彩缤纷"造句。我举手说："秋天的果园五彩缤纷，有红红的苹果、黄黄的梨、紫紫的葡萄。"老师夸我用得好，还在班上念给同学们听。我心里美滋滋的，像吃了蜜一样甜。
>
> 原来只要用心观察，就能说出好句子。我以后要多多观察！

> 10月20日　　星期日　　晴
>
> 今天在公园里，我听到了秋天的声音。
>
> 风一吹，树叶"沙沙沙"地响，像在说悄悄话。草丛里，蟋蟀"㘗㘗㘗"地叫，像在开音乐会。抬头一看，大雁"嘎嘎"叫着往南飞。
>
> 原来秋天不光有颜色，还有这么多好听的声音！
