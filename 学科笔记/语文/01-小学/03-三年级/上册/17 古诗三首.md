# 17 古诗三首

> 第1/4篇 · 祖国河山 · 下篇《富饶的西沙群岛》与此篇同属第6单元，是第6单元首篇

> 部编版三上第17课
> **阅读重点**：借助关键句理解一段话的意思
> **习作目标**：这儿真美（写景作文）

---

## 📖 课文讲了什么

三首古诗分别写了不同的景色：李白写天门山中断江开，苏轼写西湖晴雨都美，刘禹锡写洞庭湖像白银盘里的青螺。

**一句话速览**：李白写天门山雄奇、苏轼写西湖柔美、刘禹锡写洞庭湖宁静——三位诗人笔下的山水各具神韵。

**□储备 单元关联**：本单元主题"祖国河山"。《富饶的西沙群岛》写南海的丰饶，《海滨小城》写南国海滨，《美丽的小兴安岭》写东北森林。读这篇时想一想——诗人看到的山水和普通人有什么不同？

---

## ❤️ 中心思想

**三首古诗都表达了诗人对祖国壮丽河山的热爱和赞美之情。**

### 👤 诗人档案

**李白《望天门山》**：

| 项目 | 内容 |
|:-----|:-----|
| **作者** | 李白（701–762），字太白，号青莲居士，唐代伟大的浪漫主义诗人 |
| **称号** | "诗仙"，与杜甫并称"李杜" |
| **代表作** | 《静夜思》《望庐山瀑布》《将进酒》《蜀道难》 |
| **创作风格** | 豪放飘逸，想象奇绝，气势磅礴 |
| **写作背景** | 李白25岁出蜀漫游，乘船东下，第一次经过天门山。两岸青山相对而出，长江水呼啸奔流——这幅壮阔的画卷让年轻的李白心潮澎湃，写下这首千古名篇 |
| **诗意** | 长江像一把巨斧把天门山劈成两半，碧绿的江水东流到此回旋激荡。两岸青山对峙而出，一叶孤舟从日边驶来 |

**苏轼《饮湖上初晴后雨》**：

| 项目 | 内容 |
|:-----|:-----|
| **作者** | 苏轼（1037–1101），字子瞻，号东坡居士 |
| **称号** | "唐宋八大家"之一 |
| **代表作** | 前文已介绍（详见第4课） |
| **写作背景** | 苏轼任杭州通判时，与朋友在西湖饮酒。先是晴天，后来下起细雨。他看到晴天的西湖水光潋滟，雨天的西湖山色空蒙，两种景色都很美。于是他把西湖比作美女西施——淡妆浓抹都相宜 |
| **诗意** | 晴天西湖波光闪动，雨天西湖山色迷蒙。想把西湖比作西施——淡妆浓抹都这么美 |

**刘禹锡《望洞庭》**：

| 项目 | 内容 |
|:-----|:-----|
| **作者** | 刘禹锡（772–842），字梦得，唐代诗人 |
| **称号** | "诗豪" |
| **代表作** | 《陋室铭》《竹枝词》《乌衣巷》 |
| **创作风格** | 豪迈乐观，语言精炼，善于从寻常景物中发现诗意 |
| **写作背景** | 刘禹锡被贬到和州（今安徽），途经洞庭湖。秋夜明月下的洞庭湖宛如银盘托着青螺，他由此写下这首意境开阔的诗。身处逆境仍能发现美，正是"诗豪"本色 |
| **诗意** | 湖光和秋月和谐相融，湖面没有风像一面未打磨的铜镜。远望洞庭山水——白银盘里托着一只青螺 |

## 望天门山 · 李白

> 天门中断楚江开，碧水东流至此回。
> 两岸青山相对出，孤帆一片日边来。

### 🎤 朗读提示

| 要素 | 建议 |
|:-----|:-----|
| **基调** | 豪放雄壮，气势磅礴 |
| **节奏** | 天门/中断/楚江开，碧水/东流/至此回。两岸/青山/相对出，孤帆/一片/日边来 |
| **重音** | 中断、开、回、出、孤帆 |
| **语气** | 前两句浑厚有力，读出江水劈开青山的冲击力；后两句语速稍缓，读出两岸青山→一叶孤舟的开阔画面 |
| **🍃 读着玩** | 先读顺了，其他再说 |

**📜 写作背景**：公元725年，李白25岁。这一年他"仗剑去国，辞亲远游"——离开家乡四川，沿长江顺流而下。船到安徽当涂时，两岸青山突然夹江对峙，江面收窄，激流回旋——李白站在船头，被这气势惊得说不出话。

**🔑 词语解释**
| 词语 | 画面式解释 |
|:-----|:----------|
| 天门山 | 想象一下，两座大山面对面站在长江两岸，像两扇巨大的天门 |
| 中断 | 想象一下，长江像一把巨斧，"咔嚓"一声把天门山劈成了两半 |
| 楚江 | 想象一下，长江水流过楚地这一段，又宽又急，哗啦啦往前冲 |
| 回 | 想象一下，江水冲到山脚下，打了个转，激起了白色的浪花 |
| 相对出 | 想象一下，船往前开，两岸的青山像从水里冒出来一样，一座接一座 |
| 孤帆 | 想象一下，一片小小的白帆远远地漂在水面上，从太阳那边驶过来 |

**✨ 写作亮点**
| 写法亮点 | 课文内容 | 写作技巧 |
|:---------|:---------|:---------|
| **动态写景** | "断、开、出、来"四个动词 | 用动词让景物活起来 |
| **远近结合** | 远山→近水→孤帆 | 由远及近，层次分明 |
| **气势磅礴** | 中断、东流、相对出 | 写出大自然的壮美 |

## 饮湖上初晴后雨 · 苏轼

> 水光潋滟晴方好，山色空蒙雨亦奇。
> 欲把西湖比西子，淡妆浓抹总相宜。

### 🎤 朗读提示

| 要素 | 建议 |
|:-----|:-----|
| **基调** | 赞美欣赏，轻松愉悦 |
| **节奏** | 水光/潋滟/晴方好，山色/空蒙/雨亦奇。欲把/西湖/比西子，淡妆/浓抹/总相宜 |
| **重音** | 晴方好、雨亦奇、比西子、总相宜 |
| **语气** | 前两句对比着读——"晴方好"轻快明亮，"雨亦奇"舒缓朦胧；后两句读出赞叹——"总相宜"略放慢，带笑意 |
| **🍃 读着玩** | 先读顺了，其他再说 |

**📜 写作背景**：公元1073年，苏轼在杭州做通判（副市长）。一个春日，他和朋友在湖上饮酒。一开始阳光灿烂，水波潋滟；忽然下起雨来，山色朦胧，云雾弥漫——苏轼放下酒杯，觉得两种都好美。这首诗写的就是"西湖的AB面"。

**🔑 词语解释**
| 词语 | 画面式解释 |
|:-----|:----------|
| 潋滟 | 想象一下，阳光洒在西湖水面上，波光一闪一闪的，像撒了一层碎金子 |
| 空蒙 | 想象一下，下雨后山间飘起白蒙蒙的雾气，山和云分不清了，像一幅水墨画 |
| 西子 | 想象一下，古代最美的女子西施，无论化淡妆还是浓妆都好看——西湖就像她一样 |
| 淡妆浓抹 | 想象一下，西湖晴天像化了淡妆，清清爽爽；雨天像化了浓妆，朦朦胧胧——两种样子都美 |

**✨ 写作亮点**
| 写法亮点 | 课文内容 | 写作技巧 |
|:---------|:---------|:---------|
| **晴雨对比** | 晴方好vs雨亦奇 | 两种景色都美 |
| **比喻极致** | "欲把西湖比西子" | 把西湖比作美女西施 |
| **概括力强** | "淡妆浓抹总相宜" | 一句写尽西湖之美 |

## 望洞庭 · 刘禹锡

> 湖光秋月两相和，潭面无风镜未磨。
> 遥望洞庭山水翠，白银盘里一青螺。

### 🎤 朗读提示

| 要素 | 建议 |
|:-----|:-----|
| **基调** | 宁静优美，开阔明丽 |
| **节奏** | 湖光/秋月/两相和，潭面/无风/镜未磨。遥望/洞庭/山水翠，白银/盘里/一青螺 |
| **重音** | 两相和、镜未磨、山水翠、一青螺 |
| **语气** | 前两句平和舒缓，读出秋夜的安静；后两句语调微扬，"一青螺"读出惊喜——白银盘中托着一个小小的青螺 |
| **🍃 读着玩** | 先读顺了，其他再说 |

**📜 写作背景**：公元824年，刘禹锡被贬到和州（今安徽）做刺史。赴任途中经过洞庭湖，正值秋夜——月光洒在湖面上，风平浪静，君山像一颗青螺卧在银盘里。别人被贬路上愁云惨淡，他却在欣赏湖光山色。

**🔑 词语解释**
| 词语 | 画面式解释 |
|:-----|:----------|
| 相和 | 想象一下，湖水的光和秋月的颜色融为一体，分不清哪是水哪是天 |
| 镜未磨 | 想象一下，湖面平静得像一面铜镜，但还没打磨过，带着一层朦胧的光泽 |
| 山 | 这里的"山"指的是洞庭湖中的君山——一座小小的、翠绿的山岛 |
| 青螺 | 想象一下，远远看去，君山就像一只青色的螺蛳，静静地卧在银色的盘子里 |

**✨ 写作亮点**
| 写法亮点 | 课文内容 | 写作技巧 |
|:---------|:---------|:---------|
| **比喻生动** | 湖面=白银盘，君山=青螺 | 用熟悉事物比喻 |
| **大小对比** | 大湖中一个小岛 | 画面感极强 |
| **色彩鲜明** | 白银盘（银色）＋青螺（青色） | 颜色搭配美 |

## ✍️ 习作范文：这儿真美

### 📝 □了解 范文

> **那儿真美**
>
> 我们学校后面有一片小树林，那儿真美！
>
> 一走进树林，就能看见一排高大的梧桐树。秋天到了，梧桐树的叶子变黄了，像一只只金色的蝴蝶。风一吹，树叶飘落下来，地上铺了一层金色的地毯，踩上去沙沙响。
>
> 树林中间有一条弯弯的小路。路边的石头上长满了青苔，摸上去软软的。阳光透过树叶的缝隙洒下来，在地上画出一个个金色的小光斑。
>
> 每天放学后，我都喜欢到小树林里走一走。那里很安静，只有鸟叫声和风吹树叶的声音。坐在树下的长椅上看书，是最舒服的事。
>
> 这片小树林虽然不大，但它是我心中最美的地方。
