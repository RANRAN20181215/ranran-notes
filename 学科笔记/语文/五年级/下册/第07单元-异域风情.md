## 18 威尼斯的小艇

### 📖 课文概要
威尼斯是世界闻名的水上城市。小艇是主要的交通工具——又窄又深，像新月。船夫的驾驶技术特别好——快、稳、灵活。商人坐小艇做生意、老人带全家去教堂、戏院的散场时刻更是热闹非凡。

### 📜 知背景
- 作者：**马克·吐温**（美国作家）

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **威尼斯** | 意大利水城 |
| **船艄** | 船尾 |
| **操纵自如** | 控制自如 |
| **手忙脚乱** | 慌乱、不从容 |
| **簇拥** | 很多人围着 |
| **哗笑** | 大声笑 |
| **沉寂** | 非常安静 |

### 💡 动静结合

| 场景 | 状态 | 描写 |
|:----|:-----|:-----|
| 白天 | **动态** | 小艇穿梭、行人来往、戏院散场 |
| 夜晚 | **静态** | 小艇沉睡、水面平静、月光皎洁 |

> "水面上渐渐沉寂，只见月亮的影子在水中摇晃。高大的石头建筑耸立在河边，古老的桥梁横在水上，大大小小的船都停泊在码头上。静寂笼罩着这座水上城市，古老的威尼斯又沉沉地入睡了。"

**从动到静**——热闹后的宁静，让人回味。

## 19 牧场之国

### 📖 课文概要
荷兰是牧场之国——碧绿的草原上黑白花牛在吃草、骏马在奔跑、绵羊在悠闲地漫步。到了晚上，一切都安静下来，只有远处的灯塔在闪烁。

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **仪态端庄** | 姿态端正庄重 |
| **镶嵌** | 嵌入 |
| **辽阔** | 宽广 |
| **悠然自得** | 悠闲舒适 |
| **牲畜** | 家畜 |
| **遮掩** | 遮蔽 |

### 💡 反复出现的"这就是真正的荷兰"
文中出现四次——像诗歌的**副歌**，不断强调荷兰的美。

## 20\* 金字塔（略读）

### 📖 课文概要
两篇短文——《金字塔夕照》（散文，写金字塔的壮观和神秘）和《不可思议的金字塔》（非连续性文本，用数据和图表介绍金字塔的建造之谜）。

### 💡 非连续性文本
五年级第一次接触——**有图表、有数据、有批注**的阅读材料。

## ✍️ 习作：中国的世界文化遗产

### 🎯 目标
搜集资料，介绍一处中国的世界文化遗产。**学会整理资料、分类介绍。**

### 🧩 世界文化遗产（选一个）

| 名称 | 地点 | 特点 |
|:----|:-----|:-----|
| 长城 | 北京等 | 万里长城，世界奇迹 |
| 故宫 | 北京 | 明清两代的皇宫 |
| 兵马俑 | 西安 | 秦始皇的地下军队 |
| 莫高窟 | 敦煌 | 壁画和彩塑的艺术宝库 |
| 颐和园 | 北京 | 皇家园林 |
| 苏州园林 | 苏州 | 古典园林 |

### 📐 写作框架

1. **引入**：名称+地位
2. **历史**：什么时候建的、为什么建
3. **特点**：最精彩的部分
4. **价值**：为什么是"文化遗产"
5. **保护**：如何保护它

### 📝 范文

> **秦始皇帝陵兵马俑**
>
> 在西安临潼，有一个震惊世界的考古发现——秦始皇帝陵兵马俑。它被誉为"世界第八大奇迹"。
>
> 兵马俑是秦始皇的陪葬品，1974年被当地农民打井时发现。目前已出土了三个俑坑，总面积约两万平方米，出土陶俑八千多件。
>
> 最让人惊叹的是——每一个兵马俑都不一样！它们身高约1.8米，有将军俑、士兵俑、车兵俑等不同种类。它们的发型、表情、手势各不相同——有的严肃、有的微笑、有的怒目圆睁。站在它们面前，仿佛能听到两千多年前军队的呐喊声。
>
> 兵马俑让我们看到了秦朝的强大和古代工匠的智慧。每一尊陶俑都是一件艺术珍品。
>
> 1987年，兵马俑被列入《世界遗产名录》。它是中国的骄傲，也是全人类的文明瑰宝。

### 📝 第二篇范文

> **北京故宫**
>
> 在北京城的正中心，有一座宏伟的宫殿建筑群——故宫。它是明清两代皇帝的住所，已经有六百多年的历史了。
>
> 故宫又叫"紫禁城"，是全世界最大的木结构建筑群。它占地72万平方米，有房间九千多间。什么概念呢？如果你每天住一间，要25年才能住完所有的房间。
>
> 故宫最吸引我的地方是它的建筑。黄色的琉璃瓦在阳光下闪闪发光，红色的城墙高大厚重。走进太和殿，你会发现皇帝的宝座放在七层台阶之上，两边有铜鹤、铜龟。站在殿里，你仿佛能听到几百年前大臣们上朝的脚步声。
>
> 故宫里还收藏了180多万件文物。我最喜欢的是"清明上河图"——那是一幅五米多长的画，画的是北宋汴京城的热闹街景。画上有几百个人物，每个人的表情动作都不一样，像一部古代的电影。
>
> 1987年，故宫被列入《世界遗产名录》。它不仅是中国的骄傲，更是世界了解中国的一扇窗。

### ⚠️ 常见问题
1. ❌ 全篇抄资料 → ✅ 把资料变成自己的话
2. ❌ 没有重点 → ✅ 选1-2个最精彩的部分详写
3. ❌ 枯燥乏味 → ✅ 加一点有趣的细节和小故事

### 🧠 写作指导

**① 从阅读中学写作（申怡·读写结合）**
回到本单元的课文，看看作者是怎么写的——
- 《威尼斯的小艇》：从这篇可以学到**抓事物特点**——马克·吐温写小艇"像新月""像水蛇"，用比喻把事物的特点写活了。介绍文化遗产也要找到它最独特的那个特点。
- 《牧场之国》：从这篇可以学到**反复强调**——"这就是真正的荷兰"在文中出现了四次，像歌曲的副歌一样不断加深印象。你的习作也可以用一句核心句反复出现来强化主题。
→ 把这些方法用到你的作文里，语文课本就是最好的"作文书"。

**② 先搭架子再动笔（申怡·理科思维）**
动笔之前，先回答三个问题：
1. 我要介绍哪一处文化遗产？它最吸引人的是什么？
2. 分几段写？每段写什么？（引入→历史→特点→价值→保护）
3. 用什么材料来支撑？（数据、故事、传说、个人感受）
列一个简单的提纲，就像盖房子先搭钢筋一样。框架稳了，文章就稳了。

**③ 说人话，说真话（温儒敏·回到常识）**
介绍文化遗产最容易写成"百度百科"。不要大段复制资料。可以加一些自己的想象——"站在长城上，我仿佛看到了古代的士兵在烽火台上升起狼烟"，把自己的感受写进去，文章就有温度了。资料是骨架，你的话才是血肉。
