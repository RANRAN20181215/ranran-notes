# 第一单元 · 万物有灵

> 白鹭的诗意、落花生的朴实、桂花雨的乡愁、珍珠鸟的信赖——万物皆有灵。
> **阅读重点**：借助具体事物抒发感情
> **习作目标**：我的心爱之物（借物抒情）

---

## 1 白鹭

### 📖 课文概要
白鹭是一首精巧的诗。它的色素的配合、身段的大小，一切都很适宜。白鹭钓鱼、望哨、低飞——每一幅画面都像一首散文诗。

### 📜 知背景
- 作者：**郭沫若**
- 白鹭 = 一首"散文诗"——全文都围绕这个比喻展开

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **精巧** | 精致巧妙 |
| **配合** | 搭配 |
| **适宜** | 合适、恰当 |
| **寻常** | 平常、普通 |
| **悠然** | 悠闲的样子 |
| **嗜好** | 特别的爱好 |

### 💡 比喻贯穿全文
> "白鹭是一首精巧的诗。"

开头和结尾重复——**首尾呼应**。

**对比法**：白鹭 vs 白鹤、朱鹭、苍鹭——白鹭因为"大小适宜"而最美。

### 💡 三幅画面
> "在清水田里，时有一只两只白鹭站着钓鱼……"
> "晴天的清晨，每每看见它孤独地站立于小树的绝顶……"
> "黄昏的空中偶见白鹭的低飞……"

**钓鱼图、望哨图、低飞图**——画面由静到动。

## 2 落花生

### 📖 课文概要
"我们"在后园的半亩空地里种了花生。收获后，母亲做了好几样花生食品。父亲借花生讲了一个道理：**人要做有用的人，不要做只讲体面而对别人没有好处的人。**

### 📜 知背景
- 作者：**许地山**
- 笔名就叫"落华生"——他一辈子践行花生的品格

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **开辟** | 打开、开创 |
| **吩咐** | 口头指派或命令 |
| **茅亭** | 茅草盖的亭子 |
| **榨油** | 压榨出油 |
| **爱慕** | 喜爱仰慕 |
| **体面** | 好看、有面子 |
| **深夜** | 深夜 |

### 💡 借物喻人
| 花生 | 喻指 |
|:----|:------|
| 埋在地里 | 不炫耀 |
| 不好看但有用 | 朴实有用 |
| 果子藏在地下 | 默默奉献 |

> "人要做有用的人，不要做只讲体面，而对别人没有好处的人。"

**中心句**——全文的"文眼"。

### ✍️ 写法：借物喻人
选择一种事物 → 写出它的特点 → 联想到人的品格 → 点明道理

## 3 桂花雨

### 📖 课文概要
"我"小时候最喜欢桂花。桂花盛开时香气四溢，摇桂花是"我"最快乐的回忆。母亲说："这里的桂花再香，也比不上家乡院子里的桂花。"后来"我"到了杭州，也明白了这句话的含义。

### 📜 知背景
- 作者：**琦君**（台湾作家）
- 这是一篇**乡愁**散文——桂花=家乡

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **姿态** | 样子、姿势 |
| **浸** | 泡在液体里（比喻香气笼罩） |
| **尤其** | 更加、特别 |
| **完整** | 完整无缺 |
| **新鲜** | 清新、不陈旧 |

### 💡 关键词"浸"
> "整个村子都浸在桂花的香气里。"

"浸"——不是说香气飘在空气中，而是像水一样**泡**着整个村子。用词极妙。

> "这里的桂花再香，也比不上家乡院子里的桂花。"

**不是真的比不上**，是思乡之情让家乡的一切都变得最好。

## 4\* 珍珠鸟（略读）

### 📖 课文概要
"我"养了一对珍珠鸟。从最初的怕人到逐渐信赖——它敢从笼子里出来，敢喝"我"杯里的水，最后竟然在"我"的肩头睡着了。

### 📜 知背景
- 作者：**冯骥才**

### 💡 名句
> "信赖，往往创造出美好的境界。"

文章的核心——**人和动物之间，只要互相信任，就能和谐相处。**

## ✍️ 习作：我的心爱之物

### 🎯 目标
写一件你心爱的物品——它可能不贵重，但对你有特殊的意义。**借物品表达感情。**

### 📐 写作框架

1. **开头**：是什么 + 怎么得到的
2. **样子**（外形描写）
3. **故事**（你和它之间的故事，重点！）
4. **意义**（为什么是你的心爱之物）

### 📝 范文

> **我的心爱之物——爷爷的旧怀表**
>
> 在我的书桌抽屉里，放着一块已经不走的老怀表。表壳是铜色的，玻璃表面有一道细细的裂纹。虽然它早已不能用了，但它是我最珍贵的宝贝。
>
> 这块怀表是爷爷留给我的。小时候，爷爷总是从口袋里掏出这块怀表，"啪"地一声弹开表盖，然后用它来考我认时间。他的大手握着我的手，教我分辨时针和分针，我每次答对，他都笑得合不拢嘴。
>
> 爷爷去世那年，我哭得很伤心。整理遗物时，爸爸把这块怀表交给我："爷爷留给你的。"我捧着它，冰凉的金属表面仿佛还有爷爷手心的温度。
>
> 现在，我把它放在抽屉里，偶尔拿出来擦一擦。看到它，我就想起爷爷教我认时间的样子。
>
> 它不走了，但它把时间停在了最美的记忆里。

> **我的心爱之物——那条旧红领巾**
>
> 说出来你可能不信，我最心爱的东西是一条褪了色的红领巾。
>
> 这条红领巾是去年六一入队那天，校长亲自给我戴上的。那天我穿了一身新衣服，站在操场上，太阳晒得我满头汗。校长走过来，把红领巾系在我脖子上，拍了拍我的肩膀说："好孩子。"我激动得差点哭出来。
>
> 从那以后，我每天都戴着它。有一次放学路上摔了一跤，膝盖破了皮，我爬起来先看红领巾有没有弄脏。妈妈说它都洗得发白了，该换一条了。我不肯换——别的红领巾再新，也不是校长亲手给我戴的那条。
>
> 现在它挂在书桌边的挂钩上，每天早上我出门前都会摸一下。它不是什么值钱的东西，但每次看到它，我就能想起那天在操场上，心里那种"我长大了"的感觉。

### ⚠️ 常见问题
1. ❌ 写得很"贵重" → ✅ 有价值的不是价格，是情感
2. ❌ 物品和人脱节 → ✅ 重点写你和物品之间的故事
3. ❌ 没有点明"为什么心爱" → ✅ 结尾升华意义

### 🧠 写作指导

**① 从阅读中学写作（申怡·读写结合）**
回到本单元的课文，看看作者是怎么写的——
- 《落花生》：从这篇可以学到**借物喻理——用花生的朴实特点，比喻"做人要有用"的道理**
- 《桂花雨》：从这篇可以学到**借物寄情——通过摇桂花、思念桂花这些具体的事，写出对家乡的感情**
→ 把这些方法用到你的作文里，语文课本就是最好的"作文书"。

**② 先搭架子再动笔（申怡·理科思维）**
动笔之前，先回答三个问题：
1. 我要写什么主题？
2. 分几段写？每段写什么？
3. 用什么材料来支撑？
列一个简单的提纲，就像盖房子先搭钢筋一样。框架稳了，文章就稳了。

**③ 说人话，说真话（温儒敏·回到常识）**
不要堆砌好词好句。把一件小事写清楚，比写一篇"漂亮"的空话强一百倍。写你自己真正看到、听到、感受到的——这样的文章，读起来才有温度。
