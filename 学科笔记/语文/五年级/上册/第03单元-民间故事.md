# 第三单元 · 民间故事

> 猎人海力布、牛郎织女——口耳相传千年的中国故事。
> **阅读重点**：了解故事内容，创造性复述
> **习作目标**：缩写故事

---

## 9 猎人海力布

### 📖 课文概要
猎人海力布救了龙王的女儿，得到了一颗能听懂动物说话的宝石。但听到的秘密不能说——说了就会变成石头。海力布听到大山要崩塌、洪水要爆发，他为了救乡亲们，说出了秘密——变成了石头。

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **叮嘱** | 反复嘱咐 |
| **敬爱** | 尊敬热爱 |
| **崩塌** | 倒塌崩裂 |
| **发誓** | 庄严地说出决心 |
| **震天动地** | 形容声音巨大 |
| **千真万确** | 非常真实 |

### 💡 情节线
救蛇→得宝石→听鸟语知灾难→求搬家→被迫说真相→变成石头

**转折**：知道秘密但不能说 → 不说乡亲们会死 → 说了自己会死 → 选择牺牲。

## 10 牛郎织女（一）

### 📖 课文概要
牛郎从小被哥嫂虐待，和老牛相依为命。老牛开口说话，告诉他去湖边拿织女的衣服。织女是天上的仙女，不愿过没有自由的生活，下凡和牛郎成了家。

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **嫂子** | 哥哥的妻子 |
| **稀罕** | 稀奇、看重 |
| **好歹** | 好坏 |
| **尊严** | 可敬的身份地位 |
| **装饰** | 打扮、点缀 |
| **暴跳如雷** | 非常愤怒 |
| **心急如焚** | 心里急得像火烧 |

## ✍️ 习作：缩写故事

### 🎯 目标
把一个较长的民间故事缩写成简短版——**保留主干，去掉枝叶。**

### 📐 缩写方法

| 步骤 | 怎么做 |
|:----|:-------|
| ① 读懂原文 | 把握主要情节 |
| ② 保留主干 | 谁+做了什么+结果 |
| ③ 删掉细节 | 去掉对话、心理、环境描写 |
| ④ 简化语言 | 长句变短句，去掉修饰语 |
| ⑤ 保持连贯 | 用连接词衔接 |

### 缩写示例

**原文（《猎人海力布》节选）**：
海力布知道着急也没有用，不把为什么要搬家说清楚，大家是不会相信的。再一迟延，灾难就要夺去乡亲们的生命。要救乡亲们，只有牺牲自己。他想到这里，就镇定地对大家说："今天晚上，这里的大山要崩塌，洪水要淹没大地。你们看，鸟都飞走了。"

**缩写**：
海力布为了救乡亲们，决定牺牲自己。他告诉大家大山要崩塌、洪水要淹没大地。

### 📝 范文

> **《田螺姑娘》（缩写版）**
>
> 从前有个小伙子叫谢端，父母双亡，靠种地过日子，但他勤劳善良。
>
> 一天，他捡到一只大田螺，养在水缸里。之后每天回家都有热腾腾的饭菜。他很纳闷，假装出门后悄悄跑回来——只见水缸里走出一位姑娘，系上围裙开始做饭。姑娘说她是田螺变的，因为谢端心眼好，特意来报答他。
>
> 后来谢端和姑娘结了婚，过上了幸福的日子。
>
> （原文约800字，缩写后约280字——保留主干，去掉对话和环境描写。）

### ⚠️ 常见问题
1. ❌ 缩写变成"摘抄" → ✅ 用自己的话概括
2. ❌ 保留了太多细节 → ✅ 只留最关键的情节
3. ❌ 缩写后故事不连贯 → ✅ 加连接词

### 🧠 写作指导

**① 从阅读中学写作（申怡·读写结合）**
回到本单元的课文，看看作者是怎么写的——
- 《猎人海力布》：从这篇可以学到**提取关键情节——"救蛇→得宝石→知灾难→说真相→变石头"，一条线就串起了整个故事**
- 《牛郎织女》两篇对比：从中学到**保留主干删去枝叶——牛郎织女的故事很长，但核心就是"相遇→结合→分离→相会"**
→ 把这些方法用到你的作文里，语文课本就是最好的"作文书"。

**② 先搭架子再动笔（申怡·理科思维）**
动笔之前，先回答三个问题：
1. 我要写什么主题？
2. 分几段写？每段写什么？
3. 用什么材料来支撑？
列一个简单的提纲，就像盖房子先搭钢筋一样。框架稳了，文章就稳了。

**③ 说人话，说真话（温儒敏·回到常识）**
不要堆砌好词好句。把一件小事写清楚，比写一篇"漂亮"的空话强一百倍。写你自己真正看到、听到、感受到的——这样的文章，读起来才有温度。
