## 16 太阳

### 📖 课文概要
太阳离我们约一亿五千万千米远、体积约130万个地球那么大、表面温度约5500摄氏度。太阳和我们的关系非常密切——有了太阳，植物能生长、动物能生存、煤炭能形成、风能刮、雨能下。

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **繁殖** | 生物产生新个体 |
| **杀菌** | 杀死细菌 |
| **预防** | 防止 |
| **治疗** | 治疗 |
| **温度** | 冷热程度 |
| **抵得上** | 相当于 |

### 💡 说明方法（考试重点）

| 方法 | 定义 | 课文例子 |
|:----|:-----|:---------|
| **列数字** | 用具体数字 | "约一亿五千万千米" |
| **作比较** | 和熟悉的事物比 | "约130万个地球的体积才能抵得上一个太阳" |
| **打比方** | 比喻 | "太阳会发光，会发热，是个大火球" |
| **举例子** | 举例说明 | "有了太阳，地球上的庄稼和树木才能发芽、长叶、开花、结果" |
| **分类别** | 分几类 | 太阳对植物/动物/人/气候的影响 |

**课文结构**：远→大→热（特点）→ 和人类关系密切（作用）

## 17 松鼠

### 📖 课文概要
松鼠是一种漂亮的小动物——面容清秀、眼睛闪闪发光、玲珑的小面孔、帽缨形的尾巴。它们搭窝很讲究：先搬小木片、再用苔藓编扎、最后加一层盖。松鼠的窝又干净又暖和。

### 📜 知背景
- 作者：**布封**（法国博物学家）
- 这是一篇**文艺性说明文**——科学知识+文学表达

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **驯良** | 和顺善良 |
| **机警** | 机智警觉 |
| **清秀** | 清新秀丽 |
| **玲珑** | 精巧细致 |
| **敏捷** | 动作迅速灵敏 |
| **分叉** | 分成两岔 |
| **坚实** | 坚固结实 |

### 💡 对比：文艺性vs平实说明

| 对比项 | 《太阳》（平实） | 《松鼠》（文艺） |
|:-------|:----------------|:----------------|
| 语言 | 客观数据 | 生动描写 |
| 写法 | 列数字、作比较 | 比喻、拟人 |
| 目的 | 让人知道 | 让人喜欢 |

## ✍️ 习作：介绍一种事物

### 🎯 目标
选择一种你熟悉的事物，用上**说明方法**写一篇说明文。

### 📐 写作框架

1. **开头**：介绍事物名称 + 基本特点
2. **外形**（按顺序写）
3. **习性/功能/用途**（用说明方法）
4. **特点和价值**

### 📝 范文

> **我家的小台灯**
>
> 在我的书桌上，有一位"忠实的朋友"——一盏LED护眼台灯。它身高约40厘米，穿着一身白色的"外衣"。
>
> 它的灯杆可以随意弯曲，像一条灵活的长颈鹿脖子。灯罩是椭圆形的，里面藏着十几颗LED灯珠。这些灯珠虽然小，但亮度可不小——相当于60瓦的普通灯泡。而且它很省电，每小时的耗电量只有传统灯泡的五分之一。
>
> 最贴心的是它的"智能模式"。当我学习时间长了，它会自动变暗一点，提醒我该休息了。当我坐姿不端正离它太近时，它就会发出"滴滴"的警报声——比妈妈还严格！
>
> 这盏台灯已经陪伴我三年了。它就像我的老朋友，每天默默地照亮我的书本，见证着我的努力和进步。

> **为什么猫从高处摔下来不会受伤？**
>
> 你听说过"猫有九条命"吗？其实猫并不是真的有九条命，但它们确实有一种神奇的本领——从高处摔下来时，总能安全落地。
>
> 这是因为猫有"翻正反射"。当猫往下掉的时候，它的身体会先用眼睛和内耳判断哪边是上、哪边是下，然后在半空中迅速扭转身体——这个过程只需要不到一秒钟。四条腿先着地，加上猫爪上厚厚的肉垫，就像四个小弹簧，可以大大减缓冲击力。
>
> 所以小猫从三四层楼掉下来，往往拍拍屁股就走了。不过千万不要为了验证去推猫！如果楼层太高，猫也会受伤的。
>
> 猫的这个本领，是几百万年进化出来的生存技能。长知识了吧？

### ⚠️ 常见问题
1. ❌ 全篇列数字 → ✅ 多种方法结合
2. ❌ 主观感受太多 → ✅ 说明文以客观为主
3. ❌ 没有条理 → ✅ 按顺序写

### 🧠 写作指导

**① 从阅读中学写作（申怡·读写结合）**
回到本单元的课文，看看作者是怎么写的——
- 《太阳》：从这篇可以学到**列数字、作比较等说明方法——"一亿五千万千米""130万个地球"，用数据把抽象变具体**
- 《松鼠》：从这篇可以学到**文艺性说明——"面容清秀""帽缨形的尾巴"，科学知识也可以用生动的语言来表达**
→ 把这些方法用到你的作文里，语文课本就是最好的"作文书"。

**② 先搭架子再动笔（申怡·理科思维）**
动笔之前，先回答三个问题：
1. 我要写什么主题？
2. 分几段写？每段写什么？
3. 用什么材料来支撑？
列一个简单的提纲，就像盖房子先搭钢筋一样。框架稳了，文章就稳了。

**③ 说人话，说真话（温儒敏·回到常识）**
不要堆砌好词好句。把一件小事写清楚，比写一篇"漂亮"的空话强一百倍。写你自己真正看到、听到、感受到的——这样的文章，读起来才有温度。
