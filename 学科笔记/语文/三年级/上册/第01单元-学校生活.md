# 第一单元 · 学校生活

> 从暑假回到校园，看不同民族的学校、听花的读书声、学孙中山的勤学好问。
> **阅读重点**：关注有新鲜感的词句
> **习作目标**：猜猜他是谁（人物描写）

---

## 1 大青树下的小学

### 📖 课文概要
一所边疆小学，不同民族（汉族、傣族、景颇族、阿昌族、德昂族）的小朋友穿着各自的民族服装，来到学校一起上课。窗外有古老的铜钟、凤尾竹，还有猴子、松鼠来"听课"。

### 📜 知背景
- 作者：吴然，云南人，写了很多边疆儿童故事
- "大青树"是一种高大的榕树，南方村寨常把它当作"村口标志"
- 本文展现 **民族平等、团结友爱** 的主题

### 🌿 重点词语
| 词语 | 解释 |
|------|------|
| **早晨** | 从天亮到八九点的时间 |
| **鲜艳** | 颜色鲜明亮丽 |
| **服装** | 衣服鞋帽的总称 |
| **打扮** | 穿上衣服、装饰自己 |
| **绒球花** | 一种开成毛绒球状的花 |
| **招引** | 吸引 |
| **粗壮** | 又粗又结实 |
| **枝干** | 树木的枝和干 |

### ✍️ 生字
| 字 | 组词 | 字 | 组词 |
|:--:|:----|:--:|:----|
| **晨** | 早晨、清晨 | **绒** | 绒球、绒毛 |
| **球** | 足球、地球 | **汉** | 汉族、汉字 |
| **艳** | 鲜艳、艳丽 | **服** | 衣服、服务 |
| **装** | 服装、装扮 | **扮** | 打扮、装扮 |
| **粗** | 粗壮、粗心 | **静** | 安静、平静 |
| **停** | 停止、停下 | **孔** | 孔雀、面孔 |
| **雀** | 孔雀、麻雀 | **舞** | 跳舞、舞台 |

### 💡 有新鲜感的句子
> "同学们向在校园里欢唱的小鸟打招呼，向敬爱的老师问好，向高高飘扬的国旗敬礼。"

三个"向"排比，写出了同学们有礼貌、热爱祖国的样子。

> "这时候，窗外十分安静，树枝不摇了，鸟儿不叫了，蝴蝶停在花朵上，好像都在听同学们读课文。"

用"树枝、鸟儿、蝴蝶"的反应来衬托同学们读书好听——侧面描写。

## 2 花的学校

### 📖 课文概要
印度诗人泰戈尔的散文诗。花儿在地下的学校里上学，雷雨来时它们放假了，冲出地面，跳舞狂欢——诗人用想象把花儿写成了一群活泼的孩子。

### 📜 知背景
- 作者：**泰戈尔**，印度诗人，亚洲第一位诺贝尔文学奖得主
- 选自散文诗集《新月集》，用孩子的眼光看世界
- 郑振铎翻译

### 🌿 重点词语
| 词语 | 解释 |
|------|------|
| **荒野** | 荒凉的野外 |
| **口笛** | 用嘴吹的笛子 |
| **狂欢** | 纵情欢乐 |
| **罚站** | 被罚站在一边 |
| **衣裳** | 衣服 |
| **猜想** | 猜测想象 |

### ✍️ 生字
| 字 | 组词 | 字 | 组词 |
|:--:|:----|:--:|:----|
| **落** | 落下、落后 | **荒** | 荒野、荒凉 |
| **笛** | 口笛、笛子 | **舞** | 跳舞、舞台 |
| **狂** | 狂欢、疯狂 | **罚** | 惩罚、罚款 |
| **假** | 放假、请假 | **互** | 互相、互助 |
| **所** | 所以、住所 | **够** | 足够、能够 |
| **猜** | 猜想、猜测 | **扬** | 飞扬、表扬 |
| **臂** | 手臂、双臂 |

### 💡 重点品读
> "雨一来，他们便放假了。"

拟人。把花写成了盼望放假的孩子。

> "树枝在林中互相碰触着，绿叶在狂风里簌簌地响，雷云拍着大手。"

环境描写+拟人，写出暴风雨的声势。

> "你没有看见他们怎样地急着要到那儿去吗？你不知道他们为什么那样急急忙忙吗？"

反问。花为什么急着开放？因为它们也想找妈妈（大地/天空）。

## 3\* 不懂就要问（略读）

### 📖 课文概要
孙中山小时候在私塾读书，背了一天也不懂意思。他壮着胆子问先生，先生不但没骂他，还详细讲解了。孙中山说："学问学问，不懂就要问。"

### 📜 知背景
- 孙中山：中国近代民主革命家，中华民国临时大总统
- "私塾"是中国古代私人办的学校，学生只背诵不讲解
- 这个故事讲的是 **勇于提问、不糊弄** 的学习态度

### 🌿 重点词语
| 词语 | 解释 |
|------|------|
| **私塾** | 旧时的私人学校 |
| **照例** | 按照惯例 |
| **流利** | 说话又快又顺 |
| **糊里糊涂** | 不明白、不清楚 |
| **厉声** | 严厉的声音 |

### 💡 道理
> "学问学问，不懂就要问。为了弄清楚道理，挨打也值得。"

主动学习的精神——三年级了，不能再等着老师喂知识。

## ✍️ 习作：猜猜他是谁

### 🎯 目标
用文字描写一个同学，让大家猜出是谁。**抓住特征，不写名字。**

### 📐 写作框架

| 段落 | 写什么 | 示例 |
|:---:|:-------|:-----|
| ① 开头 | 他是谁？（不写名字） | "我们班有一个'小问号'" |
| ② 外貌特征 | 长相/发型/身高/衣着 | "他个子不高，圆圆的脸上嵌着一双亮晶晶的眼睛，一笑露出两颗大门牙。" |
| ③ 性格/爱好 | 他喜欢做什么/性格怎样 | "他最爱举手提问，老师说一个问题他能问出三个'为什么'。" |
| ④ 典型事例 | 一件具体的事 | "上次自然课，老师讲青蛙，他突然站起来问：'老师，青蛙为什么不吃死虫子？'把老师都问住了。" |
| ⑤ 结尾 | 你能猜出他是谁吗？ | "这就是我们班的'小问号'，你猜出他是谁了吗？" |

### 🧩 人物描写工具箱

**外貌**
- 脸型：圆脸、瓜子脸、国字脸
- 眼睛：水汪汪的、炯炯有神、眯成一条线
- 头发：短发扎成马尾、自然卷、齐刘海
- 特别标记：酒窝、大门牙、小虎牙、痣

**性格**
- 活泼开朗、文静内向、热心肠、幽默风趣、急性子、慢性子

**爱好**
- 爱看书、爱运动、爱画画、爱唱歌、爱问问题、爱帮助人

### 📝 范文（仅供参考）

> 他是我们班的"运动小达人"。
>
> 他个子高高的，瘦瘦的，两条长腿跑起来像一阵风。皮肤黑黑的，妈妈说那是"太阳给的勋章"。他笑起来特别阳光，露出一口白牙。
>
> 每次体育课，他总是第一个冲出去。上次校运会200米决赛，他像离弦的箭一样飞出去，第一个冲过终点线，全班同学都跳起来欢呼。
>
> 你猜到他是谁了吗？

---

> **我们班的"小书虫"**
>
> 她总是一个人坐在角落里看书。
>
> 她的眼睛不大，但看书的时候亮亮的，像两颗星星。头发扎成一条马尾辫，走起路来一甩一甩的。她最爱穿白色的T恤，干干净净的。
>
> 下课了，大家都冲出教室玩，只有她坐在座位上看《安徒生童话》。有一次我借她的书看，她特别高兴，跟我说了一大堆书里的故事，我这才知道——原来她不是不爱玩，是书里的世界太好玩了。
>
> 你猜到她是谁了吗？

### ⚠️ 常见问题
1. ❌ "他长得很可爱" → ✅ "他圆圆的脸上总是挂着两个小酒窝"
2. ❌ "他学习很好" → ✅ "每次数学课，老师的问题刚说完，他已经举手了"
3. ❌ 写得太笼统 → ✅ 用一件具体的事证明

### 🧠 写作指导

**① 从阅读中学写作（申怡·读写结合）**
回到本单元的课文，看看作者是怎么写的——
- 《大青树下的小学》：从这篇可以学到**抓特征**——作者写不同民族的同学，抓住了"民族服装"这个最明显的特征。你写同学，也要抓住他最特别的地方（大门牙、小酒窝、爱问问题……），而不是写千篇一律的"大大的眼睛、高高的个子"。
- 《花的学校》：从这篇可以学到**拟人**——泰戈尔把花写成渴望放假的孩子，有情感有动作。你写同学也可以让他"活"起来："他是我们班的'小问号'，一上课就像弹簧一样从座位上弹起来。"
→ 把这些方法用到你的作文里，语文课本就是最好的"作文书"。

**② 先搭架子再动笔（申怡·理科思维）**
动笔之前，先回答三个问题：
1. 我要写什么主题？（写哪个同学的什么特点）
2. 分几段写？每段写什么？（外貌→性格→事例→结尾）
3. 用什么材料来支撑？（具体的事例、外貌细节）
列一个简单的提纲，就像盖房子先搭钢筋一样。框架稳了，文章就稳了。

**③ 说人话，说真话（温儒敏·回到常识）**
不要堆砌好词好句。把一件小事写清楚，比写一篇"漂亮"的空话强一百倍。写你自己真正看到、听到、感受到的——这样的文章，读起来才有温度。
