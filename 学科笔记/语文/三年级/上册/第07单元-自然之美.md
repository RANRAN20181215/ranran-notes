## 21 大自然的声音

### 📖 课文概要
大自然有许多美妙的声音。风是大自然的音乐家，水也是大自然的音乐家，动物是大自然的歌手——整篇课文就是一首对自然的赞歌。

### 📜 知背景
- 这是一篇**散文**，用拟声词和比喻写出声音的美妙

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **美妙** | 美好奇妙 |
| **演奏** | 表演乐器 |
| **温柔** | 温和柔顺 |
| **雄伟** | 雄壮伟大 |
| **威力** | 强大的力量 |
| **汇聚** | 聚集到一起 |

### 💡 写法：拟声词大集合

| 声音来源 | 拟声词 |
|:---------|:-------|
| 风 | 轻轻柔柔的呢喃、雄伟的乐曲、热闹的音乐会 |
| 水 | 滴滴答答、叮叮咚咚、淙淙、潺潺、哗啦啦 |
| 动物 | 叽叽喳喳、唧哩哩 |

### 💡 结构

```
大自然的声音
├── 风（音乐家）：微风→狂风
├── 水（音乐家）：滴→小溪→河流→大海
└── 动物（歌手）：鸟→虫→蛙
```

**总—分—总**，每一段的开头都是中心句。

> "风，是大自然的音乐家。"
> "水，也是大自然的音乐家。"
> "动物是大自然的歌手。"

## 22 读不完的大书

### 📖 课文概要
大自然是一部永远读不完的大书——里面有高远的天空、千姿百态的植物、勇猛的动物……这本"书"有无穷的乐趣和奥秘。

### 📜 知背景
- 作者：朱维之
- "大书"的比喻——大自然像书一样值得读一辈子

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **高远** | 又高又远 |
| **沉思** | 深入思考 |
| **井然有序** | 整整齐齐、有条理 |
| **超凡脱俗** | 超过一般人、脱离世俗 |
| **雄健勇猛** | 强壮有力、勇敢凶猛 |

### 💡 排比句式
> "小麻雀叽叽喳喳，蹦蹦跳跳，叫人愉悦。老鹰在高空盘旋，展翅滑翔，突然猛扑而下，给人以雄健勇猛的感觉。"

用动词写出不同动物的特点。

## 23 父亲、树林和鸟

### 📖 课文概要
父亲一生最喜欢树林和唱歌的鸟。他能在没有鸟叫的树林里知道哪些树上有鸟——因为鸟在清晨最容易被露水打湿羽毛。父亲不是猎人。

### 📜 知背景
- 作者：牛汉
- **侧面描写**——通过父亲对鸟的了解，写出他对鸟的爱

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **突然** | 在很短时间里发生 |
| **雾蒙蒙** | 雾气很大、看不清楚 |
| **喃喃** | 小声自言自语 |
| **惊愕** | 非常吃惊 |
| **潮湿** | 含有水分比较多 |
| **舒畅** | 舒服痛快 |

### 💡 重点品读
> "父亲突然站定，朝幽深的雾蒙蒙的树林，上上下下地望了又望，用鼻子闻了又闻。"

三个叠用修饰语 + 两个动作 = **父亲对鸟的熟悉和专注**

> "我真高兴，父亲不是猎人。"

含义深刻：父亲这么了解鸟，如果是猎人，鸟就惨了。幸好他爱鸟、护鸟。

## ✍️ 习作：我有一个想法

### 🎯 目标
发现生活中的问题，提出改进建议。**这是三年级第一次写议论文/建议类作文。**

### 📐 写作框架

1. **现象**：我发现了什么问题
   - "我发现很多人去超市时都用塑料袋……"
2. **影响**：这个问题带来了什么后果
   - "塑料袋很难分解，会污染环境几百年……"
3. **建议**：我有一个想法
   - "我建议大家都带环保袋去购物……"
4. **号召**：希望大家怎么做
   - "让我们一起为地球做些力所能及的事吧！"

### 🧩 可以写什么

| 问题类型 | 例子 |
|:---------|:-----|
| **学校** | 午餐浪费、课间追逐打闹、图书角没人整理 |
| **家里** | 爸妈看手机不理人、东西乱放找不到 |
| **社区** | 垃圾分类不彻底、小区草坪被踩 |
| **社会** | 共享单车乱停、宠物随地大小便 |

### 📝 范文

> **我有一个想法**
>
> 我发现，每次放学时，校门口就堵得水泄不通。汽车、电动车、自行车挤在一起，喇叭声此起彼伏，行人在车缝里钻来钻去，非常危险。
>
> 我觉得这样下去不行。堵车不仅浪费时间，还可能发生交通事故。
>
> 我有一个想法：学校可以实行"错峰放学"，不同年级隔五分钟放学。家长们可以约定一个固定的接送点，不要全挤在校门口。还可以提倡高年级同学自己走路上学。
>
> 希望我们的校门口能变得安全又通畅。

---

> **我有一个想法**
>
> 我发现班里的图书角越来越没人去了。书架上落了一层灰，有几本书还被人弄破了。
>
> 我觉得这样很可惜。书没人看，就像玩具没人玩一样，太浪费了。
>
> 我有一个想法：我们可以选一个"图书管理员"，每周换一个人当。每个同学轮流管图书角——整理书架、修补破书、登记借还。还可以在每本书的最后一页贴一张"读后留言卡"，读完的人写上自己的名字和一句话感想。看到别人都读了，大家就会好奇，也想去读。
>
> 希望我们的图书角重新"活"起来，让大家爱上读书。

### ⚠️ 常见问题
1. ❌ 只抱怨不解决 → ✅ 每个问题都配上建议
2. ❌ 建议太空 → ✅ "建议具体怎么做"（可执行）
3. ❌ 没有说服力 → ✅ 写清楚"为什么"（影响/后果）

### 🧠 写作指导

**① 从阅读中学写作（申怡·读写结合）**
回到本单元的课文，看看作者是怎么写的——
- 《大自然的声音》：从这篇可以学到**用心感受身边事物**——作者把风声写成"音乐家"，把水声写成"演奏"，把动物叫声写成"歌手"。如果你要写"我有一个想法"，前提是你得先发现生活中的问题——而发现问题的第一步，就是像作者一样用心感受周围的一切。你注意到课间有人追跑打闹了吗？你注意到午餐有人浪费了吗？
- 《父亲、树林和鸟》：从这篇可以学到**从细节发现问题**——父亲能从没有鸟叫的树林里知道哪些树上有鸟，因为他闻到了鸟的气味、看到了露水打湿的羽毛。你提建议也要这样：先找到具体的细节证据——"我发现每次放学，校门口挤满了车"比"校门口很乱"更有说服力。
→ 把这些方法用到你的作文里，语文课本就是最好的"作文书"。

**② 先搭架子再动笔（申怡·理科思维）**
动笔之前，先回答三个问题：
1. 我发现了一个什么问题？（具体现象，不是空话）
2. 这个问题有什么影响/危害？（说清楚后果）
3. 我有什么具体的建议？（可以执行的办法）
列一个简单的提纲，就像盖房子先搭钢筋一样。框架稳了，文章就稳了。

**③ 说人话，说真话（温儒敏·回到常识）**
不要堆砌好词好句。建议类作文最怕"口号"——"让我们共同创建美好家园"不如"我建议每个同学都带一个布袋去买东西"实在。写你真正观察到的问题、真正想得出的办法——这样的文章，读起来才有温度。
