## 三年级写作进阶路径

| 阶段 | 上册单元 | 写作类型 | 核心能力 |
|:---:|:--------:|:---------|:---------|
| ① | 一 | 人物描写 | 抓特征、选事例 |
| ② | 二 | 日记 | 观察生活、记录感受 |
| ③ | 三 | 创编童话 | 想象力+故事结构 |
| ④ | 四 | 续写 | 逻辑推理+情节衔接 |
| ⑤ | 五 | 观察写作 | 五感观察、有序表达 |
| ⑥ | 六 | 写景 | 围绕中心句写具体 |
| ⑦ | 七 | 建议类 | 发现问题+提出方案 |
| ⑧ | 八 | 记事 | 按顺序写清楚经过 |

下册在此基础上深化，增加：看图写作、实验作文、想象作文、写人、资料整理等类型。

> 每个单元笔记的结构：课文精读 → 重点知识 → **习作引导（模型+框架+范文）**
