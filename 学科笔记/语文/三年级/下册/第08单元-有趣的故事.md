# 第八单元 · 有趣的故事

> 慢性子裁缝和急性子顾客、漏、枣核——故事里充满了意外和趣味。
> **阅读重点**：了解故事的主要内容，复述故事
> **习作目标**：这样想象真有趣（反转想象作文）

## 25 慢性子裁缝和急性子顾客

### 📖 课文概要
一个急性子顾客要做棉袄，遇到了慢性子裁缝。裁缝说："明年冬天来取吧。"顾客嫌太慢。但裁缝说："我已经把布料夹在柜子里了——您不用等到冬天，现在就穿不上啦！"

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **性子** | 性格、脾气 |
| **交货** | 交付货物 |
| **笑话** | 可笑的事 |
| **手艺** | 手工技艺 |
| **负责** | 尽到责任 |
| **夸奖** | 表扬、称赞 |
| **服务** | 为别人做事 |

### 💡 对比写人

| | 急性子顾客 | 慢性子裁缝 |
|:--|:-----------|:-----------|
| 说话 | 又急又快 | 慢悠悠 |
| 要求 | 要快！越快越好 | 急什么 |
| 时间 | 今天→明天→三天 | 明年冬天 |

反复结构：顾客一次次改要求（做棉袄→夹袄→衬衫→春装），裁缝每次都慢悠悠答应——最后说"布还没动呢"！

**幽默**：最大的反转是——布料还夹在柜子里！

## 26\* 方帽子店（略读）

### 📖 课文概要
一家帽子店只卖方帽子，因为老板认为"从来如此"。但孩子们不喜欢方帽子，做了圆帽子来戴。最后方帽子成了古董，圆帽子取代了方帽子。

### 💡 道理
**不能固步自封**。时代在变，观念也要更新。"从来如此"不一定就对。

## 27 漏

### 📖 课文概要
老虎和贼都想去偷老公公家的驴。老虎听到老婆婆说"怕漏"，以为"漏"是一个可怕的怪物。老虎和贼互相以为对方是"漏"，吓得落荒而逃——结果只是一个误会。

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **翻山越岭** | 翻过很多山 |
| **走南闯北** | 走过很多地方 |
| **粘胶** | 胶水 |
| **旋风** | 螺旋状的风 |
| **惊恐** | 非常害怕 |

### 💡 复述故事（本单元重点）

**按"地点变化"复述**：

1. 老公公家：老婆婆说"漏"→老虎和贼听到
2. 逃跑路上：老虎驮着贼跑
3. 树下：老虎和贼互相看见→都以为对方是"漏"
4. 结果：天亮了，什么都没发生

**方法**：抓住角色+地点+关键情节。

## 28\* 枣核（略读）

### 📖 课文概要
一个像枣核那么大的孩子，名叫枣核。他个子小但本事大——帮乡亲们赶牛、斗县官。县官把他装在钱褡里，他却蹦出来哈哈大笑。

### 💡 道理
**人小志气大，不能以貌取人。** 也叫**民间故事**。

## ✍️ 习作：这样想象真有趣

### 🎯 目标
选择一种动物，把它的某个特征**反过来想**（变大、变小、会飞、会跑、会说话……），编一个有趣的故事。

### 🧩 反转想象

| 动物 | 原特征 | 反转 | 故事方向 |
|:----|:-------|:-----|:---------|
| 蚂蚁 | 很小 | 变得比树还大 | 它怎么走路？吃什么？大家怕它？ |
| 蜗牛 | 很慢 | 跑得比豹子还快 | 壳怎么办？它还想慢下来？ |
| 母鸡 | 不会飞 | 飞上天空 | 能飞多高？要不要参加飞行比赛？ |
| 老鹰 | 很强壮 | 变得胆小如鼠 | 它怕什么？怎么捕食？ |
| 乌龟 | 很慢 | 健步如飞 | 壳还会是负担吗？和兔子再赛跑？ |

### 📐 写作框架

1. **开头**：这只动物本来是什么样 + 发生了什么变化
   - "有一只蜗牛，它做什么都慢吞吞的，大家都嫌它慢。有一天它喝了一口神奇的泉水……"
2. **变化后**：它有了什么新本事
   - "现在它跑起来像一阵风！"
3. **发生了什么**：用变化后的能力做了什么事
   - 帮助别人/闹了笑话/遇到了麻烦
4. **结局**：它喜欢这个变化吗？

### 📝 范文

> **跑得比风还快的蜗牛**
>
> 森林里住着一只小蜗牛，名叫慢慢。它做什么都很慢——上学迟到，吃饭吃到午饭才吃完，赛跑永远是最后一名。
>
> 有一天，慢慢无意中喝了一口亮晶晶的泉水。突然，它觉得浑身充满力量。它试着爬了一下——"嗖——"像火箭一样飞了出去！
>
> "哇！我变成飞毛腿了！"慢慢兴奋极了。
>
> 它去参加森林运动会。发令枪一响，其他选手才迈出一步，慢慢已经冲过了终点。兔子瞪大了眼睛，豹子张大了嘴巴——他们都不相信蜗牛能拿冠军！
>
> 可是慢慢也有烦恼。以前它喜欢一边爬一边看风景，现在太快了，什么都看不清。而且它的朋友们也追不上它了。
>
> 后来慢慢发现，快有快的好，慢有慢的好。重要的是做自己开心的事。偶尔它还是会用飞快的速度帮助别人——比如给乌龟奶奶送快递，那可真是一绝！

### ⚠️ 常见问题
1. ❌ 反转后没有故事 → ✅ 让变化推动情节
2. ❌ 变化太大失去特点 → ✅ 保留一些原特征（蜗牛的壳还在）
3. ❌ 只有搞笑没有意思 → ✅ 加点小小的道理
