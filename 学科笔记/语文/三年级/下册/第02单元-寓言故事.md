## 5 守株待兔（文言文）

### 📖 课文概要
一个农夫捡到一只撞死在树桩上的兔子，就天天守在树桩旁等兔子再来，结果田荒了，兔子也没等到。

### 📜 原文 & 翻译
**原文**：宋人有耕者。田中有株。兔走触株，折颈而死。因释其耒而守株，冀复得兔。兔不可复得，而身为宋国笑。

**翻译**：宋国有一个耕田的人。田里有一棵树桩。一只兔子跑过来撞在树桩上，折断脖子死了。于是他就放下农具守着树桩，希望能再捡到兔子。兔子不可能再得到了，他自己却被宋国人笑话。

### 🌿 重点字词
| 字 | 意思 |
|:--|:-----|
| 株 | 树桩 |
| 触 | 撞到 |
| 释 | 放下 |
| 耒 | 农具 |
| 冀 | 希望 |
| 为 | 被 |

### 💡 道理
**不要存侥幸心理**，把偶然当必然。踏踏实实做事才能有收获。

## 6 陶罐和铁罐

### 📖 课文概要
国王的御厨里，铁罐总是嘲笑陶罐"一碰就碎"。很多年后，宫殿倒塌了，铁罐锈成了一堆土，陶罐却完好无损地被人们挖出来。

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **骄傲** | 自以为了不起 |
| **傲慢** | 看不起别人 |
| **谦虚** | 虚心、不骄傲 |
| **懦弱** | 软弱不坚强 |
| **轻蔑** | 瞧不起 |
| **争辩** | 争论、辩论 |
| **价值** | 用处、意义 |

### 💡 对比
| | 陶罐 | 铁罐 |
|:--|:-----|:-----|
| 态度 | 谦虚、友好 | 傲慢、无理 |
| 结局 | 完好无损 | 锈蚀消失 |

**道理**：每个人都有长处和短处，不要拿自己的长处嘲笑别人的短处。

## 7 鹿角和鹿腿

### 📖 课文概要
鹿非常喜欢自己美丽的角，却讨厌自己细长的腿。突然遇到狮子，美丽的角差点被树枝挂住害死它，而难看的腿却帮它逃脱了。

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **匀称** | 均匀、比例合适 |
| **精美** | 精致美丽 |
| **别致** | 与众不同 |
| **抱怨** | 埋怨 |
| **犹豫** | 拿不定主意 |
| **没精打采** | 没有精神、萎靡不振 |
| **灰心丧气** | 失去信心、失望 |

### 💡 道理
> "两只美丽的角差点儿送了我的命，可四条难看的腿却让我狮口逃生！"

**不要以貌取"物"**——有用的东西不一定好看，好看的东西不一定有用。

## 8\* 池子与河流（略读）

### 📖 课文概要
池子安于现状，天天安逸地睡觉；河流忙碌地奔腾不息。许多年后，池子干涸了，河流依然滚滚向前。

### 💡 道理
**生命在于运动**。懒惰安逸的终将消亡，勤劳进取的才能长存。

## ✍️ 习作：看图画，写一写

### 🎯 目标
观察一幅图画，把看到的、想到的按顺序写下来。**学会看图作文。**

### 📐 写作框架

1. **整体观察**（一句话概括）
   - "这幅图画的是春天的田野里，几个小朋友在放风筝。"
2. **背景/环境**（时间地点天气）
   - "蓝蓝的天空中飘着几朵白云，草地绿油油的……"
3. **主体内容**（谁在干什么，按顺序写）
   - 近处：一个男孩拉着风筝线往前跑，另一个举着风筝
   - 远处：小女孩拿着蝴蝶风筝，一家三口在放风筝
4. **细节/想象**（给画面加故事）
   - "小男孩边跑边回头喊：'风来了，快放手！'"
5. **感受**（看完这幅图你想说什么）
   - "看着这幅图，我恨不得马上也去放风筝！"

### 🧩 观察顺序

```
整体 → 环境 → 主要人物 → 次要人物 → 细节 → 感受
```

### 📝 范文

> **放风筝**
>
> 星期天的下午，阳光明媚，微风习习。三个好朋友来到公园的草坪上放风筝。
>
> 小明举着燕子风筝，小红拉着线，站在不远处。"我数到三，你就放手！"小红喊道。小明大声回答："准备好了！""一、二、三——放！"小红飞快地跑起来，燕子风筝摇摇摆摆地飞上了天。
>
> 远处，一个小弟弟也在放风筝。他的三角形风筝飞得最高。旁边，他的爸爸妈妈正微笑着看着他。
>
> 天空中五颜六色的风筝越来越多，像一群快乐的小鸟在自由飞翔。
>
> 看着这幅画面，我觉得春天真美好！这个周末我也要让爸爸带我去放风筝。

### ⚠️ 常见问题
1. ❌ 只写看到的不写想到的 → ✅ 加上人物对话和心理
2. ❌ 顺序乱 → ✅ 按远近或主次顺序
3. ❌ 没有开头结尾 → ✅ 加上总起和总结
