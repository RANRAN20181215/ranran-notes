## 13 花钟

### 📖 课文概要
为什么不同的花开放时间不同？原来花开放的时间跟温度、湿度、光照、昆虫活动有关。植物学家把不同时间开放的花种在一起，就成了"花钟"。

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **争奇斗艳** | 竞相展示美丽 |
| **芬芳迷人** | 香味浓郁吸引人 |
| **吻合** | 完全符合 |
| **大致** | 大概、大约 |
| **传播** | 广泛散布 |

### 💡 花钟时间表
| 时间 | 花 | 原因 |
|:---:|:---|:-----|
| 凌晨4点 | 牵牛花 | 气温低、湿度大 |
| 5点 | 蔷薇 | 同上 |
| 7点 | 睡莲 | 光照变化 |
| 中午12点 | 午时花 | 光照最强 |
| 下午3点 | 万寿菊 | 温度最高 |
| 晚上7点 | 月光花 | 夜间开放 |
| 8点 | 夜来香 | 吸引夜行昆虫 |

### 💡 关键句
第一段关键句："不同的植物为什么开花的时间不同呢？"——下面全是回答。

## 14 蜜蜂

### 📖 课文概要
法国科学家法布尔做了一个实验：在蜂窝里抓了四十只蜜蜂，在它们身上做白色记号，装进纸袋，走四公里路放掉它们。结果二十多只蜜蜂准确飞回了家——蜜蜂有辨认方向的能力。

### 📜 知背景
- 作者：**法布尔**，法国昆虫学家，《昆虫记》作者
- 本文是**实验报告**的雏形

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **辨认** | 识别、分辨 |
| **试验** | 尝试验证 |
| **证实** | 证明是真的 |
| **推测** | 根据已知推想未知 |
| **准确** | 完全正确 |
| **逆风** | 跟风吹来的方向相反 |

### 💡 实验报告结构

| 步骤 | 内容 |
|:----|:-----|
| **提出问题** | 蜜蜂有辨认方向的能力吗？ |
| **准备** | 40只蜜蜂、白色记号、纸袋 |
| **过程** | 四公里外放掉 |
| **结果** | 二十多只飞回来了 |
| **结论** | 蜜蜂有辨认方向的能力 |

## 15\* 小虾（略读）

### 📖 课文概要
"我"从小溪里捉了一些小虾养在缸里。小虾很有趣——有的全身透明，有的带灰黑色；它们吃东西时小心翼翼，打架时却很凶猛。

### 💡 观察小技巧
- 看外形（颜色、大小）
- 看动作（吃食、打架、休息）
- 看变化（时间长了怎么样）

## ✍️ 习作：我做了一项小实验

### 🎯 目标
写一个自己做过的小实验，按**实验步骤**写清楚。

### 🧩 实验作文框架

| 部分 | 写什么 |
|:----|:-------|
| **实验名称** | 什么实验 |
| **准备材料** | 用了什么 |
| **实验过程** | 先……然后……最后…… |
| **实验结果** | 发生了什么 |
| **我的结论** | 为什么会这样 |

### 🧩 简单小实验推荐

| 实验 | 材料 | 原理 |
|:----|:----|:-----|
| 鸡蛋浮起来 | 水杯、盐、鸡蛋 | 盐水密度大 |
| 彩虹桥 | 水杯、纸巾、色素 | 毛细现象 |
| 会跳舞的葡萄干 | 雪碧、葡萄干 | 二氧化碳气泡 |
| 火山爆发 | 小苏打、白醋 | 酸碱反应 |

### 📝 范文

> **鸡蛋浮起来的秘密**
>
> 今天我做了一个有趣的小实验——让鸡蛋浮起来。
>
> 我准备了一个透明的玻璃杯、一个生鸡蛋、一包盐和一根筷子。
>
> 我先在杯子里倒了大半杯水，轻轻地把鸡蛋放进去。鸡蛋"扑通"一声沉到了杯底，躺在那里一动不动。
>
> 接着，我往水里加了一勺盐，用筷子搅拌。盐融化了，可鸡蛋还是纹丝不动。我又加了两勺盐，继续搅拌。这时，神奇的事情发生了——鸡蛋慢慢离开了杯底，摇摇晃晃地浮到了水中间！
>
> "再加一勺试试！"我兴奋地想。当我加进第四勺盐后，鸡蛋竟然露出了半个脑袋！
>
> 我查了资料才知道，原来盐水的密度比清水大，浮力也更大，所以鸡蛋就浮起来了。
>
> 这个实验太有意思了！科学真的很奇妙。

### ⚠️ 常见问题
1. ❌ 只写结果不写过程 → ✅ 按步骤一步一步写
2. ❌ 没有动作和心理 → ✅ 加"我小心翼翼地……""我兴奋地……"
3. ❌ 不知道为什么 → ✅ 查资料，写出科学原理
