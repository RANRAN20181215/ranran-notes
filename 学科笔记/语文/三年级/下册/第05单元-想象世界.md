## 16 小真的长头发

### 📖 课文概要
小叶和小美都有长头发，小真只有短短的娃娃头。但小真想象自己的头发长起来——能钓鱼、能拉牛、能做被子、能晾衣服……她的想象比谁的头发都长！

### 📜 知背景
- 这是一篇**想象故事**，教孩子怎么用想象力"变出"精彩

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **悠闲** | 悠闲自得 |
| **羡慕** | 看见别人好，希望自己也这样 |
| **碍事** | 不方便、妨碍 |
| **泡沫** | 聚在一起的小泡泡 |

### 💡 小真的想象清单

| 想象 | 功能 |
|:----|:-----|
| 头发垂到水里 | 钓鱼！ |
| 头发甩到树上 | 套住牛！ |
| 头发烫起来变成树林 | 让小鸟做窝！ |
| 头发当被子 | 盖在身上又香又暖！ |
| 头发当晾衣绳 | 晾衣服！ |

**方法**：从"长"这个特点出发，想出一连串的用途。**特点→联想→夸张。**

### ✍️ 句式
"要是……就能……"
> "要是我的头发长到能拖到地上，就能当拖把帮妈妈拖地了！"

## 17 我变成了一棵树

### 📖 课文概要
"我"不想吃饭想一直玩，就变成了一棵树。结果妈妈还是端着好吃的来了，还住在树上的鸟窝里。"我"闻着香味流口水——树叶发出哗啦啦的声音。

### 📜 知背景
- 作者：顾鹰
- 一个关于**母爱的故事**——不管孩子变成什么，妈妈总有办法

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **希望** | 心里想达到某种目的 |
| **麻烦** | 烦琐难办的事 |
| **秘密** | 不让人知道的事 |
| **香喷喷** | 形容香味浓 |
| **津津有味** | 吃得很有味道 |

### 💡 写法
**变形的想象**——现实中做不到的，在想象里全可以。
但最后还要回到现实——妈妈理解孩子，孩子也需要妈妈。

## ✍️ 习作：奇妙的想象

### 🎯 目标
写一个想象故事，让读者觉得"哇，太神奇了！"

### 🧩 想象方法

| 方法 | 说明 | 例子 |
|:----|:-----|:-----|
| **反着想** | 把现实反过来 | 如果我变成了蚂蚁会怎样？ |
| **极端想** | 把某个特点放大 | 如果我的书包能无限变大？ |
| **拟人想** | 物品变成人 | 文具盒里的文具吵架了？ |
| **穿越想** | 去另一个世界 | 我走进了课本里的世界 |

### 📐 写作框架

1. **起因**：怎么开始的
   - "那天晚上，我正写着作业，突然……"
2. **奇妙经历**：发生了什么
   - 我变小了/物品活了/到了另一个世界
3. **波折**：遇到什么困难
   - "可是风太大，我被吹上了天……"
4. **结局**：怎么样了
   - "我醒了，原来是一场梦……"（也可以不醒！）

### 📝 范文

> **躲在草丛里的星星**
>
> 有一颗小星星，觉得在天上太无聊了。每天都是发光、眨眼、看下面的人类——它好想去地上玩一玩。
>
> 有一天，它趁月亮妈妈不注意，用力一跳——"嗖——"拖着一道金色的尾巴落到了地上。
>
> "哇！"它滚进了草丛里。草叶比它的身体还高。一只萤火虫飞过来："你是谁？怎么比我还亮？"
>
> "我是星星！"小星星骄傲地说。萤火虫带着它在草丛里探险——看蜗牛赛跑、听蟋蟀唱歌、坐在荷花上看月亮。
>
> 可是，没了星星，天上缺了一角，孩子们找不着它了。小星星想了想，决定回到家。
>
> 它使劲往上一跳——"嗖——"又飞回了天上。从此，它每晚都对着地面闪三下，那是和萤火虫朋友说"晚安"。

### 🧩 题目推荐

| 题目 | 方向 |
|:----|:-----|
| 一本有魔法的书 | 书里的内容会变成真的 |
| 手罢工啦 | 手不干了，会发生什么 |
| 滚来滚去的小土豆 | 小土豆要去哪里 |
| 假如人类可以冬眠 | 冬天全部睡觉会怎样 |

### ⚠️ 常见问题
1. ❌ 想象不够"奇" → ✅ 大胆想，反常理
2. ❌ 只有想象没有故事 → ✅ 加上起因经过结果
3. ❌ 一到结尾就"原来是一场梦" → ✅ 可以不醒，让想象世界一直存在
