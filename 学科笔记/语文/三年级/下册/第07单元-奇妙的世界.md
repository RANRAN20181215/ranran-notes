## 22 我们奇妙的世界

### 📖 课文概要
这是一个奇妙的世界——一切都在生长变化。天空的珍藏：太阳、云彩、雨点、冰雪、鸟飞、蝴蝶；大地的珍藏：植物、水果、岩石、贝壳。只要我们仔细观察，就能发现这个世界的美。

### 📜 知背景
- 作者：英国作家彼得·西摩
- **从不同角度写同一个主题**——"奇妙"

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **奇妙** | 神奇巧妙 |
| **呈现** | 展现出来 |
| **变幻** | 变化、变换 |
| **光芒** | 四射的光线 |
| **闪烁** | 光亮一闪一闪 |
| **感叹** | 因感慨而发出声音 |
| **锋利** | 刀口快、尖锐 |

### 💡 结构

```
总：这是一个奇妙的世界
├── 天空的珍藏
│   ├── 太阳（升起→落下）
│   ├── 云彩（各种形状）
│   ├── 雨点（降落）
│   └── 冰雪（融化）
└── 大地的珍藏
    ├── 植物（生长→开花→结果）
    ├── 水果（颜色变化）
    └── 岩石（各种形状和颜色）
总：世界上存在的奇妙事物是无穷的
```

**总—分—总**，每个部分都从不同方面展开。

## 23 海底世界

### 📖 课文概要
海底是怎样的？海面上波涛澎湃的时候，海底依然宁静。海底有发光的鱼像闪烁的星星、有各种各样的声音、有丰富的动物（海参、乌贼、章鱼、贝类）、有茂密的植物（海藻）、还有丰富的矿产（石油、天然气、煤）。

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **波涛澎湃** | 波浪汹涌 |
| **窃窃私语** | 小声说话（拟人） |
| **蕴藏** | 蓄积而未显露 |
| **储藏** | 存放、储存 |
| **宁静** | 安静、平静 |
| **闪烁** | 光一闪一闪 |

### 💡 每段的关键句

| 段落 | 关键句 | 写了什么 |
|:----|:-------|:---------|
| 2 | 海底有光 | 发光鱼 |
| 3 | 海底有声音 | 窃窃私语 |
| 4 | 海里的动物各有各的活动方法 | 海参、乌贼、贝类等 |
| 5 | 海底有植物 | 海藻 |
| 6 | 海底有矿产 | 石油、天然气 |

**围绕关键句展开**——这是"把事物写清楚"的方法。

## 24 火烧云

### 📖 课文概要
晚饭过后，火烧云上来了。天空像着了火——葡萄灰、梨黄、茄子紫、半紫半黄、半灰半百合色。云的形状也不断变化——马→狗→狮子→然后什么也不像了。一会儿工夫，火烧云下去了。

### 📜 知背景
- 作者：萧红，民国女作家，代表作《呼兰河传》
- 这是一篇**写景散文**，主打颜色变化和形状变化

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **红彤彤** | 非常红 |
| **凶猛** | 凶恶强大 |
| **恍恍惚惚** | 看不清楚、模糊 |
| **镇静** | 沉着不慌乱 |

### 💡 颜色描写
> "这地方的火烧云变化极多，一会儿红彤彤的，一会儿金灿灿的，一会儿半紫半黄，一会儿半灰半百合色。"

**格式**：一会儿……一会儿……一会儿……
**特殊颜色**：葡萄灰、梨黄、茄子紫——用水果蔬菜形容颜色，新颖生动！

### 💡 形状变化
马→狗→狮子→消失——**层层推进**，越来越模糊。

## ✍️ 习作：国宝大熊猫

### 🎯 目标
搜集资料，整合信息，从几个方面介绍大熊猫。

### 🧩 资料搜集清单

| 方面 | 问题 |
|:----|:-----|
| 基本特征 | 大熊猫是猫吗？属于什么科？ |
| 外形 | 长什么样？为什么叫"熊猫"？ |
| 分布 | 生活在哪儿？（四川/陕西/甘肃） |
| 食物 | 吃什么？一天吃多少竹子？ |
| 习性 | 会爬树吗？冬眠吗？ |
| 保护现状 | 为什么是国宝？有多少只？ |

### 📐 写作框架

1. **引入**：用一种有趣的方式开头
   - "有一种动物，它有着黑白相间的毛，圆滚滚的身体，走起路来一摇一摆——它就是国宝大熊猫。"
2. **外形**：按顺序描写
   - 头→身体→四肢→尾巴
3. **生活习性**：吃什么、住在哪、爱干什么
4. **为什么是国宝**：珍稀、中国特有、外交礼物
5. **结尾**：我们要保护大熊猫

### 📝 范文

> **国宝大熊猫**
>
> 大熊猫是中国的国宝，也是世界上最可爱的动物之一。
>
> 大熊猫长得很特别。它全身胖乎乎的，毛色黑白分明——圆圆的脸上有两只黑眼圈，像戴了一副墨镜。四肢是黑色的，肚子是白色的，走起路来一摇一摆，憨态可掬。
>
> 大熊猫最喜欢吃竹子。它一天要吃十几公斤的竹子，坐着吃、躺着吃、靠着树吃，各种姿势都有。虽然大熊猫属于食肉目，但99%的食物都是竹子，真是"素食主义者"。
>
> 大熊猫非常珍稀。全世界野生大熊猫只有不到2000只，只生活在中国四川、陕西和甘肃的山区。它是中国特有的动物，也是和平友好的象征，经常作为"外交使者"到国外居住。
>
> 大熊猫是我们的国宝，我们要爱护环境和森林，让大熊猫永远快乐地生活下去。

### ⚠️ 常见问题
1. ❌ 全篇抄资料 → ✅ 把资料变成自己的话
2. ❌ 东一句西一句 → ✅ 分类写（外形/习性/保护）
3. ❌ 没有趣味 → ✅ 加可爱的小细节（吃竹子的姿势、打滚的样子）
