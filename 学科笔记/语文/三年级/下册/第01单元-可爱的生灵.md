# 第一单元 · 可爱的生灵

> 春天来了——看看燕子的身姿、闻闻荷花的清香、听听昆虫的故事。
> **阅读重点**：边读边想象画面
> **习作目标**：我的植物朋友（观察卡片→作文）

---

## 1 古诗三首

### 绝句 · 杜甫

> 迟日江山丽，春风花草香。
> 泥融飞燕子，沙暖睡鸳鸯。

**写作背景**：公元764年，杜甫53岁。经过八年的安史之乱，他终于回到成都草堂，过上了稍微安定的日子。春天来了——太阳暖暖的，花草香香的，燕子飞回来筑巢，鸳鸯在沙滩上晒太阳。他坐在院子里，写下了这首最简单的快乐。

**诗人逸事**：杜甫一生颠沛流离。安史之乱中他带着妻儿逃难，差点饿死。他最小的儿子因为饥饿夭折了。但你看这首诗——"迟日江山丽，春风花草香"——没有任何怨言，只有对春天纯粹的赞美。在成都草堂的这几年，是他一生中最温柔的时光。

**时代印记**：安史之乱（755-763年）刚刚结束，唐朝从鼎盛走向衰落。这首诗的珍贵之处在于——它在乱世之后写出了和平的可贵：泥融燕子飞，沙暖鸳鸯睡，这才是太平该有的样子。

**🔑 注释**
- 迟日：春天的太阳（白天变长了）
- 丽：美丽
- 泥融：泥土湿软
- 鸳鸯：水鸟，成对生活

**💡 动词**："飞"——燕子忙着筑巢；"睡"——鸳鸯悠闲享受。**一动一静**。

---

### 惠崇春江晚景 · 苏轼

> 竹外桃花三两枝，春江水暖鸭先知。
> 蒌蒿满地芦芽短，正是河豚欲上时。

**写作背景**：这是一首"题画诗"——苏轼的朋友惠崇和尚画了一幅《春江晚景》，苏轼在画上题了这首诗。他根本没去过画里的地方，却写出"春江水暖鸭先知"——想象力比亲身经历还真实。

**诗人逸事**：惠崇是北宋著名的画家兼诗僧，和苏轼是铁哥们。两人常一起谈诗论画，可惜惠崇的画后来全部失传了——我们再也看不到那幅《春江晚景》。但苏轼的这首诗保留了下来。画没了，诗还在，这就是文字的魔力。

**时代印记**：北宋文人流行"题画诗"——对着朋友的画即兴写诗。这是一种很高雅的社交活动。苏轼尤其擅长此道——他没到过画中的地方，却写得比亲眼见过还真切。

**🔑 注释**
- 惠崇：宋代画家、僧人
- 蒌蒿：一种野菜
- 芦芽：芦苇嫩芽
- 河豚：一种鱼，味道鲜美但有微毒
- 上：逆流而上

**💡** "春江水暖鸭先知"——鸭子最先知道水暖了，因为它们在水中。**生活经验→哲理**：只有亲身经历的人最了解情况。

### 三衢道中 · 曾几

> 梅子黄时日日晴，小溪泛尽却山行。
> 绿阴不减来时路，添得黄鹂四五声。

**写作背景**：初夏五月，梅子成熟的季节。曾几走在浙江三衢山的小路上——难得的是，梅雨季节居然天天放晴。他先坐船，船到尽头了又改走山路。一路绿荫比来时还浓密，还多了几声黄鹂的叫声——心情好得不得了。

**诗人逸事**：曾几是南宋著名诗人，也是陆游的老师。他教陆游写诗，传授了一句秘诀——"功夫在诗外"：不要光在文字上下功夫，要多走路、多经历。这首《三衢道中》就是最好的示范——一次普通的路边散步，变成了千古名诗。

**时代印记**：南宋初期，朝廷偏安江南。曾几主张抗金，但晚年过着隐居的生活。这首诗里的轻松愉快，其实是一个爱国诗人难得的闲暇时光。

**🔑 注释**
- 三衢：山名，在浙江
- 梅子黄时：五月梅子成熟时
- 泛：坐船
- 却：改、换
- 不减：不少于

**💡** "添得黄鹂四五声"——用声音写出山林的生机。

## 2 燕子

### 📖 课文概要
一身乌黑的羽毛，一对俊俏轻快的翅膀，加上剪刀似的尾巴——这就是活泼机灵的小燕子。春天来了，燕子从南方飞回来，为春光增添了许多生趣。

### 📜 知背景
- 作者：郑振铎，现代作家、学者

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **俊俏** | 长得好看 |
| **吹拂** | 微风轻轻吹 |
| **聚拢** | 收拢、聚集 |
| **增添** | 增加添加 |
| **生趣** | 生活的情趣 |
| **偶尔** | 有时候 |
| **荡漾** | 水波一圈圈散开 |

### 💡 外形描写（按顺序）
> "一身乌黑的羽毛，一对俊俏轻快的翅膀，加上剪刀似的尾巴，凑成了那样可爱的活泼的小燕子。"

**从头到尾**：羽毛→翅膀→尾巴，寥寥几笔就画出一只燕子。

### 💡 动词
"掠"——飞得快；"沾"——轻轻点水；"横掠""斜飞"——写出飞行的姿态。

## 3 荷花

### 📖 课文概要
"我"去公园看荷花。荷叶挨挨挤挤，荷花从中间冒出来——有的全开，有的才开两三瓣，有的还是花骨朵。微风吹来，"我"觉得自己也变成了一朵荷花在舞蹈……

### 📜 知背景
- 作者：叶圣陶，著名作家、教育家
- 这是一篇**写景抒情散文**

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **清香** | 清淡的香味 |
| **挨挨挤挤** | 挤在一起 |
| **饱胀** | 饱满、胀起来 |
| **破裂** | 裂开、绽开 |
| **姿势** | 姿态样子 |
| **翩翩起舞** | 轻快地跳舞 |

### 💡 写花三态
> "有的才展开两三片花瓣儿。有的花瓣儿全都展开了，露出嫩黄色的小莲蓬。有的还是花骨朵儿，看起来饱胀得马上要破裂似的。"

**三种姿态**——半开、全开、未开，写全了。

**"冒"字好在哪里**？不是"长出来"，是"冒出来"——写出荷花迫不及待、充满生命力的样子。

### 💡 想象
> "我忽然觉得自己仿佛就是一朵荷花……"

作者看花看入迷了，**物我两忘**——最高的审美境界。

## ✍️ 习作：我的植物朋友

### 🎯 目标
选一种植物，先用**观察卡片**记录，再写成作文。

### 🧩 观察卡（先做卡片！）

| 项目 | 记录 |
|:----|:-----|
| 名称 | 绿萝 |
| 样子 | 心形叶子，绿油油的，藤蔓从花盆垂下来 |
| 颜色 | 深绿色，新叶有点嫩黄 |
| 气味 | 淡淡的青草味，几乎闻不到 |
| 触感 | 叶子滑滑的，凉凉的 |
| 变化 | 浇了水叶子立刻精神起来 |
| 我的感受 | 它很好养，几天不浇水也能活，生命力顽强 |

### 📐 写作框架

1. **开头**：我的植物朋友是谁 + 在哪里
   - "我家的阳台上有一盆绿萝，它是我的植物朋友。"
2. **外形**：按顺序写（整体→部分）
   - "它的叶子像一颗颗绿色的心，藤蔓从花盆里垂下来……"
3. **特点**：它有什么特别之处
   - "绿萝的生命力特别顽强，只要有水就能活。"
4. **互动**：我怎么照顾它 + 它给我的快乐
   - "每周我给绿萝浇一次水，它会'咕嘟咕嘟'喝饱……"

### 📝 范文

> **我的植物朋友——向日葵**
>
> 我家小院里种了一棵向日葵，它是我的好朋友。
>
> 它的茎又粗又直，像一根绿色的棍子。叶子大大的，像一把把蒲扇。最引人注目的是它的花——金黄色的花瓣围着一圈棕色的花盘，像一个灿烂的太阳。
>
> 我发现向日葵有个秘密：它的花盘会跟着太阳转！早上它面向东方，中午抬起头朝向天空，傍晚又转向西方。难怪它叫"向日葵"！
>
> 秋天到了，向日葵的花盘里长满了瓜子。我剥了一颗尝了尝——又香又脆！
>
> 向日葵不仅美丽，还给我带来了好吃的瓜子，我特别喜欢它。

### ⚠️ 常见问题
1. ❌ 不观察直接写 → ✅ 先做观察卡，有记录再动笔
2. ❌ 只写好看/不好看 → ✅ 写变化、写习性、写互动
3. ❌ 没有感情 → ✅ 把植物当朋友来写
