# 第六单元 · 多彩童年

> 童年的水墨画、剃头大师、泡泡里的快乐、守信的宋庆龄——每个孩子的童年都不一样。
> **阅读重点**：运用多种方法理解难懂的句子
> **习作目标**：身边那些有特点的人（写人作文）

## 18 童年的水墨画

### 📖 课文概要
三首儿童诗，像三幅水墨画。

**溪边**：垂柳把溪水当作梳妆的镜子，钓鱼的孩子一动不动，上钩了！草地上蹦跳着鱼儿和笑声。

**江上**：一群孩子像鸭群一样跳进水中，水花四溅。

**林中**：雨后的松林里，蘑菇像小伞一样钻出来，孩子们戴着斗笠来采蘑菇。

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **水墨画** | 中国画的一种，用墨和水画 |
| **梳妆** | 梳头化妆 |
| **荡漾** | 水波微动 |
| **喧闹** | 声音大、热闹 |
| **斗笠** | 竹编的帽子，遮阳挡雨 |

### 💡 难句理解
> "垂柳把溪水当作梳妆的镜子，山溪像绿玉带一样平静。"

**方法**：找比喻——溪水=镜子=绿玉带，写出了溪水的静、绿、平。

> "草地上蹦跳着鱼儿和笑声。"

**方法**：通感——笑声会蹦跳？其实是孩子们看到鱼儿上钩太开心了。

## 19 剃头大师

### 📖 课文概要
小沙最怕剃头，每次都被剃头师傅折腾得很惨。有一回，"我"自告奋勇给小沙剃头，结果剪得坑坑洼洼，像梯田一样——"我"成了"剃头大师"。

### 📜 知背景
- 作者：秦文君，著名儿童文学作家
- 这是一篇**幽默故事**——自己水平差却自称"大师"

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **噩梦** | 恐怖的梦 |
| **监督** | 在旁边看着 |
| **夺门而逃** | 冲出房门逃跑 |
| **耿耿于怀** | 心里有事放不下 |
| **坑坑洼洼** | 不平整、高低不平 |
| **规规矩矩** | 很规矩、很老实 |

### 💡 幽默在哪？
"我"的自信满满 vs 实际的糟糕结果——**反差萌**。
"剃头大师"其实是**自嘲**——水平差的人吹牛自己很厉害。

## 20 肥皂泡

### 📖 课文概要
"我"最爱玩肥皂泡。用碎肥皂融化，用竹笔套管蘸着吹——轻圆的泡儿随风飘散，飞到天上，落到扇子上，一闪一闪的，像一串美丽的梦。

### 📜 知背景
- 作者：冰心，著名女作家
- 选自《繁星》《寄小读者》

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **融化** | 固体变成液体 |
| **玲珑** | 精巧细致 |
| **颤巍巍** | 抖动不稳的样子 |
| **光影零乱** | 光和影子交错杂乱 |
| **和弄** | 搅拌混合 |
| **黏稠** | 又黏又稠 |

### 💡 难句理解
> "那一个个轻清脆丽的小球，像一串美丽的梦。"

**方法**：比喻。泡泡像梦——因为它们都是美丽的、短暂的、容易破灭的。

> "目送着她们，我心里充满了快乐、骄傲与希望。"

为什么骄傲？因为是自己吹出来的。为什么希望？希望泡泡飞到远方，带着梦想一起飞。

## 21\* 我不能失信（略读）

### 📖 课文概要
宋庆龄小时候答应朋友小珍教她叠花篮。虽然那天全家去伯伯家看鸽子，但她还是留下来等小珍。她说："一个人在家，是很没劲。可是，我并不后悔，因为我并没有失信。"

### 💡 道理
**守信比玩耍更重要。** 答应了的事就要做到。

## ✍️ 习作：身边那些有特点的人

### 🎯 目标
写一个身边有特点的人，用具体事例写出他的特点。

### 🧩 特点词库

| 特点 | 可以写的事例 |
|:----|:-------------|
| **小书虫** | 课间也看书、去图书馆借一堆书 |
| **热心肠** | 帮同学值日、借文具给别人 |
| **爱问问题** | 每节课都举手、打破砂锅问到底 |
| **运动健将** | 跑步最快、跳绳冠军 |
| **幽默大王** | 讲笑话逗全班笑、说段子 |
| **昆虫迷** | 抓虫子观察、知道各种昆虫的名字 |

### 📐 写作框架

1. **标签式开头**
   - "我们班有一个'小问号'，他就是我的同桌——小明。"
2. **整体特点**
   - "他什么都想弄明白，不搞清楚绝不罢休。"
3. **具体事例（重点！）**
   - "有一次自然课上，老师讲完地球自转，下课了，他追着老师问：'那地球为什么自转？谁推了它一把？'老师都被问笑了。"
4. **结尾升华**
   - "这就是我们班的'小问号'，他的问题有时候让人头疼，但也让我们学到了很多。"

### 📝 范文

> **我的"昆虫迷"表哥**
>
> 我有一个表哥，是个十足的"昆虫迷"。
>
> 他的房间里全是关于虫子的书——《昆虫记》《奇妙的昆虫世界》……他的书桌上摆着好几个昆虫标本盒，里面是各种各样的甲虫和蝴蝶。
>
> 有一次暑假，我们去乡下玩。大人们在屋里聊天，表哥却蹲在院子里看蚂蚁搬家，一看就是半小时。他兴奋地喊我："快来看！蚂蚁在用触角传递信息！"他又给我讲这是工蚁、那是兵蚁，说得头头是道。
>
> 还有一次，他抓到了一只天牛，小心翼翼地放进玻璃瓶里，拿放大镜看了半天，然后在笔记本上画下了它的样子，还标出了触角有几节。
>
> 我觉得表哥特别了不起——对自己喜欢的事情这么认真。我也要像他一样，做一个有爱好、有热情的人。

### ⚠️ 常见问题
1. ❌ 只写特点不写事例 → ✅ "热心肠"要用一件事证明
2. ❌ 事例不具体 → ✅ 加上时间地点对话
3. ❌ 写所有人共同的特点 → ✅ 选这个人**最特别**的点
