# 第五单元 · 习作单元：按游览顺序写景物

> 海上日出、金华双龙洞——跟着课本学"游记"怎么写。
> **阅读重点**：了解按一定顺序写景物的方法
> **习作目标**：游____（游记）

---

## 16 海上日出

### 📖 课文概要
"我"在海上航行时看了日出——天空由浅蓝到红霞到深红，太阳从露出小半边脸到跳出海面，光芒四射。这不是伟大的奇观吗？

### 📜 知背景
- 作者：**巴金**
- 写于去法国留学的轮船上

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **清静** | 安静、不嘈杂 |
| **扩大** | 放大范围 |
| **范围** | 周围的界限 |
| **重荷** | 沉重的负担 |
| **冲破** | 突破、冲开 |
| **夺目** | 光彩耀眼 |
| **奇观** | 奇特壮观的景象 |

### 💡 按时间顺序写

| 时间 | 天空/太阳 | 颜色 |
|:----|:----------|:-----|
| 日出前 | 一片浅蓝 | 浅蓝 |
| 日出前 | 出现红霞 | 红 |
| 日出时 | 太阳露出小半边脸 | 红→深红 |
| 日出后 | 完全跳出，光芒四射 | 金色 |

### 💡 动词精准
> "太阳好像负着重荷似的一步一步，慢慢地努力上升，到了最后，终于冲破了云霞，完全跳出了海面，颜色红得非常可爱。"

"负着重荷""努力""冲破""跳"——**拟人化的太阳**，写出日出的艰难和壮观。

## 17 记金华的双龙洞

### 📖 课文概要
"我"从金华出发，一路经过罗甸→入山→双龙洞口→外洞→孔隙→内洞→出洞。最惊险的是过孔隙——必须躺着船才能进去，只有十几厘米的间隙。

### 📜 知背景
- 作者：**叶圣陶**
- **按游览顺序写**（移步换景）——这是写游记最重要的方法

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **盘曲而上** | 弯弯曲曲向上延伸 |
| **明艳** | 明亮艳丽 |
| **突兀森郁** | 高耸突兀、树木茂盛 |
| **孔隙** | 很小的缝 |
| **臀部** | 屁股 |
| **蜿蜒** | 弯弯曲曲 |

### 💡 游览顺序（移步换景）

```
金华城 → 罗甸 → 入山（山路盘曲）
           ↓
           洞口（像桥洞）
           ↓
           外洞（宽敞）
           ↓
           孔隙（窄小，躺着进去）
           ↓
           内洞（黑→双龙→石钟乳）
           ↓
           出洞
```

**每个地点写一个特点**：
- 山路：盘曲而上
- 洞口：像桥洞
- 外洞：像大会堂
- 孔隙：窄到只能躺着
- 内洞：黑、双龙、石钟乳

### 💡 孔隙（最精彩的部分）
> "虽说是孔隙，可也容得下一只小船进出。怎样的小船呢？两个人并排仰卧，刚合适，再没法容第三个人，是这样小的小船。"

先写船有多小 → 再写怎么过 → 最后写感受。

## ✍️ 习作：游____

### 🎯 目标
按**游览顺序**写一次出游经历，把看到的景物连成一条"线"。

### 📐 写作框架

1. **开头**：时间+地点+和谁
2. **游览经过**（按移步换景写）
   - 先到哪 → 看到什么 → 再到哪 → 看到什么
3. **最难忘的地方**（详写，重点！）
4. **结尾**：感受+推荐

### 🧩 游览顺序的词

| 用途 | 词语 |
|:----|:-----|
| 进入 | 走进、穿过、绕过、沿着 |
| 移动 | 来到、登上、步入、踏上 |
| 转换 | 一转头、一抬头、往前走、拐过弯 |
| 离开 | 走出、告别、回头望 |

### 📝 范文

> **游西湖**
>
> 去年暑假，我和爸爸妈妈一起游览了杭州西湖。
>
> 我们从断桥出发，沿着白堤慢慢走。白堤两边种满了柳树，风吹过来，柳枝轻拂湖面，像少女的长发在飘动。远处的山若隐若现，像一幅水墨画。
>
> 走了一会儿，我们坐上了游船。湖水碧绿碧绿的，船桨划开水面，激起一圈圈涟漪。船到了湖心的小瀛洲，我看到了"三潭印月"——三个石塔立在水中，据说每到中秋月圆时，塔里点灯，月光和灯光交相辉映，美极了。
>
> 下船后，我们又去了花港观鱼。池子里有成千上万条红鲤鱼，我把面包屑扔进去，它们立刻聚拢过来，红的、金的、白的，挤成一团，嘴巴一张一合的，可爱极了。
>
> 傍晚时分，太阳慢慢落山，把湖面染成了金色。我站在苏堤上，看着夕阳下的雷峰塔，心里想：西湖的美，果然名不虚传。
>
> 这次西湖之行让我真正理解了什么叫"上有天堂，下有苏杭"。下次我还要来！

### ⚠️ 常见问题
1. ❌ 写成"到此一游"（到了XX→又到了XX） → ✅ 每个地方写出特点
2. ❌ 没有详略 → ✅ 选最感兴趣的地方详写
3. ❌ 没有过渡 → ✅ 用"沿着""穿过""登上"这些词串起来

### 🧠 写作指导

**① 从阅读中学写作（申怡·读写结合）**
回到本单元的课文，看看作者是怎么写的——
- 《海上日出》（巴金）：从这篇可以学按时间顺序写景物变化——日出前（浅蓝→红霞）→日出时（小半边脸→跳出海面）→日出后（光芒四射），把变化的过程写出来，而不是只写结果
- 《记金华的双龙洞》（叶圣陶）：从这篇可以学移步换景——到哪里→看到什么→感受到什么，每个地点写一个最突出的特点，像串珠子一样串起来
→ 写游记就是当一回"导游"：带读者走到哪看到哪，选一两个地方停下来细看，其他的一笔带过。

**② 先搭架子再动笔（申怡·理科思维）**
动笔之前，先回答三个问题：
1. 我去哪了？按什么路线走的？
2. 哪个地方最难忘？要详写什么？
3. 用什么过渡词把各个景点连起来？
列一个简单的提纲，就像盖房子先搭钢筋一样。框架稳了，文章就稳了。

**③ 说人话，说真话（温儒敏·回到常识）**
不要堆砌好词好句。把一件小事写清楚，比写一篇"漂亮"的空话强一百倍。写你自己真正看到、听到、感受到的——这样的文章，读起来才有温度。

### 📝 范文二

> **游黄山**
>
> 去年五一，我和爸爸妈妈一起去了安徽黄山。人们都说"五岳归来不看山，黄山归来不看岳"，我早就想亲眼看看黄山到底有多美了。
>
> 我们坐索道上山。索道缓缓上升，脚下的树木越来越小，远处的山峰越来越近。风吹过来，缆车轻轻摇晃，妈妈吓得闭上了眼睛，我却兴奋地趴在窗户上看——山间的云雾像一层薄纱，把山峰遮得若隐若现。
>
> 下了索道，我们开始爬山。石阶很陡，两边是奇形怪状的松树——有的从石头缝里长出来，树枝伸向一边，像在跟游客招手。走了大约半小时，我们到了"飞来石"——一块巨大的石头立在山顶上，像是从天上掉下来的。我摸了摸它，冰冰凉凉的，心想：它真的飞来的吗？
>
> 最难忘的是登光明顶。登上山顶的那一刻，我惊呆了——四周全是云海，白茫茫一片，远处的山峰像小岛一样浮在云上面。太阳照在云海上，金光闪闪，美得让人说不出话来。我站在山顶上，觉得自己像个神仙。
>
> 下山的时候，腿已经不是自己的了，又酸又软。但回头看看自己爬过的山峰，心里满满的都是骄傲。
>
> 黄山的风景，真的比书上写的还要美。下次我还要来！
