# 第四单元 · 动物朋友

> 猫的古怪、母鸡的负责、白鹅的高傲——动物也有自己的性格。
> **阅读重点**：体会作家是如何表达对动物的感情的
> **习作目标**：我的动物朋友

---

## 13 猫

### 📖 课文概要
猫的性格实在有些古怪——说它老实吧，它的确有时候很乖；说它贪玩吧，又是尽职的；高兴了比谁都温柔，不高兴了一声不出；什么都怕，但又那么勇敢。猫小时候更可爱——一根鸡毛、一个线团都玩个没完。

### 📜 知背景
- 作者：**老舍**（人民艺术家，代表作《骆驼祥子》）
- 老舍爱猫——这篇课文充满老舍式的**幽默+细致**

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **古怪** | 跟一般不同，奇怪 |
| **尽职** | 尽到职责 |
| **屏息凝视** | 憋住气专注地看 |
| **温柔可亲** | 温和柔顺、可以亲近 |
| **丰富多腔** | 声音多种多样 |
| **变化多端** | 变化很多 |
| **生气勃勃** | 生命力旺盛 |

### 💡 矛盾写法（明贬实褒）

| 看似贬 | 实际是…… | 表达效果 |
|:-------|:-----------|:---------|
| "古怪" | 性格丰富 | 越说"古怪"越觉得可爱 |
| "贪玩" | 有自己的个性 | 不是没脾气的老好人 |
| "撞疼了也不哭" | 勇敢倔强 | 像小孩一样可爱 |

**"明贬实褒"**——表面上说不好，其实是带着爱意说。这是老舍的幽默。

### 💡 语气词
> "说它贪玩吧，的确是啊，要不怎么会一天一夜不回家呢？"

"吧""啊""呢"——北京口语，像在跟邻居聊天一样自然。

## 14 母鸡

### 📖 课文概要
老舍一开始讨厌母鸡——它嘎嘎乱叫、欺软怕硬、下了个蛋就炫耀个不停。但当他看到母鸡保护小鸡时——领小鸡觅食、教它们啄食、遇到危险时奋不顾身——作者"不敢再讨厌母鸡了"。

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **讨厌** | 让人不喜欢 |
| **没完没了** | 不停 |
| **细声细气** | 声音轻柔 |
| **警戒** | 小心防备 |
| **警告** | 提醒、告诫 |
| **慈爱** | 慈祥关爱 |
| **辛苦** | 身心劳苦 |
| **伟大** | 超出寻常 |

### 💡 前后态度对比

| 前期讨厌 | 后期尊敬 |
|:---------|:---------|
| 嘎嘎乱叫，没完没了 | 鸡雏面前一声不哼 |
| 欺软怕硬 | 为了小鸡敢跟大狗拼命 |
| 下个蛋就炫耀 | 默默为小鸡付出一切 |

**转折句**："可是，现在我改变了心思，我看见一只孵出一群小雏鸡的母鸡。"

**"一位母亲必定就是一位英雄"**——从母鸡到所有母亲。

## 15 白鹅

### 📖 课文概要
白鹅很高傲——它的步态从容、吃饭三眼一板、架子十足。但正是这种高傲让它显得特别有趣。作者在抗战期间住在乡下，白鹅是他生活中重要的陪伴。

### 📜 知背景
- 作者：**丰子恺**（漫画家、散文家）
- 他的文字像他的画——寥寥几笔就画出神韵

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **高傲** | 自以为了不起 |
| **郑重** | 严肃认真 |
| **呵斥** | 大声斥责 |
| **大模大样** | 满不在乎的样子 |
| **一丝不苟** | 一点都不马虎 |
| **从容** | 不慌不忙 |
| **奢侈** | 过分讲究 |

### 💡 明贬实褒（和《猫》一样的手法）
> "鹅的步态，更是傲慢了。大体上与鸭相似，但鸭的步调急速，有局促不安之相；鹅的步调从容，大模大样的，颇像京剧里的净角出场。"

**对比**：鸭（局促）vs 鹅（从容）
**比喻**：鹅的步态 = 京剧净角出场

> "这样从容不迫地吃饭，必须有一个人在旁侍候，像饭馆里的堂倌一样。"

说自己是"堂倌"（服务员）来侍候鹅——**自嘲式的幽默**。

## ✍️ 习作：我的动物朋友

### 🎯 目标
写一种你熟悉的动物——可以是你养的宠物，也可以是观察过的动物。写出它的**外形、习性、和你之间的故事**。

### 📐 写作框架

1. **开头**：介绍动物朋友
2. **外形**（按顺序）
3. **性格/习性**（用具体事例）
4. **你和它的故事**（最难忘的事）
5. **结尾**：对它的感情

### 📝 范文

> **我的动物朋友——仓鼠"团子"**
>
> 我家有一只小仓鼠，名叫"团子"。它圆滚滚的，像一个毛茸茸的小球。它的毛是浅棕色的，背上有一道深色的条纹。两只黑豆似的小眼睛，总是好奇地东张西望。
>
> 团子是个"吃货"。每次我拿着瓜子靠近笼子，它立刻站起来，两只前爪扒在笼子上，鼻子一抽一抽的。我把瓜子递进去，它用两只小爪子捧着，咔嚓咔嚓啃得飞快，腮帮子鼓得像两个小气球——它把瓜子藏到颊囊里去了！
>
> 团子还是个"睡神"。白天它大部分时间都在睡觉，缩成一团，把脑袋埋进肚子下面。但一到晚上，它就精神了——在跑轮上跑个不停，跑得哗哗响。
>
> 有一次我忘记关笼门，团子跑了出来。我找了半天，最后发现它躲在沙发垫子下面，正抱着不知道从哪里找到的瓜子啃呢！看到它那副满足的样子，我又好气又好笑。
>
> 团子虽然不会说话，但它是我最好的动物朋友。每天放学回家，看到它在笼子里等我，所有的烦恼都烟消云散了。

### 🧩 写动物的方法（本单元总结）

| 方法 | 课文例子 | 你的作文 |
|:----|:---------|:---------|
| **明贬实褒** | 猫"古怪"、鹅"高傲" | "我家的小狗真是个'小捣蛋'……" |
| **对比** | 鸭vs鹅、讨厌vs尊敬 | 猫vs狗、小时候vs现在 |
| **加故事** | 母鸡保护小鸡 | 它做了一件什么难忘的事 |
| **用动词** | 蹭、跳、扑、啃 | 准确写出动物的动作 |

### ⚠️ 常见问题
1. ❌ 写成动物百科 → ✅ 写你和动物之间的事
2. ❌ 外形和动作脱节 → ✅ 在故事中展现特点
3. ❌ 没有感情 → ✅ 写出你为什么喜欢它

### 🧠 写作指导

**① 从阅读中学写作（申怡·读写结合）**
回到本单元的课文，看看作者是怎么写的——
- 《猫》（老舍）：从这篇可以学总分结构——先用"猫的性格实在有些古怪"总起，再从老实、贪玩、尽职三个方面具体写，有条有理
- 《白鹅》（丰子恺）：从这篇可以学明贬实褒（反语）——嘴上说鹅"高傲""架子十足"，其实是带着爱意写它的可爱，越说它不好越显得喜欢
→ 写你的动物朋友也可以试试"明贬实褒"——说它是"小捣蛋""小馋猫"，读起来特别有感情。

**② 先搭架子再动笔（申怡·理科思维）**
动笔之前，先回答三个问题：
1. 我要写什么动物？
2. 它的外形、性格、故事各用什么事例来写？
3. 按什么顺序写？
列一个简单的提纲，就像盖房子先搭钢筋一样。框架稳了，文章就稳了。

**③ 说人话，说真话（温儒敏·回到常识）**
不要堆砌好词好句。把一件小事写清楚，比写一篇"漂亮"的空话强一百倍。写你自己真正看到、听到、感受到的——这样的文章，读起来才有温度。

### 📝 范文二

> **我家的小狗"胖墩"**
>
> 我家有一只小柴犬，名叫"胖墩"。它有一身浅黄色的毛，尾巴总是卷卷地翘着，像一个小问号。它的眼睛又圆又亮，每次看着我，我就觉得它在说："陪我玩吧！"
>
> 胖墩是个"跟屁虫"。我走到哪它跟到哪——我去卫生间，它蹲在门口等；我去写作业，它趴在我脚边；我去吃饭，它坐在我面前，眼巴巴地盯着我手里的鸡腿。那个眼神，谁看了都忍不住要分它一口。
>
> 它还是个"拆家高手"。有一回我放学回家，发现我的拖鞋被它咬成了两半。我气得指着它喊："胖墩！"它立刻趴下来，耳朵耷拉着，用那双无辜的大眼睛看着我——好像在说："我错了，但我下次还敢。"我真是又好气又好笑。
>
> 但胖墩也有暖心的时刻。有一次我考试没考好，一个人坐在床上哭。胖墩跳上来，用脑袋蹭我的手，还舔了舔我的脸。那一刻我觉得，它虽然不会说话，但它什么都懂。
>
> 这就是我家的小狗——会拆家、会卖萌，也会在我难过的时候陪着我。它是我们家不可缺少的一员。
