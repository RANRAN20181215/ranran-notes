## 5 琥珀

### 📖 课文概要
一只蜘蛛想吃一只小苍蝇，它们被松脂包裹住了。松脂球埋在泥沙下，经过几万年的演化变成了琥珀。渔民捡到这块琥珀，磨光后看到里面有一只苍蝇和一只蜘蛛——这真是个奇特的巧合。

### 📜 知背景
- 作者：柏吉尔（德国科普作家）
- **推测**（想象+科学）：用琥珀的样子推算出几万年前的故事

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **约摸** | 大约、大概 |
| **翻腾** | 上下翻滚 |
| **冲刷** | 水流冲击洗刷 |
| **推测** | 根据已知推想未知 |
| **详细** | 细致周密 |
| **成千上万** | 数量极多 |

### 💡 推测（科学推理）

| 琥珀里的"证据" | 推测出 |
|:---------------|:-------|
| 苍蝇和蜘蛛在一起 | 蜘蛛想吃苍蝇时被粘住 |
| 它们的腿四周有黑色的圈 | 挣扎的痕迹 |
| 琥珀是透明的 | 松脂包裹后经过很长时间 |
| 在海滩上发现 | 被海水冲刷出来的 |

**科学想象的魅力**——从一块石头推演出一个故事。

## 6 飞向蓝天的恐龙

### 📖 课文概要
恐龙真的灭绝了吗？不——有一支恐龙进化成了鸟类，飞上了蓝天！科学家找到了化石证据：恐龙有羽毛、有翅膀、像鸟一样筑巢孵蛋。恐龙并没有消失，它们变成了我们天天看到的鸟儿。

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **凶猛** | 凶恶强大 |
| **笨重** | 沉重不灵巧 |
| **敏捷** | 动作迅速 |
| **形态** | 样子、姿态 |
| **轻盈** | 轻巧优美 |
| **五彩斑斓** | 颜色多样 |
| **凌空翱翔** | 在高空飞翔 |

### 💡 演化路线
**恐龙（2.3亿年前）**
→ 一些恐龙长出羽毛
→ 开始滑翔
→ 学会飞行
→ **变成现代的鸟类**

**证据链**：
1. 化石上恐龙有羽毛印痕
2. 恐龙骨骼和鸟类很像
3. 有些恐龙有"龙鸟"特征（中华龙鸟）

## 7 纳米技术就在我们身边

### 📖 课文概要
纳米是非常小的长度单位——1纳米等于1米的十亿分之一。纳米技术可以制造"隐形"战斗机上的涂料、检测疾病的纳米机器人、永不沾油的纳米布料……高科技正在改变我们的生活。

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **纳米** | 极小的长度单位 |
| **无能为力** | 没有能力去做 |
| **拥有** | 具有 |
| **检测** | 检验测定 |
| **病灶** | 疾病所在的位置 |
| **纳米"吸星大法"** | 比喻纳米材料吸收力强 |
| **深刻** | 深入透彻 |

### 💡 纳米有多小？
> "如果把直径为1纳米的小球放到乒乓球上，相当于把乒乓球放在地球上。"

**比喻解释法**——用熟悉的东西解释陌生的概念。

## 8\* 千年梦圆在今朝（略读）

### 📖 课文概要
中华民族几千年的飞天梦——从敦煌壁画的飞天到明代万户绑火箭上天，从第一颗人造卫星到神舟五号载人上天。一代代人的努力，终于实现了"飞天"的梦想。

### 💡 时间线
明代万户（尝试飞天）→ 1970年东方红一号 → 2003年神舟五号 → 嫦娥探月

**关键词**：代代相传、坚持不懈、自主创新

## ✍️ 习作：我的奇思妙想

### 🎯 目标
发挥想象，发明一样东西来解决生活问题。**写清楚：什么东西？长什么样？有什么功能？**

### 🧩 发明构思

| 问题 | 我的发明 | 功能 |
|:----|:---------|:-----|
| 书包太重 | 自动悬浮书包 | 跟着你走，不用背 |
| 健忘 | 会提醒的智能水杯 | 到时间了自动放音乐 |
| 堵车 | 折叠飞行器 | 堵车了展开翅膀飞过去 |
| 视力下降 | 智能护眼台灯 | 坐姿不对自动调暗 |

### 📐 写作框架

1. **为什么发明**：遇到什么问题
   - "每天背着重重的书包爬五楼，我的肩膀又酸又疼……"
2. **发明叫什么**+**长什么样**（外形）
3. **有什么功能**（2-3种功能，重点写）
4. **解决问题的效果**

### 📝 范文

> **会变大变小的书包**
>
> 每天上学，我都要背一个比我还大的书包。里面装着课本、作业本、文具盒、水杯……越来越重，我的背都快被压弯了。
>
> 我想发明一种"会变大变小的书包"。
>
> 这个书包看起来和普通书包差不多，但它的侧面有三个按钮：红色、蓝色和绿色。红色按钮是"缩小"——轻轻一按，书包就变成巴掌大小，可以装进口袋里。蓝色按钮是"放大"——取书的时候再按一下，它就变回正常大小。绿色按钮是"隐身"——如果你不想被人看到书包，它就变得透明！
>
> 最神奇的是，不管变大还是变小，里面的东西都不会乱。这就像哆啦A梦的四次元口袋一样！
>
> 有了这个书包，我再也不用被它压得喘不过气了。上学路上，我把书包缩小放兜里，轻松又自在。到了教室再变回来，同学们都羡慕得不得了。
>
> 我真希望有一天，这个发明能变成现实！

### ⚠️ 常见问题
1. ❌ 功能太普通 → ✅ 大胆想，要"奇"要"妙"
2. ❌ 只有功能没有样子 → ✅ 先写外形再写功能
3. ❌ 没有说为什么发明 → ✅ 写出生活中的问题

### 🧠 写作指导

**① 从阅读中学写作（申怡·读写结合）**
回到本单元的课文，看看作者是怎么写的——
- 《飞向蓝天的恐龙》：从这篇可以学科学推理过程——从化石证据一步步推出恐龙进化成鸟类，用"证据→结论"的链条写清楚逻辑
- 《纳米技术就在我们身边》：从这篇可以学举例子说明——用"纳米涂料""纳米机器人""纳米布料"这些具体例子，把抽象的概念讲明白
→ 写你的发明时也要有逻辑：先发现问题，再展示发明怎么解决问题。用具体例子让读者能"看到"你的发明。

**② 先搭架子再动笔（申怡·理科思维）**
动笔之前，先回答三个问题：
1. 我要解决什么问题？
2. 我的发明长什么样？有什么功能？
3. 分几段来写？
列一个简单的提纲，就像盖房子先搭钢筋一样。框架稳了，文章就稳了。

**③ 说人话，说真话（温儒敏·回到常识）**
不要堆砌好词好句。把一件小事写清楚，比写一篇"漂亮"的空话强一百倍。写你自己真正看到、听到、感受到的——这样的文章，读起来才有温度。

### 📝 范文二

> **会飞的鞋子**
>
> 每天早上上学，我都要提前半个小时出门，因为路上太堵了——汽车排着长队，电动车在缝隙里钻来钻去，走路又太慢。我经常因为堵车迟到。
>
> 我想发明一种"会飞的鞋子"。
>
> 这双鞋子看起来和普通的运动鞋差不多，但鞋底加装了四个微型喷气装置。鞋帮上有一个小小的圆形按钮——轻轻一踩，鞋子底部的喷气装置就会启动，带着我慢慢飞起来。鞋跟后面还有一个方向控制器，脚尖朝左就左转，脚尖朝右就右转。最高可以飞到离地面五米，速度比自行车还快。
>
> 最酷的是，它还能自动避开障碍物——就像蝙蝠的超声波一样。如果前面有棵树或一栋楼，鞋子会自己调整方向。这样就算你是"飞行新手"也不用担心撞上什么。
>
> 有了这双会飞的鞋子，我再也不怕堵车了。别人在路上排队，我在天上飞。到了学校门口，轻轻一踩按钮，鞋子就变回普通运动鞋，谁也不知道它会飞。
>
> 我要是能穿上它上学，一定帅呆了！
