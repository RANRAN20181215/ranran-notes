# 部编版四年级语文笔记

> 四年级阅读量明显增大，开始接触长课文、古诗文、说明文、散文。

## 四年级写作进阶

| 学期 | 写作类型 | 核心能力 |
|:---:|:---------|:---------|
| 上册 | 推荐、写人、观察日记、想象、记事、活动、书信、心理 | 结构完整、细节具体、有真情实感 |
| 下册 | 写地方、发明想象、诗歌、写动物、游记、成长记事、自我介绍、改编 | 顺序清晰、表达生动、有思想深度 |

> 四年级习作字数要求：**350-400字**，上下册逐步提高。
