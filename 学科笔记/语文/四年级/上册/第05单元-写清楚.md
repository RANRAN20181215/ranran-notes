# 第五单元 · 习作单元：把一件事写清楚

> 本单元专门学"如何把一件事写清楚"——按顺序、写经过、加感受。
> **阅读重点**：了解作者是怎样把事情写清楚的
> **习作目标**：生活万花筒（选一件印象深刻的事）

---

## 16 麻雀

### 📖 课文概要
"我"打猎回来路上，看到一只小麻雀从巢里掉下来，猎狗想吃它。突然，老麻雀像石头一样从树上飞下来，挡在猎狗面前。猎狗被老麻雀的勇气镇住了——"我"唤回了猎狗。

### 📜 知背景
- 作者：**屠格涅夫**（俄国作家）
- 这是一个**由爱而生的勇气**的故事

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **摇撼** | 摇动（风摇撼白桦树） |
| **无可奈何** | 没有办法 |
| **拯救** | 挽救、救 |
| **嘶哑** | 声音沙哑 |
| **庞大** | 非常大 |
| **紧张** | 精神高度集中 |

### 💡 把事情写清楚的"三要素"

| 要素 | 课文怎么做 |
|:----|:-----------|
| **起因** | 小麻雀掉下来，猎狗逼近 |
| **经过** | 老麻雀飞下来保护（重点！用动作+神态写） |
| **结果** | 我唤回猎狗，小麻雀得救 |

### 💡 动作描写（老麻雀）
> "突然，一只老麻雀从一棵树上飞下来，**像一块石头似的落在猎狗面前**。它**扎煞起全身的羽毛**，**绝望地尖叫着**。"

比喻+动作+叫声——写出老麻雀**虽然害怕但绝不退缩**的矛盾心理。

> "一种强大的力量使它飞了下来。"

"强大的力量"——就是母爱。

## 17 爬天都峰

### 📖 课文概要
假期，"我"和爸爸爬黄山天都峰。天都峰又高又陡，"我"一开始不敢爬。遇到一位老爷爷，"我们"互相鼓励，最后都登上了峰顶。

### 📜 知背景
- 天都峰：黄山最险峰之一，坡度近90度

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **笔陡** | 像笔一样直、很陡 |
| **石级** | 石阶 |
| **发颤** | 发抖 |
| **汲取** | 吸取 |
| **居然** | 竟然、没想到 |

### 💡 写经过：按顺序+加细节

| 步骤 | 写法 |
|:----|:-----|
| ① 看到山 → **害怕** | "天都峰这么高！我爬得上去吗？" |
| ② 遇到老爷爷 → **互相鼓励** | "咱们一起爬吧！" |
| ③ 奋力攀登 → **动作细节** | "攀着铁链上，手脚并用" |
| ④ 到达山顶 → **心情** | "居然都爬上来了！" |
| ⑤ 拍照下山 → **感悟** | "互相鼓励力量大" |

**"居然"好在哪里**？——写出意料之外的惊喜。

**爸爸呢**？爸爸全程没帮忙——让孩子自己面对困难，这就是最好的教育。

## ✍️ 习作：生活万花筒

### 🎯 目标
选一件印象深刻的事，按**起因→经过→结果**写清楚。

### 🧩 选材指南（万花筒里的"小事"）

| 类型 | 例子 |
|:----|:-----|
| 第一次 | 第一次独自睡觉、第一次做饭 |
| 意外 | 下雨忘带伞、打碎玻璃杯 |
| 开心 | 收到生日礼物、考试进步 |
| 难忘 | 和好朋友吵架又和好、被老师误会 |

### 📐 写作框架（学课文的结构）

1. **起因**（1段）：事件怎么开始的
2. **经过**（2-3段）：发生了什么事（重点！）
   - 遇到什么困难/转折
   - 做了什么、想了什么
3. **结果**（1段）：最后怎么样了
4. **感受**（1段）：这件事给我的启发

### 📝 范文

> **第一次独自睡觉**
>
> 八岁那年，妈妈对我说："你长大了，该自己睡觉了。"
>
> 晚上，我躺在床上，灯一关，房间黑得像墨汁一样。窗帘被风吹动，影子晃动，像一只大怪物在张牙舞爪。我的心怦怦直跳，赶紧把被子蒙住头。
>
> 我越想越害怕，总觉得床底下有东西。我打开灯——什么也没有。我关了灯——又觉得有声音。就这样，我一晚上开了五六次灯。
>
> 后来我想到一个办法：抱着我最喜欢的布熊，给自己讲了一个"小勇士战胜黑暗"的故事。讲着讲着，我竟然睡着了！
>
> 第二天早上，妈妈笑着说："你成功了！"我心里别提有多自豪了。
>
> 从那以后，我再也不怕一个人睡觉了。困难就像黑暗——只要你勇敢面对，它就没那么可怕了。
>
> ---
>
> **第一次做饭**
>
> 妈妈生日那天，我想给她一个惊喜——做一顿饭！
>
> 我决定做西红柿炒蛋，这是我最爱吃的菜，看起来也不难。我打开冰箱，拿出两个西红柿和三个鸡蛋。切西红柿的时候，我差点切到手指——西红柿圆滚滚的，刀一滑就跑了。
>
> 打鸡蛋倒是顺利，但搅拌的时候把蛋液溅到了脸上。开火、倒油——油热了，我小心翼翼地把蛋液倒进锅里。"滋啦"一声，油花四溅，吓得我往后退了三步。我硬着头皮用铲子翻炒，鸡蛋很快就变成了金黄色的蛋块。
>
> 接下来炒西红柿。西红柿下锅后，我加了点盐和糖。可是锅里的水越来越多，眼看就要变成"西红柿汤"了。我赶紧把炒好的鸡蛋倒进去，胡乱翻炒了几下就关火了。
>
> 妈妈下班回来，看到桌上那盘黑乎乎的西红柿炒蛋，愣了一下，然后笑了。"这是我收到的最好的生日礼物。"她尝了一口："嗯，味道不错！"
>
> 我也尝了一口——有点咸，鸡蛋还有点糊。但不知道为什么，我觉得这是世界上最好吃的西红柿炒蛋。

### ⚠️ 常见问题
1. ❌ 起因太长 → ✅ 快速进入正题，重点写经过
2. ❌ 写成流水账 → ✅ 选最精彩的部分详写
3. ❌ 没有心理活动 → ✅ 加上"我想""我担心""我紧张"

### 🧠 写作指导

**① 从阅读中学写作（申怡·读写结合）**
回到本单元的课文，看看作者是怎么写的——
- 《麻雀》：从这篇可以学到**按事情发展顺序写**——起因→经过→结果，一环扣一环。
- 《爬天都峰》：从这篇可以学到**写心理变化**——害怕→互相鼓励→克服困难→成功后的喜悦，一波三折才好看。
→ 写一件事，先把"经过"拆成几个小步骤，每一步写清楚。

**② 先搭架子再动笔（申怡·理科思维）**
动笔之前，先回答三个问题：
1. 我要写哪件事？
2. 起因、经过、结果各写多少？
3. 经过中最精彩的部分是什么？
列一个简单的提纲，就像盖房子先搭钢筋一样。框架稳了，文章就稳了。

**③ 说人话，说真话（温儒敏·回到常识）**
不要堆砌好词好句。把一件小事写清楚，比写一篇"漂亮"的空话强一百倍。写你自己真正看到、听到、感受到的——这样的文章，读起来才有温度。
