# 第四单元 · 神话故事

> 盘古开天地、精卫填海、普罗米修斯盗火、女娲补天——人类最早的想象。
> **阅读重点**：感受神话中神奇的想象和鲜明的人物形象
> **习作目标**：我和____过一天（和神话/童话人物共度一天）

## 12 盘古开天地

### 📖 课文概要
宇宙混沌如鸡蛋，盘古在里面睡了一万八千年。醒来后他劈开天地——轻的上升为天，重的下沉为地。盘古头顶天脚踩地，撑了一万八千年。倒下后，他的身体化为了世间万物。

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **混沌** | 模糊一团、不清明 |
| **劈开** | 用刀斧破开 |
| **逐渐** | 慢慢 |
| **精疲力竭** | 精力耗尽、非常累 |
| **奔流不息** | 水流奔腾不停 |
| **滋润** | 湿润不干枯 |

### 💡 盘古的身体化万物

| 身体部分 | 变成 |
|:---------|:-----|
| 气息 | 风和云 |
| 声音 | 雷声 |
| 左眼 | 太阳 |
| 右眼 | 月亮 |
| 四肢 | 东/西/南/北四极 |
| 肌肤 | 大地 |
| 血液 | 江河 |
| 汗毛 | 花草树木 |
| 汗水 | 雨露 |

**中国创世神话**——体现了"**天人合一**"的观念：人死后回归自然。

## 13 精卫填海（文言文）

### 📖 课文概要
炎帝的小女儿女娃在东海游泳被淹死，化为精卫鸟。它每天从西山衔木石去填东海——要把害死它的海填平。

### 📜 原文 & 翻译
**原文**：炎帝之少女，名曰女娃。女娃游于东海，溺而不返，故为精卫，常衔西山之木石，以堙于东海。

**翻译**：炎帝的小女儿，叫女娃。女娃在东海游泳，淹死了没有回来，所以变成了精卫鸟。它常常叼着西山的树枝和石头，用来填塞东海。

### 🌿 重点字词
| 字 | 意思 |
|:--|:-----|
| 少女 | 小女儿 |
| 溺 | 淹没 |
| 故 | 因此 |
| 为 | 变成 |
| 衔 | 用嘴叼 |
| 堙 | 填塞 |

### 💡 精神
**精卫填海**——明知不可能，却坚持不懈。这是一种**不屈不挠**的精神。

## 14 普罗米修斯

### 📖 课文概要
普罗米修斯从太阳神那里盗取火种送给人类，人类从此有了火——能取暖、能照明、能烧熟食物。宙斯知道后大怒，把普罗米修斯锁在高加索山上，让鹰啄食他的肝脏。普罗米修斯不屈服——最后被大力神赫拉克勒斯救了。

### 📜 知背景
- **希腊神话**
- 普罗米修斯 = "先知者"，是泰坦神族的一员

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **悲惨** | 处境痛苦 |
| **驱寒取暖** | 赶走寒冷获得温暖 |
| **气急败坏** | 非常生气、狼狈 |
| **惩罚** | 处罚 |
| **敬佩** | 尊敬佩服 |
| **坚定** | 不动摇 |
| **屈服** | 低头认输 |

### 💡 英雄形象对比

| 人物 | 态度 | 行为 |
|:----|:-----|:-----|
| **普罗米修斯** | 为人类牺牲自己 | 盗火→受罚→不屈服 |
| **宙斯** | 冷酷专制 | 惩罚→加重惩罚 |
| **赫拉克勒斯** | 正义勇敢 | 救出普罗米修斯 |

### 💡 神话的共性
- 中国神话（盘古、精卫）：**牺牲自我、改造自然**
- 希腊神话（普罗米修斯）：**反抗权威、为人类献身**

## 15\* 女娲补天（略读）

### 📖 课文概要
天塌了一个大窟窿，地上洪水泛滥、野兽出没。女娲炼五彩石补天，斩乌龟的四条腿撑天，杀黑龙，用芦灰堵洪水——人类得救了。

### 💡 神话中的女性英雄
女娲是中国神话中的**创世女神**——她造人、补天，是中华民族的母神。

## ✍️ 习作：我和____过一天

### 🎯 目标
选择一位神话/童话人物，想象和他/她度过一天会怎样。

### 🧩 可选人物

| 类型 | 人物 |
|:----|:-----|
| 中国神话 | 盘古、精卫、女娲、孙悟空、哪吒 |
| 希腊神话 | 普罗米修斯、宙斯、雅典娜 |
| 童话 | 白雪公主、小红帽、匹诺曹 |

### 📐 写作框架

1. **怎么相遇**（时间/地点/方式）
   - "我正在看《西游记》，突然书里金光一闪……"
2. **一起做了什么**（2-3件事）
   - 去了哪里 + 经历了什么 + 用了什么超能力
3. **发生了什么有趣的事**
   - 波折/幽默/感动
4. **分别 & 感受**
   - "天黑了，她回到了书里，我永远忘不了这一天。"

### 📝 范文

> **我和孙悟空过一天**
>
> 星期六早上，我正在看《西游记》，突然书页里跳出一个小人——毛脸雷公嘴，头戴金箍，手拿金箍棒——是孙悟空！
>
> "俺老孙听说你喜欢我，特地带你去花果山玩一玩！"他拉上我，一个筋斗云就飞上了天。
>
> 花果山美极了！瀑布从山顶飞泻而下，桃子又大又红。孙悟空摘了一个最大的给我："尝尝，这是三千年一熟的蟠桃！"我咬了一口——又甜又多汁，比超市买的甜一百倍！
>
> 接着他教我七十二变。他念了一句咒语，我也跟着念——"变！"结果我变成了一头猪！孙悟空笑得在地上打滚："想当年猪八戒也是这样！"我急得直跳，他这才把我变了回来。
>
> 傍晚，孙悟空送我回家。他说："小娃娃，好好读书，将来比俺老孙还厉害！"
>
> 这一天太神奇了！我真希望孙悟空下次还能来找我玩。
>
> ---
>
> **我和哪吒过一天**
>
> 暑假的一天，我正在院子里玩水枪，突然天空中出现了一团火——一个踩着风火轮、扎着丸子头的小孩从天而降，竟然是哪吒！
>
> "小兄弟，你玩的水枪太没意思了，我带你去东海玩真正的'水战'！"哪吒一挥手，我的脚下也出现了风火轮。我们"嗖"地一下飞上了天。
>
> 来到东海，哪吒用混天绫在水里一搅，顿时掀起了滔天巨浪。龙王三太子骑着水兽冲了出来："哪吒！你又来捣乱！"哪吒冲我眨眨眼："看好了！"他抛出乾坤圈，套住了三太子的水兽。我趁机用水枪"攻击"——当然，这对龙宫的人来说就像挠痒痒。
>
> 打完水仗，哪吒带我去了陈塘关。他教我耍火尖枪，可我笨手笨脚的，差点戳到自己。哪吒笑得直拍大腿："你比我当年还笨！"不过他耐心地一遍遍教我，最后我终于能转两圈了。
>
> 傍晚，哪吒要回天庭了。他说："下次我带你去见见我的师父太乙真人！"
>
> 这真是最酷的一天！我现在每天练习转棍子——下次见到哪吒，我要让他大吃一惊！

### ⚠️ 常见问题
1. ❌ 人物性格不符 → ✅ 保持原人物特点（孙悟空调皮、精卫坚韧）
2. ❌ 平淡的一天 → ✅ 要有特异的经历（用上人物的超能力）
3. ❌ 像在写别人 → ✅ 把"我"写进去，有互动有对话

### 🧠 写作指导

**① 从阅读中学写作（申怡·读写结合）**
回到本单元的课文，看看作者是怎么写的——
- 《盘古开天地》：从这篇可以学到**宏大想象**——身体化万物，气成风云、眼成日月，敢想才敢写。
- 《普罗米修斯》：从这篇可以学到**人物性格设定**——勇敢、坚定、有牺牲精神，性格决定了故事走向。
→ 写和神话人物过一天，先想好他是什么性格，再想象你们会一起做什么。

**② 先搭架子再动笔（申怡·理科思维）**
动笔之前，先回答三个问题：
1. 我和谁过一天？
2. 分几段写？做了哪几件事？
3. 用什么细节展现人物的超能力？
列一个简单的提纲，就像盖房子先搭钢筋一样。框架稳了，文章就稳了。

**③ 说人话，说真话（温儒敏·回到常识）**
不要堆砌好词好句。把一件小事写清楚，比写一篇"漂亮"的空话强一百倍。写你自己真正看到、听到、感受到的——这样的文章，读起来才有温度。
