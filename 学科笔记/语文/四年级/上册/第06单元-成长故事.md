> **阅读重点**：学习用批注的方法阅读

## 18 牛和鹅

### 📖 课文概要
大家都说"牛眼看人比牛大，鹅眼看人比鹅小"——所以"我们"不怕牛但怕鹅。"我"被鹅追咬，吓得又哭又叫。金奎叔帮"我"赶走了鹅，说："鹅有什么可怕的！它再凶，也是把你看得比它小。"这句话改变了"我"——从此我再也不怕鹅了。

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **无所谓** | 不在乎 |
| **恐怖** | 非常害怕 |
| **欺负** | 用强横手段侵犯 |
| **助威** | 帮助增添威势 |
| **顽皮** | 淘气 |
| **无缘无故** | 没有原因 |
| **摇摇摆摆** | 走路不稳的样子 |

### 💡 批注（重点）
批注就是在阅读时**在旁边写下自己的思考**。本单元是批注策略单元。

批注的角度：
- **写得好的地方**：比喻、拟人、动词
- **有疑问的地方**：这里为什么这样写？
- **有体会的地方**：我也经历过/这个道理我懂了

### 💡 道理
> "它虽然把我们看得比它小，可我们实在比它强啊！"

**视角决定态度**——你以为它可怕，它就真可怕；你勇敢面对，它就不可怕了。

## 19 一只窝囊的大老虎

### 📖 课文概要
"我"在班级表演中演大老虎——没有台词，只出场"豁虎跳"就行。可是"我"回到家练了很久也跳不好。上台后，观众的哄笑让"我"一直耿耿于怀：到底怎样才能算"豁虎跳"？

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **窝囊** | 无能、怯懦 |
| **殷切** | 深厚恳切 |
| **笨拙** | 不聪明、不灵巧 |
| **垂头丧气** | 低着头没精神 |
| **哄堂大笑** | 满屋子人一起笑 |
| **接连不断** | 连续不停 |

### 💡 心理描写
> "我看着老师的脸，就怕她改变主意。"
> "我总算一直演到了躺下来死掉。"
> "到底怎么演完的，我一点儿也记不起来。"

**紧张、尴尬、自责**——表演失败后的心理非常真实。

为什么"我"一直记得这件事？因为童年的"小挫折"往往印象最深。

## 20 陀螺

### 📖 课文概要
"我"一直想有一个陀螺。叔叔帮"我"做了一个——丑陋但很能干，把别人的陀螺都撞飞了。"我"从此明白了"人不可貌相"的道理。

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **妩媚** | 姿态美好 |
| **毫无怨言** | 一点也没有埋怨 |
| **重整旗鼓** | 重新整顿再干 |
| **得心应手** | 心里怎么想手就能怎么做 |
| **手舞足蹈** | 双手舞动双脚跳动 |
| **不伦不类** | 不像这一类也不像那一类 |
| **自豪** | 因为自己好而骄傲 |

### 💡 名句
> "人不可貌相，海水不可斗量。"

陀螺很丑但很能打——不要以貌取人（或物）。

## ✍️ 习作：记一次游戏

### 🎯 目标
写一次游戏或活动的经过，写出**游戏的过程**和**当时的感受**。

### 🧩 可以写什么

| 游戏类型 | 例子 |
|:---------|:-----|
| 传统游戏 | 老鹰捉小鸡、丢沙包、跳皮筋 |
| 体育游戏 | 拔河、接力赛、踢毽子 |
| 课间游戏 | 捉迷藏、木头人、猜谜语 |
| 电子游戏 | 和爸爸一起打游戏 |

### 📐 写作框架

1. **准备**：什么时候、和谁、玩什么
2. **过程**：怎么玩的（规则→开始→精彩瞬间）
3. **高潮**：最紧张/最有趣的部分（详写）
4. **结果**：谁赢了 + 我的心情

### 📝 范文

> **那次拔河比赛**
>
> "一二！加油！一二！加油！"震耳欲聋的呐喊声在操场上回荡——我们班和三班的拔河比赛开始了！
>
> 裁判哨声一响，双方立刻使劲。我双手紧紧抓住绳子，身体往后仰，脚蹬着地，恨不得把整个人钉进地里。绳子中间的红布条一会儿往左，一会儿往右，像一只调皮的小鸟在两边摇摆。
>
> 最前面的大力士小刚脸涨得通红，青筋都爆出来了。排最后的"定海神针"大胖把绳子缠在腰上死死往后坐。可是三班太强了，红布条一点一点向他们那边移动。
>
> "坚持住！"班主任在边上喊。我们咬紧牙关，齐声喊着口号，拼尽最后一丝力气。可是绳子还是被拉了过去。
>
> 我们输了。大家有的擦汗，有的喘气，有的红了眼圈。但班主任说："虽然没有赢，但你们团结的样子让我很骄傲。"
>
> 是啊，输赢不重要，重要的是全班一起拼命的感觉——那种齐心协力的感觉，比赢了还让人难忘。
>
> ---
>
> **老鹰捉小鸡**
>
> "我来当老鹰！""我要当鸡妈妈！"操场上，我们的课间游戏开始了。
>
> 我自告奋勇当了"老鹰"，小丽当"鸡妈妈"，其他同学排成一串当"小鸡"。游戏规则很简单：老鹰要捉住小鸡，鸡妈妈要保护小鸡不被捉到。
>
> 游戏开始！我张开双臂，像真正的老鹰一样左右扑腾。鸡妈妈也张开双臂，左右移动，护着身后的小鸡们。我往左冲——鸡妈妈往左挡；我往右扑——鸡妈妈往右拦。一连几个回合，我一只小鸡都没捉到。
>
> 我停下来喘了口气，突然想出一个妙计。我先假装往左冲，等鸡妈妈往左移动时，我猛地转向右边！鸡妈妈来不及反应，我一把抓住了队伍最后面的"小鸡"！"哈哈，抓到一只！"大家又笑又叫，操场上热闹极了。
>
> 轮到输了的同学当老鹰，游戏继续。
>
> 上课铃响了，我们依依不舍地回到教室。虽然满头大汗，但每个人都笑得很开心。这就是游戏最纯粹的样子——没有输赢，只有快乐。

### ⚠️ 常见问题
1. ❌ 规则写太多 → ✅ 规则一两句带过，重点写玩的经过
2. ❌ 没有"画面感" → ✅ 加动作（拽/拉/喊/冲/跳）
3. ❌ 没有游戏的声音 → ✅ 加呐喊声、加油声、笑声、哨声

### 🧠 写作指导

**① 从阅读中学写作（申怡·读写结合）**
回到本单元的课文，看看作者是怎么写的——
- 《一只窝囊的大老虎》：从这篇可以学到**第一人称叙事**——用"我"的视角写，让读者跟着"我"紧张、尴尬、难忘。
- 《陀螺》：从这篇可以学到**情感变化**——从渴望到失望到惊喜到自豪，情绪起伏让故事有张力。
→ 写游戏不只要写"怎么玩"，更要写"玩的时候心情怎么变化"。

**② 先搭架子再动笔（申怡·理科思维）**
动笔之前，先回答三个问题：
1. 我写哪次游戏？
2. 分几段写？游戏过程分几个环节？
3. 每个环节我的心情是什么？
列一个简单的提纲，就像盖房子先搭钢筋一样。框架稳了，文章就稳了。

**③ 说人话，说真话（温儒敏·回到常识）**
不要堆砌好词好句。把一件小事写清楚，比写一篇"漂亮"的空话强一百倍。写你自己真正看到、听到、感受到的——这样的文章，读起来才有温度。
