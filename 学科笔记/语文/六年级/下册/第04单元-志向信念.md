# 第四单元 · 志向与信念

> 李贺的壮志、于谦的品格、郑燮的坚韧、李大钊的信仰、张思德的精神、董存瑞的壮烈——这就是中国人的"精神基因"。
> **阅读重点**：查阅相关资料，加深对课文的理解
> **习作目标**：心愿（表达愿望）

## 10 古诗三首

### 马诗 · 李贺
> 大漠沙如雪，燕山月似钩。
> 何当金络脑，快走踏清秋。

**💡** 以马喻人。马需要金络脑（好马具）才能奔驰——**人才需要平台才能施展抱负。** 大漠、雪、月、钩——都是边塞战场意象。

### 🎭 走进诗人

**写作背景**：李贺只有27年的生命——但他把27年活成了一团火。他从小体弱多病、个子矮小，长得也不好看——但他的才华像天空中划过的一道流星。他年轻时非常想为朝廷效力，骑着马在边塞的风沙里想象自己驰骋沙场的英姿。但现实是：他父亲名叫"李晋肃"——"晋"与"进士"的"进"同音，为了避讳，他连考进士的资格都没有。李贺气得吐血——他写了这首《马诗》，问天下：谁能给我一副好马鞍？让我在这清爽的秋天驰骋一回？

**逸事**：李贺是中国文学史上最"苦命"的天才。他每天骑着一头瘦驴出门，背上一个破布囊——想到好句子就写下来丢进囊里。晚上回家，他妈妈看到他写了那么多，心疼地说："这孩子要写到把心呕出来才肯罢休！"——这就是"呕心沥血"这个成语的由来。他27岁就病死了——临死前说天帝造了一座白玉楼，请他去写诗。后人说李贺是"诗鬼"——因为他写诗太奇诡了，喜欢写鬼怪、死亡、神仙，那些别人不敢写的东西他全写了。

**时代回响**：唐朝的"避讳"制度有时候挺害人的——因为父亲的名字里有一个字跟"进士"同音，李贺连考试的资格都没有。韩愈专门为他写了一篇文章《讳辩》，质问：如果父亲叫"仁"，儿子就不能做人了吗？但这也没用。李贺的悲剧不是他一个人的悲剧——他代表了那些有才华但没有入仕机会的读书人。"何当金络脑，快走踏清秋"——这匹马等了二十七年，始终没等到它的金络脑。李贺死后十五年，晚唐彻底走向了衰落——这匹千里马的早逝，像是给那个时代提前吹响了挽歌。

### 石灰吟 · 于谦
> 千锤万凿出深山，烈火焚烧若等闲。
> 粉骨碎身浑不怕，要留清白在人间。

**💡** 石灰的一生：深山开采 → 烈火煅烧 → 粉身碎骨 → 留下清白。
**这是于谦的一生——也是他人格的写照。** "清白"既指石灰的白，也指人的品格清白。

### 🎭 走进诗人

**写作背景**：于谦12岁的时候，路过一座石灰窑。他看到工人们从深山里采出灰白色的石头，扔进窑里用烈火焚烧，出来变成生石灰；浇上水，"呲"的一声炸开——粉身碎骨；最后留下的是一堵墙上的雪白墙面。这个少年突然站住了——他觉得这不就是做人的道理吗？被人锤打、被烈火考验、被水浇得粉身碎骨——但最后留下的是一身清白。他激动地回去写下了这首诗。谁也没想到，这个12岁少年写的"咏物诗"，最终成了他一生的预言——他真的像石灰一样，干干净净地活了，又干干净净地死了。

**逸事**：于谦是明朝的大英雄——1449年土木堡之变，明英宗被瓦剌俘虏，整个朝廷慌成一团，有人要逃跑、有人要投降。于谦拍案而起："谁说要跑？要打！"他带兵在北京城外跟瓦剌死战，硬是把敌人打退了，救了大明王朝。但英雄的下场往往很悲凉——后来英宗复辟，听信谗言，以"谋逆"的罪名把于谦杀了。官兵去抄家时发现：这个当了一辈子大官的人，家里穷得连一件像样的家具都没有——只有墙上挂着他自己写的"石灰吟"。他被杀的那天，北京城的老百姓哭成一片——连老天爷都下起了大雪。

**时代回响**：明朝是中国历史上一个"硬气"但"残酷"的朝代。于谦的悲剧在于两个字——"清白"。他不结党、不站队、不贪污——这在明朝的政治生态里反而成了"罪过"。他的对手都是贪婪的权贵，他们不相信这世界上真有"清白"的人——所以一定要把他弄死。于谦用一生回答了"粉骨碎身浑不怕，要留清白在人间"——他不是在写诗，他是在用命写。后人说"千锤万凿出深山"——于谦就是那块从明朝最黑暗的深山里凿出来的石头。

### 竹石 · 郑燮（郑板桥）
> 咬定青山不放松，立根原在破岩中。
> 千磨万击还坚劲，任尔东西南北风。

**💡** "咬定"——竹子咬住青山，绝不放松。**不管什么风，我自岿然不动。** 郑板桥画竹、写竹——竹就是他自己。

### 🎭 走进诗人

**写作背景**：郑板桥喜欢画竹——他一生画了几千幅竹子，写了几百首竹诗。这首诗是他画了一幅竹石图后，随手题在上面的。画面里：一丛竹子从岩石裂缝中长出来，竹根死死咬住青山不松口，不管东西南北风怎么吹——它就是不倒。郑板桥画着画着笑了：这不就是我自己吗？一辈子不攀附权贵、不随波逐流、不向任何"风"低头——穷困潦倒又怎样？我自岿然不动。

**逸事**：郑板桥是"扬州八怪"里最出名的一个。"怪"在哪里？他考上进士后当了山东潍县的知县——别人当官发财，他当官为民做主。有一年闹饥荒，他不等朝廷批准就开仓放粮，救了几万人——结果被上司弹劾，说他擅自行动。他一气之下辞官不干了——走的时候老百姓夹道相送。他回扬州卖画为生，明码标价："大幅六两，中幅四两，小幅二两"——不给钱？不给钱画也不给。他晚年给自己刻了一方印章，上面七个字："康熙秀才雍正举人乾隆进士"——一辈子三次考试跨越三朝，也挺有意思。

**时代回响**：清朝中期的"扬州八怪"现象很有意思——他们是一群不愿意跟官场同流合污的文人，聚集在扬州靠卖画为生。他们做人"怪"——不巴结权贵、不随大流、不迎合世俗；画画也"怪"——不守传统、自成一派。郑板桥的竹子为什么能打动人心？因为他不只是在画植物——他在画一种人格：根扎在破岩里也照样生长，风吹雨打也绝不弯腰。后来无数中国人在遇到困难的时候，都会想起这首诗——"千磨万击还坚劲，任尔东西南北风"。竹子说的话，人听到了。

## 11 十六年前的回忆

### 📖 课文概要
1927年，李大钊被捕。他在法庭上沉着镇定，最后被绞刑杀害。这是他的女儿李星华在父亲逝世十六年后的回忆。

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **军阀** | 武力割据的军人集团 |
| **僻静** | 偏僻安静 |
| **恐怖** | 恐惧 |
| **一拥而入** | 一下子冲进去 |
| **严峻** | 严肃严厉 |
| **会意** | 领会了意思 |
| **沉着** | 镇静、不慌张 |

### 💡 对比
| | 敌人 | 李大钊 |
|:--|:-----|:-------|
| 态度 | 粗暴、凶狠 | 沉着、镇定 |
| 语言 | 吼叫 | 从容 |
| 结局 | 永远被唾弃 | 永远被怀念 |

**坏人越凶，好人越显伟大。**

## 12 为人民服务

### 📖 课文概要
毛泽东在张思德追悼会上的演讲——人总是要死的，但死的意义不同。为人民利益而死，就比泰山还重；替法西斯卖力、替剥削人民和压迫人民的人去死，就比鸿毛还轻。

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **剥削** | 利用权力压榨 |
| **压迫** | 用权力压制 |
| **泰山** | 五岳之一（比喻极重） |
| **鸿毛** | 大雁的毛（比喻极轻） |
| **兴旺** | 兴盛 |
| **轻于鸿毛** | 比鸿毛还轻 |

### 💡 议论文结构
1. **提出观点**：为人民服务
2. **死有不同意义**：泰山 vs 鸿毛
3. **不怕批评**：有错就改
4. **团结互助**：为了共同目标

## ✍️ 习作：心愿

### 🎯 目标
写出自己的一个心愿——真实的、发自内心的。可以关于个人、关于家人、关于社会。

### 📐 写作框架

1. **心愿是什么**（开门见山）
2. **为什么有这个心愿**（故事/原因）
3. **为实现心愿做了什么**（努力/期待）
4. **心愿实现后的样子**（想象）

### 📝 范文

> **我的心愿——让奶奶听清我的声音**
>
> 我的心愿很小，小到可能不值一提——我想让奶奶听清我的声音。
>
> 奶奶的耳朵越来越背了。每次回家，我叫"奶奶"，她总是听不见。要喊很大声才行。有一次我喊太大声了，她被吓了一跳——我很难过。
>
> 去年春节，全家一起吃饭。大家有说有笑，奶奶坐在旁边，笑眯眯地看着我们，却听不到我们在说什么。她问了好几遍"你们在笑什么"，我们说了一遍又一遍。后来她不再问了——只是安静地吃饭。
>
> 那一刻，我觉得奶奶好孤独。
>
> 从那以后，我说话时尽量面对奶奶，让她能看清我的口型。我学会了慢一点、大声一点、清楚一点。我还攒零花钱想给她买一个好一点的助听器。
>
> 我的心愿是：让奶奶能清清楚楚地听到我说"奶奶，我爱你"。不是喊的，是很普通地说——她也能听到。

### 📝 第二篇范文

> **我的心愿——当一名老师**
>
> 我的心愿是当一名语文老师。
>
> 这个心愿是从三年级开始的。那时候我的语文成绩很差，最怕的就是写作文。每次作文本发下来，上面全是红圈圈——错别字一个接一个。
>
> 有一天放学后，语文老师把我叫到办公室。我以为要被批评了，低着头不敢说话。但她没有批评我——她从抽屉里拿出一本《小学生优秀作文选》，递给我说："回去看看，一周后告诉我你最喜欢哪一篇。"
>
> 那是我第一次认认真真地读作文。我发现——原来作文可以这么有趣！《我的弟弟》里那个抢零食的弟弟，就像我弟弟一样；《第一次坐飞机》里的紧张和兴奋，我也经历过。
>
> 一周后，我去找老师。她笑眯眯地问我："喜欢吗？"我使劲点头。她说："那你试着写一篇吧，写你最喜欢的。"我写了《我的爷爷》。那篇作文得了85分——我第一次及格。
>
> 从那以后，我慢慢喜欢上了语文。老师每次都在我的作文本上写很多批语——好的地方画波浪线，不好的地方教我改。我进步了，比谁都开心。
>
> 我想成为像她那样的老师——不是只会批评学生的老师，而是那个在办公室给学生递上一本书、打开一扇窗的老师。我现在每天多读一篇文章、多积累一个好句子——离我的心愿就更近一步。

### ⚠️ 常见问题
1. ❌ 心愿太大太空 → ✅ 从身边小事入手
2. ❌ 没有"为什么" → ✅ 写清愿望的来源
3. ❌ 没有实际行动 → ✅ 写你做了什么

### 🧠 写作指导

**① 从阅读中学写作（申怡·读写结合）**
回到本单元的课文，看看作者是怎么写的——
- 《石灰吟》：从这篇可以学到**托物言志**——于谦不直接说"我要清白做人"，而是通过写石灰的一生来表达自己的志向
- 《十六年前的回忆》：从这篇可以学到**通过回忆表达情感**——女儿回忆父亲李大钊的点点滴滴，把对父亲的崇敬和怀念写到了骨子里
→ 把这些方法用到你的作文里，语文课本就是最好的"作文书"。

**② 先搭架子再动笔（申怡·理科思维）**
动笔之前，先回答三个问题：
1. 我要写什么主题？
2. 分几段写？每段写什么？
3. 用什么材料来支撑？
列一个简单的提纲，就像盖房子先搭钢筋一样。框架稳了，文章就稳了。

**③ 说人话，说真话（温儒敏·回到常识）**
不要堆砌好词好句。把一件小事写清楚，比写一篇"漂亮"的空话强一百倍。写你自己真正看到、听到、感受到的——这样的文章，读起来才有温度。
