# 第六单元 · 综合性学习：难忘小学生活

> 六年了——从"a o e"到"难忘小学生活"，你变了很多。
> **毕业在即，用文字留下这段时光。**

---

## 回忆往事

### 📖 时间轴

| 年级 | 最难忘的事 |
|:----|:-----------|
| 一年级 | 第一次走进教室 / 系红领巾 |
| 二年级 | 第一次考100分 / 第一次被老师表扬 |
| 三年级 | 第一次写作文 / 第一次参加运动会 |
| 四年级 | 第一次上台演讲 / 第一次参加研学 |
| 五年级 | 第一次住校 / 最好的朋友转学了 |
| 六年级 | 毕业倒计时 |

### 💡 怎样写"回忆"？

- **不要**：我在学校很开心。
- **要**：夏天的风把窗帘吹得鼓鼓的，全班都在午休，只有风扇在转。同桌偷偷递过来一颗糖——"别让老师看见。"

**一个具体的细节 > 一万句空话。**

>
> 四年级诗歌朗诵比赛，全班都不愿意上台。您说："我来给你们示范。"然后您在讲台上朗诵了一首《乡愁》——读到最后，您的眼眶红了。教室里安静了很久。

>
> 六年了，您教我的不只是语文。我学会了认真对待每一件事，学会了做一个善良的人。李老师，谢谢您让我的小学生活有温度。
>
> 祝您身体健康、永远年轻！

>                             您的学生：小雅

（贴上篮球队合影）

【第五页 · 五年级】

（贴上演讲比赛照片）

【第六页 · 六年级】
疫情在家上了两个月网课。

再见，我的小学。你好，我的中学。

### 🧠 写作指导

**① 从阅读中学写作（申怡·读写结合）**
回到本单元的课文，看看作者是怎么写的——
- 本单元的回忆性文章：从这些可以学到**用具体小事写深情**——"夏天的风把窗帘吹得鼓鼓的，同桌偷偷递过来一颗糖"，一个细节胜过一万句空话
- 《给母校的一封信》示例：从这篇可以学到**书信格式**——称呼、正文、祝语、署名、日期，格式对了就有了"仪式感"
→ 把这些方法用到你的作文里，语文课本就是最好的"作文书"。

**② 先搭架子再动笔（申怡·理科思维）**
动笔之前，先回答三个问题：
1. 我要写什么主题？
2. 分几段写？每段写什么？
3. 用什么材料来支撑？
列一个简单的提纲，就像盖房子先搭钢筋一样。框架稳了，文章就稳了。

**③ 说人话，说真话（温儒敏·回到常识）**
不要堆砌好词好句。把一件小事写清楚，比写一篇"漂亮"的空话强一百倍。写你自己真正看到、听到、感受到的——这样的文章，读起来才有温度。
