# 第三单元 · 阅读策略：有目的地阅读

> 竹节人的玩法、宇宙生命的谜、故宫的奥秘——不同目的，不同读法。
> **阅读重点**：根据阅读目的选用恰当的阅读方法
> **习作目标**：____让生活更美好（议论文雏形）

## 9 竹节人

### 📖 课文概要
"我们"小时候自己用毛笔杆做竹节人——用线一拉，竹节人就挥舞着武器打起来。课上玩竹节人被老师没收了。但老师自己也玩得津津有味。

### 📜 知背景
- 作者：范锡林
- 这是一个关于**童年DIY乐趣**的故事

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **风靡** | 草木随风倒下（比喻流行） |
| **前功尽弃** | 以前的努力全白费了 |
| **威风凛凛** | 气势威严 |
| **别出心裁** | 独创一格 |
| **技高一筹** | 本领高一些 |
| **弄巧成拙** | 想卖弄反而办了蠢事 |
| **虎视眈眈** | 贪婪地盯着 |
| **津津有味** | 很有兴趣 |

### 💡 不同阅读目的

| 阅读目的 | 怎么读 |
|:---------|:-------|
| 想知道竹节人怎么做 | 关注制作方法段落（跳读） |
| 想体会玩的乐趣 | 关注玩的过程描写（精读） |
| 想讲这个故事 | 关注情节发展（浏览+概括） |

**带着问题读，不用从头读到尾。**

## 10 宇宙生命之谜

### 📖 课文概要
地球之外有没有生命？科学家从理论上分析：生命需要水、空气、温度。火星最像地球——但探测发现：火星表面没有液态水、大气稀薄、温度极低。目前为止，没有发现地外生命。

### 🌿 重点词语
| 词语 | 解释 |
|:----|:-----|
| **谜** | 没弄明白的问题 |
| **沧海一粟** | 大海中的一粒米（比喻非常渺小） |
| **起源** | 开始发生 |
| **提供** | 供给 |
| **考察** | 调查观察 |
| **磁场** | 磁力作用的空间 |

### 💡 阅读策略

**任务：找出火星不适合生命的原因**

读法：先看问题，然后快速扫描，找到"火星"相关的段落，仔细阅读，提取信息。

### 📖 课文概要
四则材料：材料一是故宫导游词（由南到北介绍），材料二是太和门故事，材料三是故宫平面图，材料四是网址。

### 💡 非连续性文本

## ✍️ 习作：____让生活更美好

### 🎯 目标
选择一样事物（微笑/音乐/阅读/旅行/友谊……），写出它**为什么**让生活更美好。这是**议论文的雏形——观点+理由+事例。**

### 📐 写作框架

1. **观点**：____让生活更美好（开门见山）
2. **理由1 + 事例**
3. **理由2 + 事例**
4. **理由3 + 事例**
5. **总结升华**

### 📝 范文

> **阅读让生活更美好**
>
> 如果说生活是一张白纸，那么阅读就是彩色的画笔。对我来说，阅读让生活变得更美好。
>
> 阅读让我看到了更大的世界。我从来没有去过非洲大草原，但读了《雄狮去流浪》，我仿佛看到了草原上的落日和奔跑的狮群。我没有去过海底，但读了《海底两万里》，我好像跟着尼摩船长潜入了神秘的海底世界。阅读是一扇任意门，打开它，就能去到任何地方。
>
> 阅读也让我变得更坚强。当我遇到困难的时候，我想起了《鲁滨逊漂流记》中的鲁滨逊——他在荒岛上活了二十八年，我这点困难算什么？阅读给了我力量。
>
> 阅读还让我交到了朋友。我和同桌都喜欢看《哈利·波特》，我们经常一起讨论魔法学校的趣事，友谊在阅读中越来越深。
>
> 生活中有很多美好的事物，但对我来说，没有什么比阅读更美好的了。如果你也喜欢读书，我们一定能成为好朋友！

### ⚠️ 常见问题
1. ❌ 只有"美好"没"为什么" → ✅ 写清楚"为什么让生活更美好"
2. ❌ 全篇大道理 → ✅ 用具体事例证明
3. ❌ 跑题写成记事 → ✅ 始终围绕"让生活更美好"

### 📝 范文二

> **音乐让生活更美好**
>
> 如果生活是一杯白开水，那么音乐就是那一勺蜂蜜。对我来说，音乐让生活变得更加甜美。
>
> 音乐是我的"情绪调节器"。有一次我因为和好朋友吵架，一整天都闷闷不乐。回到家，我戴上耳机，随机播放了一首轻快的钢琴曲。那旋律像一只温暖的手，慢慢地抚平了我心里的疙瘩。听着听着，我的脚开始打拍子，嘴角不自觉地向上弯——气消了一大半。
>
> 音乐也是我的"记忆收藏夹"。每次听到《小星星》，我就会想起妈妈哄我睡觉的夜晚。听到《生日快乐歌》，就想起每年生日吹蜡烛的时刻。每一段旋律背后，都藏着一段温暖的回忆。
>
> 音乐还让我交到了朋友。我和小区里的一个小伙伴因为都喜欢周杰伦的歌而熟络起来。我们互相推荐好听的歌，还约好了一起学吉他。
>
> 有人喜欢阅读，有人喜欢运动，而我喜欢音乐——它用最温柔的方式，让我的生活变得更加美好。

### 🧠 写作指导

**① 从阅读中学写作（申怡·读写结合）**
回到本单元的课文，看看作者是怎么写的——
- 《竹节人》：从这篇可以学到**把一件事写具体——从制作方法到玩法到被没收，每一步都有细节**
- 《故宫博物院》：从这篇可以学到**从不同角度说明——同一件事物，可以从历史、布局、故事等多个角度来写**
→ 把这些方法用到你的作文里，语文课本就是最好的"作文书"。

**② 先搭架子再动笔（申怡·理科思维）**
动笔之前，先回答三个问题：
1. 我选什么事物？它让生活更美好——为什么？
2. 我准备写几个理由？每个理由对应什么事例？
3. 每个事例怎么展开——先写观点还是先写故事？
列一个简单的提纲，就像盖房子先搭钢筋一样。框架稳了，文章就稳了。

**③ 说人话，说真话（温儒敏·回到常识）**
不要堆砌好词好句。把一件小事写清楚，比写一篇"漂亮"的空话强一百倍。写你自己真正看到、听到、感受到的——这样的文章，读起来才有温度。
