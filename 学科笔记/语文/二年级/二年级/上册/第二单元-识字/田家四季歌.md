# 🌾 田家四季歌

> 识字儿歌

---

## 📖 读一读

**春季**里，春风吹，
花开草长蝴蝶飞。
麦苗儿多嫩，桑叶儿正肥。

**夏季**里，农事忙，
采了蚕桑又插秧。
早起勤耕作，归来带月光。

**秋季**里，稻上场，
谷像黄金粒粒香。
身体虽辛苦，心里喜洋洋。

**冬季**里，雪初晴，
新制棉衣暖又轻。
一年农事了，大家笑盈盈。

---

## 💡 讲一讲

这首歌唱的是 **农民一年四季的生活** 🌾🎵

- 🌸 **春天** → 花开草长，蝴蝶飞舞，播种的季节
- ☀️ **夏天** → 最忙的时候：采桑叶养蚕 + 插秧种田
- 🍂 **秋天** → 丰收的季节：稻谷金黄，虽然辛苦但很开心
- ❄️ **冬天** → 农活做完了，穿上新棉衣，开开心心过年

## 🌿 词语积累

| 词语 | 意思 |
|---|---|
| **麦苗** | 小麦的幼苗 |
| **桑叶** | 桑树的叶子（喂蚕的） |
| **插秧** | 把水稻秧苗插到水田里 |
| **耕作** | 种田干活 |
| **上场** | 粮食收割后运到场院 |
| **农事** | 种田的事 |
| **笑盈盈** | 笑得很开心的样子 |

---

## 🧩 想一想

**❓ 为什么夏天要"早起勤耕作，归来带月光"？**
> 夏天白天长，农活特别多。农民天没亮就起床干活，天黑了（月亮出来了）才回家。这说明夏天农活非常繁忙辛苦！

**❓ "身体虽辛苦，心里喜洋洋"——身体辛苦为什么还开心？**
> 因为秋天是 **丰收** 的季节！看到自己种的粮食大丰收，虽然累但心里是甜的。
