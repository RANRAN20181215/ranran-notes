# 💧 我是什么

> 科普短文

---

## 📖 读一读

我会变。太阳一晒，我就变成汽。升到天上，变成无数极小极小的点儿，连成一片，在空中漂浮。人们叫我 **云**。

我在空中越升越高，体温越来越低，变成了无数小水滴。小水滴聚在一起落下来，人们叫我 **雨**。

到了冬天，我变成小硬球打下来，人们叫我 **雹子**。到了更冷的时候，我变成小花朵飘下来，人们叫我 **雪**。

我平时在池子里睡觉，在小溪里散步，在江河里奔跑，在海洋里跳舞、唱歌、开大会。

---

## 📜 知背景

这是一篇 **科普谜语** 课文——全文用第一人称"我"来讲述，让读者猜"我"是谁。

**答案是：水。** 💧

课文讲述了水的 **三态变化**：固态（冰、雹子、雪）、液态（雨、云、雾）、气态（水蒸气）。

水是地球上最常见的物质之一，也是生命最重要的组成部分——我们身体里大约 **70%** 都是水！

## 🌿 解词语

| 词语 | 意思 |
|---|---|
| **漂浮** | 浮在空气中 |
| **聚** | 集合在一起 |
| **温和** | 不冷也不热，态度好 |
| **暴躁** | 容易发火、不温和 |
| **灌溉** | 给庄稼浇水 |
| **淹没** | 水太多，把东西盖住了 |

## 💡 讲一讲

**课文的"我"还会变身术！** 🎩✨

太阳一晒，我变成 **水蒸气** 飞上天☁️
在天上聚在一起，变成了 **云** ☁️
冷了掉下来，就是 **雨** 🌧️
更冷了变成小硬球，是 **雹子** ⚪
最冷的时候变成小花朵，是 **雪花** ❄️

我平时很温和——在池子里安静待着，在小溪里散步，在江河里奔跑，在大海里跳舞唱歌🌊

但我也很暴躁——发大水的时候会淹没庄稼、冲毁房屋😡

所以人类要想办法管住我，让我只做好事不做坏事。

## 🧩 想一想

| 状态 | 叫什么 | 什么时候发生 |
|---|---|---|
| 💨 **气体** | 水蒸气（看不见） | 太阳晒的时候 |
| ☁️ **液体/小水滴** | 云、雾、雨 | 聚在一起时 |
| ⚪ **固体** | 冰、雹子、雪 | 冷的时候 |

**❓ 水的"温和"和"暴躁"分别指什么？**
> 温和 = 正常的水，浇灌庄稼、供人饮用
> 暴躁 = 洪水，淹没房屋、冲毁农田
> 我们要保护环境，减少洪水灾害！

## 📝 知识小卡片

### 🔄 水循环

```
太阳晒 → 水变水蒸气（蒸发）
  → 飞到天上变成云（凝结）
  → 变冷掉下来（降水：雨/雪/雹）
  → 流回江河湖海
  → 又开始循环……
```

这是一个 **永远不会停止** 的大循环！🌍

## 📎 拓展小故事

### 🌊 地球是"水球"

虽然我们叫"地球"，但地球表面 **71%** 的面积被水覆盖！

如果从太空看地球，它是一颗蓝色的星球🔵

但这其中：
- **97.5%** 是海水（咸的，不能喝）
- **2.5%** 是淡水（可以喝的）
- 淡水中又有 **70%** 在南北极的冰川里

所以，我们真正能喝到的淡水，只占地球上所有水的 **不到1%** ！

> 所以一定要 **节约用水** 哦！🚰💧
