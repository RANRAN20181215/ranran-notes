## 1 传统节日

### 📖 课文概要
春节到元宵节，清明节到端午节，七夕节到中秋节，重阳节到春节——一年到头，每个节日都有不同的习俗。

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **传统** | 从古流传下来的 | 春节是中国最重要的传统节日。 |
| **节日** | 值得纪念的日子 | 六一儿童节是我们的节日。 |
| **团圆** | 一家人聚在一起 | 除夕夜全家团圆吃年夜饭。 |
| **热闹** | 人很多、很欢乐 | 元宵节的大街上真热闹。 |
| **祭扫** | 祭祀、扫墓 | 清明节全家人去祭扫祖先。 |
| **乞巧** | 七夕节向织女乞求巧手 | 七夕节女孩们穿针乞巧。 |
| **赏菊** | 观赏菊花 | 重阳节和爷爷奶奶一起去赏菊。 |
| **登高** | 爬高 | 重阳节人们登高望远。 |
| **春节** | 农历正月初一 | 春节到了，家家户户贴春联。 |
| **元宵** | 一种圆形的糯米食品 | 元宵节我们全家一起吃元宵。 |

### 💡 节日时间线
| 节日 | 时间 | 做什么 |
|:----|:----|:-------|
| 春节 | 正月初一 | 贴窗花、放鞭炮 |
| 元宵节 | 正月十五 | 看花灯、吃元宵 |
| 清明节 | 4月5日左右 | 祭扫、踏青 |
| 端午节 | 五月初五 | 赛龙舟、吃粽子、挂艾草 |
| 七夕节 | 七月初七 | 乞巧 |
| 中秋节 | 八月十五 | 赏月、吃月饼 |
| 重阳节 | 九月初九 | 登高、赏菊 |

### 💡 形声字：传、统、节
"传"——**亻**（人）+ **专**（声旁）
"节"——**艹**（草字头）+ **卩**（声旁）

## 2 "贝"的故事

### 📖 课文概要
古人用贝壳当钱币，所以跟钱有关的字很多都有"贝"——财、赚、赔、购、贫、货……贝壳的"贝"藏着一个关于钱币的大秘密！

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **珍贵** | 非常宝贵 | 这张照片很珍贵。 |
| **钱币** | 钱 | 古代的钱币是用贝壳做的。 |
| **财富** | 有价值的东西 | 知识是最好的财富。 |
| **购买** | 买 | 妈妈在网上购买了一本书。 |
| **漂亮** | 好看、美丽 | 贝壳很漂亮。 |
| **贝壳** | 贝类的硬壳 | 海边有各种各样的贝壳。 |
| **装饰** | 打扮、美化 | 她用贝壳装饰相框。 |
| **随身** | 带在身上 | 古人随身带着贝壳当钱用。 |
| **损坏** | 弄坏 | 贝壳容易损坏，所以后来用金属钱币。 |
| **容易** | 不难 | 这件事做起来很容易。 |

### 💡 形声字归类：贝字旁
| 字 | 意思 | 跟"贝"的关系 |
|:--|:-----|:-------------|
| 财 | 钱财 | 贝 + 才 |
| 赚 | 挣钱 | 贝 + 兼 |
| 赔 | 亏本 | 贝 + 咅 |
| 购 | 买 | 贝 + 勾 |
| 贫 | 没钱 | 贝 + 分 |
| 货 | 货物 | 贝 + 化 |

**规律**：带"贝"的字大多跟**钱、财富**有关。

## 3 中国美食

### 📖 课文概要
凉拌菠菜、香煎豆腐、红烧茄子、烤鸭、羊肉炒饭……一道道中国美食，光看名字就流口水了！

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **美食** | 好吃的食物 | 中国的美食很多。 |
| **煎** | 锅里放油加热 | 妈妈在煎鸡蛋。 |
| **烤** | 用火直接加热 | 爸爸烤的羊肉串很香。 |
| **爆** | 大火快炒 | 葱爆羊肉是一道名菜。 |
| **蒸** | 用水蒸气加热 | 奶奶蒸的馒头又大又白。 |
| **凉拌** | 凉着加调料拌匀 | 夏天我最爱吃凉拌黄瓜。 |
| **红烧** | 加酱油烧制 | 红烧肉入口即化。 |
| **炖** | 加水慢火煮 | 冬天适合喝炖汤。 |
| **鲜美** | 味道好 | 这碗汤特别鲜美。 |
| **营养** | 对身体有益的成分 | 蔬菜有丰富的营养。 |

### 💡 形声字归类：火字旁和四点底
| 字 | 部首 | 跟火的关系 |
|:--|:----|:-----------|
| 炒 | 火 | 用火炒菜 |
| 烤 | 火 | 用火烤 |
| 烧 | 火 | 用火烧 |
| 煎 | 火 | 用火煎 |
| 煮 | 灬 | 用水煮 |
| 蒸 | 艹 | 用蒸汽蒸 |
| 爆 | 火 | 大火快炒 |

**规律**："火"和"灬"（四点底）大多跟**火、加热**有关。

## ⚠️ 易错字提醒

| 字 | 易错点 | 记忆口诀 |
|:---|:-------|:---------|
| **街** | 中间两个"土"，不要漏一个 | 街上有两个土堆 |
| **闹** | 里面是"市"，不是"布" | 热闹是自己走进市场 |
| **烧** | 右上是"戈"不是"尧" | 烧火用戈来搭 |
| **烤** | 右边不是"考" | 烤火不靠它，靠的是火 |
| **煎** | 下面是"灬"，上面是"前" | 煎东西前面有火 |

| 字 | 组词 | 易混字 | 组词 | 区分方法 |

| **烧** | 烧火 | **浇** | 浇水 | 用火烧，用水浇 |

## 📦 偏旁归类

| 偏旁 | 说明 | 例字 |
|:-----|:-----|:-----|
| **贝（贝字旁）** | 跟钱、财富有关 | 财、赚、赔、购、贫、货、贵、费 |

## ✍️ 写话：用词语写句子

### 🎯 目标
用本单元学过的形声字和词语，写完整的句子。

### 📐 练习方法
1. **看字写词**：先写出带这个偏旁的字
2. **用词造句**：用这个词写一句话
3. **连句成段**：把几个句子连起来

### 🧩 偏旁小练习
| 偏旁 | 字 | 句子 |
|:----|:--|:-----|
| 贝 | 财 | **过年我收到了压岁钱，这是我的小财富。** |
| 火 | 炒 | **妈妈在厨房里炒菜，香喷喷的。** |
| 艹 | 节 | **我最喜欢的传统节日是春节。** |
| 饣 | 饭 | **我每天帮妈妈盛饭。** |
| 灬 | 蒸 | **清蒸鱼又鲜又嫩。** |

### 📝 示例
> 中国的传统节日有很多。春节我最喜欢，因为可以贴窗花、放鞭炮。端午节吃粽子，中秋节吃月饼。中国美食真多呀！我最爱吃烤鸭和红烧茄子。

### 📝 进阶示例
> 春节是中国最盛大的传统节日。大年三十，全家人欢聚一堂吃年夜饭，热热闹闹的。妈妈做了香喷喷的红烧肉，爷爷清蒸了一条鱼，奶奶煮了热乎乎的饺子——每一道都是美食！晚饭后，我们一起看花灯、放鞭炮。团聚的感觉真温暖啊。



### 💡 写话小锦囊

#### 1. 从课文里学方法
从"传统节日""中国美食"学用词语写句子——用上表示时间或动作的词写一句话。
> 端午节到了，我和妈妈一起**包**粽子，**吃**粽子，真开心！

#### 2. 想好了再写
提笔之前先想一想：
- 我要写什么？（是写一个人、一件事，还是一处风景？）
- 用哪几个词或句式来写？（从课文里学到的）
- 先写什么，再写什么？（想好顺序再动笔）

想清楚了再写，写的时候就不慌了。

#### 3. 写真的，写自己的
写你真正看到、听到、想到的。不用编，不用抄。
- 写自己的事——哪怕是一件很小的事
- 写自己的话——用你自己会说的词
- 写真实的感受——开心就写开心，难过就写难过

> 作文不是为了写给别人看，而是为了记下自己的故事。
