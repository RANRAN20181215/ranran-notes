## 23 古诗二首

### 赋得古原草送别 · [唐] 白居易

> 离离原上草，一岁一枯荣。
> 野火烧不尽，春风吹又生。

**📜 背景**：白居易十六岁那年，带着自己的诗稿来到长安，拜访当时的大诗人顾况。顾况看到"白居易"三个字，开玩笑说："长安米价很贵，居住下来可不容易啊！"可等他读到"野火烧不尽，春风吹又生"时，大吃一惊，连忙改口："能写出这样的诗句，居住下来去哪里都不难！"从此白居易名声大噪。

### 🎭 走进诗人

**逸事**：关于这首诗，还有一个感人的背景。白居易小时候家里很穷，但他读书非常用功，读到嘴里长了口疮、胳膊肘磨出了茧子。十六岁写出"野火烧不尽，春风吹又生"时，他其实也在写自己——不管生活多么艰难，他都像野草一样顽强地活下来、长起来。这首诗既是写草，也是写他自己。

**时代印记**：唐朝的科举考试是文人改变命运的唯一途径。考生们需要在考场上当场写诗，压力巨大。白居易这首"考场作文"能成为千古名篇，说明他从小练就了过硬的功夫。"野火烧不尽，春风吹又生"这两句，后来成了中国人形容顽强精神时最常用的话——从考场到生活，从一千多年前到今天。

**🔑 注释**
- 离离：茂盛的样子
- 原：草原、原野
- 枯：干枯
- 荣：茂盛
- 尽：完、光

**💡** "野火烧不尽，春风吹又生"——野草的生命力多么顽强！**表面写草，其实也在告诉人们：要像野草一样坚强。**

### 🌿 古诗重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **离离** | 茂盛的样子 | 离离原上草，一岁一枯荣。 |
| **枯荣** | 干枯和茂盛 | 花开花落，一岁一枯荣。 |
| **不尽** | 烧不完 | 野火再大也烧不尽野草。 |
| **又生** | 再次长出来 | 春天来了，小草又生。 |
| **顽强** | 坚强、不屈服 | 野草的生命力真顽强。 |
| **原野** | 宽广的田野 | 原野上一片绿色。 |
| **送别** | 送行、告别 | 这是一首送别诗。 |
| **生命力** | 维持生命的能力 | 野草有很强的生命力。 |

## 24 羿射九日

### 📖 课文概要
很久以前，天上同时出现了十个太阳。大地被烤焦了，人类无法生存。神箭手羿翻过九十九座山、蹚过九十九条河，登上最高的山，拉开神弓——嗖嗖嗖射下了九个太阳。最后一个太阳留了下来，给大地带来光明和温暖。

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **温暖** | 暖和 | 阳光很温暖。 |
| **炙烤** | 烧烤 | 太阳炙烤着大地。 |
| **熔化** | 固体变成液体 | 铁在高温下熔化了。 |
| **艰难** | 困难 | 翻山越岭很艰难。 |
| **勃勃生机** | 生命力旺盛 | 大地上恢复了勃勃生机。 |
| **神箭手** | 射箭技术高超的人 | 羿是著名的神箭手。 |
| **翻越** | 翻过、越过 | 他翻越了九十九座山。 |
| **蹚过** | 从水中走过去 | 他蹚过了一条大河。 |
| **射箭** | 用弓射箭 | 羿擅长射箭。 |
| **传说** | 从古代流传下来的故事 | 羿射九日是一个神话传说。 |

### 💡 想象画面
> "太阳像大火球一样炙烤着大地。禾苗被晒枯了，土地被烤焦了，江河里的水快被蒸干了……"

**读这句话时，你的眼前出现了什么画面？** 一片焦渴的大地，一切都在喊"热"。

### 💡 羿的形象
- 翻过九十九座山 → 不怕困难
- 蹚过九十九条河 → 坚持不懈
- 嗖嗖嗖射下九个太阳 → 本领高强

### 💡 神话的特点
神话是古人想象出来的故事，用来解释自然现象。古人无法理解"为什么天上只有一个太阳"，于是创造了这个美丽的神话。

## 25 黄帝的传说

### 📖 课文概要
黄帝看到树叶在风中滚动，受到启发，发明了车轮。他又联合炎帝部落，打败了蚩尤，统一了各个部落。黄帝带领人们造车、造船、造房子、织布、养蚕——他是中华民族的"人文始祖"。

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **传说** | 流传下来的故事 | 黄帝的传说流传了几千年。 |
| **启发** | 受到开导而明白 | 老师的讲解给了我启发。 |
| **联合** | 结合在一起 | 大家联合起来力量大。 |
| **统一** | 合为一体 | 黄帝统一了各个部落。 |
| **贡献** | 对国家做的有益的事 | 科学家为国家做出了贡献。 |
| **部落** | 古代人群组织 | 黄帝带领他的部落不断壮大。 |
| **制造** | 加工、做出 | 黄帝教人们制造工具。 |
| **发明** | 创造出新事物 | 发明车轮改变了历史。 |
| **材料** | 用来加工的原料 | 造车需要木材做材料。 |
| **祖先** | 年代久远的前辈 | 黄帝是中华民族的祖先。 |

### 💡 想象：从观察到创造
黄帝看到树叶被风吹得滚动 → 想到圆的东西可以滚 → 发明了车轮

**想象 + 思考 = 创造**。古人从大自然中获得了无数的灵感！

### 💡 提取信息
| 发明 | 受到什么启发 |
|:----|:------------|
| 车 | 树叶滚动 |
| 船 | 木头浮在水上 |

## ⚠️ 易错字提醒

| 字 | 易错点 | 记忆口诀 |
|:---|:-------|:---------|
| **烧** | 右上是"戈"不要漏点 | 烧火要用戈来拨 |
| **烤** | 右边不是"考" | 烤火不靠别人，靠火 |
| **类** | 上面是"米"下面是"大" | 米字头加大就是类 |

## 📦 偏旁归类

| 偏旁 | 说明 | 例字 |
|:-----|:-----|:-----|
| **礻（示字旁）** | 跟神、祭祀有关 | 祖、神、礼、祝、福 |
| **亻（单人旁）** | 跟人有关 | 值、但、何、使、作 |
| **弓（弓字旁）** | 跟弓箭、弯曲有关 | 弓、张、弯、弹、引 |

**🌱 拓展**："祖"是示字旁，跟祭祀、祖先有关——古人祭祀祖先以示敬重。"羿射九日"中"射"是用弓，而"弓"字本身就是象形字，像一张弓的形状。

## ✍️ 写话：把想象的内容写下来

### 🎯 目标
选一个话题，展开想象，写一段"想象"的话。

### 📐 写作框架
1. **开头**：想象的世界是什么样的
2. **中间**：发生了什么神奇的事
3. **结尾**：有什么感受

### 🧩 想象话题推荐
1. **假如我有一双翅膀**……（想去哪里？看到什么？）
2. **假如我会七十二变**……（想变成什么？做什么？）
3. **假如我是神箭手**……（像羿一样做什么事？）
4. **假如我有一颗魔法种子**……（它会长出什么？）

### 🧩 想象写话词语宝库

**假如我有一双翅膀**
| 想写的 | 可以用的词 |
|:-------|:-----------|
| 飞去哪里 | 天空、云朵、森林、大海、高原 |
| 看到什么 | 彩虹、瀑布、雪山、草原、日出 |
| 听到什么 | 风声、鸟鸣、海浪、虫鸣 |
| 感受 | 自由、快乐、神奇、勇敢 |

**假如我是神话人物**
| 想写的 | 可以用的词 |
|:-------|:-----------|
| 羿 | 拉弓、射箭、翻山、蹚河、神箭 |
| 黄帝 | 发明、创造、智慧、观察、启发 |

### 📝 示例
> 假如我有一双翅膀，我要飞到高高的天空上。我穿过洁白的云朵，看到了彩虹桥。我飞到森林上空，看到小动物们在开音乐会。我飞到大海边，看到浪花在跳舞。有一双翅膀真好，想去哪里就去哪里！

### 📝 进阶示例（神话仿写）
> 假如我是神箭手羿，我会背着神弓，翻过九十九座大山，蹚过九十九条大河。我要射下天上多余的太阳，让大地不再被炙烤；我要让禾苗重新长起来，让江河重新流起来，让人们在清凉的风中露出笑脸。虽然射日很辛苦，但能帮助大家，我觉得一切都值得！

### ⚠️ 小提示
1. ✅ 想象要大胆（可以天马行空）
2. ✅ 但要写得具体（让人"看到"画面）
3. ✅ 故事要有头有尾



### 💡 写话小锦囊

#### 1. 从课文里学方法
从"祖先的摇篮""羿射九日"学写想象中的事物——大胆想，好好写。
> 假如我有一支神笔，我要画一座糖果房子：墙是巧克力做的，窗户是棒棒糖，屋顶是草莓饼干！

#### 2. 想好了再写
提笔之前先想一想：
- 我要写什么？（是写一个人、一件事，还是一处风景？）
- 用哪几个词或句式来写？（从课文里学到的）
- 先写什么，再写什么？（想好顺序再动笔）

想清楚了再写，写的时候就不慌了。

#### 3. 写真的，写自己的
写你真正看到、听到、想到的。不用编，不用抄。
- 写自己的事——哪怕是一件很小的事
- 写自己的话——用你自己会说的词
- 写真实的感受——开心就写开心，难过就写难过

> 作文不是为了写给别人看，而是为了记下自己的故事。
