# 第七单元 · 改变

> 大象的耳朵耷拉着、蜘蛛开店没开成、青蛙卖泥塘卖了又改、小毛虫变成了蝴蝶——它们都在改变。
> **阅读重点**：改变人称讲故事
> **写话目标**：写简单的观察记录

---

## 19 大象的耳朵

### 📖 课文概要
大象的耳朵耷拉着，小兔子说："你的耳朵怎么耷拉下来了？"小羊也说，小鹿也说……大象把耳朵竖了起来，结果虫子飞进去了，又痛又痒。大象终于明白了：还是让耳朵耷拉着吧！

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **耷拉** | 下垂、往下挂 | 小狗的耳朵耷拉着。 |
| **扇子** | 摇动生风的工具 | 大象的耳朵像两把大扇子。 |
| **不安** | 心里不踏实 | 他一个人在家觉得很不安。 |
| **自言自语** | 自己跟自己说话 | 爷爷自言自语地念叨着。 |
| **人家** | 别人 | 人家是人家，我是我。 |
| **竖起** | 立起来 | 小兔子竖起了耳朵。 |
| **跳舞** | 跳舞蹈 | 蝴蝶在花丛中跳舞。 |
| **头痛** | 头疼 | 大象竖起耳朵后觉得头痛。 |
| **撑开** | 张开、打开 | 大象把耳朵撑开像扇子。 |
| **最后** | 到最后 | 大象最后还是把耳朵耷拉下来了。 |

### 💡 道理
> "人家是人家，我是我。"

**不要别人说什么你就信什么。** 适合自己的才是最好的。大象的耳朵就是耷拉着，正常得很！

### 💡 对话推动故事
"大象，你的耳朵怎么耷拉下来了？"——每次多一个小动物问，大象就多一分不安。最后大象改变了自己，却吃了苦头。

## 20 蜘蛛开店

### 📖 课文概要
蜘蛛觉得每天蹲在网上很无聊，决定开店。卖口罩，结果来了一只河马，织了一整天。卖围巾，结果来了一只长颈鹿，织了一个星期。卖袜子，结果来了一只蜈蚣，蜘蛛吓得跑回了网上。

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **决定** | 做出选择 | 我决定每天练字。 |
| **编织** | 编东西 | 妈妈在编织毛衣。 |
| **匆忙** | 急急忙忙 | 他匆忙地跑出了门。 |
| **终于** | 最后、到底 | 我终于把作业写完了。 |
| **寂寞** | 孤单、无聊 | 一个人在家很寂寞。 |
| **口罩** | 戴在嘴上的防护用品 | 冬天出门要戴口罩。 |
| **围巾** | 围在脖子上的纺织品 | 天冷了，妈妈给我织了一条围巾。 |
| **袜子** | 穿在脚上的织物 | 店里来了一只蜈蚣要买袜子。 |
| **顾客** | 买东西的人 | 蜘蛛的店里来了一位顾客。 |
| **商店** | 卖东西的地方 | 蜘蛛开了一家商店。 |

### 💡 反复的结构
蜘蛛开店 → 来了一位顾客 → 太大了做不完 → 换一个生意
**重复三次**：口罩→河马，围巾→长颈鹿，袜子→蜈蚣。每一次都因为没考虑顾客的大小而失败。

### 💡 道理
做事之前要想清楚、做好准备，不能想当然。

## 21 青蛙卖泥塘

### 📖 课文概要
青蛙觉得自己的泥塘不怎么样，想卖出去。老牛说不喜欢这里没有草，青蛙就种了草。野鸭说不喜欢这里没有水，青蛙就引了水。小鸟说缺点树、蝴蝶说缺花、小兔说缺路……青蛙一次次改造泥塘。最后泥塘变得特别美——青蛙不卖了！

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **泥塘** | 烂泥坑 | 青蛙住在泥塘里。 |
| **牌子** | 写字的木板 | 青蛙在门口竖了一个牌子。 |
| **吆喝** | 大声叫卖 | 小贩在街上吆喝。 |
| **绿茵茵** | 绿油油的 | 绿茵茵的草地真美。 |
| **播撒** | 撒种 | 农民在田间播撒种子。 |
| **采集** | 收集、采 | 蝴蝶在采集花蜜。 |
| **缺点** | 不够好的地方 | 泥塘的缺点是没有草。 |
| **改造** | 改变、改建 | 青蛙不断改造泥塘。 |
| **破旧** | 破烂、陈旧 | 泥塘原来很破旧。 |
| **舒服** | 适意、舒适 | 改造后的家真舒服。 |

### 💡 青蛙的改变
别人提出缺点 → 青蛙改造 → 泥塘越来越好

青蛙从"想卖"变成"不卖"了——因为它在改造的过程中爱上了自己的家。**劳动让生活更美好。**

## 22 小毛虫

### 📖 课文概要
一条小毛虫不会飞、不会跑，被昆虫们嘲笑。它不悲观不失望，每天织茧。最后它破茧而出，变成了一只美丽的蝴蝶！

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **生机勃勃** | 充满生命力 | 春天的田野生机勃勃。 |
| **笨拙** | 不灵活 | 小企鹅走路很笨拙。 |
| **悲观** | 失望、不乐观 | 遇到困难不要悲观。 |
| **尽心竭力** | 用尽全力 | 小毛虫尽心竭力地织茧。 |
| **与世隔绝** | 跟世界分开 | 茧里是一个与世隔绝的小世界。 |
| **羡慕** | 看到别人好自己也想要 | 小毛虫羡慕会飞的蝴蝶。 |
| **轻盈** | 轻巧优美 | 蝴蝶的翅膀真轻盈。 |
| **牢固** | 坚固、结实 | 茧织得又牢固又温暖。 |
| **挣脱** | 用力摆脱 | 小毛虫挣脱了茧的束缚。 |
| **色彩斑斓** | 颜色鲜艳丰富 | 蝴蝶的翅膀色彩斑斓。 |

### 💡 改变人称讲故事
课文用第三人称写（它）：
> "小毛虫趴在一片叶子上，用新奇的目光打量着周围的昆虫。"

改成第一人称（我）：
> "我趴在一片叶子上，用新奇的目光打量着周围的昆虫。"

**两种感觉不一样**：第三人称像旁观者，第一人称更像在亲身体验。

### 💡 道理
**每个人都有自己该做的事。** 小毛虫不会飞不会跑，但它会织茧。坚持做好自己的事，终会迎来最美的蜕变。

## ✍️ 写话：写简单的观察记录

### 🎯 目标
选择一种动物或植物，连续观察几天，把看到的变化记下来。

### 📐 写作框架
1. **观察对象**：观察什么
2. **观察时间**：什么时候观察的
3. **观察发现**：看到了什么变化
4. **我的感受**：觉得怎么样

### 🧩 词语小宝库
| 类别 | 词语 |
|:-----|:-----|
| 时间 | 今天、第二天、过了几天、一周后 |
| 发现变化 | 发现、看到、长出了、变成了、慢慢 |
| 动作 | 爬、钻、伸、吃、吐、飞、破 |
| 形状 | 小小的、胖乎乎的、长长的、椭圆 |
| 颜色 | 黑色、白色、绿色、彩色、透明 |
| 感受 | 神奇、开心、惊讶、期待、激动 |

### 📝 示例：养蚕观察记录
> 4月10日：蚕宝宝从卵里钻出来了，像黑色的小蚂蚁。
> 4月12日：蚕宝宝变白了，身体长长了一点，开始吃桑叶了。
> 4月15日：蚕宝宝长大了好多，胖乎乎的，吃桑叶时发出"沙沙"的声音。
> 4月20日：蚕宝宝开始吐丝了，把自己包在茧里面。
> 5月1日：蚕蛾从茧里飞出来了！生命真的好神奇。

### 📝 进阶示例：发豆芽观察日记
> 10月1日：我把绿豆泡在水里。绿豆硬硬的、圆圆的，像绿色的小宝石。
> 10月2日：绿豆喝饱了水，变得胖胖的，有的皮都撑破了，露出了白色的身体。
> 10月3日：绿豆长出了小小的白芽，弯弯的，像小蝌蚪的尾巴。
> 10月5日：豆芽越长越长，白色的茎顶着两片嫩嫩的绿叶，真可爱！
> 10月7日：豆芽长得有五六厘米高了，绿油油的，充满了生机。

### 🧩 可以观察什么
| 动物 | 植物 |
|:----|:-----|
| 蚕宝宝 | 豆芽 |
| 小蝌蚪 | 蒜苗 |
| 蚂蚁 | 绿萝 |
| 蜗牛 | 向日葵 |



### 💡 写话小锦囊

#### 1. 从课文里学方法
从"小毛虫""青蛙卖泥塘"学写观察记录——把看到的变化写清楚。
> 我在花盆里种了一颗绿豆。第一天它还是个硬硬的小豆子，过了几天长出了嫩芽。哇，真神奇！

#### 2. 想好了再写
提笔之前先想一想：
- 我要写什么？（是写一个人、一件事，还是一处风景？）
- 用哪几个词或句式来写？（从课文里学到的）
- 先写什么，再写什么？（想好顺序再动笔）

想清楚了再写，写的时候就不慌了。

#### 3. 写真的，写自己的
写你真正看到、听到、想到的。不用编，不用抄。
- 写自己的事——哪怕是一件很小的事
- 写自己的话——用你自己会说的词
- 写真实的感受——开心就写开心，难过就写难过

> 作文不是为了写给别人看，而是为了记下自己的故事。
