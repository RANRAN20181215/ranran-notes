---

## 💡 讲一讲

这是一篇"看着就饿了"的课文！🤤

通过 **中国美食菜单** 学习汉字的 **烹饪方法偏旁**：

| 烹饪方法 | 偏旁 | 例子 |
|---|---|---|
| 🍳 **炒** | 火字旁 | 炒饭、炒菜 |
| 🔥 **烧** | 火字旁 | 红烧茄子 |
| ♨️ **烤** | 火字旁 | 烤鸭 |
| 💨 **蒸** | 草字头 | 蒸饺 |
| 🍲 **煮** | 四点底（火的变形） | 水煮鱼 |
| 🥟 **炸** | 火字旁 | 炸酱面 |
| 🥗 **拌** | 提手旁 | 凉拌菠菜 |
| 🥘 **炖** | 火字旁 | 小鸡炖蘑菇 |

> 大部分烹饪方式都跟 **火** 有关——所以"火"字旁和"四点底"（灬，也是火的变形）在很多烹饪字里出现。

---

## 🌿 解词语

| 词语 | 意思 |
|---|---|
| **凉拌** | 加调料拌着吃（不用火） |
| **红烧** | 加酱油和糖烧 |
| **烤** | 放在火上烤熟 |
| **煮** | 放在水里煮熟 |
| **蒸** | 利用水蒸气加热 |
| **炸** | 放在热油里炸熟 |
