# 🇨🇳 神州谣

> 识字歌谣

---

## 📖 读一读

我神州，称中华，
山川美，可入画。

黄河奔，长江涌，
长城长，珠峰耸。

台湾岛，隔海峡，
与大陆，是一家。

各民族，情谊浓，
齐奋发，共繁荣。

---

## 📜 知背景

"神州"是中国的古称。古人认为中国是"神仙居住的地方"——所以叫"神州"。"华夏""中华""神州"都是中国的别称。

这篇歌谣介绍了中国最有代表性的 **山川地理** 和 **民族团结**。

**四个关键地理标志：**
- 🌊 **黄河**：中国的"母亲河"
- 🌊 **长江**：中国最长的河流
- 🏰 **长城**：世界上最长的城墙
- 🏔️ **珠峰**：世界最高峰（珠穆朗玛峰）

---

## 🌿 解词语

| 词语 | 意思 |
|---|---|
| **神州** | 中国的古称 |
| **奔** | 奔流、奔跑 |
| **涌** | 水大量涌出来 |
| **耸** | 高高地立着 |
| **隔** | 分开、隔着 |
| **海峡** | 两块陆地之间的狭长海面 |
| **情谊** | 感情 |
| **繁荣** | 富强、兴旺 |
