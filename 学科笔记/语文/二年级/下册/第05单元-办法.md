# 第五单元 · 办法

> 丢了羊怎么办？禾苗不长怎么办？画杨桃该怎么画？小马能不能过河？——每个问题都需要想办法。
> **阅读重点**：根据提示讲故事
> **写话目标**：按顺序写一件事

## 12 寓言二则

### 亡羊补牢

### 📖 课文概要
一个人养了一群羊。羊圈破了个窟窿，邻居劝他修，他不听。夜里狼叼走了一只羊。第二天邻居又劝，他还是不修，结果又丢了一只。他这才赶紧把羊圈修好了。从此羊再也没丢过。

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **窟窿** | 洞、破洞 | 墙上有一个窟窿。 |
| **叼走** | 用嘴衔走 | 乌鸦叼走了一块肉。 |
| **街坊** | 邻居 | 街坊邻居要互相帮助。 |
| **后悔** | 事后感到懊悔 | 我很后悔没有听妈妈的话。 |
| **从此** | 从这时起 | 从此他认真学习，成绩变好了。 |
| **羊圈** | 关羊的围栏 | 羊圈的栅栏坏了。 |
| **劝告** | 用道理说服人 | 大家劝告他不要大意。 |
| **接受** | 同意收下 | 他接受了邻居的劝告。 |
| **损失** | 失去的东西 | 因为大意损失了一只羊。 |
| **修补** | 修理、补好 | 他赶紧修补羊圈的窟窿。 |

### 💡 道理
> "亡羊补牢，犹未晚也。"

丢了羊之后赶紧补羊圈，还不算晚。**犯了错误不怕，及时改正就好。**

### 揠苗助长

### 📖 课文概要
一个人嫌自己田里的禾苗长得太慢，就一棵一棵地往上拔——拔完之后禾苗"长高"了一大截。可是第二天，禾苗全都枯死了。

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **焦急** | 非常着急 | 他焦急地走来走去。 |
| **转来转去** | 走来走去 | 妈妈在客厅里转来转去。 |
| **筋疲力尽** | 累得力气用光了 | 跑完步我筋疲力尽。 |
| **枯死** | 干枯而死 | 花好几天没浇水，枯死了。 |
| **禾苗** | 庄稼的幼苗 | 田里的禾苗绿油油的。 |
| **拔高** | 往上拔、拉高 | 他把禾苗一棵棵拔高。 |
| **巴望** | 急切地盼望 | 他巴望禾苗快快长大。 |
| **总算** | 终于 | 拔完禾苗，他总算松了一口气。 |
| **白费** | 白白浪费 | 他的力气全部白费了。 |
| **结果** | 最后的结局 | 结果禾苗全枯死了。 |

### 💡 道理
**违反事物的生长规律，急于求成，反而会坏事。** 不管是种庄稼还是学习，都不能太着急。

## 13 画杨桃

### 📖 课文概要
美术课上，老师让同学们画杨桃。"我"坐在前排，看到的杨桃像五角星，就把它画成了五角星。有同学嘲笑他画错了。老师让大家轮流到"我"的位置看——原来从那个角度看，杨桃真的是五角星形的！

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **叮嘱** | 反复告诉、嘱咐 | 妈妈叮嘱我过马路要小心。 |
| **审视** | 仔细看 | 老师审视了我的画。 |
| **严肃** | 认真、不随便 | 老师说话很严肃。 |
| **教诲** | 教育、指导 | 老师的教诲我记在心里。 |
| **和颜悦色** | 态度温和亲切 | 老师和颜悦色地给我们讲解。 |
| **轮流** | 一个接一个 | 大家轮流上讲台发言。 |
| **角度** | 观察的位置 | 从我的角度看到的是五角星。 |
| **准确** | 完全正确 | 从侧面看画得更准确。 |
| **相似** | 差不多、像 | 杨桃和五角星有一点相似。 |
| **相信** | 认为是对的 | 要相信自己的眼睛。 |

### 💡 道理
**看问题角度不同，结果也不同。** 不要轻易说别人错了，换到对方的角度看看再说。

### 💡 对话描写
课文通过老师和同学的对话推动情节——"不像！""像什么？""像五角星！"——短句多，读起来像在看一场小话剧。

## 14 小马过河

### 📖 课文概要
小马帮妈妈送麦子到磨坊，路上被一条小河挡住了。老牛说河水很浅，松鼠说河水很深。小马不知道该怎么办，跑回家问妈妈。妈妈告诉它：光听别人说不行，自己试试才知道。小马鼓起勇气下了河——原来河水既不像老牛说的那么浅，也不像松鼠说的那么深。

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **愿意** | 同意、乐意 | 我愿意帮妈妈做家务。 |
| **立刻** | 马上 | 听到铃声，我立刻跑进教室。 |
| **突然** | 忽然 | 天突然下起了雨。 |
| **难为情** | 不好意思 | 做错事了，他有点难为情。 |
| **亲切** | 亲近、温和 | 妈妈亲切地摸着我的头。 |
| **磨坊** | 磨面粉的地方 | 小马把麦子驮到磨坊。 |
| **拦住** | 挡住 | 小河拦住了小马的去路。 |
| **深浅** | 深和浅的程度 | 他不知道河的深浅。 |
| **脑筋** | 思考的能力 | 遇到问题要动脑筋。 |
| **勇气** | 敢于面对困难的胆量 | 小马鼓起勇气下了河。 |

### 💡 道理
> "光听别人说，自己不动脑筋，不去试试，是不行的。"

**别人说的不一定适合你，要自己动脑筋、亲自试。** 老牛高所以水浅，松鼠小所以水深，小马不高不矮，水刚合适。

### 💡 故事结构（按顺序）
妈妈让小马送麦子 → 被小河挡住 → 问老牛 → 问松鼠 → 回家问妈妈 → 自己去试 → 成功过河

## ⚠️ 易错字提醒

| 字 | 易错点 | 记忆口诀 |

| **牢** | 宝盖头下面不要写成"牛" | 牢房是宝盖头下面一头牛 |
| **疲** | 里面是"皮"不是"病" | 疲惫像生病，但里面是皮 |
| **愿** | 心字底，里面有"原" | 愿在心里面，原来是心愿 |
| **麦** | 上面是"青"字头，不要少一横 | 麦子上半青，下半是夕 |
| **突** | 下面是"犬"不是"大" | 突然冒出狗（犬） |

## ✍️ 写话：按顺序写一件事

### 🎯 目标
按照事情发生的先后顺序，写清楚一件完整的事。

### 📐 写作框架
1. **起因**：为什么做这件事
2. **经过**：遇到了什么问题，怎么想的
3. **结果**：最后怎么样了

### 🧩 词语小宝库
| 类别 | 词语 |
|:-----|:-----|
| 开始 | 一开始、有一天、今天、周末 |
| 遇到问题 | 忽然、没想到、可是、但是 |
| 想办法 | 左思右想、动脑筋、请教 |
| 解决问题 | 终于、最后、总算、这才 |
| 结果/感受 | 成功、开心、高兴、明白了、记住了 |

### 📝 示例
> 今天妈妈让我去楼下买酱油。我跑到小卖部，阿姨说酱油有三种，我不知道买哪种。我赶紧跑回家问妈妈，妈妈说买生抽。我又跑回小卖部，买到了生抽。回到家，妈妈夸我能干。

### 📝 进阶示例（寓言仿写）
> 一天，小明做数学作业时遇到一道难题。他想了很久也没想出来，有点着急。他问同桌这道题怎么做，同桌说选A；问后面的同学，同学说选C。小明不知道听谁的，只好回家问爸爸。爸爸说："你先自己动脑筋想一想。如果还是不会，我来教你。"小明静下心重新读题，终于自己算出了答案——果然，自己做出来的感觉最棒！

### 🧩 顺序词
| 开头 | 中间 | 结尾 |
|:----|:----|:-----|
| 有一天 | 然后 | 最后 |
| 今天 | 接着 | 结果 |
| 一开始 | 这时候 | 终于 |



### 💡 写话小锦囊

#### 1. 从课文里学方法
从"画杨桃""小马过河"学按顺序写——写出自己的想法和做法。
> 我在做手工。先折一个三角形，再翻过来，画上眼睛——一只小狐狸就做好啦！

#### 2. 想好了再写
提笔之前先想一想：
- 我要写什么？（是写一个人、一件事，还是一处风景？）
- 用哪几个词或句式来写？（从课文里学到的）
- 先写什么，再写什么？（想好顺序再动笔）

想清楚了再写，写的时候就不慌了。

#### 3. 写真的，写自己的
写你真正看到、听到、想到的。不用编，不用抄。
- 写自己的事——哪怕是一件很小的事
- 写自己的话——用你自己会说的词
- 写真实的感受——开心就写开心，难过就写难过

> 作文不是为了写给别人看，而是为了记下自己的故事。
