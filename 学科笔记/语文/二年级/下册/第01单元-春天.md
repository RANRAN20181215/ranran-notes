# 第一单元 · 春天

> 春天来了——读古诗里的柳树和风筝，找田野里的春天，看开满鲜花的小路，听邓小平爷爷植树的故事。
> **阅读重点**：读句子，想象画面
> **写话目标**：用积累的词语写话

## 1 古诗二首

### 村居 · [清] 高鼎

> 草长莺飞二月天，拂堤杨柳醉春烟。
> 儿童散学归来早，忙趁东风放纸鸢。

**📜 背景**：晚清诗人高鼎晚年隐居在乡村。一个春日的午后，他正在屋里读书，忽然被窗外孩子们的欢笑声吸引。他放下书走出去——柳树绿了、黄莺飞了、孩子们跑着笑着放风筝。这热热闹闹的春日场景让他心里暖暖的，提笔写下了《村居》。

**🔑 注释**
- 村居：住在村子里
- 拂堤：柳条轻轻拂过堤岸
- 醉春烟：沉醉在春天的雾气里
- 纸鸢：风筝

**💡** "忙趁东风放纸鸢"——"忙趁"写出孩子们迫不及待的心情。

### 🎭 走进诗人

**逸事**：高鼎的一生其实很坎坷——他生活在清朝末年，兵荒马乱。但神奇的是，他写的诗一点也不苦。《村居》里全是阳光、笑声和风筝。有人说，他是在用诗"保存"那些美好的时刻——现实越艰难，他越要写下那些珍贵的快乐。所以他笔下的春天，比谁的春天都明亮。

**时代印记**：高鼎生活在晚清，那是中国历史上最动荡的时期之一——鸦片战争、太平天国……可《村居》里没有一丝战火的气息。这让后人读到诗时常常恍惚：原来在那个苦难的时代，春天依然如约而至，孩子们依然会放学放风筝。

### 咏柳 · [唐] 贺知章

> 碧玉妆成一树高，万条垂下绿丝绦。
> 不知细叶谁裁出，二月春风似剪刀。

**📜 背景**：贺知章八十六岁那年，终于告老还乡了。他离开家乡做官五十多年，回来时已是白发苍苍的老爷爷。走在故乡的小路上，一棵嫩绿的柳树在春风中摇曳——那细长的柳叶像被剪刀精心裁剪过一样。老人家站在柳树下，眼泪差点掉下来：家乡的春天还是那么美啊！

**🔑 注释**
- 碧玉：绿色的玉石
- 妆成：打扮好
- 丝绦：丝线做的带子
- 裁：裁剪

**💡** "二月春风似剪刀"——把春风比作剪刀，柳叶像被剪出来的，想象力真奇妙！

### 🎭 走进诗人

**逸事**：贺知章是唐朝最长寿的诗人之一，活了八十六岁。他性格特别乐观开明，朋友遍布朝野。李白第一次到长安时，贺知章已经八十多岁了。他读了李白的诗，惊呼"你是天上贬下来的神仙啊！"当场解下随身佩戴的金龟换酒请李白喝。李白感动得不得了，一辈子都记得这位可爱的老前辈。

**时代印记**：贺知章经历了唐朝最鼎盛的开元盛世。他的一生几乎和唐朝的黄金时代重叠——那是一个自信、开放、人人都相信明天会更好的时代。一个八十六岁的老人回乡时眼里还充满好奇和赞叹，这就是盛世最好的证明。

### 🌿 古诗重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **拂堤** | 柳条轻轻擦着堤岸 | 春风拂堤，柳枝轻轻摆动。 |
| **醉春烟** | 沉醉在春天的雾气里 | 远处的柳树仿佛醉春烟一般朦胧。 |
| **纸鸢** | 风筝 | 孩子们在草地上放纸鸢。 |
| **碧玉** | 绿色的玉石 | 柳树的叶子像碧玉一样绿。 |
| **丝绦** | 丝线编的带子 | 柳条像绿色的丝绦垂下来。 |
| **裁剪** | 用剪刀剪裁 | 春风像一位裁剪师，剪出了细长的柳叶。 |
| **散学** | 放学 | 每天散学后我都要先写作业。 |
| **归来** | 回来 | 爸爸傍晚才从公司归来。 |

## 2 找春天

### 📖 课文概要
几个孩子脱掉棉袄，冲出家门去田野里找春天。小草是春天的眉毛，野花是春天的眼睛，嫩芽是春天的音符，小溪是春天的琴声——春天像个害羞的小姑娘。

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **害羞** | 不好意思、怕生 | 小妹妹很害羞，躲在妈妈身后。 |
| **遮遮掩掩** | 躲躲藏藏、不明显 | 春天遮遮掩掩地走来，很难发现。 |
| **探出头** | 伸出来 | 小草从地下探出头来。 |
| **音符** | 音乐里的符号 | 小嫩芽像春天的音符。 |
| **触到** | 碰到、摸到 | 微风轻轻触到我的脸。 |
| **挣脱** | 用力摆脱 | 孩子们挣脱棉袄的束缚冲出家门。 |
| **奔向** | 朝……跑去 | 我们奔向田野去找春天。 |
| **仔细** | 认真细心 | 我仔细地观察刚发芽的小草。 |
| **寻找** | 找 | 我们在树林里寻找春天的痕迹。 |
| **叮叮咚咚** | 形容流水的声音 | 小溪叮叮咚咚地流向远方。 |

### 💡 想象画面
- 小草 → 春天的眉毛
- 野花 → 春天的眼睛
- 嫩芽 → 春天的音符
- 小溪 → 春天的琴声

用眼睛看、耳朵听、鼻子闻、手触摸——全身感受春天！

## 3 开满鲜花的小路

### 📖 课文概要
鼹鼠先生收到一个包裹，里面是"一堆小颗粒"。他拿去问松鼠太太，路上包裹漏了。春天来了，那条路变成了开满鲜花的小路——原来"小颗粒"是花种子！

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **包裹** | 包好的东西 | 妈妈收到了一个快递包裹。 |
| **漏** | 从缝隙里掉出来 | 书包破了个洞，笔漏出来了。 |
| **绚丽多彩** | 颜色非常多、非常美 | 春天花开，绚丽多彩。 |
| **惊奇** | 惊讶、好奇 | 我惊奇地发现种子发芽了。 |
| **邮递员** | 送信送包裹的人 | 邮递员叔叔每天都很辛苦。 |
| **懊丧** | 因失望而不开心 | 玩具坏了，他很懊丧。 |
| **花朵** | 花 | 花朵在阳光下慢慢绽放。 |
| **刺猬** | 一种身上有刺的小动物 | 小刺猬背着一个果子。 |
| **鼹鼠** | 一种生活在地下的动物 | 鼹鼠先生喜欢在洞里睡觉。 |
| **松鼠** | 尾巴蓬松的小动物 | 小松鼠在树上跳来跳去。 |

### 💡 有趣的悬念
一开始你不知道"小颗粒"是什么，读到春天花开才恍然大悟。故事告诉我们：**意外的失误也可能变成美好的事**。

## 4 邓小平爷爷植树

### 📖 课文概要
1985年植树节，81岁的邓小平爷爷在天坛公园种树。他挖坑、放树苗、填土、扶正——每一个步骤都认认真真。小柏树种好了，像战士一样笔直地站着。

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **令人难忘** | 让人忘不了 | 那次旅行令人难忘。 |
| **兴致勃勃** | 很有兴趣、很有精神 | 爸爸兴致勃勃地给我讲故事。 |
| **茁壮** | 健康强壮 | 小树苗茁壮地成长。 |
| **扶正** | 扶起来弄直 | 他把歪了的画扶正。 |
| **参天大树** | 高耸入云的大树 | 学校门口有一棵参天大树。 |
| **天坛** | 北京的一座古代建筑 | 天坛公园里有很多古树。 |
| **挖坑** | 挖一个洞 | 爷爷在院子里挖坑种花。 |
| **树苗** | 刚长出来的小树 | 姐姐买了一棵小树苗。 |
| **休息** | 停下来歇一歇 | 劳动累了，坐在路边休息。 |
| **笔直** | 很直、不弯 | 解放军叔叔站得笔直。 |

### 💡 做事认真
种树要挖坑—放树—填土—扶正，每一步都认真。大人物做小事也一样不马虎。

## ⚠️ 易错字提醒

| 字 | 易错点 | 记忆口诀 |
|:---|:-------|:---------|
| **纸** | 下面没有点（不要写成"低"的右边） | "纸上没有点" |
| **柳** | 右边是"卯"，不要写成"印" | 柳条像卯眼，中间有一点 |
| **绿** | 右上是"彐"，不是"丑" | 绿色是"录"，不是"丑" |
| **野** | 左边是"里"，右边是"予" | 田野里有"里"和"予" |
| **满** | 右下不是"两"，里面是"从" | 鲜花满路，从从争艳 |

## ✍️ 写话：用积累的词语写春天

### 🎯 目标
用本单元学过的词语，写一段关于春天的话。

### 📐 写作框架
1. **开头**：春天来了
2. **看到的**：小草、野花、柳树、小鸟……
3. **听到的**：小溪叮咚、小鸟叽喳……
4. **闻到的**：花香、青草味……
5. **感受**：我喜欢春天

### 🧩 词语小宝库
| 类别 | 词语 |
|:----|:-----|
| 天气 | 温暖、阳光、微风 |
| 植物 | 嫩芽、柳枝、野花、小草 |
| 颜色 | 绿油油、红艳艳、金灿灿 |
| 动作 | 探出头、冒出来、飞来飞去 |
| 感受 | 开心、快乐、温暖 |
| 四字词语 | 绚丽多彩、兴致勃勃、令人难忘 |

### ✨ 词语超市（按句式分类）
**描写开头**：春天来了、春回大地、万物复苏、春天悄悄地走来了
**描写颜色**：绿油油的、红艳艳的、金灿灿的、碧绿碧绿的
**描写动作**：探出头来、冒出来、飞来飞去、摇摇摆摆、叮叮咚咚
**描写感受**：真舒服呀、多么美好、暖暖的、开心极了

### 📝 示例
> 春天来了。小草从地下探出头来，绿油油的。柳树长出了嫩芽，在风中摇来摇去。小鸟在树上叽叽喳喳地唱歌。春天的阳光暖暖的，真舒服！我喜欢春天。

### 📝 进阶示例（用上更多词语）
> 春天悄悄地走来了。田野里，小草探出了绿油油的脑袋；小路旁，野花开得红艳艳的，绚丽多彩。小溪叮叮咚咚地流着，像在弹琴。小鸟在枝头飞来飞去，叽叽喳喳地唱着歌。我兴致勃勃地跑到草地上放纸鸢，春天的风暖洋洋的，真令人难忘！



### 💡 写话小锦囊

#### 1. 从课文里学方法
从"找春天"学用积累的词语写话——把学过的词用在自己的句子里。
> "小草从地下**探出头来**，**绿油油**的。"——用上课文里的词，句子就变美了。

#### 2. 想好了再写
提笔之前先想一想：
- 我要写什么？（是写一个人、一件事，还是一处风景？）
- 用哪几个词或句式来写？（从课文里学到的）
- 先写什么，再写什么？（想好顺序再动笔）

想清楚了再写，写的时候就不慌了。

#### 3. 写真的，写自己的
写你真正看到、听到、想到的。不用编，不用抄。
- 写自己的事——哪怕是一件很小的事
- 写自己的话——用你自己会说的词
- 写真实的感受——开心就写开心，难过就写难过

> 作文不是为了写给别人看，而是为了记下自己的故事。
