# 第四单元 · 童心

> 彩色的梦、枫树上的喜鹊、沙滩上的童话、一只小虫子的世界——孩子的心里藏着最奇妙的想象。
> **阅读重点**：运用学到的词语写话
> **写话目标**：写一段通顺的话

---

## 8 彩色的梦

### 📖 课文概要
"我"有一大把彩色的梦——彩色铅笔。用它们画出了绿色的草坪、红色的野花、蓝色的天空、紫葡萄的叮咛……原来彩色的梦就是画出来的世界。

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **彩色** | 多种颜色 | 我用彩色铅笔画了一幅画。 |
| **精灵** | 活泼可爱的小神仙 | 小精灵在花丛中跳舞。 |
| **葱郁** | 草木茂盛翠绿 | 森林里葱郁的树木遮住了阳光。 |
| **叮咛** | 反复地嘱咐 | 妈妈叮咛我要注意安全。 |
| **对话** | 两个人说话 | 我和同桌在对话。 |
| **草坪** | 大片的草地 | 我们在草坪上放风筝。 |
| **滑过** | 轻快地擦过 | 铅笔尖在纸上滑过。 |
| **透明** | 能透过光线 | 玻璃是透明的。 |
| **梦境** | 梦里出现的情景 | 彩色的梦境里有蓝天和白云。 |
| **烟囱** | 排烟的管子 | 烟囱里冒出袅袅炊烟。 |

### 💡 想象：彩色铅笔 = 彩色的梦
把铅笔比作"彩色的梦"，画面立刻变得生动有趣。
**排比句**："脚尖滑过的地方，大块的草坪，绿了；大朵的野花，红了；大片的天空，蓝了……"

## 9 枫树上的喜鹊

### 📖 课文概要
"我"喜欢站在枫树下看喜鹊窝。喜鹊阿姨教喜鹊弟弟唱歌、做游戏、学拼音。"我"看懂了它们的对话，觉得它们一家人真快乐。

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **喜欢** | 喜爱 | 我喜欢看故事书。 |
| **懂得** | 知道、理解 | 我懂得了妈妈的不容易。 |
| **快乐** | 开心、高兴 | 一家人在一起很快乐。 |
| **拼音** | 字母拼读 | 我们在学拼音。 |
| **阿姨** | 称呼妈妈的姐妹 | 喜鹊阿姨在教宝宝唱歌。 |
| **渡口** | 过河的地方 | 枫树长在渡口边。 |
| **绿荫** | 树荫 | 我们在绿荫下乘凉。 |
| **撑开** | 打开 | 喜鹊阿姨撑开翅膀。 |
| **伞** | 遮雨遮阳的工具 | 枫树的树冠像一把绿色的伞。 |
| **山冈** | 不高的山 | 喜鹊飞过了山冈。 |

### 💡 孩子的观察
"我"把喜鹊当成一家人来写——"喜鹊阿姨""喜鹊弟弟"。给动物加上人的称呼，故事就变温暖了。

### 💡 想象喜鹊的对话
> "鹊！鹊鹊鹊！"——我知道，这便是：喤！鹳鹊鹊鹊！"
> "鹊！鹊！鹊！"——我知道，这便是：啊！鹳鹊！"

**孩子用自己的方式"翻译"鸟语**，多可爱的想象！

## 10 沙滩上的童话

### 📖 课文概要
海边的沙滩上，"我们"垒起城堡，开始编童话——城堡里住着凶狠的魔王，抢走了美丽的公主。勇士们挖地道、炸城堡，救出了公主。公主是谁？就是"我"的妈妈！

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **城堡** | 古代的大房子 | 我们在沙滩上垒了一座城堡。 |
| **凶狠** | 凶恶、狠毒 | 故事里有一个凶狠的魔王。 |
| **补充** | 加上、补足 | 我补充了一句话。 |
| **合力** | 一起用力 | 我们合力把石头搬开了。 |
| **欢呼** | 高兴地呼喊 | 进球了，大家欢呼起来。 |
| **堡垒** | 防守用的建筑 | 城堡的堡垒又高又厚。 |
| **攻打** | 进攻 | 勇士们一起攻打城堡。 |
| **赞赏** | 称赞、表扬 | 老师赞赏我们的想象力。 |
| **凶狠** | 凶恶、狠毒 | 魔王凶狠地瞪着眼睛。 |
| **魔窟** | 魔鬼住的地方 | 勇士们冲进了魔窟。 |

### 💡 你一句我一句编故事
> "这里有一座城堡！"
> "城堡里住着凶狠的魔王！"
> "他抢走了美丽的公主！"

孩子玩的时候**你一句我一句**一起编故事，这就是合作创造。

### 💡 有趣的结尾
公主居然是妈妈！——**把游戏的想象和现实生活连接起来**，特别温馨。

## 11 我是一只小虫子

### 📖 课文概要
当一只小虫子好不好？我的小伙伴都觉得不好——会被苍耳刺到、被狗尿淹到、被小鸟吃掉。但我觉得当小虫子其实挺有意思的：在草叶上伸懒腰、用露珠洗脸、坐免费火车……

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **屁股** | 身体后面 | 我不小心坐到了地上，屁股好疼。 |
| **毛茸茸** | 毛很多的样子 | 小兔子毛茸茸的真可爱。 |
| **摇摇晃晃** | 不稳的样子 | 弟弟摇摇晃晃地走过来。 |
| **免费** | 不用花钱 | 公交车对老人免费。 |
| **撞伤** | 撞到受伤 | 小鸟差点把小虫子撞伤。 |
| **昏头昏脑** | 迷迷糊糊、不清醒 | 转了几圈后我昏头昏脑的。 |
| **特快列车** | 速度很快的火车 | 小虫子把狗毛当特快列车。 |
| **干净** | 没有脏东西 | 洗完脸感觉真干净。 |
| **幸运** | 运气好 | 没有被鸟吃掉，真是幸运。 |
| **伙伴** | 一起玩的人 | 我的小伙伴都很可爱。 |

### 💡 换个角度看世界
当小虫子有不好的地方，但也有好的地方——**换个角度，坏事情也能变成好事**。

### 💡 拟人化
把小虫子当作人来写：伸懒腰、洗脸、坐火车——**让读者觉得小虫子跟小朋友一样可爱**。

## ⚠️ 易错字提醒

| 字 | 易错点 | 记忆口诀 |
|:---|:-------|:---------|
| **游** | 右上是"斿"，不是"放" | 游泳的人在方阵中 |
| **戏** | 右边是"戈"不是"找" | 游戏用戈不用找 |
| **幸** | 上面是"土"不是"士" | 幸运的土里有羊 |
| **梦** | 下面是"夕"不是"歹" | 晚上做梦到夕阳 |
| **喜** | 上面是"士"不是"土" | 喜欢的人士，不是土 |

## ✍️ 写话：写一段通顺的话

### 🎯 目标
选一个话题，写一段话，做到句子通顺、前后连贯。

### 📐 写作框架
1. **第一句**：告诉大家你要写什么（中心句）
2. **第二三句**：写具体的内容
3. **最后一句**：写自己的感受

### 🧩 话题词语宝库

**假如我有一盒彩色铅笔**
| 要画的 | 可以用的词 |
|:-------|:-----------|
| 草坪 | 绿油油、软绵绵、一望无际 |
| 天空 | 蓝湛湛、飘着白云、瓦蓝瓦蓝 |
| 花朵 | 红艳艳、五颜六色、绚丽多彩 |
| 太阳 | 金灿灿、暖洋洋、光芒万丈 |

**假如我是一只小虫子**
| 要写的 | 可以用的词 |
|:-------|:-----------|
| 起床 | 伸懒腰、打哈欠、用露珠洗脸 |
| 吃饭 | 吸花蜜、啃树叶、吮果汁 |
| 旅行 | 免费火车、树叶小船、毛毛虫巴士 |
| 危险 | 小心鸟、躲开雨、别踩到我 |

### 📝 示例
> 当一只小虫子真有趣。早上起来，可以在草叶上伸懒腰。用一颗露珠就能把脸洗干净，比我们用毛巾还方便。要是想出去旅行，跳到狗身上就可以出发了，不用买票呢！

### 📝 进阶示例（想象写话）
> 假如我有一盒彩色的铅笔，我要画出彩色的梦。脚尖滑过的地方，一大片草坪绿了，像铺上了绿地毯；大朵的野花红了，像小姑娘的脸蛋；大块的天空蓝了，蓝得像大海。我还要画一间小木屋，烟囱里飘出彩色的炊烟——就像我彩色的梦。

### ⚠️ 小提示
1. ✅ 句子要完整，谁 + 做什么
2. ✅ 注意标点：逗号、句号、感叹号
3. ✅ 前后顺序不乱



### 💡 写话小锦囊

#### 1. 从课文里学方法
从"枫树上的喜鹊""沙滩上的童话"学围绕一个意思写一段话——写出自己的想象。
> 我多想有一双翅膀啊！我要飞到云朵上，和小鸟做邻居，和太阳做朋友。

#### 2. 想好了再写
提笔之前先想一想：
- 我要写什么？（是写一个人、一件事，还是一处风景？）
- 用哪几个词或句式来写？（从课文里学到的）
- 先写什么，再写什么？（想好顺序再动笔）

想清楚了再写，写的时候就不慌了。

#### 3. 写真的，写自己的
写你真正看到、听到、想到的。不用编，不用抄。
- 写自己的事——哪怕是一件很小的事
- 写自己的话——用你自己会说的词
- 写真实的感受——开心就写开心，难过就写难过

> 作文不是为了写给别人看，而是为了记下自己的故事。
