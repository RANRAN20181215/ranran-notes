# 第二单元 · 关爱

> 雷锋叔叔在哪里？千人糕是怎么来的？一匹出色的马是什么？——这些故事里，藏着人与人之间的关爱。
> **阅读重点**：读句子，想画面
> **写话目标**：写清楚一件简单的事

---

## 5 雷锋叔叔，你在哪里

### 📖 课文概要
我们沿着长长的小溪、弯弯的小路寻找雷锋叔叔。他在小溪边抱着迷路的孩子，在雨路上背着年迈的大娘——雷锋叔叔走到哪里，好事就做到哪里。

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **泥泞** | 因有烂泥而不好走 | 雨后的小路很泥泞。 |
| **年迈** | 年纪很大 | 一位年迈的老奶奶在过马路。 |
| **荆棘** | 带刺的植物 | 小路两旁长满了荆棘。 |
| **晶莹** | 光亮而透明 | 草叶上挂着晶莹的露珠。 |
| **寻觅** | 寻找 | 我在书架前寻觅那本书。 |
| **迷路** | 找不到路 | 弟弟在商场里迷路了。 |
| **顺着** | 沿着 | 顺着这条小河走就能到家。 |
| **足迹** | 走过的脚印 | 沙滩上留下了一串足迹。 |
| **温暖** | 暖和、暖心 | 雷锋叔叔的故事让人温暖。 |
| **奉献** | 不求回报地付出 | 我们要学习雷锋的奉献精神。 |

### 💡 反复的写法
"雷锋叔叔，你在哪里，你在哪里？"——反复问，表达寻找的急切。
"沿着……顺着……"——句式相同，读起来像在跟着一起找。

### 💡 雷锋精神
**助人为乐**——哪里需要帮助，雷锋就出现在哪里。雷锋已经离开了我们，但他的精神一直留在人们心里。

## 6 千人糕

### 📖 课文概要
爸爸告诉孩子：一块普通的米糕，要经过很多人的劳动才能到我们手里——种稻子需要农具、化肥，用铁锅蒸需要钢铁……一块米糕是"千人糕"。

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **特别** | 不一般、非常 | 这本书特别好看。 |
| **平时** | 平常的时候 | 我平时都是七点起床。 |
| **确实** | 的确、真的 | 这蛋糕确实很好吃。 |
| **应该** | 理所当然 | 我们应该珍惜粮食。 |
| **劳动** | 干活、做事 | 劳动最光荣。 |
| **米糕** | 用大米做的糕点 | 奶奶做的米糕又甜又软。 |
| **需要** | 一定要有 | 植物需要阳光和水。 |
| **经过** | 通过、经历 | 米糕要经过很多道工序。 |
| **加工** | 把原材料做成成品 | 农民把稻谷加工成大米。 |
| **农具** | 种田用的工具 | 爷爷的农具房里放着锄头。 |

### 💡 珍惜劳动成果
一块小小的米糕，背后有农民种稻、工人做工具、司机运输、售货员卖货……每一个环节都离不开别人的劳动。**我们吃到的每一口食物，都来之不易。**

### 💡 说话有条理
爸爸从"米"开始，一步步往前推——大米怎么来的？稻子怎么种的？工具哪里来的？**一步一步讲清楚**，这就是"有条理"。

## 7 一匹出色的马

### 📖 课文概要
全家人去散步，妹妹走累了要妈妈抱。爸爸捡起一根柳枝说："这是一匹出色的马，你骑着回家吧！"妹妹骑着"马"，高兴地跑回了家。

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **出色** | 特别好、出众 | 他这次考试表现得非常出色。 |
| **波纹** | 水面上的细波 | 湖面上泛起了层层波纹。 |
| **景色** | 风景 | 春天的景色真美。 |
| **恋恋不舍** | 舍不得离开 | 我在游乐场玩得恋恋不舍。 |
| **求** | 请求、要求 | 妹妹哭着求妈妈抱她。 |
| **散步** | 慢慢走路 | 晚饭后我们去公园散步。 |
| **异常** | 很、非常 | 今天的天气异常暖和。 |
| **柔软** | 软和、不硬 | 小草的叶子很柔软。 |
| **拾起** | 捡起来 | 爸爸从地上拾起一根柳枝。 |
| **蹦蹦跳跳** | 又蹦又跳 | 小兔子蹦蹦跳跳真可爱。 |

### 💡 爸爸的智慧
妹妹走不动了，爸爸没有抱她，而是用一根柳枝当"马"——**用想象和游戏代替懒惰**，让妹妹自己走回家。这是聪明的爱。

### 💡 对比
- 去的时候：妹妹很兴奋，蹦蹦跳跳
- 回来的时候：妹妹累了，要妈妈抱
- 爸爸给了"马"之后：妹妹又高兴了，跑回家

## ⚠️ 易错字提醒

| 字 | 易错点 | 记忆口诀 |
|:---|:-------|:---------|
| **冒** | 上面是"冖"，不是"日" | 冒字头上不是日，盖顶下面藏眼睛 |
| **暖** | 左边是"日"，右边不是"爱" | 日出才温暖，日字旁不能丢 |
| **满** | 右下是"从"不是"两" | 满满的从草堆 |
| **糕** | 左边是"米"，右上是"羊" | 米做的糕点，羊字头 |
| **像** | 右边有"象"不是"向" | 人像大象一样高大 |

## ✍️ 写话：写清楚一件简单的事

### 🎯 目标
用几句话写一件小事，把谁、什么时候、在哪里、做了什么写清楚。

### 📐 写作框架
1. **什么时候**（时间）
2. **谁**（人物）
3. **在哪里**（地点）
4. **做什么**（事情经过）
5. **结果或感受**

### 🧩 词语小宝库
| 类别 | 词语 |
|:-----|:-----|
| 时间词 | 星期天、昨天、放学后、一天 |
| 人物 | 我、妈妈、爸爸、同学、爷爷 |
| 地点 | 学校、超市、公园、家里、路边 |
| 动作 | 帮忙、扶起、捡到、送给、分享 |
| 感受 | 开心、温暖、自豪、高兴、感动 |

### 📝 示例
> 星期天，我和妈妈去超市买菜。超市里人很多，妈妈在后面挑菜。我看到一个老奶奶够不到上面的酱油，就帮她拿了下来。老奶奶笑着说："谢谢你，小朋友！"我心里可开心了！

### 📝 进阶示例（用上更多好词）
> 放学后，我和小明在操场上玩。忽然，我们看到一位一年级的小同学摔倒了，正坐在地上哭。我们赶紧跑过去，把他扶起来，帮他拍掉身上的土。小同学破涕为笑，说："谢谢哥哥！"我和小明虽然累了一身汗，但心里暖暖的。

### ⚠️ 小提示
1. ✅ 写清楚"谁、什么时候、在哪里、做什么"
2. ✅ 可以写帮助别人，也可以写别人帮助你
3. ✅ 加上一句话写自己的感受



### 💡 写话小锦囊

#### 1. 从课文里学方法
从"雷锋叔叔你在哪里""千人糕"学写清楚一件事——谁做了什么，结果怎样，按顺序写。
> 今天我的铅笔掉地上了，同桌帮我捡起来。我说"谢谢"，她笑了。

#### 2. 想好了再写
提笔之前先想一想：
- 我要写什么？（是写一个人、一件事，还是一处风景？）
- 用哪几个词或句式来写？（从课文里学到的）
- 先写什么，再写什么？（想好顺序再动笔）

想清楚了再写，写的时候就不慌了。

#### 3. 写真的，写自己的
写你真正看到、听到、想到的。不用编，不用抄。
- 写自己的事——哪怕是一件很小的事
- 写自己的话——用你自己会说的词
- 写真实的感受——开心就写开心，难过就写难过

> 作文不是为了写给别人看，而是为了记下自己的故事。
