# 第六单元 · 大自然的秘密

> 夏天的西湖、雷雨前后、野外迷路怎么办、太空生活什么样——大自然藏着好多秘密！
> **阅读重点**：提取主要信息
> **写话目标**：用表示时间顺序的词写

## 15 古诗二首

### 晓出净慈寺送林子方 · [宋] 杨万里

> 毕竟西湖六月中，风光不与四时同。
> 接天莲叶无穷碧，映日荷花别样红。

**📜 背景**：杨万里在杭州做官时，好朋友林子方要去福建赴任。天还没亮，杨万里就赶到西湖边的净慈寺为林子方送行。两人走出寺门，晨光正好洒在西湖上——满湖的荷叶一直铺到天边，碧绿碧绿的；初升的太阳照在荷花上，红得格外耀眼。杨万里被这美景惊住了，拉着朋友说："你看这荷花，到了福建可就看不到了！"

**🔑 注释**
- 晓出：清晨走出
- 净慈寺：杭州西湖边的寺庙
- 毕竟：到底、终究
- 四时：春夏秋冬四季
- 别样红：格外红、特别红

**💡** "接天莲叶无穷碧"——荷叶一直铺到天边，一片碧绿。"映日荷花别样红"——阳光下的荷花红得格外鲜艳。**一碧一红，色彩对比强烈**。

### 🎭 走进诗人

**逸事**：杨万里一生写了四千多首诗，但最为人称道的还是那些描写风景的小诗。他有个"怪癖"——写诗的时候不许任何人打扰。有一天他在书房构思，家人喊他吃饭喊了好几遍也不出来。家人推门一看，发现他坐在桌前，桌上放着一枝从院子里折来的荷花——原来他在对着荷花找灵感呢！

**时代印记**：南宋时期，杭州（临安）是国家的首都，西湖更是文人墨客的聚集地。六月的西湖荷花远近闻名，每年夏天都有无数人前来观赏。杨万里在送别的清晨看到这一池荷花，用"无穷碧"和"别样红"六个字，把西湖六月的美写到了极致——至今无人超越。

### 绝句 · [唐] 杜甫

> 两个黄鹂鸣翠柳，一行白鹭上青天。
> 窗含西岭千秋雪，门泊东吴万里船。

**📜 背景**：经历了八年安史之乱的颠沛流离后，杜甫终于在成都盖了一间草堂安顿下来。一个春天的早晨，他坐在窗前——两只黄鹂在翠绿的柳枝间唱歌、一行白鹭飞上了蓝蓝的天、远处西山上还盖着千年不化的雪、门口停着从万里之外来的船。他忽然觉得：战争终于过去了，生活又恢复了平静和美好。这一瞬间的感动，让他写下了这首诗。

**🔑 注释**
- 鸣：叫
- 白鹭：白色水鸟
- 含：包含、含着
- 西岭：西边的山
- 东吴：江南一带

**💡** 四个画面：黄鹂 + 翠柳（近处），白鹭 + 青天（远处），窗含雪（静态），门泊船（动态）。**一幅画里有远有近、有动有静。**

### 🎭 走进诗人

**逸事**：杜甫被称为"诗圣"，但很少有人知道他是一个超级"细节控"。他写诗要求每一个字都精确——"两个黄鹂"就不能写"几只黄鹂"，因为坐在窗前看出去，正好就看到了两只；"一行白鹭"也不能写"一群"，因为他看到的白鹭排成了一行。正是这种对细节的极致追求，让他的诗像一幅画一样清晰。

**时代印记**：杜甫写这首诗的时候，长达八年的安史之乱刚刚结束。唐朝从最辉煌的顶峰跌下来，国家满目疮痍。但春天还是来了，鸟儿还在唱歌，船还可以自由航行。杜甫把这种"劫后余生"的平静写进了诗里——越平静，越珍贵。

### 🌿 古诗重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **毕竟** | 到底、终究 | 毕竟还是春天暖和。 |
| **无穷** | 没有尽头 | 天空中有无穷无尽的星星。 |
| **别样** | 特别、不一样 | 春天的花开得别样美。 |
| **鸣** | 叫 | 小鸟在枝头鸣叫。 |
| **含** | 包含、含着 | 窗含远处的山。 |
| **泊** | 停船 | 船泊在岸边。 |
| **千秋** | 千年 | 千年不化的雪。 |
| **翠** | 翠绿色 | 柳树长出了翠绿的叶子。 |

## 16 雷雨

### 📖 课文概要
雷雨前：满天乌云、树叶不动、蝉不叫、大风、蜘蛛逃走、闪电雷声。雷雨中：哗哗哗下起来了，窗外什么都看不清。雷雨后：天亮了、彩虹出来、蝉叫了、蜘蛛又坐在网上、池塘水满了。

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **黑沉沉** | 颜色很黑、很低 | 天黑沉沉的，要下雨了。 |
| **垂下来** | 向下挂 | 柳枝垂到了水面上。 |
| **越来越亮** | 越来越亮 | 闪电越来越亮，雷声越来越响。 |
| **清新** | 清爽新鲜 | 雨后的空气真清新。 |
| **迎面扑来** | 对着脸吹过来 | 一阵花香迎面扑来。 |
| **乌云** | 黑色的云 | 乌云遮住了太阳。 |
| **闪电** | 云层间的强烈放电 | 一道闪电划破天空。 |
| **雷声** | 打雷的声音 | 轰隆隆的雷声震耳欲聋。 |
| **彩虹** | 雨后天空出现的彩色弧 | 雨停了，天边挂着一道彩虹。 |
| **池塘** | 蓄水的坑 | 池塘里的水满了。 |

### 💡 时间顺序
**雷雨前 → 雷雨中 → 雷雨后** ——按时间顺序写得清清楚楚。

### 💡 提取信息：雷雨前的变化
| 什么 | 怎么了 |
|:----|:-------|
| 乌云 | 黑沉沉地压下来 |
| 树叶 | 一动不动 |
| 蝉 | 一声也不叫 |
| 风 | 忽然刮起来 |
| 蜘蛛 | 从网上逃走了 |

## 17 要是你在野外迷了路

### 📖 课文概要
要是你在野外迷了路，别慌张——大自然有很多天然的指南针：太阳中午在南边，树影指北方；北极星永远挂在北方；大树南边枝叶稠、北边枝叶稀；沟渠里的积雪化得快的是北边……

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **慌张** | 紧张、着急 | 遇到事情不要慌张。 |
| **指南针** | 指示方向的工具 | 指南针永远指向南方。 |
| **分辨** | 辨认、分清 | 我能分辨东南西北。 |
| **忠实** | 忠诚、可靠 | 狗是人类忠实的朋友。 |
| **向导** | 带路的人 | 大自然是我们的向导。 |
| **野外** | 郊外、野外 | 我们在野外露营。 |
| **天然** | 自然存在的、不是人工的 | 这些都是天然的指南针。 |
| **枝叶** | 树枝和叶子 | 大树的枝叶很茂密。 |
| **稠** | 多而密 | 南边的枝叶很稠。 |
| **稀** | 少而疏 | 北边的枝叶很稀。 |

### 💡 提取信息：天然的指南针
| 什么时候 | 用什么 | 怎么看 |
|:---------|:------|:-------|
| 白天 | 太阳 | 中午在南边，树影指北 |
| 晚上 | 北极星 | 永远在北方 |
| 阴雨天 | 大树 | 南面枝叶稠，北面稀 |
| 雪后天晴 | 沟渠积雪 | 化得快的是北边 |

## 18 太空生活趣事多

### 📖 课文概要
在太空中生活真有趣！睡觉要绑在睡袋里，喝水要用吸管，走路要穿带钩子的鞋，洗澡要用特殊的淋浴器——因为在太空里，东西都会飘起来。

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:-----|:-----|:-----|
| **宇宙** | 天地万物 | 宇宙很大，有很多星星。 |
| **航天员** | 在太空工作的人 | 航天员在太空站工作。 |
| **漂浮** | 浮在水面或空中 | 树叶在水面上漂浮。 |
| **吸管** | 吸饮料的管 | 我用吸管喝酸奶。 |
| **特殊** | 特别的、不一般的 | 航天员有特殊的训练。 |
| **安稳** | 稳定、不动 | 在地球上睡觉很安稳。 |
| **普通** | 一般的、平常的 | 在太空里不能像在地球上一样普通的走路。 |
| **引力** | 把物体拉向地面的力 | 地球有引力，所以东西不会飘。 |
| **淋浴** | 站着冲水洗澡 | 太空里有特殊的淋浴器。 |
| **有趣** | 有意思、好玩 | 太空生活真有趣！ |

### 💡 提取信息：太空和地球不一样
| 做什么 | 地球上 | 太空里 |
|:------|:-------|:--------|
| 睡觉 | 躺在床上 | 绑在睡袋里 |
| 喝水 | 用杯子 | 用吸管挤 |
| 走路 | 普通走 | 穿钩子鞋 |
| 洗澡 | 淋浴 | 特殊淋浴器 |

**原因**：太空里没有引力，东西会飘起来。

## ✍️ 写话：用表示时间顺序的词写

### 🎯 目标
用"先……接着……然后……最后……"或"……前……中……后……"写一段话。

### 📐 写作框架
1. **开头**：告诉大家你要写什么
2. **中间**：按顺序写出变化
3. **结尾**：结果或感受

### 🧩 时间顺序词
| 阶段 | 词语 |
|:----|:-----|
| 开始 | 一开始、先 |
| 中间 | 接着、然后、后来 |
| 高潮 | 这时候、渐渐地 |
| 结束 | 最后、终于 |

### 🧩 主题词语宝库

**写雷雨**
| 阶段 | 可以用的词 |
|:-----|:-----------|
| 雨前 | 乌云密布、黑沉沉、闷热、一动不动、闪电、雷声 |
| 雨中 | 哗哗哗、豆大的雨点、看不清、噼里啪啦 |
| 雨后 | 彩虹、清新、太阳出来了、积水、空气 |

**写自然现象（如日出、月食等）**
| 阶段 | 可以用的词 |
|:-----|:-----------|
| 开始前 | 黑漆漆、安静、期待 |
| 变化中 | 渐渐、慢慢地、越来越亮、一点一点 |
| 完全出现 | 金光闪闪、耀眼、美丽极了 |

### 📝 示例
> 下雨前，天空乌云密布，树叶一动不动。接着，大风呼呼地刮起来了。然后，哗啦啦——豆大的雨点落了下来。渐渐地，雨小了。最后，雨停了，天边出现了一道彩虹。

### 📝 进阶示例
> 傍晚，天空还是蓝蓝的。忽然，一阵大风刮了起来，树叶被吹得哗哗响。接着，黑沉沉的乌云从天边压过来，把天空遮得严严实实的。一道闪电划过，轰隆隆的雷声紧跟着响起来了。哗——大雨像倒水一样落了下来。渐渐地，雷声小了，雨也小了。最后，雨停了，太阳重新露出了笑脸，天边挂着一道美丽的彩虹。雨后的空气格外清新！



### 💡 写话小锦囊

#### 1. 从课文里学方法
从"雷雨""要是你在野外迷了路"学用"先……然后……最后……"写一段话。
> 回家的路上，**先**看到天黑了，**然后**下起了大雨，**最后**雨停了，天边出现了一道彩虹。

#### 2. 想好了再写
提笔之前先想一想：
- 我要写什么？（是写一个人、一件事，还是一处风景？）
- 用哪几个词或句式来写？（从课文里学到的）
- 先写什么，再写什么？（想好顺序再动笔）

想清楚了再写，写的时候就不慌了。

#### 3. 写真的，写自己的
写你真正看到、听到、想到的。不用编，不用抄。
- 写自己的事——哪怕是一件很小的事
- 写自己的话——用你自己会说的词
- 写真实的感受——开心就写开心，难过就写难过

> 作文不是为了写给别人看，而是为了记下自己的故事。
