## 1 曹冲称象

### 📖 课文概要
古时候有人送了一头大象给曹操，大家想知道大象有多重。官员们说造大秤、砍大树做秤杆，曹操都不满意。七岁的曹冲说：把大象赶到船上画线，换成石头一块块称。大家都夸曹冲聪明。

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:----|:-----|:-----|
| **柱子** | 房屋或船上的支柱 | 大象的腿像四根柱子。 |
| **到底** | 究竟、最终 | 大家想知道大象到底有多重。 |
| **秤杆** | 称东西的杆子 | 哪有这么大的秤杆呢？ |
| **果然** | 真的、确实 | 曹冲的办法果然行得通。 |
| **议论** | 大家一起讨论 | 官员们一边看一边议论。 |
| **重量** | 有多重 | 大象的重量谁也不知道。 |
| **砍倒** | 用刀斧把树砍断 | 有人建议砍一棵大树做秤杆。 |
| **船舷** | 船的两侧边沿 | 曹冲在船舷上画了一条线。 |
| **下沉** | 往下沉 | 大象上了船，船身就下沉。 |
| **石头** | 石块的统称 | 往船上装石头，装到画线的地方。 |
| **称赞** | 表扬、夸奖 | 曹操听了曹冲的办法，连连称赞。 |
| **聪明** | 智力高、理解力强 | 曹冲是个聪明的孩子。 |

### 💡 曹冲的办法
1. 大象**赶**上船→船身**沉**→沿着水面**画**线
2. 大象**赶**下船→往船上**装**石头→**装**到线齐
3. 石头**称**一称→加起来就是大象的重量

**用船代替大秤——换一种思路！**

### ⚠️ 易错字提醒
| 字 | 易错点 | 记忆口诀 |
|:---|:-------|:---------|
| **底** | 下面有一点，不是"广"+"氏" | 广+氏+点=到底 |
| **秤** | 左边是"禾"，右边是"平" | 禾苗用天平=秤 |
| **船** | 右边是"㕣"，不是"几"+"口" | 舟+"㕣"=船 |
| **然** | 左上是"犬"，不是"大" | 犬+灬=果然 |
| **量** | 中间是"曰"，不是"日" | 日（曰）+一+里=重量 |

### 🔍 形近字辨析
| 字 | 组词 | 易混字 | 组词 | 区分方法 |
|:---|:-----|:-------|:-----|:---------|
| **柱** | 柱子 | **住** | 住下 | 木字旁是柱子，单人旁是居住 |
| **秤** | 秤杆 | **称** | 称赞 | 左边禾是秤，左边禾+尔=称 |
| **底** | 到底 | **低** | 高低 | 有点是底，单人旁是低 |
| **议** | 议论 | **蚁** | 蚂蚁 | 言字旁是议论，虫字旁是蚂蚁 |

### 🎵 多音字总结
| 字 | 读音 | 组词 | 读音 | 组词 |
|:---|:-----|:-----|:-----|:-----|
| **杆** | gān | 旗杆 | gǎn | 秤杆、笔杆 |
| **重** | zhòng | 重量 | chóng | 重新、重复 |
| **称** | chēng | 称赞 | chèng | 秤（同"秤"） |
| **得** | de | 跑得快 | dé | 得到 | děi | 得努力 |

### 🧩 偏旁归类
| 偏旁 | 字 | 说明 |
|:-----|:---|:-----|
| **舟**（舟字旁） | 船、舱、艘、舷 | 都和船有关 |
| **禾**（禾字旁） | 秤、称、科、程 | 都和谷物、度量有关 |
| **木**（木字旁） | 柱、杆、树、根 | 都和树木有关 |
| **亻**（单人旁） | 做、伯、仔、们 | 都和人有关 |

### 📝 词语采蜜集

**四字词语**
- 又高又大、一边……一边……、果然不出所料

**近义词**
- 到底—究竟、议论—讨论、称赞—夸奖、聪明—智慧

**反义词**
- 重—轻、沉—浮、高—矮、大—小、满意—不满

## 2 玲玲的画

### 📖 课文概要
玲玲画了一幅《我家的一角》准备参加评奖，不小心弄脏了画。她急得哭了。爸爸拿起笔，在脏的地方画了一只小狗。玲玲高兴了——弄巧成拙变成了画龙点睛。

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:----|:-----|:-----|
| **评奖** | 评选奖励 | 玲玲的画要去参加评奖。 |
| **弄脏** | 搞脏了 | 玲玲不小心把画弄脏了。 |
| **伤心** | 难过 | 看到画脏了，玲玲很伤心。 |
| **仔细** | 认真细心 | 爸爸仔细看了看画。 |
| **满意** | 符合心意 | 玲玲满意地笑了。 |
| **参加** | 加入 | 玲玲的画要参加比赛。 |
| **糟糕** | 坏了、不好了 | 糟糕，画上多了一个墨点！ |
| **懒洋洋** | 没精神的样子 | 爸爸懒洋洋地坐在沙发上。 |
| **脑筋** | 思考的能力 | 只要肯动脑筋，坏事也能变好事。 |
| **坏事** | 不好的事 | 弄脏画是坏事，但也能变好事。 |
| **好事** | 好的事 | 爸爸画了小狗，坏事变好事。 |
| **端详** | 仔细地看 | 爸爸端详着玲玲的画。 |

### ⚠️ 易错字提醒
| 字 | 易错点 | 记忆口诀 |
|:---|:-------|:---------|
| **拿** | 上面是"合"，下面是"手" | 合+手=拿（手合起来拿东西） |
| **奖** | 右上是"夕"，不是"刀" | "丬"+"夕"+"大"=奖状 |
| **脏** | 右边是"庄"，不是"压" | 月字旁+"庄"=弄脏 |
| **筋** | 上面是"⺮"，下面是"肋" | 竹字头+"肋"=脑筋 |

### 🔍 形近字辨析
| 字 | 组词 | 易混字 | 组词 | 区分方法 |
|:---|:-----|:-------|:-----|:---------|
| **画** | 图画 | **花** | 花朵 | 田+凵=画，艹+化=花 |
| **奖** | 评奖 | **奖** | 划桨 | 大+夕=奖，木+奖=桨 |
| **报** | 报名 | **抱** | 拥抱 | 扌+卩+又=报，扌+包=抱 |
| **懒** | 懒洋洋 | **嫩** | 娇嫩 | 竖心旁+赖=懒，女+敕=嫩 |

### 🎵 多音字总结
| 字 | 读音 | 组词 | 读音 | 组词 |
|:---|:-----|:-----|:-----|:-----|

| **参** | cān | 参加 | shēn | 人参 |
| **教** | jiào | 教室 | jiāo | 教书 |
| **骨** | gǔ | 骨头 | gū | 骨碌 |

### 🧩 偏旁归类
| 偏旁 | 字 | 说明 |
|:-----|:---|:-----|
| **氵**（三点水） | 洋、污、泪、涂 | 都和水有关 |

### 📝 词语采蜜集

**四字词语**

## 3 一封信

### 📖 课文概要
露西给在国外出差的爸爸写信。第一次写得很伤心：没人陪、台灯坏了……妈妈告诉她要多写开心的事。第二次写信写得很开心：小狗很好玩、台灯修好了、太阳出来了。

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:----|:-----|:-----|
| **今天** | 这一天 | 今天露西想给爸爸写信。 |
| **写信** | 写书信 | 露西在桌上认真地写信。 |
| **出国** | 到国外 | 爸爸出国了，要很久才回来。 |
| **台灯** | 桌上的灯 | 台灯坏了，房间很暗。 |
| **开心** | 高兴 | 露西写了第二封信，她很开心。 |
| **怀抱** | 抱在怀里 | 爸爸把孩子抱在怀里。 |
| **修理** | 把坏的东西修好 | 妈妈找人修理了台灯。 |
| **陪伴** | 陪着一起 | 有小狗陪伴，露西不孤单。 |
| **难过** | 伤心、不好受 | 第一封信写得很难过。 |
| **明亮** | 光线充足 | 太阳出来了，房间真明亮。 |
| **冷清** | 冷静、不热闹 | 爸爸不在家，家里很冷清。 |
| **团圆** | 亲人聚在一起 | 等到爸爸回家，我们就团圆了。 |

### 💡 对比阅读
| 第一封信 | 第二封信 |

| "没人陪我" | "小狗在叫" |
| "台灯坏了" | "台灯修好了" |
| ——伤心 | ——开心 |

同一件事，换个角度想，心情就不一样了。

## 4 妈妈睡了

### 📖 课文概要
妈妈睡了，孩子仔细看着睡梦中的妈妈：妈妈的眼睛闭上了，嘴巴微微笑着，头发粘在额头上。妈妈是那么美丽、温柔。孩子发现——妈妈太累了，她睡着了。

## ✍️ 写话：写几句完整的话

### 🎯 目标
围绕一个意思写3-5句完整的话，做到通顺、连贯。

### 📐 小提示
1. 先想好写什么（一件小事、一个人、一个场景）
2. 第一句话点明要写什么
3. 后面几句话把"经过""样子""心情"写清楚

### 🏪 词语小宝库

**描写人物的词语**
| 类别 | 词语 |
|:-----|:-----|
| 外貌 | 弯弯的眉毛、红润的脸、明亮的眼睛、乌黑的头发 |
| 性格 | 温柔、善良、耐心、慈祥、勤劳 |
| 心情 | 开心、难过、着急、紧张、得意、委屈、兴奋 |

**动作词**
| 类别 | 词语 |
|:-----|:-----|
| 手的动作 | 捧、端、拿、扫、洗、擦、叠 |
| 日常家务 | 扫地、洗碗、擦桌、洗菜、倒垃圾、整理 |

### 📝 示例

> 今天妈妈下班回来很累。我给她倒了一杯水。妈妈笑了，摸着我的头说："你长大了。"我心里很高兴。

> 我的妈妈很温柔。她有一头乌黑的长发，脸上总是笑眯眯的。每天放学回家，妈妈都会问我："今天在学校开心吗？"我爱我的妈妈。

> 星期天，我帮妈妈做家务。我先扫地，把每个角落都扫得干干净净。然后擦桌子，把桌子擦得亮亮的。妈妈夸我是好孩子，我心里比吃了蜜还甜。

### 🏪 词语小宝库（写话用）

**描写家人的词语**
| 人物 | 可以用这些词 |
|:-----|:------------|
| 妈妈 | 美丽、温柔、勤劳、关心、照顾、拥抱、微笑、香喷喷的饭菜 |
| 爸爸 | 高大、认真、忙碌、有力、严格、温暖、宽厚的肩膀 |
| 自己 | 快乐、认真、努力、进步、帮助、成长 |

**常用句式**
- "……一边……一边……"：妈妈一边听音乐一边做饭。
- "……又……又……"：我又高兴又激动。
- "……像……"：妈妈的笑脸像一朵花。

### ⚠️ 注意
- 写真实的事，不说假话
- 写完读一遍，看看通不通顺
- 不会写的字先空着，写完了查字典



### 💡 写话小锦囊

#### 1. 从课文里学方法
从"妈妈睡了"学写几句完整的话——围绕一个意思，写3-5句通顺的话。
> 我的妈妈很温柔。她有一头乌黑的长发，脸上总是笑眯眯的。我爱我的妈妈。

#### 2. 想好了再写
提笔之前先想一想：
- 我要写什么？（是写一个人、一件事，还是一处风景？）
- 用哪几个词或句式来写？（从课文里学到的）
- 先写什么，再写什么？（想好顺序再动笔）

想清楚了再写，写的时候就不慌了。

#### 3. 写真的，写自己的
写你真正看到、听到、想到的。不用编，不用抄。
- 写自己的事——哪怕是一件很小的事
- 写自己的话——用你自己会说的词
- 写真实的感受——开心就写开心，难过就写难过

> 作文不是为了写给别人看，而是为了记下自己的故事。
