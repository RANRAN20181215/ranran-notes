# 第一单元 · 大自然的秘密

> 小蝌蚪怎样找妈妈？"我"到底是什么？植物妈妈又有哪些办法？
> **阅读重点**：积累并运用表示动作的词
> **写话目标**：用表示动作的词写几句话

## 1 小蝌蚪找妈妈

### 📖 课文概要
小蝌蚪甩着长长的尾巴，在池塘里游来游去。它们先长出后腿，再长出前腿，尾巴慢慢变短，最后变成青蛙。一路上问鲤鱼、问乌龟，终于找到了自己的青蛙妈妈。

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:----|:-----|:-----|
| **脑袋** | 头 | 小蝌蚪大大的脑袋，黑灰色的身子。 |
| **口袋** | 用布做的装东西的袋子 | 妈妈的口袋里装着糖果。 |
| **带领** | 在前面带路 | 老师带领我们去春游。 |
| **宽嘴巴** | 又大又宽的嘴 | 青蛙长着宽嘴巴，专吃害虫。 |
| **快活** | 快乐、高兴 | 小蝌蚪在池塘里快活地游来游去。 |
| **捕食** | 捕捉食物 | 青蛙在田里捕食害虫。 |
| **鼓着** | 凸起、鼓起 | 青蛙鼓着大眼睛，蹲在荷叶上。 |
| **迎上去** | 朝对方走去 | 小蝌蚪看见妈妈，连忙迎上去。 |
| **追上去** | 从后面赶上去 | 乌龟游走了，小蝌蚪赶紧追上去。 |
| **已经** | 表示事情完成了 | 小蝌蚪已经长出了后腿。 |
| **尾巴** | 动物身体末端 | 小蝌蚪的尾巴慢慢变短了。 |
| **连忙** | 赶快、急忙 | 小蝌蚪连忙叫："妈妈！妈妈！" |

### 💡 动作词积累
> "他们看见鲤鱼妈妈在教小鲤鱼**捕**食。"
> "小蝌蚪**游**过去，**追**上去，**叫**着：'妈妈，妈妈！'"

**甩、游、追、叫、蹬、跳**——用一连串动词写出小蝌蚪找妈妈的急切。

### ⚠️ 易错字提醒
| 字 | 易错点 | 记忆口诀 |
|:---|:-------|:---------|
| **脑** | 左边月字旁，右边不要写成"凶" | 月字旁+"凶"少一撇 |
| **袋** | 上面是"代"，不是"伐" | 衣服（衣）里装"代" |
| **宽** | 下面是"见"，不是"贝" | 帽子（宀）下"见"得宽 |
| **顶** | 右边是"页"，不是"贝" | "丁"到"页"上去就是顶 |

### 🔍 形近字辨析
| 字 | 组词 | 易混字 | 组词 | 区分方法 |
|:---|:-----|:-------|:-----|:---------|
| **睛** | 眼睛 | **晴** | 晴天 | 有目才是眼睛，有日才出晴天 |
| **哪** | 哪里 | **那** | 那边 | 有口才能问"哪"，没口就是"那" |
| **肚** | 肚子 | **吐** | 吐气 | 月字旁是身体，口字旁是嘴巴 |
| **孩** | 孩子 | **该** | 应该 | 子字旁是小孩，言字旁是该说 |

### 🎵 多音字总结
| 字 | 读音 | 组词 | 读音 | 组词 |
|:---|:-----|:-----|:-----|:-----|
| **教** | jiāo | 教书 | jiào | 教室、教育 |

| **只** | zhǐ | 只有 | zhī | 一只青蛙 |

### 🧩 偏旁归类
| 偏旁 | 字 | 说明 |
|:-----|:---|:-----|
| **月**（月字旁） | 脑、肚、脸、腿、脚 | 都和身体部位有关 |
| **目**（目字旁） | 眼、睛、睡、睁 | 都和眼睛有关 |
| **辶**（走之底） | 追、送、过、远 | 都和行走有关 |
| **足**（足字旁） | 跳、蹬、跑、路 | 都和脚的动作有关 |

### 📝 词语采蜜集

**四字词语**
- 游来游去、大摇大摆

**近义词**
- 快活—快乐、高兴—开心、连忙—急忙

**反义词**
- 快—慢、大—小、长—短、宽—窄、黑—白

## 2 我是什么

### 📖 课文概要
"我"会变：太阳一晒变成汽，升到天空变成云；冷风一吹变成雨、冰雹或雪。"我"温和时灌溉田地，暴躁时淹没庄稼。猜猜"我"是什么？（答案：水）

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:----|:-----|:-----|
| **飘浮** | 轻飘飘地浮在空中 | 白云在天空中飘浮。 |
| **冰雹** | 从天上落下来的冰块 | 夏天有时会下冰雹。 |
| **温和** | 温暖平和 | 水有时很温和，有时很暴躁。 |
| **暴躁** | 急躁、控制不住脾气 | 弟弟的脾气很暴躁。 |
| **淹没** | 大水漫过 | 洪水淹没了庄稼。 |
| **灌溉** | 浇水、滋润 | 水能灌溉田地，帮助庄稼生长。 |
| **灾害** | 灾难祸害 | 洪水是一种自然灾害。 |
| **变成** | 从一种变成另一种 | 水可以变成汽。 |
| **太阳** | 天上的太阳 | 太阳一晒，水就变成汽。 |
| **云** | 天上的云朵 | 水蒸气升到天上变成云。 |
| **早晨** | 早上 | 早晨的云像一层薄纱。 |
| **傍晚** | 快天黑的时候 | 傍晚的云被染成了红色。 |
| **红袍** | 红色的袍子 | 早晨和傍晚，云披上红袍。 |

### 💡 动作词积累
> "小水滴**聚**在一起**落**下来。"
> "小硬球**打**下来。"
> "小雪花**飘**下来。"

**落、打、飘**——用不同的动词写不同的状态，精准！

### ⚠️ 易错字提醒
| 字 | 易错点 | 记忆口诀 |
|:---|:-------|:---------|
| **变** | 上面是"亦"少一点，下面是"又" | "亦"字少一点，加个"又"就变 |
| **海** | 右边是"每"，不是"母" | 三点水+"每"人都是大海 |
| **洋** | 右边是"羊"，上面是"丷" | 三点水+"羊"在大洋 |
| **坏** | 左边是土字旁，右边是"不" | 土里加"不"就是坏 |
| **给** | 左边是绞丝旁，右边是"合" | 丝线（纟）+"合"在一起就是给 |

### 🔍 形近字辨析
| 字 | 组词 | 易混字 | 组词 | 区分方法 |
|:---|:-----|:-------|:-----|:---------|
| **雹** | 冰雹 | **泡** | 水泡 | 雨字头是冰雹，三点水是泡泡 |
| **淹** | 淹没 | **掩** | 掩护 | 三点水是水淹，提手旁是手掩 |
| **晒** | 晒太阳 | **洒** | 洒水 | 日字旁是晒，三点水是洒 |
| **温** | 温和 | **湿** | 潮湿 | 日上加皿是温，水边显是湿 |

### 🎵 多音字总结
| 字 | 读音 | 组词 | 读音 | 组词 |
|:---|:-----|:-----|:-----|:-----|
| **没** | méi | 没有 | mò | 淹没、沉没 |
| **为** | wéi | 成为 | wèi | 因为、为什么 |
| **好** | hǎo | 好人 | hào | 好客、爱好 |
| **的** | de | 好的 | dí | 的确 |
| **种** | zhǒng | 种子 | zhòng | 种地、种花 |

### 🧩 偏旁归类
| 偏旁 | 字 | 说明 |
|:-----|:---|:-----|
| **氵**（三点水） | 海、洋、温、淹、没 | 都和水有关 |
| **冫**（两点水） | 冰、冷、凉、冲 | 都和水、寒冷有关 |
| **雨**（雨字头） | 雹、雷、雪、雾、霜 | 都和天气现象有关 |
| **日**（日字旁） | 晒、晴、暖、明 | 都和太阳有关 |

### 📝 词语采蜜集

**四字词语**
- 越升越高、四海为家、狂风暴雨

**近义词**
- 温和—温柔、暴躁—急躁、帮助—帮忙

**反义词**
- 温和—暴躁、升—降、高—低、早晨—傍晚

## 3 植物妈妈有办法

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:----|:-----|:-----|
| **旅行** | 出门远行 | 蒲公英的孩子要去旅行。 |
| **蒲公英** | 一种开黄花、种子带绒毛的植物 | 蒲公英的种子像小伞兵。 |
| **降落伞** | 从空中慢慢下降的伞 | 蒲公英的种子像一个小小的降落伞。 |
| **苍耳** | 种子带刺的植物 | 苍耳的小刺能挂住动物的皮毛。 |
| **豌豆** | 豆荚成熟后会炸开 | 豌豆妈妈让豆荚晒在太阳底下。 |
| **炸开** | 突然裂开 | 豆荚被太阳晒得炸开了。 |
| **纷纷** | 多而杂乱地 | 种子纷纷从豆荚里蹦出来。 |
| **山洼** | 山里的低处 | 蒲公英的种子落在山洼里。 |
| **铠甲** | 古代战士的护甲 | 苍耳穿上带刺的铠甲。 |
| **知识** | 知道和了解的事物 | 植物妈妈的办法真多，我们要多学知识。 |
| **仔细** | 认真、细心 | 只要仔细观察，就能发现植物的秘密。 |
| **粗心** | 不细心 | 粗心的小朋友却得不到它。 |

## ✍️ 写话：用动作词写几句话

### 🎯 目标
用上**至少3个表示动作的词**写一段话，写清楚一件事。

### 📐 小提示
1. 想好要写什么（可以写小动物、放学路上、做家务……）
2. 把"做了什么"拆成一连串动作
3. 写完读一读，看看动作词用准了没

### 🏪 词语小宝库

**动作词分类**
| 类别 | 词语 |
|:-----|:-----|
| 手的动作 | 拿、捧、端、抱、抓、扔、接、拍、打、提 |
| 脚的动作 | 跑、跳、踢、踩、跨、蹦、爬、追、走 |
| 嘴的动作 | 吃、喝、咬、吞、舔、吹、喊、唱 |
| 眼睛的动作 | 看、望、盯、瞪、眯、瞧、扫、瞄 |

### 📝 示例

> 早上，我**背**起书包**走**出家门。路上**看**见一只小猫咪**跳**上台阶。我**蹲**下来**摸**了摸它的头，它**喵**了一声，**跑**走了。

> 妈妈在厨房里**忙**着。她先**洗**菜、**切**菜，再**打**开火**倒**油，"刺啦"一声把菜**倒**进锅里，**翻**炒几下，一盘香喷喷的菜就**端**上了桌。

> 放学了，小明**收**起书本**塞**进书包，**跑**出教室。他在操场上**追**着足球，**踢**了一脚，球**飞**了出去。他**笑**着**擦**了擦汗。

### ⚠️ 注意
❌ "我做了饭" → ✅ "我**洗**菜、**切**菜、**炒**菜，一碗香喷喷的蛋炒饭就**端**上了桌。"



### 💡 写话小锦囊

#### 1. 从课文里学方法
从"小蝌蚪找妈妈"学用动词写几句话——把一连串动作写清楚。
> 小蝌蚪**甩**着尾巴**游**过去，**追**上去**叫**着"妈妈！"——三个动词写出急切的心情。

#### 2. 想好了再写
提笔之前先想一想：
- 我要写什么？（是写一个人、一件事，还是一处风景？）
- 用哪几个词或句式来写？（从课文里学到的）
- 先写什么，再写什么？（想好顺序再动笔）

想清楚了再写，写的时候就不慌了。

#### 3. 写真的，写自己的
写你真正看到、听到、想到的。不用编，不用抄。
- 写自己的事——哪怕是一件很小的事
- 写自己的话——用你自己会说的词
- 写真实的感受——开心就写开心，难过就写难过

> 作文不是为了写给别人看，而是为了记下自己的故事。
