## 1 场景歌

### 📖 课文概要
一幅幅画面：海边的军舰和帆船、乡村的稻田和鱼塘、公园的石桥和翠竹、校园的队旗和铜号——量词歌，朗朗上口。

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:----|:-----|:-----|
| **海鸥** | 海上的鸟 | 一只海鸥在海面上飞翔。 |
| **沙滩** | 海边沙地 | 孩子们在沙滩上堆沙堡。 |
| **军舰** | 军用大船 | 一艘军舰在大海上航行。 |
| **帆船** | 用帆的船 | 远处的帆船像一片叶子。 |
| **稻田** | 种水稻的田 | 一片稻田金黄金黄的。 |
| **鱼塘** | 养鱼的池塘 | 一方鱼塘里养了很多鱼。 |
| **石桥** | 石头做的桥 | 弯弯的石桥像半个月亮。 |
| **翠竹** | 绿色的竹子 | 一丛翠竹在风中摇摆。 |
| **队旗** | 少先队旗 | 一面队旗在操场上飘扬。 |
| **铜号** | 铜做的喇叭 | 他吹起铜号，声音真响亮。 |
| **红领巾** | 少先队员的标志 | 一群"红领巾"在打扫卫生。 |

### 💡 量词积累
一只海鸥、一片沙滩、一艘军舰、一条帆船
一方鱼塘、一块稻田、一座石桥、一丛翠竹
一面队旗、一把铜号、一群"红领巾"

**一只/一片/一艘/一条——量词不能乱用！**

### ⚠️ 易错字提醒
| 字 | 易错点 | 记忆口诀 |
|:---|:-------|:---------|
| **桥** | 右边是"乔"，第一笔是撇 | 木字旁+"乔"字组成桥 |
| **队** | 左边是"阝"（左耳旁），不是"人" | 左耳旁+人=队伍的人 |
| **旗** | 右边是"其"，不是"共" | 方人+"其"=旗帜 |
| **舰** | 右边是"见"，不是"贝" | 舟字旁+"见"=军舰 |
| **铜** | 右边是"同"，不是"司" | 金字旁+"同"=铜 |

### 🔍 形近字辨析
| 字 | 组词 | 易混字 | 组词 | 区分方法 |
|:---|:-----|:-------|:-----|:---------|
| **鸥** | 海鸥 | **欧** | 欧洲 | 鸟字旁是海鸥，欠字旁是欧洲 |
| **舰** | 军舰 | **航** | 航空 | 舟+见=舰，舟+亢=航 |
| **稻** | 稻田 | **蹈** | 舞蹈 | 禾字旁是稻谷，足字旁是舞蹈 |
| **桥** | 石桥 | **娇** | 娇气 | 木字旁是桥，女字旁是娇 |

### 🎵 多音字总结
| 字 | 读音 | 组词 | 读音 | 组词 |
|:---|:-----|:-----|:-----|:-----|
| **把** | bǎ | 一把伞 | bà | 刀把儿 |
| **号** | hào | 铜号、学号 | háo | 号叫、号啕大哭 |
| **量** | liàng | 重量 | liáng | 量尺寸 |
| **的** | de | 好的 | dí | 的确 | dì | 目的 |

### 🧩 偏旁归类
| 偏旁 | 字 | 说明 |
|:-----|:---|:-----|
| **舟**（舟字旁） | 舰、船、艘、航 | 都和船有关 |
| **钅**（金字旁） | 铜、铁、银、铅 | 都和金属有关 |
| **阝**（左耳旁） | 队、阳、阴、阵 | 和地形、升降有关 |
| **纟**（绞丝旁） | 红、领、绿、纸 | 都和丝织品有关 |

### 📝 词语采蜜集

**四字词语**
- 四面八方、五颜六色

**近义词**
- 一座—一个、一群—一堆、漂亮—美丽

**反义词**
- 大—小、多—少、远—近、高—低

## 2 树之歌

### 📖 课文概要
杨树高、榕树壮、梧桐叶像手掌；枫叶秋天红，松柏四季绿；木棉喜暖，桦树耐寒。每棵树都有自己的特点。

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:----|:-----|:-----|
| **梧桐** | 一种叶子像手掌的树 | 道路两旁种满了梧桐树。 |
| **手掌** | 手心的部分 | 梧桐树的叶子像我们的手掌。 |
| **枫叶** | 枫树的叶子，秋天变红 | 秋天的枫叶像一团团火。 |
| **松柏** | 松树和柏树，四季常青 | 松柏四季披绿装。 |
| **木棉** | 一种开红花的树 | 木棉喜暖在南方。 |
| **桦树** | 树皮白色的树 | 桦树耐寒守北疆。 |
| **银杏** | 叶子像扇子的树 | 银杏水杉活化石。 |
| **水杉** | 古老的树种 | 水杉是植物界的"活化石"。 |
| **桂花** | 开黄色小花、很香的树 | 八月桂花满枝香。 |
| **壮** | 强壮、高大 | 榕树长得又高又壮。 |
| **装扮** | 打扮、装饰 | 枫树把秋天装扮得格外美丽。 |

### 💡 识字规律
**木字旁**的汉字大多和树木有关：杨、榕、梧、桐、枫、松、柏、桦、棉、杉、桂

👉 学会**部首查字法**后，看到木字旁就去"木"部查。

### ⚠️ 易错字提醒
| 字 | 易错点 | 记忆口诀 |
|:---|:-------|:---------|
| **杨** | 右边是"昜"，不是"易" | 木+"昜"=杨树好阳光 |
| **壮** | 右边是"士"，不是"土" | "丬"+"士"才强壮 |
| **枫** | 右边是"风"，不是"凡" | 木+"风"=枫叶随风飘 |
| **装** | 右下是"衣"，不是"女" | 壮士穿"衣"=装 |
| **化** | 右半边是"匕"，不是"七" | 单人旁+"匕"=化石 |

### 🔍 形近字辨析
| 字 | 组词 | 易混字 | 组词 | 区分方法 |
|:---|:-----|:-------|:-----|:---------|
| **柏** | 松柏 | **伯** | 伯伯 | 木字旁是柏树，单人旁是伯父 |
| **棉** | 木棉 | **绵** | 连绵 | 木字旁是棉花，绞丝旁是丝绵 |
| **杉** | 水杉 | **衫** | 衬衫 | 木字旁是杉树，衣字旁是衬衫 |
| **桂** | 桂花 | **挂** | 挂起来 | 木字旁是桂树，提手旁是挂 |

### 🎵 多音字总结
| 字 | 读音 | 组词 | 读音 | 组词 |
|:---|:-----|:-----|:-----|:-----|
| **绿** | lǜ | 绿色 | lù | 绿林 |
| **好** | hǎo | 好看 | hào | 爱好 |
| **干** | gān | 干净 | gàn | 干活、树干 |
| **柏** | bǎi | 松柏 | bó | 柏林 |

### 🧩 偏旁归类
| 偏旁 | 字 | 说明 |
|:-----|:---|:-----|
| **木**（木字旁） | 杨、榕、梧、桐、枫、松、柏、桦、棉、杉、桂 | 都和树木有关 |
| **艹**（草字头） | 花、草、苗、芽 | 都和植物有关 |
| **纟**（绞丝旁） | 绿、红、细、经 | 都和丝线、颜色有关 |
| **扌**（提手旁） | 披、挂、打、拍 | 都和手的动作有关 |

### 📝 词语采蜜集

**四字词语**
- 四季常青、满枝飘香

**近义词**
- 壮—强、喜暖—爱暖、耐寒—抗寒

**反义词**
- 高—矮、壮—弱、暖—寒、新—旧

## 3 拍手歌

### 📖 课文概要
"你拍一，我拍一，动物世界很新奇……"用拍手游戏的方式认识各种动物：孔雀、锦鸡、雄鹰、大雁、老虎、黄鹂、百灵、熊猫。

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:----|:-----|:-----|
| **保护** | 小心爱护 | 我们要保护动物。 |
| **动物** | 鸟兽虫鱼的总称 | 动物是我们人类的朋友。 |
| **自由** | 不受约束 | 小鸟在天空中自由地飞翔。 |
| **朋友** | 友好的人或事物 | 动物和人类是朋友。 |
| **新奇** | 新鲜奇特 | 动物世界很新奇。 |
| **孔雀** | 尾羽很漂亮的鸟 | 孔雀的尾巴像一把大扇子。 |
| **锦鸡** | 羽毛很美的鸟 | 锦鸡的羽毛五颜六色。 |
| **雄鹰** | 大而勇猛的鹰 | 雄鹰在蓝天上飞翔。 |
| **大雁** | 排成人字飞的鸟 | 大雁秋天飞到南方去。 |
| **百灵** | 歌声很好听的鸟 | 百灵鸟的歌声真动听。 |
| **嬉戏** | 游戏、玩耍 | 动物们在森林里嬉戏。 |
| **丛林** | 茂密的树林 | 丛林深处有老虎。 |

### ⚠️ 易错字提醒
| 字 | 易错点 | 记忆口诀 |
|:---|:-------|:---------|
| **保** | 右边是"呆"，不是"朵" | 站人旁+"呆"=保护 |
| **护** | 右边是"户"，不是"卢" | 提手旁+"户"=爱护 |
| **猴** | 右边是"侯"，不是"候" | 反犬旁+"侯"=猴子 |
| **虎** | 第三笔是横钩，不是撇 | "虍"字头要记住 |
| **雀** | 上面是"小"，下面是"隹" | "小"+"隹"=孔雀 |

### 🔍 形近字辨析
| 字 | 组词 | 易混字 | 组词 | 区分方法 |
|:---|:-----|:-------|:-----|:---------|
| **鹰** | 雄鹰 | **雁** | 大雁 | 广字头是鹰，厂字头是雁 |
| **歌** | 唱歌 | **喝** | 喝水 | 欠字旁是唱歌，口字旁是喝水 |
| **丛** | 丛林 | **从** | 从前 | 一横加"从"是丛林 |
| **拍** | 拍手 | **怕** | 害怕 | 提手旁是拍，竖心旁是怕 |

### 🎵 多音字总结
| 字 | 读音 | 组词 | 读音 | 组词 |
|:---|:-----|:-----|:-----|:-----|
| **间** | jiān | 中间 | jiàn | 间隔、间接 |
| **处** | chù | 到处 | chǔ | 相处、处理 |
| **好** | hǎo | 友好 | hào | 好动 |
| **着** | zhe | 看着 | zháo | 着急 | zhuó | 衣着 |

### 🧩 偏旁归类
| 偏旁 | 字 | 说明 |
|:-----|:---|:-----|
| **鸟**（鸟字旁） | 鸽、鹅、鸭、鸡 | 都和鸟类有关 |
| **隹**（隹字旁） | 雀、雁、雄、鹰 | 也是鸟类的意思 |
| **豸**（反犬旁） | 猴、狮、猫、狗 | 都和兽类有关 |
| **攵**（反文旁） | 敢、散、收、放 | 和手的动作有关 |

### 📝 词语采蜜集

**四字词语**
- 三五成群、自由自在

**近义词**
- 保护—爱护、新奇—新鲜、嬉戏—玩耍

**反义词**
- 保护—伤害、新—旧、深—浅、大—小

## 4 田家四季歌

### 📖 课文概要
春季里春风吹，花开草长蝴蝶飞；夏季里农事忙，采桑养蚕又插秧；秋季里稻上场，谷像黄金粒粒香；冬季里雪初晴，新做棉衣暖又轻。

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:----|:-----|:-----|
| **播种** | 播撒种子 | 春天农民伯伯忙着播种。 |
| **施肥** | 给庄稼加肥料 | 给麦苗施肥，麦子才能长得好。 |
| **插秧** | 把秧苗插进水田 | 夏天到了，农民在田里插秧。 |
| **耕作** | 耕地种田 | 田家四季都要耕作。 |
| **丰收** | 收获很多 | 秋天是丰收的季节。 |
| **农事** | 农业上的事情 | 夏季里农事忙。 |
| **采桑** | 采摘桑叶 | 采桑养蚕又插秧。 |
| **蚕** | 吐丝做茧的虫 | 春蚕到死丝方尽。 |
| **稻谷** | 水稻的果实 | 稻谷像黄金一样闪着光。 |
| **棉衣** | 棉花做的衣服 | 穿上新棉衣，又暖又轻。 |
| **辛苦** | 身心劳苦 | 农民伯伯耕作很辛苦。 |
| **归来** | 回来 | 夕阳西下，农民扛着锄头归来。 |

### ⚠️ 易错字提醒
| 字 | 易错点 | 记忆口诀 |
|:---|:-------|:---------|
| **季** | 上面是"禾"，下面是"子" | 禾苗的儿子=季（一年四季） |
| **肥** | 右边是"巴"，不是"已" | 月字旁+"巴"=肥料 |
| **辛** | 上面是"立"，下面是"十" | 站"立"十"年"很辛苦 |
| **苦** | 上面是草字头，下面是"古" | 草（艹）很"古"老=苦 |
| **年** | 第三笔是横，不是撇 | 记住"年"字没有撇 |

### 🔍 形近字辨析
| 字 | 组词 | 易混字 | 组词 | 区分方法 |
|:---|:-----|:-------|:-----|:---------|
| **季** | 季节 | **李** | 李树 | 上面禾是季节，上面木是李树 |
| **吹** | 吹风 | **欢** | 喜欢 | 口字旁是吹，又字旁是欢 |
| **归** | 归来 | **扫** | 扫地 | 彐+巾=归，扌+彐=扫 |
| **粒** | 粒粒香 | **拉** | 拉车 | 米字旁是一粒米，提手旁是拉 |

### 🧩 偏旁归类

## ✍️ 写话：用学过的字词写句子

### 🎯 目标

### 📐 小提示

> **一座**弯弯的**石桥**架在河上，桥边有一**丛翠竹**。几只**海鸥**从天空飞过，远处停着**一艘军舰**。这里的风景真美啊！

### 💡 写话小锦囊

#### 1. 从课文里学方法
从"场景歌""树之歌"学用字词写句子——用上量词和树名写一个场景。
> **一棵**高大的**梧桐树**站在路边，**一只**小鸟在枝头唱歌。

#### 2. 想好了再写
提笔之前先想一想：
- 我要写什么？（是写一个人、一件事，还是一处风景？）
- 用哪几个词或句式来写？（从课文里学到的）
- 先写什么，再写什么？（想好顺序再动笔）

想清楚了再写，写的时候就不慌了。

#### 3. 写真的，写自己的
写你真正看到、听到、想到的。不用编，不用抄。
- 写自己的事——哪怕是一件很小的事
- 写自己的话——用你自己会说的词
- 写真实的感受——开心就写开心，难过就写难过

> 作文不是为了写给别人看，而是为了记下自己的故事。
