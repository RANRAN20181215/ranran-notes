# 🐸 小蝌蚪找妈妈

> 科普童话

---

## 📖 读一读

池塘里有一群小蝌蚪，大大的脑袋，黑灰色的身子，甩着长长的尾巴，快活地游来游去。

小蝌蚪先遇到 **鲤鱼妈妈**，问："我们的妈妈在哪里？"
鲤鱼妈妈说："你们的妈妈四条腿，宽嘴巴。到那边去找吧！"

小蝌蚪又遇到 **乌龟**，追着叫："妈妈！妈妈！"
乌龟说："我不是你们的妈妈。你们的妈妈头顶上有两只大眼睛，披着绿衣裳。你们到那边去找吧！"

小蝌蚪游啊游，终于找到了 **青蛙**——大眼睛，绿衣裳，白肚皮，四条腿。他们高兴地叫："妈妈！妈妈！"

青蛙妈妈笑着说："好孩子，你们已经长成青蛙了，快跳上来吧！"

---

## 📜 知背景

这篇课文是一篇 **科普童话**——用故事的形式讲科学知识。

小蝌蚪找妈妈的过程，其实就是在讲 **青蛙的成长过程（变态发育）**：

**小蝌蚪 → 长后腿 → 长前腿 → 尾巴变短 → 变成青蛙**

青蛙是 **两栖动物**——小时候在水里生活（像鱼一样用鳃呼吸），长大了可以上岸生活（用肺呼吸和皮肤呼吸）。

## 💡 讲一讲

**小蝌蚪找妈妈的路上，自己也悄悄在变化！** 🐸✨

池塘里有一群小蝌蚪，黑黑的、圆圆的，拖着一条小尾巴游来游去。他们想找妈妈，但不知道妈妈长什么样。

他们问鲤鱼妈妈——鲤鱼妈妈说："你们妈妈四条腿，宽嘴巴。"
他们看到乌龟四条腿，就叫妈妈——乌龟说："不对！你们妈妈大眼睛，绿衣裳。"

小蝌蚪游啊游，自己也慢慢发生了变化：先长后腿🦵，再长前腿🦵，尾巴越来越短……

最后他们终于找到了青蛙妈妈——哇！和自己长得一样：大眼睛、绿衣裳、四条腿！

妈妈说："你们已经长大了！" 🥹

## 🧩 想一想

| 小蝌蚪问谁 | 得到了什么信息 |
|---|---|
| 🐟 **鲤鱼妈妈** | 四条腿，宽嘴巴 |
| 🐢 **乌龟** | 大眼睛，绿衣裳 |

**❓ 为什么小蝌蚪长得不像妈妈？**
> 因为青蛙是 **变态发育**。小蝌蚪先长尾巴在水里游，像一条小鱼。然后慢慢长出腿、褪掉尾巴，最后才变成青蛙的样子。

## 📝 知识小卡片

### 🐸 青蛙的成长过程

```
卵 → 小蝌蚪（有尾巴）→ 长后腿 → 长前腿 
→ 尾巴变短 → 幼蛙 → 成蛙
```
整个过程大约需要 **2—3个月**。

## 📎 拓展小故事

### 🌍 全世界的"小蝌蚪"

不仅中国小朋友学《小蝌蚪找妈妈》，这个故事还被拍成了 **中国第一部水墨动画片**（1960年）！

这部动画片全部用 **中国水墨画** 的风格制作，画面就像会动的齐白石画作一样。在国际上拿了很多奖，是中国的骄傲！🏆

而且你知道吗？青蛙一年可以吃掉 **上万只害虫**，是农民伯伯的好帮手！🌾🐸
