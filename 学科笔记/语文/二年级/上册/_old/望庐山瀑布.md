# 🌊 望庐山瀑布

> **〔唐〕李白**

---

## 📖 读一读

日照 / 香炉 / 生紫烟，↗️
遥看 / 瀑布 / 挂前川。↘️
飞流 / 直下 / 三千尺，↗️
疑是 / 银河 / 落九天。↘️

> ⏸️ 读出惊叹的语气——李白被眼前的瀑布震撼到了！

## 📜 知诗人

**李白**——"诗仙"，我们都很熟悉了。

李白一生喜欢 **旅游** 和 **喝酒** 🍶🌍。他游遍了中国的名山大川，特别偏爱庐山——这座山他去了 **五次** ！

大约50岁时，李白来到江西庐山。远远地看到香炉峰旁边的瀑布，像一条白色的巨幅帘子挂在山前。

李白平时就爱夸张，看到这么壮观的瀑布，他的 **"夸张病"** 又犯了：这瀑布有三千尺那么高！是天上的银河掉下来了吧！？

> 李白的诗总是充满 **神奇的想象力**，别人看到瀑布说"好高啊"，李白却说"银河落九天"！

---

## 🌿 解词语

| 词语 | 意思 | 小提示 |
|---|---|---|
| **香炉** | 香炉峰 | 🏔️ 庐山上的一座山峰 |
| **生紫烟** | 升起紫色的烟雾 | 🌫️ 阳光照射水汽形成的颜色 |
| **遥看** | 远远地看 | 👀 从远处看全景 |
| **挂前川** | 像一条大河挂在山前 | 瀑布挂在山前，像挂着的白布 |
| **三千尺** | 很高很高 | 📏 夸张的说法，不是真的三千尺 |
| **九天** | 天空的最高处 | ☁️ 古人认为天有九层 |

## 💡 讲一讲

**李白看到庐山瀑布，整个人都惊呆了！** 😲🌊

太阳照在香炉峰上
水汽升腾，变成了紫色的烟雾，美极了！🌫️✨

远远看去，瀑布像一条 **白色的巨幅绸缎** 挂在山前
"哗啦啦——"的声音震耳欲聋💥💧

李白瞪大眼睛：
"哇！这水流从三千尺高的地方直冲下来！
简直像天上的银河掉下来了！" 🌌💫

> 别人写瀑布："有一条瀑布"，李白写瀑布："银河落九天"。这就是诗仙和普通人的区别！🌟

## 🧩 想一想

| 李白看到的 | 用了什么手法 | 效果 |
|---|---|---|
| 📏 **三千尺** | 夸张 | 让人感觉瀑布特别高 |
| 🌌 **银河落九天** | 夸张 + 想象 | 让人感觉瀑布像仙境 |
| 🌫️ **生紫烟** | 写实 | 写出了阳光下的水汽 |

**❓ 李白为什么这么喜欢用"三千尺""九万里"这种大数字？**
> 因为李白是 **浪漫主义诗人**，他看到的不是"真实"，而是"感觉"——瀑布真的有三千尺吗？不一定。但李白心里的感觉就是"三千尺"！这叫 **艺术夸张** 🎨

## 📎 拓展小故事

### 🍶 李白在庐山的"神仙生活"

李白五次上庐山，有一次干脆在山上住了大半年。

他每天做什么呢？

**第一件事：喝酒** 🍶
李白无酒不欢。他在庐山一边喝酒一边看瀑布，喝醉了就躺在石头上睡觉。

**第二件事：写诗** ✍️
他在庐山写了20多首诗！除了《望庐山瀑布》，还有《庐山谣寄卢侍御虚舟》等名篇。

**第三件事：炼丹** 🧪
李白晚年迷上了"炼丹术"，想炼出长生不老的仙丹……当然没炼成。

有一次，李白的粉丝 —— 一个叫 **汪伦** 的人（没错，就是"桃花潭水深千尺"那个汪伦）请他去玩。李白说：
"等等，让我在庐山再看几天瀑布！"

> 李白在庐山上写下"疑是银河落九天"的时候，也许真的觉得自己离天上神仙不远了 ✨☁️
