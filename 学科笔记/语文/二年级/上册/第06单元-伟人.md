# 第六单元 · 伟人

> 大禹治水三过家门不入、朱德和战士们一起挑粮、周总理和傣族人民一起过泼水节——伟人的故事让人感动。

## 1 大禹治水

### 📖 课文概要
很久以前洪水泛滥，百姓日子过得很苦。鲧用"堵"的办法没成功。他的儿子禹用"疏通"的办法——把水引到大海里。禹在外治水十三年，三次路过家门都没进去。最终洪水退了，百姓过上了好日子。

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:----|:-----|:-----|
| **洪水** | 大水 | 洪水淹没了村庄和农田。 |
| **泛滥** | 水到处流 | 河水泛滥，冲毁了房屋。 |
| **驱逐** | 赶走 | 大禹要把洪水驱逐走。 |
| **恢复** | 变回原来的样子 | 洪水退了，人们恢复了正常生活。 |
| **幸福** | 生活好、快乐 | 百姓过上了幸福的生活。 |
| **灾难** | 灾祸、苦难 | 洪水给人们带来了巨大的灾难。 |
| **百姓** | 人民、人们 | 大禹为了百姓治水。 |
| **治理** | 管理、处理 | 大禹用了十三年的时间治理洪水。 |
| **疏通** | 打通、让水流通 | 大禹用疏通的办法治水。 |
| **淹没** | 大水漫过 | 洪水淹没了田地。 |
| **十三年** | 十三年时间 | 大禹治水用了十三年。 |
| **伟大** | 非常了不起 | 大禹是一位伟大的英雄。 |

### 💡 联想画面
> "禹在外治水十三年，三次路过自己的家门，都没有进去看一看。"
>
> → **闭上眼睛想一想**：禹路过家门口，听见家人的声音，他多想进去啊！但他没有……

### ⚠️ 易错字提醒
| 字 | 易错点 | 记忆口诀 |
|:---|:-------|:---------|
| **洪** | 右边是"共"，不是"其" | 三点水+"共"=洪水 |
| **灾** | 上面是"宀"，下面是"火" | 房子（宀）着"火"=灾难 |
| **难** | 右边是"隹"，不是"住" | 又+"隹"=困难 |
| **道** | 上面是"首"，下面是"辶" | "首"+走之=道路 |
| **年** | 第三笔是横，不是撇 | 年字中间那一横要记住 |

### 🔍 形近字辨析
| 字 | 组词 | 易混字 | 组词 | 区分方法 |
|:---|:-----|:-------|:-----|:---------|
| **洪** | 洪水 | **哄** | 哄人 | 三点水是水，口字旁是哄 |
| **灾** | 灾难 | **栽** | 栽树 | 宀+火=灾，木+戈+衣=栽 |
| **被** | 被动 | **披** | 披上 | 衣字旁是被子，提手旁是披 |
| **理** | 治理 | **里** | 里面 | 王字旁+里=道理 |

### 🎵 多音字总结
| 字 | 读音 | 组词 | 读音 | 组词 |
|:---|:-----|:-----|:-----|:-----|
| **难** | nán | 困难 | nàn | 灾难、苦难 |
| **没** | méi | 没有 | mò | 淹没、沉没 |
| **为** | wéi | 成为 | wèi | 为了、因为 |
| **行** | xíng | 行走 | háng | 行业 |
| **处** | chù | 到处 | chǔ | 处理、相处 |

### 🧩 偏旁归类
| 偏旁 | 字 | 说明 |
|:-----|:---|:-----|
| **氵**（三点水） | 洪、治、淹、没、漫 | 都和水有关 |
| **辶**（走之底） | 道、通、过、远、近 | 都和行走有关 |
| **宀**（宝盖头） | 灾、安、定、家 | 都和房屋有关 |
| **隹**（隹字旁） | 难、雄、雅、雁 | 都和鸟类有关（难有困难意） |

### 📝 词语采蜜集

**四字词语**
- 洪水泛滥、安居乐业、千辛万苦、三过家门而不入

**近义词**
- 治理—整治、恢复—复原、幸福—快乐、辛苦—辛劳

**反义词**
- 幸福—痛苦、疏通—堵塞、成功—失败、伟大—渺小

## 2 朱德的扁担

### 📖 课文概要
朱德同志和红军战士一起在井冈山，要翻山越岭去挑粮。战士们心疼朱德年纪大，把他的扁担藏了起来。朱德又找了一根扁担，写上"朱德的扁担"，继续和战士一起挑粮。

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:----|:-----|:-----|
| **扁担** | 挑东西用的棍子 | 朱德的扁担上有他的名字。 |
| **同志** | 志同道合的人 | 朱德同志是战士们的榜样。 |
| **队伍** | 军队 | 红军队伍在山上驻扎。 |
| **心疼** | 心里舍不得 | 战士们心疼朱德年纪大。 |
| **敬爱** | 尊敬热爱 | 大家敬爱朱德同志。 |
| **争着** | 抢着去做 | 战士们争着去挑粮。 |
| **不料** | 没想到 | 不料，扁担被人藏了起来。 |
| **越发** | 更加 | 大家越发敬爱朱德同志了。 |
| **山路** | 山上的路 | 山路很难走。 |
| **粮食** | 吃的、食物 | 战士们要下山挑粮食。 |
| **会师** | 几支队伍会合 | 井冈山会师是重要历史事件。 |
| **战士** | 军人 | 红军战士很勇敢。 |

### 💡 联想画面
> "朱德同志也跟战士们一块儿去挑粮。"
> "大家见了，越发敬爱朱德同志，不好意思再藏他的扁担了。"
>
> → 大家都想照顾他，他却说"我和大家一样"。**以身作则**的伟人。

### ⚠️ 易错字提醒
| 字 | 易错点 | 记忆口诀 |
|:---|:-------|:---------|
| **扁** | 里面是"𠤎"+"冂" | "户"加"冂"=扁担 |
| **担** | 右边是"旦"，不是"旦"加一点 | 扌+"旦"=担子 |
| **志** | 上面是"士"，不是"土" | "士"+"心"=志气 |
| **伍** | 右边是"五"，不是"午" | 单人旁+"五"=队伍 |
| **疼** | 外面是"疒"，里面是"冬" | 病（疒）+"冬"=心疼 |

### 🔍 形近字辨析
| 字 | 组词 | 易混字 | 组词 | 区分方法 |
|:---|:-----|:-------|:-----|:---------|
| **扁** | 扁担 | **偏** | 偏旁 | 扁加单人旁是偏 |
| **担** | 扁担 | **胆** | 胆量 | 提手旁是担，月字旁是胆 |
| **敬** | 敬爱 | **警** | 警察 | 苟+攵=敬，苟+言=警 |
| **伍** | 队伍 | **五** | 五光十色 | 单人旁加了就是伍 |

### 🎵 多音字总结
| 字 | 读音 | 组词 | 读音 | 组词 |
|:---|:-----|:-----|:-----|:-----|
| **扁** | biǎn | 扁担 | piān | 扁舟（小船） |
| **挑** | tiāo | 挑粮、挑担 | tiǎo | 挑拨、挑战 |
| **藏** | cáng | 藏起来 | zàng | 西藏、宝藏 |
| **重** | zhòng | 重量 | chóng | 重新 |

### 🧩 偏旁归类
| 偏旁 | 字 | 说明 |
|:-----|:---|:-----|
| **扌**（提手旁） | 担、挑、藏（右下）、找 | 都和手的动作有关 |
| **亻**（单人旁） | 伍、位、们、仗 | 都和人有关 |
| **心**（心字底） | 志、忘、念、想 | 都和思想、心情有关 |
| **疒**（病字头） | 疼、痛、病、疾 | 都和疾病有关 |

### 📝 词语采蜜集

**四字词语**
- 翻山越岭、争着挑粮、以身作则

**近义词**
- 心疼—疼爱、敬爱—尊敬、越发—更加、不料—没想到

**反义词**
- 敬爱—厌恶、心疼—嫌弃、难—易、轻—重

## 3 难忘的泼水节

### 📖 课文概要
1961年，周总理来到西双版纳和傣族人民一起过泼水节。总理身穿傣族服装，和群众互相泼水祝福。大家的笑声、水花、快乐心情，让这个泼水节特别难忘。

### 🌿 重点词语
| 词语 | 解释 | 例句 |
|:----|:-----|:-----|
| **泼水节** | 傣族传统节日 | 泼水节是傣族最隆重的节日。 |
| **傣族** | 我国少数民族之一 | 傣族人民生活在云南。 |
| **龙船** | 装饰成龙的船 | 江面上划着一条条龙船。 |
| **花炮** | 节日的礼花 | 花炮升上天空，五彩缤纷。 |
| **令人难忘** | 让人忘不了 | 这个泼水节令人难忘。 |
| **祝福** | 祝愿、希望别人好 | 周总理向人们泼水祝福。 |
| **健康** | 身体好 | 总理祝大家健康长寿。 |
| **幸福** | 快乐、美满 | 人们脸上洋溢着幸福的笑容。 |
| **欢呼** | 高兴地呼喊 | 人们欢呼着迎接总理。 |
| **象脚鼓** | 傣族乐器 | 人们敲起象脚鼓，跳起舞。 |
| **地毯** | 铺在地上的厚布 | 地面上铺着红地毯。 |
| **敬爱** | 尊敬爱戴 | 总理受到了各族人民的敬爱。 |

### 💡 联想画面
> "周总理一手端着盛满清水的银碗，一手拿着柏树枝蘸了水，向人们泼洒，为人们祝福。"
>
> → 水花在阳光下闪闪发光，每个人的脸上都笑开了花！

### ⚠️ 易错字提醒
| 字 | 易错点 | 记忆口诀 |
|:---|:-------|:---------|
| **泼** | 右边是"发"，不是"发" | 三点水+"发"=泼水 |
| **族** | 右边是"𫠩"+"矢"，不是"方"+"人"+"矢" | 方+人+矢=民族 |
| **龙** | 第三笔是撇，第四笔是竖弯钩 | "龙"字像一条龙在跳舞 |
| **令** | 上面有一点，和"今"不同 | 有点是"令"，没点是"今" |
| **敬** | 左边是"苟"少一横，右边是"攵" | "苟"+"攵"=敬爱 |

### 🔍 形近字辨析
| 字 | 组词 | 易混字 | 组词 | 区分方法 |
|:---|:-----|:-------|:-----|:---------|
| **泼** | 泼水 | **拨** | 拨开 | 三点水是泼，提手旁是拨 |
| **族** | 民族 | **旅** | 旅行 | 方+人+矢=族，方+人+辰=旅 |
| **令** | 命令 | **今** | 今天 | 有点是令，没点是今 |
| **驶** | 行驶 | **使** | 使用 | 马字旁是驶，单人旁是使 |

| 字 | 读音 | 组词 | 读音 | 组词 |
|:---|:-----|:-----|:-----|:-----|
| **盛** | shèng | 盛大 | chéng | 盛饭、盛水 |
| **好** | hǎo | 好像 | hào | 好客 |
| **长** | cháng | 长寿 | zhǎng | 生长、长大 |

| **铺** | pū | 铺开、铺路 | pù | 店铺、床铺 |

### 🧩 偏旁归类
| 偏旁 | 字 | 说明 |
|:-----|:---|:-----|
| **氵**（三点水） | 泼、江、泛、浪 | 都和水有关 |
| **攵**（反文旁） | 敬、散、收、放 | 和手的动作有关 |

## ✍️ 写话：学写日记

### 🎯 目标
学会写日记，记录一天中印象最深的事。

### 📐 格式
```
X月X日  星期X    天气：晴/阴/雨

（正文空两格，写今天发生的事）
```

### 📝 示例
> 3月12日  星期二  天气：晴
>
> 今天学校组织我们去植树。我拿起小铲子挖了一个坑，把树苗放进去，填上土，再浇上水。看着小树站得直直的，我真高兴！希望它快快长大。

### 🏪 词语小宝库

**日记常用词**
| 类别 | 词语 |
|:-----|:-----|
| 时间 | 今天、早上、中午、下午、放学后、晚上 |
| 天气 | 晴、多云、阴天、小雨、大雨、雪天 |
| 心情 | 高兴、激动、感动、难过、生气、紧张、得意 |
| 感受 | 开心极了、难忘的一天、收获满满、真不容易 |
| 连接词 | 先……然后……接着……最后…… |
| 感悟词 | 我明白了、我学会了、我觉得、我想起 |

### 📝 示例2

> 5月8日  星期三  天气：晴
>
> 今天老师给我们讲了《大禹治水》的故事。大禹为了治水十三年没回家，三过家门而不入，太伟大了！我想：大禹为什么能坚持这么久？因为他心里装着百姓。我以后也要做一个对别人有帮助的人。

> 10月1日  星期二  天气：阴转晴
>
> 今天我们班竞选班干部，我还报了名呢！我站在讲台上，心怦怦跳，说了自己想当劳动委员的想法。虽然最后只差一票没选上，但我为自己勇敢站上去感到高兴。下次我一定继续努力！

### ⚠️ 注意
- 写真实的事，不用编
- 选一件**印象最深**的事，不是记流水账
- 加上自己的**感受**（高兴、难过、感动……）



### 💡 写话小锦囊

#### 1. 从课文里学方法
从"大禹治水""朱德的扁担"学写日记——把一天中最难忘的事记下来。
> X月X日 星期X 天气：晴  
> 今天老师讲了《大禹治水》的故事。大禹三过家门而不入，太伟大了！

#### 2. 想好了再写
提笔之前先想一想：
- 我要写什么？（是写一个人、一件事，还是一处风景？）
- 用哪几个词或句式来写？（从课文里学到的）
- 先写什么，再写什么？（想好顺序再动笔）

想清楚了再写，写的时候就不慌了。

#### 3. 写真的，写自己的
写你真正看到、听到、想到的。不用编，不用抄。
- 写自己的事——哪怕是一件很小的事
- 写自己的话——用你自己会说的词
- 写真实的感受——开心就写开心，难过就写难过

> 作文不是为了写给别人看，而是为了记下自己的故事。
